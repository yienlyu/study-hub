# 胺基酸氧化與尿素生成（陳顧中）

## 1. 蛋白質消化與泛素

- 胃：pepsin（胃酸活化 pepsinogen）；胰：**trypsin**（切 **Lys、Arg 的羧基端**）、**chymotrypsin**（切芳香族 **Phe、Tyr、Trp** 的羧基端）、carboxypeptidase；小腸：aminopeptidase。
  - 例：RVYIK↓MPFA 用 trypsin 切在 R、K 之後 → **R ／ VYIK ／ MPFA**。
  - **酶原活化連鎖**：腸道 enteropeptidase 先把 trypsinogen 切成 **trypsin** → trypsin 再活化 **chymotrypsinogen、procarboxypeptidase、proelastase**（以及更多 trypsinogen）。胰臟內有 **pancreatic trypsin inhibitor** 防止提早活化。
- 細胞內蛋白質降解：**ubiquitin**（76 個胺基酸的小蛋白）以 **ATP 依賴**的方式接到目標蛋白的 **Lys** 上 → 26S **proteasome** 分解。
  | 酵素 | 名稱 | 工作 |
  |---|---|---|
  | **E1** | ubiquitin-activating enzyme | **用 ATP 活化** ubiquitin 的 C 端 |
  | E2 | ubiquitin-conjugating enzyme | 接手攜帶 ubiquitin |
  | **E3** | ubiquitin ligase | **決定辨識哪個標的蛋白**（專一性），把 ubiquitin 接上去 |
  - 鍵結：ubiquitin C 端的 carboxyl 與標的 **Lys 側鏈 ε-amino group** 形成 **isopeptide bond**。

## 2. 胺基的去除：轉胺與氧化脫胺 ⭐⭐⭐

- **轉胺（transamination）**：多數胺基酸分解的**第一步**。胺基轉給 **α-ketoglutarate → glutamate**；輔酶 **pyridoxal phosphate（PLP，vitamin B₆）**，以 Schiff base 運作。
  - ALT：alanine + α-KG ⇌ pyruvate + glutamate；AST：aspartate + α-KG ⇌ OAA + glutamate
  - **ALT 比 AST 更專一反映肝損傷**：ALT 主要在肝；AST 廣布於肝、心、骨骼肌、腎、腦、紅血球。
  - **PLP 怎麼接**：沒有受質時，PLP 的醛基與酵素活性中心 **Lys 的 ε-amino group** 形成 Schiff base（**internal aldimine**）；受質進來後換成與受質胺基結合（external aldimine）。
- **氧化脫胺**：**glutamate dehydrogenase**（肝粒線體，NAD⁺ 或 NADP⁺）把 glutamate → α-KG + **NH₄⁺**；GTP 抑制、ADP 活化。是調控氧化脫胺的主角。
  - 先轉胺、再脫胺 = **transdeamination**。
  - **Hyperinsulinism-hyperammonemia syndrome**（GDH 持續活化突變）：β 細胞 glutamate 過度氧化成 α-KG → TCA → ATP ↑ → 關 K<sub>ATP</sub> → **insulin 過度分泌 → 低血糖**；肝臟過度氧化脫胺 → **高血氨**。
- PLP 參與的反應：轉胺、**脫羧**（GABA、histamine、dopamine、serotonin）、**ALA synthase（heme）**、**轉硫**（cystathionine β-synthase）、racemization、glycogen phosphorylase、serine dehydratase、serine hydroxymethyltransferase。**不做羧化**（carboxylation 是 biotin）。
- **Asparagine** →（asparaginase）→ aspartate + NH₄⁺ →（AST）→ **OAA**。

## 3. 氨的運輸 ⭐⭐

- **肝外組織 → glutamine**：glutamate + NH₄⁺ + ATP →（**glutamine synthetase**）→ glutamine（血中最多的胺基酸之一）→ 肝、腎 →（**glutaminase**）→ glutamate + **NH₄⁺**。
- **肌肉 → alanine（glucose-alanine cycle）**：肌肉 pyruvate 轉胺成 alanine → 肝 → 轉胺回 pyruvate（糖質新生）＋胺基進尿素循環。過程包含**糖解、轉胺、糖質新生**；不含肝醣分解、β-oxidation、氧化脫胺。
- 血液中含量高的胺基酸：**alanine、glutamine**（氮的運輸形式）。
- **Glucose-alanine cycle 比 Cori cycle 多做的事**：把骨骼肌的**胺基氮**送到肝臟。肝臟 ALT 產生的是 **glutamate**（不是 glutamine）。
- **肝性腦病變為什麼傷腦**（練習題 125）：大腦**沒有完整的尿素循環**，只能用 glutamate dehydrogenase（α-KG + NH₄⁺ → glutamate）與 glutamine synthetase（glutamate + NH₄⁺ → glutamine）固定氨 → **α-KG 被抽離 TCA** → TCA 變慢、**ATP 不足**。

## 4. 尿素循環 ⭐⭐⭐

| 步驟 | 位置   | 反應                                                                                       |
| ---- | ------ | ------------------------------------------------------------------------------------------ |
| 0    | 粒線體 | NH₄⁺ + HCO₃⁻ + 2 ATP →（**carbamoyl phosphate synthetase I, CPS I**）→ carbamoyl phosphate |
| 1    | 粒線體 | carbamoyl phosphate + **ornithine** →（ornithine transcarbamoylase）→ **citrulline**       |
| 2    | 細胞質 | citrulline + **aspartate** + ATP →（argininosuccinate synthetase）→ argininosuccinate      |
| 3    | 細胞質 | argininosuccinate →（argininosuccinase）→ **arginine + fumarate**                          |
| 4    | 細胞質 | arginine →（arginase）→ **urea** + ornithine                                               |

- 尿素的**兩個氮**：一個來自 **NH₄⁺**（經 carbamoyl phosphate），另一個來自 **aspartate**；碳來自 **HCO₃⁻**。
- **與 TCA 的連結（aspartate-argininosuccinate shunt）**：**fumarate → malate → OAA → aspartate**，所以直接串起兩個循環的是 **fumarate 與 aspartate**。
- 每產生 1 個 urea 消耗 **4 個高能磷酸鍵**（3 ATP → 2 ADP + AMP）。
- **N-acetylglutamate（NAG）**：由 **acetyl-CoA + glutamate**（NAG synthase）合成，**arginine 活化**這個酵素；NAG 是 **CPS I 的必需別構活化劑**。
- 粒線體內的酵素：CPS I、ornithine transcarbamoylase、glutamate dehydrogenase；**glutamine synthetase 不在肝粒線體**。CPS II 在細胞質，做 pyrimidine。
- 直接參與尿素循環的胺基酸：**arginine、aspartate、ornithine、citrulline**（glutamine、alanine、asparagine 不直接參與）。
  - **Ornithine、citrulline 不是**合成蛋白質用的標準胺基酸；ornithine 是第一步的受質，也是最後再生的產物。
- **唯一可逆的步驟**：**argininosuccinase（argininosuccinate lyase）** 切出 arginine + fumarate。
- **能量帳**：CPS I 用 2 ATP（→ 2 ADP）＋ argininosuccinate synthetase 用 1 ATP（→ AMP + PPi，PPi 再水解）= **3 ATP、4 個高能磷酸鍵**。fumarate → malate → OAA 時產生 **1 NADH**（約 2.5 ATP），部分抵銷耗能。
- **尿素的原子**：C 來自 **HCO₃⁻**；N 一個來自游離 **NH₄⁺**、一個來自 **aspartate**（用 ¹⁵N 標記 aspartate → 只標到尿素兩個 N 的其中一個）。
- **不同動物的含氮廢物**：多數硬骨魚 → **氨**；哺乳類、**鯊魚** → **尿素**；鳥類、爬蟲類 → **尿酸**。

### 尿素循環酵素缺陷 ⭐

| 缺陷酵素                         | citrulline             | 其他線索                                                            |
| -------------------------------- | ---------------------- | ------------------------------------------------------------------- |
| CPS I                            | ↓                      | 高血氨                                                              |
| Ornithine transcarbamoylase      | ↓                      | 高血氨；carbamoyl phosphate 溢流去做 pyrimidine → **orotic acid ↑** |
| **Argininosuccinate synthetase** | **↑**（citrullinemia） | argininosuccinate、arginine ↓（練習題 122）                         |
| Argininosuccinate lyase          | ↑                      | **argininosuccinate ↑**，arginine、fumarate 生成 ↓                  |
| Arginase                         | —                      | **arginine ↑**                                                      |

- 判讀原則：**缺陷點上游堆積、下游減少**。arginase 不能直接改用 argininosuccinate。

## 5. 碳骨架去向：生醣 vs 生酮 ⭐⭐

- 胺基酸碳骨架進入 7 個產物：pyruvate、acetyl-CoA、acetoacetyl-CoA、α-KG、succinyl-CoA、fumarate、OAA。
- **純生酮**：**Leu、Lys**。**生酮＋生醣**：**Ile、Phe、Trp、Tyr、Thr**（口訣：3T2LIF → 2L 純生酮，其餘兩者皆是）。其他都是純生醣。
- **產生 propionyl-CoA → methylmalonyl-CoA → succinyl-CoA** 的：**Ile、Met、Thr、Val**（口訣 IMTV）。
- **Leucine** 不能變成 OAA（純生酮）。

## 6. 一碳單位與輔酶 ⭐⭐⭐

| 輔酶                            | 來源             | 關鍵反應                                                                                                                             |
| ------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **THF**（tetrahydrofolate，B₉） | 葉酸             | **N⁵,N¹⁰-methylene-THF**：serine ⇌ glycine、**dUMP → dTMP**；N⁵-methyl-THF：homocysteine → methionine；histidine → FIGLU → glutamate |
| **S-adenosylmethionine（SAM）** | methionine + ATP | 最主要的**甲基供應者**（PC、creatine、epinephrine、DNA 甲基化）                                                                      |
| **Vitamin B₁₂**                 | cobalamin        | **methionine synthase**（homocysteine → Met，搭配 N⁵-methyl-THF）、**methylmalonyl-CoA mutase**                                      |
| **BH₄**（tetrahydrobiopterin）  |                  | **Phe、Tyr、Trp hydroxylase**、**NO synthase**（不是 pyruvate carboxylase、tyrosinase）                                              |
| **PLP（B₆）**                   |                  | 轉胺、脫羧、ALA synthase、轉硫                                                                                                       |
| **Biotin**                      |                  | **carboxylase**（pyruvate、acetyl-CoA、propionyl-CoA carboxylase）                                                                   |
| Niacin（B₃）                    | NAD⁺             | 缺乏 → **pellagra**（可由 Trp 合成）                                                                                                 |

- 必需胺基酸：**His、Ile、Leu、Lys、Met、Phe、Thr、Trp、Val**（兒童 + Arg）。
- **SAM** 由 **methionine + ATP** 形成；給出甲基後成 **S-adenosylhomocysteine（SAH）** → 水解成 homocysteine。
- **Serine hydroxymethyltransferase**（Ser → Gly）：THF 接下一個碳變成 **N⁵,N¹⁰-methylene-THF**，同時需要 **PLP**。
- **Propionyl-CoA → succinyl-CoA** 三步：propionyl-CoA carboxylase（**biotin**）→ D-methylmalonyl-CoA → epimerase → L-methylmalonyl-CoA → mutase（**B₁₂**）。題目問「依序」就是 **biotin → B₁₂**。
- **Thiamin（B₁）缺乏**（如長期酗酒：周邊神經病變、心衰竭）：PDH、α-KG DH、**BCKDH**、**transketolase** 受影響 → pyruvate 進不了 PDH，血中乳酸、丙酮酸 ↑。**Pyruvate carboxylase 不受影響**（它用 biotin）。

### Homocysteine 交叉點：B₁₂、葉酸、B₆ ⭐⭐⭐

- **再甲基化**：homocysteine →（**methionine synthase**，輔酶 **B₁₂**，甲基來自 **N⁵-methyl-THF**）→ methionine。N⁵-methyl-THF 由 **MTHFR** 製造（單行道）。
- **轉硫**：homocysteine + serine →（**cystathionine β-synthase, CBS**，**PLP**）→ cystathionine → cysteine。
- **B₁₂ 的兩份工作**：methionine synthase ＋ **methylmalonyl-CoA mutase**。葉酸只參與前者 → **methylmalonic acid（MMA）用來分辨**：

|              | homocysteine         | MMA   | 補葉酸                       |
| ------------ | -------------------- | ----- | ---------------------------- |
| **葉酸缺乏** | ↑                    | 正常  | 貧血改善                     |
| **B₁₂ 缺乏** | ↑                    | **↑** | 貧血改善，**神經症狀救不了** |
| MTHFR 活性低 | ↑                    | 正常  | 治療補 folate、B₆、B₁₂       |
| CBS 缺乏     | ↑（methionine 也 ↑） | 正常  | 限 Met、補 B₆                |

- **Methyl trap**：B₁₂ 缺 → N⁵-methyl-THF 的甲基交不出去 → 葉酸全卡在這個型態 → 其他葉酸型態不足（**功能性葉酸缺乏**）→ dTMP 合成受阻 → **兩者都造成巨球性貧血**。
- CBS 功能下降但 methionine synthase 正常：受影響的是**轉硫**（homocysteine → cystathionine），不等於 B₁₂ 酵素缺陷，也不影響 methylmalonyl-CoA。

## 7. 先天胺基酸代謝疾病 ⭐⭐⭐

| 疾病                          | 缺陷                                                                         | 重點                                                                                |
| ----------------------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Phenylketonuria（PKU）**    | **phenylalanine hydroxylase**，或 **dihydrobiopterin reductase**（BH₄ 再生） | Phe **轉胺**成 **phenylpyruvate** → phenyllactate、phenylacetate 從尿排出；智能障礙 |
| **Alkaptonuria**              | **homogentisate dioxygenase**                                                | 尿液變黑                                                                            |
| **Albinism**                  | **tyrosinase**                                                               | 無法合成 melanin                                                                    |
| **Maple syrup urine disease** | **branched-chain α-keto acid dehydrogenase**（Leu、Ile、Val 的**氧化脫羧**） | 尿液楓糖漿味；與 Tyr、Pro 無關                                                      |
| **Homocystinuria**            | **cystathionine β-synthase**                                                 | homocysteine 堆積                                                                   |
| **Methylmalonic acidemia**    | methylmalonyl-CoA mutase 或 B₁₂                                              | 與 Val、Ile、Met、Thr 代謝有關                                                      |

<div data-fig="phe-tyr-diseases"></div>

- **PKU 的飲食**：Phe 不能轉成 Tyr → **Tyr 變成條件式必需**，要由飲食補充（不是一起限制）；Tyr 不足 → melanin ↓ → **皮膚白皙**；phenylpyruvate、phenylacetate 等**增加**、尿有怪味。人體沒有 shikimate pathway，無法另外補出 Phe／Tyr。
- **BH₄ 缺乏型 PKU**（DHPR 或 BH₄ 合成缺陷）：Phe ↑ 但 **PAH 蛋白本身正常**；BH₄ 同時是 **Tyr hydroxylase（→ L-DOPA）、Trp hydroxylase（→ 5-HTP）、NOS** 的輔因子 → 腦脊髓液 **dopamine、serotonin 代謝物 ↓**。只限 Phe 不夠，要**補 BH₄ 與神經傳導物質前驅物**。
- **Homocystinuria（CBS 缺乏）**：homocysteine 堆積並回推 → **methionine ↑**；cysteine 改由飲食供應（**條件式必需**）；治療**限 Met、補 B₆**（加 B₁₂、葉酸）；心血管疾病風險 ↑。
- **Methylmalonic acidemia 分型**：血中 MMA、**C3（propionyl）carnitine ↑**。注射 B₁₂ **有效** → B₁₂ 代謝異常；**無效** → mutase 本身缺陷 → 限制經 propionyl-CoA 代謝的 **Met、Thr、Val、Ile**。
- **MSUD**：新生兒 Leu、Ile、Val 及其 α-keto acids 都堆積 → BCKDH（TPP）缺陷。

## 8. 胺基酸衍生物 ⭐⭐

| 衍生物                                                             | 來源                                            | 重點                                                                                           |
| ------------------------------------------------------------------ | ----------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Catecholamines**：DOPA → dopamine → norepinephrine → epinephrine | **Tyrosine**                                    | Tyr hydroxylase（BH₄）、DOPA decarboxylase（**PLP**）、dopamine β-hydroxylase、PNMT（**SAM**） |
| **Serotonin、melatonin、niacin**                                   | **Tryptophan**                                  | Trp hydroxylase（BH₄）；melanin 來自 **Tyr** 不是 Trp                                          |
| **GABA**                                                           | Glutamate（脫羧，PLP）                          |                                                                                                |
| **Histamine**                                                      | Histidine（脫羧）                               |                                                                                                |
| **Creatine**                                                       | **Glycine + Arg**（+ SAM）                      |                                                                                                |
| **Glutathione**                                                    | **Glu、Cys、Gly**                               | 還原型 GSH 清除過氧化物（紅血球）                                                              |
| **Porphyrin（heme）**                                              | **Glycine + succinyl-CoA**（ALA synthase，PLP） |                                                                                                |
| **Nitric oxide**                                                   | **Arginine**（NO synthase，BH₄）                | 活化**可溶性 guanylyl cyclase** → cGMP ↑ → 血管舒張                                            |
| Polyamines                                                         | Ornithine（脫羧）+ SAM                          |                                                                                                |
| Taurine                                                            | Cysteine                                        |                                                                                                |
| Purine 環                                                          | Glycine、Gln、Asp                               |                                                                                                |
| Bile acid 結合                                                     | Glycine、taurine                                |                                                                                                |

- Serine 由糖解中間物 **3-phosphoglycerate** 生成，再變成 glycine、cysteine。芳香族胺基酸在植物、細菌由 **shikimate pathway** 合成（Thr 不是）。
- **Glutathione 的三個酵素**別混：**glutathione peroxidase**（2 GSH → GSSG，清 H₂O₂）、**glutathione reductase**（GSSG → 2 GSH，**NADPH + FAD**）、**glutathione S-transferase, GST**（把 GSH 接到外來藥物上解毒）。
- **Catecholamine 合成**：Tyr →（Tyr hydroxylase，**BH₄**）→ L-DOPA →（DOPA decarboxylase，**PLP**）→ dopamine →（dopamine β-hydroxylase）→ norepinephrine →（**PNMT，SAM 給甲基**）→ epinephrine。
- **Melatonin**：Trp → serotonin → melatonin，**松果腺、夜間**分泌最多（可調時差）。
- **Polyamines**：ornithine →（**ornithine decarboxylase, ODC**，PLP）→ **putrescine** → spermidine → spermine；後兩步由**脫羧後的 SAM（decarboxylated SAM）提供 aminopropyl**，不是甲基。**DFMO** 抑制 ODC → putrescine ↓、spermidine 合成受限（抗寄生蟲）。
- **Creatine 兩步**：**AGAT**（Arg + Gly → **guanidinoacetate**，腎）→ **GAMT**（**SAM** 給甲基 → creatine，肝）→ 肌肉的 creatine kinase 才做 phosphocreatine。抑制 GAMT：guanidinoacetate → creatine 受阻，creatine kinase 本身不受影響。
- **NO**：進入平滑肌活化 **soluble guanylyl cyclase**（GTP → cGMP，不是 adenylyl cyclase）→ 平滑肌鬆弛。
- **Taurine** 來自 **cysteine**，主要功能是**結合膽酸形成膽鹽**。

## 9. Heme 代謝 ⭐⭐

- 合成：**glycine + succinyl-CoA →（ALA synthase，PLP，粒線體）→ δ-aminolevulinate** → porphobilinogen → … → protoporphyrin + Fe²⁺ → heme。**粒線體與細胞質之間來回**進行。
- 分解（脾臟巨噬細胞）：heme →（heme oxygenase）→ biliverdin + **Fe²⁺ + CO** →（還原）→ **bilirubin** → 與 **albumin** 結合送到肝 → **bilirubin diglucuronide** → 膽汁 → 腸道細菌 → **urobilinogen**、stercobilin。
- 含 porphyrin：**heme、chlorophyll、cobalamin**；phycocyanin（藻藍素）是開鏈 tetrapyrrole。
- 未結合 bilirubin 在血中由 **albumin** 運送（不是 haptoglobin、transferrin、hemoglobin）；heme oxygenase 開環放出的是 **CO**（不是 CO₂、NO）。

### 黃疸：哪一種 bilirubin 上升 ⭐⭐

| 情境                                  | 上升的 bilirubin | 機轉                                      |
| ------------------------------------- | ---------------- | ----------------------------------------- |
| **新生兒生理性黃疸**（尤其早產兒）    | **未結合型**     | 肝臟 **UDP-glucuronyltransferase 未成熟** |
| **溶血**（如 G6PD 缺乏 + 氧化性藥物） | **未結合型**     | heme 分解太多，送到肝臟的負荷超過結合能力 |
| 膽道阻塞                              | 結合型           | bilirubin diglucuronide 排不出去          |

- **未結合型不溶於水** → 與 albumin 結合、**不經尿排出**；結合型（diglucuronide）水溶 → 阻塞時尿呈深茶色。
- 紅血球 NADPH 不足 → GSSG 還原不了 → 溶血 → 巨噬細胞分解 heme → **未結合 bilirubin 負荷 ↑**（不是在血中直接變成結合型）。

## 🎙️ 上課錄影重點（陳顧中，Ch23-2 後半〈Ch18-1〉+ Ch18-3）

- 老師：**Ch18 是三章裡最愛考的一章**，即使題數變少，每年至少一到兩題。
- **胺基三來源**：① 吃進來或細胞舊蛋白分解 ② **腸道菌**分解 urea 釋出氨 → 經血送回肝重做尿素（大腸處理不乾淨會有氨味）③ **腎近端小管**的 **glutaminase** 很發達 → 尿中有氨味（炒腰花沒洗乾淨也有）。
- **Ubiquitination**：ubiquitin 是小分子**標記蛋白**；標記要耗 **ATP**；接在目標蛋白的 **lysine（一字縮寫 K）**；E1 → E2 → **E3（ligase，真正把它接上）**；可接很多個 / 不同長度 → 電泳呈**階梯狀 ladder**；送 **proteasome**（小分子蛋白；lysosome 分解胞器）。近年發現也參與 DNA 修補、NF-κB 發炎、**autophagy**。今年暑假醫師國考：「被 ubiquitin 修飾的蛋白**一定**被 proteasome 分解」→ **錯**。
- **轉胺（分解第一步）**：胺基受體 = **α-ketoglutarate** → **glutamate**；酵素 transaminase（aminotransferase），每個胺基酸各有一個；**ALT = GPT、AST = GOT** → 器官（尤其肝）受損時活性越高越嚴重（身體要先分解受損組織）。陷阱：**oxoglutarate = α-ketoglutarate 的舊名**。
- **「三組人馬」（請背起來，靠轉胺互換）：α-KG ⇄ glutamate、pyruvate ⇄ alanine、OAA ⇄ aspartate**（合成非必需胺基酸時也是這三組）。
- **PLP（pyridoxal phosphate）= 維生素 B₆**：轉胺酶輔酶（以 **Schiff base** 接在 Lys）；也是 glycogen phosphorylase 輔酶；參與九大反應：轉胺、**脫羧**、脫胺、**轉硫**、**heme 合成**、racemization（L ⇄ D）、去甲基代謝等。建議背全名。
- **氨的運送**：一般器官 glutamate（酸，大量入血會酸中毒）→ **glutamine synthetase（有 -et- 的 synthetase 需要 ATP；synthase 不用）** → **glutamine** 在血中運送 → **肝臟粒線體** → **glutaminase** → glutamate。
- **Glucose-alanine cycle（肌肉獨有，每兩三年考一次）**：肌肉用 **pyruvate → alanine** 運氨 → 肝 → 轉回 pyruvate → **糖質新生**（alanine 也是糖質新生原料）。（老師說講義 AI 圖的箭頭畫反）
- **為什麼都要變回 glutamate？** 只有 glutamate 能進入肝臟粒線體最內層啟動尿素循環 → **氧化脫胺：glutamate dehydrogenase（不是脫胺酶，考過）** → α-KG + NH₄⁺。**先轉胺、再脫胺**。
- **尿素循環**：在**肝臟**（醫技國考：合成尿素的器官是肝，不是腎）；**開始在粒線體、結束在細胞質**；四步驟只有**第一步在粒線體**。
  - 起始：**NH₄⁺ + HCO₃⁻ + ATP → carbamoyl phosphate**（**CPS I，粒線體，尿素循環**；CPS II 在細胞質，做核苷酸）。「整本生化第一步驟都特別重要」。
  - ① **ornithine（鳥胺酸，真的是胺基酸）+ carbamoyl phosphate →（ornithine transcarbamylase，背全名）→ citrulline**
  - ② citrulline + **aspartate** → argininosuccinate（synthetase，耗 ATP；酵素不重要）。⭐ **aspartate 帶入尿素的第二個胺基**；aspartate 來自 **OAA**。
  - ③ argininosuccinase → **arginine + fumarate**；**fumarate 串起尿素循環與 TCA = aspartate–argininosuccinate shunt**（另有 malate–aspartate shuttle，主要是把細胞質 NADH 帶進電子傳遞鏈）。
  - ④ **arginase** → **urea + ornithine**（「urea + ornithine = arginine」）。
  - 尿素的兩個氮：一個來自**氧化脫胺的 NH₄⁺**、一個來自 **aspartate**（國考陷阱選項：「來自 NH₄⁺ 與 alanine」→ 錯）。
  - **N-acetylglutamate（NAG）** = CPS I 的**異位（allosteric）活化劑**。
- **Ch18-3（續）**：**PKU** 是「第一名愛考」的病（Phe → Tyr 失敗）；Tyr → melanin 失敗 → **albinism**。**Alkaptonuria（第三名會考）**：**homogentisate dioxygenase** 缺乏 → **homogentisate（黑尿酸）**累積在**關節**（尤其脊椎，英國男子由 173 公分縮到 150 多）→ 尿液放室溫 10–15 分鐘變黑、嚴重關節炎、鞏膜變灰、多汗、灰斑。Tyr 代謝路上任一酵素異常 → **高酪胺酸血症（tyrosinemia）**。
- **α-KG 家族**：Glu、Gln、**Arg、His、Pro**；His → formimino-THF → 進核苷酸合成；Arg → ornithine → Glu。
- **Glutathione（只要考到，八成九成考結構，三顆星）**：**tripeptide = Glu + Cys + Gly**。功能：① 清除 ROS：**glutathione peroxidase** 用 2 GSH（還原態）→ GSSG（氧化態，雙硫鍵 dimer）；**glutathione reductase（FAD / B₂ + NADPH，醫學系考過不是 NADH）**還原回 GSH → NADPH 來自 **PPP**（紅血球）② 偏鹼環境下協助蛋白質雙硫鍵摺疊 ③ **GST（glutathione S-transferase）**標記藥物解毒；**γ-glutamyl cycle** 把胞外胺基酸帶進細胞。美白抗皺效果見仁見智（安慰劑效應）。
- **GABA**：glutamate **脫羧（PLP）** → 抑制性神經傳導物質（癲癇、助眠）；glutamate 本身也是神經傳導物質，腦傷（腦震盪）時大量釋放反而加重傷害。今年寒假考題：哪個胺基酸不是神經傳導物質前驅物（Trp → serotonin → melatonin；Tyr → catecholamines）。
- **Polyamines（spermidine、spermine）**：穩定 DNA（精子頭部 DNA 多而得名）；材料 glutamate / arginine → ornithine → 去羧（PLP）；⚠️ **SAM 在這裡的唯一例外：提供甲基以外的含碳骨架**（不是給甲基）；寄生蟲很需要 → 抑制劑（DFMO）可當抗寄生蟲藥。
- **Arg → NO**：**NOS**（iNOS、eNOS）需 **NADPH** 與 **BH₄**；NO 擴張血管（諾貝爾獎）；富含 Arg：**90% 以上的純巧克力**、未調味花生、核桃。**NO → 活化 guanylyl cyclase → cGMP↑ → 平滑肌放鬆、血管擴張**；**PDE（phosphodiesterase）把 cGMP 水解成 GMP**；⚠️ **Viagra 抑制 PDE5**（不是促進 cGMP 生成或 cyclase 活性；十年前連考三四年）。L-arginine 補充品：「天然威而鋼」、增肌、精蟲活動力、降體脂。
- **Histamine**：histidine **去羧（PLP）**；發炎、胃酸分泌、清醒。
- **IMTV → succinyl-CoA**（**I**le、**M**et、**T**hr〔T 有三個，是 threonine〕、**V**al）：經 **propionyl-CoA**（另一個出處：奇數碳脂肪酸）→ **propionyl-CoA carboxylase（biotin）** → methylmalonyl-CoA → **mutase（B₁₂）** → succinyl-CoA。B₁₂ 人體不能製造、易由尿排出 → 要多吃。mutase 或 B₁₂ 異常 → **methylmalonic acidemia**（目前只考「哪個胺基酸代謝異常有關」）。
- **營養師經典難題（1152）**：A「Arg、His、Pro 經 **glutamine** 生成 α-KG」→ 錯（是 **glutamate**）；B「serine 經 serine **hydroxymethyltransferase** 生成 pyruvate」→ 錯（是 serine **dehydratase**）；**C「cysteine 經 cysteine desulfurase → pyruvate」正確**（同一位出題老師連考兩次）；D「Met 生成 α-KG」→ 錯（Met 屬 IMTV → succinyl-CoA）。
- Phe、Tyr → fumarate；**Asp、Asn → OAA**（Asp 參與核苷酸合成）。
- **BCAA（Leu、Ile、Val；R group 有分支）**：運動飲料、能量飲、高蛋白都在加；減少 protein breakdown、**預防抽筋**；⚠️ **不在肝臟分解**（肌肉為主）；**branched-chain α-keto acid dehydrogenase**（輔酶 **TPP = B₁**）缺陷 → **maple syrup urine disease（楓糖尿症**，尿有楓糖甜味、智能障礙、嬰兒死亡；治療可補 B₁）。

## 🎙️ 上課錄影重點（陳顧中，Ch18-2 醫，10/15，1:05:53）

> 前半講六大輔酶（老師：「生化沒有一個老師把這些 cofactor 從頭整合」），後半講碳骨架去向與 Trp、Tyr、Phe 的衍生物和疾病。課中穿插的國考題答案請對照講義（biotin／avidin 題 B、homocysteine 醫技題 B、serine dehydratase 醫師題 C）。

**① Biotin（B₇）** ⭐⭐

- 帶入**一個碳**，來源是 **CO₂ → 碳酸根（HCO₃⁻）**；共價接在酵素的 **lysine** 上。
- 課本三個酵素：**pyruvate carboxylase**（pyruvate C3 → OAA C4，**糖質新生第一步**）、**acetyl-CoA carboxylase**（脂肪酸合成第一步）、**propionyl-CoA carboxylase**（IMTV 路徑）。
- ⭐ 口訣：**名字是 carboxylase（加 CO₂）→ biotin；名字是 *de*carboxylase（脫 CO₂）→ PLP（B₆）**。
- **Avidin**（生蛋白）緊抓 biotin → ACC 不作用 → 不合成脂肪（國考考過「生蛋白中抑制 biotin 的成分」）；實驗上用 biotin 標記＋**streptavidin** 珠子拉下複合物驗證 protein–protein interaction。

**② Tetrahydrofolate（THF，來自葉酸 B₉）** ⭐⭐

- 形成需要 **NADPH**；**磺胺類藥物**抑制細菌合成 THF。
- 結構裡藏著 **glutamic acid**（研究所考題，老師怕國考出）；pterin、aminobenzoate 不重要。
- 三種重要型態：**甲基（N⁵-methyl）、亞甲基（N⁵,N¹⁰-methylene）、醛基（formyl）**。
- 兩大功能：① **Ser、Gly、Met、His** 代謝 ② **核苷酸合成**。Ser ⇄ Gly 用**亞甲基型**；甲基型 → **Met**（甲基化）；His 代謝產生 **formimino-THF** → 醛基型 → 核苷酸。
- **亞甲基 → 甲基是單行道**（老師說第一版講義 AI 畫錯、已重畫）。前幾年愛考，這一兩年停了，「兩年後再考的機會蠻大」。

**③ BH₄（tetrahydrobiopterin）** ⭐⭐

- ⚠️ 不是 THF、不是葉酸；**材料是 GTP**。
- 輔酶：**Trp hydroxylase、Phe hydroxylase、Tyr hydroxylase、NO synthase**（第五個太冷門）。

**④ SAM（S-adenosylmethionine，AdoMet）** ⭐⭐⭐

- 結構 = **adenosine + methionine 經硫（S）相連**；功能 **99% 是甲基化**。
- Methionine cycle 用到的維生素：**B₉（N⁵-methyl-THF）、B₁₂（methionine synthase 的真正輔酶）、B₆（PLP）、B₂（FAD）**——考過「哪個維生素**不在**這個 cycle」。
- 中間產物 **homocysteine** → 經轉硫（**cystathionine β-synthase，需 PLP / B₆**）→ **cysteine** → glutathione。
- 酵素缺乏（主因）或 B₆ 缺乏 → **homocystinuria**；homocysteine↑ → **ROS↑ → oxidized LDL → macrophage 吞成泡沫細胞 → atherosclerosis**。
- 也連到 **choline → betaine** 代謝（黃老師 PC 合成那段；老師「偷瞄到黃老師有考這一題」）。

**⑤ TPP（B₁，thiamine pyrophosphate）**

- ⭐ 口訣：**看到 dehydrogenase 問輔酶 → 選 B₁，九成以上中**（PDH、α-KG DH、BCKDH〔楓糖尿症〕）；另一個是 PPP 的 **transketolase**。缺乏 → **腳氣病（beriberi）**。

**⑥ 碳骨架的去向（四種考法）** ⭐⭐⭐

1. 20 種胺基酸經 **六類中間產物**進 TCA：α-KG、succinyl-CoA、fumarate、OAA、pyruvate、**酮體類（acetyl-CoA / acetoacetyl-CoA 算一類）**。
2. 哪個胺基酸走哪個產物（難）：三組人馬 Glu→α-KG、**Ala→pyruvate**、Asp→OAA 先記。
3. 生糖 vs 生酮：⭐ 口訣 **3T2Lip**——3 個 T（Thr、Trp、Tyr）、2 個 L（Leu、Lys）、**I**le、**P = Phe**（不是 Pro！原本想寫 IF，怕忘了 F 是誰）。不在口訣裡的都是純生糖。
4. **只有 2L（Leu、Lys）是純生酮**，其餘 3T + Ile + Phe 生酮又生糖。

- **→ pyruvate**：**Ala**（最重要）、**Ser、Gly、Cys**（綁在一起）；下面兩個 T 不用記。老師叫大家別背酵素，結果今年國考考了 **serine dehydratase**（Ser 一步變 pyruvate，**兩個梯次都考**）和 Thr → pyruvate 的酵素。
- 生酮那 9 步「連課本都懶得畫」→ 不用背，**衍生物才重要**。

**⑦ Tryptophan 衍生物** ⭐⭐⭐

- **Indole（吲哚）結構只有 Trp 有** → 考題看到 indole-（如植物生長素 **indoleacetic acid**）就是 Trp。
- **Niacin（B₃）**：Trp 衍生 → 用來合成 **NAD⁺、NADP⁺**（方向別寫反）；缺乏 → **pellagra（癩皮病）4D：皮膚炎、腹瀉、失智、死亡**；中南美洲以**玉米**為主食者 Trp 不足。
- **Serotonin（5-HT）**：Trp hydroxylase（**BH₄**）→ decarboxylase（**PLP**）；快樂感（香蕉、巧克力、優酪乳、鮭魚、曬太陽、運動）；**類癌症候群（carcinoid）**：神經內分泌細胞轉癌時大量分泌 5-HT → 測 serotonin（醫技考題）。
- **Melatonin（褪黑激素，與美白無關）**：serotonin 在**眼睛沒有光刺激時**轉成 melatonin → 助眠（成人奶粉加 Trp；房間太亮就沒用）。

**⑧ Tyrosine 衍生物** ⭐⭐⭐

- **Thyroxine（T3、T4）**：課本列為衍生物，但嚴格說是 Tyr 殘基接**碘**才有活性。
- **Melanin（黑色素，≠ melatonin）**：關鍵第一步 **tyrosinase** → DOPA → melanin；缺 → **albinism**（眼睛紅是血管色、易皮膚癌）。
- **Catecholamines**：材料 **Tyr**（Phe 也對，但兩個都出現時**選 Tyr**）；四個：**DOPA → dopamine → norepinephrine → epinephrine**（國考考過順序）；三大輔酶：**Tyr hydroxylase（BH₄）→ decarboxylase（PLP）→ 甲基化（SAM）**。
- **Tyrosinase（皮膚）與 tyrosine hydroxylase（神經）是同工酶**：都把 Tyr 變 DOPA，位置與產物不同。

**⑨ PKU（苯酮尿症，第一名愛考）** ⭐⭐⭐

- **Phe 與 Tyr 只差一個 OH**；PKU = Phe **無法羥化成 Tyr**。
- 酵素 **phenylalanine hydroxylase**，輔酶 **BH₄**；用過的 BH₄ 由 **dihydropteridine reductase（用 NADH）** 再生。⚠️ **兩個酵素缺任何一個都會 PKU**（不只課本寫的 hydroxylase）。
- Phe 改走**轉胺** → **phenylpyruvate、phenylacetate、phenyllactate**（三個都考過）：帶苯環、疏水、可穿膜 → **神經毒、mental retardation**；尿有怪味（腐臭／有機味）。
- 治療只有**飲食限制 Phe**；無 Phe 嬰兒奶粉已納入健保。

# 考點分析

## 🔥 高頻考點（113 共筆 Ch18，87 題）

1. **PLP 參與哪些反應**（約 10 題）：轉胺、脫羧（GABA、histamine、DOPA → dopamine）、ALA synthase、轉硫；**不參與** norepinephrine → epinephrine（SAM）、acetyl-CoA carboxylase（biotin）。
2. **尿素循環**（約 12 題）：fumarate、aspartate 連接 TCA；urea 的第二個 N 來自 aspartate；CPS I 在粒線體、需要 NAG；arginine、ornithine 是循環中產生的胺基酸。
3. **BH₄ 與 THF**（約 10 題）：BH₄ 給 hydroxylase 與 NO synthase；THF 不參與 alanine 代謝；5,10-methylene-THF 用在 serine、glycine、dTMP。
4. **PKU、MSUD、alkaptonuria、albinism、homocystinuria** 的酵素配對（約 12 題）。
5. **Glutamine／glucose-alanine cycle**（約 10 題）：glutaminase 釋出 NH₄⁺、glutamine synthetase 在肝外。
6. **生酮／生醣、IMTV、必需胺基酸**（約 8 題）。
7. **Heme 分解**：CO 而不是 CO₂、bilirubin 由 albumin 運送、urobilinogen 由腸道細菌產生。

## 📒 115 共筆對照（W7 Ch18-3、Ch22 胺基酸合成與 heme，10/22）

- **Alkaptonuria 是老師說的第三常考**：HGD 基因缺陷；除了黑尿、關節炎，還有**皮膚黑斑、眼睛黑點、背痛**（堆在脊椎）。Tyr 路徑上**其他**酵素缺陷都歸為 **tyrosinemia**（酵素名看看即可）。
- **Glutathione 補充**：GSH **不是酵素**，是 glutathione peroxidase 的受質；**glutathione peroxidase 含 selenocysteine（要硒）**；Glu 是用 **γ-carboxyl** 接 Cys（不是一般肽鍵）。其他功能：鹼性環境下**不需酵素**幫蛋白質形成雙硫鍵、維持血中 Fe²⁺、合成 leukotriene；γ-glutamyl cycle「國考沒考過」。
- **Glutamate 本身就是神經傳導物質**（腦創傷時大量釋放、讓傷害更嚴重），去羧後才變成抑制性的 GABA。NOS 除了 **BH₄** 還要 **NADPH**。
- **MMA**：體染色體隱性；多的 propionyl 接上 carnitine 成 **C3-carnitine**，血液可篩檢。
- **胺基酸分類（Table 18-1）**：必需 9（His、Ile、Leu、Lys、Met、Phe、Thr、Trp、Val）、**條件式必需 6（Arg、Cys、Gln、Gly、Pro、Tyr）**、非必需 5（Ala、Asn、Asp、Glu、Ser）。口訣 3T2LIPHMV 裡的 **Tyr 其實是條件式必需**，題目問「條件式必需」選 Tyr；**Arg 是發育中兒童要從食物補充**的那個。人體用的是 **21 種**（含 selenocysteine；pyrrolysine 只在部分古菌、細菌）。
- **六大前驅物家族（Table 22-1）**：α-KG → Glu、Gln、Pro、Arg；**3-PG → Ser、Gly、Cys**；OAA → Asp、Asn、Met、Thr、Lys；pyruvate → Ala、Val、Leu、Ile；PEP + E4P → Trp、Phe（→ Tyr）；R5P（經 **PRPP**）→ His。只要背 **α-KG、pyruvate、OAA** 三家，分解與合成進出位置相同。Ile 畫在 pyruvate 或 Asp（Thr）家族**都對**。
- **加醯胺基兩種酵素別混**：Asn synthetase 的 N 來自 **Gln**、ATP → **AMP + PPi**；Gln synthetase 直接接 **NH₄⁺**、ATP → **ADP + Pi**。
- **3-PG → Ser 三步：氧化（NAD⁺）→ 轉胺（Glu）→ 去磷酸**；Ser →（**serine hydroxymethyltransferase，PLP**）→ Gly + **N⁵,N¹⁰-methylene-THF**；Ser →（serine dehydratase，PLP）→ pyruvate。
- **Cys 合成（轉硫作用）**：Met → SAM → homocysteine，Hcy + **Ser** →（**cystathionine β-synthase，PLP**）→ cystathionine → **Cys + α-ketobutyrate**。**硫來自 Met、碳骨架與胺基來自 Ser**。植物、細菌反過來，用無機硫做 Cys 再做 Met。
- **Taurine**：Cys → cysteinesulfinate → **hypotaurine**（脫 CO₂）→ taurine；功能：結合膽酸、抗氧化、滲透壓、穩定細胞膜、調節 Ca²⁺ 訊號。
- 芳香族胺基酸的 **shikimate pathway** 人體沒有，老師說不重要但考過一次：**shikimic acid、chorismate** 兩個名字要認得。
- **Heme**：**ALA synthase**（第一步）最重要；**起點與終點都在粒線體**。Porphyrin 接 Fe²⁺ → heme，接 **Co → B₁₂**。分解**先脾後肝**；bilirubin 由 **albumin** 送到肝。
- 尿素循環缺陷中最重要的是 **CPS I deficiency**（起始步驟）。
