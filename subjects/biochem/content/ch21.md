# 脂質生合成（黃彥華）

> Take home message 四段：① 脂肪酸與 eicosanoids ② 三酸甘油酯 ③ 膜磷脂 ④ 膽固醇、類固醇與 isoprenoids。

## 1. 脂肪酸合成總覽 ⭐⭐⭐
- 場所：動物在**細胞質**（植物在葉綠體）；原料 **acetyl-CoA**、還原力 **NADPH**、能量 ATP。
- Acetyl-CoA 是醣類與脂質代謝的交會點：醣類 → pyruvate →（粒線體）acetyl-CoA → **citrate** 運出 → 細胞質合成脂肪酸。

### Acetyl-CoA 的運出：citrate shuttle ⭐⭐
1. 粒線體：acetyl-CoA + OAA →（**citrate synthase**）→ **citrate**（citrate transporter 運出）
2. 細胞質：citrate + ATP →（**citrate lyase**，ATP-citrate lyase）→ acetyl-CoA + OAA
3. OAA →（**malate dehydrogenase**，耗 NADH）→ malate →（malic enzyme）→ pyruvate + CO₂ + **NADPH** → pyruvate 回粒線體 →（pyruvate carboxylase）→ OAA
- ⚠️ 考古問「把 acetyl-CoA 送出、再把 acceptor（OAA）送回粒線體」需要的酵素依序是 **citrate synthase → citrate lyase → malate dehydrogenase**。Acetyl-CoA 的 carrier 是 **citrate**。

### Malonyl-CoA 與 ACC（限速步驟）⭐⭐⭐
- **Acetyl-CoA + HCO₃⁻ + ATP →（acetyl-CoA carboxylase, ACC）→ malonyl-CoA**
- ACC 三個部分：**biotin carrier protein**、**biotin carboxylase**、**transcarboxylase**；**biotin** 是輔酶（以 Lys 側鏈相接）。
- **活化型＝去磷酸化、聚合成長絲（filamentous）**；citrate 促進聚合、palmitoyl-CoA 使其解聚。
- Malonyl-CoA 只出現在**合成**，不參與分解；它同時**抑制 CPT I**（第 17 章）。

### Fatty acid synthase（FAS）的四步循環
- 每一輪加 2 個碳（來自 malonyl-CoA，放出 CO₂）：**縮合 → 還原（NADPH）→ 脫水 → 還原（NADPH）**
- 中間物接在 **ACP（acyl carrier protein）**上；β-hydroxyacyl 為 **D 型**（β-oxidation 是 L 型）。
- 合成一個 **palmitate（16:0）**：8 acetyl-CoA + 7 ATP + **14 NADPH** → palmitate。
- **NADPH 來源**：① **pentose phosphate pathway**（G6P → ribulose-5-P）② **malic enzyme**（malate → pyruvate）。

| 載體 | CoA | **ACP** |

### 調控 ⭐⭐
- **Insulin** → 去磷酸化 ACC（**活化**）；**glucagon、epinephrine → PKA**、**AMPK**（能量低）→ 磷酸化 ACC（**失活**）。
- **Citrate**：ACC 的別構活化劑；**palmitoyl-CoA**：回饋抑制。
- 必需脂肪酸：人類只能在 **Δ9 以內**引入雙鍵 → **linoleate（18:2 Δ9,12）**、α-linolenate 要從植物取得。

## 2. Eicosanoids ⭐⭐
- 來自 **C20 多元不飽和脂肪酸**，主要是 **arachidonic acid（20:4 Δ5,8,11,14）**。
- **Paracrine／局部荷爾蒙**：濃度低、作用在附近細胞、**半衰期短（快速代謝）**。
- 生成：膜磷脂 →（**phospholipase A₂**）→ arachidonate（不是從 TG 水解）
  - **Cyclic 路徑**：COX（cyclooxygenase）→ PGH₂ → **prostaglandins**、**thromboxanes**（血小板，凝血）
  - **Linear 路徑**：**lipoxygenase** → **leukotrienes**（白血球；LTD₄ 使支氣管收縮 → **氣喘**）
- **NSAIDs**（aspirin、ibuprofen、naproxen、meclofenamate）**抑制 COX** → 擋住 PG 與 TX；aspirin 不可逆地**乙醯化** COX 的 Ser。Rofecoxib、celecoxib 選擇性抑制 **COX-2**。
- Prostaglandin 功能：調控 cAMP 合成、子宮收縮（PGF₂α）、血流、睡眠（PGE₂、PGD₂）、**發燒、發炎、疼痛**。
- ⚠️ 植物不能合成 leukotriene；aspirin 不擋 arachidonate 的生成；thromboxane 走 cyclic（COX）路徑。

## 3. 三酸甘油酯
- **Glycerol-3-phosphate** + 2 acyl-CoA → lysophosphatidic acid → **phosphatidic acid（PA）** → DAG → **TG**。
- Glycerol-3-P 的來源：DHAP（糖解）還原、肝臟 glycerol kinase、**glyceroneogenesis**（pyruvate carboxylase、**PEPCK** 反向糖解）。
- **TG cycle**：脂肪組織釋出的 FFA 約 **75% 被重新酯化**回 TG（耗 ATP 的 futile cycle）。**AMPK** 磷酸化 GPAT 與 HSL 抑制這個循環。
- **Insulin** 促進醣類與胺基酸 → acetyl-CoA → 脂肪酸 → TG；**糖尿病**缺 insulin → 脂肪酸合成下降、acetyl-CoA 轉向**酮體**（呼氣有 acetone 味）。

## 4. 膜磷脂 ⭐⭐
- 在**平滑內質網**合成，經**運輸囊泡**送到 Golgi、細胞膜等處；部分在粒線體合成。
- 共同起點 **PA**，兩種「活化頭基」的策略：
  - **CDP-diacylglycerol 策略**（細菌，真核用於 **PI、PG、cardiolipin**）：PA + CTP → CDP-DAG + 頭基
  - **CDP-頭基策略**（哺乳類 **PC、PE**）：choline → phosphocholine →（**CTP:phosphocholine cytidylyltransferase**，限速）→ **CDP-choline** + DAG → PC
- **真核特有**：PC、**PI**（PI 只在真核）；細菌也有 PE、PS、PG、cardiolipin。
- **細菌的 PE**：CDP-DAG + **serine** → PS →（**decarboxylation**）→ PE。哺乳類：ethanolamine + CDP 路徑，或 PS 經 **PS decarboxylase（粒線體）** → PE。
- **PE → PC**：**S-adenosylmethionine（AdoMet、SAM）** 提供 **3 個甲基**（methionine → SAM → S-adenosylhomocysteine）。Choline 的來源之一就是 serine → ethanolamine → 甲基化。
- Phospholipase 專一性：**A₁**（sn-1）、**A₂**（sn-2，釋放 arachidonate）、**C**（磷酸前，產生 DAG + IP₃）、**D**（磷酸後）。

## 6. 膽固醇生合成與調控 ⭐⭐⭐
- 全部 27 個碳都來自 **acetyl-CoA**：
  **3 acetyl-CoA（2C×3）→ HMG-CoA（6C）→（HMG-CoA reductase，2 NADPH）→ mevalonate（6C）→ 活化（3 ATP）→ isopentenyl pyrophosphate（IPP，5C）＋ dimethylallyl-PP → geranyl-PP（10C）→ farnesyl-PP（15C）→ squalene（30C）→ lanosterol → cholesterol（27C）**
- **HMG-CoA reductase（ER 膜，細胞質側）是限速酶**：
  1. **荷爾蒙**：insulin → 去磷酸化（活化）；glucagon、**AMPK（低 ATP）** → 磷酸化（抑制）
  2. **Sterol 誘導泛素化降解**：膽固醇／lanosterol 多 → reductase 被 **ubiquitin** 標記 → proteasome 分解
  3. **轉錄**：SREBP（膽固醇低時活化）↑ reductase 與 LDL receptor 的基因
  4. **Statins**（lovastatin、simvastatin 是真菌 polyketide；atorvastatin 合成）帶有類 mevalonate 結構 → **競爭性抑制** → 細胞內膽固醇 ↓ → **LDL receptor ↑** → 血中 LDL 清除更快
- 細胞內多餘膽固醇由 **ACAT** 酯化儲存。
- 膽固醇的衍生物：**膽鹽**、**vitamin D（calcitriol）**、類固醇荷爾蒙（progesterone → glucocorticoid〔cortisol，糖質新生、抗發炎〕、mineralocorticoid〔aldosterone，Na⁺ 再吸收〕、androgen、estrogen）。⚠️ **Prostacyclin 是 eicosanoid，不是膽固醇衍生物**。

## 🎙️ 上課錄影重點（黃彥華，09/17 + 09/24）
- ⭐ **配分（老師在 09/24 課堂宣布）：期中考黃彥華老師的部分（Ch17、Ch21、Ch12）共 42 分，陳顧中老師的部分 58 分。**
- 本章四段：① 脂肪酸合成 + eicosanoids ② 三酸甘油酯合成 ③ 膜磷脂（含 sphingolipid 疾病）④ 膽固醇。前兩段是「**能量模式**」，後兩段是「**疾病模式**」。
- **Acetyl-CoA 運出粒線體**：acetyl-CoA 是親水小分子、過不了膜 → 與 **OAA** 經 **citrate synthase（「結婚的律師」，不需 ATP）** 合成 citrate → **citrate transporter** → 細胞質 **citrate lyase（「離婚的律師」，要付贍養費 = ATP）** → acetyl-CoA + OAA。OAA 回粒線體兩條路：① → malate（malate–α-KG transporter）② malate → **malic enzyme（產 NADPH）** → pyruvate（pyruvate transporter）→ pyruvate carboxylase → OAA。
- 糖尿病 / 極度飢餓的人 TCA 中間產物（OAA）被用光 → acetyl-CoA 在**粒線體**走 ketogenesis；⚠️ 酮體用 **HMG-CoA synthase / lyase（粒線體）**，膽固醇用 **HMG-CoA reductase（細胞質）**——「這三個一定放在同一題考你」。
- **ACC（acetyl-CoA carboxylase）=「你不會就會死」，脂肪酸合成的速率決定步驟（兩分題）**：acetyl-CoA + **HCO₃⁻ + ATP**，cofactor **biotin**（biotin carrier protein → biotin carboxylase → transcarboxylase）→ **malonyl-CoA（3 碳）**。⚠️ **去磷酸化才活化**（聚合成 filament）。
- **合成 vs 分解「倒著走」**：β-oxidation 是 A（去氫）→ B（加水）→ C（去氫）→ X（thiolysis）；合成是 Y（malonyl-CoA 去掉 CO₂ 與 acetyl 縮合成 4 碳 β-keto）→ C（還原成 OH）→ B（脫水成雙鍵）→ A（還原成單鍵）。差別：合成在**細胞質**、用 **NADPH**；分解在粒線體、用 FAD / NAD⁺。每輪加 2 碳，終產物 16 碳 **palmitate**。
- **NADPH 兩個來源（要背）**：**pentose phosphate pathway**、**malic enzyme**（malate → pyruvate）。「你需要的 cofactor 在哪裡，反應就在哪裡」。
- 動物細胞：粒線體（β-oxidation、酮體、elongation）、細胞質（FA 合成、膽固醇前段）、**ER**（磷脂合成、elongation、**desaturation**）；植物的 β-oxidation 在 peroxisome、FA 合成在葉綠體（不著重）。
- **ACC 調控（兩分題）**：**citrate ↑**（勒沙特列：反應物多）→ 活化 ACC 與 citrate lyase；**palmitoyl-CoA** feedback 抑制 ACC（「找關鍵的人＝主任」）；**glucagon、epinephrine → PKA、AMPK → 磷酸化 ACC（抑制）**；**insulin → phosphatase → ACC 活化**。吃飽時 insulin 也讓 **PDH phosphatase** 去磷酸化 **PDH**（⚠️ 第二個「去磷酸化才活化」的例外）→ pyruvate → acetyl-CoA。
- **Eicosanoids（兩分題）**：**arachidonic acid（20:4，cis Δ5,8,11,14）** 接在磷脂 **第 2 碳**；荷爾蒙活化 **PLA₂** 切下 → **PGH₂ synthase**（半成品）→ 各 isomerase / synthase：**PGF₂α（子宮收縮、分娩、月經）**、**PGE₂ / PGD₂（睡眠–清醒週期）**、PGI、**thromboxane（凝血）**；**leukotriene**（直鏈、不環化）→ 平滑肌收縮、**氣喘** → anti-leukotriene 是抗氣喘藥。Eicosanoids 是 **paracrine / local hormone**（隔壁細胞馬上用掉、組織濃度低、turnover 快）。命名：從人類精液萃取、以為來自 prostate gland；溶在 ether = PGE、溶在 phosphate buffer（瑞典文 F）= PGF。
- **NSAID（兩分題）**：aspirin、**ibuprofen**、**naproxen** = 非選擇性 **COX（cyclooxygenase）inhibitor** → 抑制 prostaglandin（退燒、抗發炎）**也抑制 thromboxane（抗凝血）**。老師情境：產後出血又發燒的產婦給 NSAID → 燒退了但止不了血；低劑量用來預防微血栓，**開刀前要停藥**。
- **三酸甘油酯合成**：FFA 先活化成 acyl-CoA（**相當 2 ATP**）；骨架 **glycerol-3-phosphate**（glycerol 太鈍），可經 **glyceroneogenesis**：pyruvate →（pyruvate carboxylase）OAA →（**PEPCK**）→ … → **DHAP** → G3P。**GPAT（glycerol-3-phosphate acyltransferase）**接第 1 碳 → **lyso-PA**（lyso = 第 2 碳還沒接）→ 接第 2 碳 = **PA** → phosphatase 去磷酸 = **DAG** → 接第 3 碳 = **TG**。生理上釋出的 FFA 約 **75% 會重新酯化回 TG**（TG–FFA cycle）；**AMPK** 抑制 GPAT，也抑制 ATGL、HSL、MGL（避免空轉）。
- **膜磷脂合成**：主要在 **smooth ER**，其次粒線體 → 經 Golgi 送到各膜；小時候長高走磷脂、成年後只會長胖（TG）。真核 + 原核共有：G3P → PA →（**CTP → 放 PPi**，相當 2 ATP）→ **CDP-diacylglycerol**（中心產物）→ 被官能基取代、**CMP 被踢出**（「向 CMP 致敬」）：serine → **PS** →（decarboxylase，one way）→ **PE**；glycerol 3-phosphate → PG → 兩個 PG → **cardiolipin（梅毒螺旋體的 marker）**。**只在真核**：inositol 取代 CMP → **PI**（考過「真核有、原核沒有」選 PI；PC 也只在真核）。真核另有 PA 來源：**DAG**（+ ATP）、**DHAP**（需 **NADPH** 還原第 2 碳）。
- **PC、PE 的真核路徑：ATP → CTP → DAG**（choline / ethanolamine 先磷酸化 → CDP-choline → DAG 取代 CMP）。**關鍵酵素 E2 = CTP:phosphocholine cytidylyltransferase（兩分題）**：PC 是**肺泡表面張力素**，早產兒缺乏 → 無法自主呼吸（給類固醇促進合成）。
- **PS、PE、PC 三角關係**：PS → PE 去羧（單向）或 transferase 互換（雙向）；PS ↔ PC 直接換官能基；**PE → PC 靠 PEMT + SAM（AdoMet）三次甲基化（單向，常考）**。**SAM 是最重要的甲基供應者（兩分題）**，由 **methionine + ATP** 合成，給出甲基後成 homocysteine。
- **Phospholipases**：A1 切第 1 酯鍵、**A2 切第 2 酯鍵（釋出 arachidonic acid，兩分題）**、**C 切磷酸根之前（兩分題）**、D 切磷酸根之後。**PLC 切 PIP₂（PI 4,5-bisphosphate）→ IP₃ + DAG**：IP₃ → ER 釋放 Ca²⁺；DAG → PKC → 細胞「開始發瘋」（強烈活化）。
- **Sphingolipid**：結構不考，**考疾病**。以 **ceramide** 為骨架接上各種醣 → 在 **lysosome** 由專一酵素逐一切醣 → 基因缺陷 → 堆積在細胞膜（尤其神經細胞）= **lysosomal lipid storage disease**（遺傳病）。GM1 →（**β-galactosidase**）GM2 →（**hexosaminidase A**）GM3：缺 β-galactosidase → GM1 堆積（generalized gangliosidosis）；缺 hexosaminidase A → **Tay-Sachs**（GM2）；缺 **sphingomyelinase** → **Niemann-Pick**（sphingomyelin 堆積，肝脾腫大、智能發育不全；台灣案例、近年常考）。
- **膽固醇合成（考酵素、碳數、調控，不考結構）**：2 + 2 + 2 = **6 碳 HMG-CoA** →（**HMG-CoA reductase，細胞質，NADPH**）→ **mevalonate（仍是 6 碳，常被考成 5 碳）** → 三次 ATP 磷酸化（像《天龍八部》段譽被灌三掌功力）→ 自動去 CO₂ + 磷酸根 → **5 碳 isoprene（IPP / DMAPP）** → 10 碳 geranyl-PP → 15 碳 farnesyl-PP → **30 碳 squalene** → cyclase → **lanosterol** → … → **27 碳膽固醇**。考法：「下列膽固醇合成的碳數序列何者正確」。
- **HMG-CoA reductase 降解（兩分題）**：lanosterol 多 → 結合 ER 膜上的 **Insig** → Insig 拉來 HMG-CoA reductase → **gp78** 掛上 **ubiquitin**（「死神貼符號」）→ **proteasome** = **ubiquitin-mediated proteolysis**。藥物：**statins**（如 Lipitor）抑制 HMG-CoA reductase。
- 膽固醇恆定總圖：↓HMG-CoA reductase（glucagon 抑制、ubiquitin 降解）、↓LDL receptor、↑ACAT；**insulin 促進 HMG-CoA reductase**。
- 膽固醇衍生物（「下列何者不是膽固醇衍生物」四選一）：**膽鹽、vitamin D、progesterone → cortisol、aldosterone、雄性素、雌激素**。

# 考點分析

## 🔥 高頻考點（113 共筆 Ch21 + 混在 Ch17-2 的合成題）
1. **ACC 是限速步驟**；需要 **biotin**；在**細胞質**；**insulin 促進**（說被 insulin 抑制是錯的）。
2. 脂肪酸合成**不需要 NADH**（用 NADPH）；acetyl-CoA 的 carrier 是 **citrate**；shuttle 酵素順序 citrate synthase → citrate lyase → malate dehydrogenase。
3. **合成 vs 分解**：位置、NADPH vs NAD⁺/FAD、D vs L、trans-enoyl 兩邊都有。
4. **PE → PC 的甲基供應者是 S-adenosylmethionine**（考 2 次）；細菌 PE 合成用 serine（CDP-DAG）；**PI 只在真核**。
5. **Tay-Sachs**：hexosaminidase A、**GM2 ganglioside**（考 3 次）。
6. **HMG-CoA reductase 的調控**：**sterol 引發泛素化降解**（考 2 次）；insulin 促進（「insulin 刺激 HMG-CoA reductase」是對的）。
7. **Eicosanoids**：短命、局部；**ibuprofen／aspirin 抑制 COX**；thromboxane 不走 linear 路徑。
8. **不是膽固醇衍生物**：prostacyclin。
9. **Linoleate** 人類不能合成（Δ12 雙鍵）。

## 🎙️ 老師課堂提示
- ⭐ **配分：黃彥華老師（Ch17、21、12）42 分；陳顧中老師（Ch23、18、22）58 分。**

## 📒 115 共筆對照（W3 Ch21）
- 老師說的常見考題：「許多磷脂質都扮演結構角色，**唯獨哪一個扮演訊息傳遞角色**？」→ **PI**（PIP₂ 被 PLC 切成 IP₃ + DAG）。
- **Cardiolipin** 是梅毒血清學檢驗（非螺旋體抗原試驗）抗原配方的成分，測的是病人的抗體；**cardiolipin 不是梅毒螺旋體獨有**的成分。
- **E2（CCT）** 在胎兒約 **32 週**才成熟，之後才能大量合成 PC（肺泡表面張力素）→ 早產兒無法自主呼吸。
- 膽固醇衍生物題（「下列何者**不是**膽固醇衍生物」）：膽鹽要認得 **cholate、glycocholate、taurocholate**（國考考過）；脂溶性維生素 **ADEK 中只有 D** 來自膽固醇。
- 共筆補充（簡報未提）：轉錄層級的調控是 **SREBP–SCAP–Insig**：膽固醇低 → SCAP 帶 SREBP 從 ER 到 Golgi → **S1P、S2P** 兩次切割 → bHLH 片段入核 → HMG-CoA reductase 與 LDL receptor 轉錄 ↑；膽固醇高 → SCAP 與 Insig 結合、留在 ER。
- 共筆也列 **glucagon 抑制 HMG-CoA reductase**（磷酸化），與 insulin 相反。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| 脂肪酸合成用 NADH | 只用 **NADPH**（來源：PPP、**malic enzyme**） |
| ACC 磷酸化才活化 | ACC **去磷酸化才活化**；citrate 活化，palmitoyl-CoA、glucagon／epinephrine（PKA、AMPK 磷酸化）抑制 |
| Insulin 抑制 ACC／HMG-CoA reductase | Insulin **促進**兩者 |
| Acetyl-CoA 直接穿出粒線體 | 以 **citrate** 形式出來 → **citrate lyase（耗 ATP）** 切回 acetyl-CoA + OAA |
| 合成在粒線體、β-oxidation 在細胞質 | **相反**：合成在**細胞質**、β-oxidation 在**粒線體** |
| Trans-enoyl 中間物只在合成路徑 | 合成與分解**兩邊都有** trans 中間物；差別是 **D-（合成）vs L-（分解）β-hydroxyacyl** |
| PE ⇄ PC 可雙向 | **PE → PC 單向**（PEMT，SAM 三次甲基化）；PS ⇄ PC、PS ⇄ PE 有雙向的 head-group exchange |
| PC 的甲基來自 THF | 來自 **SAM（AdoMet）**，源頭是 **methionine** |
| 細菌與真核都用 CDP-頭基策略做 PC／PE | 細菌用 **CDP-DAG**；哺乳類 PC／PE 用 **CDP-choline／CDP-ethanolamine**；PI 只在**真核** |
| Tay-Sachs 累積 glucocerebroside | Tay-Sachs = **hexosaminidase A → GM2 ganglioside**；Gaucher 才是 glucocerebroside |
| 膽固醇是 HMG-CoA reductase 的別構抑制劑 | 高 sterol 觸發 reductase **泛素化 → proteasome 降解**（Insig、gp78），並抑制 SREBP 轉錄 |
| HMG-CoA reductase 在粒線體 | Reductase 在 **ER／細胞質**（膽固醇）；**synthase／lyase 在粒線體**（酮體） |
| Prostacyclin 是膽固醇衍生物 | Prostacyclin 是 **eicosanoid**（arachidonate）；膽固醇衍生物是膽鹽、vitamin D、類固醇荷爾蒙 |
| Aspirin 抑制 lipoxygenase | Aspirin、ibuprofen 抑制 **COX**（前列腺素、thromboxane）；leukotriene 走 lipoxygenase（linear） |
| 膽固醇合成碳數：mevalonate 5 碳 | Acetate **C2** → mevalonate **C6** → isoprene C5 → squalene **C30** → cholesterol **C27** |
| 人類可合成 linoleate | 人類無法在 **Δ9 之後**加雙鍵 → linoleate（18:2 Δ9,12）是必需脂肪酸 |
