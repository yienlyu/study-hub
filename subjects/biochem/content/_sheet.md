## β-oxidation 與 ATP 計算
@ch ch17
@fig beta-oxidation
| 步驟 | 酵素 | 產物 |
|---|---|---|
| ① 去氫 | acyl-CoA dehydrogenase | **FADH₂**、trans-Δ² |
| ② 水合 | enoyl-CoA hydratase | **L**-β-hydroxy |
| ③ 去氫 | β-hydroxyacyl-CoA DH | **NADH** |
| ④ 硫解 | thiolase | acetyl-CoA |

- 偶數 n 碳：循環 **n/2 − 1** 次、acetyl-CoA **n/2** 個；活化扣 **2 ATP**（ATP → AMP）。
- **Palmitate（16:0）= 106 ATP**；stearate（18:0）= 120 ATP。
- 每輪（不含 acetyl-CoA）= 4 ATP；1 acetyl-CoA 進 TCA = 10 ATP。

## Carnitine shuttle 與脂肪酸運輸
@ch ch17
@fig carnitine-shuttle
- 活化在粒線體**外膜**（acyl-CoA synthetase，PPi 水解）。
- **CPT I（外膜）＝ 限速、被 malonyl-CoA 抑制** → translocase → CPT II（內膜基質側）。
- 能穿內膜：acyl-carnitine、citrate、malate、pyruvate；**不能**：acyl-CoA、acetyl-CoA、malonyl-CoA。
- 脂肪動員：glucagon／epinephrine → PKA → **HSL、perilipin 磷酸化**；FA 由 **albumin** 運送。

## 奇數碳與酮體
@ch ch17
@fig ketogenesis
- 奇數碳 → **propionyl-CoA** →（carboxylase，**biotin**）→ methylmalonyl-CoA →（mutase，**B₁₂**）→ **succinyl-CoA**。
- 酮體：**肝粒線體**合成（HMG-CoA synthase → lyase）→ acetoacetate、**β-hydroxybutyrate（血中最多）**、acetone（呼氣）。
- **肝臟不能用酮體**（缺 thiophorase）；腦飢餓時改用。
- HMG-CoA **synthase／lyase 在粒線體（生酮）**；**reductase 在細胞質／ER（膽固醇）**。

## 脂肪酸合成 vs 分解
@ch ch21
@fig fa-synthesis
| | β-oxidation | 合成 |
|---|---|---|
| 位置 | 粒線體 | **細胞質** |
| 載體 | CoA | **ACP** |
| 電子 | FAD、NAD⁺ | **NADPH** |
| 中間物 | **L** | **D** |
| 兩碳單位 | 放出 acetyl-CoA | 加入 **malonyl-CoA** |
| 運輸 | carnitine shuttle | **citrate shuttle** |

- **ACC 限速**（biotin）：citrate、insulin（去磷酸化）活化；glucagon、AMPK、palmitoyl-CoA 抑制。
- Citrate shuttle 酵素順序：citrate synthase → **citrate lyase** → **malate DH**（→ malic enzyme 產 NADPH）。
- 1 palmitate = 8 acetyl-CoA + 7 ATP + **14 NADPH**。必需脂肪酸：linoleate、α-linolenate。

## Eicosanoids、磷脂、鞘脂
@ch ch21
@fig eicosanoids
- 膜磷脂 →（**PLA₂**）→ arachidonate → **COX**（PG、TX；**NSAIDs／aspirin 抑制**）或 **lipoxygenase**（leukotrienes → 氣喘）。
- 磷脂起點 **PA**：CDP-DAG 策略（PI、PG、cardiolipin；細菌 PS → PE）；CDP-choline 策略（PC，cytidylyltransferase 限速）。
- **PE → PC：3 個 SAM**；PI 只在真核。
- **Tay-Sachs** = hexosaminidase A → GM2；**Niemann-Pick** = sphingomyelinase；Gaucher = β-glucosidase。

## 膽固醇合成與 statins
@ch ch21
@fig cholesterol-synthesis
- Acetyl-CoA（2C）→ HMG-CoA（6C）→ **mevalonate（6C）** → **IPP（5C）** → geranyl（10C）→ farnesyl（15C）→ **squalene（30C）** → lanosterol → **cholesterol（27C）**。
- **HMG-CoA reductase** 調控：① 荷爾蒙（insulin＋、glucagon／AMPK－）② sterol 誘導泛素化降解 ③ **SREBP** 轉錄 ④ **statins 競爭性抑制 → LDLR ↑**。
- 衍生物：膽鹽、vitamin D、類固醇荷爾蒙（**prostacyclin 不是**）。

## 四大類受體與第二傳訊者
@ch ch12
@fig second-messengers
| 類型 | 例子 |
|---|---|
| GPCR | β-adrenergic、glucagon、rhodopsin、嗅覺 |
| 受體酵素 | **insulin receptor（RTK）**、ANF（受體 GC） |
| 門控通道 | **nicotinic ACh**、電壓門控 Na⁺ |
| 核受體 | steroid、thyroid（結合 HRE、zinc finger） |

- **G<sub>s</sub> → AC → cAMP → PKA（R₂C₂ + 4 cAMP）**；關閉：GTPase、PDE、βARK + β-arrestin。

- NO → 可溶性 GC（heme）→ cGMP → PKG；**sildenafil 抑制 PDE5**。視覺：光 → **cGMP ↓**。
- Insulin：IRS-1 → **Grb2 → Sos → Ras → Raf → MEK → ERK**；**PI3K → PIP₃ → Akt → GSK3 失活**、GLUT4 移位。

## 各器官燃料
@ch ch23
@fig organ-fuel
| 器官 | 重點 |
|---|---|
| 腦 | 葡萄糖（120 g／天、20% O₂）；飢餓用**酮體**；脂肪酸過不了 BBB |
| 骨骼肌 | 休息用 FA；3/4 肝醣；**無 G6Pase**；phosphocreatine |
| 心肌 | 脂肪酸、高度有氧 |
| 肝 | 輸出葡萄糖、酮體、VLDL；glucokinase + GLUT2 |
| 紅血球 | **無粒線體** → 只糖解 → lactate |

- **Cori cycle**：肌肉 2 ATP、肝 6 ATP；glucose-alanine cycle 同時運 C 和 N。
- Creatine：Arg + Gly（腎）→ SAM 甲基化（肝）；creatinine 是**非酵素**脫水環化。

## Insulin、glucagon 與磷酸化規則
@ch ch23
@fig insulin-secretion
- 分泌：血糖 → GLUT2 → ATP/ADP ↑ → **K-ATP 關（sulfonylurea）** → 去極化 → **Ca²⁺ 流入** → 胞吐；incretin（GLP-1、GIP）。
- GLUT：1 紅血球／BBB、**2 肝與 β 細胞**、3 神經元、**4 肌肉脂肪（insulin）**、5 果糖。
- Glucagon／epinephrine → cAMP → PKA：肝醣分解 ↑、糖質新生 ↑、糖解 ↓、脂解 ↑。
- **磷酸化 → 分解**：glycogen synthase 磷酸化失活；phosphorylase 磷酸化活化。
- **AMPK**：抑制 ACC、HMG-CoA reductase；**mTORC1**：營養充足才活化（rapamycin 抑制）。

## Leptin 與飢餓、糖尿病
@ch ch23
@fig slide-ch23-leptin
- **Leptin**：脂肪細胞、**OB gene**、16 kD → 下視丘 **JAK-STAT → POMC ↑、NPY ↓** → 吃少；NE → β3 → **UCP1** 產熱；多數肥胖是 **leptin resistance**。
- Adiponectin ↑ insulin 敏感度；**ghrelin（胃）促進食慾**（Prader-Willi 高）；PYY₃₋₃₆ 抑制食慾。
- 長期飢餓：肝醣 → TG → 蛋白質；**酮體上升最多**；腦用酮體。
- **T1DM**：β 細胞自體免疫破壞、年輕、瘦、**酮酸中毒**；**T2DM**：insulin resistance、肥胖、中年。

## 胺基酸氮的去路
@ch ch18
@fig urea-cycle
- 轉胺（**PLP**）→ glutamate →（**glutamate DH**）→ NH₄⁺；肝外用 **glutamine**、肌肉用 **alanine** 運氮。
- 尿素循環：**CPS I（粒線體，NAG 必需）** → citrulline → ＋**aspartate** → argininosuccinate → arginine + **fumarate** → urea + ornithine。
- 尿素的 2 個 N：NH₄⁺ + **aspartate**；4 個高能鍵；與 TCA 的連結是 **fumarate、aspartate**。
- 純生酮：**Leu、Lys**；IMTV → propionyl-CoA → succinyl-CoA。

## 核苷酸代謝與藥物
@ch ch22
@fig dtmp-cycle
- Purine：在 **PRPP** 上蓋環 → **IMP**；原料 Gly、Gln、Asp、formyl-THF、CO₂（**不用 Asn**）。
- Pyrimidine：先做環（**CPS II 細胞質**、ATCase：CTP 抑制、ATP 活化）再接 PRPP。
- **RNR**：一酵素還原四種 NDP；**dATP 抑制**。dTMP：thymidylate synthase + methylene-THF → DHF →（**DHFR**）→ THF。
- 藥物：**5-FU → TS**；**methotrexate／aminopterin（人）、trimethoprim（菌）→ DHFR**；AZT → 反轉錄酶；acyclovir → HSV TK；**allopurinol → xanthine oxidase**。
- **Lesch-Nyhan** = HGPRT 完全缺乏（X-linked）；**SCID** = ADA 缺乏 → dATP ↑ → 抑制 RNR；**ADA 缺乏不造成痛風**。
