# 器官間代謝整合與激素調控（陳顧中）

> 課程大綱三大塊：① 各主要器官的燃料代謝（腦、骨骼肌、肝、血液）② 激素調控（insulin、leptin、glucagon、epinephrine）③ 代謝壓力（飢餓、糖尿病）。去年共筆分成 23-1（黃彥華）與 23-2（陳顧中），題目是同一份。

## 1. 各器官的燃料代謝 ⭐⭐⭐

| 器官               | 燃料儲存                    | 偏好燃料                                                                     | 輸出                             | 關鍵特點                                                                       |
| ------------------ | --------------------------- | ---------------------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------ |
| **腦**             | 無                          | **葡萄糖**（每天 ~120 g，總能量 15%）；**飢餓時用酮體（β-hydroxybutyrate）** | 無                               | 高度有氧（耗全身 **20% 氧氣**）；脂肪酸過不了血腦障壁                          |
| **骨骼肌（休息）** | 肝醣（全身 **3/4** 的肝醣） | **脂肪酸**                                                                   | 無                               | 也可用酮體                                                                     |
| **骨骼肌（運動）** | 無                          | **葡萄糖**（先來自肝醣，後期加脂肪酸）                                       | **lactate、alanine**             | 爆發力靠 **phosphocreatine**                                                   |
| **心肌**           | 少量                        | **脂肪酸**（高度依賴氧化磷酸化）                                             | 無                               | 粒線體極多                                                                     |
| **肝臟**           | 肝醣、TG                    | 胺基酸、葡萄糖、脂肪酸                                                       | **葡萄糖、脂肪酸（VLDL）、酮體** | 代謝中樞；**脂肪酸合成主要場所**；生酮                                         |
| **脂肪組織**       | **TG**                      | 葡萄糖、脂肪酸                                                               | 脂肪酸、glycerol                 | 棕色／米色脂肪靠 **UCP1** 產熱                                                 |
| **紅血球**         | 無                          | 葡萄糖                                                                       | **lactate**                      | **沒有粒線體 → 只靠無氧糖解**；PPP 產生 NADPH 維持 glutathione 還原態；2,3-BPG |
| 腎臟               |                             |                                                                              |                                  | 飢餓時也做糖質新生                                                             |

- **燃料使用順序**：**肝醣 → 三酸甘油酯 → 蛋白質**。
- **肌肉肝醣不能補血糖**：肌肉**沒有 glucose-6-phosphatase**，肝醣分解產生的 G6P 只能自己用。只有肝（和腎）能釋出葡萄糖。
- 肝臟用 **hexokinase IV（glucokinase，Km 高、不被 G6P 抑制）** 與 **GLUT2** 緩衝血糖。
- **心肌**高度依賴粒線體氧化：脂肪酸為主，葡萄糖、**乳酸**、酮體都能燒（「心肌不能用乳酸」是錯的）。
- **紅血球糖解的兩條支路**：
  - **2,3-BPG**（由 1,3-BPG 分出）：**降低血紅素對 O₂ 的親和力** → 在組織放氧。
  - **PPP（G6PD）→ NADPH** → **glutathione reductase（FAD）** 把 GSSG 還原成 GSH。電子供應者是 **NADPH，不是 ATP**；ATP 正常也補不了 NADPH，NADPH 少 → **GSH/GSSG 比值下降**。
- **G6PD 缺乏**（練習題 133、157）：吃氧化性藥物 → NADPH 不夠 → GSH 回補不上 → ROS 清不掉 → **溶血** → 釋出的 heme 分解增加 → 送到肝臟的**未結合 bilirubin** 負荷 ↑（接 Ch18 heme 分解）。

## 2. 乳酸、Cori cycle 與 glucose-alanine cycle ⭐⭐

- 無氧時：pyruvate + **NADH** →（**lactate dehydrogenase**）→ lactate + NAD⁺（再生 NAD⁺ 讓糖解繼續）。**淨產 2 ATP**（NADH 被用掉）。
  - 1 葡萄糖 → 2 乳酸的帳：**淨 2 ATP、無淨 NADH**（糖解做的 2 NADH 全被 LDH 用掉）。LDH 本身**不產生 ATP**。
  - 糖解本身的帳（複習）：投資期 hexokinase、PFK-1 共 **−2 ATP**；回收期 PGK、pyruvate kinase 各 ×2 共 **+4 ATP**；GAPDH **+2 NADH** → **淨 2 ATP + 2 NADH**。⚠️「總產 4 ATP」不是「淨產 4 ATP」。

### GAPDH 與 LDH：乳酸發酵是為了還 NAD⁺ ⭐⭐

- 糖解第六步 **GAPDH（glyceraldehyde-3-phosphate dehydrogenase）** 是整條路徑**唯一的氧化還原反應**，會消耗 NAD⁺：
  ```
  G-3-P + NAD⁺ + Pi → 1,3-bisphosphoglycerate + NADH + H⁺
  ```
- 缺氧時電子傳遞鏈停擺、粒線體收不回 NADH，唯一的出路是 **LDH**：
  ```
  Pyruvate + NADH + H⁺ → Lactate + NAD⁺
  ```
  乳酸發酵的生理意義不是要做出乳酸，而是**把 NAD⁺ 還給 GAPDH**。
- **抑制 LDH → 最先卡住的是 GAPDH**（練習題 141）：胞質游離 NAD⁺ 只有約 0.3–0.5 mM，劇烈運動時糖解通量又很大 → 庫存小 ÷ 通量大 = **數秒內耗盡**。這是**輔因子（受質）供應斷掉**，不是酵素被抑制。
  - ⚠️ **PFK-1** 雖是糖解的傳統限速步驟，但它**不需要 NAD⁺**，在這個情境下不是最先卡住的地方——題目問「先限制」就是在考這個區別。
  - 因此 GAPDH 被稱為糖解的 **redox-sensing node**：胞質 NAD⁺/NADH 比值一下降，整條路徑就在這裡中斷。
- **正常情況下的替代出路**：把胞質 NADH 的電子送進粒線體。

  | 穿梭系統                         | 機制                                         | 產能    | 主要組織   |
  | -------------------------------- | -------------------------------------------- | ------- | ---------- |
  | **Malate–aspartate shuttle**     | 經 OAA／malate 往返，電子交給粒線體 **NAD⁺** | 2.5 ATP | 心、肝     |
  | **Glycerol-3-phosphate shuttle** | DHAP ⇌ G-3-P，電子交給 **FAD**               | 1.5 ATP | 骨骼肌、腦 |

  兩條最後都要把電子倒進電子傳遞鏈；**缺氧時 ETC 本來就停了**，所以救不了場 → 無氧時乳酸發酵是唯一解。

- **常被拿來配錯的調控關係**（看到熟悉的分子先別安心，要檢查「它真的管那個酵素嗎」）：

  | 酵素                      | 真正的調控                                                                              |
  | ------------------------- | --------------------------------------------------------------------------------------- |
  | Hexokinase                | 被**產物 G-6-P** 回饋抑制（不是 acetyl-CoA）                                            |
  | PFK-1                     | ATP、citrate、H⁺ 抑制；AMP、**F-2,6-BP** 活化（與 FADH₂ 無關）                          |
  | Pyruvate kinase           | **F-1,6-BP 前饋活化**；ATP、alanine 抑制；肝型另受 **cAMP／PKA**（不是 cGMP）磷酸化失活 |
  | PDH／pyruvate carboxylase | **Acetyl-CoA** 抑制 PDH、活化 pyruvate carboxylase                                      |
  - 糖解**不產生也不使用 FADH₂**（FADH₂ 出現在 TCA 的 succinate dehydrogenase 與 β-oxidation）。

- **LDH 缺乏症**（LDHA 突變，glycogen storage disease XI）：高強度運動時肌肉痙攣、運動不耐、橫紋肌溶解。缺血前臂運動試驗：**乳酸不升、pyruvate 上升、氨正常上升**；McArdle 病（肌肉 glycogen phosphorylase 缺乏）是**乳酸與 pyruvate 都不升、氨上升**——差別在 pyruvate。
- 乳酸去路：約 **2% 從尿排出**；大部分轉回 pyruvate → 進粒線體氧化，或在**肝、腎**做糖質新生。
- **Cori cycle**：肌肉（糖解，得 2 ATP）→ 乳酸 → 血液 → **肝（糖質新生，花 6 ATP）** → 葡萄糖 → 血液 → 肌肉。
  - 整體帳：肌肉得 2 ATP，肝臟花 4 ATP + 2 GTP → **淨耗 4 ATP 當量**。Cori cycle 是跨器官的能量轉移，不是產能循環。
- **Glucose-alanine cycle**：肌肉的胺基轉到 pyruvate 形成 **alanine** → 肝 → 轉胺回 pyruvate（糖質新生）、胺基進**尿素循環**。同時運送碳和氮。
  - 肝臟的 ALT 把胺基交給 α-KG 形成 **glutamate**（不是 glutamine），glutamate 再到粒線體氧化脫胺 → 尿素循環。
  - 比 Cori cycle 多的功能：**把肌肉的胺基氮送到肝臟**。劇烈運動時肌肉輸出的就是 **lactate 與 alanine**（不能輸出葡萄糖）。

- **Warburg effect**：癌細胞即使有氧也把葡萄糖代謝成**乳酸**（aerobic glycolysis）。
  - 治療標的：許多腫瘤依賴 **LDHA**。LDHA 抑制劑（如 FX11、GSK2837808A）的邏輯就是練習題 141 的情境：切斷 NAD⁺ 再生 → **GAPDH 停擺** → 癌細胞 ATP 供應崩潰。

## 3. Creatine／phosphocreatine ⭐

- **Phosphocreatine + ADP ⇌（creatine kinase）⇌ creatine + ATP**：數秒內的爆發力來源。
- Creatine 由 **arginine + glycine** 在**腎**開始、在**肝**以 **S-adenosylmethionine** 甲基化完成；大部分存在骨骼肌。
- Creatine／phosphocreatine 每天約 1–2% **非酵素性脫水環化**成 **creatinine** → 尿液排出（腎功能指標）。
- ⚠️ 考古陷阱：phosphocreatine → creatine 是**去磷酸**，不是脫水（脫水是變成 creatinine）。

## 4. Insulin ⭐⭐⭐

- **5.8 kD** 胜肽，由**胰臟 β 細胞**分泌：A、B 兩條鏈（共 51 個胺基酸，A 鏈 21 + B 鏈 30）以 2 個雙硫鍵相連；切掉 **C-peptide** 而成。
  - 三條雙硫鍵的配置：
    | 編號 | 位置 | 類型 |
    | --- | --- | --- |
    | 1 | A7 – B7 | 鏈間（interchain） |
    | 2 | A20 – B19 | 鏈間 |
    | 3 | A6 – A11 | 鏈內（intrachain，A 鏈自己形成的小環）|
- **分泌機制**：高血糖 → **GLUT2** 進 β 細胞 → 糖解、氧化 → **ATP/ADP ↑** → **ATP-sensitive K⁺ 通道關閉** → 膜**去極化** → **電壓門控 Ca²⁺ 通道**打開 → Ca²⁺ 流入 → insulin 胞吐。（sulfonylurea 藥物直接關 K<sub>ATP</sub> 通道）
- **Incretin effect**：口服葡萄糖比靜脈注射引起更多 insulin（腸道分泌 **GLP-1、GIP** → cAMP ↑）。
- **作用：促進合成、抑制分解**
  - ↑ 肌肉、脂肪的葡萄糖吸收（**GLUT4** 移到細胞膜）、糖解、**肝醣合成**、脂肪酸與 TG 合成（ACC）、膽固醇合成（HMG-CoA reductase）、蛋白質合成
  - ↓ **糖質新生**、脂解、肝醣分解、蛋白質分解
- **訊號**：insulin receptor（**RTK**，二聚體自體磷酸化）→ **IRS-1 → PI3K → Akt** → GLUT4 移位、**GSK3 磷酸化而失活** → glycogen synthase 活化；另一支 Grb2 → Ras → MAPK（生長）。也會活化 **mTORC1**、PPARγ（insulin 敏感度）。
  - **GSK3β 的 Ser9**：Akt 磷酸化 Ser9 → GSK3β **被抑制** → 不再磷酸化（抑制）glycogen synthase → 肝醣合成。把 Ser9 突變成不能磷酸化的 Ala：GLUT4 照樣移位、葡萄糖攝取照樣增加，但**肝醣合成效應減弱**——兩個分支是分開的。
- 蘭氏小島：**α → glucagon、β → insulin、δ → somatostatin**。

### 「促進合成、抑制分解」⭐⭐

- 核心：「合成／分解」在**反應層次**和**生理層次**指的不是同一件事。
  - **反應層次**看 ΔG 和分子走向：糖解放能、分子變小 → 分解代謝。
  - **生理層次**看整個身體的淨物質流向：insulin 被稱為合成激素，是指它讓營養素**從循環流入儲存**，不是說它催化的每一步都是縮合反應。葡萄糖從血液進細胞、變成肝醣或脂肪存起來，整體方向是合成的，但中間必然經過分解性的步驟。
- **Insulin 抑制的「分解」專指已儲存巨分子的拆解**，共同點是**把庫存拿出來燒**；飽食時外面有現成營養，沒道理動用存糧：

  | 被抑制     | 過程                  |
  | ---------- | --------------------- |
  | 肝醣分解   | glycogen → glucose    |
  | 脂解       | TG → FFA + glycerol   |
  | 蛋白質分解 | protein → amino acids |
  | 糖質新生   | 把胺基酸拿去造糖      |

  糖解不屬於這一類：它處理的是**剛吃進來的葡萄糖**，不是庫存。「促進糖解」與「抑制分解」針對的是不同的受質來源，沒有衝突。

- **糖解在飽食狀態的兩個合成任務**：
  1. **提供合成所需的 ATP**：肝醣合成（UDP-glucose 形成）、蛋白質合成（每個胜肽鍵約 4 個高能磷酸鍵）都耗能；合成本身不產能，能量必須由分解代謝供應。
  2. **提供脂肪合成的碳骨架**：
     ```
     葡萄糖 → 糖解 → pyruvate → acetyl-CoA
     → citrate 運出粒線體 → ATP-citrate lyase
     → cytosolic acetyl-CoA → ACC（insulin 活化）
     → malonyl-CoA → 脂肪酸 → TG 儲存
     ```
     **吃過量的醣會變胖，走的就是這條路。** 葡萄糖無法直接變成脂肪，必須先被糖解拆成三碳、再氧化脫羧成二碳，才能當脂肪酸合成的建材。所以在肝臟，**糖解是脂質合成的前置步驟**；不促進糖解，就沒有 acetyl-CoA 可以造脂肪（de novo lipogenesis）。
- **印證：insulin 同時打開兩端**，同一個訊號、同一時間，三者都指向**把碳流導向儲存**。

  | 目標             | Insulin 的作用                                         |
  | ---------------- | ------------------------------------------------------ |
  | PFK-2（肝 L 型） | 去磷酸化活化 → F-2,6-BP ↑ → PFK-1 活化（**推進糖解**） |
  | ACC              | 去磷酸化活化 → malonyl-CoA ↑（**啟動脂肪合成**）       |
  | CPT-1            | 被 malonyl-CoA 抑制（**關閉脂肪氧化**）                |

  沒有糖解，ACC 就拿不到 acetyl-CoA。

- **更準確的定義**：insulin 是**儲存訊號（storage signal）**，不是「只促進縮合反應的激素」。它在營養充足時把碳與氮導入長期儲存、把血糖拉回正常；糖解是達成這兩件事的工具。
- **Glucagon 是鏡像**：促進肝醣分解、脂解、糖質新生、生酮——把庫存拿出來用；而它在肝臟**抑制**糖解（cAMP／PKA 使 L 型 PFK-2 失活），因為此時肝的任務是**輸出**葡萄糖而不是消耗它。
  - ⚠️ 這只發生在肝臟：肌肉的 **M 型 PFK-2 沒有 PKA 磷酸化位點**，epinephrine 在肌肉反而**促進**糖解——同一個 cAMP 訊號，在兩個器官造成相反結果。
  - 「促進／抑制糖解」取決於**該器官在當下分工中扮演的角色**。

### 胰島素分泌的臨床推理⭐⭐

| 情境                                | insulin | C-peptide | 判讀                        |
| ----------------------------------- | ------- | --------- | --------------------------- |
| **自行注射外源 insulin**            | ↑       | **↓**     | 市售 insulin 不含 C-peptide |
| Insulinoma、sulfonylurea、T2DM 早期 | ↑       | ↑         | 內生性分泌：兩者等量切出    |
| T1DM                                | ↓       | ↓         | β 細胞被破壞                |

- **K<sub>ATP</sub> 通道突變、ATP 關不掉**：K⁺ 持續外流 → 不能去極化 → Ca²⁺ 進不來 → **insulin 分泌減少**（與「關不掉 → 分泌增加」相反）。
- **Sulfonylurea vs GLP-1**：sulfonylurea **直接關 K<sub>ATP</sub>**，不管血糖高低都讓 β 細胞去極化 → **易低血糖**；GLP-1 只**放大**葡萄糖引發的分泌（**葡萄糖依賴性**），血糖正常時作用就變弱，又抑制 glucagon、延緩胃排空 → 少低血糖。
- **Hyperinsulinism-hyperammonemia syndrome**：glutamate dehydrogenase 持續活化 → β 細胞 glutamate → α-KG 進 TCA → ATP ↑ → insulin 過度分泌（**低血糖**）；肝臟氧化脫胺過多 → **高血氨**（見 Ch18）。

## 5. Glucagon、epinephrine 與 cAMP ⭐⭐

- 空腹時 **glucagon**（胰臟 α 細胞）作用在**肝**；**epinephrine** 作用在肝和肌肉。
- **GPCR → G<sub>s</sub> → adenylyl cyclase → cAMP → PKA**：
  - 肝：**肝醣分解 ↑**（phosphorylase kinase → glycogen phosphorylase b → a）、**糖質新生 ↑**、**糖解 ↓**（PFK-2 被磷酸化 → F-2,6-BP ↓；pyruvate kinase 被磷酸化失活）、生酮 ↑
  - 脂肪：**HSL、perilipin 被磷酸化 → 脂解 ↑**（脂肪酸由 albumin 運送；不需要 PKC）
  - 肌肉（epinephrine）：肝醣分解與**糖解 ↑**（準備戰鬥或逃跑）
- **磷酸化規則**：「**磷酸化 → 分解**、去磷酸化 → 合成」：glycogen synthase **磷酸化＝失活**；glycogen phosphorylase **磷酸化＝活化（a 型）**。
- Glycogen phosphorylase 需要 **pyridoxal phosphate（PLP）**。
- **肌肉沒有 glucagon 受體**：glucagon 不能直接促進肌肉肝醣分解，肌肉靠 epinephrine（肌肉有 glycogen phosphorylase、cAMP、PKA，缺的只是受體）。
- **Epinephrine 在肝、肌肉對糖解作用相反的原因**：肝臟 PKA 磷酸化 **PFK-2/FBPase-2** 雙功能酵素 → **fructose-2,6-bisphosphate ↓**（PFK-1 最強的活化劑）→ 肝糖解 ↓，把葡萄糖留給血液；**肌肉的同工酶不受這種抑制**，加上 cAMP 促進肝醣分解提供受質 → 肌肉糖解 ↑ 就地產能。
- **AMPK**（能量感測器，AMP:ATP 高時活化）：促進葡萄糖吸收、糖解、脂肪酸氧化；抑制合成（ACC、HMG-CoA reductase）。運動、metformin 會活化。
  - **活化條件**：飢餓／熱量限制、缺氧、缺血、劇烈運動、極端溫度、**adiponectin**、ghrelin。**飽食後 ATP/AMP 高 → 不會活化**。
  - **骨牌**：AMPK **磷酸化抑制 ACC** → **malonyl-CoA ↓** → CPT I 抑制解除 → 長鏈脂肪酸進粒線體氧化 ↑；脂肪酸合成 ↓。另外**抑制 mTORC1**（AMPK 是 mTOR 的抑制者，不是活化者）。

## 6. mTOR ⭐

- **PI3K 相關的 Ser/Thr kinase**，因 **rapamycin** 而發現；rapamycin 與 **FKBP12** 結合後**別構抑制 mTORC1**（不影響 mTORC2）。
- **營養充足**時活化（胺基酸 Leu/Arg、insulin/IGF-1、高 ATP）→ 蛋白質、脂質合成、細胞生長；**抑制 autophagy**。Metformin、rapamycin 抑制 mTOR → 與延緩老化有關。

## 7. Leptin 與脂肪激素 ⭐⭐

- **Leptin**：**16 kD**，**脂肪細胞分泌**（不是下視丘），**OB（obese）gene** 產物；受體由 **DB gene** 編碼，在下視丘 arcuate nucleus。
- 訊號：leptin receptor → **JAK-STAT**（JAK 磷酸化 Tyr → STAT3/5/6）→ ↑ **POMC**（α-MSH，抑制食慾）、↓ NPY/AgRP → **吃少、能量消耗增加**。
- **產熱**：leptin → 交感神經 **norepinephrine** → 脂肪細胞 **β3-adrenergic receptor** → cAMP/PKA → **UCP1（thermogenin）**表現 ↑ → 粒線體質子漏 → 產熱。
- Leptin **促進** β-oxidation、**抑制**脂肪合成。OB 基因缺陷 → leptin 不足 → 肥胖；但**多數肥胖者 leptin 很高，問題是 leptin resistance**。
- **Adiponectin**（**ADIPOQ** gene，脂肪細胞）：↑ insulin 敏感度、↑ AMPK、脂肪酸氧化；肥胖時反而下降。
- **Ghrelin**（胃）：飢餓素，**28 個胺基酸**，促進食慾、**促進 growth hormone 分泌**；**Prader-Willi syndrome** 血中 ghrelin 異常高。
- **PYY₃₋₃₆**（迴腸、結腸）：抑制食慾。
- **GLP-1**：遠端迴腸與大腸 **L 細胞**分泌的 incretin；**葡萄糖依賴性**促 insulin、抑制 glucagon、**延緩胃排空**、增加飽足感。
- **UCP1 的能量帳**（練習題 148）：質子繞過 ATP synthase 回基質 → 電化學梯度的能量**以熱散失**，每單位燃料的 ATP 減少（P/O ratio ↓）。⚠️ 呼吸鏈**不會**因此變慢：Δp 下降解除了對電子傳遞的背壓（respiratory control）→ **耗氧量反而上升**，產熱正是靠電子傳遞持續運轉。

## 8. 飢餓與糖尿病 ⭐⭐

- **長期飢餓**：insulin ↓、glucagon ↑；肝醣耗盡 → **糖質新生**（原料：肌肉蛋白的胺基酸、glycerol、lactate）→ OAA 被抽走 → **生酮**；腦改用**酮體**以節省蛋白質；**血中酮體（β-hydroxybutyrate、acetoacetate）上升最多**。不會有肝醣合成。
- 空腹時肝細胞：glycogen synthase 磷酸化（失活）、glycogen phosphorylase 磷酸化（活化）、**glucose-6-phosphatase 活化**、CPT I 活化。
- **Type 1 DM**：自體免疫破壞 **β 細胞** → **insulin 缺乏**；年輕發病、偏瘦、需要注射 insulin、**易酮酸中毒**。（insulin resistance 不是 T1DM 的主因）
- **Type 2 DM**：**insulin resistance**（insulin 正常或偏高）；中年後發病、肥胖、家族史，佔糖尿病大多數。
- **「豐盛中的飢餓」（starvation in the midst of plenty）**：血糖雖高，insulin 缺乏或阻抗讓細胞用不到葡萄糖 → 代謝狀態像飢餓 → 脂解、酮體生成 ↑。
- 飢餓時脂肪分解出的 **glycerol → 肝臟糖質新生**；三條脂肪酸 → β-oxidation → acetyl-CoA → 酮體。

## 9. 酮體的開關：malonyl-CoA、OAA 與 SCOT ⭐⭐

- **合成**：肝**粒線體**，acetyl-CoA →（thiolase）→ acetoacetyl-CoA →（**HMG-CoA synthase，粒線體型 HMGCS2**）→ HMG-CoA →（HMG-CoA lyase）→ **acetoacetate** → β-hydroxybutyrate（NADH）或自發脫羧成 acetone。
- **利用**：肝外組織（心、腦、肌肉）以 **SCOT（succinyl-CoA:3-ketoacid CoA transferase，舊稱 thiophorase）** 從 succinyl-CoA 借 CoA 活化 acetoacetate → acetoacetyl-CoA → 2 acetyl-CoA → TCA。
  - **肝臟缺 SCOT** → 做酮體但自己不能用；**紅血球沒有粒線體** → 也不能用。
  - 抑制 HMGCS2：不能合成，**仍能用外源 acetoacetate**；抑制 SCOT：能合成，**不能用**（心肌酮體氧化 ↓）。
- **為什麼飢餓／T1DM 會大量生酮**（即使血糖很高）：
  1. insulin ↓、glucagon ↑ → 脂解 ↑ → 大量脂肪酸送到肝。
  2. ACC 被抑制 → **malonyl-CoA ↓** → **CPT I 解除抑制** → β-oxidation ↑ → acetyl-CoA 大增。
  3. **OAA 被拉去糖質新生** → 能和 acetyl-CoA 合成 citrate 的 OAA 不夠 → acetyl-CoA 轉向 HMG-CoA → 酮體。
- 反過來，**吃飽時 malonyl-CoA ↑**（正在合成脂肪）→ 抑制 CPT I → 脂肪酸不進粒線體 → **酮體生成減少**。malonyl-CoA 不是酮體原料，也不活化 HMG-CoA synthase。

<div data-fig="ketone-switch"></div>

- **延伸：脂肪肝（NAFLD）反而生酮變少**——直覺上「脂肪多 → acetyl-CoA 多 → 酮體多」，但人體示蹤研究發現禁食時脂肪肝的 β-oxidation 量和正常人差不多，acetyl-CoA 卻**改進 TCA 氧化**而不是做酮體 → 多出的 ATP 推動**糖質新生** → 禁食血糖偏高；同時 insulin 偏高、glucagon/insulin 比值低，也不利生酮。（研究層級，非國考重點）

## 🎙️ 上課錄影重點（陳顧中，Ch23-1 實體 + Ch23-2 非同步遠距）

- 老師說的「很愛考」都是指**國考**（醫師、牙醫、營養、醫技四科出題老師相近，講義收錄各科國考題）；期中考難度「大概就跟國考題差不多」，題目會類似但不會一模一樣，不要背答案。
- 本章 = 把上學期到現在所有能量代謝放在器官與荷爾蒙上總整理；重點器官：**大腦、骨骼肌、肝臟、紅血球**（心肌類似骨骼肌、脂肪交給黃老師，不另外講）。
- **儲存三形態與動用順序：糖（肝醣）→ 脂肪（TG）→ 蛋白質**（蛋白質分解產氨有毒，盡量不走到這步）；餓一兩天體重不太變是因為只消了糖。112 年牙醫國考考過「送分題」。
- **大腦**：平常用 glucose；**長期飢餓（starvation）改用酮體（β-hydroxybutyrate）**；不儲存、不輸出能量。不直接用脂肪酸：FA 與 **albumin** 結合、不易通過 **BBB**（astrocyte 其實能做 β-oxidation）。
- **骨骼肌**：**resting 時用脂肪酸**（長期臥床的人會變瘦）；運動早期用肝醣、晚期才燒脂肪（有氧運動心跳 120–130、持續 30 分鐘以上才開始消脂）；飢餓時也用酮體；蛋白質（有毒性）、**creatine phosphate**。**全身肝醣 3/4 在肌肉、1/4 在肝臟**；肌肉肝醣只留給自己用（「自私」）——因為**缺 glucose-6-phosphatase**（只有肝臟有）；肌肉輸出 **乳酸** 與 **alanine**。
- **無氧糖解**：糖解照走到 pyruvate（4 − 2 = **2 ATP + 2 NADH**），缺氧時 **lactate dehydrogenase** 用 **NADH** 還原 pyruvate → 乳酸。乳酸不是壞東西：只有約 2% 排到尿中。**Cori cycle（各科系平均每兩年考一次）**：肌肉乳酸 → **肝臟**糖質新生（**耗能，6 ATP**）→ glucose 回肌肉。「看到**無氧**或 **Cori cycle**，答案找**乳酸**，幾乎百分之百」。
- **Warburg effect**：癌細胞即使有氧也偏好無氧糖解 → 快速得到 ATP、產生乳酸（今年醫技國考）。
- **Creatine / phosphocreatine**：真正給能量的是帶磷酸的 phosphocreatine；**瞬間爆發力**（國考：100 公尺賽跑前幾秒的能量）、約 5 分鐘內；**creatine kinase** 讓兩者互換；用舊後以**脫水**形成廢物 **creatinine** 排出（國考問「怎麼變的」）。富含：瘦牛肉（菲力）、瘦豬肉、鮭魚、小魚乾。心肌大部分時間偏好脂肪酸。
- **肝臟**：什麼都用（不考）；儲存 1/4 肝醣與 TG（脂肪肝）；飢餓時輸出 glucose、脂肪酸 / 酮體、glycerol（糖質新生原料）。吃飽時 **hexokinase 與 glucose transporter** 發達 → 合成肝醣 → 間接降血糖。**Glycogen synthase：平常活化、磷酸化抑制**；**glycogen phosphorylase：平常不活化、磷酸化活化**。
- **酮體五大重點（黃老師也很愛考）**：① 在**肝臟**製造 ② **fasting** 時 ③ 材料是脂肪酸 β-oxidation 後的 **acetyl-CoA** ④ 先做 **acetoacetate**，再生成 **β-hydroxybutyrate** 與 **acetone** ⑤ **β-hydroxybutyrate 是最主要的能量提供者、濃度最高**，acetoacetate 次之，**acetone 不提供能量、由呼氣排出**；失控 → 酮酸血症。調控：glucagon 促進、insulin 抑制，關鍵是 **malonyl-CoA 越多、酮體越少**（高能量狀態）。
- **紅血球**：**沒有粒線體** → 只能無氧糖解 → 乳酸；中間產物 2,3-BPG；**PPP 提供 NADPH 讓 glutathione 維持還原態**、協助糖解。
- 荷爾蒙依「吃飽 vs 肚子餓」分兩大類。吃飽：**insulin（第一名）> leptin > mTOR（牙醫系近 15 年沒考過）**，胚胎那個「這輩子應該都不會考」。
- **Insulin**：proinsulin 切除 **C-peptide**（以前以為是垃圾）；**β cell** 分泌 insulin、**α cell** glucagon、**δ cell** somatostatin（青春期後抑制長高）。**Glucose 刺激分泌（醫學系考過）**：glucose 進細胞 → ATP ↑ → **關閉 K⁺ 通道（K⁺ 應由內往外，老師說講義箭頭畫反）→ 去極化 → 打開 Ca²⁺ 通道 → Ca²⁺ 流入 → 分泌泡釋出 insulin**。**Incretin effect**：口服葡萄糖誘導的 insulin 比靜脈注射多（GLP-1）。
  - Proinsulin 在 β cell 的分泌顆粒中儲存並進行加工。前驅物 preproinsulin（110 aa）在粗糙內質網合成，訊號胜肽被切除成 proinsulin（86 aa），運至高基氏體後裝入顆粒，在顆粒內完成最終轉換。
  - 由兩個 prohormone convertase 切割：
  ```
    Proinsulin --[PC1/3 切 B-C 接合]-->
                --[PC2 切 C-A 接合]-->
                --[carboxypeptidase E 修掉殘餘鹼性胺基酸]-->
    Insulin (A+B, 51 aa) + C-peptide (31 aa)
  ```
- **Insulin 功能 = 促進合成、抑制分解**；⚠️ **糖解要視為「合成」（被促進）**；**抑制糖質新生、抑制酮體形成**。GI 值越高越易胖；低 GI 水果有芭樂、小番茄。
- **Insulin receptor = RTK（receptor tyrosine kinase）**；其他 RTK 是 monomer、結合 ligand 才 dimerization，⚠️ **insulin receptor 本身就是 dimer（例外）**，但要結合 insulin 才有活性 → **autophosphorylation**。下游兩條：**IRS → PI3K → AKT（打開 glucose transporter）**；**RAS → RAF → MEK → ERK（生長發育；醫學系曾考四個選項排列順序）**。
- **GLUT 口訣「二肝胰腸、四肌脂」（二肝姨嘗試雞汁）**：GLUT2 肝、胰、腸；**GLUT4 肌肉、脂肪，完全受 insulin 調控**。國考開始考冷門：**GLUT5 = 果糖**、**GLUT9 = 尿酸鹽（urate）**。**GSK3β 抑制 glycogen synthase；insulin 抑制 GSK3β → 肝醣合成**。
- **mTOR**（mammalian target of rapamycin，complex 1 / 2）：吃飽時活化 → 生長發育；癌細胞利用它狂長（mTOR inhibitor 曾是研究熱點，但癌細胞會繞路）；抑制 mTOR 的小鼠活得更久；糖尿病藥 **metformin** 會抑制 mTOR。
- **Leptin（瘦素，越多越瘦）**：由 **OB（肥胖）基因**產生，缺陷 → 嚴重肥胖；**脂肪細胞（adipocyte）分泌**；功能：① 抑制脂肪合成、促進燃燒 ② 作用於**下視丘**抑制食慾（JAK-STAT，不用背）③ 活化棕色脂肪 **UCP1（thermogenin）= 哺乳類唯一的去耦合劑** → 電子傳遞照走但不產生 ATP、產熱。**Leptin resistance** → leptin 多也不瘦。
- 肚子餓類：**glucagon、epinephrine（第一名）> ghrelin > AMPK、adiponectin（只在醫學系出現，屬難題）**。
- **Glucagon = 抑制合成、促進分解**（與 insulin 相反）：抑制糖解、促進糖質新生、促進酮體、↑cAMP。**Epinephrine** 功能幾乎同 glucagon，⚠️ **例外：在肌肉促進糖解（考過）**（媽媽抬車要肌肉爆發力），其他器官仍抑制糖解；還會心跳加快、血壓上升、呼吸變快。
- **脂肪分解的 cAMP 訊息圖（幾乎每次國考都考，打星號）**六個重點：① 荷爾蒙結合**細胞膜**上 receptor（不是核膜或細胞質）② **GPCR → G protein** ③ **adenylyl cyclase：ATP → cAMP**（cAMP 與 glucagon 同向、與 insulin 反向）④ **PKA** ⑤ **hormone-sensitive lipase** → FA + glycerol ⑥ 血中 FFA 由 **albumin** 運送（也因此大腦少用 FA）。
- **Ghrelin（飢餓素，28 aa 小胜肽）**：原以為與 growth hormone 有關而命名；主要由**胃**分泌（胃排空時）、其次胰臟 → 作用於**下視丘** → 食慾↑。**Prader-Willi syndrome（小胖威利）**：ghrelin 過高、一直吃不飽，3–5 歲發病，未控制常活不過 30 歲（老師口誤後更正為「特別高」）。
- **AMPK（AMP-activated protein kinase）**：低能量 / 危急時活化（starvation、hypoxia、缺血、劇烈運動、溫度劇變、adiponectin）→ **促進產能反應、抑制耗能反應**（含**抑制糖質新生**、抑制合成）；**AMPK 抑制 mTOR**。
- **Adiponectin**：也由脂肪細胞分泌、**越多越健康**（體脂過低的健美選手反而不好）；促進脂肪氧化、調控血糖、**增加細胞對 insulin 的敏感性**（預防糖尿病）、經 AMPK 抑制糖質新生；肥胖者偏低 → **代謝症候群**、癌症風險↑。促進：減重、少吃（七分飽）、**魚油**、**烏龍茶 / 綠茶（真的用茶葉泡的）**、PPAR agonist。

**Adiponectin vs Leptin**

| 特徵           | Adiponectin（脂聯素）                             | Leptin（瘦素）                                 |
| -------------- | ------------------------------------------------- | ---------------------------------------------- |
| 來源           | 脂肪細胞                                          | 脂肪細胞                                       |
| 與脂肪量       | **負相關**（肥胖者低）                            | **正相關**（肥胖者高，但常 leptin resistance） |
| 作用部位／機制 | 骨骼肌、肝，經 **AMPK**                           | **下視丘**：↓NPY、↑POMC                        |
| 主要功能       | ↑ β-oxidation、↑ 葡萄糖攝取、**↓ 肝臟糖質新生**   | **↓ 食慾**、調節能量平衡                       |
| Insulin 敏感性 | **直接 ↑**（抗糖尿病）                            | 間接                                           |
| 臨床           | 低 → 肥胖、insulin resistance、糖尿病、心血管疾病 | 高（但抗性）→ 肥胖、代謝症候群                 |
| 口訣           | **Add energy burning**                            | **Let's stop eating**                          |

- **GLP-1（glucagon-like peptide 1，瘦瘦針主成分）**：由**腸**分泌的 **incretin（考過：GLP-1 由腸分泌，ghrelin 才是胃）**；↑insulin、↓glucagon，但讓血糖維持恆定不會掉太低 → 不會餓；**延緩胃排空** → ghrelin 不增加。停藥後若不改飲食，一年內約一半人恢復體重；副作用噁心、頭暈；胰臟癌風險尚未證實。
- **Starvation 時使用酮體的三大器官：心臟、大腦、肌肉**（酮體在肝臟製造）——醫師國考送分題。
- **Type 1 DM（先天、juvenile、insulin-dependent）**：人數少；病毒破壞 β cell、insulin 基因異常、⭐ **血中可測到對抗自己胰島細胞的自體抗體（用來區分 type 1 / type 2）**；治療天天打 insulin（每次換部位避免皮膚硬化）；年輕發病、通常很瘦、易酮酸血症。
- **Type 2 DM（後天、病因不明、占約 90%、有家族史）**：少數是中年後 β cell 壞掉；多數是 **insulin resistance —— 問題在 insulin receptor**（收不到訊號 → GLUT 不打開），血中 insulin 正常甚至偏高；中老年、肥胖較易（瘦的人也可能）。早期警訊：大肚子、愛吃甜食、飯後想睡、關節痛、難減重。指標：**HbA1c**、OGTT。
- 經典題「糖尿病何者正確」：細胞吃不到糖 → 身體以為沒有糖 → **肝細胞脂肪酸氧化↑、acetyl-CoA↑**（準備做酮體）；不會促進肝醣或脂肪儲存。

# 考點分析

## 🔥 高頻考點（113 共筆 Ch23 36 題 + 2026 slides 38 題國考）

1. **Insulin 促進合成、抑制分解**：不促進糖質新生、不分解儲存的 TG；促進 lipogenesis、HMG-CoA reductase。
2. **GLUT 位置**：GLUT2（肝、胰 β 細胞、小腸、腎小管，**心臟沒有**）、GLUT4（肌肉、脂肪，insulin 調控）、GLUT5（果糖）、GLUT9（尿酸）。
3. **Leptin**：脂肪細胞分泌、OB gene、**經 norepinephrine → UCP1 產熱**、促進 β-oxidation、肥胖多為 leptin resistance。
4. **酮體**：肝臟最多、β-hydroxybutyrate 最多、acetoacetate 最先生成、飢餓時血中上升最多。
5. **Cori cycle**：LDH 用 NADH、肝臟做糖質新生；「肌肉缺葡萄糖時把 pyruvate 變成 lactate 當燃料」是錯的。
6. **肌肉缺 glucose-6-phosphatase**（國考 4 題換句話）。
7. **紅血球**：無粒線體、只靠糖解、**PPP** 產生 NADPH；pyruvate 不會變成 acetyl-CoA。
8. **Glucagon／epinephrine**：肝醣分解 ↑、肝臟糖解 ↓、脂解靠 cAMP 與 G 蛋白，**不需要 PKC**。
9. **T1DM vs T2DM**：insulin resistance 不是 T1DM 的特徵。
10. **Creatine**：SAM 參與合成、phosphocreatine → creatine 不是脫水。
11. **Prader-Willi → ghrelin 異常高**；**ADIPOQ → adiponectin**。

- 共筆題目多為「下列敘述何者正確／錯誤」的**四選項敘述題**，一題考四個概念 → 要整張表都熟。
