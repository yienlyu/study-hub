# 器官間代謝整合與激素調控（陳顧中）

> 課程大綱三大塊：① 各主要器官的燃料代謝（腦、骨骼肌、肝、血液）② 激素調控（insulin、leptin、glucagon、epinephrine）③ 代謝壓力（飢餓、糖尿病）。去年共筆分成 23-1（黃彥華）與 23-2（陳顧中），題目是同一份。

## 1. 各器官的燃料代謝 ⭐⭐⭐

| 器官 | 燃料儲存 | 偏好燃料 | 輸出 | 關鍵特點 |
|---|---|---|---|---|
| **腦** | 無 | **葡萄糖**（每天 ~120 g，總能量 15%）；**飢餓時用酮體（β-hydroxybutyrate）** | 無 | 高度有氧（耗全身 **20% 氧氣**）；脂肪酸過不了血腦障壁 |
| **骨骼肌（休息）** | 肝醣（全身 **3/4** 的肝醣） | **脂肪酸** | 無 | 也可用酮體 |
| **骨骼肌（運動）** | 無 | **葡萄糖**（先來自肝醣，後期加脂肪酸） | **lactate、alanine** | 爆發力靠 **phosphocreatine** |
| **心肌** | 少量 | **脂肪酸**（高度依賴氧化磷酸化） | 無 | 粒線體極多 |
| **肝臟** | 肝醣、TG | 胺基酸、葡萄糖、脂肪酸 | **葡萄糖、脂肪酸（VLDL）、酮體** | 代謝中樞；**脂肪酸合成主要場所**；生酮 |
| **脂肪組織** | **TG** | 葡萄糖、脂肪酸 | 脂肪酸、glycerol | 棕色／米色脂肪靠 **UCP1** 產熱 |
| **紅血球** | 無 | 葡萄糖 | **lactate** | **沒有粒線體 → 只靠無氧糖解**；PPP 產生 NADPH 維持 glutathione 還原態；2,3-BPG |
| 腎臟 | | | | 飢餓時也做糖質新生 |

- **燃料使用順序**：**肝醣 → 三酸甘油酯 → 蛋白質**。
- **肌肉肝醣不能補血糖**：肌肉**沒有 glucose-6-phosphatase**，肝醣分解產生的 G6P 只能自己用。只有肝（和腎）能釋出葡萄糖。
- 肝臟用 **hexokinase IV（glucokinase，Km 高、不被 G6P 抑制）** 與 **GLUT2** 緩衝血糖。

## 2. 乳酸、Cori cycle 與 glucose-alanine cycle ⭐⭐
- 無氧時：pyruvate + **NADH** →（**lactate dehydrogenase**）→ lactate + NAD⁺（再生 NAD⁺ 讓糖解繼續）。**淨產 2 ATP**（NADH 被用掉）。
- 乳酸去路：約 **2% 從尿排出**；大部分轉回 pyruvate → 進粒線體氧化，或在**肝、腎**做糖質新生。
- **Cori cycle**：肌肉（糖解，得 2 ATP）→ 乳酸 → 血液 → **肝（糖質新生，花 6 ATP）** → 葡萄糖 → 血液 → 肌肉。
- **Glucose-alanine cycle**：肌肉的胺基轉到 pyruvate 形成 **alanine** → 肝 → 轉胺回 pyruvate（糖質新生）、胺基進**尿素循環**。同時運送碳和氮。
- **Warburg effect**：癌細胞即使有氧也把葡萄糖代謝成**乳酸**（aerobic glycolysis）。

## 3. Creatine／phosphocreatine ⭐
- **Phosphocreatine + ADP ⇌（creatine kinase）⇌ creatine + ATP**：數秒內的爆發力來源。
- Creatine 由 **arginine + glycine** 在**腎**開始、在**肝**以 **S-adenosylmethionine** 甲基化完成；大部分存在骨骼肌。
- Creatine／phosphocreatine 每天約 1–2% **非酵素性脫水環化**成 **creatinine** → 尿液排出（腎功能指標）。
- ⚠️ 考古陷阱：phosphocreatine → creatine 是**去磷酸**，不是脫水（脫水是變成 creatinine）。

## 4. Insulin ⭐⭐⭐
- **5.8 kD** 胜肽，由**胰臟 β 細胞**分泌：A、B 兩條鏈（共 51 個胺基酸）以 2 個雙硫鍵相連；切掉 **C-peptide** 而成。
- **分泌機制**：高血糖 → **GLUT2** 進 β 細胞 → 糖解、氧化 → **ATP/ADP ↑** → **ATP-sensitive K⁺ 通道關閉** → 膜**去極化** → **電壓門控 Ca²⁺ 通道**打開 → Ca²⁺ 流入 → insulin 胞吐。（sulfonylurea 藥物直接關 K<sub>ATP</sub> 通道）
- **Incretin effect**：口服葡萄糖比靜脈注射引起更多 insulin（腸道分泌 **GLP-1、GIP** → cAMP ↑）。
- **作用：促進合成、抑制分解**
  - ↑ 肌肉、脂肪的葡萄糖吸收（**GLUT4** 移到細胞膜）、糖解、**肝醣合成**、脂肪酸與 TG 合成（ACC）、膽固醇合成（HMG-CoA reductase）、蛋白質合成
  - ↓ **糖質新生**、脂解、肝醣分解、蛋白質分解
- **訊號**：insulin receptor（**RTK**，二聚體自體磷酸化）→ **IRS-1 → PI3K → Akt** → GLUT4 移位、**GSK3 磷酸化而失活** → glycogen synthase 活化；另一支 Grb2 → Ras → MAPK（生長）。也會活化 **mTORC1**、PPARγ（insulin 敏感度）。

## 5. Glucagon、epinephrine 與 cAMP ⭐⭐
- 空腹時 **glucagon**（胰臟 α 細胞）作用在**肝**；**epinephrine** 作用在肝和肌肉。
- **GPCR → G<sub>s</sub> → adenylyl cyclase → cAMP → PKA**：
  - 肝：**肝醣分解 ↑**（phosphorylase kinase → glycogen phosphorylase b → a）、**糖質新生 ↑**、**糖解 ↓**（PFK-2 被磷酸化 → F-2,6-BP ↓；pyruvate kinase 被磷酸化失活）、生酮 ↑
  - 脂肪：**HSL、perilipin 被磷酸化 → 脂解 ↑**（脂肪酸由 albumin 運送；不需要 PKC）
  - 肌肉（epinephrine）：肝醣分解與**糖解 ↑**（準備戰鬥或逃跑）
- **磷酸化規則**：「**磷酸化 → 分解**、去磷酸化 → 合成」：glycogen synthase **磷酸化＝失活**；glycogen phosphorylase **磷酸化＝活化（a 型）**。
- Glycogen phosphorylase 需要 **pyridoxal phosphate（PLP）**。
- **AMPK**（能量感測器，AMP:ATP 高時活化）：促進葡萄糖吸收、糖解、脂肪酸氧化；抑制合成（ACC、HMG-CoA reductase）。運動、metformin 會活化。

## 6. mTOR ⭐
- **PI3K 相關的 Ser/Thr kinase**，因 **rapamycin** 而發現；rapamycin 與 **FKBP12** 結合後**別構抑制 mTORC1**（不影響 mTORC2）。
- **營養充足**時活化（胺基酸 Leu/Arg、insulin/IGF-1、高 ATP）→ 蛋白質、脂質合成、細胞生長；**抑制 autophagy**。Metformin、rapamycin 抑制 mTOR → 與延緩老化有關。

## 7. Leptin 與脂肪激素 ⭐⭐
- **Leptin**：**16 kD**，**脂肪細胞分泌**（不是下視丘），**OB（obese）gene** 產物；受體由 **DB gene** 編碼，在下視丘 arcuate nucleus。
- 訊號：leptin receptor → **JAK-STAT**（JAK 磷酸化 Tyr → STAT3/5/6）→ ↑ **POMC**（α-MSH，抑制食慾）、↓ NPY/AgRP → **吃少、能量消耗增加**。
- **產熱**：leptin → 交感神經 **norepinephrine** → 脂肪細胞 **β3-adrenergic receptor** → cAMP/PKA → **UCP1（thermogenin）**表現 ↑ → 粒線體質子漏 → 產熱。
- Leptin **促進** β-oxidation、**抑制**脂肪合成。OB 基因缺陷 → leptin 不足 → 肥胖；但**多數肥胖者 leptin 很高，問題是 leptin resistance**。
- **Adiponectin**（**ADIPOQ** gene，脂肪細胞）：↑ insulin 敏感度、↑ AMPK、脂肪酸氧化；肥胖時反而下降。
- **Ghrelin**（胃）：飢餓素，促進食慾；**Prader-Willi syndrome** 血中 ghrelin 異常高。
- **PYY₃₋₃₆**（迴腸、結腸）：抑制食慾。

## 8. 飢餓與糖尿病 ⭐⭐
- **長期飢餓**：insulin ↓、glucagon ↑；肝醣耗盡 → **糖質新生**（原料：肌肉蛋白的胺基酸、glycerol、lactate）→ OAA 被抽走 → **生酮**；腦改用**酮體**以節省蛋白質；**血中酮體（β-hydroxybutyrate、acetoacetate）上升最多**。不會有肝醣合成。
- 空腹時肝細胞：glycogen synthase 磷酸化（失活）、glycogen phosphorylase 磷酸化（活化）、**glucose-6-phosphatase 活化**、CPT I 活化。
- **Type 1 DM**：自體免疫破壞 **β 細胞** → **insulin 缺乏**；年輕發病、偏瘦、需要注射 insulin、**易酮酸中毒**。（insulin resistance 不是 T1DM 的主因）
- **Type 2 DM**：**insulin resistance**（insulin 正常或偏高）；中年後發病、肥胖、家族史，佔糖尿病大多數。

# 考點分析

## 🔥 高頻考點（113 共筆 Ch23 36 題 + 2026 slides 38 題國考）
1. **Insulin 促進合成、抑制分解**：不促進糖質新生、不分解儲存的 TG；促進 lipogenesis、HMG-CoA reductase。
2. **GLUT 位置**：GLUT2（肝、胰 β 細胞、小腸、腎小管，**心臟沒有**）、GLUT4（肌肉、脂肪，insulin 調控）、GLUT5（果糖）、GLUT9（尿酸）。
3. **Leptin**：脂肪細胞分泌、OB gene、**經 norepinephrine → UCP1 產熱**、促進 β-oxidation、肥胖多為 leptin resistance。
4. **酮體**：肝臟最多、β-hydroxybutyrate 最多、acetoacetate 最先生成、飢餓時血中上升最多。
5. **Cori cycle**：LDH 用 NADH、肝臟做糖質新生；「肌肉缺葡萄糖時把 pyruvate 變成 lactate 當燃料」是錯的。
6. **肌肉缺 glucose-6-phosphatase**（國考 4 題換句話）。
7. **紅血球**：無粒線體、只靠糖解、**PPP** 產生 NADPH；pyruvate 不會變成 acetyl-CoA。
8. **Glucagon／epinephrine**：肝醣分解 ↑、肝臟糖解 ↓、脂解靠 cAMP 與 G 蛋白，**不需要 PKC**。
9. **T1DM vs T2DM**：insulin resistance 不是 T1DM 的特徵。
10. **Creatine**：SAM 參與合成、phosphocreatine → creatine 不是脫水。
11. **Prader-Willi → ghrelin 異常高**；**ADIPOQ → adiponectin**。
