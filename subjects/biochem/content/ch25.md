## 1. 早期見解 ⭐

- **Watson & Crick（1953）**提出 DNA 模型，1962 年諾貝爾獎：**A–T、G–C 互補，雙股螺旋，反向平行**（雖然耳熟能詳，國考照樣考）。
- **Arthur Kornberg** 發現 *E. coli* **DNA polymerase I**，1959 年諾貝爾獎。老師：「美麗的錯誤」——真正在複製叉負責複製的是 **DNA polymerase III**，Pol I 主要是**去除 primer**；但兩者結構、作用大同小異，獎沒有被追回。
- **Mg²⁺ 是所有 DNA 聚合酶（RNA 聚合酶也是）必需的 cofactor**：活性中心是由 **Asp（D705、D882）**和金屬離子形成的 pocket（slides 寫 Me²⁺，後來證實是 Mg²⁺）。微量必需元素叫 **trace element**。
- **Meselson–Stahl 實驗**證明 DNA 複製是**半保留**（百十三考古 ch25-36）。

## 2. DNA 複製的 3 步驟與 5 特性 ⭐⭐⭐

- **3 steps：initiation（起始）→ elongation（延長）→ termination（終止）**；複製、轉錄、轉譯都用這三個名詞。
- **5 characteristics**：
  1. **Bidirectional 雙向性**：一個 origin 產生**兩個 replication fork**，往兩個方向走（考古：bidirectional = two replication forks，不是 two origins）。
  2. **Semiconserved 半保留**：新 DNA 一股舊（模板）、一股新。
  3. **Semidiscontinuous 半不連續**：**leading strand 連續，lagging strand 以 Okazaki fragment 片段合成**。
  4. **需要 primer**：primer 是**一小段 RNA**（不是 DNA）。
  5. **延長方向 5'→3'**。

## 3. Initiation（*E. coli*）⭐⭐⭐

### oriC

- **oriC**（C = chromosome）：*E. coli* 只有 **245 bp**。
- 含 **11 個 GATC 序列**，其 **A 被 Dam methylase 甲基化**（Dam = DNA adenine methylation）。
- **DUE（DNA unwinding element）**：**13 bp 重複三次、AT-rich** → 雙股在這裡被解開。
  - 老師的原則：「**要被打開的都是 AT-rich，要很緊密結合的都是 GC-rich**」（AT 只有兩個氫鍵），用理解的、不要硬背。
- **DnaA binding site**：**9 bp 重複 4–5 次**（R1–R5，有些課本畫 4 個、有些畫 5 個）；**R site 不帶 ATP、I site 帶 ATP**（老師：「知道就好，從來沒考過」）。
- **IHF（integration host factor）、FIS** 協助、激發 initiation（IHF 彎曲 DNA）。
- **原核：每條染色體只有一個 oriC；真核：multiple oriC**（人的 DNA 比大腸桿菌大一千倍，多個 origin 同時開、加速合成）→ 國考考過的正確選項。

### Initiation 過程

| 步驟 | 蛋白 | 作用 |
|---|---|---|
| 1 | **DnaA**（帶 ATP） | 辨識並結合 oriC 的 DnaA binding site，抓住 DNA **反向扭轉** → 把 AT-rich 的 **DUE denature**（解成單股）；以 **HTH（helix-turn-helix）** 結合 DNA |
| 2 | **DnaC** | **chaperone（伴隨蛋白）**，像 cargo 把 **DnaB** 送到解開區的兩端（耗 ATP），DnaB 接上後離開 |
| 3 | **DnaB = helicase（去螺旋酶）** | 往兩邊繼續解開雙股 → **bidirectional** |
| 4 | **SSB**（single-stranded DNA-binding protein） | 結合單股 DNA，防止氫鍵重新配對（氫鍵不需要化學反應，靠近就會形成）；吸引 primase |
| 5 | **Primase = DnaG** | **引子合成酶**，合成一小段 **RNA primer** |

- **DnaA、DnaC 屬於 AAA+ ATPase** 家族。
- **HTH（helix-turn-helix）** 是 **DNA-binding motif**：棒狀 helix + 轉彎 + 棒狀 helix，像叉子插進雙股螺旋。蛋白質結合 DNA 的方式：正負電（如 histone）＋三種 motif（後面章節）。
- 國考愛考：**造成 turn 的胺基酸 = glycine、proline**。
- **真核的 SSB 叫 RPA（replication protein A）**——國考考過好幾次。
- 百十三考古：**DNA ligase 不參與 initiation**（DnaB、DnaG、Dam methylase 都需要；ch25-42）。

## 4. Elongation ⭐⭐⭐

### Leading 與 lagging strand

- **Leading strand（領導股）**：合成方向和 fork 前進方向**相同** → **連續合成**。
- **Lagging strand（落後股）**：方向相反 → 一段一段合成 **Okazaki fragment**，最後用 **DNA ligase** 接起來。
- **Okazaki fragment 是一段 DNA**（在 DNA replication 時合成；不是 RNA、不是 transcription；考古多題）。**Klenow fragment 是一段蛋白質**，別搞混。
- 老師講的 Okazaki 故事：他只發現一件事——**複製時有片段 DNA 存在**；leading／lagging 名稱保留至今，但他的兩個推論是錯的：
  1. ✗ leading 比較快、lagging 比較慢 → ✓ **兩股速度一樣**。
  2. ✗ lagging 的聚合酶做完一段會掉下來、再去找下一個 primer → ✓ **聚合酶從頭到尾沒有掉下來**；lagging strand 的模板**繞一圈（loop）**，讓兩股的聚合酶同方向、同速度前進（**trombone model**，Fig 25-12，11/26 詳細講）。

### DNA polymerase 的反應

- **Primer 提供 3'-OH**（primer 雖是 RNA，3' 端仍是 OH）。
- **3'-OH 親核攻擊 dNTP 的 α 磷酸**，β、γ 兩個磷酸以 **PPi** 離開 → 形成 **phosphodiester bond（磷酸二酯鍵）**。老師：「國考已經考到爛掉但還是繼續考」。
- **如何標記新合成的 DNA → 用 [α-³²P]dNTP**（只有 α 磷酸留在 DNA 上；β、γ 隨 PPi 離開）。
- 聚合酶結構像**右手**：palm（催化胺基酸）、fingers（辨識核苷酸）、thumb（結合 DNA），中間 pocket 分 insertion site 與 post-insertion site（百十三共筆）。

### Replication fork 上的蛋白質（Table 25-4，老師：比前一張表「更經典、更重要」）

| 蛋白 | 功能 |
|---|---|
| **SSB** | 結合單股 DNA |
| **DnaB helicase** | **解開雙股螺旋（unwinding）** |
| **Primase（DnaG）** | 合成 **RNA primer**（**DNA-dependent RNA polymerase**） |
| **DNA Pol III** | **在 fork 上合成 leading 與 lagging strand，最重要的複製酵素** |
| **DNA Pol I** | **去除 RNA primer**、補上 DNA（nick translation） |
| **DNA ligase** | 接合 Okazaki fragment（ligation） |
| **DNA gyrase（topoisomerase II）** | **解除超螺旋（supercoil）** |

- **Helicase vs gyrase**（老師特別區分）：fork 往前走時，前方 DNA 被擠壓 → 產生超螺旋 → **gyrase 解除超螺旋**；**helicase 解開的是 fork 上單純的雙股螺旋**。
- **Topoisomerase II**：**同時切斷兩股**、需要 **ATP**（百十三考古 ch25-11：II、IV）；細菌的 **DNA gyrase 會引入負超螺旋**。
- **Lagging strand 上的酵素順序**：**primase → DNA Pol III → DNA Pol I → DNA ligase**（ch25-31）。

## 5. DNA polymerase 的種類（11/26 上課內容，先依 slides 與百十三共筆）⭐⭐⭐

### *E. coli* 的 Pol I、II、III

| | Pol I | Pol II | Pol III |
|---|---|---|---|
| 基因 | *polA* | *polB* | *polC* |
| 每細胞分子數 | **約 400**（要去除很多 primer） | 約 100 | **約 10**（只有一個 oriC，理論上兩個 fork 就夠） |
| 速度（nt/s） | 16–20 | 2–5 | **250–1,000** |
| Processivity | 3–200 | 10,000 | **500,000** |
| **3'→5' exonuclease（校正）** | ＋ | ＋ | ＋（ε subunit／DnaQ） |
| **5'→3' exonuclease（去 primer）** | **＋（只有 Pol I）** | − | − |
| 主要功能 | **去除 RNA primer**、修補 | 修補 | **複製（leading＋lagging）** |

- **3'→5' exonuclease = proofreading**：錯配的核苷酸無法形成氫鍵，聚合酶把 3' 端甩到 exo 位置切掉再回來繼續。
- 錯誤率：校正後 DNA 合成約 **10⁻¹¹**；RNA polymerase 沒有校正，約 10⁻⁹（百十三共筆數字）。
- **Pol III holoenzyme**：多個 subunit；**β subunit = sliding clamp**（增加 processivity；ch25-09）；clamp-loading complex 把 β clamp 裝到 primer 上。
- **Sliding clamp 各物種名稱**：*E. coli* **β clamp**、真核 **PCNA**、噬菌體 gp45（考古 ch25-44：PCNA 類似 β subunit，形成環狀 sliding clamp）。

### Nick translation 與 Klenow fragment

- **Nick**：一條鏈上相鄰核苷酸缺一個磷酸二酯鍵。
- **Pol I 有三個 domain**：polymerase、**5'→3' exonuclease（去除 primer）**、**3'→5' exonuclease（校正）**。Pol I 從 nick 用 5'→3' exo 切掉 RNA primer、同時用 polymerase 補上 DNA → **nick translation**；最後留下的 nick 由 **DNA ligase** 接起來。
- **Klenow fragment**：用蛋白酶切 Pol I，**大片段（約第 324–928 個胺基酸）**保留 **polymerase + 3'→5' exo**，**沒有 5'→3' exo** → 可以校正、不能 nick translation；實驗室可代替 Pol III。小片段有 5'→3' exo。

### DNA ligase

- 機轉：ligase 先從能量分子取得 **AMP（enzyme–AMP）** → 把 AMP 轉到 nick 的 **5'-phosphate** → 3'-OH 攻擊、釋出 AMP → 磷酸二酯鍵。
- 能量來源：***E. coli* 用 NAD⁺**；**T4 噬菌體與人（真核）用 ATP**（百十三共筆勘誤：老師去年上課說人用 NAD⁺，查文獻是 ATP；百十三 W11 共筆的「E. coli 用 NADH」也是錯字，應為 NAD⁺）。

## 6. Termination 與其他 ⭐

- *E. coli* 只有一個 oriC，對面是 **Ter（termination region）**；兩個 fork 在 Ter 相遇，兩個子環狀 DNA 互相套在一起（catenane）→ **topoisomerase IV** 解開。
- 各物種的對應蛋白（slides p.34）：功能差不多、名稱不同；國考考過 **SSB ↔ RPA**。

## 7. 真核生物的 DNA 複製 ⭐⭐

- **Chromatin replication**：fork 接近時 nucleosome 解離，新股上用新舊 histone 重組；完全成熟要到 fork 後方好幾 kb（新 DNA 先接 core histone，再接 H1）。
- **真核 DNA polymerase**（老師常考 α、δ、ε、γ）：
  - **Pol α**：帶 **primase** 活性 → **類似 *E. coli* primase**（考古 ch25-13）。
  - **Pol δ、Pol ε**：主要複製（lagging、leading）。
  - **Pol γ**：**粒線體**（考古 ch25-35：粒線體 DNA 複製與修補）。
  - Pol β：修補。
- **Pre-RC（prereplicative complex）**：**ORC、CDC6、CDT1** 協助把 **MCM2–7 helicase** 裝到 origin（類似 DnaC 幫 DnaB），再加入 CDC45、GINS 後開始複製。
- **為什麼真核需要多個 origin**：真核複製速度慢、基因體又大（ch25-43）。

## 8. 線狀染色體末端：端粒酶 ⭐⭐⭐

- **末端問題**：DNA polymerase 只能 5'→3'、要 primer 的 3'-OH → lagging strand 最末端的 primer 移除後補不回來 → **每次複製 5' 端都變短**。
- **Telomerase**：帶有自己的 **RNA template**（如 AACCCC 配 TTGGGG）＋**反轉錄酶 TERT** → **延長染色體 3' 端**；再由 primase 做 primer，合成互補的 lagging strand。
- **端粒酶活性與癌症、老化**：活性太高 → 癌細胞不會正常老化（immortal，考古 ch25-06）；活性不足 → 老化（Hayflick limit）。老化理論：telomere、free radical。

## 9. 抗病毒藥：acyclovir ⭐

- 疱疹病毒（HSV）的 **viral thymidine kinase** 把 acyclovir 磷酸化（親和力比細胞 TK 高約 200 倍）→ acyclo-GMP → acyclo-GTP → **抑制病毒 DNA polymerase**；acyclovir 沒有完整的五碳糖、**沒有 3'-OH** → 鏈終止。

## 10. PCR ⭐⭐

- **Kary Mullis，1983**；在體外放大極少量 DNA。
- 需要：**模板 DNA、兩段 primer（提供 3'-OH）、dNTP、耐熱 DNA polymerase（Taq）**。
- 循環：**變性（denaturation，約 94 °C）→ 黏合（annealing，約 55 °C）→ 延長（extension，約 72 °C）**；每循環產物加倍，**2ⁿ 指數放大**。
- 百十三共筆補充：**RT-PCR**（RNA 先反轉錄成 cDNA）；**real-time PCR（qPCR）**：SYBR Green I（結合雙股 DNA，非專一）、TaqMan probe（專一）。

## 11. DNA 修復（*E. coli* 四種，Table 25-5）⭐⭐⭐

| 修復 | 辨識／重要酵素 | 特點 |
|---|---|---|
| **Mismatch repair** | **MutS、MutL、MutH**；靠 **GATC 甲基化**分辨新舊股 | 新股剛合成時還沒甲基化 → 切新股；**DNA Pol III** 補、ligase 接；真核同源蛋白 **MSH、MLH** |
| **Base-excision repair** | **DNA glycosylase** 切掉鹼基 → **AP site**（abasic）→ AP endonuclease 切磷酸二酯鍵 | 只去**鹼基**；Pol I 補、ligase 接 |
| **Nucleotide-excision repair** | **ABC excinuclease = UvrA、UvrB、UvrC**（UvrA 是 ATPase） | 切掉一段寡核苷酸（原核 12–13 nt、真核 27–29 nt）；Pol I 補、ligase 接 |
| **Direct repair** | **Photolyase**（cofactor **FADH⁻、folate**）修 UV 造成的 **cyclobutane pyrimidine dimer** | **人類沒有 photolyase**；**不需要 ligase** |

- Mismatch repair 細節：GATC 平均每 256 bp 一個；新合成 DNA 幾分鐘內就被甲基化，所以要在這之前修；MutS–MutL 結合錯配，MutH 在未甲基化的 GATC 切口，exonuclease 切到錯配處，**SSB** 保護單股。
- 常見題：**哪種修復有 Pol III 參與 → mismatch repair**；**哪種不需要 ligase → direct repair**；**DNA glycosylase 不參與 methyl-directed mismatch repair**（屬於 base-excision；國考）。

## 12. DNA 重組 ⭐

- 同源重組也是一種修復（例如複製叉遇到 nick 而斷裂）。
- 中間產物 **Holliday intermediate（X 形 crossover）**；**RuvC** 切開（resolution），**DNA ligase** 接合。

## 🎙️ 上課錄影重點（施純明，11/19：slides p.1–17）

- 大綱：initiation、elongation、termination「不管是 DNA 複製、RNA 轉錄或蛋白質轉譯，都是這三個過程」；**DNA repair 國考常考**，但 repair 和 recombination「比較偏向記憶的部分，這是免不了的」。
- DNA 結構雖然耳熟能詳，「國考還是照樣考」：ATGC 互補、雙股螺旋、反向平行（兩股 5'、3' 剛好相對）。
- 電顯照片：環狀 DNA 從一點往兩個方向複製，最後變成兩個環；一個藍一個橘 → **半保留**。
- **Kornberg 的「美麗錯誤」**：他發現 Pol I 拿到 1959 年諾貝爾獎，但真正在複製的是 **Pol III**，「錢有沒有要回來？沒有」，因為兩者結構作用大同小異。（順帶提到 Watson 最近過世。）
- **Mg²⁺**：D705、D882（aspartic acid）和二價金屬離子形成 active site pocket；「DNA 聚合酶、RNA 聚合酶都需要鎂離子當 cofactor」，綜合維他命裡加微量鎂就是這個原因，叫 **trace element**。
- **3 步驟 5 特性**快速念過；**primer 是一段短的 RNA，不是 DNA**，「這是非常重要的」。
- **oriC**：C 是 chromosome；*E. coli* **245 bp、11 個 GATC**，A 被 **Dam methylase** 甲基化；**DUE：13 bp 重複三次、AT-rich**。「只要要被打開的都是 AT-rich，要緊密結合的都是 GC-rich」——兩年後國考時你們會把 AT、GC 搞混，要用理解的。DnaA binding site 9 bp 重複（R1–R5）；**R site 沒 ATP、I site 有 ATP「知道就好，從來沒考過」**。oriC 三個特性：AT-rich、DUE 會被解開、11 個 GATC 被甲基化。
- **Initiation 過程**：DnaA 結合後**反向扭轉**（像抓住辮子反向扭），把 DUE **denature** 成單股 → **DnaC（chaperone，像 cargo／shuttle）帶 DnaB 到兩端**（沒有 DnaC，DnaB 不會自己跑去）→ **DnaB helicase（去螺旋酶）**往左右繼續打開 → **bidirectional**。
- **HTH（helix-turn-helix）**：DnaA 結合 DNA 的 DNA-binding motif，像叉子插進雙股；蛋白質結合 DNA 除了正負電，還有三種 motif（後面講）。現場問答：**造成 turn 的胺基酸 → glycine、proline**（答對的同學「待會來找我登記」）；考試會問「下列哪個胺基酸不會造成 turn」。
- 重要蛋白（Table 25-3）：DnaA、DnaB、DnaC、**primase（DnaG）**、**SSB**、DNA gyrase。**SSB** 很重要：剛打開的單股如果不保護，氫鍵不需要化學反應、靠近就會再配回去。**Primase = 引子合成酶，產物是一小段 RNA**；DnaG、DnaB、DnaC 分別是什麼都要知道。
- **原核一個 oriC、真核 multiple oriC**（人的 DNA 比大腸桿菌大一千倍）→ 國考考過的正確選項。
- **Elongation**：leading strand 連續；lagging strand 一段一段 = **Okazaki fragment**，都遵守 5'→3' → **semidiscontinuous，不連續的是 lagging strand**。
- **聚合反應**：primer 提供 **3'-OH**，攻擊 dNTP 的 **α 磷酸**，β、γ 以 PPi 離開 → **phosphodiester bond**，「國考已經考到爛掉但還是繼續考」。**標記 DNA 用 α-³²P dATP**（現場問 α、β、γ 哪個）；「primer 在做什麼？提供 OH」也考過。
- **Gyrase vs helicase**：gyrase（topoisomerase）解除 fork 前方被擠壓的**超螺旋**；helicase 解開 fork 上**單純的雙股螺旋**，「這兩個功能不一樣」。
- **Okazaki 的故事**：他只發現「有片段 DNA 存在」；他說 leading 快、lagging 慢 → **錯，速度一樣**；他說聚合酶做完一段會掉下來再找下一個 primer → **錯，聚合酶從頭到尾沒有掉下來**，DNA 會**繞一圈**。名詞 leading／lagging 沿用至今。
- **真核的 SSB 叫 RPA（replication protein A）**，「國考考過好幾次」。
- **Table 25-4「更經典、更重要」**：SSB 結合單股、DnaB helicase 解旋、primase 合成 RNA primer、**Pol III 在 fork 上複製（最重要）**、**Pol I 去除 primer**（Kornberg 發現的是這個）、**ligase 接 Okazaki fragment**、gyrase 處理 supercoil。「Pol III 跟 Pol I 請同學不要搞混」。

# 考點分析

## 🔥 高頻考點（百十三考古 Ch25 38 題）

1. **Okazaki fragment**：DNA replication 時在 **lagging strand** 合成的**短 DNA 片段**（5 題換句話；不是 RNA、不是 transcription）。
2. **Pol I vs Pol III**：Pol III 是主要複製酶（leading＋lagging）、β subunit 是 sliding clamp；**Pol I 的 5'→3' exo 去除 RNA primer**、可被 Klenow 切；**3'→5' exo = proofreading**（Pol I、II、III 都有）。
3. **Primase = DNA-dependent RNA polymerase**，合成 RNA primer；真核類比是 **Pol α**。
4. **Helicase 解開雙股；topoisomerase II 同時切兩股、需要 ATP**。
5. **Lagging strand 酵素順序**：primase → Pol III → Pol I → ligase。
6. **Leading／lagging 特性題組**：需要多個 primer、Okazaki fragment、需要 ligase → lagging。
7. **Bidirectional = 兩個 replication fork**；Meselson–Stahl 證明半保留。
8. **Telomerase** 延長染色體 3' 端；癌細胞不老化和端粒酶有關。
9. **真核 Pol γ 在粒線體**；**PCNA 類似 β clamp**；真核需要多個 origin。
10. **Initiation 不需要 DNA ligase**（DnaB、DnaG、Dam methylase 都需要）。
11. 國考（slides 標註）：Mg²⁺ cofactor、**phosphodiester bond**、**α-³²P 標記**、primer 提供 3'-OH、真核 multiple oriC、**RPA**、nick translation／Klenow。
12. 修復：**Pol III 參與 mismatch repair**、**direct repair 不需要 ligase**、**DNA glycosylase 屬 base-excision**、人沒有 photolyase。

## 📝 出題模式

- 百十三考古多為英文單選；**題組**（三種 polymerase 各問一個功能、leading vs lagging 二選一）很多。
- 同一題常出好幾次（Okazaki fragment、Pol I 5'→3' exo、replication fork 敘述），選項順序或答案位置不同，要看懂敘述而不是背字母。
- slides 上的「國考題 see Zuvio」是老師在 Zuvio 出的國考題，集中在 p.4、6、12、15、16、27、47。

## 🎙️ 老師課堂提示

- **AT-rich 才會被打開、GC-rich 結合緊密**：用理解的，不要背。
- **Primer 是 RNA**、提供 3'-OH；**α-³²P** 標記；**磷酸二酯鍵**「考到爛掉還是繼續考」。
- **Pol III 負責複製、Pol I 去除 primer**，不要搞混；**DnaA／DnaB／DnaC／DnaG** 各是什麼要知道。
- **Glycine、proline 造成 turn**；**真核 SSB = RPA**；**真核 multiple oriC**。
- R site／I site 和 ATP 的關係「從來沒考過」。
- Repair、recombination 偏記憶但國考常考（11/26 講）。

## ⚠️ 陷阱整理

| ✗ 錯誤說法 | ✓ 正確 |
|---|---|
| Kornberg 發現的 Pol I 是主要複製酶 | 主要複製酶是 **Pol III**；Pol I 去除 primer |
| Primer 是一小段 DNA | **RNA**（primase 合成） |
| Leading strand 比 lagging strand 快 | **兩股速度一樣**（trombone model） |
| Lagging 的 Pol III 做完一段就掉下來 | **不會掉下來**，模板繞一圈 |
| Helicase 解除超螺旋 | Helicase 解開**雙股**；解除**超螺旋**是 topoisomerase／gyrase |
| Okazaki fragment 是 RNA 片段 | 是 **DNA** 片段（開頭有 RNA primer） |
| 3'→5' exonuclease 用來去除 primer | 3'→5' exo 是**校正**；去 primer 是 Pol I 的 **5'→3' exo** |
| 用 γ-³²P dNTP 標記新 DNA | **α-³²P**（β、γ 隨 PPi 離開） |
| Bidirectional 表示有兩個 origin | 一個 origin、**兩個 replication fork** |
| Klenow fragment 能做 nick translation | Klenow **沒有 5'→3' exo**，不能 nick translation |
| 人有 photolyase 可以 direct repair | **人沒有 photolyase** |
