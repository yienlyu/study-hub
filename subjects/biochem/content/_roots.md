## 酵素名字尾：看名字就知道做什麼
@ch ch17,ch21,ch18,ch22
| 字根 | 意思 | 本科例字 |
|---|---|---|
| **-ase** | 酵素 | lipase、arginase、glutaminase |
| kinase | 用 ATP **加上磷酸** | hexokinase、PKA、tyrosine kinase |
| phosphatase | **拿掉磷酸**（水解） | glucose-6-phosphatase、phosphoprotein phosphatase |
| phosphorylase | 用無機磷酸**切斷**鍵（phosphorolysis） | glycogen phosphorylase、purine nucleoside phosphorylase |
| synthase | 合成，**不直接用** ATP | fatty acid synthase、citrate synthase、NO synthase |
| synthetase | 合成，**要水解 ATP／NTP** | carbamoyl phosphate synthetase I、glutamine synthetase |
| carboxylase | 加上 **CO₂**（多半要 biotin） | acetyl-CoA carboxylase、pyruvate carboxylase、propionyl-CoA carboxylase |
| decarboxylase | 拿掉 CO₂（多半要 PLP） | DOPA decarboxylase、ornithine decarboxylase |
| dehydrogenase | 拿走氫，交給 NAD⁺／FAD | acyl-CoA dehydrogenase、glutamate dehydrogenase |
| reductase | 還原（加電子，常用 NADPH） | HMG-CoA reductase、ribonucleotide reductase、DHFR |
| oxidase／oxygenase | 用 O₂ 氧化／把 O 原子加進受質 | xanthine oxidase、homogentisate 1,2-dioxygenase |
| hydroxylase | 加上 –OH | phenylalanine hydroxylase、tyrosine hydroxylase |
| transferase | **轉移**一個基團 | aminotransferase、carnitine acyltransferase、UDP-glucuronyltransferase |
| mutase | 同一分子內**搬位置** | methylmalonyl-CoA mutase（要 B₁₂） |
| lyase | 不靠水解把鍵切開 | HMG-CoA lyase、argininosuccinate lyase |
| deaminase | 拿掉胺基 | adenosine deaminase（缺乏 → SCID） |

- 考古常考 **synthase vs synthetase**：CPS I（尿素循環）是 synthetase，要 2 ATP。

## 代謝路徑：-lysis 分解、-genesis 生成
@ch ch17,ch21,ch23
| 字根 | 意思 | 本科例字 |
|---|---|---|
| glyco-／gluco- | 醣／葡萄糖 | glycolysis、glycogen、glucagon |
| **-lysis** | 分解、切開 | glycolysis、lipolysis、proteolysis |
| **-genesis** | 生成 | gluconeogenesis、ketogenesis、lipogenesis |
| neo- | 新的 | gluconeogenesis（從非醣「新」造出葡萄糖） |
| -gen | 產生…的東西、前驅物 | glycogen、zymogen、pepsinogen |
| ana-／cata- | 往上（合成）／往下（分解） | anabolism、catabolism |
| lipo- | 脂質 | lipoprotein、lipase、lipogenesis |
| chylo- | 乳糜 | chylomicron |
| keto- | 酮基（C=O） | ketone bodies、ketogenic、α-ketoglutarate |
| acyl- | 醯基（R–CO–） | acyl-CoA、diacylglycerol |
| acet-（2C）／malonyl-（3C） | 醋酸二碳／丙二醯三碳 | acetyl-CoA、acetoacetate、malonyl-CoA |
| oxalo- | 草醯 | oxaloacetate |

## 化學結構的前後綴
@ch ch18,ch22
| 字根 | 意思 | 本科例字 |
|---|---|---|
| -ate／-ic acid | 酸根（體內解離態）／酸 | pyruvate、lactate、glutamate、uric acid |
| -ose／-ol | 醣／醇 | glucose、ribose；glycerol、cholesterol |
| -yl | 基團 | methyl、propionyl、succinyl |
| de- | 去除 | deamination、decarboxylation、dephosphorylation |
| trans- | 轉移、跨越 | transamination、transporter |
| hydroxy-／amino-／methyl- | –OH／–NH₂／–CH₃ | 3-hydroxybutyrate、aminotransferase、S-adenosylmethionine（SAM） |
| carbamoyl- | H₂N–CO– | carbamoyl phosphate |
| homo- | 多一個 CH₂ | homocysteine、homogentisate |
| di-／tri- | 二／三 | diacylglycerol、triacylglycerol |
| dihydro-／tetrahydro- | 加 2／4 個 H（還原態） | dihydrofolate、tetrahydrofolate（THF）、tetrahydrobiopterin（BH₄） |
| pyro- | 兩個磷酸連在一起 | pyrophosphate（PPi）、thiamine pyrophosphate（TPP） |
| cyclo-／cyclic | 環狀 | cAMP、adenylyl cyclase、guanylyl cyclase |

## 激素與訊息傳遞
@ch ch12,ch23
| 字根 | 意思 | 本科例字 |
|---|---|---|
| -crine | 分泌 | endocrine、paracrine、autocrine |
| insul- | 島 | insulin（胰「島」β 細胞） |
| gluc- + -agon | 醣 + 帶動 | glucagon（把血糖帶上來） |
| adipo- | 脂肪組織 | adiponectin |
| lept- | 瘦 | leptin（讓人變瘦、抑制食慾） |
| ghrel- | growth hormone release | ghrelin（胃分泌、增加食慾） |
| epi-／ad- + nephr-／ren- | 在上面 + 腎 | epinephrine = adrenaline（腎上腺素） |
| nor- | 少一個甲基 | norepinephrine |
| agon-／antagon- | 作用劑／拮抗劑 | β-adrenergic agonist |
| -tonin | 張力、調節 | serotonin（sero 血清）、melatonin（melan 黑） |

## 疾病與檢驗名
@ch ch18,ch22
| 字根 | 意思 | 本科例字 |
|---|---|---|
| hyper-／hypo- | 過多／過少 | hyperammonemia、hypoglycemia |
| **-emia** | 血中 | hyperammonemia、homocysteinemia |
| **-uria** | 尿中出現 | phenylketonuria（PKU）、alkaptonuria、homocystinuria |
| -osis | 狀態、病症 | ketosis、acidosis |
| -ism | 狀態 | albinism（albus 白） |
| xanth- | 黃 | xanthine、hypoxanthine（allopurinol 抑制 xanthine oxidase） |
| bili- + rubin／verdin | 膽 + 紅／綠 | bilirubin、biliverdin |
| porphyr- | 紫 | porphyrin、porphyria |
| melan- | 黑 | melanin（tyrosinase 缺乏 → albinism） |
| anti-／-metabolite | 對抗／代謝物 | antimetabolite：methotrexate、5-FU |
