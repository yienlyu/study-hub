# 脂肪酸分解代謝（黃彥華）

> Take home message 三段：① 脂肪的消化、動員與運輸 ② 脂肪酸氧化 ③ 酮體。脂肪酸氧化提供心臟、肝臟等組織 **>80%** 的能量需求。

## 1. 脂肪酸的三個來源 ⭐⭐

| 來源 | 運輸形式 | 關鍵分子 |
|---|---|---|
| ① **飲食**（小腸吸收） | **Chylomicron**（經淋巴 → 血液） | 膽鹽乳化、**ApoC-II 活化 LPL** |
| ② **肝臟自己合成**（de novo） | **VLDL** → IDL → LDL | ApoB-100 |
| ③ **脂肪組織儲存** | 游離脂肪酸（FFA）+ **serum albumin** | Epinephrine / glucagon → cAMP → PKA → HSL |

- 共同難題：脂質**不溶於水** → 消化要靠**膽鹽**乳化、運輸要靠**脂蛋白**或 **albumin**。
- Acetyl-CoA 的三條去路：① 進 **TCA cycle** ② 在**肝臟**變成**酮體**（水溶性燃料，給腦和其他組織）③ 在**細胞質**合成脂肪酸。

## 2. 消化與吸收
- **膽鹽（bile salts）**：膽固醇衍生、肝臟製造、膽囊儲存；bile acid 與 **glycine 或 taurine** 以 amide 鍵結合 → **glycocholate、taurocholate**。兩性分子（一面親水、一面疏水）→ 形成 **micelle**。
- 小腸 lipase 把 TG 分解 → 腸細胞吸收後**重新合成 TG** → 與膽固醇、apolipoprotein 包成 **chylomicron** → **淋巴管** → 血液。
- 微血管內皮上的 **lipoprotein lipase（LPL）**（以多醣鏈錨在內皮細胞表面）被 chylomicron 上的 **ApoC-II 活化** → 水解 TG 成 **glycerol + FFA** → 肌肉氧化、脂肪細胞再酯化儲存。

## 3. 脂蛋白 ⭐⭐

| | Chylomicron | VLDL | IDL | LDL | HDL |
|---|---|---|---|---|---|
| 密度 | **最低**（<0.95） | 0.95–1.006 | 1.006–1.019 | 1.019–1.063 | **最高**（1.063–1.210） |
| TG % | **最多（~85%）** | ~50% | | ~10% | ~4%（蛋白質最多） |
| 主要 apo | **B-48**、C-II、E | B-100、C、E | B-100、E | **B-100** | **A-I**、C、E |
| 角色 | 運送**飲食** TG | 運送**肝臟合成**的 TG | | 送膽固醇到周邊（**bad**） | 把膽固醇送回肝（**good**） |

- **密度與 TG 含量成反比**：TG 越多、越輕。脂蛋白結構：中心是中性脂質（TG、cholesteryl ester），表面是 phospholipid、膽固醇和 apolipoprotein。

| Apolipoprotein | 功能 |
|---|---|
| **A-I** | HDL 主要蛋白，**活化 LCAT** |
| **B-48** | **只在 chylomicron** |
| **B-100** | LDL 主要蛋白，**與 LDL receptor 結合** |
| **C-II** | **活化 LPL**（chylomicron、VLDL） |
| C-III | 抑制 LPL |
| E | 殘體（remnant）被肝臟清除 |

## 4. LDL 與膽固醇恆定 ⭐⭐
- LDL 進入細胞的順序：**ApoB-100 與 LDL receptor 結合 → clathrin coated pit → receptor-mediated endocytosis → endosome → lysosome** 分解出膽固醇與胺基酸；受體回收到細胞膜。
- 細胞內膽固醇過多時的**三種自我調節**：
  1. **降低 LDL receptor 數量**
  2. **抑制 HMG-CoA reductase**（膽固醇合成的限速酶，在**細胞質**／ER）
  3. **酯化儲存**：細胞內用 **ACAT**（acyl-CoA:cholesterol acyltransferase）；血漿中用 **LCAT**（lecithin:cholesterol acyltransferase，肝分泌、附在 HDL／LDL 上）。Cholesteryl ester 比膽固醇更疏水。
- **動脈硬化**：LDL 被**氧化** → 巨噬細胞以 **scavenger receptor** 吞入氧化 LDL → **泡沫細胞（foam cell）** → 斑塊。（不是內皮細胞變泡沫細胞）
- **家族性高膽固醇血症（FH）**：**LDL receptor 基因突變** → 血中 LDL 清不掉；黃色瘤，台灣約 8 萬人、近半未被篩出，40 歲 2 成、60 歲 8 成 5 有冠心病。

## 5. 脂肪組織的動員 ⭐
- **Epinephrine、glucagon** →（GPCR）→ adenylyl cyclase → **cAMP ↑** → **PKA** 磷酸化 **perilipin** 與 **hormone-sensitive lipase（HSL）**。
- 三個 lipase 依序：**ATGL**（TG → DAG）→ **HSL**（DAG → MAG）→ **MGL**（MAG → glycerol）。
- FFA 進血液後**與 serum albumin 結合**運送（不是 hemoglobin，也不是自由溶解），再經細胞膜 fatty acid transporter 進入肌肉、心臟。
- **Glycerol** 送到肝臟：**glycerol kinase**（脂肪細胞沒有）→ glycerol-3-phosphate →（glycerol-3-P dehydrogenase）→ **DHAP** → 糖解或糖質新生。

## 6. 活化與 carnitine shuttle ⭐⭐
- **活化（細胞質／粒線體外膜）**：fatty acid + CoA + ATP →（**acyl-CoA synthetase**）→ fatty acyl-CoA + **AMP + PPi**；PPi 再水解成 2 Pi → **耗 1 ATP，但等於 2 個高能鍵（算 2 ATP）**。
- Fatty acyl-CoA **不能**直接穿過粒線體內膜，要靠 carnitine：
  1. **CPT I（carnitine acyltransferase I，外膜）**：acyl-CoA → **acyl-carnitine** ← **限速、調控點，被 malonyl-CoA 抑制**
  2. **Acyl-carnitine/carnitine translocase（內膜）**：把 acyl-carnitine 送進基質、carnitine 送出
  3. **CPT II（內膜基質側）**：acyl-carnitine → acyl-CoA，carnitine 回收
- 能穿過粒線體內膜的少數分子：**fatty acyl-carnitine**、malate、citrate、pyruvate（acetyl-CoA、acyl-CoA、malonyl-CoA 都不行）。

## 7. β-oxidation ⭐⭐⭐
- 歷史：**Knoop**（以苯環標記 → 一次切 **2 個碳**）、Lehninger（在**粒線體**）、Lynen（ATP 依賴的活化、與 CoA 形成 **thioester**）。
- 四步驟（**順序必背**）：**去氫（FAD）→ 水合（H₂O）→ 去氫（NAD⁺）→ 硫解（CoA）**

| 步驟 | 酵素 | 產物 |
|---|---|---|
| ① 去氫 | acyl-CoA dehydrogenase | **trans-Δ²-enoyl-CoA** + **FADH₂** |
| ② 水合 | enoyl-CoA hydratase | **L-β-hydroxyacyl-CoA**（加 H₂O） |
| ③ 去氫 | β-hydroxyacyl-CoA dehydrogenase | β-ketoacyl-CoA + **NADH** |
| ④ 硫解 | **thiolase**（加 CoA-SH） | **acetyl-CoA** + 少兩個碳的 acyl-CoA |

<div data-fig="beta-oxidation"></div>

### ATP 計算（必考）
- 1 FADH₂ = **1.5** ATP、1 NADH = **2.5** ATP、1 acetyl-CoA 經 TCA = **10** ATP（3 NADH + 1 FADH₂ + 1 GTP）。
- **每一輪 β-oxidation（不含 acetyl-CoA）= 1 FADH₂ + 1 NADH = 4 ATP**。
- 偶數 n 碳：循環 **n/2 − 1** 次、acetyl-CoA **n/2** 個、消耗 H₂O **n/2 − 1** 個、活化 **−2**。

| 脂肪酸 | 循環 | Acetyl-CoA | FADH₂ / NADH | 淨 ATP |
|---|---|---|---|---|
| **Palmitate（16:0）** | **7** | **8** | **7 / 7** | 80 + 10.5 + 17.5 − 2 = **106** |
| Laurate（12:0） | 5 | 6 | 5 / 5 | 60 + 20 − 2 = 78 |
| Arachidate（20:0） | 9 | 10 | 9 / 9 | 100 + 36 − 2 = 134 |

## 8. 奇數碳脂肪酸 ⭐⭐
- 最後一輪剩下 **propionyl-CoA（3C）**：
  **propionyl-CoA →（propionyl-CoA carboxylase，biotin、ATP、HCO₃⁻）→ D-methylmalonyl-CoA →（epimerase）→ L-methylmalonyl-CoA →（methylmalonyl-CoA mutase，coenzyme B₁₂）→ succinyl-CoA → TCA**
- B₁₂ 缺乏 → methylmalonyl-CoA 堆積（methylmalonic acidemia）。B₁₂ 也是 methionine synthase（homocysteine → methionine）的輔酶。
- 碳的去向：β-oxidation 從**羧基端**一次切兩個碳，**ω 端（甲基端）的 3 個碳最後成為 propionyl-CoA**（所以 ¹⁴CH₃(CH₂)₉COOH 的標記會出現在 propionyl-CoA）。

## 9. 合成與分解的協調調控
- **Malonyl-CoA**（脂肪酸合成的第一個產物）**抑制 CPT I** → 合成時不會同時把脂肪酸送進粒線體燒掉。
- 高血糖 → insulin → ACC 去磷酸化（活化）→ malonyl-CoA ↑ → 脂肪酸合成 ↑、β-oxidation ↓。
- 低血糖 → glucagon → PKA 磷酸化 ACC（失活）→ malonyl-CoA ↓ → CPT I 解除抑制 → β-oxidation ↑。

## 10. Peroxisome 的 β-oxidation
- 第一步的 FADH₂ 直接把電子交給 O₂ → **H₂O₂**（由 catalase 分解），**不產生 ATP**；處理**極長鏈脂肪酸**，切短後送粒線體。
- **Zellweger syndrome**：無法製造 peroxisome。**X-linked adrenoleukodystrophy（XALD）**：peroxisome 膜上的極長鏈脂肪酸轉運蛋白缺陷 → 無法氧化。

## 11. 酮體 ⭐⭐⭐
- 三種：**acetoacetate、D-β-hydroxybutyrate、acetone**（acetone 不能產能，由呼吸排出）。
- 場所：**肝細胞的粒線體基質**（主要是肝臟，不是腎、腸或肌肉）。
- 合成：2 acetyl-CoA →（thiolase）→ acetoacetyl-CoA →（**HMG-CoA synthase**，+acetyl-CoA）→ **HMG-CoA** →（**HMG-CoA lyase**）→ **acetoacetate** →（β-hydroxybutyrate dehydrogenase，**消耗 NADH**）→ **β-hydroxybutyrate**；acetoacetate 自發脫羧 → acetone。
- ⚠️ HMG-CoA synthase / lyase 在**粒線體**做酮體；**HMG-CoA reductase** 在**細胞質（ER）**做膽固醇。
- 運輸：以 **β-hydroxybutyrate** 為主（血中最多），其次 acetoacetate。
- 利用：肝外組織（心、骨骼肌、腎、飢餓時的腦）把 β-hydroxybutyrate → acetoacetate →（**succinyl-CoA:acetoacetate CoA transferase**，**肝臟沒有** → 肝自己不能用酮體）→ acetoacetyl-CoA → 2 acetyl-CoA → TCA。
- **何時大量產生**：**飢餓、未治療的糖尿病** → 糖質新生把 TCA 中間物（**oxaloacetate**）抽走 → acetyl-CoA 無法進 TCA → 轉成酮體。
  - **Ketosis**：血中可達 90 mg/100 mL、尿中 5,000 mg/24 hr
  - **Acidosis**：acetoacetate、β-hydroxybutyrate 降低血液 pH
  - 兩者合併 = **ketoacidosis**

## 🎙️ 上課錄影重點（黃彥華，09/10 + 09/17）
- 本章架構三段：① 消化、動員與運送 ② β-oxidation（四步驟 + ATP 計算）③ 酮體。老師反覆標「**兩分題**」：β-oxidation 兩分、酮體兩分、膽鹽、albumin、chylomicron、LDL / HDL、LDL receptor、FH、HMG-CoA reductase、膽固醇恆定三招、CPT I。
- **鳥瞰圖**：醣類、蛋白質、脂質代謝都匯集到 **acetyl-CoA**；能量多時 acetyl-CoA 送回細胞質合成脂肪酸（Ch21）。建議「口袋裡放一張代謝圖」，吃早餐、午餐時把醣、脂肪、蛋白質代謝各走一遍。
- **膽鹽（bile salt）= 雙面人**：類似膽固醇骨架，OH 都排在同一側 → hydrophilic face + hydrophobic face；一手抓 TG、一手把 **pancreatic lipase** 拉近 → 解決 TG 與酵素「水火不容」（insolubility）。國考考法：給 **glycocholate、taurocholate**，要認出是膽鹽。
- **Free fatty acid 在血液中一定由 serum albumin 攜帶**（老師講了「第五次」）：COOH 的 pKa 約 5，在 pH 7 血中會解離 → 酸化 → 血紅素帶氧↓；一個 albumin 約可帶 **7–10** 個 FFA。
- **三大來源**（記住這張總圖）：飲食 → **chylomicron**（TG 86%）；肝臟 de novo → **VLDL**（TG ~50%）；脂肪細胞儲存 → 需**荷爾蒙**（epinephrine、glucagon）才能動員（「減肥特別難」）。
- **記 chylomicron 就像記女朋友**：記名字、喜歡什麼、走什麼路（**血管與淋巴管**）、怎麼被活化與代謝。腸道 mucosa 把 FFA 重新組成 TG，並加上 **ApoC-II** → 在微血管活化 **lipoprotein lipase（LPL）**。
- 脂蛋白依**密度**分類（離心區分）：蛋白質比例越高密度越高（雞湯浮在上面的是油）。**攜帶 TG：chylomicron、VLDL；攜帶膽固醇：LDL（~50%）、HDL（~25%）**。
- **LDL = bad**：肝 → 周邊；發炎 / 氧化的 LDL 被 macrophage 吞到撐爆 → 癱在血管內壁 → 鄰近細胞增生把它蓋起來 = **foam cell** → 粥狀動脈硬化。**HDL = good**：周邊 → 肝的清道夫，也提供內分泌腺合成類固醇荷爾蒙的原料。
- Apolipoprotein 只要記三個：**ApoC-II**（活化 LPL）、**ApoA-I**（HDL，活化 **LCAT**）、**ApoB-100**（LDL 被受體辨識）。
- **LDL receptor 內吞（Fig 17-x，10 步驟）**：rough ER 合成 → Golgi → 膜上 clathrin coated pit → endocytosis → endosome（pH ~6，受體與 LDL 分離、受體回收）→ lysosome（pH ~5）水解 → 釋出膽固醇；酯化膽固醇聚成 droplet。
- **細胞內膽固醇恆定三招（兩分題，「不會就自動讓分」）**：① **↓LDL receptor 合成**（外面不要再吃進來）② **↓HMG-CoA reductase**（自己也不要做）③ **↑ACAT（或 LCAT）**把 free 膽固醇酯化成 droplet（像把台北街頭的暴龍引去動物園）。⚠️ 選項裡會同時出現 **HMG-CoA reductase / synthase / lyase**：後兩者是**酮體合成**的酵素。
- **家族性高膽固醇血症（FH）**：LDL receptor 突變 → 細胞吃不到 LDL → 自己拼命做（HMG-CoA reductase↑）→ 血中 LDL 很高 → 黃色瘤、早發冠心病。台灣約 8 萬人；40 歲 2 成、50 歲 6 成、60 歲 8.5 成罹冠狀動脈疾病。「看到黃色瘤就要把整個家族找來檢查」。
- **脂肪動員**：epinephrine / glucagon → Gs → adenylyl cyclase → **cAMP（二級訊息）→ PKA（富爸爸）** → 磷酸化 **perilipin**（從躺著變站起來、放開 **CGI-58** → 活化 **ATGL**）與 **HSL** → ATGL（TG → DAG）→ HSL（DAG → MAG）→ **MGL**（→ glycerol）。看到 epinephrine / glucagon 先賭「促進代謝」，看到 insulin 先賭「促進合成」。六個二級訊息：**cAMP、cGMP、IP₃、DAG、Ca²⁺、NO**（Ch12）。
- Glycerol 回肝 → glyceraldehyde 3-phosphate → 糖解 / 糖質新生（中間步驟不用背）。
- **進粒線體**：FFA 在細胞質（「福隆外海」）要送到粒線體基質（「城中區土地銀行」）才能「印鈔票」。活化：ATP → **AMP + PPi**（PPi → 2 Pi）= **相當消耗 2 ATP** → fatty acyl-CoA；外膜 **CPT I** 換成 fatty acyl-carnitine（「睡衣趴要穿對衣服」）→ 進內膜 → **CPT II** 換回 CoA。為什麼要換兩次？多層次管控，防止異常的 acyl-CoA 進入粒線體。**調控 β-oxidation 的關鍵 = CPT I**（合成第一個產物 **malonyl-CoA** 一出現就抑制它）。
- **β-oxidation 四步驟**：① acyl-CoA dehydrogenase（α、β 去氫 → **FADH₂**，生成 enoyl-CoA）② hydratase（加水，β 位置接 OH）③ dehydrogenase（**NADH**，β-ketoacyl-CoA）④ thiolase（CoA-SH 親核攻擊 → 釋出 **acetyl-CoA**）。Knoop 用帶苯環的脂肪酸餵狗：偶數碳 → phenylacetic acid、奇數碳 → benzoic acid → 證明「兩個碳一切」。
- **ATP 計算（全天下都會的兩分題）**：palmitoyl-CoA（16 碳）→ **7 輪、8 acetyl-CoA**；7 FADH₂ × 1.5 + 7 NADH × 2.5 = 28；8 × 10（每個 TCA = 1 FADH₂ + 3 NADH + 1 GTP）= 80 → **108**；從 palmitate 開始要再扣活化的 2 → **106**。⚠️ 選項一定同時有 106 與 108，看清楚從哪裡開始問。
- **奇數碳（進階題，如 17 碳）**：最後剩 **propionyl-CoA（3 碳）** → 要加一個碳（**HCO₃⁻** + ATP + **propionyl-CoA carboxylase**，cofactor **biotin**）→ D-methylmalonyl-CoA → **epimerase** → L 型 → **methylmalonyl-CoA mutase（coenzyme B₁₂，互換相鄰碳上的 H 與取代基）** → **succinyl-CoA** 進 TCA。老師比喻：PGY1（carboxylase）接錯位置 → 找 R（epimerase）→ 再找老師（B₁₂）。
- **合成與分解協調（三顆星）**：低血糖 → glucagon → PKA、**AMPK** 磷酸化 **ACC → 失活**；吃飽 → insulin → **phosphatase 去磷酸 → ACC 活化**（⚠️ ACC 是「**去磷酸化才活化**」的例外）→ malonyl-CoA ↑ → 抑制 CPT I、在**細胞質**合成脂肪酸（需 NADPH）。
- **Peroxisome**：也做長鏈 β-oxidation，但目的不是 ATP（產生 H₂O₂、熱）。疾病：**Zellweger syndrome**（活不過一歲）、**X-ALD**（very long chain FA 堆積）。
- **酮體**：前提是 TCA 中間產物被用光（**極度飢餓、糖尿病**）→ acetyl-CoA 進不了 TCA → 在**肝臟粒線體**合成短鏈能量分子供腦、心等。成分：**acetone、acetoacetate、β-hydroxybutyrate**（口氣有 acetone 味；COOH → **acidosis**；ketone → **ketosis**；兩者 = **ketoacidosis**）。路徑：2 acetyl-CoA → acetoacetyl-CoA →（+ acetyl-CoA，**HMG-CoA synthase，粒線體**）→ HMG-CoA →（**HMG-CoA lyase**）→ acetoacetate；β-hydroxybutyrate 需 NADH。肝臟輸出酮體到心、骨骼肌、腎、腦。

# 考點分析

## 🔥 高頻考點（113 共筆考古 Ch17-1、17-2）
1. **Free fatty acid 在血中與 serum albumin 結合**（同一題考 3 次）。
2. **β-oxidation ATP 計算**：palmitate **106**、每輪 **4 ATP**、7 個 H₂O、7 FADH₂（不是 8）、laurate 5 輪。
3. **四步驟順序**：FAD 去氫 → 水合 → NAD⁺ 去氫 → 硫解；**不需要 NADP⁺**、不需要 biotin。
4. **Carnitine／CPT I**：fatty acyl-carnitine 才能穿過內膜；CPT I 被 malonyl-CoA 抑制。
5. **奇數碳**：propionyl-CoA → **succinyl-CoA**；cofactor **B₁₂（mutase）**、biotin（carboxylase）。
6. **酮體**：在**肝臟**生成、以 **β-hydroxybutyrate** 形式運送；OAA 不足 + acetyl-CoA 過多 → acetoacetate、β-hydroxybutyrate。
7. **脂蛋白**：飲食脂質 → **chylomicron**；**LPL 水解血漿脂蛋白的 TG**；**FH = LDL receptor 突變**；LDL 進細胞第一步是 **ApoB-100 結合受體**；**巨噬細胞吞氧化 LDL → 斑塊**。
8. **HMG-CoA reductase（細胞質）vs HMG-CoA synthase（粒線體，生酮）**。

## 📝 出題模式
- **全英文單選**，題幹常出現「Which is NOT / incorrect」，約 1/3 是否定題。
- 計算題換脂肪酸長度（12、16、18、20 碳）或換問法（水、FADH₂、ATP），**先背公式**：循環 = n/2 − 1。
- 同一份共筆會出現**一模一樣的題目**（albumin、ketone body 運輸形式），代表老師反覆使用。
- 17-2 也混入 Ch21 脂肪酸合成的題目（ACC、citrate shuttle、合成 vs 分解比較），已歸到第 21 章練習。

## 🎙️ 老師課堂提示
- 老師點名的「兩分題」：膽鹽（glycocholate、taurocholate）、**FFA 由 serum albumin 攜帶**、chylomicron、LDL vs HDL、LDL receptor 與 **FH**、**膽固醇恆定三招**、**HMG-CoA reductase vs synthase / lyase**、CPT I、β-oxidation 與 ATP 計算、酮體。
- 計算陷阱：palmitoyl-CoA = **108**、palmitate = **106**（選項一定兩個都有）；活化相當消耗 **2 ATP**（ATP → AMP + PPi）。
- 進階題：奇數碳（17 碳）要會 propionyl-CoA → succinyl-CoA（biotin、B₁₂）。
- 例外要記：**ACC 去磷酸化才活化**；malonyl-CoA 抑制 CPT I。
