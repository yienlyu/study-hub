## 1. 中心法則與施老師五堂課的章節 ⭐

- **Central dogma**：DNA →（replication 複製）→ DNA；DNA →（transcription 轉錄）→ RNA →（translation 轉譯）→ protein；特殊路徑 RNA →（**reverse transcription 反轉錄**）→ DNA（反轉錄病毒如 HIV、反轉錄轉座子、**端粒合成**）。
- 施老師五堂課：**Ch24** 基因體 → **Ch25** 複製 → **Ch26** 轉錄 → **Ch27** 轉譯 → **Ch28** 基因表現調控。
- 百十三共筆補充（百十一）：RNA → RNA（RNA 病毒）、DNA → 蛋白質（無細胞系統）；從蛋白質出發的傳遞**還沒有發現**。

## 2. DNA 結構與基因體大小 ⭐

- DNA 兩大結構特性：**雙股螺旋、反向平行**（5'→3' 對 3'→5'）；**A=T 兩個氫鍵、G≡C 三個氫鍵**（老師：後面很多地方都用到氫鍵多寡）。
- mRNA 與 DNA 的**模板股（template strand）**互補且反向平行；DNA 用 ATCG，RNA 用 **AUCG**（A 配 U）。
- 基因體大小（slides 表）：

| 生物 | 基因體 | 染色體 | 基因數 |
|---|---|---|---|
| 噬菌體 ΦX174 | 約 5 kb | – | 很少 |
| 噬菌體 T4 | 168 kb | – | – |
| 大腸桿菌 *E. coli* | 4.6 × 10⁶ bp | **1（環狀）** | 約 4,500 |
| 酵母菌 | – | – | 約 6,000 |
| 人 | **3 × 10⁹ bp** | **46（23 對，線狀）** | 約 2 萬 |
| 稻米 | 比人小 | – | **約 3.7 萬（比人多將近兩倍）** |

- **基因體大小、基因數和生物複雜度沒有絕對關係**（稻米基因比人多；有些植物、兩棲類 DNA 比人多幾十倍）。
- 人和大腸桿菌比較（百十三共筆，參考百八）：

| | 人 | *E. coli* |
|---|---|---|
| 鹼基對 | 3 × 10⁹ | 4 × 10⁶ |
| 染色體 | 23 對 | 1 條，不成對 |
| 全長 | **1.8 m** | 1.6 mm |
| 型態 | **線狀** | **環狀** |
| 分裂時間 | 16–24 小時 | 20–40 分鐘 |
| oriC | **多個** | **一個** |

## 3. 超螺旋（supercoil）與 linking number ⭐⭐

- **Supercoil**：雙股螺旋本身再扭轉，「螺旋中又產生螺旋」。老師比喻：把一條橡皮筋（環狀 DNA）抓住南北極再繼續轉，像電話線打結。細胞中大部分 DNA 以超螺旋存在。
- **複製、轉錄會自然產生超螺旋**：RNA polymerase 往前走時，**前方（下游）被擠緊 → positive supercoil（overwound）**，**後方（上游）被鬆開 → negative supercoil（underwound）**。
- **Linking number（Lk）**：relaxed DNA 每 **10.5 bp 轉一圈**（這個數字不變）。
  - **Lk₀ = bp / 10.5**；**ΔLk = Lk − Lk₀**
  - **超螺旋密度 σ = ΔLk / Lk₀**
- 例題（slides、錄影）：2,100 bp 環狀 DNA，Lk₀ = 2100 / 10.5 = **200**；少轉兩圈（underwound by two turns）→ Lk = 198 → **σ = (198 − 200) / 200 = −0.01**。
- **細胞內 DNA 有 5–7% 被解開（underwound），σ ≈ −0.05 到 −0.07**，也就是細胞內 DNA 多為**負超螺旋**（因為複製、轉錄都要解開雙股）。
- σ 為正 = positive supercoil（overwound，繞得更緊）；σ 為負 = negative supercoil（underwound，繞得更鬆）。
- 解除超螺旋的酵素是 **topoisomerase**（細菌的 **DNA gyrase** 專門引入負超螺旋，見 Ch25）。

## 4. 染色質的層次 ⭐

- 人 3 × 10⁹ bp 的 DNA 拉直約 **1.8 公尺**，要裝進細胞核 → 必須層層捲曲包裝。
- 由小到大：**DNA 雙股螺旋 2 nm** → 纏在 histone 上的「串珠」**11 nm** → **30 nm chromatin fiber** → 更高層次的摺疊 → 染色體。
- 組蛋白纏繞的染色質是**真核生物特有**；包裝可以大幅縮小體積，也能調控基因表現。

## 5. Histone 與 nucleosome ⭐⭐⭐

- **Histone 五種：H1、H2A、H2B、H3、H4**。
- **核小體核心 = histone octamer（八聚體）= (H2A、H2B、H3、H4) × 2**；DNA 在 octamer 外**繞約兩圈**。
- **H1 不在 octamer 裡**，在核心外面、結合 **linker DNA**（考古：「Which does not contribute to the octameric histone core? → **H1**」）。
- 相鄰核小體之間是 **linker（spacer）DNA**，上面也有 non-histone protein 結合。
- **Histone 是小（十幾到二十幾 kD）、高度鹼性的蛋白質**：含大量（約 20–30%）**lysine、arginine**（帶正電），和**帶負電的 DNA 磷酸根**以正負電作用結合。
  - 老師：國考不會考你 20 個胺基酸的結構，會考「histone 含哪些胺基酸才能和 DNA 結合」→ **Lys、Arg**；histone 是**鹼性**蛋白質。
- 長度（百十三共筆）：核心 DNA **146 bp**；一個核小體保護約 **180 bp**；spacer 10–100 bp 不等；用 endonuclease 切染色質跑膠會看到**約 200 bp 倍數**的梯狀 band，電顯下像串珠。

## 6. 細胞死亡（slides 標為補充資料）⭐⭐

三種模式：**apoptosis（細胞凋亡）、autophagy（自噬）、necrosis（壞死）**，都和疾病有關。

| | Necrosis 壞死 | Apoptosis 凋亡 |
|---|---|---|
| 發生時機 | 細胞受到不可逆傷害（病理性） | 計畫性死亡（programmed cell death），汰換更新 |
| 訊號 | 外在刺激 | 體內或外在 |
| ATP | 不需要 | **需要** |
| 細胞變化 | **腫脹（swelling）→ 破裂** | **縮小（shrinkage）→ apoptotic body** |
| 細胞膜 | 破裂 | **完整**（apoptotic body 外膜完整） |
| 清除 | 內容物釋出 | **巨噬細胞吞掉 apoptotic body** |
| 發炎 | **有**（酵素等釋出） | **沒有** |
| DNA 電泳 | 隨機分布（smear） | **梯狀 DNA ladder（180 bp 倍數）** |

- **Apoptosis 的生理例子**：胎兒指間的蹼消失、蝌蚪變態、昆蟲蛻變、眼睛玻璃體與水晶體、每天汰換大量老舊血球。**癌細胞逃避 apoptosis** → 不死又長得快（immortalize）。
- **Autophagy**：把**受損或老化的胞器**（尤其會產生自由基的**粒線體**）送到溶酶體分解再利用；比較 **reversible**，不一定走到死亡；飢餓、斷食（如 168 斷食）會啟動 → 細胞更健康、抗老化。**2016 年諾貝爾獎**（日本大隅良典實驗室；老師講的故事是研究生把酵母菌培養皿忘在外面過了一個假期，發現酵母菌反而更健康）。
- 百十三共筆補充：用 NMR 偵測急性心肌梗塞的細胞死亡方式，necrosis 預後差、autophagy 預後較好。

### Apoptosis 的偵測：DNA ladder（國考）⭐⭐⭐

- Apoptosis 時 **DNase（核酸內切酶）把 DNA 片段化**，但**被 histone 包住的 DNA 受到保護**，只切沒被保護的 **linker（spacer）DNA**。
- 每段被保護的長度約 **180 bp**；有的切點沒切到 → 產生 **180、360、540、720 …（180 的倍數）** 的片段。
- 跑**洋菜膠電泳（agarose gel）**：control 的大片段 DNA 卡在 well 附近；apoptosis 的樣品出現 **DNA ladder**。看到 DNA ladder 就表示有 apoptosis；necrosis 是隨機切，呈 smear。
- 老師：「漸漸發現國考開始考 apoptosis 怎麼偵測」，因為和 histone 有關所以被考的機會比較多。

## 7. 其他（百十三共筆補充，今年 slides 沒有）

- **重複序列**：DNA reassociation kinetics（Britten & Kohne, 1968）發現有些序列重複 10⁵–10⁶ 次。**Satellite DNA**（短序列串聯重複，佔高等真核 10–20%，不編碼）；rRNA、tRNA、histone 基因重複數百到數千次；**Alu sequence**（約 300 bp、上百萬複本、散布全基因體，屬 SINE）。
- **Intron** 讓真核基因體變大；可能和 exon shuffling、**alternative splicing** 有關。
- **基因家族**（hemoglobin、histone、immunoglobulin）與 **pseudogene**（和表達基因序列相似，但 promoter 失能不轉錄）。

## 🎙️ 上課錄影重點（施純明，11/19）

- 開場先說明這五堂課的章節分配（Ch24–28）；第二十四章是基本概念、講得快，**第二十五章會講仔細**，「二十五章聽懂了，後面二十六章等等就比較容易」。
- **DNA 結構兩大特性：雙股螺旋、反向平行**；**GC 三個氫鍵、AT 兩個氫鍵**要先記住，後面很多地方會用到。
- 基因體：大腸桿菌 4.6 × 10⁶ bp、**一條**染色體、約 4,500 個基因；人 **3 × 10⁹ bp、46 條、約 2 萬個基因**；**稻米基因數（約 3.7 萬）比人還多將近兩倍**。
- **Supercoil**：環狀 DNA 像橡皮筋，抓住南北極繼續轉 → 螺旋中又有螺旋。轉錄時 RNA polymerase 往右走，**右邊（前方）變緊、左邊被鬆開**，所以細胞裡自然就會產生超螺旋。
- **Linking number**（課本 p.2143）：relaxed DNA **每 10.5 bp 一圈，「這數字不會變」**；Lk₀ = bp/10.5、σ = ΔLk/Lk₀。現場例題：2,100 bp → Lk₀ = 200，少兩圈 → σ = −0.01。正常細胞 **5–7% 被打開 → σ = −0.05～−0.07**，因為複製、轉錄都要解開雙股；positive／negative supercoil「知道就好」。
- 人的 DNA 全部拉長約 **1.8 公尺**，要裝進細胞核一定要層層包裝：**30 nm** chromatin fiber → **11 nm**（一個 histone 纏的 DNA）→ **2 nm** 雙股螺旋。
- **Histone「國考常常考」**：DNA 在 histone 上**繞兩圈**；**H2A、H2B、H3、H4 各兩個 = octamer**，**H1 在球體外面**、結合 linker DNA。Histone 為什麼能結合 DNA？DNA 磷酸根帶負電 → histone 帶正電，含大量 **lysine、arginine** → 是**鹼性蛋白質**，分子量只有十幾到二十幾 kD。「國考不會考二十個胺基酸的結構，會考它的運用」。
- **細胞死亡三種模式**（補充資料）：
  - **Necrosis**：細胞**脹大 → 破掉**，胞器、酵素跑出來 → 周邊**發炎**，是「最不好的死亡模式」。
  - **Apoptosis**：細胞**縮小** → **apoptotic body**（膜是完整的，裡面有胞器與片段化 DNA）→ **巨噬細胞吃掉**，**不發炎**。生理例子：胎兒手指間的蹼、每天汰換血球；壞處：該死的不死 → **cancer**（immortalize、長得特別快）。
  - **Autophagy**：先把**老化的胞器（粒線體、高基氏體）吃掉**，持續缺營養才走向死亡，比較 **reversible**；日本實驗室偶然發現（培養皿忘在外面一個假期，酵母菌反而更健康）、**諾貝爾獎**；斷食、168 → 清除產生**自由基**的老化粒線體 → 抗老化。
- **Apoptosis 怎麼偵測（黑板，「國考開始考」）**：DNase 切 DNA 時，**被 histone 保護的地方切不到、只切 spacer（linker）DNA**；每段 **180 bp**，沒切到的就變 **360、540、720…** → 洋菜膠電泳出現 **DNA ladder**（用 100 bp marker 對照）；沒有 apoptosis 的 control 是一大坨卡在 well 附近。「因為和 histone 相關，所以這個被考的機會稍微多一點」。

# 考點分析

## 🔥 高頻考點

1. **Histone octamer = (H2A、H2B、H3、H4) × 2，H1 不在核心內**（百十三考古 ch24-03）。
2. **Histone 富含 Lys、Arg、帶正電、鹼性**，靠正負電和 DNA 結合（老師點名國考）。
3. **Apoptosis 的 DNA ladder**：spacer DNA 被切、180 bp 倍數、洋菜膠電泳；necrosis 是 smear。
4. **Apoptosis vs necrosis**：縮小 vs 腫脹、膜完整 vs 破裂、不發炎 vs 發炎、需要 ATP vs 不需要。
5. **Linking number 計算**：Lk₀ = bp/10.5、σ = ΔLk/Lk₀；細胞內 DNA 為負超螺旋（σ 約 −0.05～−0.07）。
6. **DNA 與 RNA 的共同點**：都含磷酸、五碳糖、含氮鹼基（百十三考古 ch24-01）；差別在 2' 位置（RNA 為 –OH）、T vs U。
7. **互補股與回文序列**：5'-CGCGAATTCGCG-3' 的互補股寫成 5'→3' 還是 **5'-CGCGAATTCGCG-3'**（回文；百十三考古 ch24-07）；能形成 hairpin 的 RNA 序列要有**反向互補**的兩段（ch24-02）。
8. **Operator 是 DNA 序列**；activator、repressor、transactivator 是蛋白質（ch24-04，Ch28 的觀念）。
