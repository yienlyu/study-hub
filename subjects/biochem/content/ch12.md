# 生化訊息傳遞（黃彥華）

> 113 共筆沒有 Ch12 的考古（只有 Ch21 一題 IP3／DAG），以下依 2026 上課 slides 整理；練習區另有依 slides 編寫的模擬新題。Ch23 的胰島素、升糖素也會用到這章的訊息路徑。

## 1. 訊息傳遞系統的八個特徵（12.1）
| 特徵 | 意思 |
|---|---|
| **Specificity** 專一性 | 訊號分子與受體互補結合，其他分子接不上 |
| **Sensitivity** 敏感度 | 受體對訊號的親和力高（**Kd 低**）；Kd 高代表結合弱、要很高濃度才有反應 |
| **Amplification** 放大 | 酵素活化酵素的 **cascade**，訊號呈幾何級數放大 |
| **Modularity** 模組化 | 具多個結合 domain 的蛋白組成可互換的訊號複合體（如 SH2、PTB、PH domain） |
| **Desensitization / adaptation** 去敏感 | 回饋關閉受體或把受體移出細胞膜 |
| **Divergence** 發散 | 一個受體活化兩條以上路徑、產生不同效應 |
| **Integration** 整合 | 兩個訊號的效應相反或相加，最後合成單一反應 |
| **Localized response** 局部反應 | 破壞訊息的酵素就在附近，反應只在局部、短暫 |

## 2. 四大類訊號轉導器 ⭐⭐
| 類型 | 例子 | 怎麼傳 |
|---|---|---|
| ① **G protein–coupled receptor（GPCR）** | β-adrenergic（epinephrine）、glucagon、rhodopsin、嗅覺、味覺 | 受體 → 三聚體 G 蛋白 → 酵素 → **第二傳訊者** |
| ② **Receptor enzyme（RTK、receptor guanylyl cyclase）** | **Insulin receptor**、EGFR、PDGFR、ANF receptor | 配體結合 → 受體**自體磷酸化** → kinase cascade |
| ③ **Gated ion channel** | 電壓門控 Na⁺、**nicotinic ACh receptor**、ionotropic glutamate、GABA<sub>A</sub> | 開關離子通道 → 膜電位改變 |
| ④ **Nuclear receptor** | **Steroid**、thyroid hormone | 荷爾蒙進細胞 → 受體 → 結合 DNA（HRE）→ 調控轉錄 |

## 3. β-adrenergic receptor 與 cAMP ⭐⭐⭐
- Adrenergic receptor 四型：**α1、α2、β1、β2**。**Agonist** 模仿天然配體（isoproterenol）；**antagonist** 結合但不觸發反應（propranolol，β-blocker）。
- 路徑：**Epinephrine → β-adrenergic receptor（7 次跨膜）→ G<sub>s</sub>（GDP 換成 GTP，α 與 βγ 分離）→ G<sub>sα</sub>-GTP 活化 adenylyl cyclase → ATP → cAMP → PKA → 磷酸化目標蛋白**（肝：glycogen phosphorylase kinase → 肝醣分解）。
- **GTPase switch**：G<sub>sα</sub> 內建 **GTPase**，把 GTP 水解成 GDP 就自己關掉，回去和 βγ 結合。
- **PKA**：R₂C₂ 四聚體；每個 R 次單元結合 **2 個 cAMP**（共 4 個）→ 釋出 2 個活性 C（catalytic）次單元。**AKAP** 把 PKA 錨定在特定位置。PKA 活性可用 **FRET**（CFP/YFP）偵測。
- **Epinephrine cascade 的放大**（Fig. 12-7）：1 個 epinephrine → 10 個 G<sub>sα</sub> → 200 個 cAMP → 100 個 PKA → … → **100,000 個葡萄糖**（課本說這些數字還是低估）。⚠️ **cAMP → PKA 這一步不放大**：活化 1 個 PKA catalytic subunit 需要 2 個 cAMP。

### 訊號如何關掉
1. Epinephrine 離開受體
2. G<sub>sα</sub> 的 **GTPase** 水解 GTP（GAP、RGS 加速；GEF 促進換成 GTP）
3. **cAMP phosphodiesterase** 把 cAMP 分解成 5′-AMP
4. **去敏感（desensitization）**：**βARK**（β-adrenergic receptor kinase）磷酸化受體的 C 端 → **β-arrestin** 結合 → 受體被內吞（之後去磷酸化、送回細胞膜）

### 同一套機制偵測荷爾蒙、光、氣味、味道
- Vasopressin（G<sub>i</sub>，cAMP↓）、epinephrine（G<sub>s</sub>，cAMP↑）、**光（rhodopsin → transducin → cGMP PDE → cGMP↓**，關閉 Na⁺/Ca²⁺ 通道）、氣味（G<sub>olf</sub> → cAMP↑）、甜味（gustducin）。
- **視覺：光刺激 cGMP 的水解**，正好對應 β-adrenergic 反應中刺激 cAMP 的合成。

## 4. cGMP 與 PKG（12.3）⭐
- 兩種 guanylyl cyclase：
  - **膜上的 receptor guanylyl cyclase**：**ANF（atrial natriuretic factor）**、guanylin 受體（同源二聚體，細胞內為 GC domain）
  - **可溶性 guanylyl cyclase（含 heme）**：被細胞內的 **NO** 活化
- GTP →（guanylyl cyclase）→ **cGMP** → **PKG** → 平滑肌放鬆；cGMP 被 **cGMP phosphodiesterase（PDE）** 分解成 GMP。
- **Viagra（sildenafil）、Cialis（tadalafil）**：抑制 **cGMP PDE（PDE5）** → cGMP 停留更久 → 血管舒張。NO 由 arginine 經 NO synthase 產生，半衰期短。

## 5. DAG、IP₃、Ca²⁺ ⭐⭐
- 配體 → GPCR → **G<sub>q</sub>** → **phospholipase C（PLC）** 把 **PIP₂** 切成：
  - **IP₃**（水溶性）→ 結合 **ER 上的 Ca²⁺ 通道** → Ca²⁺ 釋入細胞質
  - **DAG**（留在膜上）+ Ca²⁺ → 活化 **protein kinase C（PKC）**
- Ca²⁺ 濃度會**振盪**（用螢光染劑 **fura-2** 測得，200–500 nM）。
- ⚠️ 考法：「InsP₃ binds to **Ca²⁺** channels in the ER while DAG activates **protein kinase C**」。

## 6. Receptor tyrosine kinase：insulin receptor ⭐⭐⭐
- Insulin receptor：**(αβ)₂**，α 在外結合 insulin、β 跨膜帶 tyrosine kinase domain；結合後 **β 次單元互相磷酸化 Tyr（autophosphorylation）**，activation loop 讓出受質結合位。
- 四條下游路徑：
  1. **MAPK cascade（細胞分裂、基因表現）**：受體磷酸化 **IRS-1** → **Grb2（SH2）→ Sos（GEF）→ Ras-GTP → Raf → MEK → ERK** → 進核磷酸化 Elk1 等轉錄因子
  2. **肌肉吸收葡萄糖**：GLUT4 平時在囊泡裡，insulin 讓它融合到細胞膜
  3. **肝醣合成**：IRS-1 → **PI3K**（PIP₂ → **PIP₃**）→ PDK1 → **PKB（Akt）** → 磷酸化 **GSK3（失活）** → glycogen synthase 去磷酸化（活化）；Akt 也促使 **GLUT4** 移到細胞膜
  4. **Cross talk**：insulin receptor 可磷酸化 β-adrenergic receptor 的 Tyr → GPCR 被內吞、反應變弱
- 其他 RTK：VEGFR、PDGFR、**EGFR**、TrkA、FGFR（domain 組成不同）。

## 7. Adaptor proteins 與 membrane rafts（12.5）
- **SH2、PTB domain**：認得磷酸化的 Tyr；**14-3-3**：認得磷酸化的 Ser/Thr；**PH domain**：結合 **PIP₃**。多個 domain 組合出複雜的訊號複合體。
- **Membrane raft、caveolae**：富含 **sphingolipid 與膽固醇**的微區，把訊號蛋白集中在一起，提高局部濃度與效率。

## 8. Gated ion channels（12.6）
- 細胞內為負：V<sub>m</sub> **−50 到 −70 mV**，主要由 **Na⁺K⁺-ATPase**（**3 Na⁺ 出、2 K⁺ 進**）建立。離子流向取決於濃度梯度和電位（電化學梯度）。
- 神經：**電壓門控 Na⁺ 通道**傳遞動作電位 → 軸突末端**電壓門控 Ca²⁺ 通道**打開 → 釋放 **acetylcholine** → 下一個細胞的**配體門控（nicotinic）通道**打開。

## 9. 核受體與類固醇荷爾蒙（12.7）⭐
- Steroid / thyroid hormone 以 serum binding protein 運輸 → 擴散進細胞 → 結合**細胞內（核）受體** → 受體二聚化、結合 **HRE（hormone response element）** → 調控轉錄 → 數小時到數天才出現效應。
- 受體結構：保守的**含鋅 DNA 結合 domain（zinc finger）** + C 端**荷爾蒙結合 domain**。
- 藥物：**Tamoxifen** 結合 estrogen receptor 但**不活化**（乳癌治療）；**RU486（mifepristone）** 阻斷 **progesterone receptor**（避孕、阻止著床）。

## 10. 細胞週期、癌症與凋亡（12.8–12.9）
- **CDK + cyclin**：G1 = cyclin D–CDK4/6；G1/S = **cyclin E–CDK2**；S = cyclin A–CDK2；M = cyclin B–CDK1。
- 生長因子 → MAPK → Jun/Fos → 轉錄 cyclin、CDK、**E2F**。
- **G1 → S 的關卡**：CDK 磷酸化 **pRb** → 釋放 **E2F** → 轉錄 DNA 合成相關酵素。DNA 受損 → ATM/ATR → **p53** → **p21** 抑制 CDK2-cyclin E → 停在 G1。
- **Proto-oncogene → oncogene**：病毒插入或突變（Ras、Src、ErbB、Myc…）；**tumor suppressor**：p53、pRb、APC。**p53 突變**集中在 DNA 結合區（R175、R248、R273 等熱點）。
- 標靶藥：**Gleevec（imatinib）**抑制 BCR-ABL（慢性骨髓性白血病）、**Herceptin** 對 HER2 乳癌；roscovatine 佔據 CDK2 的 ATP 結合位。
- **Apoptosis**：Fas ligand / TNF → death receptor → FADD → **caspase-8** → caspase-3；或粒線體釋出 **cytochrome c** → Apaf-1 → **caspase-9** → caspase-3。

# 考點分析

## ⚠️ 去年沒有 Ch12 的考古

## 🔮 預測考點（依 slides 份量）
1. **四大類受體**對應例子：insulin → RTK；epinephrine、glucagon → GPCR；ACh（nicotinic）→ ion channel；steroid → nuclear receptor。
2. **cAMP 路徑順序**：受體 → G<sub>s</sub>（GTP）→ adenylyl cyclase → cAMP → PKA；終止靠 GTPase、PDE、**βARK + arrestin**。
3. **PKA 的活化**：cAMP 結合 **regulatory** 次單元 → 釋出 catalytic 次單元。
4. **第二傳訊者配對**：PLC → IP₃（Ca²⁺）＋ DAG（PKC）；NO → 可溶性 GC → cGMP；ANF → 膜 GC。
5. **Viagra 抑制 cGMP PDE**；**視覺 = cGMP 水解**。
6. **Insulin → IRS-1 → PI3K → Akt → GSK3 磷酸化失活 → glycogen synthase 活化**（和 Ch23 的國考題一樣）。
7. **Tamoxifen（estrogen receptor 拮抗）、RU486（progesterone receptor）**。
8. **pRb–E2F、p53–p21** 控制 G1/S。
