## 1. 訊息傳遞系統的八個特徵（12.1）
| 特徵 | 意思 |
|---|---|
| **Specificity** 專一性 | 配體與受體構型互補，專一結合，其他分子接不上 |
| **Sensitivity** 敏感度 | 受體對訊號的親和力高（**Kd 低**）；Kd 高代表結合弱、要很高濃度才有反應 |
| **Amplification** 放大 | 一個第一傳訊分子活化數個第二傳訊分子，再活化更多第三傳訊分子：酵素活化酵素的 **cascade**，訊號層層放大 |
| **Modularity** 模組化 | 蛋白質有多個 binding domain（SH2、PTB、PH…），組成可互換的訊號複合體；**磷酸化產生新的結合位點**、去磷酸化時複合體解散 |
| **Desensitization / adaptation** 去敏感 | 反應過多時移除受體、水解訊號來源，回饋抑制 |
| **Integration** 整合 | 多個訊號同時調控一個反應時效應相加：訊號 1 促進、訊號 2 抑制 Response A，整合後反應可能不發生或變小 |
| **Divergence** 發散 | 一個受體活化數條功能不同的下游路徑 |
| **Localized response** 局部反應 | 訊號在擴散到周遭前就被附近的酵素分解，反應只在局部 |

## 2. 四大類訊號轉導器 ⭐⭐
| 類型 | 例子 | 怎麼傳 |
|---|---|---|
| ① **G protein–coupled receptor（GPCR）** | β-adrenergic（epinephrine）、glucagon、rhodopsin、嗅覺、味覺 | 受體 → 三聚體 G 蛋白 → 酵素 → **第二傳訊者** |
| ② **Receptor enzyme（RTK、receptor guanylyl cyclase）** | **Insulin receptor**、EGFR、PDGFR、ANF receptor | 配體結合 → 受體**自體磷酸化** → kinase cascade |
| ③ **Gated ion channel** | 電壓門控 Na⁺、**nicotinic ACh receptor**、ionotropic glutamate、GABA<sub>A</sub> | 開關離子通道 → 膜電位改變 |
| ④ **Nuclear receptor** | **Steroid**、thyroid hormone | 荷爾蒙進細胞 → 受體 → 結合 DNA（HRE）→ 調控轉錄 |

- **訊息傳遞的重要位置：membrane raft**（與 caveolae）：細胞膜上富含**膽固醇、鞘脂類（sphingolipid）**的區域，把受體、G 蛋白、激酶集中在一起，傳遞集中又有效率。

### Agonist 與 antagonist（以 β-adrenergic receptor 為例）⭐
| 分子 | 角色 | K<sub>d</sub>（μM） | 結合後 |
|---|---|---|---|
| **Epinephrine** | 天然配體（心跳↑、支氣管擴張、血糖↑） | 5 | 活化受體 |
| **Isoproterenol** | **Agonist**（由 epinephrine 改造，親和力更強） | 0.4 | 活化受體 |
| **Propranolol** | **Antagonist**（β-blocker，降血壓、治心絞痛、減慢心跳） | 0.0046 | 阻斷受體活化 |

- K<sub>d</sub> = [R][L]/[RL]，**越小親和力越高**：propranolol 親和力最強，所以能擋住 epinephrine 與 isoproterenol。

## 3. GPCR 與 β-adrenergic receptor／cAMP ⭐⭐⭐
- GPCR：**七次跨膜**。G 蛋白是 **αβγ 異三聚體**；不活化時 Gα 結合 **GDP**；活化時 Gα 換成 **GTP**，Gα-GTP 與 Gβγ 分離、分別調控下游。
- **六種次級傳訊者**：

| 次級傳訊者 | 主要功能 |
|---|---|
| cAMP | 活化 PKA |
| cGMP | 活化 PKG、調控特定離子通道（CNG） |
| IP₃ | 促進 ER 釋放 Ca²⁺ |
| DAG | 活化 PKC |
| Ca²⁺ | 活化 PKC、calmodulin 等 |
| NO | 活化 soluble guanylyl cyclase |

- Adrenergic receptor 四型（epinephrine、norepinephrine 刺激）：**α₁** 血管平滑肌收縮、**α₂** 抑制部分神經傳導物質釋放、**β₁** 心跳與心肌收縮力↑、**β₂** 支氣管平滑肌舒張。
- 路徑：**Epinephrine → β-adrenergic receptor → 活化的受體當 GEF，讓 G<sub>sα</sub> 放掉 GDP、換成 GTP → G<sub>sα</sub>-GTP 與 βγ 分離 → 活化膜上 adenylyl cyclase → ATP → cAMP（3′,5′-cAMP）→ PKA → 磷酸化目標蛋白的 Ser／Thr**。
- **PKA**：R₂C₂ 四聚體；每個 R 次單元有 **2 個 cAMP 結合位**，沒結合 cAMP 時 R 佔住 C 的受質結合位；**4 個 cAMP** 結合 2 個 R 後釋出 2 個活性 C 次單元。**AKAP**（A-kinase anchoring protein）結合 R 次單元，把 PKA 定位在特定區域。
- **Epinephrine cascade**（肝醣分解）：PKA → 磷酸化活化 **phosphorylase kinase** → glycogen phosphorylase **b → a** → 肝醣分解成 **G1P** →（phosphoglucomutase）**G6P** →（肝細胞有 **glucose-6-phosphatase**）游離葡萄糖進血液。
- 放大的數字（Fig. 12-7）：1 個 epinephrine → 10 個 G<sub>sα</sub> → 200 個 cAMP → 100 個 PKA → … → **100,000 個葡萄糖**。⚠️ **cAMP → PKA 這一步不放大**：活化 1 個 C 次單元需要 2 個 cAMP。

<div data-fig="gpcr-camp"></div>

### 訊號如何關掉（desensitization／adaptation）
1. **GTPase switch**：Gα 內建 **GTPase**，把 GTP 水解成 GDP + Pi，Gα-GDP 回去和 βγ 結合；**GAP、RGS** 加速水解（GEF 則促進換成 GTP）。
2. **cAMP phosphodiesterase（PDE）**：cAMP → **5′-AMP**，PKA 活性下降。
3. **受體去敏感**：epinephrine 持續刺激時，游離的 **Gβγ 把 βARK（又稱 GRK2）招募到膜內側** → βARK 磷酸化受體 **C 端的 Ser** → **β-arrestin** 結合磷酸化位點，擋住受體與 G 蛋白偶聯 → 受體–arrestin 複合體被**內吞**（desensitization）→ arrestin 解離、受體去磷酸化後送回細胞膜（**resensitization**）。

### FRET 偵測 PKA 活性
- 能量供體 **CFP（476 nm）**、受體 **YFP（527 nm）**；兩者靠得夠近時 CFP 的激發能量共振轉移給 YFP。
- 感測蛋白 = CFP + **PKA consensus sequence** + **14-3-3 phosphoserine-binding domain** + YFP：PKA 磷酸化 Ser → 14-3-3 domain 抓住磷酸化 Ser → 構型改變、CFP 與 YFP 靠近 → **FRET 增加，527 nm 螢光相對上升**。

### 視覺訊息傳遞：同一套機制偵測光 ⭐⭐
- **Rhodopsin** = **opsin + retinal**（感光分子），位在視桿細胞外節，是感光型 GPCR。
- 光 → rhodopsin 活化、當 GEF → **transducin（G<sub>t</sub>）** 換成 GTP → 活化 **cGMP PDE（PDE6）** → cGMP 水解成 5′-GMP、**cGMP↓** → **CNG channel 關閉** → Na⁺、Ca²⁺ 流入↓ → 視桿細胞**過極化** → glutamate 釋放↓。

| | β-adrenergic pathway | Visual transduction |
|---|---|---|
| 刺激 | Epinephrine | 光 |
| GPCR | β-adrenergic receptor | Rhodopsin |
| G protein | G<sub>s</sub> | Transducin（G<sub>t</sub>） |
| Effector | Adenylyl cyclase | PDE6 |
| 次級傳訊者 | cAMP **上升** | cGMP **下降** |
| 主要下游 | PKA | CNG channels |

- 兩者都有 GTPase switch、訊號放大與終止機制。其他同類：vasopressin（G<sub>i</sub>，cAMP↓）、氣味（G<sub>olf</sub> → cAMP↑）、甜味（gustducin）。

## 4. cGMP 與 PKG（receptor guanylyl cyclase，12.3）⭐
- Guanylyl cyclase：GTP → **cGMP** → **PKG** → 磷酸化下游蛋白。兩種：
  - **膜型（跨膜受體）GC**：胞外配體結合區＋胞內催化區，例如 **ANF（atrial natriuretic factor）** 受體、guanylin 受體 → 血管舒張、排鈉
  - **可溶性 GC（sGC，含 heme）**：**NO** 直接穿過細胞膜，結合 heme 的 **Fe²⁺** 而活化
- cGMP 被 **PDE** 水解成 **5′-GMP**，訊號終止。
- 藥物：**Sildenafil（Viagra）、Tadalafil（Cialis）= PDE5 inhibitor** → cGMP 停留更久 → 海綿體平滑肌舒張、血液流入。**Nitroglycerin** 經 NO 訊號促進 cGMP 合成。

## 5. DAG、IP₃、Ca²⁺（phosphoinositide 系統）⭐⭐
- 配體 → GPCR → **G<sub>qα</sub>** 換成 GTP → 活化 **phospholipase C-β（PLCβ）** → 水解膜內側的 **PIP₂（PI 4,5-bisphosphate）**：
  - **IP₃**（親水）→ 結合 **ER 上的 IP₃ receptor（就是 Ca²⁺ 通道）** → Ca²⁺ 釋入細胞質
  - **DAG**（疏水、留在膜上）+ 上升的 Ca²⁺ → 活化 **protein kinase C（PKC）**
- **Ca²⁺ + calmodulin（CaM）** → 調控 **CaMK**、**MLCK**（myosin light-chain kinase）等。
- 走這條路的配體：

| 配體 | 受體 | 路徑 |
|---|---|---|
| Epinephrine | **α₁**-adrenergic | G<sub>q</sub> → PLCβ |
| Acetylcholine | **M₁、M₃、M₅** | G<sub>q</sub> → PLCβ |
| Vasopressin | **V₁** | G<sub>q</sub> → PLCβ |
| TRH | TRH receptor | G<sub>q</sub> → PLCβ |
| Angiotensin II | **AT₁** | G<sub>q</sub> → PLCβ |
| PDGF | PDGF receptor（**RTK**） | **PLCγ** |

- 細胞內 Ca²⁺ 用螢光染劑 **fura-2** 測；norepinephrine 刺激肝細胞後 Ca²⁺ 因正負回饋升降，稱 **Ca²⁺ oscillation**（200–500 nM）。
- ⚠️ 考法：「InsP₃ binds to **Ca²⁺** channels in the ER while DAG activates **protein kinase C**」。

## 6. Receptor tyrosine kinase：insulin receptor ⭐⭐⭐
- RTK 與 GPCR 不同：不靠 G 蛋白，而是配體（多為**生長因子**）結合後受體**二聚化、自體磷酸化 Tyr**，再活化 kinase cascade。
- 種類：**Insulin receptor**、VEGFR、PDGFR、**EGFR**、TrkA、FGFR；膜內都有 tyrosine kinase domain，膜外各不相同（**不用背哪種配哪個膜外構造**）。共筆註：「INSR 常考，但老師說其他的也記一下」。
- **Insulin receptor**：**(αβ)₂**，兩半一模一樣（共筆寫 homodimer），α 在外結合 insulin、β 跨膜帶 tyrosine kinase domain（**IRK**）；insulin 結合後 β 互相磷酸化 Tyr 成 **phosphotyrosine（pY）**，activation loop 讓出受質結合位 → 磷酸化 **IRS-1**（insulin receptor substrate-1）。
- 下游路徑：
  1. **細胞增生（MAPK cascade）**：磷酸化的 IRS-1 → **Grb2（SH2 認 pY）→ Sos（Ras 的 GEF）→ Ras-GTP → Raf-1（MAPKKK）→ MEK（MAPKK）→ ERK（MAPK）** → 進核磷酸化轉錄因子（Elk1 等）→ 細胞分裂
  2. **肝醣合成與血糖利用**：IRS-1 → **PI3K**（PIP₂ → **PIP₃**）→ PDK1 → **PKB（Akt）**：
     - 讓囊泡裡的 **GLUT4** 移到細胞膜、多吸血糖；insulin 下降時 GLUT4 被內吞回 endosome 待命（避免空腹時過度吸收葡萄糖）
     - 磷酸化 **GSK3 → 失活** → GSK3 不能磷酸化 glycogen synthase → **GS 保持去磷酸化 = 活化**，合成肝醣
- ⚠️ **共筆要小心的兩句**：共筆寫「SoS 活化 Ras……將 GTP 轉為 GDP」，正確是 Sos 讓 Ras **放掉 GDP、換成 GTP**而活化（Ras 自己水解 GTP 才是關掉）；共筆寫「PIP₃ 磷酸化 PKB」，正確是 PIP₃ 把 PKB 與 **PDK1** 招到膜上，由 PDK1 磷酸化 PKB。
- **ras 寫法**：正體 Ras／ras 指正常的 proto-oncogene；共筆說斜體 *ras* 指 oncogene。（一般習慣是基因寫斜體、蛋白寫正體，考試照題目語境判斷。）
- **Cross talk**：
  - **互相抑制**：insulin receptor 磷酸化 β-adrenergic receptor 的 Tyr → β 受體被內吞、降解，反應變弱
  - **互相加成**：insulin receptor 與 GPCR 一起促進細胞增生

## 7. Adaptor proteins（12.5）
- **SH2、PTB domain**：認得磷酸化的 Tyr；**SH3**：結合 proline-rich 序列（Grb2 的 SH3 抓 Sos）；**14-3-3**：認得磷酸化的 Ser/Thr；**PH domain**：結合 **PIP₃**。多個 domain 組合出複雜的訊號複合體。

## 8. Gated ion channels（12.6）
- 細胞內為負：V<sub>m</sub> **−50 到 −70 mV**，主要由產電性（electrogenic）的 **Na⁺K⁺-ATPase**（**3 Na⁺ 出、2 K⁺ 進**）建立；離子順電化學梯度流動，Na⁺ 傾向流入、K⁺ 傾向流出。
- 神經：**depolarization** = Na⁺ 進入；**repolarization** = K⁺ 離開；軸突末端**電壓門控 Ca²⁺ 通道**打開、Ca²⁺ 進入 → 分泌囊泡釋放 **acetylcholine** → 結合下一個細胞的**配體門控（nicotinic）通道**。

## 9. 核受體與類固醇荷爾蒙（12.7）⭐
- 固醇類荷爾蒙很疏水，血液中靠 **serum binding protein** 運送，可直接穿過細胞膜與核膜，但仍要結合 **nuclear receptor** 才能調控轉錄。受體依種類**位在細胞質或細胞核**（共筆註：兩種描述都對）。
- 受體「兩隻手」：**C 端荷爾蒙結合 domain** + 保守的**含鋅 DNA 結合 domain（zinc finger）**，結合 **HRE（hormone response element）** → 招募 **coactivator（或 corepressor）** → 調控轉錄 → 數小時到數天才出現效應。
- 藥物：**Tamoxifen** 結合 estrogen receptor 但**不活化** estrogen-responsive genes（乳癌）；**RU486（mifepristone）** 阻斷 **progesterone receptor** → 子宮內膜不穩定、避免著床（事後避孕、引產）。

## 10. 細胞週期調控（12.8）⭐⭐
- **CDK 要結合 cyclin 才有活性**：G1 = **cyclin D–CDK4/6**；G1/S = **cyclin E–CDK2**；S = cyclin A–CDK2；M = cyclin B–CDK1。G1 → S 之前有 **restriction point**。
- 生長因子（insulin、cytokines）→ **Ras → Raf → MEK → ERK** → 進核磷酸化 **Jun、Fos** → ①促進 cyclin／CDK 表現 ②活化 **E2F**、轉錄 DNA 合成所需酵素。
- **正常**：cyclin D–CDK4/6 先磷酸化 **pRb**，cyclin E–CDK2 再磷酸化 → pRb 放開 **E2F** → DNA synthesis 基因表現 → **G1 → S**。
- **DNA 受損**：DNA 斷裂／輻射 → **MRN complex** 偵測 → **ATM／ATR** → **p53** 活化 → **p21**（CDK inhibitor）合成↑ → 抑制 cyclin E–CDK2 → pRb 無法充分磷酸化、E2F 被抓住 → **G1 arrest**（讓細胞有時間修 DNA）。

| | 正常細胞 | DNA 受損細胞 |
|---|---|---|
| p53 | 未明顯活化 | 活化 |
| p21 | 低 | 增加 |
| Cyclin E–CDK2 | 活化 | 受抑制 |
| pRb | 磷酸化 | 無法充分磷酸化 |
| E2F | 活化 | 被 pRb 抑制 |
| 細胞週期 | G1 → S | **G1 arrest** |

## 11. 細胞癌化與凋亡（12.9）⭐⭐
| | **Oncogene** | **Tumor suppressor gene** |
|---|---|---|
| 正常功能 | 原為 proto-oncogene，調控生長增殖 | 抑制異常增殖、維持基因組穩定 |
| 癌化機轉 | **Gain-of-function** | **Loss-of-function** |
| 代表 | Ras、Raf、Myc | **TP53、RB1、APC** |

- Oncogene 兩種來源：①**retrovirus** 攜帶宿主 proto-oncogene，在其他細胞異常表現（transformation）②proto-oncogene 自發或外在因素突變。
- **p53**（TP53 編碼）：轉錄因子、「基因組的守護者」；突變集中在 DNA 結合區（R175、R248、R273 等熱點）→ 細胞週期停滯與凋亡失常。
- Oncogene 出現在訊息傳遞的各層級：

| 層級 | 代表 oncogene |
|---|---|
| Growth factor | **sis**（PDGF 相關） |
| Growth factor receptor | **erbB、neu、kit** |
| Intracellular transducer | **ras、raf、src、abl**（老師重點） |
| Transcription factor | **myc、jun、fos** |

- **Ras 訊號終止與癌化**：Ras 是 small GTPase，自己水解 GTP 而關掉，**GAP** 加速；突變 Ras 水解 GTP 的能力（或對 GAP 的反應）下降 → **持續結合 GTP** → MAPK 路徑過度活化。
- **標靶治療**：基因分析找出異常分子（例：大腸直腸癌各基因突變比例）。

| 藥物 | 標的 | 疾病 |
|---|---|---|
| **Imatinib（Gleevec）** | **BCR-ABL** tyrosine kinase（t(9;22) 融合基因，持續活化） | **CML** |
| **Trastuzumab（Herceptin）** | **HER2** receptor | HER2 陽性乳癌 |
| Roscovitine（seliciclib） | 佔據 **CDK2** 的 ATP 結合位 | 抗癌候選藥 |

- **Apoptosis**：**caspase**（cysteine-dependent aspartate-specific protease），平時是 procaspase。
  - Initiator：**caspase-8、9**；Executioner：**caspase-3、6、7**
  - **外在路徑**：FasL + Fas（CD95）、或 TNF-α + TNFR1 → death domain 招募 **FADD** → **caspase-8** → executioner caspases
  - **內在（粒線體）路徑**：DNA 損傷、氧化壓力 → **Bax／Bak** → 粒線體外膜通透 → **cytochrome c** 釋出 → 與 **Apaf-1** 形成 **apoptosome** → **caspase-9** → executioner caspases
  - 兩條的連結：caspase-8 切 **Bid** → 促進粒線體路徑

## 🎙️ 上課錄影重點（黃彥華，11/12，1:48:53）

- **今天的架構**：八大特色 → 四大訊息傳遞（**GPCR、receptor tyrosine kinase、gated ion channel、固醇類荷爾蒙**）→ adaptor protein 與 membrane raft → cell cycle（CDK）→ oncogene、tumor suppressor（p53）→ apoptosis。課本的細菌訊息傳遞與嗅覺、味覺細節**不講**。
- **份量**：老師說 **GPCR 和 RTK 是兩大重點，大約 35%：35%**。
- **六大二級訊息傳遞者**：cAMP、cGMP、IP₃、DAG、Ca²⁺、NO。
- **Kd**：Kd 越低 binding 越好；antagonist propranolol Kd 0.0046 遠低於 epinephrine（5），一丟進去就搶走受體。agonist、antagonist 都是荷爾蒙的 **analog**。
- **G 蛋白的比喻**：GDP 時 α（爸爸）、β（媽媽）、γ（寶寶）住在一起；epinephrine 來了給 α「富爸爸的錢」（GTP）→ α 離家去找 adenylyl cyclase。關掉有兩處：**PDE 把 cAMP 變 5′-AMP**、**GTPase 把 GTP 變 GDP**（α 變窮回家）。**PDE「要記住」**，後面 cGMP 也會用到。
- **PKA = R₂C₂**：2 個 cAMP 結合 R → C 釋出；**FRET**（CFP 476 nm → YFP 527 nm；PKA 磷酸化的序列＋14-3-3）是偵測 PKA 活化的經典方法，「請大家要知道」。
- **放大**：epinephrine 濃度不需要高，就能放大到 10 萬倍；荷爾蒙過多（如雌激素）放大過頭 → 腫瘤風險。
- **GPCR 有哪些**：β-adrenergic receptor 與 **rhodopsin** 都是；老師：「考簡單一點就是『下列哪些是 GPCR』，GPCR 是誰要知道。」GEF 換上 GTP；**GAP、RGS** 讓 GTP 水解關掉。
- **去敏感**：PKA → **βARK** 磷酸化受體 C 端 → **β-arrestin** 結合 → 內吞到 endosome（pH 6）→ arrestin 釋放、受體回到膜上。「請大家注意 **βARK 跟 βARR**。」
- **視覺**：光 → rhodopsin（像 GEF）→ **transducin-GTP** → 活化 **PDE** → **cGMP 水解成 GMP** 才看得到。epinephrine（cAMP↑）和 rhodopsin（cGMP↓）這兩個例子「**務必要會**」。
- **Guanylyl cyclase 兩種**：膜上 receptor form（**ANF**、guanylin、endotoxin）、可溶性 heme form（**NO**）。cGMP → **PKG**。這部分「也是常考的考題」。
- **威而鋼**：抑制 **PDE** → cGMP 延長 → 血管平滑肌放鬆。原本為心絞痛設計（硝化甘油舌下錠 → NO → cGMP）。老師：「很簡單的考題、兩分題，不會自動讓分。」**NO 活化可溶性 GC、Viagra 抑制 cGMP PDE「這個要會」**。
- **IP₃／DAG／Ca²⁺**：老師用 GPCR 活化 **PLC** 為例（slides 寫 G<sub>q</sub>），PIP₂ → IP₃（ER 上 IP₃ receptor 放 Ca²⁺）＋ DAG；Ca²⁺ 與 DAG 都活化 **PKC**，Ca²⁺ 也活化 calmodulin-dependent kinase。「**重要的基本題，一定要會**。」**fura-2（AM）**測細胞內 Ca²⁺（越紅越高）要記住。
- **RTK「我自己就是豪門」**：配體結合 → 雙體靠近 → **autophosphorylation**（關鍵字）。細胞外的 leucine-rich、cysteine-rich、Ig domain **不用背**。
- **Insulin 四個例子**：① **IRS-1 → Grb2 → Sos → Ras → Raf-1 → MEK → ERK** → 進核磷酸化 **Elk1**，與 SRF 結合 DNA → 細胞分裂（「這個次序請大家背一下」，Ras 打星星）；② **GLUT4** 送到肌細胞膜（被動運輸），血糖降後內吞；③ **IRS-1 → PI3K（PIP₂ → PIP₃）→ PKB → 磷酸化 GSK3（失活）→ glycogen synthase 維持去磷酸化（活化）→ 合成肝醣**；④ **cross talk**：insulin receptor 磷酸化 GPCR 的 Tyr → 走 Grb2–Sos–Ras–MAPK。
- **MAPK 命名**：ERK = MAPK，MEK = MAPKK，Raf = MAPKKK。
- **基因寫法**：正體 Ras 是正常蛋白／基因；**小寫斜體（*ras*、*raf*）是 oncogene**，「內行的寫法」。要記的 oncogene：Ras、Raf、**c-Abl**、**c-Myc**。Ras 突變 → GAP 關不掉 → 持續增生。
- **Membrane raft**（期中前講過）：膽固醇、caveolin 多的較厚區域，很多 receptor（尤其 RTK）在這裡做訊息傳遞。
- **Ion channel** 只講 Na⁺K⁺-ATPase（3 Na⁺ 出、2 K⁺ 進）→ 去極化、再極化 → **電壓門控 Ca²⁺ 通道** → 釋放 **acetylcholine** → nicotinic ACh receptor；神經細節留給生理。
- **固醇類荷爾蒙**：需要 serum binding protein 運送；受體在細胞質或細胞核都有人報告，「兩個都對」；受體兩隻手：**zinc finger 結合 HRE**、**C 端結合荷爾蒙**。**Tamoxifen**（ER 拮抗，用於雌激素驅動的乳癌、卵巢癌、子宮內膜癌）與 **RU486**（progesterone receptor 拮抗，子宮內膜不穩定 → 流產；需處方）「**這兩個例子都要會**」。
- **CDK 調控**：cyclin 結合後，還要特定 Tyr 位置磷酸化才活化；關掉靠 **DBRP** → cyclin 被 **ubiquitin** 標記降解（和 HMG-CoA reductase 降解機制一樣）。老師說這張 slide 可能沒放在給同學的講義裡。
- **DNA 受損**：MRN（sensor，不用背）→ ATM/ATR → **p53** → **p21** 結合 CDK–cyclin → 停止增生。正常細胞：CDK–cyclin 磷酸化 **Rb** → 釋出 **E2F** → G1 → S。「這也是需要大家知道的。」p53 突變的病人反覆得癌症。
- **大腸癌多步驟突變、CDK2 抑制劑**：知道概念就好，不用背；精準醫療依特定突變選藥。
- **Apoptosis**：TNF-α 或 **Fas ligand（Fas = CD95）** → death domain → procaspase → **caspase-8** → 粒線體 **cytochrome c** → **caspase-9** → caspase-3、6、7。考題會以「programmed cell death」出現；關鍵字「8、3、6、7、9」。
