# 胺基酸生合成、紫質與 heme（陳顧中）

> 📌 **期中考範圍**：以 *Ch18-3 Ch22* slides p46–77 與 10/22 錄影為準。授課大綱（p47）只有：必需／非必需胺基酸、胺基酸衍生物、porphyrin 與 heme（succinate-glycine 路徑）、heme 分解、黃疸。**核苷酸合成與分解由期中考後的老師講，不考**（移到「核苷酸代謝（期中考後）」）。
> 老師：Ch22 是他三章中國考出現率最低的一章；很多胺基酸只在植物、細菌合成，「認真讀整個合成途徑是浪費時間」，抓下面的考點就好。

## 1. 必需、條件式必需、非必需胺基酸 ⭐⭐⭐
- **必需 9 個**（人體無法從頭合成）：His、Ile、Leu、Lys、Met、Phe、Thr、Trp、Val。老師口訣 **3TLIPHMV**（3 個 T = Thr、Trp、Tyr）。
- ⚠️ **Tyr 是條件式必需**（conditionally essential）：人體不能從頭做，但能由 **Phe 加一個 –OH**（Phe hydroxylase，BH₄）轉來。題目問「條件式必需」選 **Tyr**。
- 條件式必需 6 個：**Arg、Cys、Gln、Gly、Pro、Tyr**；**Arg** 是**發育中兒童**合成不足、要從食物補充的那個（1121 醫檢師）。
- 非必需 5 個：Ala、Asn、Asp、Glu、Ser。
- **兼具必需 + 生酮 = Leu**（純生酮只有 Leu、Lys）。
- 合成時一樣靠**轉胺（PLP）**接上胺基：α-keto acid + Glu → 胺基酸 + α-KG。

## 2. 六大前驅物家族 ⭐⭐
| 前驅物 | 合成的胺基酸 | 備註 |
|---|---|---|
| **α-Ketoglutarate** | **Glu → Gln、Pro、Arg** | **Pro、Arg 主要由 glutamate 轉換**（1131、1152 醫師） |
| **3-Phosphoglycerate** | **Ser → Gly、Cys** | 三者是親戚；合成走 3-PG，但分解走 pyruvate |
| **Oxaloacetate** | **Asp → Asn**（Met、Thr、Lys 人體不做） | |
| **Pyruvate** | **Ala**（Val、Leu、Ile 人體不做） | |
| PEP + erythrose-4-P | Phe、Tyr、Trp（shikimate） | 人體沒有這條 |
| **Ribose-5-P（經 PRPP）** | His | 與 PPP 有關 |
- 老師：只要背 **α-KG、pyruvate、OAA** 三家，分解與合成進出的位置相同（反過來走）。

## 3. Ala、Asp、Glu、Asn、Gln
- Ala ← pyruvate、Asp ← OAA、Glu ← α-KG，都是**轉胺**一步。
- **Glutamine synthetase**：Glu + **NH₄⁺** + ATP → Gln + **ADP + Pi**。
- **Asparagine synthetase**：Asp + **Gln（給 N）** + ATP → Asn + Glu + **AMP + PPi**。兩個別混。

## 4. Ser、Gly、Cys ⭐⭐
- **3-PG → Ser** 三步：氧化（NAD⁺）→ 轉胺（Glu）→ 去磷酸。
- **Ser ⇄ Gly**：**serine hydroxymethyltransferase（PLP）**，同時產生 **N⁵,N¹⁰-methylene-THF**（一碳單位最主要來源）。
- **Cys（轉硫作用）**：Met → SAM → SAH → homocysteine；homocysteine + **Ser** →（**cystathionine β-synthase，PLP**）→ cystathionine → **Cys** + α-ketobutyrate。**硫來自 Met，碳骨架與胺基來自 Ser**。
- 動物用飲食 **Met 做 Cys**；植物、細菌用**無機硫**做 Cys、再做 Met（p59）。

## 5. 胺基酸衍生物：creatine、taurine、glycine ⭐⭐
- **Creatine**：**Gly + Arg**（AGAT，腎）→ guanidinoacetate →（GAMT，**SAM 給甲基**，肝）→ creatine → 送肌肉，creatine kinase → phosphocreatine。相關胺基酸 **Gly、Arg、Met（SAM）**。
  - 1152 營養師：「Arg 和 Gly 藉由**轉甲基作用**生成肌酸」✓；NOS 產生的是 **NO**（不是 nitrogen dioxide）；melatonin 來自 **Trp**（不是 Arg + Tyr）；只有 **L-form** 胺基酸被吸收利用。
- **Taurine（牛磺酸，約占體重 0.1%）**：Cys → cysteine sulfinate → hypotaurine → taurine。功能：**結合膽酸形成膽鹽**（最主要）、抗氧化、滲透壓調節、穩定細胞膜、調節 Ca²⁺ 訊號；心血管、骨骼肌、視網膜、中樞神經需要。
- **膽鹽** = 膽酸（由膽固醇）+ **glycine 或 taurine**。
- **Glycine 的衍生物（p62）**：**glutathione**（Glu–Cys–Gly）、**creatine**、**porphyrin／heme**、**purine**、glyoxylate（植物）、bile salt 結合。

## 6. 芳香族胺基酸：shikimate pathway
- Phe、Tyr、Trp 由 PEP + erythrose-4-P 經 **shikimic acid pathway**（中間物 **shikimate、chorismate**）合成——**只在植物、細菌**，人體沒有。老師：不重要但考過一次，兩個名字要認得。

## 7. Porphyrin 與 heme 合成 ⭐⭐⭐
- **Porphyrin（紫質，tetrapyrrole）**：四個 pyrrole（五元環）組成。衍生物：**heme（中間是 Fe）**、**葉綠素（Mg）**、phycobilin 藻膽素、**cobalamin = B₁₂（中間是 Co）**。
- 醫檢師國考：**最不易儲存、大多由尿排出、可做輔酶**的維生素 = **B₁₂**（cyanocobalamin）。
- **Succinate-glycine 路徑**：**succinyl-CoA + glycine** →（**ALA synthase，PLP，限速、被 heme 回饋抑制**）→ **δ-aminolevulinate（ALA）** → porphobilinogen → … → protoporphyrin IX + Fe²⁺（ferrochelatase）→ heme。植物用 **glutamate** 做 ALA。
- 動物 heme 主要前驅物 = **glycine**（111-2 醫師）；heme 的碳來自 succinate 與 glycine。
- ⚠️ **位置**：起點（ALA synthase）在**粒線體** → 中間步驟在**細胞質** → 最後回**粒線體**完成。考題「heme 合成在細胞質中完成」✗（1121 醫師），答「在粒線體完成」。
- 路徑中任一酵素缺陷 → **紫質症（porphyria）**；常考 acute intermittent porphyria（PBG deaminase）、porphyria cutanea tarda（uroporphyrinogen decarboxylase）。

## 8. Heme 分解與黃疸 ⭐⭐⭐
- 來源：大多是**老化紅血球**，少部分來自 cytochrome 等 heme 蛋白；胺基酸與鐵回收再用，bilirubin 要溶解後排出。
- **先脾後肝**：
  - **脾臟**（巨噬細胞）：heme →（**heme oxygenase**，NADPH、O₂）→ **biliverdin**（綠）+ **Fe²⁺ + CO** →（**biliverdin reductase**）→ **bilirubin**（未結合型，不溶於水）。
  - 血中由 **albumin** 運送到肝（不是 haptoglobin、transferrin）。
  - **肝臟**：**UDP-glucuronyltransferase** 接上 2 個 **UDP-glucuronate** → **bilirubin diglucuronide**（結合型）→ 膽汁 → 腸道細菌 → **urobilinogen** → stercobilin（糞便）。
- 考過：heme 分解的器官 = **脾臟**（1151）；heme → biliverdin 的酵素 = **heme oxygenase**（不是 oxidase，1141 醫師）；bilirubin 在肝與 **glucuronic acid** 結合（1141 醫檢師）；放出的氣體是 **CO**（不是 CO₂、NO）。

### 黃疸：哪一種 bilirubin 上升 ⭐⭐
| 情境 | 上升的 bilirubin | 機轉 |
|---|---|---|
| **新生兒生理性黃疸**（尤其早產兒） | **未結合型** | 肝臟 **UDP-glucuronyltransferase 未成熟**（一兩個月內自行消失） |
| **溶血**（如 G6PD 缺乏 + 氧化性藥物） | **未結合型** | heme 分解太多，送到肝的負荷超過結合能力 |
| 膽道阻塞 | 結合型 | bilirubin diglucuronide 排不出去 |
- 未結合型不溶於水 → 接 albumin、**不經尿排出**；結合型水溶 → 阻塞時尿呈深茶色。
- 成人黃疸是肝臟出問題的警訊（眼白變黃、皮膚黃褐色）。

## 🎙️ 上課錄影重點（陳顧中，Ch18-3 Ch22 後半，非同步遠距）
- 老師：**Ch22 是三章中國考出現率最低的一章**；本章由老師講胺基酸合成與含氮物（heme、porphyrin），**核苷酸部分「由下一個老師（期中考後）來講」**。很多胺基酸只在植物 / 細菌合成，「認真讀整個合成途徑是浪費時間」。
- 六個前驅物：**α-KG、pyruvate、OAA**（就是「三組人馬」，人體真正會合成的主要是這三類）、**3-phosphoglycerate**、PEP / E4P（同一類，不在人體合成）、**R5P**（His，與 PPP 有關）。
- **必需胺基酸口訣「3TLIPHMV」**：3 個 T（Thr、Trp、**Tyr**）、Leu、Ile、Phe、His、Met、Val。⚠️ **Tyr 有爭議**：人體不能從無到有，但可由 Phe 加一個 OH 轉來 → 新課本列為 **conditionally essential amino acid**（老師說若是出題老師不太敢考；營養系考過此名詞）。
- 合成去向對照：**α-KG → Glu、Gln、Pro、Arg**（與分解同一條；His 合成跑去 R5P）；**3-phosphoglycerate → Ser、Gly、Cys**（三者有親戚關係）；pyruvate → Ala（其餘三個是必需）；OAA → Asp、Asn（打星號的不在人體合成）。醫師國考：**Pro 主要由 glutamate 形成**（113 與今年考了幾乎一模一樣的題目）。合成時也是**轉胺（PLP）**。
- **Ser ⇄ Gly**（methylene-THF）；Gly → creatine、glyoxylate（植物）、glutathione、porphyrin、purine；Ser → **PS**；**Ser、Gly 分解走 pyruvate，但合成走 3-phosphoglycerate**。
- **Creatine 合成**：**Gly + Arg** + **SAM（AdoMet）給甲基** → creatine → creatine kinase → phosphocreatine；三個相關胺基酸：Gly、Arg、**Met**（SAM 來源）；在腎、肝製造 → 送肌肉。今年考題「arginine 合成相關敘述何者正確」：A「形成 nitric **dioxide**」錯（是 NO，「很惡劣」）；**B「Arg + Gly 轉甲基形成肌酸」正確**；C Arg + Tyr → melatonin 錯；D 只有 **L-form** 被吸收。
- **Cys**：Met → homocysteine →（**cystathionine β-synthase，轉硫，PLP**，Ser 參與）→ Cys → glutathione。**Taurine（牛磺酸，占體重 0.1%）**：最主要 → **膽鹽**；抗氧化、消除疲勞（提神飲料、紅牛，喝多效果遞減）。**膽鹽主成分：膽固醇 + glycine + taurine**（偶有 PC）。
- **芳香族胺基酸（Phe、Tyr、Trp，280 nm 吸光）**：近年考「合成中間產物是 **shikimate / chorismate**」→ **shikimic acid pathway**（人體不合成）。
- **Porphyrin（紫質）**衍生物：heme、葉綠素、藻膽素（海洋生物）、**cobalamin = B₁₂**（中間是**鈷**；heme 中間是**鐵**）。材料：**哺乳類 = glycine + succinyl-CoA**；植物 = glutamate。**ALA synthase（輔酶 PLP / B₆）** → δ-aminolevulinate → **pyrrole**（五碳環）→ 四個 pyrrole = porphyrin → + Fe = heme。醫師國考：**不易儲存、大多由尿排出的重要輔酶維生素 = B₁₂**。
- ⚠️ **Heme 合成開始在粒線體、中途到細胞質、最後回粒線體完成 → 答「在粒線體合成」**（同尿素循環、糖質新生跨兩區）。途中任一步驟錯誤 → **porphyria（紫質症）**。
- **Heme 分解（偏生理）**：**先脾後肝**；脾：heme →（**heme oxygenase**）→ **biliverdin** + Fe + **CO（考過）**（需 NADPH）→（**biliverdin reductase**）→ **bilirubin**；血中由 **albumin** 運送（albumin 也運 FFA）；肝：**UDP-glucuronyltransferase** 用 2 分子 **UDP-glucuronate** 糖化 → **bilirubin diglucuronide** 排到腸道 / 糞便（最終廢物形態考過）；腸道細菌 → **urobilinogen**。heme oxygenase 與 UDP-glucuronyltransferase 都考過國考，biliverdin reductase 還沒。
- **黃疸**：糖化反應不健全；新生兒黃疸（肝未成熟，一兩個月自行消失）；成人黃疸是肝臟出問題的警訊（肝受損不痛、痛時多已末期）——眼白變黃、皮膚黃褐色（不是曬黑）。
