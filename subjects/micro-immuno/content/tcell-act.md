# T 細胞活化與免疫細胞合作（依 113 共筆整理）

## 1. CD4 TH 分化（Signal 3 決定）⭐⭐⭐（共筆：「下圖必考」）
| 亞群 | 誘導 cytokine（APC） | 轉錄因子 | 分泌 | 功能 |
|---|---|---|---|---|
| **TH1** | **IL-12**、IFN-γ | T-bet | **IFN-γ**、IL-2、TNF | 活化 **M1 macrophage**、胞內病原 |
| **TH2** | **IL-4** | GATA3 | **IL-4、IL-5、IL-13**（IL-3、IL-9） | 寄生蟲、過敏；IL-4 → **IgE**；IL-5 → **eosinophil**；IL-13 → 黏液、平滑肌收縮；M2 macrophage |
| **TH17** | **TGF-β + IL-6**（IL-23、IL-21） | RORγt | **IL-17、IL-22** | 胞外細菌、真菌；IL-17 → G-CSF → **neutrophil**；IL-22 → 上皮更新 |
| **TFH** | IL-6、IL-21 | Bcl-6 | **IL-21**、IL-4 | 幫 B 細胞（germinal center） |
| **Treg** | **TGF-β**（at-RA） | **FoxP3** | **TGF-β、IL-10** | 抑制免疫、耐受 |

- 互相抑制：IFN-γ 抑制 TH2；IL-4 抑制 TH1；**IL-10 抑制 TH1**。
- 黏膜共生菌：平時 at-RA → pTreg；感染時 IL-6 → TH17。
- **IL-2**：T 細胞生長因子（自分泌），促 TH 增殖成熟。

## 2. CD8 CTL
- 活化：DC 直接（大量 B7）或 CD4 幫助 DC（**cross-priming**、CD40L、IL-2、4-1BB）。
- 在周邊只需 Signal 1；殺完立刻找下一個（serial killing）。
- 武器：**perforin**（打洞）、**granzymes**（→ BID→tBID、pro-caspase 3 → caspase 3 → ICAD 切開、CAD 切 DNA → apoptosis）、granulysin、**FasL**（最快，不經粒線體）；也分泌 IFN-γ、TNF-α、LT-α。
- ⚠️ **TGF-β 不是 CD8 毒殺用的分子**（Treg 分泌）。

## 3. B 細胞活化：TD vs TI 抗原
| | **TD（thymus-dependent）** | **TI（thymus-independent）** |
|---|---|---|
| 抗原 | **蛋白質（>90%）** | TI-1：**LPS**（polyclonal activator，高劑量非專一）；TI-2：重複多醣（莢膜） |
| Signal 2 | **TFH 的 CD40L ↔ B 的 CD40** + cytokines | TLR（TI-1）或 BCR 大量交聯（TI-2） |
| 結果 | class switch、affinity maturation、**memory**、IgG | **主要 IgM**、無記憶 |

- TD：B 細胞以 **MHC II** 呈現 peptide 給 TFH（signal 1 = BCR 結合抗原）；IL-21 → STAT3。
- 嬰兒對莢膜菌（肺炎鏈球菌）易感：B 細胞（TI-2 反應）尚未成熟。

## 4. Germinal center
- B 細胞與 T 細胞在 follicle 邊界相遇（CXCR5 / CCR7）→ 生發中心：**somatic hypermutation、class switch**、與 **FDC** 競爭抗原（affinity selection）；Bcl-2 表現下降（易凋亡、需被救）。
- **AID（activation-induced cytidine deaminase）**：C → U → SHM 與 class switch recombination（G-quadruplex 結構）。
- 產生 plasma cell 與 **memory B cell**（記憶的主要區域）。

## 5. Isotype (class) switch
- 只換 **constant region**、V region 不變（專一性不變）。
- **DNA 層級**：switch regions 重組（**Cδ 前沒有 switch region** → IgM/IgD 用 **RNA splicing**；membrane vs secreted form 也用 RNA 層級）。

| Cytokine | 誘導 isotype（小鼠為主） |
|---|---|
| **IL-4** | **IgG1、IgE** |
| **IFN-γ** | IgG3、IgG2a |
| **TGF-β** | IgG2b、**IgA** |
| IL-21 | IgG3、IgG1、IgA |
| **IL-5** | IgG1、**IgA** |

## 6. X-linked hyper-IgM syndrome
- **CD40L（CD154）缺陷**（T 細胞上）→ 無法 class switch → IgM 正常或升高、IgG/IgA/IgE 低；CD4 T 細胞數目**正常**；易反覆感染，亦可有自體免疫。

## 7. 抗體反應
- Primary：lag → log（先 IgM 後 IgG）→ plateau → decline。
- Secondary：lag 短、**IgG 為主**、親和力持續上升。

# 考點分析

## 🔥 高頻考點
1. **IL-12 → TH1**（考 4 次，還有複選組合版）。
2. **TH1 分泌 IFN-γ**；**TH2 不分泌 IL-12**。
3. **CD40L 缺陷 → hyper-IgM**；hyper-IgM「CD4⁺ T 數目下降」為錯。
4. **Class switch 需要 CD4 T 細胞**（考 2 次）。
5. **IL-4 → IgE**；IL-5 → IgA（依共筆表）；TGF-β + IL-6 → TH17。
6. **FasL 誘發 T 細胞凋亡**（考 2 次）；perforin 在靶細胞打洞。
7. **CTLA-4 結合 B7**；CD28 為 naïve T 的 second signal。
8. **Germinal center 是抗體記憶產生的主要區域**；「沒有 B 細胞凋亡」錯。
9. **TFH 主要分泌 IL-21**。
10. **TI 抗原產生 IgM**。
