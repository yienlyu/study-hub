# 正黏液病毒與副黏液病毒 內容整理（依百十四共筆整理、對照百十三共筆，陳玫潔）

> 📑 依百十四共筆 Ch48&49（115. Nov. 11，組長上傳區「副黏液病毒、正黏液病毒.pdf」）整理，輔以 2026 講義「1151 Orthomyxoviruses & Paramyxoviruses handout」；文末附百十三共筆（W10-1）對照。I'm@TMU 的兩段錄影還沒有逐字稿。

## 1. 兩科先分清楚 ⭐⭐⭐

兩科都是**有套膜、螺旋對稱、自帶 RNA 聚合酶的 (−) ssRNA 病毒**。

| | **正黏液病毒（Orthomyxoviridae）** | **副黏液病毒（Paramyxoviridae）**＋肺炎病毒科 |
|---|---|---|
| 代表 | **Influenza A、B、C**（上課只講 A、B） | **麻疹、腮腺炎、副流感**；RSV、hMPV（重分類到 **Pneumoviridae**） |
| 基因體 | **分段**：A、B **8 段**，C、D **7 段** | **不分段**（連續） |
| 複製位置 | **細胞核**（RNA 病毒的例外） | **細胞質** |
| 大小 | 較小（**110 nm**） | 較大（**150 nm**） |
| 表面棘突 | **HA 與 NA 在不同棘突** | **HA 與 NA 在同一棘突**（HN） |
| 巨細胞（syncytia） | **無** | **有**（F 蛋白） |
| 變異 | **drift（突變）＋shift（重組）** | 抗原穩定，感染一次多終身免疫 |

## 2. 流感病毒簡介與分類 ⭐⭐⭐

- 有套膜，**界面活性劑（detergent）可使其失活**。
- 正黏液病毒科共七屬，重點是會感染人的 Influenza A、B、C：

| 型 | 段數 | 特性 |
|---|---|---|
| **A** | 8 | **跨物種（人畜共通）**，常造成大流行 |
| **B** | 8 | **不跨物種**，常造成大流行 |
| **C** | 7 | 變異性低，不太會造成大流行 |
| **D** | 7 | 主要感染**牛** |

- 其他屬（Isavirus、Thogotovirus、Quaranjavirus）較少感染人，不重要。
- **變異性：A > B > C**；A 是人畜共通，所以會在動物身上發生 antigenic shift。
- 人類流感分型：**A 用 HA、NA 分亞型（subtype，如 H1N1、H3N2）**；**B 用 lineage（Victoria、Yamagata）**。之後的 clade、sub-clade **不用記**。

## 3. 流感病毒結構 ⭐⭐⭐

- **HA（hemagglutinin，H1–18）**：
  1. 黏附上皮細胞表面含**唾液酸（sialic acid）**的受體。
  2. 數字較小的較會感染人（所以常見 H1N1、H3N2）。
  3. 在**酸性環境**下促使套膜與 endosome **融合**。
  4. 凝集**人、雞、天竺鼠的 RBC**。
  5. 誘發**中和抗體**。
- **NA（neuraminidase，N1–11）**：
  1. **切斷宿主唾液酸與病毒的連接**，讓病毒離開細胞（**作用與 HA 相反**）。
  2. 數字小的較會感染人。
  3. **Zanamivir（Relenza）、oseltamivir（Tamiflu）的標的**：讓複製後的病毒無法傳播，**A、B 都有效**。
- **型別專一蛋白（type-specific，區分 A、B、C）**：
  - **M1（matrix）**：結構蛋白，與**組裝**有關。
  - **M2（membrane）**：形成**通道蛋白**、促進 **uncoating**、調控酸性環境促進 HA 生成；**amantadine 的標的**，只對 A 有效，**現在不用這個藥治療流感了**。
  - **NP（nucleocapsid protein）**。
- **RNA**：線性螺旋、負單股、**8 段**（C 7 段）；各段對應的蛋白表「參考即可」。

## 4. 流感病毒複製 ⭐⭐

1. **Binding**：HA 結合受體上的唾液酸 → **endocytosis** 形成 endosome。
2. **Uncoating**：**M2 產生酸性環境** → 套膜與 endosome 膜融合 → 釋出 RNA、**進入細胞核**。
3. **Transcription**：形成 mRNA；**cap snatching**：用 **cap-dependent endonuclease** 把宿主 mRNA 的 **5′ cap** 接到自己的 mRNA 上 → 離開細胞核。
4. **Protein synthesis**：用宿主核糖體；**HA、NA** 經 ER 修飾送到細胞膜；其餘蛋白（如 **RNAP：PB1、PB2、PA**）回細胞核組成 **vRNP**＝(−) RNA 片段＋**NP**＋**RNAP（RdRp）**。
5. **RNA replication**：(−) vRNA → (+) cRNA → 更多 (−) vRNA；等 RNAP 等蛋白進核結合後再出核。
6. **Assembly**：**M1** 組裝病毒，宿主細胞膜成為套膜；套膜上有 **HA、NA、M1、M2**。
7. **Budding**：**NA 切斷唾液酸與 HA 的連結** → 出芽離開，**導致細胞死亡**。

## 5. 流感的致病與免疫 ⭐⭐

- **致病機轉**：
  1. 先攻擊**黏膜上皮、纖毛上皮**等上皮細胞 → 破壞第一道防線。
  2. **NA 切斷黏液中的唾液酸殘基** → 病毒能感染其他組織（HA 負責一開始結合 target cell）。
  3. 優先從上皮細胞釋出、進入肺部，以 **cell-to-cell spread** 加速擴散。
  4. 擴散到下呼吸道 → **支氣管、肺泡上皮脫落**。
  5. 增加**細菌黏附**上皮的機會 → 續發肺炎。
- **典型 vs 非典型肺炎**（百十四補充）：

| | 典型肺炎 | 非典型肺炎 |
|---|---|---|
| 病原 | 細菌，**肺炎鏈球菌**最常見 | 黴漿菌、披衣菌、退伍軍人菌，以及病毒（SARS、COVID-19、流感） |
| 病程 | 急性、進展快、死亡率較高 | 漸進式，「**walking pneumonia**」，症狀較輕 |
| 症狀 | 高燒、劇咳、黃綠濃痰、喘、單側胸痛 | **乾咳**為主（可持續數週）、不一定高燒、全身非特異症狀、通常不流鼻水 |

- **免疫反應與症狀**：
  - **組織症狀**：monocyte、lymphocyte 發炎 → **黏膜下水腫**。
  - **全身性症狀**：來自 **IFN 與淋巴因子（lymphokines）**。
  - **局部症狀**：來自**上皮細胞受損**。
  - 痊癒靠 **IFN 與細胞免疫（NK、T 細胞）**；**抗體**負責預防日後感染 → 要打疫苗。
  - 症狀：呼吸道症狀、肌肉痠痛、高燒；**CNS 損傷**通常只在小孩、老人、免疫缺失者。
  - 續發細菌感染 → 開抗生素。
- **感染時間軸**（參考百十二共筆）：

| 天數 | 事件 |
|---|---|
| ~1 | 呼吸道分泌物出現病毒 |
| ~2 | 出現流感症狀 |
| 3–4 | 誘發 IFN |
| ~5 | CMI |
| ~7 | 細菌感染 |
| ~8 | 呼吸道明顯感染；血清與分泌物出現抗體 |

## 6. 抗原變異與命名 ⭐⭐⭐

| | **Antigenic drift** | **Antigenic shift** |
|---|---|---|
| 程度 | **小突變** | **大突變**（記法：Oh shift，代誌大條了） |
| 機制 | **HA、NA 基因**點突變 | 不同病毒株（可跨物種）**8 段 RNA 重組（reassortment）**，可能產生新種 |
| 頻率 | 高，**2–3 年**一次 | 不定期 |
| 結果 | **地區性** A、B 流行（年度 epidemic），各地區不同 | **全球大流行（pandemic）** |
| 型別 | **A、B** | **只有 A**（重組發生在豬等動物上） |

- **命名**：**類型／分離地點／株號／年份（HxNx）**；株號由研究團隊隨意取、不重要；**只有 A 有 subtype（HxNx）**，B 沒有。例：**A/Fujian/411/2002 (H3N2)**；動物株在類型與地點間加動物，如 **A/duck/Alberta/35/76**。
- **流行史重點**：
  - 病毒基因會重組 → 產生新種；常在**豬**體內重組（豬可同時感染人與鳥的病毒）。
  - **傳統市場活體販賣**促進感染。
  - **禽流感很少傳人**，只有零星個案；跨物種不容易，但**一旦人傳人可能造成嚴重大流行**。

## 7. 流感治療與疫苗 ⭐⭐⭐

| 藥物 | 標的 | 作用 | 範圍與備註 |
|---|---|---|---|
| **Amantadine、rimantadine** | **M2** | 抑制 **uncoating** | **只對 A**（B、C 無效）；現今不常用；amantadine 可促進多巴胺釋放，也用來治療**帕金森氏症** |
| **NA 抑制劑** | **NA** | 抑制病毒從感染細胞**釋出** | **A、B 都有效**；A 型感染前 **24–48 小時**內使用較有效（有症狀就及早投藥） |

| NA 抑制劑 | 給藥方式 |
|---|---|
| **Oseltamivir（克流感，Tamiflu）** | **口服**膠囊／懸浮液 |
| **Zanamivir（瑞樂沙，Relenza）** | **吸入**乾粉 |
| **Peramivir（瑞貝塔）** | **靜脈注射** |

- **疫苗**（**不活化疫苗**）：
  - 兩種製法：**福馬林失活的全病毒疫苗**；**界面活性劑處理的 HA 與 NA 萃取物**（不是完整病毒）。
  - **四價（2A2B）**：A(H1N1)、A(H3N2)、B/Victoria、B/Yamagata；**三價沒有 Yamagata**。
  - 可用傳統**雞蛋培養**或較新的**細胞培養**（穩定性較高）製造。
  - 每年流行株不同 → 疫苗廠依 **WHO 預測**製作；今年疫苗都會含 H1N1、H3N2、B/Victoria，Yamagata 通常不太變。
  - 今年疫苗株：

| | 雞蛋製程 | 細胞／重組製程 |
|---|---|---|
| H1N1 | A/Missouri/11/2025 (H1N1)pdm09 | A/Missouri/11/2025 (H1N1)pdm09 |
| H3N2 | A/Darwin/1454/2025 | A/Darwin/1415/2025 |
| B/Victoria | B/Tokyo/EIS13-175/2025 | B/Pennsylvania/14/2025 |
| B/Yamagata | B/Phuket/3073/2013 | B/Phuket/3073/2013 |

  - 台灣公費疫苗（講義）：**細胞培養**疫苗適合**對雞蛋過敏者**；**MF59 佐劑**疫苗用於 **> 65 歲**、保護力增加 10–20%。

## 8. 副黏液病毒總論 ⭐⭐

- **分類**：老師說有興趣再讀（分類依核酸親緣關係，沒有絕對邏輯）。
- **結構**：
  - **Helical nucleocapsid**：(−) ssRNA＋**N**（nucleoprotein，主要結構蛋白，形成保護性螺旋）＋**P**（phosphoprotein，聚合酶輔因子）＋**L**（large protein，**RdRp**）。
  - **M（matrix）**：連接 nucleocapsid 與套膜。
  - **套膜醣蛋白**：**F 蛋白（較小）**＋**附著蛋白（較大）**。
- **F 蛋白（fusion）**：負責膜融合，讓病毒與宿主結合，也讓細胞彼此融合成**多核巨細胞（syncytia）**；**水解成 F1、F2，以雙硫鍵相連**才活化。
- **附著蛋白**（類似正黏液病毒的 HA），可用來區分屬：

| 附著蛋白 | 病毒 | 特性 |
|---|---|---|
| **HN**（hemagglutinin-neuraminidase） | **腮腺炎、副流感**（已重分類為 Human rubulavirus 2、4 與 respirovirus 1、3） | HA 結合唾液酸與 RBC；NA 幫病毒離開、有助傳播 |
| **H**（hemagglutinin） | **麻疹** | 結合宿主細胞上的蛋白質受體 |
| **G**（glycoprotein） | **RSV、hMPV** | 結合受體，但**不屬於 hemagglutinin** |

- **P 蛋白**（上屆補充）：選擇性剪接可轉譯出 **V、C 蛋白**，幫病毒躲避先天性免疫。
- **複製**：**全部在細胞質**（與多數 (−) RNA 病毒相同；正黏液病毒在核內是例外）；RNA 聚合酶隨 nucleocapsid 帶入細胞。
  1. 附著蛋白結合受體 → **F 蛋白**協助 fusion 進入。
  2. Genome 在 **L、P** 幫忙下轉錄出 mRNA 與全長 (+) RNA 模板 → 複製出新的 (−) genome。
  3. 新 genome 與 L、N、P 組成 helical nucleocapsid → 與 **M** 在帶病毒醣蛋白的細胞膜上結合。
  4. **出芽**離開，**不會殺死宿主細胞**。

## 9. 麻疹（Measles）⭐⭐⭐

- **病原**：*Measles morbillivirus*，**只有一種血清型**；**人是唯一宿主**；**飛沫**傳播；潛伏期 1–2 週（約 **14 天**）。
- **侵襲率 > 90%**，傳染力極強，**R0 超大（一人可傳 15 人）**；康復後**終身免疫**。
- 補充（百十二）：五種典型兒童出疹疾病之一（另四種：德國麻疹、玫瑰疹、第五病、水痘）。
- **疫苗**：安全、具成本效益，一歲時接種尤佳；疫苗覆蓋率低的地區仍流行且致死率高，多是 5 歲以下。
- **致病機轉**：飛沫 → 上呼吸道上皮局部複製 → 感染 **monocyte、lymphocyte**，經淋巴與血液造成 **viremia** → 全身散播（結膜、泌尿道、小血管、CNS）→ **T cell 攻擊受感染的內皮細胞** → **斑丘疹（maculopapular rash）**。
- 結果：大部分感染受控並終身免疫；罕見情況在一段時間後出現神經併發症。
- **神經併發症** ⭐⭐⭐：

| | 宿主 | 通常感染年齡 | 腦中有病毒 | 發生率 | 病理 | 病程 |
|---|---|---|---|---|---|---|
| **ADEM** | 正常 | **> 2 歲** | **無** | 1:1000 | 發炎、**脫髓鞘** | 數週（一次性） |
| **MIBE** | **免疫抑制** | 不限 | 有 | 無數據 | 包涵體 | 數月（漸進） |
| **SSPE** | 正常 | **< 2 歲** | 有 | 1:10⁶ | 包涵體、發炎 | **數年**（漸進） |

  - **AME（acute measles encephalitis）**：急性期病毒進 CNS，約在出疹期。
  - **ADEM**：發炎導致脫髓鞘，造成癲癇。
  - **MIBE**：病毒以 fusion 做 cell-to-cell 傳播、躲避抗體 → 需 T 細胞清除；**CMI 缺陷**者可能致死，表現為非典型的 **giant cell pneumonia without a rash**。
  - **SSPE**：**最嚴重**；通常兩歲前染病，**多年後發作**；病毒以 cell fusion 在腦神經細胞間擴散、不進血液、躲避抗體；人格、行為、認知、記憶改變，可能失明、痙攣、昏迷、死亡。
- **症狀**：
  - 潛伏期 14 天。
  - **前驅期 2–4 天（最具傳染力）**：**高燒＋CCC：咳嗽（cough）、鼻炎（coryza）、結膜炎（conjunctivitis）**。
  - **Koplik spots（重要）**：前驅期約 2 天後出現的**黏膜潰瘍**（口腔、結膜、陰道），持續 24–48 小時。
  - **紅疹**：Koplik spots 後 12–24 小時出現，**從耳下開始**，1–2 天蓋滿全身＝**cephalocaudal spread（頭尾擴散）**；出疹當天燒最高、病情最重。
  - **肺炎**：麻疹死因的 **60%**；營養不良者更易死亡；常續發細菌感染。
  - **腦炎**：0.5%，致死率 15%，可能演變成 SSPE。
- **「免疫失憶」**：麻疹會讓之前打過的疫苗失效 —— 降低**記憶 B 細胞多樣性**（殺掉針對其他病原的 B 細胞，換成麻疹專一的）；也降低骨髓中的 **naïve B 細胞**。
- **診斷**：臨床（病史、**Koplik spots**）；**鼻咽拭子**、呼吸道分泌物、尿液、血液、腦組織檢體；**RT-PCR**；血清學 **IgM（發病 4–60 天，正在感染）**、IgG（> 60 天，曾感染）。
- **流行病學**：出現病徵前就有傳染力；好發**秋冬**；**MMR**（活性減毒三合一）約一歲打第一劑；高危險群：**5 歲以下、未接種、免疫缺失、營養不良（特別是維生素 A 缺乏）**。

## 10. 腮腺炎（Mumps）⭐⭐

- 套膜、不分段 (−) ssRNA；表面 **HN**（附著）＋**F**（融合）。
- 好發 **5–15 歲**，投影片指出**男性**較多；感染後多有持久免疫；嬰兒有母體抗體約 **6 個月**被動免疫。
- **傳染源：唾液**；途徑：飛沫、直接接觸、汙染物；**潛伏期 12–26 天**；**腮腺腫脹前 1–6 天到腫脹後約一週**具傳染力。
- **致病**：呼吸道局部複製 → **viremia** → 全身感染（**腮腺、睪丸、卵巢、胰臟、內耳**、周邊神經、CNS）；在**腮腺導管上皮**複製 → 腫脹（腮腺導管＝**Stensen's duct**）。
- **臨床**：單側或雙側**腮腺炎（parotitis）**、耳痛、張口疼痛僵硬；發燒、頭痛、倦怠 3–5 天。
- **併發症**：**睪丸炎／卵巢炎**（重要）、**胰臟炎**、**腦膜腦炎**、心肌炎、**神經性耳聾**；少見：多關節炎、水腦症。
- **檢測**：病程中可從**口腔分泌物、尿液**檢出病毒；CNS 感染可在 **CSF** 檢出；後期出現病毒專一抗體。
- **治療**：**沒有特效藥**，支持療法；**止痛藥**；投影片列 **prednisolone** 治療睪丸炎（共筆註：不宜視為現行常規）。
- **預防**：**MMR 活性減毒疫苗**（Edmonston-Zagreb 麻疹、L-Zagreb 腮腺炎、Wistar RA 27/3 德國麻疹）；**12 個月後**第一劑，**4–6 歲**（或 12 歲前）第二劑。

## 11. 副流感病毒（HPIV）⭐⭐

- 套膜、螺旋核殼、不分段 (−) ssRNA；**HN＋F**。
- 與腮腺炎不同，**感染侷限於呼吸道**；飛沫、接觸傳染；好發嬰幼兒。
- **四型**：

| 型 | 重點 |
|---|---|
| **HPIV-1** | **哮吼（croup）**的常見病原；也造成其他上、下呼吸道感染 |
| **HPIV-2** | **急性喉氣管支氣管炎**（croup） |
| **HPIV-3** | 兒童**細支氣管炎、肺炎**；**最常與中耳炎相關** |
| **HPIV-4** | 呼吸道感染；分 **4a、4b** |

- **臨床**：上、下呼吸道感染；約佔呼吸道感染 **10%**；代表疾病 **croup**（喉、氣管發炎 → 上呼吸道狹窄）：**犬吠樣咳嗽（barking cough）、聲音沙啞、吸氣性喘鳴（inspiratory stridor）**；另有支氣管炎、細支氣管炎、肺炎，以及中耳炎、咽炎、結膜炎、鼻炎。
- **高風險**：嬰幼兒；**免疫抑制（如器官移植）**者可能發生**致命肺炎**。
- **季節性依血清型而定**。
- **診斷**：病毒培養、**RT-PCR**。
- **治療**：無專一抗病毒藥，支持療法、監測呼吸道；依嚴重度用**類固醇**，中重度可霧化 **epinephrine**；投影片提冷熱蒸氣霧化（共筆註：證據不支持常規使用）；少數需**插管**；**ribavirin** 極少用。**沒有疫苗**。

## 12. 呼吸道融合病毒（RSV）⭐⭐⭐

- 原屬副黏液病毒科，重分類到**肺炎病毒科（Pneumoviridae）**（與 hMPV 同科）。
- 飛沫、接觸、汙染物傳染；**嬰兒**發病與死亡率高，**2 歲以下**較嚴重；高風險：**先天心肺疾病**的嬰幼兒；**老年人**的發病與死亡率可與流感相當。
- 症狀似感冒（流鼻水、發燒、咳嗽），呼吸有**哮鳴聲（wheezing）**；暴露約一週後發病，發病後很快具傳染力 → **家中有兄弟姊妹**易互傳。
- 美國 CDC：**2 歲前幾乎都感染過**；25–40% 有支氣管炎或肺炎；0.5–2% 需住院。
- **診斷**：**快篩**呼吸道分泌物（確認 RSV、排除細菌）；**A 型株造成重症**，B 型株多無症狀、多數人感染過；**鼻咽分泌物（含上皮細胞）可見細胞融合形成巨細胞**。
- **治療**：輕症支持療法（退燒、止咳）；重症監測血氧、給氧、霧化食鹽水化痰、抽痰、呼吸器；**ribavirin aerosol**；嚴重時 IGIV 搭配 **RSV-IGIV（Synagis）** 或 ribavirin（Virazole）；約 1–2 週康復。藥名字尾 **-mab** 是抗體藥物。
- **預防**：洗手；高風險族群流行季預防性打 **RSV 抗體（palivizumab）**；有症狀的學齡手足遠離 2 歲以下嬰兒；避免人群與訪客；打流感疫苗（感染時可排除流感）。
- **RSV 疫苗**：國內核准 **3 種**（基因重組、mRNA）；新生兒與高風險嬰兒接種**抗體**（被動免疫）；經醫師評估**自費 1 劑**疫苗（主動免疫）：**≥ 75 歲**、**60–74 歲高危險群**（慢性肺、心血管、肝、腎病，長照機構住民）、**懷孕 28–36 週孕婦**（嬰兒出生至 6 個月被動免疫；**只能打艾沛兒**）。
- **健保全額給付 RSV 單株抗體**（全國）：**未滿 31 週早產兒**、**≤ 35 週合併慢性肺病早產兒**、**嚴重先天性心臟病**嬰幼兒。另有縣市補助（臺北、新北、花蓮雙軌；桃園、臺南、雲林補助孕婦疫苗）。
- 共筆另引百十二的 2022 兒科醫學會聲明：當時健保給付對象是未滿 **33 週**早產兒、≤ 35 週合併慢性肺病、一歲以下先心病童，一歲前每月一劑、最多 6 劑（舊標準，以上一條為準）。

## 13. 人類間質肺炎病毒（hMPV）與免疫負債 ⭐

- **hMPV**：呼吸道傳染；無症狀或感冒，嚴重者支氣管炎、肺炎；佔孩童感冒 **15%**；**≤ 5 歲**最多，**5–16%** 發展成下呼吸道感染（「killer pneumonia」）；診斷 **RT-PCR**。
- **免疫負債（immunity debt）**：COVID-19 期間居家隔離 → 病原循環減少、疫苗接種率下降 → 免疫刺激減少、易感族群比例上升 → 疫苗可預防疾病再流行風險增加（新冠、流感、RSV、hMPV、肺炎鏈球菌、腺病毒）。這是族群免疫缺口的描述，不是個體免疫變差的證據，用語仍有爭議。
- **Tripledemic**（講義）：COVID-19、流感、RSV 同時流行。

## 百十三共筆對照

- **流感 segment 對應蛋白表**：百十三有文字版（PB2 cap recognition、PB1 elongation、PB1-F2 促細胞凋亡、PA cap snatching、PA-X、M42 可取代 M2、**NS1 是干擾素拮抗蛋白**、NS2/NEP 調控 RNP 出核、NS3 與適應新宿主有關），標「參考就好」；百十四同樣標「參考即可」。

- **流感藥**：百十四另補 **peramivir（靜注）**與三種 NA 抑制劑給藥方式，以及 amantadine 治帕金森氏症；百十三沒有。
- **副黏液病毒分類**：百十三附完整分類表 —— 麻疹屬（Orthoparamyxovirinae）、腮腺炎病毒亞科 Rubulavirinae（腮腺炎、HPIV-2、4）、Respirovirus（HPIV-1、3）、肺炎病毒科（Orthopneumovirus：RSV；Metapneumovirus：hMPV）。
- **麻疹**：
  - 前驅症狀百十三寫 **CCC＋P（畏光，photophobia）**。
  - 百十三註 **SSPE 的病毒變成 defective form**，不積極複製但仍造成病理變化；並註神經併發症的發生順序是表格由上往下。
  - 百十三附 WHO 數據：2017 年全球 11 萬人死於麻疹；2000–2016 年疫苗讓死亡下降 84%、預防約 2,040 萬例死亡。
- **腮腺炎**：
  - 百十三寫潛伏期 12–26 天「比麻疹長」。
  - 百十三寫生殖腺受侵犯**可能造成不孕**；**胰臟感染（重要）可能導致第一型糖尿病**。
  - 百十三寫無有效藥物、**症狀通常一到兩週消失**。
  - MMR：百十三寫一歲後第一劑、十二歲前第二劑，**保護力 88%**（參考百十二）。
- **副流感**：
  - 百十三寫 **HPIV-1（Sendai virus）是 croup 最常見原因**；1、3 同屬，2、4 同屬。
  - 季節性：百十三寫 **HPIV-1 四季可見、HPIV-2、4 常見於秋冬**。
  - 中耳炎：百十三另註**最常併發中耳炎的是肺炎鏈球菌**（參考 108 共筆）。
  - 診斷另列 **X 光**監測 croup 氣道狹窄。
  - 治療：百十三寫蒸氣治療可改善發炎黏膜；百十四註證據不支持常規使用，另補類固醇、霧化 epinephrine。
- **RSV**：百十三寫孕婦接種沒有週數限制、也沒有「只能打艾沛兒」；沒有縣市補助與 31 週的健保給付標準。

# 考點分析

## 🔥 高頻考點

- **流感病毒在細胞核複製**、**分段** (−) RNA（A、B 8 段，C 7 段）；副黏液病毒**不分段**、在細胞質。
- **HA vs NA** 功能；**drift vs shift**（shift 只有 A 型、造成大流行）。
- **抗流感藥標的**：amantadine → **M2**（只 A）；oseltamivir、zanamivir → **NA**（A、B）。
- **Cap-snatching**。
- **附著蛋白**：HN（腮腺炎、副流感）、H（麻疹）、G（RSV）。
- **麻疹**：三 C、**Koplik spots**、頭到腳紅疹、**SSPE**、免疫失憶。
- **腮腺炎併發症**：睪丸炎、胰臟炎、腦膜腦炎、耳聾。
- **HPIV-1、2 → 哮吼（croup）**、HPIV-3 → 細支氣管炎、肺炎、中耳炎；**RSV 是嬰兒致命呼吸道感染最常見原因**、palivizumab、ribavirin。
- **MMR 是活性減毒疫苗**；流感疫苗是不活化疫苗。

## 📝 出題模式

- 「哪一種 RNA 病毒在細胞核內複製？」→ Influenza。
- 「造成流感大流行的機制」→ antigenic shift（reassortment）。
- 「Oseltamivir 的作用機轉」→ 抑制 neuraminidase，阻止病毒釋出。
- 「兒童發燒、咳嗽、鼻炎、結膜炎，頰黏膜白點，紅疹由臉往下擴散」→ 麻疹。
- 「青春期男性腮腺腫大後睪丸疼痛」→ 腮腺炎。
- 「嬰兒細支氣管炎，細胞培養見融合細胞」→ RSV。
- 「幼兒犬吠樣咳嗽（croup）最常見病原」→ HPIV-1。
