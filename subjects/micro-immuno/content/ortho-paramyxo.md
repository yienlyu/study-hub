# 正黏液病毒與副黏液病毒 內容整理（依今年講義與百十三共筆整理，陳玫潔）

> 📑 依 2026 講義「1151 Orthomyxoviruses & Paramyxoviruses handout」（69 頁）與百十三共筆 W10-1（Ch48&49）整理。I'm@TMU 已有兩段錄影（1151 Orthomyxoviruses & Paramyxoviruses-1、-2），但還沒有逐字稿；百十四共筆也還沒上傳。

## 1. 兩科先分清楚 ⭐⭐⭐

| | **Orthomyxoviridae（正黏液病毒）** | **Paramyxoviridae（副黏液病毒）**＋Pneumoviridae |
|---|---|---|
| 代表 | **Influenza A、B、C**（D 主要感染牛） | **麻疹、腮腺炎、副流感**；RSV、hMPV（肺炎病毒科） |
| 基因體 | **(−) ssRNA、分段**：A、B **8 段**，C（與 D）**7 段** | **(−) ssRNA、不分段** |
| 外觀 | 有套膜、螺旋核殼；界面活性劑可使其失活 | 有套膜、螺旋核殼 |
| 複製位置 | **細胞核**（RNA 病毒的特例） | 細胞質 |
| 表面蛋白 | **HA**（H1–18）＋**NA**（N1–11）分開 | **F 蛋白（融合）**＋附著蛋白（**HN／H／G**） |
| 變異 | **drift（突變）＋shift（重組）** | 抗原穩定，感染一次多終身免疫 |

## 2. 流感病毒分類與變異 ⭐⭐⭐

- 屬：*Alphainfluenzavirus*（A，**人畜共通**）、*Beta*（B）、*Gamma*（C）、*Delta*（D，牛）；另有 Isavirus、Thogotovirus（人可感染，Dhori、Bourbon virus，**壁蝨**傳播）、Quaranjavirus。
- **變異性：A > B > C**。
- 人類流感分類：**A 用 HA／NA 分亞型（subtype）**（如 H1N1、H3N2）；**B 用 lineage**（Victoria、Yamagata）。之後的 clade、sub-clade（百十三：不用記）。
- **抗原變異**：

| | **Antigenic drift** | **Antigenic shift** |
|---|---|---|
| 程度 | **小變化** | **大變化** |
| 機制 | HA、NA 基因**點突變** | 不同病毒株（含動物株）**基因體分段重組（reassortment）** |
| 頻率 | 每 **2–3 年** | 不定期 |
| 結果 | **地區性流行（年度 epidemic）** | **全球大流行（pandemic）** |
| 型別 | **A、B** | **只有 A**（**B 沒有 shift**） |

- 百十三共筆：豬可同時感染人類與鳥類的流感病毒 → 在豬體內重組出新病毒；傳統市場活體販售促進感染；禽流感很少傳人，只有零星個案。
- **命名**：型別／分離地點／株號／年份（HxNx，只有 A 有亞型）；動物株在型別後加宿主，例：**A/duck/Alberta/35/76 (H1N1)**、**A/Hong Kong/156/97 (H5N1)**（禽傳人）；2013–14 中國 **H7N9** 禽流感。

## 3. 流感病毒結構 ⭐⭐⭐

- **HA（hemagglutinin，H1–18）**：
  1. **病毒附著蛋白**：結合上皮細胞受體上的**唾液酸（sialic acid）**。
  2. 在**酸性 pH** 下促進套膜與細胞膜（endosome）**融合**。
  3. 凝集**人、雞、天竺鼠的紅血球**。
  4. 誘發**保護性中和抗體**。
- **NA（neuraminidase，N1–11）**：有**酵素活性**，**切斷**醣蛋白與細胞受體上的唾液酸 → 防止病毒聚集、**幫助病毒從感染細胞釋出**。是 **zanamivir（Relenza，瑞樂沙）**、**oseltamivir（Tamiflu，克流感）**的標的，**A、B 型都有效**。
- 型別專一蛋白（用來區分 A、B、C）：
  - **M1（matrix）**：結構蛋白，連接核殼與套膜、促進組裝。
  - **M2（membrane）**：形成**離子通道**，幫助 **uncoating** 與 HA 生成；**amantadine 的標的**（只對 A 型有效，B 型無預防效果）。
  - **NP（nucleocapsid protein）**。
- **vRNP**：一段 (−) vRNA＋NP＋RNA 聚合酶複合體（**RNAP：PB1、PB2、PA**）。

## 4. 流感病毒複製 ⭐⭐

1. **附著**：HA 結合唾液酸 → endocytosis 進入。
2. **Uncoating**：M2 使 endosome 內酸化 → HA 介導套膜與 endosome 膜融合 → vRNP 釋出、**進入細胞核**。
3. **轉錄**：**cap-snatching**：PA 的 **cap 依賴性核酸內切酶**從宿主 mRNA 切下 5′ cap（m7GpppXm）當引子，接到病毒 mRNA 上。
4. 轉譯：HA、NA、M2 經 ER 修飾送到細胞膜；RNAP、NP 回到細胞核組成 vRNP。
5. **複製**：(−) vRNA → (+) cRNA → 更多 (−) vRNA（都在細胞核）。
6. **組裝**：M1 把 vRNP 帶到細胞膜。
7. **出芽**：從**細胞膜**出芽；**NA 切斷唾液酸與 HA 的連結**讓病毒離開。

## 5. 流感的致病與免疫 ⭐⭐

- 病毒先攻擊並殺死**分泌黏液的纖毛上皮細胞** → 失去第一道防線。
- **NA 切斷黏液中的唾液酸** → 病毒得以接觸組織。
- 病毒優先從上皮細胞**頂端**釋出、進入肺 → 細胞間擴散與傳給他人。
- 擴散到**下呼吸道** → 支氣管、肺泡上皮脫落。
- **促進細菌附著上皮 → 續發細菌性肺炎**。
- 組織學：黏膜發炎（主要是**單核球與淋巴球**）、黏膜下水腫。
- **全身症狀（發燒、倦怠、頭痛、肌痛）來自干擾素與淋巴激素反應**；局部症狀來自上皮受損。
- **干擾素與細胞免疫（NK、T 細胞）**負責痊癒（也造成症狀）；**抗體**負責預防日後感染 → 要打疫苗。
- 時間軸（百十三共筆）：約第 1 天分泌物出現病毒、第 2 天出現症狀、第 3–4 天干擾素、第 5 天 CMI、第 7 天前後可能續發細菌感染、約第 8 天血清與分泌物出現抗體。

## 6. 流感治療與疫苗 ⭐⭐⭐

| 藥物 | 標的 | 作用 | 範圍 |
|---|---|---|---|
| **Amantadine、rimantadine** | **M2** | 抑制 **uncoating** | **只有 A 型**（對 B、C 無效） |
| **Zanamivir（Relenza）、oseltamivir（Tamiflu）** | **NA** | 阻止病毒**從感染細胞釋出** | **A、B 型都有效**；可預防；A 型發病 **24–48 小時內**使用才有效 |

- **控制病毒最好的方法是疫苗**：
  - **不活化疫苗**，使用「**當年流行株**」：福馬林不活化全病毒疫苗，或界面活性劑處理的病毒顆粒、含 HA 與 NA 的萃取物。
  - 建議對象：**老人**、慢性肺病或心臟病患者。
  - **四價疫苗**：A(H1N1)pdm09、A(H3N2)、B/Victoria、B/Yamagata（多一個 B lineage）；講義列出 2026–2027 雞蛋製程與細胞／重組製程的疫苗株。
  - 台灣公費疫苗（講義）：**細胞培養**疫苗適合**對雞蛋過敏者**、病毒變異性低；**MF59 佐劑**疫苗保護力增加 10–20%，用於 **> 65 歲**。

## 7. 副黏液病毒總論 ⭐⭐

- **(−) ssRNA**、套膜、螺旋核殼。
- **F 蛋白（fusion）**：細胞膜融合 → 形成**多核巨細胞（syncytia）**。
- **附著蛋白**分三種，可用來分屬：

| 附著蛋白 | 病毒 | 活性 |
|---|---|---|
| **HN**（hemagglutinin-neuraminidase） | **腮腺炎、副流感** | 凝血＋神經胺酸酶 |
| **H**（hemagglutinin） | **麻疹** | 只有凝血 |
| **G**（glycoprotein） | **RSV、hMPV** | 兩者皆無 |

- 分類（百十三共筆：老師跳過）：麻疹屬 *Morbillivirus*（麻疹）、*Rubulavirus*（腮腺炎、HPIV-2、4）、*Respirovirus*（HPIV-1、3）；RSV、hMPV 在**肺炎病毒科（Pneumoviridae）**。

## 8. 麻疹（Measles，Rubeola）⭐⭐⭐

- 病原：*Measles morbillivirus*；**只感染人**；**飛沫**傳播；潛伏期 1–2 週（約 **14 天**）；**侵襲率 > 90%**（高度傳染）；**感染一次終身免疫**。
- WHO（2018）：2017 年全球仍有 11 萬人死於麻疹，多是五歲以下；2000–2016 年疫苗使麻疹死亡下降 84%、救了約 2,040 萬人。
- 病毒經呼吸道 → **單核球／淋巴球**擴散全身 → **斑丘疹（maculopapular rash）**。
- **症狀**：發燒、**三 C：咳嗽（cough）、鼻炎（coryza）、結膜炎（conjunctivitis）**、倦怠（「miserable」）；**Koplik spots**（口腔頰黏膜）；**紅疹由頭往腳（cephalocaudal）擴散**。
- **傳染期**：出現症狀前 1 天到出疹後 5 天。
- **三種神經併發症**：**ADEM**（急性瀰漫性腦脊髓炎）、**MIBE**（麻疹包涵體腦炎）、**SSPE**（亞急性硬化性全腦炎，與**缺陷型病毒**有關）。
- **診斷**：臨床（**Koplik spots 是特徵性的 pathognomonic**）、鼻咽拭子培養、**RT-PCR**、血清學（**IgM 在發病第 4–60 天陽性**，之後 IgG）。
- **「免疫失憶」**：麻疹病毒攻擊**記憶 B 細胞** → 殺掉對其他病原的記憶 B 細胞、骨髓 naïve B 細胞多樣性也下降（像胎兒） → 未打疫苗的小孩感染後**對以前得過的病原又變得易感**（Science 2019、Sci Immunol 2019）。

## 9. 腮腺炎（Mumps）⭐⭐

- 好發 **5–15 歲**、**男性**較多；**感染一次終身免疫**；被動免疫可維持到 **6 個月**。
- 保毒：病人**唾液**；傳染：直接接觸飛沫、汙染物。**潛伏期 12–26 天**；腫脹前 1–6 天到之後一週都具傳染力。
- 臨床：單側或雙側**腮腺**疼痛腫脹（腮腺管 Stensen duct）、耳痛、張口痛；發燒、頭痛 3–5 天。
- **併發症**：**睪丸炎／卵巢炎**、**胰臟炎**、**腦膜腦炎**、心肌炎、**神經性耳聾**、多關節炎、水腦。
- 治療：止痛；睪丸炎用 prednisolone。預防：**MMR 疫苗**。
- **MMR**：**活性減毒**疫苗（Edmonston-Zagreb 麻疹、L-Zagreb 腮腺炎、Wistar RA 27/3 德國麻疹）；**> 12 個月**打第一劑，**4–6 歲**第二劑。

## 10. 副流感病毒（HPIV）⭐⭐

- **四型**：
  - **HPIV-1**（Sendai virus，*Respirovirus*）：**哮吼（croup）最常見原因**。
  - **HPIV-2**（*Rubulavirus*）：急性喉氣管支氣管炎（croup）。
  - **HPIV-3**（*Respirovirus*）：兒童**細支氣管炎與肺炎**；**最常與中耳炎相關**。
  - **HPIV-4**（4a、4b）：呼吸道感染。
- **只侷限在呼吸道**：上呼吸道感染、支氣管炎、**喉氣管支氣管炎（croup）**；約佔 **10%** 的呼吸道感染；也常造成中耳炎、咽炎、結膜炎、鼻炎。
- 季節性依血清型而不同；**免疫低下者（如移植病人）**可能造成致命肺炎。
- 診斷：培養、**RT-PCR**。治療：冷或熱蒸氣霧化、小心監測哮吼兒童的呼吸道、少數需插管或 **ribavirin**。**沒有疫苗**。

## 11. 呼吸道融合病毒（RSV）⭐⭐⭐

- **嬰兒致命性呼吸道感染最常見的原因**；全世界兒童罹病與死亡負擔大；在**老年人**的罹病與死亡和流感相當。
- CDC：幾乎所有兒童**2 歲前**都感染過，只有 25–40% 出現細支氣管炎或肺炎，其中 0.5–2% 需住院。
- 細胞培養可見**融合細胞（syncytia）**。
- 兩株：**A 株造成嚴重病例**；B 株多無症狀、多數人都被傳染過。
- **診斷**：呼吸道分泌物檢驗可確認 RSV、排除細菌感染；嚴重病例需要**含上皮細胞的鼻咽分泌物**；**快速免疫層析法**。
- **治療**：輕症只給退燒藥；重症給氧氣、吸入治療、抽痰、呼吸器；**ribavirin 霧化**；有時合併 **RSV-IGIV**（如 Synagis）。痊癒約 1–2 週。
- **預防**：勤洗手；高危險兒童在流行季**每月注射 RSV 抗體（palivizumab，Synagis）**；有感冒症狀的學齡兒童遠離 2 歲以下手足；減少訪客、避開人潮、流行季盡量不送托嬰；打流感疫苗。
- **台灣 RSV 疫苗（講義）**：核准 3 種（基因重組、mRNA），自費 1 劑：**≥ 75 歲**、**60–74 歲高危險群**、**懷孕 28–36 週孕婦**（讓嬰兒出生到 6 個月內有被動免疫）。**健保給付 RSV 單株抗體**：未滿 31 週早產兒、≤ 35 週合併慢性肺病早產兒、嚴重先天性心臟病嬰幼兒；部分縣市另有孕婦疫苗或嬰兒單株抗體補助。

## 12. 人類間質肺炎病毒（hMPV）⭐

- **呼吸道**傳播；無症狀、普通感冒、細支氣管炎、肺炎；佔兒童普通感冒約 **15%**；**5 歲以下**最多，5–16% 發展成下呼吸道感染。診斷：**RT-PCR**。

## 13. Tripledemic 與免疫負債 ⭐

- **Tripledemic**：COVID-19、流感、RSV 同時流行。
- **免疫負債（immunity debt）**：COVID-19 期間的非藥物介入（口罩等）減少了各種病原的傳播，加上疫苗接種延遲 → 缺乏免疫刺激，易感族群增加 → 疫情解封後反彈（新冠、流感、RSV、hMPV、肺炎鏈球菌、腺病毒）。

## 百十三共筆對照

- **Influenza A／B／C／D 段數**：百十三表格寫 A、B 8 段；C、D 7 段（講義只標 C 是 7 段）。百十三另寫「B 不跨物種，常造成大流行」「C 變異性低，不太會造成大流行」。
- **Amantadine**：百十三寫「現在不用這個藥治療流感了」。
- **疫苗**：百十三寫三價疫苗沒有 Yamagata；四價是 2A2B。今年講義列的 2026–2027 疫苗仍是四價（含 B/Phuket Yamagata）。
- **流感 segment 對應蛋白表**（PB2、PB1、PA、HA、NP、NA、M1／M2、NS1／NS2）：百十三參考百十二共筆附上，標註「參考就好」；NS1 是干擾素拮抗蛋白。
- **副黏液病毒結構**：百十三補充 N（核蛋白）、P（聚合酶輔因子）、L（RdRp）、M 蛋白；F 蛋白水解成 F1、F2 以雙硫鍵相連才活化。
- **副黏液病毒分類**：百十三註明老師上課跳過。

# 考點分析

## 🔥 高頻考點

- **流感病毒在細胞核複製**、**分段** (−) RNA（A、B 8 段，C 7 段）；副黏液病毒**不分段**、在細胞質。
- **HA vs NA** 功能；**drift vs shift**（shift 只有 A 型、造成大流行）。
- **抗流感藥標的**：amantadine → **M2**（只 A）；oseltamivir、zanamivir → **NA**（A、B）。
- **Cap-snatching**。
- **附著蛋白**：HN（腮腺炎、副流感）、H（麻疹）、G（RSV）。
- **麻疹**：三 C、**Koplik spots**、頭到腳紅疹、**SSPE**、免疫失憶。
- **腮腺炎併發症**：睪丸炎、胰臟炎、腦膜腦炎、耳聾。
- **HPIV-1 是哮吼最常見原因**；**RSV 是嬰兒致命呼吸道感染最常見原因**、palivizumab、ribavirin。
- **MMR 是活性減毒疫苗**；流感疫苗是不活化疫苗。

## 📝 出題模式

- 「哪一種 RNA 病毒在細胞核內複製？」→ Influenza。
- 「造成流感大流行的機制」→ antigenic shift（reassortment）。
- 「Oseltamivir 的作用機轉」→ 抑制 neuraminidase，阻止病毒釋出。
- 「兒童發燒、咳嗽、鼻炎、結膜炎，頰黏膜白點，紅疹由臉往下擴散」→ 麻疹。
- 「青春期男性腮腺腫大後睪丸疼痛」→ 腮腺炎。
- 「嬰兒細支氣管炎，細胞培養見融合細胞」→ RSV。
- 「幼兒犬吠樣咳嗽（croup）最常見病原」→ HPIV-1。

## ⚠️ 易混點

| 容易選錯 | 正確 |
|---|---|
| ✗ 所有 RNA 病毒都在細胞質複製 | ✓ **流感病毒在細胞核**轉錄與複製 |
| ✗ Influenza B 也會 antigenic shift | ✓ **shift 只有 A**；B 只有 drift |
| ✗ Amantadine 對 A、B 都有效 | ✓ Amantadine（M2）**只對 A**；NA 抑制劑才對 A、B 都有效 |
| ✗ NA 負責病毒附著 | ✓ **HA** 附著唾液酸；**NA** 切唾液酸幫病毒**釋出** |
| ✗ 副黏液病毒基因體分段 | ✓ 副黏液病毒**不分段**；分段的是流感 |
| ✗ 麻疹病毒的附著蛋白是 HN | ✓ 麻疹是 **H**（沒有 NA 活性）；HN 是腮腺炎、副流感；RSV 是 **G** |
| ✗ MMR 是不活化疫苗 | ✓ MMR 是**活性減毒**；流感疫苗是**不活化** |
| ✗ RSV B 株造成重症 | ✓ **A 株**造成重症 |
| ✗ 哮吼最常見原因是 HPIV-3 | ✓ **HPIV-1**；HPIV-3 是細支氣管炎、肺炎、中耳炎 |
| ✗ 流感全身症狀是病毒直接破壞造成 | ✓ 全身症狀來自**干擾素與淋巴激素**；局部症狀才是上皮受損 |
