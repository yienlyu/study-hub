# 腸桿菌科（依 113 共筆整理，鍾筱菁）

## 1. 總體特徵
- **G(−) 桿菌、不產孢子、兼性厭氧**、中等大小。
- **發酵 glucose、還原 nitrate、catalase (+)、oxidase (−)**（與其他 GNB 區分）。
- 共同抗原 **enterobacterial common antigen**（core polysaccharide）。
- 造成 1/4–1/3 菌血症、**>70% UTI**、許多腸道感染。
- 致病性：
  - 必定致病：***S.* Typhi、*Shigella*、*Yersinia pestis***
  - 伺機：*E. coli*、*Klebsiella pneumoniae*、*Proteus mirabilis*
  - 後天獲得毒力基因（質體、噬菌體、pathogenicity island）：*E. coli*
- Reservoir：動物（多數 *Salmonella*、*Yersinia*）；**人類唯一宿主：*Shigella*、*S.* Typhi**。

## 2. 培養鑑別
- **MacConkey agar（含膽鹽）**：乳糖發酵者粉紫色（*E. coli*、*Klebsiella*、*Enterobacter*、*Citrobacter*、*Serratia*）；不發酵者無色（*Salmonella*、*Shigella*、*Proteus*、*Yersinia*）→ **乳糖發酵常作為初步鑑定**。
- **Hektoen agar**：H₂S (+) 黑色（*Salmonella*、*Proteus*）。
- 乳糖 (−) + 有運動 + H₂S → *Salmonella*、*Proteus*；乳糖 (−) + **無運動** + 無 H₂S → ***Shigella***、*Yersinia*。
- *Klebsiella*：大莢膜 → mucoid 菌落、無運動。
- *Proteus*：**swarming**、urease（腎結石）。

## 3. 抗原與毒力
- **O antigen**（LPS，O1–O181）、**K antigen**（capsule；*Salmonella* 為 **Vi**）、**H antigen**（flagella，熱不穩定）→ 例 **O157:H7**。Teichoic acid 不是（那是 G+）。
- **LPS / endotoxin**：Lipid A → 發燒、休克、**DIC**；只有 LPS 叫 endotoxin。
- Capsule（抗吞噬、全身跑透透）、antigenic phase variation、exotoxins、**Type III secretion system**、抗藥性質體（sex pili 傳遞）。

## 4. 致病性 *E. coli* ⭐⭐⭐

|---|---|---|---|---|
| **UPEC** | **UTI（90%）**、腎盂腎炎 | **P pili**、AAF、Dr fimbriae | Hemolysin | 泌尿道 |

- K1 *E. coli* → 新生兒腦膜炎。
- 不同腹瀉型態主要取決於**毒力因子**。
- ↑cAMP 的毒素：**ETEC LT、cholera toxin、B. anthracis edema toxin、B. cereus 腹瀉型、pertussis toxin**；**Shiga toxin 不同（抑制蛋白合成）**。

## 5. *Salmonella*
- 有 **peritrichous flagella**（與 *Shigella* 區別）、>2500 血清型；命名 *S. enterica* serotype Typhi → *S.* Typhi。
- **感染劑量高：~10⁵ CFU**（*Shigella* 只要 10–100）。
- 經 **M cell** 入侵，可在 macrophage 內存活 → 進入**淋巴、血液**造成全身感染（SPI-1、SPI-2、T3SS）。
- 非傷寒（*S.* Typhimurium、Enteritidis）：**生雞蛋、家禽、乳製品**；腸胃炎；不必通報。
- **傷寒（*S.* Typhi）**：人唯一宿主、**帶原者（膽囊，Typhoid Mary）**、糞口 / 水源；高燒、玫瑰疹、肝脾腫大；第 1 週血液培養、第 3 週糞便；**Widal test**；Vi 抗原疫苗。

## 6. *Shigella*
- **無鞭毛**、乳糖 (−)、H₂S (−)；**10–100 CFU 即致病**；**人唯一宿主、人傳人**（糞口、污染水）。
- 四群：A *S. dysenteriae*（**Shiga toxin**，最嚴重 → HUS）、B *flexneri*、C *boydii*、D *sonnei*。
- **高度侵襲結腸上皮**（M cell → 細胞間擴散）→ 痢疾：少量、帶血、黏液、白血球的糞便，**tenesmus**；誘導 macrophage 凋亡。

## 7. *Yersinia*
- **Y. pestis → 鼠疫（plague）**：鼠 → **跳蚤叮咬**；F1 capsule（抗吞噬）、Pla protease（分解 C3b、C5a）；Yops（T3SS）。
  - Bubonic（淋巴腺，50–75%）、Septicemic（~100%）、**Pneumonic（人傳人飛沫，~100%）**；streptomycin；無有效疫苗。
- **Y. enterocolitica**：**4°C 可生長（cold enrichment）** → 冰箱食物；小腸結腸炎、**假性闌尾炎**、reactive arthritis。

# 考點分析

## 🔥 高頻考點（32 題）
1. **E. coli 致病型配對**：HUS / Shiga-like toxin → **EHEC**（考 5 次）；LT ≈ cholera toxin（考 3 次）；UPEC P pili；EPEC 不破壞腸細胞。
2. **Salmonella vs Shigella 感染劑量**（<100 CFU 是 Shigella；考 3 次，常當錯誤選項）。
3. **Uropathogenic E. coli 造成 HUS** → 錯（考 2 次）。
4. **Shigella**：侵入腸黏膜、人傳人、不發酵乳糖 + 無運動（情境題）。
5. **Salmonella**：有鞭毛、Widal、生蛋、可進入血液淋巴、傷寒帶原者。
6. **Plague = Y. pestis**（考 3 次）；跳蚤叮咬。
7. **乳糖發酵用於初步鑑定**；oxidase (−)；G(−)（「Gram-positive」是錯的）。

## 📝 出題模式
- 情境題：「某國小學童腹瀉、裡急後重，不發酵乳糖、無運動」→ Shigella；「越南女孩持續發燒、肝腫大、不發酵乳糖」→ Salmonella。
- E. coli 表格一定要背（共筆標「粗體必背」）。
