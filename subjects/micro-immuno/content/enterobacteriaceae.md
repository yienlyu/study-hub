# 腸桿菌科（依 113 共筆整理，鍾筱菁）

## 1. 總體特徵
- **G(−) 桿菌、不產孢子、兼性厭氧**、中等大小。
- **發酵 glucose、還原 nitrate、catalase (+)、oxidase (−)**（與其他 GNB 區分）。
- 共同抗原 **enterobacterial common antigen**（core polysaccharide）。
- 造成 1/4–1/3 菌血症、**>70% UTI**、許多腸道感染。
- 致病性：
  - 必定致病：***S.* Typhi、*Shigella*、*Yersinia pestis***
  - 伺機：*E. coli*、*Klebsiella pneumoniae*、*Proteus mirabilis*
  - 後天獲得毒力基因（質體、噬菌體、pathogenicity island）：*E. coli*
- Reservoir：動物（多數 *Salmonella*、*Yersinia*）；**人類唯一宿主：*Shigella*、*S.* Typhi**。

## 2. 培養鑑別
- **MacConkey agar（含膽鹽）**：乳糖發酵者粉紫色（*E. coli*、*Klebsiella*、*Enterobacter*、*Citrobacter*、*Serratia*）；不發酵者無色（*Salmonella*、*Shigella*、*Proteus*、*Yersinia*）→ **乳糖發酵常作為初步鑑定**。
- **Hektoen agar**：H₂S (+) 黑色（*Salmonella*、*Proteus*）。
- 乳糖 (−) + 有運動 + H₂S → *Salmonella*、*Proteus*；乳糖 (−) + **無運動** + 無 H₂S → ***Shigella***、*Yersinia*。
- *Klebsiella*：大莢膜 → mucoid 菌落、無運動。
- *Proteus*：**swarming**、urease（腎結石）。

## 3. 抗原與毒力
- **O antigen**（LPS，O1–O181）、**K antigen**（capsule；*Salmonella* 為 **Vi**）、**H antigen**（flagella，熱不穩定）→ 例 **O157:H7**。Teichoic acid 不是（那是 G+）。
- **LPS / endotoxin**：Lipid A → 發燒、休克、**DIC**；只有 LPS 叫 endotoxin。
- Capsule（抗吞噬、全身跑透透）、antigenic phase variation、exotoxins、**Type III secretion system**、抗藥性質體（sex pili 傳遞）。

## 5. *Salmonella*
- 有 **peritrichous flagella**（與 *Shigella* 區別）、>2500 血清型；命名 *S. enterica* serotype Typhi → *S.* Typhi。
- **感染劑量高：~10⁵ CFU**（*Shigella* 只要 10–100）。
- 經 **M cell** 入侵，可在 macrophage 內存活 → 進入**淋巴、血液**造成全身感染（SPI-1、SPI-2、T3SS）。
- 非傷寒（*S.* Typhimurium、Enteritidis）：**生雞蛋、家禽、乳製品**；腸胃炎；不必通報。
- **傷寒（*S.* Typhi）**：人唯一宿主、**帶原者（膽囊，Typhoid Mary）**、糞口 / 水源；高燒、玫瑰疹、肝脾腫大；第 1 週血液培養、第 3 週糞便；**Widal test**；Vi 抗原疫苗。

## 6. *Shigella*
- **無鞭毛**、乳糖 (−)、H₂S (−)；**10–100 CFU 即致病**；**人唯一宿主、人傳人**（糞口、污染水）。
- 四群：A *S. dysenteriae*（**Shiga toxin**，最嚴重 → HUS）、B *flexneri*、C *boydii*、D *sonnei*。
- **高度侵襲結腸上皮**（M cell → 細胞間擴散）→ 痢疾：少量、帶血、黏液、白血球的糞便，**tenesmus**；誘導 macrophage 凋亡。

## 7. *Yersinia*
- **Y. pestis → 鼠疫（plague）**：鼠 → **跳蚤叮咬**；F1 capsule（抗吞噬）、Pla protease（分解 C3b、C5a）；Yops（T3SS）。
  - Bubonic（淋巴腺，50–75%）、Septicemic（~100%）、**Pneumonic（人傳人飛沫，~100%）**；streptomycin；無有效疫苗。
- **Y. enterocolitica**：**4°C 可生長（cold enrichment）** → 冰箱食物；小腸結腸炎、**假性闌尾炎**、reactive arthritis。

## 🎙️ 上課錄影重點（鍾筱菁，10/16）
- **考試方式**：中文出題、**菌名用英文**，老師覺得很重要的會全英文。期中考只考期中範圍；期末會拿期中的細菌來比較，但「不會考太細」。**Neisseria 改由黃姿雯老師上**，但鍾老師的整理表仍會把它一起放進來比較（國考不分誰教的）。
- 這堂只上到 *Yersinia* 開頭；**弧菌、*Klebsiella*、*Proteus* 等後半部 10/23（五）接著上**。
- **為什麼同樣拉肚子要分菌**：細菌致病主要靠**毒素**，而且多是**外毒素**；水瀉或血便、有沒有發燒，取決於各自的 enterotoxin。國考很多「描述糞便 → 猜菌」的情境題。
- **氧氣**：腸道沒有氧 → 腸內菌是兼性厭氧、微厭氧或絕對厭氧；住在**肺、皮膚**的菌是好氧菌。*Pseudomonas aeruginosa* 放在這裡只是比較，它**住肺部、是好氧菌**。
- **腸道菌相（國考題）**：「用廣效抗生素把腸道細菌全部殺光才健康」→ **錯**，要維持好菌。好菌與過敏、自體免疫、肥胖、癌症、COVID-19 重症都有關（慢性病 ↔ 菌相失衡是**惡性循環**）。LP33 調節過敏體質只在 **5 歲前**有長期效果，之後只有暫時緩解。
- **鑑定第一步 = 乳糖發酵**（MacConkey 加酸鹼指示劑，產酸變紅）：*E. coli*、*K. pneumoniae* 發酵；*Salmonella*、*Shigella*、*Proteus*、*Yersinia* 不發酵。黃字重點：**革蘭氏陰性桿菌中只有腸內桿菌科是 oxidase (−)**，其他都是 (+)。
- **Salmonella vs Shigella**：*Salmonella* **有鞭毛（會動）、產 H₂S（黑色）**；*Shigella* 兩者皆無（HE agar）。
- **血清鑑定（醫學系一定要背）**：最外層的構造會引發中和抗體 → **H = flagella、K（*Salmonella* 叫 Vi）= capsule、O = LPS 最外段**；三者都沒有時用 pili 或 **outer membrane protein**（「老師沒特別講的，猜 OMP」）。
- **Capsule 放諸天下皆準**：抗吞噬，但本身變成新抗原 → **血清分型、做疫苗**（*S. pneumoniae* 13 價等、*N. meningitidis*、*H. influenzae*、*S.* Typhi 的 Vi）。這些都是多醣，**只有炭疽 capsule 是胜肽**。
- **LPS 三部分**：**Lipid A（有毒性，常考）**、core polysaccharide、**O antigen**（約 40 個重複糖單位，很長、暴露在外 → 抗原）。**只有 LPS 叫 endotoxin**，其他帶脂質的毒素只能叫「類內毒素」。LPS 是**所有 G(−) 共有**的 virulence factor，十五到二十年前的國考每年都考。
- **LPS → 敗血症**：免疫反應太強（「是你自己把自己搞死」）：上皮通透性 ↑、發燒（pyrogen）、全部白血球活化、**血小板與凝血系統活化 → DIC**（皮膚瘀斑、器官出血）、肝臟急性期反應 → **septic shock**、器官衰竭。美國 CDC 把敗血症視為**發炎／免疫疾病**而非單純感染症。G(+) 也會敗血症但要慢慢累積毒素；*N. meningitidis* 可造成 5–6 小時致死的猛暴性敗血症。
- **敗血症治療（課堂腦力激盪）**：抗生素仍要給但**不夠**；要加**支持性療法**（輸液、輸血、強心劑維持循環）、**免疫抑制劑**、**抗凝血藥物**。
- ***E. coli***：以發現者 Escherich 命名，coli = 大腸。分型：**O（LPS，到 O181）、H（flagellin）、K（capsule）**；**O157:H7 = 出血性大腸桿菌代表株**（O = LPS 第 157 型、H = flagellin 第 7 型，老師說這是「常識」）。**K1 → 嬰幼兒腦膜炎**。
- **七種致病型**：UPEC、ETEC、EHEC（= **STEC**，同一隻）、EPEC、EIEC、EAEC、AIEC；**記不住就記 ETEC、EHEC、EPEC 這三支**，EIEC、EAEC 有空看。
- **UPEC**：女生尿道短 → 多喝水；**蔓越莓汁的花青素抑制 UPEC 黏附**（pH 不是重點）；黏附靠 **pili 與 fimbriae**；**hemolysin** 溶 RBC（血尿）並活化發炎。
- **ETEC（旅行者腹瀉）**：黏附因子看看就好，**腸毒素一定要背**。**LT（heat-labile）= cholera-like toxin，A-B toxin**：B 負責黏，A 進去 → **↑cAMP → Cl⁻ 分泌 → 水瀉**；**ST（heat-stable）→ ↑cGMP** → 同樣水瀉。⚠️ **國考題：ETEC 不破壞腸上皮、不出血，糞便沒有血**。
- **↑cAMP 小整理**：*B. anthracis* **edema toxin**（局部水腫）、**ETEC LT**、**cholera toxin**（後兩者造成腹瀉）。
- **EHEC / STEC（最毒、會死人）**：**血便、出血性結腸炎、HUS（溶血性尿毒症候群 → 腎衰竭）**。毒素三個名字都要背：**Shiga toxin = Stx1/Stx2 = verocytotoxin**（課本的「Shiga-like toxin」本質相同）。與 ***Shigella dysenteriae* 的 Shiga toxin 機制一模一樣**：**A-B toxin**，B 接細胞受體（國考甚至考過受體），**A 結合 60S ribosome → 抑制蛋白質合成 → 細胞死亡**。對照：**白喉毒素作用在 EF-2**。
- **EHEC 與 EPEC「師出同門」**：共同黏附因子 **bundle-forming pili** 與 **intimin–Tir**。細菌用 **secretion system** 把 **Tir（translocated intimin receptor）打進宿主細胞、表現在細胞表面**，細菌表面的 **intimin** 再黏上去 → 形成**基座（pedestal）**完整黏附。課堂問答：**intimin 在細菌上、Tir 在宿主細胞上**。
- **EPEC 沒有毒素**：只黏附、擾亂絨毛吸收 → 只能欺負小朋友（**嬰兒腹瀉**），**不破壞細胞**。**ETEC、EPEC、EHEC 三者中只有 EHEC 會破壞上皮細胞**（國考超愛考這個比較）。
- **EIEC**：有類 hemolysin → 腹瀉也帶血，**類似 shigellosis**（但不是真的破壞腸細胞）。**EAEC**：很長的 fimbriae 把細胞聚集在一起；**類 STa 毒素 → ↑cGMP → 水瀉**。**AIEC**：躲在腸上皮細胞內，與 **Crohn's disease** 相關（歐美較常見，嚴重者截腸或做人工肛門）。
- 台灣 EHEC：自 1999 年起只有 5 例。
- ***Salmonella* 命名（不要亂寫）**：屬名、種名**斜體**；血清型 **Typhi 大寫、不斜體**。全名 *Salmonella enterica* serovar Typhi → 簡寫 *Salmonella* Typhi、*S.* Typhimurium。Pathogenicity island「看看，不會考」。
- **住在 macrophage 的兩個好處**（課堂複習，同 *Listeria*）：① 逃避免疫攻擊 ② 隨細胞全身跑 → **全身性疾病**。所以**傷寒是 systemic disease，不只是拉肚子**。
- **傷寒病程**：吃入 → 小腸 → 被 macrophage 吞 → 淋巴結、肝、脾、骨髓 → 發燒、**皮膚紅斑（玫瑰疹）** → **最後住進膽囊**慢慢排菌。⚠️ **國考題（老師連考兩三年還有人錯）：第 1 週約 90% 從血液培養分離，約第 3 週才從糞便分離**。**Widal test**（O、H 抗原的血清凝集）主要考醫技系。
- **以人為唯一宿主**：糞口 = ***S.* Typhi、*Shigella*、*V. cholerae***（霍亂、傷寒、痢疾）；飛沫 = 白喉；**性病**（沒有人畜共通的性病）。傷寒**要通報**；非傷寒（*S.* Typhimurium，murine = 老鼠；*S.* Enteritidis）是**自限性食物中毒、不用通報**，與**受感染雞卵巢 → 汙染的蛋**有關（老師吃壽喜燒不放生蛋）。
- **傷寒瑪麗的三個概念**：① 傷寒靠**健康帶原者**傳播（國考題）② **人傳人**，不是吃雞鴨牛羊 ③ **膽囊**是 *S.* Typhi 的居住處（她死後解剖發現膽囊充滿傷寒桿菌）。台灣每年約 1 例。
- ***Shigella***：**無鞭毛、不會動**（與 *Salmonella* 最大差別）；*S. dysenteriae* 最重要；人唯一宿主、糞口。**< 100 顆即可感染 → 能真正人傳人**（已開發國家以人傳人、同志間性行為為主）。台灣 **6–10 月**流行；高雄早餐店重複使用蛋液致死的案例。**高度侵襲 → 血便**；Shiga toxin（A-B → 60S）殺死上皮細胞與 macrophage；可併發 **HUS**。
- ***Yersinia***：抗吞噬。鼠疫是**生物恐怖攻擊武器**候選；**飢餓的跳蚤**（感染後無法吸血 → 一直叮咬）。**腺鼠疫**：叮咬 → 淋巴結腫大，致死率約 50%；**肺炎型／敗血型**：腺鼠疫病人的菌跑到呼吸道 → **人傳人**，未及時給抗生素致死率約 100%。

## 🎙️ 上課錄影重點（鍾筱菁，10/22，颱風假改同步遠距）
- 國考**不分哪位老師上的**；**腸桿菌科、弧菌、彎曲桿菌、幽門桿菌、綠膿桿菌要一起記、一起比較**；*Bacteroides fragilis* 會在最後的絕對厭氧菌一起教。前面是觀念養成，後面個案「用問的你就要能回答」。
- ***Y. pestis* 有 capsule**（上次沒講）：**F1 protein = 蛋白莢膜**。⚠️ **大部分莢膜是多醣，蛋白（胜肽）莢膜只有 *B. anthracis*（poly-D-glutamic acid）與 *Y. pestis*（F1）**（黃字 = 國考題）。F1 是**潛在疫苗標的但還沒有疫苗**，可作血清型鑑定。Yop proteins「太 detail，不會考」。
- 鼠疫：**跳蚤叮咬，不是老鼠咬**；腺鼠疫 50–75%；咽喉 → 肺 → 人傳人的**肺炎型與敗血型可近 100%**；初期像流感 → **第一個病人（吹哨者）很重要**；抗生素有效但要**及時**（同炭疽）；**沒有疫苗、感染力極強、可吸入 → 生物恐怖攻擊武器（國考題）**；近年俄國實驗室事件、2019 中國病例。
- **E. coli K1 capsule → 嬰幼兒腦膜炎**；*S.* Typhi capsule（Vi）→ 血清型與疫苗。
- ***Y. enterocolitica***：一般食物中毒、兒童**假性闌尾炎**；**4 °C 可生長 → 冷藏增殖法（冰箱放兩週以上再分離）**，與 ***Listeria*** 一起記（國考小題）。
- ***K. pneumoniae***：**厚莢膜**（血清型）、正常菌 → **伺機性感染**「從頭到腳」（肺炎、腦膜炎、腹瀉、UTI、敗血症）；肺炎特色 **痰中帶血**；國考較少考。
- ***P. mirabilis***：**周鞭毛 → swarming（在培養基上「遊行」，無法形成單一菌落）**；住膀胱，**urease** 把 urea → NH₃ + HCO₃⁻ → pH ↑ → **腎結石**（「you smell funny」= 阿摩尼亞味）。對照：**胃裡產 urease 的是 *H. pylori***。
- 弧菌與感染劑量的比較見「Neisseria、Helicobacter、Pseudomonas、Vibrio」章。

# 考點分析

## 🔥 高頻考點（32 題）
1. **E. coli 致病型配對**：HUS / Shiga-like toxin → **EHEC**（考 5 次）；LT ≈ cholera toxin（考 3 次）；UPEC P pili；EPEC 不破壞腸細胞。
2. **Salmonella vs Shigella 感染劑量**（<100 CFU 是 Shigella；考 3 次，常當錯誤選項）。
3. **Uropathogenic E. coli 造成 HUS** → 錯（考 2 次）。
4. **Shigella**：侵入腸黏膜、人傳人、不發酵乳糖 + 無運動（情境題）。
5. **Salmonella**：有鞭毛、Widal、生蛋、可進入血液淋巴、傷寒帶原者。
6. **Plague = Y. pestis**（考 3 次）；跳蚤叮咬。
7. **乳糖發酵用於初步鑑定**；oxidase (−)；G(−)（「Gram-positive」是錯的）。

## 📝 出題模式
- 情境題：「某國小學童腹瀉、裡急後重，不發酵乳糖、無運動」→ Shigella；「越南女孩持續發燒、肝腫大、不發酵乳糖」→ Salmonella。
- E. coli 表格一定要背（共筆標「粗體必背」）。

## 🎙️ 老師課堂提示
- 錄影中點名的國考題：**廣效抗生素殺光腸道菌才健康（錯）**、乳糖發酵與 **oxidase (−)**、**H／K（Vi）／O 抗原**對應的構造、**Lipid A 是毒性所在**、**只有 LPS 是 endotoxin**、LPS → 敗血症與 DIC、**ETEC 不破壞上皮、糞便無血**、**ETEC／EPEC／EHEC 只有 EHEC 破壞細胞**、Shiga toxin 的受體與 **60S** 機制、**傷寒第 1 週驗血、第 3 週驗糞便**、**健康帶原者**、鼠疫可當生物武器。
- 必背：**ETEC、EHEC、EPEC** 的毒素；UPEC 記 pili 與 fimbriae；EIEC、EAEC 有空再看；黏附因子看看就好（**intimin 在細菌、Tir 在宿主細胞**例外，課堂有問）。
- 跨章比較：↑cAMP（edema toxin、LT、cholera toxin）；抑制蛋白合成（Shiga toxin → 60S；白喉毒素、*Pseudomonas* exotoxin A → EF-2）；capsule 可分型與做疫苗（只有炭疽是胜肽）；以人為唯一宿主（糞口、飛沫、性病）。
- 考題用中文、菌名用英文；Widal test 主要是醫技系考點；*Salmonella* pathogenicity island 不考。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| 腸桿菌科 oxidase (+) | **oxidase (−)**、catalase (+)、發酵 glucose、還原 nitrate（*Vibrio*、*Pseudomonas* 才是 oxidase +） |
| *Salmonella*、*Shigella* 在 MacConkey 呈粉紅 | 兩者**不發酵乳糖 → 無色**；粉紫的是 *E. coli*、*Klebsiella*、*Enterobacter* |
| *Shigella* 有鞭毛、產 H₂S | ***Shigella* 無鞭毛、H₂S (−)**；*Salmonella* 有周鞭毛、H₂S (+) |
| *Shigella* 感染劑量很高 | ***Shigella* 10–100 CFU**；*Salmonella* 約 10⁵；*V. cholerae* > 10⁷ |
| Teichoic acid 是腸桿菌抗原 | Teichoic acid 是 **G(+)**；腸桿菌是 O（LPS）、K（莢膜；*Salmonella* 為 Vi）、H（鞭毛） |
| ETEC 造成血便 | ETEC：**旅行者水瀉、不發燒**（LT ↑cAMP、ST ↑cGMP） |
| EPEC 產 Shiga toxin | **EPEC 無 Shiga toxin**；EHEC（O157:H7）才有 → HUS |
| Shiga toxin 增加 cAMP | Shiga toxin **切 60S rRNA → 抑制蛋白合成**（B 次單元接 Gb3） |
| UPEC 用 BFP 黏附 | UPEC 用 **P pili**（腎盂腎炎）；BFP 是 EPEC／EHEC |
| 傷寒第一週驗糞便 | **第 1 週血液培養**、第 3 週糞便；帶原者藏在**膽囊** |
| EPEC 會破壞腸上皮 | EPEC 只黏附（BFP、intimin–Tir）、擾亂絨毛 → 嬰兒腹瀉；三者中**只有 EHEC 破壞細胞** |
| Intimin 是宿主細胞上的受體 | **Intimin 在細菌**；**Tir** 由細菌打進宿主、表現在**宿主細胞表面** |
| EHEC 與 STEC 是不同菌 | **同一隻**；Shiga toxin = Stx1/2 = verocytotoxin（= Shiga-like toxin） |
| Lipid A 負責抗原性、O antigen 有毒 | **Lipid A 有毒性**；**O antigen** 是抗原（血清分型） |
| 敗血症只要給抗生素就能治 | 還要**支持性療法**（輸液、升壓）、免疫抑制、抗凝血；敗血症被視為免疫／發炎疾病 |
| 非傷寒型沙門氏菌要通報 | **傷寒要通報**；非傷寒（Typhimurium、Enteritidis）是自限性食物中毒 |
| 非傷寒沙門氏菌只在人類 | 非傷寒型來自**生蛋、家禽**；**人唯一宿主是 *S.* Typhi 與 *Shigella*** |
| *S. dysenteriae* 不產毒素 | *S. dysenteriae* type 1 產 **Shiga toxin**（最嚴重，可 HUS） |
| 鼠疫由蚊子傳播 | 鼠 → **跳蚤**叮咬；肺鼠疫可人傳人飛沫 |
| *Y. enterocolitica* 需高溫才長 | **4 °C 可生長**（冰箱食物）；假性闌尾炎 |
| *Proteus* 不動 | *Proteus* **swarming**、urease（腎結石） |
