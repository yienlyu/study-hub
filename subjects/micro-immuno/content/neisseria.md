# Neisseria、Helicobacter、Campylobacter、Pseudomonas、Vibrio（依考古詳解整理）

> 113 共筆沒有收錄本章，以下整理自考古詳解。

## 1. *Neisseria*（G(−) 雙球菌、腎形 / 咖啡豆形）
- 黏膜常駐；致病種需**營養豐富培養基 + CO₂**（chocolate / Thayer-Martin）。
- 共同毒力：**pili**、**IgA1 protease**、**LOS（lipooligosaccharide，無 O antigen 的 LPS）**。

| | *N. gonorrhoeae*（淋病） | *N. meningitidis*（腦膜炎） |
|---|---|---|
| 傳播 | 性行為；新生兒產道 → **結膜炎（失明）** | **飛沫**；人為唯一宿主、**鼻咽帶菌** |
| 莢膜 | 無（或類莢膜） | **polysaccharide capsule → 疫苗** |
| 特有毒力 | **Opa（protein II）**、Por（I）、Rmp（III）；**pili antigenic variation**（重組）與 **phase variation**（slipped-strand mispairing → 暫時不表現） | capsule、LOS（endotoxin → 敗血症、DIC） |
| 臨床 | 男：尿道炎（多有症狀）；女：子宮頸炎（多無症狀）→ **PID、TOA、不孕、子宮外孕** | 6 個月–3 歲高危；腦膜炎、菌血症（**可入血**，75% 可血中分離） |
| 診斷 | 男性尿道分泌物：**嗜中性球內 G(−) 雙球菌**；**NAAT 為金標準**；**不靠血清抗體 4 倍上升** | CSF |

- ⚠️ 淋病雙球菌「virulence factor 是 pili 和 IgM protease」→ 錯（**IgA** protease）；**flagella 不是**其毒力因子。
- 環境中 1–2 小時即死亡。

## 2. *Helicobacter pylori*
- G(−) 螺旋、**microaerophilic**、**urease (+)**（產氨中和胃酸）；**人為唯一宿主**（非人畜共通）、糞口 / 口口傳播、可終生存在。
- 毒力：adhesins（BabA、SabA）、urease、mucinase、**VacA（空泡毒素）**、**CagA（type IV secretion 打入胃上皮）**。
- 疾病：**~90% 消化性潰瘍**、胃炎、**胃癌**、MALT lymphoma（不是大腸癌、不是食物中毒）。有十二指腸潰瘍者胃癌風險反而較低。
- 診斷：**urea breath test（¹³C/¹⁴C）**、stool antigen（HpSA）、**切片組織學 = 金標準**；**血清學準確度低，不宜作為低盛行區第一線**。

## 3. *Campylobacter jejuni*
- G(−) 彎曲、microaerophilic、**人畜共通**（未煮熟家禽）。
- 血便、痢疾；併發 **Guillain-Barré syndrome**（O:19 molecular mimicry）、reactive arthritis。
- 一般不致命（免疫低下者例外）。

## 4. *Pseudomonas aeruginosa*
- **好氧（可用 nitrate 厭氧呼吸）** G(−) 桿菌、**單一極鞭毛**、oxidase (+)、**不產孢子**。
- 水溶性色素：**pyocyanin（藍綠，產 ROS、毒素）**、pyoverdin（螢光黃綠）。
- 毒力：**Exotoxin A（ADP-ribosylate EF-2，同白喉毒素）**、**ExoS / ExoT（T3SS，破壞上皮；非蛋白合成抑制劑）**、elastase、biofilm、**多重抗藥**。
- **Opportunistic、院內感染**：呼吸器、IV 溶液、麻醉器材；**燒燙傷、cystic fibrosis 肺炎**、UTI、傷口、眼。
- **對 soap、dyes、QACs、多種藥物、乾燥有抗性**。

## 5. *Vibrio*（彎曲 G(−) 桿菌、兼性厭氧、嗜鹽）
| 菌 | 感染 | 特點 |
|---|---|---|
| **V. cholerae** | 霍亂（米湯樣水瀉） | **只有 O1、O139** 產 cholera toxin（A-B，↑cAMP）；人唯一宿主 |
| **V. parahaemolyticus** | **生海鮮食物中毒** | Kanagawa hemolysin；台灣常見食物中毒原因 |
| **V. vulnificus** | 生蠔 → 原發性敗血症；傷口接觸海水 → 蜂窩性組織炎、壞死 | **肝病、糖尿病高危**；死亡率高 |
| V. alginolyticus | 傷口、耳部感染 | — |

- Vibrio 不耐酸（需高菌量才過胃）。

## 6. 其他
- 細菌性腦膜炎三大菌（*S. pneumoniae*、*N. meningitidis*、*H. influenzae*）**共通最重要毒力 = capsule**。
- HIV 感染者全球最常見伺機感染：**Mycobacterium tuberculosis**。
- 人為唯一宿主：*Shigella*、*S.* Typhi、*V. cholerae*、*H. pylori*（糞口）；*C. diphtheriae*、*N. meningitidis*（飛沫）；*N. gonorrhoeae*、梅毒、披衣菌（性病）。

## *Neisseria*（黃姿雯講義，Murray Ch.23）
| 項目 | slides 重點 |
|---|---|
| 菌屬 | 35 種，多為黏膜共生菌；致病種只有 ***N. gonorrhoeae*（淋病雙球菌）** 與 ***N. meningitidis*（腦膜炎雙球菌）**；**人是唯一 reservoir** |
| 特性 | G(−) 好氧雙球菌；不會動、不產孢子；**全部 oxidase (+)**、多數 catalase (+)；**natural competency**（幫助修復嗜中性球 ROS 造成的 DNA 損傷） |
| 培養 | 非致病種：nutrient、blood agar 都長；***N. meningitidis*：nutrient ±、blood +++**；***N. gonorrhoeae*：nutrient、blood 都不長，要 chocolate agar**；**絕對好氧**、怕乾燥與血液中的脂肪酸、金屬 → 淋菌要用運送培養拭子；挑剔程度 **gonococcus > meningococcus**；35–37 °C，**怕冷**；淋菌需 **5% CO₂**；選擇性：**modified Thayer-Martin**（chocolate + vancomycin、colistin、nystatin、trimethoprim） |
| 毒力因子 | **Pili**（附著、抗嗜中性球殺菌；phase 與 antigenic variation）；**Por（PorB）**：干擾吞噬、幫助入侵、抗血清殺菌；**Opa**：結合上皮與吞噬細胞；**Rmp**：干擾血清殺菌；**鐵攝取蛋白**（transferrin 受體）；**LOS**（lipid A + core，**無 O antigen**）→ 刺激 **TNF-α**；**IgA1 protease**；**capsule 只有 *N. meningitidis*** |
| 表面抗原變化 | **Phase variation**：基因 ON/OFF（莢膜、pili；入侵時要關掉莢膜）；**Antigenic variation**：pili 經程式化重組依序換抗原 → 「領先」免疫反應 → **淋病可重複感染、不產生免疫，pili 疫苗失敗** |
| 致病步驟 | **黏附**（pili、Opa、LOS）→ **逃避**（進入黏膜細胞與嗜中性球內繁殖）→ **入侵**（transcytosis 到黏膜下層） |
| 淋病 | 每年約 8,800 萬例；**男**：化膿性尿道炎、排尿痛（**95% 有症狀**）；**女**：子宮頸炎、**PID、不孕**（**約一半有症狀**，無症狀者是 reservoir）；咽炎、**播散性感染**（女性 1–3%，男性罕見：敗血性關節炎、皮膚病灶）；**新生兒眼炎** → 1% silver nitrate、1% tetracycline 或 0.5% erythromycin 眼藥膏預防 |
| 淋病診斷 | **Gram stain**：有症狀男性尿道炎 > 90% 有效，**對女性子宮頸炎不敏感**（例外：嗜中性球內 G(−) 雙球菌）；喉、肛門因有共生 Neisseria 不準；**NAAT = 金標準**（常與披衣菌一起驗），但**測不出抗藥性**；培養用 modified Thayer-Martin |
| 淋病治療 | **不建議 penicillin**；**ceftriaxone + azithromycin**；抗藥：低程度 = 染色體 **PBP 突變**；高程度 = **plasmid 上的 penicillinase（可轉移）**；**抗原多樣 → 沒有疫苗**；安全性行為、追蹤性伴侶、新生兒眼部預防 |
| 腦膜炎雙球菌疾病 | 每年約 50 萬例；**流行性腦脊髓膜炎**（突發頭痛、發燒、頸部僵硬）；**腦膜炎雙球菌血症**：快速進展敗血症、**瘀斑（petechial rash）**、多重器官衰竭；**空氣傳播、約 10% 帶菌**；不立即治療死亡率高 |
| 莢膜 | 多醣莢膜 **13 個血清群**、抗吞噬、用於分型（A、B、C、W135、Y）；**四價疫苗 A、C、W135、Y**；**B 型免疫原性差、與人類神經組織抗原相似 → 沒有疫苗** |
| 腦膜炎雙球菌診斷 | **CSF Gram stain** 有效；莢膜抗原檢測（CSF、血、尿）比 Gram stain 不敏感、尿液偽陽性 → 價值有限；CSF、血、痰培養 |
| 腦膜炎雙球菌治療 | **ceftriaxone 或 cefotaxime**（敏感才用 penicillin）；**很少有 plasmid → 很少有 β-lactamase**；密切接觸者化學預防：**rifampin、ciprofloxacin 或 ceftriaxone**；A、C、Y、W135 多醣與結合型疫苗 |
| 比較 | 共同：**LOS（endotoxin）**、pili 變異、OMP 變異（Por／Opa／Rmp）、IgA protease、鐵攝取；**淋菌無莢膜、抗藥較常見**；**腦膜炎菌有多醣莢膜、抗藥罕見** |
| 流行病學比較 | 淋菌：病原菌；生殖道、口咽、肛門黏膜；**性傳染**；多性伴年輕人（女 15–19 歲、男 20–24 歲）；全球、美國高；**無疫苗**。腦膜炎菌：正常菌／病原菌；口咽黏膜；**飛沫**；**> 2 個月嬰兒、6 個月–2 歲高峰**，以及群居年輕人（宿舍、軍營）；非洲「**腦膜炎帶**」；**在上呼吸道不致病，入血才致病**；有疫苗（非全部血清型） |
| 相關菌屬 | 生長慢、挑剔、伺機性：***Eikenella corrodens***（小 GNB）：**人咬傷、打架拳傷**、亞急性心內膜炎；***Kingella kingae***（小 G(−) 球桿菌）：亞急性心內膜炎 |

**🎙️ Neisseria 錄影重點（10/21）**：淋病雙球菌**有 fimbriae**、腦膜炎雙球菌**有莢膜**；檢體中常見**被吞進細胞內的咖啡豆形雙球**；**怕低溫 → 送檢千萬不要冰**；natural competency 幫助修復 ROS 造成的 DNA 損傷；毒力因子**都在外膜**（Por、Opa、LOS、鐵攝取），pili 與 Opa 的 **phase variation（開關）**、**antigenic variation（重組換成分）** → **淋病沒有疫苗**；淋菌**高盛行、低致死**（美國嚴重、台灣相對低），腦膜炎菌**低盛行、高致死**；淋菌抗藥兩機制：**自身 PBP 突變**、**外來 penicillinase**（美國 CDC 重點監測）；腦膜炎雙球菌血症 → **四肢瘀斑**、急診急重症；**密切接觸者預防性投藥**；**ACWY 疫苗**台灣非常規；女性淋病**一半以上無症狀 → 主要傳播者**，男性多有症狀 → 要追蹤性伴侶；**母親淋病 → 新生兒結膜炎 → 抗生素眼藥預防**。

## *Campylobacter* 與 *Helicobacter*（螺旋形 G(−)，講義「螺旋桿菌、綠膿桿菌」）
| 項目 | slides 重點 |
|---|---|
| 共同特性 | **microaerophilic（5% O₂，太多太少都不行）**；**oxidase (+)、catalase (+)**；**nonfermentative（不用糖當碳源）**；*H. pylori* 早期叫 *Campylobacter pylori* |
| *C. jejuni*（空腸彎曲桿菌） | 螺旋形、**海鷗翅膀狀（gull's wings）**；不產孢子、**單一或雙極鞭毛、會動**；**42 °C 長得比 37 °C 好**（雞的體溫 42 °C）；**人畜共通**：吃**未熟雞鴨牛羊肉**；急性腸胃炎、**血便或痢疾**、腹絞痛、發燒，嚴重可敗血症 |
| Guillain-Barré syndrome | **自體免疫**；***C. jejuni* O:19 的 LPS 與神經 ganglioside 交叉反應** → 攻擊髓鞘、四肢無力，嚴重影響呼吸心臟；治療：類固醇、免疫抑制、血漿置換；**流感疫苗**也有約十萬分之一案例 |
| 其他 *Campylobacter* | *C. coli*：腸胃炎；*C. fetus*：心血管；***C. upsaliensis*（狗）也與 GBS 有關**（國考考過：**jejuni 與 upsaliensis** 兩隻都會造成 GBS） |
| *H. pylori* | 螺旋形、**端叢鞭毛、運動性極強（corkscrew）**；microaerophilic；**人是唯一自然宿主**、人傳人（糞口）；胃炎、**消化性潰瘍**、**胃腺癌**、**MALT lymphoma**；台灣盛行率約 **50%**（共食、夜市文化） |
| 人是唯一宿主（老師整理表） | **糞口**：*Shigella*、*Salmonella* Typhi、*V. cholerae*、***H. pylori***；**呼吸道**：*S. pyogenes*、*S. pneumoniae*、*N. meningitidis*、*C. diphtheriae*、*B. pertussis*、*M. pneumoniae*、*M. tuberculosis*；**性傳染**：*N. gonorrhoeae*、*T. pallidum*、*C. trachomatis* |
| 發現史 | **2005 諾貝爾獎（Marshall、Warren）**；難養（微氧，加血清、炭、澱粉、蛋黃）、沒有動物模型 → **Marshall 自己喝下菌液**證明 Koch's postulates，再用抗生素治好 → 潰瘍是感染症，不只是胃酸 |
| 毒力：移生 | adhesin **BabA、SabA**；acid inhibitory protein；**urease (+++)**：urea → NH₃ + HCO₃⁻ → pH ↑ 耐胃酸（老師對照：膀胱裡產 urease 的是 *Proteus*） |
| 毒力：入侵 | mucinase、phospholipase、proteinase |
| 毒力：組織傷害 | **VacA**：細胞內產生空泡殺細胞；**CagA**：經 **type IV secretion system** 打入胃上皮（**講義寫 type VI 是錯的**），干擾 cytoskeleton、誘導 **IL-8**（**既是 cytokine 也是 chemokine，國考考過**）→ 招募嗜中性球 → protease、ROS → 發炎 |
| 胃癌 | 慢性胃炎 → 纖維化、腸型上皮增生；**CagA (+)**、**IL-1 (+++)** 風險高 |
| 診斷 | 難養，**不從糞便培養**（易誤診）；**侵入性：biopsy（確診，高敏感高特異）**、biopsy urease test；**非侵入性：¹³C / ¹⁴C urea breath test（篩檢）**、糞便抗原 |
| 治療 | **PPI（增強抗生素作用）+ macrolide + β-lactam**，約一個月 |

## *Pseudomonas aeruginosa*（綠膿桿菌）與 *Burkholderia*
| 項目 | slides 重點 |
|---|---|
| 特性 | G(−)、常成對；**好氧，氧化葡萄糖而不發酵**（可走完整 TCA cycle）；營養需求極簡單（水 + 少量糖就能活）→ 水、土、醫院到處都有；老師提醒教科書說「絕對好氧」不精確，**厭氧環境也能生存**（nitrate 呼吸） |
| 鑑別 | **β 溶血**；**綠色色素**：**pyocyanin（藍綠）**、**pyoverdin（黃綠、螢光）**、pyorubin（紅棕）；**葡萄味** |
| 疫學 | 對多數常用抗生素抗藥 → **用抗生素治療中的病人、免疫低下者伺機感染**、院內感染主因 |
| 感染部位 | **肺：cystic fibrosis 病人主要病原**（CFTR，第 7 對染色體，白人常見）；**皮膚：燒燙傷傷口**（八仙塵爆）、**游泳 → 毛囊炎**；UTI；**耳：swimmer's ear**；**眼：隱形眼鏡 → 角膜潰瘍**；菌血症、心內膜炎。想到綠膿桿菌就想到**水** |
| 毒力：黏附 | flagella、pili、LPS；**alginate**（黏稠多醣 → **biofilm** 基質，**國考考過**）→ 抗生素抗性 |
| 毒力：毒素 | **Exotoxin A：ADP-ribosylate EF-2 抑制 peptide elongation，與白喉毒素同機制**（國考考過）；對照 **Shiga toxin / Stx**：切 60S rRNA 的 adenine；pyocyanin 產 superoxide、H₂O₂、誘導 IL-8 |
| 毒力：酵素 | **LasA（serine protease）+ LasB（zinc metalloprotease）→ elastase** → 出血性病灶、抑制補體與嗜中性球趨化；alkaline protease；phospholipase C；**ExoS、ExoT：type III secretion → 破壞上皮** |
| 抗藥 | **intrinsic + adaptive**；**ampC β-lactamase** |
| *Burkholderia*（舊屬 *Pseudomonas*） | 潮濕環境、伺機性；***B. cepacia***；***B. pseudomallei* → 類鼻疽（melioidosis）**：土壤、**汙水**、東南亞、澳洲；皮膚與吸入感染；酗酒、糖尿病、慢性腎肺病高危；各處膿瘍；**高傳染性、可作生物武器**；台灣**颱風淹水後**病例增加（2024 起明顯上升）。老師說**不會考，但「搞不好國考會考」**；***B. gladioli***：植物病原，產 **bongkrek acid（米酵菌酸）**、抑制粒線體 → 寶林茶室食物中毒（**不考**） |

> 🎙️ 錄影補充（10/22）：彎曲桿菌與幽門桿菌要一起記（**微氧、oxidase (+)、不用糖**）；*Pseudomonas* 是老師「心目中的超級細菌」，**黃字＝會考**：不發酵糖、alginate/biofilm、Exotoxin A 與白喉毒素同機制、多重抗藥；其他酵素「自己看看」。

## *Vibrio*（講義「腸桿菌及弧菌」）
- 共同特性：**彎曲桿菌**、**oxidase (+)**、有鞘的極鞭毛、**需要鹽**、耐鹽鹼；**TCBS agar**。
- ***V. cholerae***：**O1、O139 產霍亂毒素**（↑cAMP → **米湯樣腹瀉**）；毒素基因在 **CTXφ** 噬菌體；**TCP 菌毛**；感染劑量 **> 10⁷**；**人為唯一宿主**，經汙染的食物與水；O1 無莢膜。
- ***V. parahaemolyticus***：生海鮮 → 胃腸炎；**Kanagawa hemolysin**（heat-stable）。
- ***V. vulnificus***：**肝病患者**高死亡率；海水或魚刺傷口 → 壞死性感染、水泡性皮膚炎；生蠔 → 敗血症；多醣莢膜。
- 🎙️ 10/22 錄影：**從弧菌開始之後的 G(−) 菌都是 oxidase (+)**（腸桿菌科才是 oxidase (−)）；弧菌**耐鹼、需要膽鹽 → TCBS**，三隻在 TCBS 顏色不同；**感染力：*Shigella* 1–10 顆 > 傷寒 10⁵ > 霍亂 10⁷（最弱，要很髒的水）**；霍亂毒素與 ETEC LT 都是 **AB toxin、↑cAMP**；**除了 LPS（內毒素）以外，腸毒素、霍亂毒素、破傷風毒素都是外毒素**；Kanagawa hemolysin 只溶 **人 O 型血與兔血**（「我不曉得為什麼常考」）；*V. vulnificus*：**已開發國家主要弧菌**，肝癌、肝硬化、酒精性肝病者高危，**人不傳人**，雲嘉南常見。

# 考點分析

## 🔥 高頻考點（29 題）
1. **H. pylori**：urease（診斷、breath test）、VacA、人唯一宿主、microaerophilic、胃潰瘍 / 胃癌、診斷金標準 = 組織學、血清學不宜第一線（出 6+ 次）。
2. **Neisseria**：疫苗 = capsule（N. meningitidis）、毒力因子「不包括 flagella」、Opa 是 N. gonorrhoeae 專屬、pili phase vs antigenic variation、淋病 → 不孕 / PID、診斷不靠抗體上升。
3. **Pseudomonas**：不產孢子、ExoS 不是蛋白合成抑制劑（Exotoxin A 才是）、對消毒劑有抗性、CF 病人。
4. **Zoonosis**：*C. jejuni* 是；H. pylori、N. meningitidis、S. Typhi 不是。
5. **Vibrio**：生海鮮 → V. parahaemolyticus；生蠔 → V. vulnificus；只有 O1、O139 致霍亂。
6. **Lipid A = endotoxin 活性**。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| *Neisseria* 的毒力因子是 IgM protease、鞭毛 | **IgA1 protease**、pili、LOS；**沒有鞭毛** |
| *N. gonorrhoeae* 有多醣莢膜可做疫苗 | 莢膜疫苗是 ***N. meningitidis***；淋病沒有疫苗 |
| 淋病診斷靠血清抗體 4 倍上升 | **NAAT 是金標準**；男性尿道分泌物嗜中性球內 G(−) 雙球菌 |
| 女性淋病多有症狀 | 黃姿雯講義：**女性約一半有症狀**（無症狀者是 reservoir）、**男性 95% 有症狀** → 女性 PID、不孕、子宮外孕 |
| 腦膜炎雙球菌有其他動物宿主 | **人唯一宿主**、鼻咽帶菌、飛沫 |
| 淋病用 penicillin 治療 | **ceftriaxone + azithromycin**；高程度抗藥 = plasmid penicillinase，低程度 = PBP 突變 |
| 腦膜炎雙球菌 B 型有多醣疫苗 | 四價疫苗 **A、C、W135、Y**；**B 型免疫原性差、像人類神經抗原 → 無多醣疫苗** |
| *N. gonorrhoeae* 可在一般 blood agar 生長 | 淋菌要 **chocolate agar／modified Thayer-Martin + 5% CO₂**；腦膜炎菌 blood agar 可長 |
| 腦膜炎雙球菌常帶 β-lactamase | 腦膜炎菌**很少有 plasmid、很少產 β-lactamase**；接觸者預防用 rifampin、ciprofloxacin 或 ceftriaxone |
| *H. pylori* 嚴格厭氧、人畜共通 | **microaerophilic**、urease (+)、**人唯一宿主** |
| *H. pylori* 與大腸癌相關 | 與**胃癌、MALT lymphoma**、消化性潰瘍相關 |
| *H. pylori* 診斷金標準是血清學 | **切片組織學**；血清學在低盛行區不宜第一線 |
| *Campylobacter* 併發 HUS | ***C. jejuni* → Guillain-Barré**（分子擬態）；HUS 是 EHEC |
| *Pseudomonas* 是厭氧菌 | **好氧**（可用 nitrate 厭氧呼吸）、單一極鞭毛、oxidase (+) |
| ExoS／ExoT 抑制蛋白合成 | **Exotoxin A** ADP-ribosylate EF-2；ExoS／T 經 T3SS 破壞上皮 |
| 所有 *V. cholerae* 都產霍亂毒素 | **只有 O1、O139** |
| 霍亂毒素增加 cGMP | 霍亂毒素 **↑cAMP**（Gs 持續活化） |
| *V. vulnificus* 主要造成水瀉 | 生蠔 → **原發性敗血症**、傷口壞死性感染；**肝病**高危 |
| *V. parahaemolyticus* 用 TCBS 呈黃色、Kanagawa 不耐熱 | Kanagawa hemolysin **heat-stable**；生海鮮食物中毒 |
