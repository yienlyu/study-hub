# Neisseria、Helicobacter、Campylobacter、Pseudomonas、Vibrio（依百十四共筆整理、對照百十三共筆）

## 1. _Neisseria_（奈瑟菌屬）（G(−) 雙球菌、腎形 / 咖啡豆形）

- 黏膜常駐；**oxidase (+)**；**人是唯一宿主**；怕冷怕乾（運送不能冰）。
- 培養：非致病種 nutrient、blood agar 都長；_N. meningitidis_ **blood agar (+)**、nutrient ±；_N. gonorrhoeae_ **blood agar (−)、只長 chocolate agar**（國考）。選擇性培養基（selective medium） **Thayer-Martin**（含 vancomycin、colistin、nystatin、trimethoprim）。天生 **natural competence**，可修補被 neutrophil ROS（reactive oxygen species，活性氧） 傷害的 DNA。
- 共同毒力：**pili**、**IgA1 protease**、**LOS（lipooligosaccharide，無 O antigen 的 LPS（lipopolysaccharide，脂多醣），毒性在 lipid A）**。LOS 也見於 _Haemophilus_、_H. pylori_。

|          | _N. gonorrhoeae_（淋病（gonorrhea））                                                                                                                                                                                                                                                                           | _N. meningitidis_（腦膜炎（meningitis））                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| 傳播     | 性行為；新生兒產道 → **結膜炎（失明）**                                                                                                                                                                                                                                                            | **飛沫**（droplet）；人為唯一宿主、**鼻咽帶菌**（carriage）                          |
| 莢膜     | 無（或類莢膜）                                                                                                                                                                                                                                                                                     | **polysaccharide capsule → 疫苗**                             |
| 特有毒力 | **Por（protein I，打洞；被吞後能逃出吞噬體、住在 neutrophil 裡）**、**Opa（protein II，黏附上皮）**、**Rmp（protein III，抑制血清補體）**、搶鐵蛋白；LOS 與 IgM 凝集 → macrophage 大量 TNF-α；**pili antigenic variation**（重組）與 **phase variation**（slipped-strand mispairing → 暫時不表現） | capsule、LOS（endotoxin → 敗血症（sepsis）、DIC（disseminated intravascular coagulation，瀰漫性血管內凝血））                       |
| 臨床     | 男：尿道炎（**95% 有症狀**，膿狀分泌物、灼熱、睪丸痛）；女：子宮頸炎（**約一半無症狀**）→ **PID（pelvic inflammatory disease，骨盆腔發炎）、TOA、不孕（infertility）、子宮外孕**（ectopic pregnancy）、**Fitz-Hugh-Curtis**（腹膜炎、肝周炎）；新生兒眼炎（ophthalmia neonatorum）；瀰漫性感染：心內膜炎（endocarditis）、腦膜炎、**gonococcal dermatitis-arthritis syndrome**                                             | 6 個月–3 歲高危；腦膜炎、菌血症（**可入血**，75% 可血中分離） |
| 診斷     | 男性尿道分泌物：**嗜中性球內 G(−) 雙球菌**；**NAAT（nucleic acid amplification test，核酸擴增檢驗） 為金標準**（常和披衣菌一起驗）；**不靠血清抗體 4 倍上升**                                                                                                                                                                                       | CSF（cerebrospinal fluid，腦脊髓液） Gram 染色                                                 |
| 治療     | 有 β-lactamase、**不用 penicillin** → 第三代 cephalosporin（**ceftriaxone**、cefotaxime）；新生兒眼炎：1% 硝酸銀或 erythromycin 眼藥                                                                                                                                                               | cefotaxime、ceftriaxone；接觸者口服 **rifampicin** 預防       |
| 疫苗     | **無**（phase variation：表現開關；antigenic variation：抗原序列改變）                                                                                                                                                                                                                             | **有**：莢膜 A、C、W135、Y，約 2 年保護力                     |

- ⚠️ 淋病雙球菌「virulence factor 是 pili 和 IgM protease」→ 錯（**IgA** protease）；**flagella 不是**其毒力因子。
- _N. meningitidis_ 血清型以莢膜分 6 類（A、B、C、W135、X、Y），以 **W135、Y** 最多；疾病：**腦膜炎**（未治療致死率近 100%，治療後約 10%；發燒頭痛頸僵直）、**meningococcemia**（DIC 紫斑，致死約 50%）、**Waterhouse-Friderichsen syndrome**（兩側腎上腺出血、休克，6–8 小時內死亡）。
- 流行病學：淋病好發 15–24 歲性活躍者；腦膜炎雙球菌好發 **6 個月–2 歲**嬰幼兒與宿舍、軍營的年輕人（約 20 歲第二高峰），非洲「腦膜炎帶」最多。
- 環境中 1–2 小時即死亡。

## 2. _Campylobacter_（彎曲桿菌屬） 與 _Helicobacter_（螺旋桿菌屬） 的共同點（百十四共筆）

- **微需氧（microaerophilic，約 5% O₂）**（另一個微需氧菌：豬丹毒桿菌 _Erysipelothrix rhusiopathiae_）、**oxidase (+)、catalase (+)**、**不發酵碳水化合物**（以蛋白質等為碳源）。

## 3. _Helicobacter pylori_（幽門螺旋桿菌）

- G(−) **螺旋**、高度運動性、**單端鞭毛**、microaerophilic、**urease (+++)**（分解尿素產氨、pH↑中和胃酸；_Proteus mirabilis_ 也有 urease）；**人為唯一宿主**（非人畜共通）、**糞口**（fecal-oral）、人傳人、可終生存在。
  - 口糞傳染且人為唯一宿主：_S._ Typhi、_Shigella_、_V. cholerae_、_H. pylori_。
- **2005 諾貝爾**：Marshall、Warren。以往認為潰瘍是胃酸過多；_H. pylori_ 不易培養（培養基加 blood、serum、charcoal、starch、egg yolk），動物不會得病 → Marshall **自己喝菌液**、得到潰瘍並再分離出菌，符合 Koch 假說，最後以抗生素治癒。
- 毒力：
  - **移生**：adhesins（**BabA、SabA**）、acid inhibitory proteins、**urease**。
  - **入侵**（invasion）：mucinase、phospholipases、proteinase 鑽到黏膜下逃避免疫。
  - **組織損傷**：**VacA**（空泡毒素）、**CagA**（經 **type IV secretion system** 打入上皮 → **IL-8** → 趨化 neutrophil → protease、ROS 破壞胃組織）。
  - **胃癌風險**：慢性胃炎（gastritis）、纖維化、上皮增生；**CagA(+) 是癌化關鍵**；IL-1(+++) 造成纖維化與異常增生。
- 疾病：胃炎、**消化性潰瘍（~90%）**、**胃腺癌**、**MALT（mucosa-associated lymphoid tissue，黏膜相關淋巴組織） lymphoma**（不是大腸癌、不是食物中毒（food poisoning））。有十二指腸潰瘍者胃癌風險反而較低。
- 診斷：糞便培養困難易誤診；**侵入式**：胃鏡**切片（金標準（gold standard））**；**非侵入式：urea breath test（國考愛考）**——吃含 ¹⁴C（或 ¹³C）的尿素，urease 分解後以 ¹⁴CO₂ 呼出；stool antigen（HpSA（H. pylori stool antigen））；**血清學準確度低，不宜作為低盛行區第一線**。
- 治療：**PPI（proton pump inhibitor，氫離子幫浦抑制劑）＋兩種抗生素（macrolide、β-lactam）**吃一個月（防抗藥）；PPI 抑制胃酸並增加抗生素作用。

## 4. _Campylobacter jejuni_（空腸彎曲菌）

- G(−) 彎曲、不產孢子（spore）、microaerophilic、**42 °C 長得較好**；單端或兩端鞭毛、會動。
- **人畜共通**：吃未熟的雞鴨牛羊肉；多為腹瀉，嚴重時發燒、腹痛、**血便**，甚至菌血症（bacteremia）、敗血症。一般不致命（免疫低下者例外）。
- **Guillain-Barré syndrome**：自體免疫；**C. jejuni O:19** 的 LPS 與**神經節苷脂（gangliosides）**相似 → 抗體攻擊髓鞘 → 四肢無力，進一步影響呼吸肌、心肌而致死；不是單一病因（流感疫苗、病毒感染也會）。治療以**抑制免疫**為主：類固醇、**plasma exchange**、**IVIG**。

| 菌種             | 主要宿主         | 疾病                                              |
| ---------------- | ---------------- | ------------------------------------------------- |
| _C. jejuni_      | 家禽、牛、羊     | 腸胃炎、腸外感染、**GBS**、**reactive arthritis** |
| _C. coli_        | 豬、家禽、羊、鳥 | 腸胃炎、腸外感染                                  |
| _C. fetus_       | 羊、牛           | **心血管感染**                                    |
| _C. upsaliensis_ | 狗、貓           | 腸胃炎、腸外感染、GBS                             |

## 5. _Pseudomonas aeruginosa_（綠膿桿菌 / 銅綠假單胞菌）

- 名稱：pseudo（假）monas（單）aeruginosa（綠銅）；傷口常呈**綠色螢光**、**葡萄味（grapelike odor）**。
- **好氧**（aerobic） G(−) 桿菌（少氧也能活；呼吸作用產能、**不發酵糖**）、**成對**出現（_S. pneumoniae_ 也成對但是 G(+)）、**單端（polar）鞭毛**、oxidase (+)、**β-hemolysis**、不產孢子。
- 色素：**pyocyanin（藍綠，產超氧化物與過氧化物、破壞纖毛細胞、活化 IL-8）**、**pyoverdine（螢光黃綠，水溶性鐵載體）**、pyorubin（暗紅，抵禦氧化壓力）。
- 毒力：adhesins（flagella、pili）、**LPS（endotoxin）**、**alginate**（mucoid 多醣 → biofilm／莢膜，附著、抗吞噬，是**高抗藥性**的原因）、**Exotoxin A（阻斷 peptide elongation；ADP-ribosylate EF-2（elongation factor 2，延長因子 2），同白喉毒素）**、**elastase**（LasA serine protease＋LasB zinc metalloprotease；分解彈力蛋白 → 出血性病變、抑制 neutrophil）、alkaline proteinase、**phospholipase C**（heat-labile hemolysin）、**ExoS／ExoT（T3SS（type III secretion system，第三型分泌系統），約 20 種蛋白組成的注射針，破壞上皮；非蛋白合成抑制劑）**。
- **多重抗藥**：先天抗藥＋後天抗藥（分泌 **AmpC β-lactamase**）；**對 soap、dyes、QACs（quaternary ammonium compounds，四級銨）、多種藥物、乾燥有抗性**。
- **Opportunistic、院內感染**（nosocomial infection）：生存力強、到處都能活（游泳池、隱形眼鏡藥水、自來水 → **角膜潰瘍**（corneal ulcer）；耳 → **swimmer's ear**（急性瀰漫性外耳炎）；隱形眼鏡藥水兩大感染源之一，另一個是阿米巴）；呼吸器、IV 溶液、麻醉器材。
  - **燒燙傷**（局部血管損傷、組織壞死、菌血症）、**毛囊炎**（游泳）、UTI（urinary tract infection，泌尿道感染）、菌血症、心內膜炎。
  - **Cystic fibrosis**：西方白人最常見的體染色體隱性遺傳病，第 7 對染色體 **CFTR**（cystic fibrosis transmembrane conductance regulator） 缺陷 → 黏液黏稠 → 細菌殘留、反覆肺部感染。

## 6. _Burkholderia_（伯克氏菌屬）（曾歸在 _Pseudomonas_）

- 潮濕環境表面都能活；免疫低下者的伺機感染（_B. cepacia_、_B. pseudomallei_）。
- **_B. pseudomallei_**：**類鼻疽**；東南亞、印度、非洲、澳洲的土壤、水、植被；經皮膚或呼吸道；酗酒、糖尿病、慢性腎或肺病者從無症狀到重症；常見**膿瘍**（abscess）；高傳染性被列為**生物武器**（biological weapon）。
- **_B. gladioli_**：食物中毒（汙染玉米、椰子、木耳、銀耳、澱粉製品）；產生 **bongkrek acid（米酵菌酸，不可逆抑制粒線體（mitochondria） ADP/ATP 轉運酶）**、toxoflavin 等毒素。

## 7. _Vibrio_（弧菌屬）（彎曲 G(−) 桿菌、兼性厭氧（facultative anaerobe）、嗜鹽）

| 菌                                  | 感染                                                                                         | 特點                                                                                                                                                                                                                                                                                                         |
| ----------------------------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **V. cholerae**                     | 霍亂（**洗米水樣**白色水瀉：來不及被膽色素染色、抑制膽汁）                                   | O antigen 分 200 多型，**只有 O1、O139** 產 cholera toxin（A-B，↑cAMP → Cl⁻ 與水排入腸道）；毒素基因由 **phage CTXφ** 帶入（另有 Ace、Zot；**TCP**（toxin-coregulated pilus） 是 phage 受體也是定居因子）；O1 沒有莢膜；要驗到毒素才算確診；人唯一宿主但很少人傳人（汙水、食物）；感染劑量約 **10⁷**（Salmonella 10⁵、Shigella 10–100） |
| **V. parahaemolyticus**（腸炎弧菌） | **生海鮮食物中毒**、傷口感染                                                                 | **Kanagawa hemolysin**（耐熱外毒素，Cl⁻ 分泌↑；對人 O 型血或兔血 β 溶血）；台灣常見食物中毒原因                                                                                                                                                                                                              |
| **V. vulnificus**（創傷弧菌）       | 生蠔 → 原發性敗血症；傷口接觸海水、魚鱗刮傷、處理螃蟹 → 起泡性皮炎、**壞死性傷口**，常需截肢 | **肝病（肝硬化（cirrhosis）、肝癌）、糖尿病高危**；死亡率高（美國弧菌死亡的 90%）；莢膜抗吞噬，cytolysin、protease、collagenase 破壞組織                                                                                                                                                                                  |
| V. alginolyticus                    | 傷口、耳部感染                                                                               | —                                                                                                                                                                                                                                                                                                            |

- 共通：彎曲 G(−) 桿菌、**端鞭毛**、oxidase (+)、**嗜鹽、耐鹼**；**TCBS（thiosulfate-citrate-bile salts-sucrose agar） agar**：_V. cholerae_ 黃、_V. parahaemolyticus_ 綠、_V. vulnificus_ 藍綠。
- Vibrio 不耐酸（需高菌量才過胃）。

## 8. 其他

- 細菌性腦膜炎三大菌（_S. pneumoniae_、_N. meningitidis_、_H. influenzae_）**共通最重要毒力 = capsule**。
- HIV（human immunodeficiency virus，人類免疫缺乏病毒） 感染者全球最常見伺機感染（opportunistic infection）：**Mycobacterium tuberculosis**。
- 人為唯一宿主：_Shigella_、_S._ Typhi、_V. cholerae_、_H. pylori_（糞口）；_C. diphtheriae_、_N. meningitidis_（飛沫）；_N. gonorrhoeae_、梅毒、披衣菌（性病）。

| 比較             | 共同：**LOS（endotoxin）**、pili 變異、OMP 變異（Por／Opa／Rmp）、IgA protease、鐵攝取；**淋菌無莢膜、抗藥較常見**；**腦膜炎菌有多醣莢膜、抗藥罕見**                                                                                                                                                                                                                                                  |
| 流行病學比較     | 淋菌：病原菌；生殖道、口咽、肛門黏膜；**性傳染**；多性伴年輕人（女 15–19 歲、男 20–24 歲）；全球、美國高；**無疫苗**。腦膜炎菌：正常菌（normal flora）／病原菌；口咽黏膜；**飛沫**；**> 2 個月嬰兒、6 個月–2 歲高峰**，以及群居年輕人（宿舍、軍營）；非洲「**腦膜炎帶**」；**在上呼吸道不致病，入血才致病**；有疫苗（非全部血清型（serotype））                                                                                   |
| 相關菌屬         | 生長慢、挑剔、伺機性：**_Eikenella corrodens_**（小 GNB）：**人咬傷、打架拳傷**、亞急性心內膜炎；**_Kingella kingae_**（小 G(−) 球桿菌）：亞急性心內膜炎                                                                                                                                                                                                                                              |

**🎙️ Neisseria 錄影重點（10/21）**：淋病雙球菌**有 fimbriae**、腦膜炎雙球菌**有莢膜**；檢體中常見**被吞進細胞內的咖啡豆形雙球**；**怕低溫 → 送檢千萬不要冰**；natural competency 幫助修復 ROS 造成的 DNA 損傷；毒力因子**都在外膜**（Por、Opa、LOS、鐵攝取），pili 與 Opa 的 **phase variation（開關）**、**antigenic variation（重組換成分）** → **淋病沒有疫苗**；淋菌**高盛行、低致死**（美國嚴重、台灣相對低），腦膜炎菌**低盛行、高致死**；淋菌抗藥兩機制：**自身 PBP 突變**、**外來 penicillinase**（美國 CDC 重點監測）；腦膜炎雙球菌血症 → **四肢瘀斑**、急診急重症；**密切接觸者預防性投藥**；**ACWY 疫苗**台灣非常規；女性淋病**一半以上無症狀 → 主要傳播者**，男性多有症狀 → 要追蹤性伴侶；**母親淋病 → 新生兒結膜炎（conjunctivitis） → 抗生素眼藥預防**。

## _Pseudomonas aeruginosa_（綠膿桿菌）與 _Burkholderia_

## _Vibrio_（講義「腸桿菌及弧菌」）

- 共同特性：**彎曲桿菌**、**oxidase (+)**、有鞘的極鞭毛、**需要鹽**、耐鹽鹼；**TCBS agar**。
- **_V. cholerae_**：**O1、O139 產霍亂毒素**（↑cAMP → **米湯樣腹瀉**）；毒素基因在 **CTXφ** 噬菌體；**TCP 菌毛**；感染劑量（infectious dose） **> 10⁷**；**人為唯一宿主**，經汙染的食物與水；O1 無莢膜。
- **_V. parahaemolyticus_**：生海鮮 → 胃腸炎；**Kanagawa hemolysin**（heat-stable）。
- **_V. vulnificus_**：**肝病患者**高死亡率；海水或魚刺傷口 → 壞死性感染、水泡性皮膚炎；生蠔 → 敗血症；多醣莢膜。
- 🎙️ 10/22 錄影：**從弧菌開始之後的 G(−) 菌都是 oxidase (+)**（腸桿菌科才是 oxidase (−)）；弧菌**耐鹼、需要膽鹽 → TCBS**，三隻在 TCBS 顏色不同；**感染力：_Shigella_ 1–10 顆 > 傷寒（typhoid fever） 10⁵ > 霍亂 10⁷（最弱，要很髒的水）**；霍亂毒素與 ETEC（enterotoxigenic E. coli，產腸毒素型） LT 都是 **AB toxin、↑cAMP**；**除了 LPS（內毒素）以外，腸毒素（enterotoxin）、霍亂毒素、破傷風毒素都是外毒素**；Kanagawa hemolysin 只溶 **人 O 型血與兔血**（「我不曉得為什麼常考」）；_V. vulnificus_：**已開發國家主要弧菌**，肝癌、肝硬化、酒精性肝病者高危，**人不傳人**，雲嘉南常見。

# 考點分析

## 🔥 高頻考點（29 題）

1. **H. pylori**：urease（診斷、breath test）、VacA、人唯一宿主、microaerophilic、胃潰瘍 / 胃癌、診斷金標準 = 組織學、血清學不宜第一線（出 6+ 次）。
2. **Neisseria**：疫苗 = capsule（N. meningitidis）、毒力因子「不包括 flagella」、Opa 是 N. gonorrhoeae 專屬、pili phase vs antigenic variation、淋病 → 不孕 / PID、診斷不靠抗體上升。
3. **Pseudomonas**：不產孢子、ExoS 不是蛋白合成抑制劑（Exotoxin A 才是）、對消毒劑有抗性、CF 病人。
4. **Zoonosis**：_C. jejuni_ 是；H. pylori、N. meningitidis、S. Typhi 不是。
5. **Vibrio**：生海鮮 → V. parahaemolyticus；生蠔 → V. vulnificus；只有 O1、O139 致霍亂。
6. **Lipid A = endotoxin 活性**。

- 英文單選為主、「NOT correct」比例高；多題跨章（E. coli、B. cereus 重複出現在此章）。
