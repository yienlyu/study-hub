# 披衣病毒、黃病毒與肝炎病毒 內容整理（依今年講義整理，林良宗）

> 📑 依 2026 講義「Togaviridae & Flaviviridae」（27 頁）與「The A, B, C's of Hepatitis Viruses」（76 頁）整理。這兩份還沒有逐字稿，百十三、百十四共筆也還沒上傳；之後有錄影逐字稿或共筆再補老師口頭提點的考點。

## 1. Togaviridae 與 Flaviviridae 的共同特徵 ⭐⭐

| | **Togaviridae（披衣病毒）** | **Flaviviridae（黃病毒）** |
|---|---|---|
| 名稱 | toga = coat（指**套膜**） | flavi = yellow（**黃熱病毒**是原型） |
| 大小 | 45–75 nm | **37–50 nm**（較小） |
| 基因體 | **不分段 (+) ssRNA** | **不分段 (+) ssRNA** |
| 套膜／衣殼 | 有套膜、**二十面體**衣殼 | 有套膜、二十面體衣殼 |
| 差別 | **基因體排列方式與結構蛋白的轉譯方式不同** | 轉譯成**單一 polyprotein** 再切 |
| 代表 | Alphavirus（CHIKV、EEE、WEE、VEE）、**Rubivirus（德國麻疹）** | **黃熱病、日本腦炎、登革熱、西尼羅、Zika、HCV** |

- 兩科**多數由節肢動物傳播 → 統稱 arbovirus（arthropod-borne virus）**。
- **例外**：**德國麻疹病毒（呼吸道傳播）**與 **HCV（血液傳播）**不是 arbovirus。

## 2. Arbovirus 的傳播生態 ⭐⭐⭐

- **病媒（vector）**：吸血節肢動物——**蚊子、壁蝨、白蛉**等。
  - 病毒在節肢動物的**唾液腺**造成**持續性增殖感染（persistent productive infection）**，所以叮一次就能傳。
  - 因此有**地理與季節分布**（蚊子多的地方、雨季）。
- **保毒宿主（reservoir／amplifying host）**：病毒在其體內大量增殖但**不發病（inapparent disease）**。
- **人類多半是 dead-end host（終端宿主）**：體內病毒量不足以再傳給蚊子。
  - 人感染後可為**亞臨床感染**，或出現**出血熱、腦炎、肝炎、腎炎**。
- **潛伏期短**、**多數為亞臨床感染**。

## 3. Chikungunya 病毒（CHIKV）⭐

- Togaviridae、**Alphavirus**；非洲、亞洲、歐洲、印度洋與太平洋島嶼流行，**2013 年首次傳入美洲**。
- 病媒：**埃及斑蚊（Aedes aegypti）與白線斑蚊（Aedes albopictus）**——**和登革熱、Zika 共用同一種病媒蚊**。
- 症狀：**發燒＋關節痛**最常見；另有頭痛、肌痛、關節腫脹、紅疹。**很少致命，但症狀可以很嚴重**；症狀與登革熱、Zika 相似。
- 診斷：**RT-PCR、IgM-capture ELISA（MAC-ELISA）、PRNT**（三件組，arbovirus 都一樣）。
- 治療：**無疫苗、無抗病毒藥**，症狀治療；**最好的預防是避免被蚊子叮**。

## 4. 德國麻疹病毒（Rubella virus）⭐⭐⭐

- Togaviridae、**Rubivirus**；**呼吸道病毒、不是 arbovirus**。
- **只感染人**；**只有一個血清型**；傳染力很高，又稱 **German measles**。
- 傳播：**飛沫**（咳嗽、打噴嚏），以及**孕婦 → 胎兒**。
- 臨床：
  - **25–50% 無症狀**。
  - **後天性（postnatal）德國麻疹**：輕微、自限性；**紅疹、淋巴結腫大、低度發燒**。兒童症狀輕；**成人較嚴重，常有關節炎／關節痛**。
  - **懷孕期（尤其前三個月）感染後果嚴重**：流產、胎死腹中、死產、**先天性德國麻疹症候群（CRS，機率可達 90%）**。
  - 全球每年超過 **10 萬**嬰兒因 CRS 出現**失明、失聰、心臟病**等缺陷 → **具致畸胎性（teratogenic）**。
- 診斷：**RT-PCR、IgM 與 IgG**。
- 預防：**減毒活疫苗 RA27/3 株**；**12 個月**第一劑、**4–6 歲**追加；**95% 可得長期免疫**；**孕婦不可接種**（活疫苗）。即 **MMR 的 R**。

## 5. 重要的 Flavivirus ⭐⭐

| 病毒 | 分布 | 備註 |
|---|---|---|
| **黃熱病毒（YFV）** | 美洲、非洲 | **原型病毒**；**有疫苗（17D 減毒活疫苗）** |
| **日本腦炎病毒（JEV）** | 亞洲 | **有疫苗（不活化）** |
| **登革熱病毒（DENV）** | 熱帶、亞熱帶 | **四個血清型** |
| **西尼羅腦炎病毒（WNV）** | 北美、歐洲、非洲 | 人與**馬**都會感染 |
| **Zika 病毒（ZIKV）** | 非洲外廣泛分布 | 與**小頭症**有關 |
| **C 型肝炎病毒（HCV）** | 全球 | **不是 arbovirus**，血液傳播 |

- 記法：**有疫苗的只有黃熱病與日本腦炎**（登革熱、Zika 都沒有）。

## 6. 日本腦炎病毒（JEV）⭐⭐

- **人畜共通循環**：蚊子 ↔ **豬與涉禽（水鳥）**；**亞洲與西太平洋地區可用疫苗預防的腦炎中最主要的一種**。
- 病媒：**三斑家蚊屬（Culex）**，尤其 ***Culex tritaeniorhynchus***；常在**稻作與灌溉的鄉村農業區**。
- 流行：主要影響流行區的**兒童**；溫帶在**夏秋**高峰、熱帶亞熱帶全年有、**雨季**高峰。
- 臨床：**多數無症狀或症狀輕微，不到 1% 發展成臨床疾病**；初期發燒、頭痛、嘔吐 → 神經症狀、無力、運動障礙，**兒童常見抽搐**。
  - **致死率 20–30%**；存活者 **30–50% 留下神經、認知或精神後遺症**。
- 診斷：**CSF 或血清的 IgM-capture ELISA**、CSF 或腦組織 PCR。
- 疫苗：**IXIARO**——**Vero 細胞培養的不活化疫苗**，是目前唯一的 JE 疫苗；**2 個月大以上**可打，**兩劑間隔 28 天**。

## 7. 登革熱病毒（DENV）⭐⭐⭐

- **最重要的 arbovirus**，也是**全世界最重要、分布最廣的病毒性出血熱**。
- 每年 **5,000 萬–1 億**人感染，其中約 **50 萬例 DHF、2.2 萬人死亡，多數是兒童**。
- **四個血清型（DENV 1–4）**；源自猴子，在 100–800 年前於非洲或東南亞各自跳到人類身上。
- 流行：約 **25 億人（全球 40%）**住在有風險的地區，**超過 100 個國家**流行。
- 病媒：**埃及斑蚊、白線斑蚊**（和 CHIKV、ZIKV 相同）。
- 臨床光譜：
  - **DF（典型登革熱）**：急性發燒、自限性。
  - **DHF（登革出血熱）**：**血漿滲漏（plasma leakage）併出血**；只佔少數感染，但可進展到**休克與死亡**，是公衛上最重要的部分。
- 診斷：**臨床表現＋流行病學暴露史**；實驗室用 **RT-PCR、MAC-ELISA（最常用）、IgG ELISA、NS1 ELISA、PRNT**。
- 治療：**沒有合格疫苗、沒有特效藥**；**有效疫苗必須是四價的**；最好的預防是避免蚊子叮咬。

### DHF 的致病機轉假說 ⭐⭐⭐

| 假說 | 內容 |
|---|---|
| **二次感染／抗體依賴性增強（ADE）** | Halstead 提出；**體外可證實，體內難觀察** |
| **病毒毒力** | Rosen 提出；強毒株造成 DHF、弱毒株只造成 DF |
| **自體抗體** | 與**血小板或內皮細胞交叉反應**的抗體 |
| **宿主遺傳** | **HLA class 基因**與 DHF 易感性相關；**非洲裔族群有基因幾乎完全保護**不發生重症 |

- **ADE 的機制**（考試重點）：第一次感染產生的抗體，在**感染到不同血清型**時結合病毒卻**無法中和**；抗體–病毒複合體經 **Fcγ receptor** 進入**單核球**→ 病毒**複製量更多** → 重症風險上升。
- 也因為 ADE 的風險，**登革熱疫苗遲遲無法開發**（必須四價、同時涵蓋四型）。

## 8. Zika 病毒（ZIKV）⭐⭐

- Flavivirus、arbovirus；**1947 年於烏干達 Zika 森林**首次分離。
- 主要疫情：2007 Yap 島、2013–15 法屬波里尼西亞、**2015 巴西**、2015 維德角。
- 傳播：**蚊子叮咬**、**孕婦 → 胎兒**、**性行為**、輸血（可能但未確認）。
- 臨床：**80% 無症狀或症狀輕微**、很少致命；但
  - **懷孕期感染 → 胎兒小頭症（microcephaly）**；
  - **與 Guillain-Barré 症候群（GBS）強烈相關**（成人，風險隨年齡上升）。
- 診斷：**RT-PCR、MAC-ELISA、PRNT**。治療：**無疫苗、無特效藥**；**孕婦避免前往流行區**。

## 9. Arbovirus 感染的治療與防治（總結）⭐

1. **除了支持性療法外沒有治療方法**。
2. **最容易的防治是消滅病媒與其孳生地**。
3. **疫苗是最好的保護方式**：**17D 黃熱病減毒活疫苗**、**不活化日本腦炎疫苗**。
4. **登革熱疫苗因 ADE（免疫增強）的風險而難以開發**，必須是四價、安全又負擔得起。

# 肝炎病毒

## 10. 五種肝炎病毒總表 ⭐⭐⭐

| | **A** | **B** | **C** | **D** | **E** |
|---|---|---|---|---|---|
| 科別 | **Picornaviridae**（Hepatovirus） | **Hepadnaviridae** | **Flaviviridae**（Hepacivirus） | 類**類病毒（viroid-like）**、缺陷病毒 | 類 **Calicivirus**（自成一類） |
| 核酸 | **(+) ssRNA 7.5 kb** | **部分雙股環狀 DNA 3.2 kb** | **(+) ssRNA 9.6 kb** | **(−) ssRNA 1.7 kb 環狀** | **(+) ssRNA 7.5 kb** |
| 套膜 | **無**（裸露） | **有** | **有** | **有（借 HBsAg）** | **無** |
| 來源 | **糞便** | 血液、體液 | 血液、體液 | 血液、體液 | **糞便** |
| 傳播 | **糞口** | 皮膚、黏膜（性、血、母嬰） | 皮膚、黏膜 | 皮膚、黏膜 | **糞口** |
| 發病 | **突然** | **緩慢（insidious）** | **緩慢** | 突然 | 突然 |
| 潛伏期 | **15–50 天** | **45–160 天** | 14–180 天 | 15–64 天 | 15–50 天 |
| **慢性化** | **不會** | **會** | **會（最會）** | **會** | **不會** |
| 死亡率 | < 0.5% | 1–2% | 約 4% | 高到很高 | 1–2%；**孕婦 20%** |
| 併發症 | 無 | **肝硬化、HCC** | **肝硬化、HCC** | 肝硬化、**猛暴性肝炎** | 無 |
| 診斷 | **anti-HAV IgM** | HBsAg、HBeAg、anti-HBc IgM | anti-HCV、PCR | **anti-HDV ELISA** | IgM／IgG anti-HEV |
| 預防 | **疫苗（不活化）** | **疫苗（基因重組次單位）** | **沒有疫苗**；篩檢血源 | 打 **B 肝疫苗**即可 | 安全飲水；中國已核准疫苗 |

- 口訣：**「A、E 吃進去，不會慢性；B、C、D 血與體液，會慢性」**；**只有 B 是 DNA 病毒**。
- 歷史分類：A、E 是**腸道傳播**的「傳染性肝炎」；B、D 是**血清性肝炎**；C 原本叫 **NANB（非 A 非 B）肝炎**。

## 11. A 型肝炎病毒（HAV）⭐⭐

- **Picornaviridae 的 Hepatovirus（＝ enterovirus 72）**；**(+) ssRNA 7.5 kb、二十面體、無套膜、27 nm**。
- **只有一個血清型**（但有多個基因型）→ 疫苗好做、感染一次終身免疫。
- **抵抗力強**：耐**清潔劑、酸（pH 1）、有機溶劑（乙醚、氯仿）、乾燥、60°C**；在淡水與海水中可存活數月。**以氯消毒（飲用水）與紫外線可去活性**。
- 目標細胞：**肝細胞**。
- 傳播：**糞口與人際接觸**；**通常不經血液、也不母嬰垂直傳染**。
- 臨床：
  - 潛伏期**約 1 個月（15–50 天）**→ **黃疸突然出現**。
  - **成人 > 80% 有症狀；兒童多數無症狀**。
  - 肝細胞損傷、**膽汁鬱積（黃疸、高膽紅素）**、**白蛋白下降**。
  - **不會慢性化、不會造成肝癌**，極少猛暴性肝炎。
  - 與 HBV 不同，**免疫複合體相關症狀很少出現**。
- **症狀出現前 10 天糞便就有大量病毒 → 出現症狀前就有傳染力**（防疫重點）。
- **診斷首選：anti-HAV IgM（ELISA 或 RIA）**；病毒**很難在組織培養中生長**，不做常規分離。
- 治療與預防：
  - 支持療法，**沒有抗病毒藥**。
  - **免疫球蛋白（被動免疫）**：暴露前或暴露後**兩週內**給予，**80–90% 有效**，保護可維持**約 6 個月**。
  - **台灣已核准使用不活化（killed）A 肝疫苗**。
  - 改善衛生可減少傳播。
- 流行病學：**全球都有、沒有季節性**；社區、餐廳、學校會因汙染食物與飲水而**群聚爆發**；**1988 年上海生食毛蚶造成近 30 萬人感染、47 死**。

## 12. B 型肝炎病毒（HBV）：病毒學 ⭐⭐⭐

- **Hepadnaviridae**；**有套膜的 DNA 病毒、42 nm（Dane particle）**、二十面體衣殼。
- **基因體 3.2 kb、部分雙股的環狀 DNA**；**4 個重疊的讀碼框**：
  - **P**（polymerase）、**S**（HBsAg 的 L、M、S）、**C**（HBcAg、HBeAg）、**X**（HBx）。
- 套膜上有 **L、M、S 三種重疊的醣蛋白**；**親肝性（tropism for liver）**。
- 血中三種顆粒：**Dane particle（完整病毒，10⁷–10⁹/ml）**、**球形與絲狀顆粒（只有 HBsAg，10¹³/ml，最多）**。
- 傳染力：**比 HIV 高 50–100 倍**；在桌面、刮鬍刀、血漬上**可存活約一週**仍具感染力。

### 四種 mRNA ⭐⭐

| mRNA | 產物 |
|---|---|
| **3.5 kb（pregenomic RNA，比基因體長）** | **HBcAg、HBeAg、DNA polymerase**；**當作基因體複製的模板** |
| 2.1 kb | HBsAg 的 **S 與 M** |
| 2.4 kb | HBsAg 的 **L** |
| 0.7 kb | **HBx** |

### P 蛋白（DNA polymerase）的四種活性 ⭐⭐⭐

1. **DNA 依賴性 DNA 聚合酶**：把部分雙股 DNA 補成 **cccDNA**。
2. **RNA 依賴性 DNA 聚合酶（反轉錄酶）**。
3. **C 端 RNase H**：分解 RNA。
4. **N 端：反轉錄 (−) DNA 的蛋白質引子**。
- **⚠️ 沒有 retrovirus 的 integrase 活性**（和 HIV 最大的差別之一）。

### HBcAg vs HBeAg ⭐⭐

- 兩者**由同一個 3.5 kb mRNA 的同一讀碼框**轉譯，但**起始密碼子不同** → 非常相似但抗原性不同。
- **HBcAg**：**細胞質內的磷酸化蛋白**，C 端富含鹼性胺基酸，組成衣殼，**不分泌到血中**。
- **HBeAg**：**分泌型蛋白**、功能不明，**是「高傳染力、高風險」的指標**。
- **Pre-S1 區是肝細胞辨識位（受體結合）**；M 多 pre-S2、L 多 pre-S1＋pre-S2。

### HBx 蛋白 ⭐⭐

- 154 個胺基酸的多功能磷酸化蛋白，**病毒複製所必需**（轉活化 Core 與 S promoter）。
- 主要在**細胞質**，會**結合並隔離 p53** 與修復因子 DDB1；上調 src、Ras-Raf-MAPK、PKC、Jak1-STAT、NF-κB/IKK、PI3K/PKB 等路徑。
- **是弱的致癌基因**，在轉殖鼠可造成肝腫瘤；**HCC 中最常被嵌入宿主基因體的就是 HBx 那一段**。

### 複製（為什麼 DNA 病毒要用反轉錄）⭐⭐⭐

1. 進入後修補 gapped (+) DNA → **cccDNA**（在細胞核），由**宿主 RNA pol II** 轉錄。
2. 轉錄出**比基因體長的 pregenome（3.5 kb）**，轉譯出 P 蛋白與衣殼。
3. **P 蛋白結合 pregenome 3′ 端 → 一起包進衣殼 → 在衣殼內反轉錄成 (−) DNA**（**病毒 DNA 在細胞質中透過 RNA 中間產物複製**）。
4. RNase H 把 RNA 分解掉後，再合成 (+) DNA。
5. **在 ER 完成成熟與出芽**；因為出芽後核苷酸池無法補充，**(+) 股合成不完全 → 形成部分雙股 DNA**。
6. **以胞吐釋出**。

## 13. B 型肝炎：疾病與致病機轉 ⭐⭐⭐

- 傳播：血液、性接觸、**母嬰（周產期）**；潛伏期 **45–120 天**。
- 急性肝炎：發燒、倦怠、嘔吐、**深褐／綠色尿**、黃疸、**ALT 與 ALP 上升**、氣球樣肝細胞。**89% 會痊癒**。
- **1% 發生猛暴性肝炎** → 抽搐、昏迷、死亡；原因是**大量的 CTL 反應**。
- **10%（HBsAg > 6 個月）轉為慢性**，20–30 年後可為無症狀帶原、慢性活動性肝炎、**肝硬化或 HCC**；部分 HBV 基因（常是 **HBx 或截短的 S**）**隨機嵌入**肝細胞染色體。
- **年齡是關鍵**：**0–6 歲兒童痊癒率只有 30–70%，30–90% 會變慢性**；成人相反。
- **飲酒會加速肝病進展**。
- **致病機轉**：**HBV 本身不造成直接細胞病變；症狀與痊癒都是細胞媒介免疫（CTL）與發炎造成的**。
  - 嬰幼兒**細胞免疫尚未成熟 → 組織傷害少，但容易變成慢性帶原者**。
  - **慢性帶原者（尤其 HBeAg 陽性）肝癌風險更高**。
  - **anti-HBs 可提供終身免疫**；**anti-HBe 代表傳染力低**。
  - 台灣**慢性肝炎、肝硬化、原發性肝癌的主因就是慢性 HBV**，**> 80% 的病人 HBsAg 陽性**。

## 14. B 型肝炎的血清學標記 ⭐⭐⭐

- 檢驗方法：**ELISA 或 RIA**；五項合稱**「乙肝兩對半」**：**HBsAg、anti-HBs、anti-HBc、HBeAg、anti-HBe**。
- **HBeAg（與病毒 DNA）是「體內有感染性病毒、正在複製」的最佳指標 → 高危險患者**。
- **Window stage（空窗期）**：HBsAg 已消失、anti-HBs 還沒出現 → **此時要驗 anti-HBc IgM**（**最早出現的抗體是 anti-HBc**）。
- **慢性感染驗不到 anti-HBs**；若慢性病人血清中出現 anti-HBs，**可能產生免疫複合體疾病**。
- **非複製／低複製期**：HBsAg (+)、HBeAg (−)、病毒 DNA 低或測不到、ALT 正常，但**仍有 HBV 相關疾病與再活化的風險**，尤其 anti-HBe (−) 時。

| 標記 | 早期（無症狀） | 早期急性 | 急性 | 慢性 | 晚期急性 | **痊癒** | **接種疫苗** |
|---|---|---|---|---|---|---|---|
| **HBsAg** | ＋ | ＋ | ＋ | ＋ | ＋ | − | **−** |
| **HBeAg** | − | ＋ | ＋ | ＋ | − | − | − |
| **anti-HBc** | − | − | −＊ | **＋** | ＋/− | **＋** | **−** |
| **anti-HBe** | − | − | − | − | ＋/− | ＋/− | − |
| **anti-HBs** | − | − | − | **−** | − | **＋** | **＋** |

＊急性期應驗得到 **anti-HBc IgM**。
- **最常考**：**只有 anti-HBs (+)、anti-HBc (−) → 打過疫苗**；**anti-HBs 與 anti-HBc 都 (+) → 自然感染後痊癒**。

## 15. B 型肝炎的治療與預防 ⭐⭐⭐

- **成人急性感染通常不治療**：休息、營養、症狀處理、監測血液。
- **慢性感染**：
  - **IFN-α**。
  - **Lamivudine（肝安能，3TC）**：口服**胞嘧啶核苷類似物**、**反轉錄酶抑制劑**。
  - **Entecavir（貝樂克）**：**鳥嘌呤核苷類似物**。
  - 其他 DNA 聚合酶抑制劑：**Adefovir（Hepsera）、Telbivudine（Tyzeka）、Tenofovir（Viread）**。
- **被動免疫（HBIG）**：給 **HBsAg (+)、HBeAg (+) 或高危險母親的新生兒**，以及暴露於感染血液／體液而**未接種、接種不明或已知無反應者**；**最好 24 小時內**，**超過 7 天大概無效**。
- **疫苗（主動免疫）**：
  - **第一代**：從慢性帶原者血漿純化的 **22 nm HBsAg 顆粒**（**次單位疫苗**）。
  - **第二代（現行）**：把 **S 基因的質體送進酵母菌（*Saccharomyces cerevisiae*）**表現 → 基因重組次單位疫苗。
  - **台灣 1984 年 7 月**起針對帶原母親的新生兒全面接種，**1986 年 7 月**擴大到所有新生兒；**出生後 2–5 天、1 個月、6 個月共 3 劑**。
  - **HCC 是第一個可用疫苗預防的人類癌症** ⭐⭐⭐。

## 16. C 型肝炎病毒（HCV）⭐⭐⭐

- **Flaviviridae、Hepacivirus**；**有套膜、(+) ssRNA 9.6 kb、約 50 nm**。
- 歷史：1978 **Harvey Alter** 發現「非 A 非 B 肝炎（NANB）」；**1989 Michael Houghton（Chiron）**以 cDNA 選殖出病毒。
- **6 個主要基因型**、許多亞型；**極度高變異（每天產生約 10¹² 個變異株）→ quasispecies**。
- 傳播：**血液**——靜脈注射藥物、刺青、穿耳洞、針灸、共用刮鬍刀、美容與宗教儀式的割傷；**性傳染少見**。
- 流行：全球 **1.7–3 億**人感染；**台灣盛行率 1.5–2.0%（約 40 萬人）**。

### 基因體與蛋白 ⭐⭐

- 兩端有 UTR：**5′ UTR 含 IRES（轉譯 polyprotein）與 miR-122 結合位（肝專一，促進複製）**。
- **單一 polyprotein，由病毒與細胞的蛋白酶切開**。

| 蛋白 | 功能 |
|---|---|
| **Core** | 到脂滴上組裝 |
| **E1、E2** | 套膜醣蛋白，負責結合與進入；**含高變異區（HVR）→ 產生逃脫突變** |
| p7 | **離子通道**，參與組裝與產生 |
| NS2 | 調控生活史與組裝；與 NS3 合成 **NS2/3（半胱胺酸）蛋白酶** |
| **NS3** | **多功能：protease、helicase、NTPase**；**切 TRIF 與 IPS-1 癱瘓宿主先天免疫**；**抗病毒藥的主要標的**；與 NS4A 組成 **NS3/4（絲胺酸）蛋白酶** |
| NS4A | NS3/4 的輔因子 |
| NS4B | 誘導**膜性網（membranous web）**形成複製複合體 |
| NS5A | 磷酸化蛋白，參與複製與**抗 IFN（ISDR）** |
| **NS5B** | **RNA 聚合酶，易出錯 → 產生大量 quasispecies**，造成免疫逃脫與抗藥 |

### 疾病與自然史 ⭐⭐⭐

- **70–90% 會變成慢性**（比 HBV 更會慢性化）；**只有 10–30% 自限性**；**年輕女性清除病毒的機會較好**。
- 急性期**多半輕微而未被診斷**；慢性病人常**無症狀**，或倦怠、噁心、右上腹痛、深色尿、**ALT 起伏**。
- **25–40 年後**由纖維化 → **肝硬化 → HCC**；猛暴性肝炎 < 1%。
- **肝外表現**：**冷凝球蛋白血症（cryoglobulinemia）**、**B 細胞非何杰金氏淋巴瘤**、腎絲球腎炎、紫質症。
- HCV 會**抑制細胞凋亡與 IFN 作用** → 宿主細胞不死、形成持續感染。
- **在西方國家，HCV 造成肝硬化與 HCC 的重要性高於 HBV**；**飲酒加速病程**。

### 研究模式與診斷治療 ⭐⭐

- **只感染人與黑猩猩**、**非常難在細胞培養中生長**；**JFH-1（genotype 2a）在 Huh7.5 細胞**才能產生感染性顆粒；另有 SCID 人肝嵌合鼠、subgenomic replicon（Huh7，不產生顆粒）。
- 診斷：**ELISA 測 anti-HCV（感染後 2–5 個月才陽性）**；**確診用 PCR（感染後 1–2 週就陽性）**。
- 治療：
  - 舊標準：**長效干擾素（pegylated IFN-α）＋ ribavirin**；**IL28B SNP 可預測 SVR**；**GT1 治癒率 40–60%、GT2/GT3 70–80%**。
  - **DAA（直接作用抗病毒藥）**：boceprevir、telaprevir、**sofosbuvir**、ledipasvir、simeprevir、ombitasvir 等（Sovaldi、Harvoni、Viekira Pak）；**費用高、有抗藥性問題**（曾為 1,000 美元／顆／天，12 週療程）。
  - 末期肝病可肝移植，但**新肝臟必然再感染**。
  - **⚠️ 目前沒有 C 肝疫苗**。

## 17. D 型肝炎病毒（HDV）⭐⭐⭐

- **1977 年 Mario Rizzetto 在義大利發現**，又稱 **delta virus**。
- **缺陷病毒（defective virus）**：**(−) ssRNA、1.7 kb、環狀**，**36 nm**；**必須有 HBV 提供 HBsAg 當套膜**，才能包裝並從肝細胞釋出。
- **像植物的類病毒（viroid）**：
  - **Viroid-like domain**：**核酶（ribozyme）自我切割與再接合**病毒基因體。
  - **Protein-coding domain**：**HDAg（delta antigen）**。
  - **70% 核苷酸互相配對，折成穩定的桿狀（rod-like）雙股結構**。
- **HDV 需要 HBV 來傳播（保護、吸附），但基因體複製本身不需要 HBV** ⭐⭐⭐。
- 流行：感染全球 **3 億 HBsAg 帶原者中的 5%**；南美與非洲高、義大利與希臘中度；**希臘與台灣的性工作者盛行率高**。
  - 傳播途徑與 HBV 相同；**靜脈藥癮（IVDA）是最常見的途徑（17–90% 共同感染）**。
  - 三個基因型：**I 型全球分布、II 型在台灣、日本與北亞、III 型在南美**。
- **共同感染 vs 重疊感染** ⭐⭐⭐：

| | **Co-infection（同時感染）** | **Superinfection（重疊感染）** |
|---|---|---|
| 情境 | HBV 與 HDV 同時感染 | **慢性 HBV 患者再感染 HDV** |
| 頻率與嚴重度 | 較少見 | **較常見、較嚴重** |
| 結果 | **急性期較嚴重、可能肝衰竭**；轉慢性的風險與單獨 HBV 相同（約 5%） | **容易慢性化並快速進展為肝硬化**、可能**猛暴性肝衰竭**；**> 60% 變肝硬化** |

- 治療：**HBV＋HDV 對 IFN 的反應比單獨 HBV 差**；**lamivudine 對 HBV/HDV 共同感染無效**。
- 預防：**預防 HBV 就等於預防 HDV**（打 B 肝疫苗）；慢性 HBV 患者則要衛教減少風險行為。

## 18. E 型肝炎病毒（HEV）⭐⭐

- 1980 年代蘇聯占領阿富汗期間，軍營爆發疫情時發現。
- **全球最常見的急性病毒性肝炎病因**。
- 病毒學：**小（32 nm）、無套膜 RNA 病毒**，形態像 **Norwalk virus**、**類似（但不等於）Calicivirus**；**(+) ssRNA 7.5 kb、有 3′ poly(A) 尾**；現已自成一類「Hepatitis E-like viruses」。
- 流行：**糞口傳播**，**多數疫情與糞便汙染的飲水有關**；主要在開發中國家；**印度 5 歲以下兒童的 anti-HEV 抗體可達 60%**；**人傳人極少**。
- 疾病：潛伏期 **2–9 週**；症狀**和 A 肝相似**（噁心、嘔吐、腹瀉、黃疸），多數數月內痊癒；**不會造成慢性肝病**。
  - ⚠️ **懷孕第三孕期的孕婦死亡率高達 20%** ⭐⭐⭐。
- 診斷：**IgM／IgG anti-HEV**，血清與糞便可測 **HEV RNA**。
- 預防：避免來源不明的飲水與冰塊、生食貝類與未削皮的蔬果；**西方國家捐血者的免疫球蛋白無效**；**中國已核准預防性疫苗**。

# 考點分析

## 🔥 高頻考點

- **Arbovirus 的定義與生態**：病媒唾液腺持續感染、保毒宿主不發病、**人是 dead-end host**；**德國麻疹與 HCV 雖同科但不是 arbovirus**。
- **德國麻疹**：**致畸胎、CRS 90%**、**RA27/3 減毒活疫苗、孕婦禁用**、只有一個血清型。
- **登革熱**：**四個血清型**、**DHF 的 ADE 機制（FcγR → 單核球）**、**疫苗必須四價**、NS1 抗原檢驗。
- **日本腦炎**：**豬與水鳥**是宿主、**Culex** 傳播、**不活化疫苗（IXIARO）**。
- **Zika**：**小頭症與 Guillain-Barré 症候群**、可經性行為與母嬰傳播。
- **五種肝炎病毒的核酸、傳播途徑與慢性化**（最常考的整合題）：**只有 HBV 是 DNA**；**A、E 不慢性**；**C 最會慢性（70–90%）**。
- **HBV 的 P 蛋白有反轉錄酶但沒有 integrase**；**pregenomic RNA 是複製模板**。
- **HBV 血清學判讀**：**HBeAg＝傳染性最佳指標**、**空窗期驗 anti-HBc IgM**、**疫苗者只有 anti-HBs**。
- **HBV 不直接造成細胞損傷，症狀來自 CTL**；**嬰幼兒感染反而容易慢性化**。
- **HCC 是第一個可用疫苗預防的人類癌症**。
- **HDV 是缺陷病毒**：**借 HBsAg 當套膜**、**傳播需要 HBV 但複製不需要**；**superinfection 比 co-infection 嚴重**。
- **HEV 在孕婦第三孕期死亡率 20%**。

## 📝 出題模式

- 「以下何者不是 arbovirus？」→ **德國麻疹病毒或 HCV**。
- 「孕婦前三個月感染，新生兒白內障、耳聾、心臟缺損」→ **德國麻疹（CRS）**。
- 「第二次感染不同血清型反而更嚴重的機制」→ **antibody-dependent enhancement**。
- 「病人 HBsAg (−)、anti-HBs (+)、anti-HBc (−)」→ **接種過疫苗**；若 anti-HBc 也 (+) → **自然感染後痊癒**。
- 「急性 B 肝空窗期要驗什麼？」→ **anti-HBc IgM**。
- 「哪一種肝炎病毒需要另一種病毒才能完成感染？」→ **HDV（需要 HBsAg）**。
- 「哪一種肝炎對孕婦特別致命？」→ **HEV**。
- 「HBV 的 DNA polymerase 不具有下列何種活性？」→ **integrase**。

## ⚠️ 易混點

| 容易選錯 | 正確 |
|---|---|
| ✗ Togaviridae、Flaviviridae 都是蚊子傳播 | ✓ **德國麻疹（飛沫）與 HCV（血液）是例外** |
| ✗ 登革熱和 Zika 的病媒不同 | ✓ **CHIKV、DENV、ZIKV 共用埃及斑蚊與白線斑蚊**；**JEV 才是 Culex** |
| ✗ DHF 是第一次感染最嚴重 | ✓ **二次感染不同血清型**經 ADE 才容易重症 |
| ✗ 登革熱已有成熟疫苗 | ✓ 講義階段**尚無合格疫苗**；**有疫苗的是黃熱病（17D 活疫苗）與日本腦炎（不活化）** |
| ✗ HAV 會慢性化、會致癌 | ✓ **HAV 不慢性化、不致癌**；會致癌的是 **HBV、HCV** |
| ✗ A 肝出現黃疸後傳染力最強 | ✓ **症狀出現前 10 天**糞便病毒量就很高 |
| ✗ HBV 是 RNA 病毒 | ✓ **HBV 是唯一的 DNA 肝炎病毒**（部分雙股環狀） |
| ✗ HBV 的聚合酶有 integrase | ✓ **沒有**；嵌入是隨機發生，不是酵素活性 |
| ✗ HBV 直接殺死肝細胞 | ✓ **CTL 與發炎**造成傷害；猛暴性肝炎是**過強的 CTL** |
| ✗ 成人感染 HBV 比嬰幼兒容易變慢性 | ✓ **嬰幼兒才容易（30–90%）**；成人約 10% |
| ✗ anti-HBs 陽性代表正在感染 | ✓ **anti-HBs 代表痊癒或接種疫苗**；正在感染看 **HBsAg** |
| ✗ HDV 複製需要 HBV | ✓ **只有包裝與傳播需要 HBsAg**，**基因體複製不需要** |
| ✗ HDV co-infection 比 superinfection 嚴重 | ✓ **superinfection 更常見、更嚴重**（> 60% 肝硬化） |
| ✗ HEV 會變成慢性肝炎 | ✓ **不會**；特別處是**孕婦第三孕期死亡率 20%** |
| ✗ C 肝有疫苗 | ✓ **沒有 HCV 疫苗**；靠血源篩檢與風險行為改變 |
