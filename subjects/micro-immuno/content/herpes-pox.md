## 3. 疱疹病毒共同特性 ⭐⭐

- **大型、有套膜的二十面體 capsid，線狀 dsDNA**（考古陷阱：❌「雙股環形」）。
- 構造由內而外：DNA core → **capsid** → **tegument**（基質蛋白＋酵素：幫 DNA 複製、躲免疫）→ **envelope**（glycoprotein spikes）。
- 基因多、蛋白功能重疊（redundancy）；UL／US 兩端的 **inverted repeats** → 基因體重組、形成異構物（HSV、VZV、CMV）。
- **自己編碼 DNA polymerase → 抗病毒藥的標的**。
- **DNA 複製與 capsid 組裝都在細胞核**。
- 釋放：exocytosis、cell lysis、**cell–cell bridges**（細胞融合 → 躲抗體）。
- 感染型態：**lytic、persistent、latent，EBV 還會 immortalize**。
- ⭐ **所有疱疹病毒都會潛伏 → 終生感染、會復發、無法根治**；控制主要靠**細胞性免疫**。

### 複製：IE（α）→ E（β）→ L（γ）

| 時期                     | 做什麼                                             |
| ------------------------ | -------------------------------------------------- |
| Immediate-early（**α**） | DNA-binding protein、調節因子 → 掌控宿主轉錄機器   |
| Early（**β**）           | 複製相關：**DNA polymerase**、轉錄因子             |
| Late（**γ**）            | 大量**結構蛋白** → 組裝                            |

- Tegument 蛋白：**α-TIF（VP16）**和宿主轉錄因子結合 → 啟動 IE 基因；**vhs（UL41）**關掉宿主蛋白合成、分解宿主 mRNA。
- **Rolling circle replication**：線狀 DNA 先環化 → 一長串連續基因體 → 包進 procapsid 時再切開（在細胞核）。

## 4. HSV-1／HSV-2（單純疱疹病毒）⭐⭐

- Herpes 源自希臘文「**to creep**（爬行）」。HSV-1 偏上半身（口傳播）、HSV-2 偏下半身（性傳播），但兩者都可能出現在任一處。
- 致病：細胞病變、**cell-to-cell spread 與多核巨細胞（syncytia）躲抗體** → 主要靠 **TH1、CTL** 清除；症狀多來自細胞免疫的免疫病理。
- **潛伏處**：**HSV-1 → 三叉神經節（trigeminal ganglia）**；**HSV-2 → 腰薦脊神經節（lumbosacral）**。沿感覺神經回到皮膚 → **復發在同一個位置**。
- **LATs（latency-associated transcripts）**：潛伏時累積的轉錄物（其餘基因休眠），調節潛伏並參與早期再活化。
- **復發誘因**（Box 53-3）：**UV-B**（滑雪、曬太陽）、**發燒（fever blister）**、情緒壓力（例如期末考）、物理刺激、月經、辛辣酸性食物、免疫抑制（化放療、HIV）。

| HSV-1 疾病                    | 重點                                                                     |
| ----------------------------- | ------------------------------------------------------------------------ |
| **Herpes labialis（唇疱疹）** | **最常見的復發型 HSV-1**；唇黏膜交界處；先癢、刺痛 → 水泡 → 2–3 天結痂  |
| Herpetic gingivostomatitis    | 幼童口咽感染；發燒、喉痛、淋巴結腫                                       |
| Herpes pharyngitis            | 年輕人喉嚨痛                                                             |
| Herpetic keratitis            | 眼疱疹：異物感、結膜炎、刺痛、畏光                                       |
| **Herpetic whitlow**          | **手指感染；醫護人員**                                                   |
| Herpes gladiatorum            | 摔角手：身體皮膚                                                         |
| Eczema herpeticum             | 瀰漫至多器官（眼、腦、肺、肝），少見                                     |
| **Herpes encephalitis**       | **死亡率 70%**，少見；MRI 顳葉破壞、CSF 有 RBC、PCR 陽性                 |

- **HSV-2 生殖器疱疹**：倦怠、厭食、發燒、兩側鼠蹊腫痛 → 生殖器、會陰、臀部成簇水泡 → 潰瘍；尿道炎、排尿痛。**復發較輕**（月經、壓力、細菌感染誘發）。
- **新生兒疱疹（多為 HSV-2）**：產前或產道感染；口、皮膚、眼、**CNS**，可致命 → **孕婦篩檢；生產時正在發作就剖腹產**。
- 病程：初次感染症狀重、復發輕；**水泡破掉（wet ulcer）時傳染力最強**，結痂代表免疫在作用。
- 高風險：小孩（HSV-1）、性活躍者（HSV-2）、醫護（whitlow）、免疫低下、新生兒。**無疫苗**。

| 方法                         | 看什麼                                                                                             |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| **Tzanck smear**（刮潰瘍底） | **多核巨細胞（Tzanck cell）＋ Cowdry type A inclusion bodies**；又稱 chickenpox／herpes skin test |
| 細胞培養                     | 多數細胞株可見 CPE                                                                                 |

- **Cowdry type A**：核內嗜酸性小滴，周圍有透明光暈，染色質推到核膜邊緣。

### 抗疱疹藥 ⭐⭐⭐

- **多數是 nucleoside analogue，標的是病毒 DNA polymerase**。
- **Acyclovir（ACV）＝最常開的抗 HSV 藥**：**guanosine analogue**；先被**病毒 thymidine kinase（Tk）**磷酸化，再由宿主酵素變成 acyclo-GTP → 當病毒 polymerase 的受質 → **少了 3'-OH，鏈終止**。對病毒 polymerase 的親和力約為人類的 **100 倍** → 毒性低。
- **只能壓制，不能清除潛伏感染**（考古：❌「Acyclovir can cure latent HSV」）。
- **Foscarnet**：**pyrophosphate 類似物**，佔住 DNA polymerase 的焦磷酸結合位；用在 **ACV 抗藥（Tk 突變）的 HSV 與 CMV**。
- FDA 核准藥（Box 53-5）：HSV：acyclovir、penciclovir、valacyclovir、famciclovir、ara-A、trifluridine；VZV：acyclovir、famciclovir、valacyclovir、**VZIG**、活疫苗；**EBV：none**；CMV：**ganciclovir**、valganciclovir、foscarnet、cidofovir。

## 5. VZV（水痘－帶狀疱疹病毒）⭐⭐

- **初次感染 = 水痘（chickenpox、varicella）**：經典兒童出疹病之一（其他：rubella、roseola、fifth disease、measles）；斑點 → 丘疹 → 水泡 → 膿疱 → 結痂，**各階段同時存在**，集中在軀幹。
- **復發 = 帶狀疱疹（shingles、zoster，皮蛇）**：潛伏在**背根、顱神經節**，免疫下降時沿**單一皮節（dermatome）**出現帶狀、疼痛水泡，好發 45 歲以上；起疹前 4–5 天單側神經痛。
- ⭐ **和 HSV 不同：VZV 主要經呼吸道（飛沫）傳染**，也可接觸。呼吸道初始複製 → 病毒血症 → 皮膚。
- 會形成 syncytia、躲體液免疫 → **細胞性免疫是控制關鍵**。
- 風險族群：5–9 歲（輕）；青少年與成人（可能致命肺炎）；**老人、免疫低下（帶狀疱疹）**；新生兒、免疫低下（肺炎、腦炎、瀰漫性水痘）。考古：❌「VZV 主要風險族群是移植病人與新生兒」（移植是 CMV）。
- 診斷：**ELISA 測抗原、PCR**；已開發國家 >90% 成人有 VZV 抗體。
- 治療：兒童通常不用；成人、免疫低下用 **ACV、famciclovir、valacyclovir**、**VZIG**。預防：**減毒活疫苗（Oka 株）**；帶狀疱疹疫苗 **Zostavax、Shingrix**（預防 shingles 與疱疹後神經痛）。

## 6. EBV（Epstein-Barr virus）⭐⭐⭐

- 無所不在；感染淋巴組織與唾腺；**唾液、口腔接觸、共用牙刷杯子** → 「**kissing disease**」。中年前 **90–95%** 都感染過；**潛伏在（記憶）B 細胞**。
- **Infectious mononucleosis（傳染性單核球增多症）**：潛伏 30–50 天；**三聯徵：淋巴腺腫、脾腫大、滲出性咽炎**＋高燒、疲倦；扁桃腺偽膜、oral hairy leukoplakia；**給 ampicillin 會起疹**。
- **Downey cell（atypical lymphocyte）＝ 活化增生的 T 細胞**（不是 B 細胞）：細胞質更嗜鹼、有空泡，核呈卵形、腎形或分葉，邊緣被紅血球壓出鋸齒。⭐ 考古：❌「Downey cells 是被 EBV 永生化的 B 細胞」。
- 致癌（EBV＋其他因子）：
  - **Burkitt's lymphoma**：B 細胞惡性腫瘤，**中非 4–8 歲兒童、下顎**，和瘧疾等慢性共感染有關。
  - **鼻咽癌（NPC）**：**上皮細胞**惡性腫瘤，年長的華人與非洲男性；**台灣 60–85% 的 NPC 有 EBV**。老師補充：和飲食、習慣（鹹魚、抽菸、檳榔）有關。
  - 免疫缺陷者對 EBV 高度易感（Clinical Case 53-2：Duncan 家族 X-linked 淋巴增生症）。
- **Heterophile antibody（嗜異性抗體）**：**不是針對 EBV**，是 EBV 像 mitogen 一樣非專一活化 B 細胞產生的；可跨物種反應 → **Monospot test（馬紅血球）**。出現在**急性期、短暫**。
- 病毒蛋白：**ZEBRA**（Z 基因，啟動 IE 與 lytic cycle）、LP、**LMPs（類致癌基因）**、EBNA。

| ---------------- | ----------- | ------- | ------- | --- | ----- |

- **生病期間：anti-VCA、anti-MA；恢復期才出現 anti-EBNA**（老師：「Anti-EBNA 是你好了之後 develop 的抗體」）。
- anti-EBNA 陽性 ≠ 病毒清光（終生潛伏）、≠ 一定是 Burkitt。

- 流行病學：孩童無症狀或輕微、青少年成人 → IM、免疫低下 → 腫瘤；**無季節性；目前沒有控制方法**。

## 7. CMV（巨細胞病毒）⭐⭐⭐

- 產生帶**核內與細胞質包含體**的巨細胞；**owl's eye（貓頭鷹眼）inclusion body**、basophilic inclusion。
- 傳播：**唾液、呼吸道黏液、母乳、尿、精液、子宮頸分泌物**、輸血、器官移植、胎盤。多數**無症狀、潛伏**於各種組織（單核球、巨噬細胞、T 細胞）。
- ⭐ **最常見造成先天缺陷的病毒（most common viral cause of congenital defects）**。
- ⭐ 老師明講考法：「**如果考試問 CMV 的 primary target population**，就回 **perinatal（胎兒、新生兒）、免疫低下的 AIDS 病人、移植病人**」。
- **結果高度取決於免疫狀態**：正常人 → 無症狀帶原或 **mononucleosis（heterophile Ab 陰性）**；血清陰性母親的新生兒 → **cytomegalic inclusion disease**；AIDS、免疫抑制 → 多部位症狀。

| 族群               | 表現                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------- |
| **先天（新生兒）** | 肝脾腫大、黃疸、出血點、**小頭畸形、腦內鈣化**、眼部發炎；存活者**失聰、視力障礙、智能缺陷** |
| 周產期             | 多無症狀，或肺炎、類單核球增多症                                                             |
| **AIDS**           | CMV mononucleosis、瀰漫性 CMV、**視網膜炎（retinitis）**                                     |
| **移植**           | **肺炎**、肝炎、心肌炎、腦膜腦炎                                                             |

- 細胞性免疫負責痊癒，抗體作用有限；抑制細胞性免疫 → 復發、嚴重。
- 診斷（Table 53-7）：細胞學「owl's eye」、抗原、原位雜交、PCR；**人類二倍體纖維母細胞**培養看 CPE、免疫螢光測 early antigen（最常用）；血清學只看初次感染。
- 治療**只用在免疫低下者**：**ganciclovir**、cidofovir、foscarnet。控制：篩檢捐血與器官捐贈者。

## 8. HHV-6、HHV-7、HHV-8 ⭐

- **HHV-6（human T-lymphotropic）**：唾液傳播、很常見；**2–12 個月嬰兒玫瑰疹（exanthem subitum、roseola）**：**突然高燒約 3–4 天 → 退燒後才出疹**（淡紅斑丘疹），自限。成人可有類 mono 症狀；>70% 多發性硬化症病人有感染跡象；**在多種癌症被偵測到**（Hodgkin's lymphoma、口腔癌、glioma、某些 T 細胞白血病）。
- **HHV-7**：和 HHV-6 很像，也造成玫瑰疹；**主要在 CD4⁺ T 細胞**。
- **HHV-8（KSHV）**：**oncovirus**，**AIDS 病人常見腫瘤 Kaposi's sarcoma**；也可能和多發性骨髓瘤有關。

## 🎙️ 上課錄影重點（林良宗，2026/11/4）

- **表格會考**：「tables are very important… I'm hinting you, you will see it again」[00:00]；複習時用 Table 53-1 和 HHV 疾病表互相比較 [00:49]。
- **潛伏的邏輯** [07:00–10:20]：病毒複製就會做蛋白 → 被免疫系統看到；疱疹病毒的策略是「**躲起來不複製**」= latency → 等宿主狀況差再出來 → **一旦感染就終生帶著、會在同一個地方復發，無法根治，只能 suppress**。
- **分組看潛伏處** [12:52]：α 躲神經、γ 躲 B 細胞（EBV、KSHV，**和癌症有關**）、β 是單核球、淋巴球（CMV、HHV-6、HHV-7）。
- HSV-1 約 **75%** 人口抗體陽性；AIDS 病人的疱疹嚴重、一個月好不了，**要用打的、大量用藥壓住** [18:37]。
- **HSV-2 與孕婦** [20:41]：第三孕期、生產前檢查 HSV-2；**生產時正在發作就剖腹產**，避免嬰兒經產道感染。
- **診斷要念**：HSV 用 **Tzanck smear** 看多核巨細胞、Cowdry type A [22:30]。
- **Acyclovir 機制** [23:42]：nucleoside analog、少一個 OH → chain termination；要先經**病毒 thymidine kinase** 修飾，對病毒 polymerase 的親和力約高 **100 倍** → 所以對人毒性低。每個病毒後面的 **clinical case 建議多念**。
- **VZV 是呼吸道（droplet）傳染** [26:18]，要特別注意。
- **EBV** [26:18–29:27]：NPC 好發亞洲年長男性，和飲食與習慣（鹹魚、抽菸、檳榔）有關；**anti-EBNA 是好了之後才出現的抗體**；**heterophile antibody 不是針對 EBV**，是 B 細胞被感染後亂放的抗體，會和其他動物紅血球反應；診斷看 atypical lymphocyte（Downey cell）。
- **CMV 考法（老師直接講）** [29:27]：「**如果考試問 CMV 的 primary target population**，就回 perinatal、AIDS 等免疫低下、移植病人」；**most common viral cause of congenital defects**；owl's eye inclusion；CMV 的 mononucleosis 是 **heterophile antibody negative**。
- **HHV-6 玫瑰疹** [12:52]：一歲以下嬰兒突然發高燒三、四天不退、沒有其他感冒症狀，接著出疹就好了。
- **Summaries 一定要念** [29:27]：「make sure you read them」，含 port of entry、傳播、治療的表。
