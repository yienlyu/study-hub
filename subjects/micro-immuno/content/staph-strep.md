# 葡萄球菌、鏈球菌、腸球菌（依百十三共筆整理，黃姿雯）

> 百十四共筆還沒出，以下暫依**百十三共筆 W7（學藝未審版）**整理，搭配考古詳解；百十四出來後改成依百十四整理、對照百十三。黃姿雯老師 10/17 公布的講義重點在「上課 slides」分頁。

## 1. 鑑別流程 ⭐⭐
```
G(+) cocci
├─ Catalase (+) → Staphylococcus（葡萄串）
│   ├─ Coagulase (+)、mannitol 發酵 (+)、β 溶血 → S. aureus
│   └─ Coagulase (−)（CoNS）→ S. epidermidis（導管、人工瓣膜）、S. saprophyticus（年輕女性 UTI 5–10%）
└─ Catalase (−) → Streptococcus / Enterococcus（鏈狀）
    ├─ β 溶血 → Lancefield（細胞壁 C-carbohydrate）
    │   ├─ Group A：S. pyogenes（bacitracin 敏感）
    │   └─ Group B：S. agalactiae（**CAMP test +**）
    ├─ α 溶血
    │   ├─ Optochin 敏感、bile soluble、Quellung (+) → S. pneumoniae（雙球菌、莢膜）
    │   └─ Optochin 抗性 → Viridans streptococci（mitis → 亞急性心內膜炎；mutans → 蛀牙）
    └─ γ（不溶血）/ 6.5% NaCl、bile-esculin 生長 → Enterococcus（faecalis、faecium）
```

| 菌 | Catalase | 溶血 | CAMP |
|---|---|---|---|
| S. aureus | + | β | − |
| S. pyogenes | − | β | − |
| S. agalactiae | − | β | **+** |
| E. faecalis | − | γ | − |

## 2. *Staphylococcus aureus*
- G(+) 小球菌、成堆不規則排列（0.5–1.5 μm）、兼性厭氧、**不會動**；**耐乾、耐高鹽、耐極端 pH**，容易留在環境中散播；培養基上大而圓、不透明的菌落。
- 棲息：**鼻腔前側（anterior nares）、皮膚、鼻咽**；約 **20–60% 健康成人**帶菌。其他常駐：*S. capitis*（皮脂腺）、*S. hominis*（頂漿腺），通常不致病。
- 易感：衛生差、營養不良、組織受傷、免疫低下（肝病、糖尿病、HIV、化療）。
- 毒力（老師上課提到的是 capsule、slime layer、Protein A）：
  - **結構**（指數生長期表現）：**capsule**、**slime layer**（含黏附蛋白）都抑制吞噬；peptidoglycan（類似 endotoxin 作用）；teichoic acid；**Protein A**（*S. aureus* 特有，抓 **IgG1、2、4 的 Fc**，抑制調理）；**coagulase**（*S. aureus* 特有；bound form 與 free form；fibrinogen → fibrin 形成屏障）。
  - **酵素**（穩定期、quorum sensing 後才釋放）：coagulase 隔絕免疫細胞；**hyaluronidase**（分解結締組織）、**fibrinolysin**（溶解血塊，與 coagulase 相反）、lipase、**nuclease**（切 NETs 逃脫、避免被死細胞的黏稠 DNA 黏住）幫助擴散；另有 catalase。
- 毒素：
  - **Cytotoxins**（攻擊紅血球、白血球、血小板、巨噬細胞、纖維母細胞的膜；要記功能）：**α**（最常見，組織壞死）、**β = sphingomyelinase C**（水解膜磷脂）、**δ**（幾乎所有葡萄球菌都有，像界面活性劑）、**γ**（在膜上穿孔，類似補體 MAC）、**PVL**（特殊菌株，類似 γ toxin 穿孔）。
  - **Exfoliative toxin**（serine protease，切 **desmoglein 1**，表皮與真皮分離）→ **SSSS 燙傷樣皮膚症候群**（好發新生兒；患部常培養不到菌，因為是毒素作用）。**ETA 耐熱、來自 phage**；**ETB 不耐熱、來自質體**。
  - **Enterotoxin**（A 最常見；**heat-stable**，100 °C 15–30 分鐘以上才失活；superantigen；促 mast cell 釋放介質 → 蠕動↑、嘔吐）→ **食物中毒：吃到預先形成的毒素**，快速嘔吐
  - **TSST-1**（superantigen，通常沒有外傷）→ **Toxic shock syndrome**（90% TSS；年輕女性與**衛生棉條**有關）
- 疾病：**局部皮膚**——毛囊炎 → 癤（furuncle）→ 膿疱（impetigo，常見新生兒）；**系統性**——骨髓炎（好發骨骺端 metaphysis）、菌血症（醫療器材）→ **急性心內膜炎**、肺炎（老人、幼童、肺病者；膿胸、敗血性休克）、敗血性關節炎。
- **CoNS**（無 coagulase；院內、伺機感染）：*S. epidermidis*（導管、分流管、**人工關節、心瓣膜、血管支架**的 biofilm）、***S. saprophyticus*（性行為頻繁年輕女性的 UTI）**；傷口感染則 *S. aureus*、CoNS 都有。
- 抗藥：**MRSA**：外來移動因子 **SCCmec**（含 **mecA**）經水平轉移插入 → 變異的 **PBP2a**，β-lactam 親和力差。
  - **HA-MRSA**（醫院，多重抗藥）vs **CA-MRSA**（社區，地域性：美國 USA300、亞洲 ST59；**SCCmec IV、產 PVL**，常引起嚴重肺炎；β-lactam 以外的抗生素仍有效）。台灣院內 MRSA 比例由約 80% 降到約 60%。
  - 治療：MSSA → methicillin／oxacillin；MRSA → TMP-SMX、doxycycline 口服，**vancomycin、daptomycin** 靜脈。預防：洗手；主動監控（ICU 鼻腔採檢，陽性用 **mupirocin** 去移生 5 天＋全身清潔）。
  - 檢測：MALDI-TOF、無菌部位感染直接 Gram 染色。
- ⚠️ 不會產生 IgA protease（那是肺炎鏈球菌、Neisseria）、不會產生 C5a peptidase（那是 GAS）；不會造成 rheumatic fever。

## 3. *Streptococcus pyogenes*（GAS）
- 鏈球菌共通：G(+)、成對或成鏈、兼性厭氧、**catalase (−)**、不動、不產孢子；需要營養豐富的培養基（加血液、血清），有些要 CO₂（capnophilic）→ **不是院內感染菌**（和 *S. aureus* 最大差別）。
- 分類：**Lancefield**（1933，細胞壁 C-carbohydrate：A、B、C、F、G）、**溶血**（β：GAS bacitracin 敏感、GBS 抗性；α：肺炎鏈球菌 optochin 敏感、草綠鏈球菌抗性；γ：腸球菌）。
- GAS 特性：β 溶血強（比 GBS 強）、小白菌落、受高濃度葡萄糖抑制；group A 抗原 = N-acetylglucosamine＋rhamnose。
- 棲息：**口咽**（健康孩童與年輕人無症狀帶菌）；冬天、密閉空間飛沫傳染。最嚴重的鏈球菌疾病多由 GAS 造成。
- 毒力：**M protein**（GAS 特有；C 端保守、**N 端變異 → 依 emm 基因分型**；干擾 C3b；class I 與 rheumatic fever 有關）、**M-like protein**（抓 Fc、fibronectin）、黏附三要素 **LTA、M protein、F protein**（內化後可持續感染）、hyaluronic acid 莢膜、**C5a peptidase**、streptokinase、DNase（逃 NETs）、**Streptolysin O**（oxygen-labile、抗原性強 → **ASO titer**；被皮膚膽固醇抑制 → 膿皮症不易測得）、Streptolysin S。
- **SpeA（pyrogenic / erythrogenic exotoxin）**：**superantigen**，由 **lysogenic phage** 基因編碼 → **猩紅熱**（strawberry tongue、Pastia's lines）。
- 化膿性疾病：
  - **咽喉炎**（孩童細菌性喉嚨痛多為 GAS；2–4 天發病；有白色滲出物）→ 未治療 → **猩紅熱**（全身紅疹、**口周蒼白**、**草莓舌**、**Pastia line**）。
  - 皮膚（菌株與咽喉炎不同）：**impetigo／pyoderma**（結痂，採檢要掀開痂）、**erysipelas**（臉與四肢、**界線清楚**）、**cellulitis**（深及皮下、**界線不清**）、**壞死性筋膜炎**（噬肉菌；沿筋膜擴散 → 清創＋抗生素，可能 STSS）。
  - 系統性：菌血症、肺炎、**產褥熱**、**STSS**（有黏多醣莢膜與 SpeA、SpeC 的菌株）。
- **非化膿性後遺症**（抗體介導、像自體免疫）：**Rheumatic fever**（咽喉炎後、class I M protein）、**Acute glomerulonephritis**（**多在皮膚感染後**、nephritogenic M protein）。
- 診斷：Gram 染色；培養（後咽、扁桃腺；bacitracin 或 **PYR**）；抗原快篩（專一高、敏感低 → 陰性要再確認）；**ASO**（風濕熱、AGN）、**anti-DNase B**（腎絲球腎炎）；PCR。
- 治療：penicillin／amoxicillin（過敏改 cephalosporin、macrolide）；風濕熱患者長期預防性抗生素。**GAS、GBS 都沒有抗藥性問題、也都沒有疫苗**。
- 其他 β 溶血：*S. anginosus*（小菌落、局部化膿）、*S. dysgalactiae*（咽喉炎、可致 AGN 但**不會**風濕熱）。
- 考題：Group-specific carbohydrate **每株 GAS 都有，不是區分毒性的標準**；M4、M22 亞型沒有莢膜。

## 4. *Streptococcus agalactiae*（GBS）
- 棲息：陰道、泌尿生殖道、下消化道。
- **新生兒腦膜炎、敗血症的主因**（產道感染；帶原母親約 60% 傳給嬰兒）：

| | 早發性 | 晚發性 |
|---|---|---|
| 時間 | 出生**一週內**（生產時） | 一週到三個月（照顧時） |
| 表現 | 菌血症、肺炎、腦膜炎 | 菌血症、腦膜炎 |
| 預後 | 15–30% 神經後遺症 | 死亡率較低，25–50% 神經併發症 |
| 血清型 | Ia、III、V | **III** |

- 成人：孕婦產後子宮內膜炎、UTI（預後佳）；有基礎病的老人菌血症、肺炎等，死亡率較高。陰道帶菌女性約 10–30%。
- 毒力：**莢膜**（9 型 Ia、Ib、II–VIII）、**sialic acid** 抑制補體替代路徑。
- 診斷：CSF Gram 染色；孕婦**35–37 週**陰道／直腸採檢（PCR）；LIM broth；**bacitracin 抗性、CAMP (+)、分解 hippurate**。產時預防性抗生素（IAP）大幅降低新生兒疾病。
- β 溶血（比 GAS 弱）、菌落大；Lancefield B 抗原在**細胞壁**（C-carbohydrate）。

## 5. *Streptococcus pneumoniae*
- G(+) 雙球菌（lancet-shaped）、α 溶血、catalase (−)、**optochin 敏感**、**bile soluble**、inulin 發酵、**Quellung reaction**。
- 造成 **60–70% 細菌性肺炎**；約 90 種莢膜血清型。培養要血液或 **chocolate agar**、5–10% CO₂；有氧 α 溶血、厭氧 β 溶血。
- 不靠外毒素，靠結構與酵素：**polysaccharide capsule**（抗吞噬）、**IgA protease**、**pneumolysin**（結合膜上膽固醇打洞）。
- 疫苗：**PPV23**（多醣，≥2 歲到成人）、**PCV13**（接上減毒白喉毒素，6 週–5 歲；台灣 104 年起常規 2＋1：2、4、12–15 個月）。
- 高危：**6 個月–4 歲**、**>60 歲**、免疫低下；冬天；**內源性、社區感染（非院內）**，老人常先有病毒感染再併發。疾病：**大葉性肺炎**（先像感冒，後突發高燒、寒顫、胸痛、咳血）、鼻竇炎、**中耳炎**（5 歲前）、腦膜炎、菌血症（25–30% 肺炎病人）。
- 診斷：痰 Gram 染色（失敗率約 50%）、**Quellung reaction**、CSF 血清檢測；和其他 α 溶血菌區分：inulin 發酵、optochin 敏感、bile soluble。
- 抗藥：**PBP 改變**（PRSP），不是 penicillinase。
- 疫苗無法涵蓋所有血清型。

## 6. Viridans & Enterococcus
- **Viridans**（形容詞，不是菌名＝在血液培養基呈綠色的一群）：α 或 γ 溶血、optochin 抗性、不用 Lancefield；口腔、口咽、消化道、生殖道、皮膚的好菌，少數致病。
  - **mitis group**（*S. mitis*、*S. oralis*；penicillin 抗藥增加）→ **亞急性心內膜炎**（比 *S. aureus* 的急性心內膜炎溫和；在瓣膜形成 biofilm／vegetation；高風險病人牙科處置前預防性抗生素）。
  - **mutans group**：*S. mutans* → **蛀牙**（黏液層 → 牙菌斑；醣類發酵成酸）。
- **Enterococcus**（已從鏈球菌屬獨立；*E. faecalis*、*E. faecium*）：G(+) 成對或短鏈（外觀難與肺炎鏈球菌區分）；好氧厭氧都長、**10–45 °C、pH 4.6–9.9、高鹽與膽鹽中可生長**；乳酸菌；多為不溶血；**PYR (+)**、optochin 抗性、不被膽鹽溶解。
  - 毒力不多：黏附與 **biofilm**、**抗藥性**（天生抗 oxacillin、cephalosporin；獲得性抗 aminoglycoside、**vancomycin**，由**質體**介導可傳給別菌；*E. gallinarum*、*E. casseliflavus* 天生抗 vancomycin）。
  - **最常見的院內感染菌之一**：**UTI（導尿管，最常見）**、腹膜感染（多菌混合）、菌血症、**心內膜炎**（最難治）。危險因子：導尿管或血管導管、長期住院、廣效抗生素。
  - 治療：**aminoglycoside＋細胞壁抗生素（ampicillin 或 vancomycin）**合併；VRE 用 linezolid、quinupristin/dalfopristin（對 *E. faecalis* 無效）；隔離與限制抗生素。

## 7. 疾病 ↔ 病原速查
| 疾病 | 病原 |
|---|---|
| Toxic shock syndrome | S. aureus（TSST-1）；GAS（STSS） |
| 燙傷樣皮膚症候群 | S. aureus exfoliative toxin |
| 食物中毒（2–6 h 嘔吐） | S. aureus enterotoxin |
| 咽喉炎、猩紅熱、壞死性筋膜炎 | S. pyogenes |
| Rheumatic fever、AGN | S. pyogenes（非化膿性） |
| 新生兒腦膜炎 | S. agalactiae（GBS） |
| 肺炎（社區） | S. pneumoniae |
| 亞急性心內膜炎 | Viridans（S. mitis） |
| 導尿管 UTI（院內） | Enterococcus、CoNS |
| 胃潰瘍 | ❌ 不是 staph → *H. pylori* |

| 局部皮膚感染 | **毛囊炎** → **癤（furuncle）** → **癰（carbuncle，多個癤相連、更深）**；**膿皰病（impetigo）**：新生兒最常見 |
| 全身性感染 | 骨髓炎（**metaphysis** 形成膿瘍）、菌血症（來自其他感染部位或醫療器材；可併發心內膜炎）、肺炎與膿胸（壞死性肺炎 + 敗血性休克，死亡率高）、敗血性關節炎 |
| CoNS | 院內與伺機感染：***S. epidermidis***（傷口、**導管與分流管、人工植入物**最常見）；***S. saprophyticus* → 年輕性活躍女性 UTI**；其他 CoNS → 導尿管 UTI；*S. aureus* 可經菌血症播種到泌尿道 |
| 流行病學 | 健康成人帶菌率 **20–60%**（前鼻孔、皮膚、鼻咽、腸道）；危險因子：衛生營養差、組織損傷、原發感染、糖尿病、免疫缺陷 |
| MRSA | **HA-MRSA**：多重抗藥（常見）；**CA-MRSA**：與 HA-MRSA 無關、各國菌株不同（美國 **USA300**、亞洲 **ST59**）；皮膚感染、嚴重肺炎；帶 **SCCmec IV 與 PVL**；**除 β-lactam 外對多數抗生素仍敏感** |
| 預防 | 醫護 universal precautions；MRSA 主動與被動監測；**局部 mupirocin 去移生（decolonize）**；洗手 |
| 檢驗 | 檢體：膿、滲出液、痰、尿、血；**成簇或四聯體 G(+)**；大菌落、**β 溶血**；Staph tri-plate、**heat-stable nuclease**、**mannitol 發酵**、**novobiocin 敏感**；*S. aureus*：**coagulase (+)**、**Protein A (+)**（乳膠凝集：塗 fibrinogen 與 IgG） |

## *Streptococcus*（鏈球菌屬）
| 項目 | slides 重點 |
|---|---|
| 特性 | 成對或成鏈；不產孢子、不會動；兼性厭氧、**需要血液或血清的營養培養基**；**catalase (−)**；部分是口咽正常菌；部分需 CO₂（capnophilic） |
| 分類 | ① **Lancefield 分群**（1933，Rebecca Lancefield）：依細胞壁 **C-carbohydrate**，用來快速鑑定溶血性鏈球菌 ② 溶血：**β（全溶血）**：A、B、C、F、G 群；**α（半溶血）**：*S. pneumoniae* 與 viridans；**γ（不溶血）**：*Enterococcus* ③ 生化特性：主要用在 α、γ 溶血菌 |

## *S. pyogenes*（GAS，化膿性鏈球菌）
| 項目 | slides 重點 |
|---|---|
| 菌落 | 短鏈、1–2 μm；**小白色菌落、大溶血圈**；**高濃度葡萄糖抑制生長** |
| 疾病地位 | 最嚴重的鏈球菌；**細菌性咽頭炎最常見原因**；化膿性感染；「**食肉菌**」→ 肌肉壞死 |
| 抗原 | **Group-specific carbohydrate**（細胞壁，乾重 10%；N-acetylglucosamine + rhamnose = Lancefield A 抗原）；**M protein**（type-specific，*emm* 基因；N 端可變、C 端保守；**class I M protein 與風濕熱有關**） |
| 抗吞噬 | **hyaluronic acid 莢膜**（免疫原性差）；**M protein 阻擋 C3b 結合**；M-like protein 抓抗體 **Fc** 或 fibronectin；**C5a peptidase** 使趨化因子 C5a 失活 |
| 黏附與入侵 | **LTA、M protein、F protein（接 fibronectin）**；M、F protein 內化 → 持續感染、深部組織 |
| Pyrogenic exotoxin（erythrogenic） | **SpeA–C、SpeF**；**heat-labile**；由 **lysogenic** 菌株產生；**superantigen** → **壞死性筋膜炎、STSS、猩紅熱紅疹** |
| Streptolysins | **SLS**：**oxygen-stable**、細胞結合型，溶 RBC、WBC、血小板 → **β 溶血**；**SLO**：**oxygen-labile**、有抗原性 → **ASO 抗體**；**被膽固醇抑制 → 皮膚感染不產生抗體** |
| 酵素 | **Streptokinase**（plasminogen → plasmin，溶血塊）；**hyaluronidase**（分解結締組織）；**DNase**（降低膿液黏稠）→ 幫助擴散 |
| 流行病學 | 健康兒童與年輕人口咽**暫時性帶菌**；咽炎病人分離到才有臨床意義；**飛沫**（教室、冬季）；入口：皮膚或咽部；未治療者產生抗特定 M protein 抗體 → 長期免疫（型別特異） |
| 化膿性：咽部 | **鏈球菌咽炎**（暴露後 2–4 天）；**猩紅熱**：咽炎併發症、帶 prophage 的菌株 → 瀰漫性紅疹、**口周蒼白、草莓舌、Pastia line** |
| 化膿性：皮膚 | **膿皰病（pyoderma / impetigo）**：接觸病人或污染物、皮膚破損 → 膿疱破裂結痂；**無全身症狀**；溫暖潮濕季節、衛生差的幼童；**造成皮膚感染與咽炎的菌株不同**；**丹毒（erysipelas）**：疼痛與全身症狀，老人與幼童、臉或腿；**蜂窩組織炎**：皮膚與皮下、感染界線不清 |
| 壞死性筋膜炎 | 深部皮下、沿筋膜擴散 → 肌肉與脂肪大量破壞 → 水泡、壞疽 → 多重器官衰竭；**積極外科清創** |
| 嚴重全身性 | 菌血症、肺炎、**產褥熱**；**STSS**：多伴菌血症與壞死性筋膜炎、有潛在疾病者高危；菌株有明顯黏多醣莢膜與 **SpeA、SpeC** |
| 非化膿性（抗體媒介） | **風濕熱**：**只接在咽炎後**（含亞臨床）、兒童、**class I M protein**；心、關節、血管、皮下；**急性腎絲球腎炎**：**皮膚感染後比咽炎後多**、nephritogenic M 血清型；腎炎、高血壓，可能心衰竭或慢性腎衰竭 |
| 檢驗 | 檢體取扁桃腺後咽、**痂皮下膿**；**bacitracin 敏感或 PYR (+)**；group carbohydrate 快篩：**快、專一但敏感度低 → 陰性要再確認**；**ASO → 風濕熱或 AGN**；**anti-DNase B → 鏈球菌腎絲球腎炎**（皮膚感染後也適用）；核酸擴增 |
| 治療 | **沒有疫苗**；咽炎：口服 penicillin 或 amoxicillin；過敏：口服 cephalosporin 或 macrolide；嚴重感染：靜脈 penicillin **+ 蛋白合成抑制劑**；**風濕熱病人長期預防性抗生素** |

## *S. agalactiae*（GBS，無乳鏈球菌）
| 項目 | slides 重點 |
|---|---|
| 特性 | β 溶血、B 群唯一菌種；菌落比 GAS 大、溶血圈較小（1–2% 不溶血） |
| 血清標記 | ① B 群細胞壁多醣 ② **9 種莢膜多醣型**（Ia、Ib、II–VIII；**Ia、III、V 最常見**）③ 表面蛋白（c antigen） |
| 致病 | 莢膜抗吞噬（直到有型特異抗體）；Ia、Ib、II 型莢膜末端 **sialic acid → 抑制補體 alternative pathway** |
| 新生兒 | **新生兒腦膜炎與敗血症主因**；**早發型**：子宮內或出生時感染、**第 1 週內**發病（菌血症、肺炎、腦膜炎，要驗 CSF；存活者 15–30% 神經後遺症）；**晚發型**：外來感染（母親或其他嬰兒）、**1 週到 3 個月**、菌血症合併腦膜炎（死亡率低但神經併發症 25–50%） |
| 成人 | 孕婦：產後子宮內膜炎、傷口、UTI（預後好）；男性與非孕婦：老人或有潛在疾病者菌血症、肺炎、骨關節、軟組織 → 死亡率相對高；**孕婦風險高於男性與非孕婦** |
| 流行病學 | 移生在**下消化道與泌尿生殖道**；陰道暫時帶菌 10–30%；出生時母傳子約 60%；**早發型以 Ia、III、V**；**晚發型多為 III 型**；成人以 Ia、V；**產中預防性抗生素**使新生兒病例大幅下降 |
| 檢驗 | CSF Gram stain；孕婦肛門陰道拭子 **PCR**；**LIM broth（colistin + nalidixic acid）**選擇性增菌；**bacitracin 抗性、CAMP (+)、hippurate 水解** |
| 預防與治療 | **懷孕 35–37 週篩檢**；penicillin（新生兒可選廣效）；過敏：cephalosporin 或 vancomycin；macrolide、clindamycin、tetracycline 抗藥常見；**帶菌或高風險孕婦都要化學預防** |

## 其他鏈球菌
| 菌 | slides 重點 |
|---|---|
| C、F、G 群 | 最常造成人類疾病的其他 β 溶血鏈球菌 |
| *S. anginosus* | 小菌落、窄 β 溶血圈（培養 2 天）；**膿瘍** |
| *S. dysgalactiae* | 大菌落、大溶血圈；咽炎 → **AGN（從不造成風濕熱）** |
| Viridans（草綠） | α 溶血與不溶血的異質群；***S. pneumoniae* 是其中最毒的**；牙齦、牙齒、口腔最多；侵襲力低，**牙科或手術讓它進入血流 → 牙科手術前預防性抗生素**；最嚴重 = **亞急性心內膜炎**（瓣膜上 biofilm 贅生物，原有心臟病者高危）；***S. mutans* slime layer → 牙菌斑、蛀牙**；penicillin 抗性漸增 |

## *S. pneumoniae*（肺炎鏈球菌）
| 項目 | slides 重點 |
|---|---|
| 地位 | **60–70% 細菌性肺炎** |
| 特性 | 有莢膜、橢圓、**成對（雙球菌）**或短鏈；blood agar（大菌落）或 chocolate agar（小菌落）；**5–10% CO₂** 長得好；**有氧培養 α 溶血（pneumolysin）、厭氧可 β 溶血**；高葡萄糖長不好（大量乳酸）；**多醣莢膜 > 90 種血清型** |
| 致病（**沒有毒素，症狀來自宿主反應**） | 表面 adhesin 移生；**secretory IgA protease**；**pneumolysin ≈ SLO**（接膽固醇、打洞，也活化補體）；teichoic acid 與 PDG 片段活化補體產生 C5a；過氧化氫 → ROS；**phosphorylcholine 接 PAF 受體 → 進入細胞躲避調理與吞噬**；莢膜與 pneumolysin 抑制吞噬細胞 oxidative burst |
| 流行病學 | 健康人喉嚨與鼻咽常駐（**6 歲兒童 ≫ 成人**）；冷季最多；**內源性感染**；離開棲地活不久 → **社區感染**；危險群：幼童、老人、免疫低下、肺病或病毒感染、群居；吸入肺 → 肺炎；經**耳咽管**到中耳 |
| 肺炎 | 起病急、寒顫、39–41 °C；**發病前 1–3 天常有病毒上呼吸道感染**；有痰帶血、胸痛；**大葉性肺炎**；高危：**6 個月–4 歲兒童、60 歲以上** |
| 其他疾病 | 鼻竇炎、**中耳炎**（幾乎每個孩子 5 歲前都得過）；**腦膜炎**（死亡率高、神經後遺症）；菌血症（肺炎 25–30%、腦膜炎 > 80%） |
| 檢驗 | 痰：細長成對 G(+) 球菌、周圍不染色莢膜；**Quellung 反應**（加型特異抗血清 → 莢膜膨脹）；CSF 測 C polysaccharide 抗原；**約一半肺炎病人痰培養陰性**；與其他 α 溶血菌區別：**inulin 發酵 (+)、optochin 敏感、bile soluble** |
| 治療 | penicillin G 或 V、cephalosporin、erythromycin、chloramphenicol；嚴重：**vancomycin + ceftriaxone** |
| 疫苗 | 血清型太多 → 只涵蓋高盛行型：**PPV23**（多醣、23 型、**2 歲以上**高風險者與成人）；**PCV13**（結合型：13 型接在**無毒突變白喉毒素**上；**6 週–5 歲**有效）；**台灣 104 年起 PCV13 納入常規接種，2、4、12–15 個月（2+1）** |

## *Enterococcus*（腸球菌）
| 項目 | slides 重點 |
|---|---|
| 分類 | **1984 年**獨立成屬，**舊稱 group D streptococci** |
| 特性 | 成對或短鏈 G(+) 球菌（像 *S. pneumoniae*）；catalase (−)；兼性厭氧、溫度與 pH 範圍廣；**可在高 NaCl 與膽鹽中生長**；***E. faecalis*（75%）、*E. faecium*（20%）** |
| 致病 | 住院病人的致命疾病；① **黏附與 biofilm**（表面蛋白、pili、膜醣脂、gelatinase）② **抗藥**：**先天對 oxacillin、cephalosporin 抗藥**；後天獲得 aminoglycoside、**vancomycin** 抗藥基因 |
| 疾病 | 人與動物腸道菌（*E. faecalis* 每克糞便 10⁵–10⁷）；**院內感染**：導尿管與器械相關 UTI、腹膜感染（多菌混合）、菌血症、心內膜炎 |
| 檢驗 | blood agar 上**多不溶血**；**optochin 抗性、不被膽汁溶解、PYR (+)** |
| 治療 | 多數抗生素在臨床濃度**不殺菌**；**aminoglycoside + β-lactam（ampicillin）或 vancomycin 協同**；抗藥時用 linezolid、daptomycin、tigecycline；限制抗生素使用與感染控制 |

## 🎙️ 錄影重點（10/21，黃姿雯）
| 主題 | 老師上課強調 |
|---|---|
| 考試範圍提醒 | **抗生素治療原則上不考**（三年級整合課程再學、guideline 會變），老師特別說會考的才要背；實驗室鑑定現在都用蛋白質圖譜（MALDI-TOF），但**傳統生化鑑定「考試還是會考」** |
| 球菌總覽 | 名字有 coccus 就是球菌；醫療重要的 G(+) 球菌只有 *Staphylococcus*、*Streptococcus*（+ *Enterococcus*）；*Neisseria* 名字沒有 coccus 但是 G(−) 球菌，致病種只有兩隻；**catalase** 一個測試就分開葡萄與鏈球菌 |
| 葡萄球菌生理 | **兼性厭氧、耐高鹽**（選擇性培養基把鹽濃度拉高）、耐 pH 與溫度 → **環境中容易留存** → 感控重點；*S. aureus* 移生在**鼻腔前側**；血盤上全溶血是 **α toxin**，外圈放冰箱後才溶的是 **β toxin**（hot-cold） |
| 毒力因子分兩階段 | 結構型（Protein A、coagulase、黏附蛋白）在 **exponential phase** 隨生長產生；分泌型毒素與酵素受 **quorum sensing** 調控，在 **stationary phase** 菌量夠多才一起分泌 |
| Peptidoglycan | 也能誘導 cytokine、造成類似內毒素的發膿反應，但**力道不如 G(−) 的 LPS** |
| Protein A | *S. aureus* 特有（「身分證」），結合抗體 **Fc region** → 中和抗體 |
| Cytotoxin 四型 | α：全溶血、組織破壞主角；β：**sphingomyelinase**，不立刻破膜；δ：像**界面活性劑**、無特異性；γ 與 **PVL**：多個次單元在宿主膜上**打洞**，概念像補體 MAC |
| 三種「特定菌株帶特定毒、引起特定病」 | **Exfoliative toxin**（protease 切 **desmoglein 1** → SSSS，嬰幼兒；病灶**採檢常看不到細菌**）；**Enterotoxin**（**heat-stable，100 °C 30 分鐘才破壞**；superantigen；**A 型最常見**；老師提醒「食物中毒千萬不要漏掉金黃色葡萄球菌」）；**TSST-1**（superantigen；**衛生棉條**案例；**> 90% TSS** 由 *S. aureus*，但該菌株**不造成一般傷口感染**） |
| 酵素 | **DNase**：打斷黏稠 DNA、**逃脫嗜中性球 NETs**；**coagulase**（bound + free）把 fibrinogen 變 fibrin「築城牆」，作用跟 **fibrinolysin 相反** |
| 皮膚感染 | 甲溝炎、毛囊炎 → 癤 → 癰；**impetigo 特別注意：新生兒、嬰兒房群聚**（醫護手部清潔） |
| 系統性感染 | 菌血症、**急性心內膜炎**（手術成功但術後感染）、肺炎；**容易忽略的：骨髓炎、敗血性關節炎**（案例：共用化妝刷 → 骨髓炎 → 下半身癱瘓） |
| CoNS | ***S. epidermidis***：產黏性物質與 **biofilm → 管路、人工裝置**；***S. saprophyticus***：**年輕、性生活頻繁女性 UTI**（老師反問：UTI 第一名仍是 **E. coli**，saprophyticus 只在這個特定族群最常見） |
| MRSA 機制 | 經水平基因轉移、**site-specific recombination** 取得 **SCCmec cassette** 上的 **mecA** → 做出對 β-lactam 親和力差的 **PBP2a**；**HA-MRSA 多重抗藥**；**CA-MRSA** 帶 **PVL** → 嚴重肺炎，但**對常規抗生素較敏感**；台灣 THARS 監測，醫院 MRSA 比例已降到 **60% 以下**；最後線藥 **vancomycin** |
| 感控 | 勤洗手、醫護常是傳播者（「staff → staph」）、**識別證**是常見留存處；**被動 vs 主動監測**：北醫附醫對進 ICU 病人做**鼻腔前側 MRSA 篩檢** → **mupirocin 抹鼻 + 頸部以下 chlorhexidine 擦澡**去移生（台灣多數醫院不做，擔心 mupirocin 抗藥） |
| 葡萄球菌三盤鑑定 | **Mannitol salt agar**（*S. aureus* 發酵、CoNS 不行）；**DNase agar**；**Novobiocin**：CoNS 中**只有 *S. saprophyticus* 抗性**；快篩：coagulase + Protein A **乳膠凝集** |
| 鏈球菌分類 | 溶血：β 全溶血、α 草綠、γ 不溶血；**viridans 是形容詞不是菌種名**；**optochin**：*S. pneumoniae* 敏感、其他草綠抗性；**bacitracin**：GAS 敏感、GBS 抗性；Lancefield 依細胞壁 **C carbohydrate**（區分 β 溶血菌） |
| GAS 毒力 | **玻尿酸莢膜 = 偽裝、低抗原性**；**M protein 抑制補體**；**C5a peptidase 只有 GAS 有**；**SpeA–E**：**heat-labile、在噬菌體、superantigen** → 壞死性筋膜炎、STSS、**猩紅熱紅疹**；**SLS** 造成全溶血、oxygen-stable；**SLO** 具抗原性 → **ASO**；**Streptokinase** 強到可當**溶血栓藥** |
| GAS 疾病 | 細菌性咽頭炎（**腫脹明顯 + 白苔**偏細菌性）→ 未治療可併發**猩紅熱**（軀幹紅疹、**草莓舌**、帕氏線）；兒童口周結痂 **pyoderma**；成人**丹毒（紅腫邊界清楚，臉與腳）** vs **蜂窩性組織炎（無邊界）** → **壞死性筋膜炎**（外表只紅腫，切開肌肉已糜爛；媒體稱「噬肉菌」） |
| 非化膿性併發症 | **抗體交叉反應**攻擊自身組織：**class I M protein → 風濕熱**（心臟、關節）；**腎型 M protein → 急性腎絲球腎炎**；用 **ASO** 判斷是否為鏈球菌感染後併發症 |

# 考點分析

## 🔥 高頻考點（39 題）
1. **鑑別題（情境 + 實驗室結果）**：catalase → 溶血 → CAMP / optochin / 6.5% NaCl。**幾乎每份考古都有 2–3 題**。
2. **疾病 ↔ 病原配對**（含組合題 ①–⑤）。
3. **S. aureus 毒素與酵素**：enterotoxin heat-stable、TSST-1 superantigen、Protein A、coagulase。
4. **GAS**：M protein 分型、SpeA superantigen、ASO、C5a peptidase、PSGN（孩童咽喉炎一週後腎炎）。
5. **S. pneumoniae**：capsule（抗吞噬 + 疫苗）、PBP 改變抗藥。
6. **棲息部位**：S. aureus 鼻/皮膚、S. pyogenes 口咽、E. faecalis 大腸、Viridans 口腔。

## ⚠️ 陷阱
- Lancefield 只用在 β 溶血菌；Viridans 不用。
- 猩紅熱毒素是 phage 基因插入細菌染色體表現，不是 phage 裂解釋出。
- S. aureus enterotoxin 是 heat-stable（加熱不一定能破壞）。
- 考古 Part II 第 3 題原答案「X」：第 19 題相同題幹，正確答案 ①③。
