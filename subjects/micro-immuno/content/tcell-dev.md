# T 細胞發育與抗原辨識（依 113 共筆整理）

## 1. TCR–CD3 complex
- TCR：**αβ（90–99%）** 或 **γδ（1–10%）**；各鏈有 V、C domain，V 上有 CDR1–3，**CDR3 最多變**（位於結合位中央、接 peptide）。
- **TCR 本身無訊息傳遞能力** → 靠 **CD3（γ、δ、ε、ζ）**：εδ、εγ、ζζ 三對；各鏈有 **ITAM**。
- Co-receptor：**CD4（接 MHC II β2）**、**CD8（接 MHC I α3）**，增加親和力並帶 Lck。

| | αβ T | γδ T |
|---|---|---|
| 多樣性 | 高 | 低（理論可更高，實際很有限） |
| CD4/CD8 | 單陽性，CD4 > CD8 | 多為 double negative 或 CD8⁺ |
| MHC 限制 | ✅ | **❌（不受 MHC 限制）** |
| 辨識 | pMHC | 完整分子、磷脂（IPP、MIC A/B） |
| 位置 | 淋巴器官 | 黏膜上皮 |

## 2. TCR 基因
- α ≈ Ig 輕鏈（V-J-C）；β ≈ 重鏈（V-D-J-C-D-J-C）；γ（V-J-C-J-C）；**δ（V-D-J-C）位於 α 基因座內（Vα 與 Jα 之間）**，α 重組時 δ 被刪除。
- 同樣有 **RSS 12/23 rule**、RAG、junctional diversity（P、N nucleotides）、allelic exclusion。
- TCR 特有：D 片段可 frameshift 讀取、δ 鏈可串接多個 D → 多樣性更高。
- ⚠️ **TCR 沒有 somatic hypermutation、沒有 class switch**。
- α chain CDR3 涵蓋 VJ 交界；β chain CDR3 涵蓋 VD、DJ 交界。

## 3. 胸腺中的發育
1. 骨髓 HSC → CLP → 胸腺。
2. **Double negative（DN1–4，皮質）**：Notch 訊號確定 T 命運；β 鏈重組、pre-TCR。
3. **Double positive（CD4⁺CD8⁺）**。
4. **Positive selection（皮質，cTECs）**：能**適度**辨識 **self-MHC** 者存活 → 決定 **MHC restriction**；辨識 MHC I → CD8，辨識 MHC II → CD4；不能結合者凋亡（death by neglect）。
5. **Negative selection（皮髓交界 / 髓質，mTECs、DC、macrophage）**：**對 self-antigen 親和力太強者凋亡** → **self-tolerance**；骨髓來源 APC（DC、macrophage）最重要，因為可在 MHC I、II 上呈現 self peptide 且集中在髓質。
6. 只有約 **5%** 存活 → single positive、成熟、MHC restricted、self-tolerant。
- Treg 在胸腺發育（tTreg）也參與 self-tolerance。
- MHC I/II 缺陷小鼠：positive selection 受阻 → **卡在 CD4⁺CD8⁺ DP 階段**。

## 4. T 細胞活化三訊號
- **Signal 1**：TCR–pMHC；CD4/CD8 → **Lck** 磷酸化 CD3/ζ 的 **ITAM** → **ZAP-70** → … → NFAT 等轉錄因子 → **IL-2**。
- **Signal 2（共刺激 = 保險）**：**CD28 ↔ B7（CD80/86）**；缺少 → **anergy**。ICOS、CD40–CD40L、**4-1BB（CD8 專屬）**。
  - 負調控：**CTLA-4（CD152）**：對 B7 親和力 ~20 倍於 CD28、可移除 B7；**PD-1–PD-L1**（腫瘤利用）→ checkpoint blockade（-mab）。
- **Signal 3**：cytokines 決定分化。
- 免疫突觸：中心 TCR / CD28，周邊 **LFA-1–ICAM-1**（TCR 結合後 LFA-1 親和力↑）；**L-selectin 只在 naïve T**（經 HEV 進淋巴結）。
- Effector T 只需 Signal 1。

# 考點分析

## 🔥 高頻考點
1. **Negative selection 機制**：自我抗原辨識 → **主動誘發凋亡**；T、B 細胞都有；Positive selection 才決定 MHC restriction。
2. **Positive selection 與 self-tolerance「最不相關」**（它與 MHC restriction 有關）。
3. **γδ T**：不受 MHC 限制；不是由 αβ T 衍生；來自骨髓、在胸腺成熟。
4. **TCR 敘述**：與 CD3 複合傳訊、在胸腺重組、CDR3 最多變；「因缺乏 SHM 而多樣性遠小於 BCR」為錯。
5. **δ 基因位於 α 基因座的 V 與 J 之間**。
6. **HIV 經 CD4 感染 helper T**。
7. **CD4 不是傳遞 TCR 訊息的膜蛋白**（CD3 γ/ε/ζ 才是；TCR α 本身不傳訊，但考古以 CD4 為答案）。
