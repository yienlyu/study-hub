# Bacillus、Listeria、Corynebacterium（依 113 共筆整理，鍾筱菁）

> 產孢子的 G(+) 桿菌只有兩屬：**Bacillus（需氧）**、**Clostridium（厭氧）**。*Listeria*、*Corynebacterium*、*Propionibacterium* 都**不產孢子**。

## 1. *Bacillus anthracis* ⭐
- 好氧、G(+)、**產孢子**、**無鞭毛（不動）**、不溶血；Koch 1877 分離。
- 毒力：
  - **Spore**：土壤存活 60 年；被巨噬細胞吞入後萌發、隨血流擴散。
  - **Capsule：poly-D-glutamic acid（胜肽，不是多醣）**，抗吞噬（pXO2）。
  - **毒素（pXO1 質體）**：3 蛋白組成 2 種 A-B toxin
    - **PA83（Protective antigen）** → 切掉 PA20 成 **PA63**，聚合成孔（B subunit）→ **疫苗抗原**、單抗 raxibacumab 標的
    - **EF（edema factor）**：calmodulin-dependent adenylate cyclase → **↑cAMP → 水腫**；**Edema toxin = PA + EF**
    - **LF（lethal factor）**：zinc protease，切 **MEK** → 殺死巨噬細胞；**Lethal toxin = PA + LF**
    - PA 單獨無毒性。
- 疾病：
  | 型 | 比例 / 途徑 | 特徵 | 致死率 |
  |---|---|---|---|
  | **Cutaneous** | **>90%，最常見** | papule → vesicle → ulcer → **黑色焦痂 eschar** | 治療後 <1%，未治入血 >30% |
  | Gastrointestinal | **最罕見**，吃未煮熟含孢子肉 | 腹痛、吐血、血便 | >50% |
  | **Inhalation** | **wool-sorter's disease**；**生物武器** | 類病毒呼吸道症狀 → 快速高燒、縱膈腔淋巴結腫、敗血性休克 | ~100% |
- 草食動物主要**吃入孢子**感染。
- 診斷：鏡檢、DFA、gamma phage lysis、PCR。
- 治療：**ciprofloxacin / doxycycline** + 1–2 種抗生素；皮膚型可口服 amoxicillin；暴露後預防 60 天；**不可切開皮膚病灶**（會散播）。
- 疫苗：失活 PA，18 個月 6 劑。

## 2. *Bacillus cereus*
- G(+)、產孢子、**有鞭毛會動**、土壤無所不在。
- **炒飯症候群**：
  | | **Emetic（嘔吐型）** | **Diarrheal（腹瀉型）** |
  |---|---|---|
  | 食物 | **米飯（炒飯）** | 肉、蔬菜、醬汁 |
  | 潛伏 | **<6 h**（約 2 h） | >6 h（6–9 h） |
  | 毒素 | **heat-stable、proteolysis-resistant** | **heat-labile**（↑cAMP / 孔洞） |
- 眼部感染（土壤污染異物）、**產莢膜菌株 → 嚴重肺炎**、導管感染。

## 3. *Listeria monocytogenes* ⭐
- G(+) 短桿菌、**不產孢子**、兼性厭氧、**weak β-hemolysis**、**CAMP (+)（with S. aureus）**。
- **20–25°C tumbling motility（end-over-end）** → **初步判斷依據**；37°C 運動差。
- **4°C 可生長 → 冰箱食物、cold enrichment**；耐酸鹼（胃酸、膽汁）。
- **Facultative intracellular**：
  1. **Internalin（InlA、InlB）** 進入細胞
  2. **Listeriolysin O（LLO）** 溶解液泡 → 進入細胞質
  3. **ActA** + Arp2/3 → **actin 聚合（彗尾）** → 胞內移動、感染鄰細胞（不必出細胞）
- 因為躲在細胞內，**細胞免疫重要、體液免疫不重要**。
- 感染：孕婦（**經胎盤** → 流產、新生兒敗血症 / 腦膜炎）、免疫低下（腦膜炎）；人畜共通、獸醫重要病原。
- 治療：**ampicillin / penicillin + gentamicin**；無疫苗。

## 4. *Corynebacterium diphtheriae* ⭐
- G(+)、不產孢子、**club-shaped（棒狀、不規則）**；**人類唯一宿主**（非人畜共通）；飛沫。
- **只有被帶 *tox* gene 的 β-phage 溶原化的菌株才產毒**。
- **Diphtheria toxin（A-B）**：B 接受體 → endosome 酸化 → A 進細胞質 → **ADP-ribosylation of EF-2** → 抑制蛋白合成（與 *Pseudomonas* exotoxin A 相同）。⚠️ 不是結合 60S（那是 Shiga toxin）。
- 臨床：**灰色偽膜**（扁桃腺、咽）、心肌炎、神經病變。
- 診斷：**Elek test（immunodiffusion，偵測毒素是否產生）**、PCR；Schick test（測抗體，已淘汰）；tellurite agar。
- 治療：**先給 antitoxin，再給抗生素**（penicillin、erythromycin）。
- 預防：**DPT（Diphtheria、Pertussis、Tetanus）**，出生 2 個月開始；toxoid。

## 5. *Erysipelothrix rhusiopathiae*（老師說不考）
- G(+)、不產孢子、microaerophilic、人畜共通（豬）；類丹毒 erysipeloid。

## 🎙️ 上課錄影重點（鍾筱菁，10/14）
- 老師自稱「國考小字典」，黃字 = **國考題**；「**我只會考我自己的部分**（今天教的）」；沒講的不會考。鼓勵大四修「進階微生物學」（國考衝刺班）。
- 開場複習 **G+ vs G− 四大不同**：外膜有無（G− 雙層膜、PDG 夾中間）、PDG 厚薄、**LPS（G− 特有）**、**teichoic acid（G+ 特有）** → 決定染色、用藥、致病機轉。臨床縮寫：**GPB、GPC、GNB、GNC**（本章 = GPB）。
- **Koch's postulates 是國考題**（連結病原與疾病）；Koch 在病牛羊血液中看到大隻、有孢子的 *B. anthracis*。病死牛羊要**就地焚燒**。1979 年前蘇聯 Sverdlovsk 兩週死 100 人 → 懷疑在研發生物武器。
- **生物恐怖攻擊武器三條件**：① 高度感染性（**spore** 耐 UV、乾燥、熱、冷、**酸**）② 致死率極高 ③ 沒有有效治療或疫苗不普及。課堂舉例符合者：**炭疽、鼠疫（國考題）、天花**（1980 年代宣布絕跡後就沒人打疫苗；猴痘讓人重提種牛痘）；HIV 不是（感染率、致死率低）；**Ebola 不合格（殺人太快）**。
- **能住在白血球裡的細菌的兩個特色**：① 逃避免疫攻擊 ② 隨著白血球**全身跑透透** → 造成**全身性疾病**（anthrax spore 被 macrophage 吞入後萌發、分泌毒素；*Listeria* 同理）。
- **產孢子的細菌只有兩種，都是 G+ 桿菌**：**Bacillus（好氧）**、**Clostridium（絕對厭氧）**；「拜託你們只要記得這兩個，其他都不用記」。Spore 要用 **malachite green（孔雀綠）+ 加熱** 才染得進去。實驗課用的是 *B. subtilis*（枯草桿菌）。
- **Capsule「放諸天下皆準」**：mask 表面抗原 → 逃避免疫辨識；但 capsule 本身會變成新抗原 → 可用來**血清分型、做疫苗**（*S. pneumoniae*、*N. meningitidis*、*S.* Typhi、*H. influenzae*、GBS；這部分是黃老師範圍、不考）。⚠️ **炭疽的 capsule 是胜肽（poly-D-glutamic acid）、不是多醣（國考題）**，且不拿來分型或做疫苗。
- **內毒素只有 LPS**，其他都叫外毒素（「上完我的課一定要知道，不然鞭數十驅之別院」）。
- **Anthrax toxin**：PA83 結合細胞表面後掉一個 20 kDa 片段 → **PA63** 形成孔洞，幫 EF / LF 進入；**EF = adenylate cyclase：ATP → cAMP → 開 Cl⁻ 通道 → Na⁺ 跟著 → 水分分泌 → 水腫**（影響 macrophage）；**LF = zinc-dependent protease** 切 signaling 分子 → 細胞死亡。分子量 83 / 63「不會考」。**疫苗抗原選 PA**（課堂投票；「斬馬腿」：擋住 PA，EF、LF 就無效）。屬於 **A-B toxin**。
- 國考考法：「Bacillus edema toxin 的作用機制與下列何者相同？」→ **cholera toxin、ETEC 的 LT**（都 ↑cAMP）。老師會整理 A-B toxin、↑cAMP、抑制蛋白合成的總表，「誰跟誰一起背」。
- **入侵途徑嚴重度（課堂投票）**：**吸入 > 吃入 > 皮膚**。皮膚是人體最大器官與第一道防線，下有淋巴系統（嚴重皮膚感染先看到淋巴結腫）；燒傷（八仙塵爆）死於感染；呼吸道為了氣體交換與循環「一膜之隔」→ 最嚴重。
- **三型炭疽（國考題，醫學系與護理系都考）**：皮膚型**最常見（~90%）**、致死率最低（焦痂；有塗、吃抗生素 < 1%，放任進入循環 > 30%）；腸胃型約 50%（吐血、血便、腹痛）；吸入型（自然界 = **woolsorters' disease**，現在是生物武器路徑）近 100%，但**及早發現、吃抗生素可壓到 10% 以下**，最慘的是延遲治療。
- **2001 年 911 後一週的炭疽信件**：22 人出現炭疽、11 人吸入型、5 人死亡（其中一位是郵差）；結果是美國防禦實驗室的人所為（Netflix《致命炭疽恐攻》）。
- 診斷（國考有考）：**DFA**、**gamma phage lysis**（溶菌斑，對 *B. anthracis* 97% 專一）。治療：及早；重症可打 **PA 抗體**（被動免疫，像蛇毒血清；仍在動物實驗）；暴露後預防要吃 **60 天**抗生素（孢子可在 macrophage 存活很久）。疫苗 **18 個月 6 劑、自費**、不普及（牛羊農、上戰場的人才打）；希望發展 3 劑終身免疫（類比台灣 B 肝疫苗全面接種、抑制肝癌）。
- ***B. cereus*（看到 cereus 要想到「很好吃」）**：有孢子；cereus 是「蠟」的意思（蠟狀桿菌；仙人掌桿菌名稱由來不明）。兩種**外毒素**：**嘔吐型 ↔ 米飯**、**腹瀉型 ↔ 蔬菜 / 肉**。孢子在土壤 → 跌倒磨到眼睛 → **角膜炎**。⚠️ 原本無 capsule，但**有 capsule 的菌株與嚴重肺炎有關（國考題）**。
- 「炒飯症候群」（美國 Chinatown 路邊擺太久的炒飯）；冰箱的飯拿出來要加熱。**嘔吐型約 2 小時（< 6 h）發作、heat-stable**；**腹瀉型 > 6 小時（要到腸胃道才拉）、heat-labile**。老師婆婆的故事：吃便當半小時就拉肚子 → 不可能是這個便當（飯還沒到腸道）。
- ⚠️ **老師勘誤：腹瀉型毒素是 pore-forming toxin，不是 cAMP 機制**（「課本寫錯，害我教了好幾年錯」），但最終同樣造成離子釋放、水瀉。新聞例：饗饗的仙人掌桿菌食物中毒（多在 7、8 月）。
- ***Listeria*（看到 Listeria 要想到「很會動」，高度移動性 = 國考題）**：沒有孢子。「**細菌有三毛：pili、fimbriae 負責黏（尤其 G−），flagella 負責動**；會動的細菌一定有 flagella」。*Listeria* 有**端鞭毛**、旋轉型運動。**三種「很會動」**：① 外面靠鞭毛 ② 細胞內溶解 phagolysosome、利用宿主 **actin** 在屁股組裝成「小火箭」跑到隔壁細胞 ③ 隨 macrophage 全身跑。
- 可在 **1–45 °C（含 4 °C）** 生長、**耐酸鹼** → 食物中毒；吃入 → macrophage → 淋巴 → 循環 → 肝、脾 → **腦膜炎**；最慘烈是**穿過胎盤** → 胎兒腦膜炎、敗血症；流產「是輕的」，影響胎兒發育是一輩子的事。新聞：孕婦吃辦桌後流產、早產發燒男嬰 → 「孕婦拜託不要去吃辦桌」。
- **Cold enrichment（冷藏增殖法）**：檢體放 4 °C 一至兩週，其他菌死了它還會長 → **國考小哉問答案 = *Listeria***（下堂課還會教另一支）。CAMP test 下下週黃老師講（臨床較少用於 *Listeria*）。食物中毒類通常沒有疫苗。
- ***Erysipelothrix*（豬丹毒桿菌）**：細長、G+ 但看起來粉紅色、微厭氧、長得慢、人畜共通（豬）→ **類丹毒、不化膿**（GAS 的丹毒會化膿）；問病史「最近有沒有抱豬豬」；預防 = 戴手套抱豬豬。「看了 15 年國考沒考過」。
- ***Corynebacterium diphtheriae***：形狀像**鼓棒**、**沒有孢子**；白色偽膜（剝開紅紅的）、咽喉炎、心內膜炎。**以人為唯一宿主**的三大傳染途徑：腸胃道（多為 GNB，下堂課）、**飛沫（白喉）**、**性病（沒有人畜共通的性病，「歡迎挑戰我」）**。4 種 biotype 都可能致病（曾是送分的爭議題）。
- **「這張圖會考很多很多次，用記憶吐司拓印下來」**：不是所有白喉桿菌都致病，要被帶 **tox 基因的 β 噬菌體**感染過（像吸血鬼）才會產 **diphtheria toxin**；**A-B toxin**：B 結合受體、帶 A 進細胞，**A 作用在 EF-2 → 抑制蛋白質合成 → 細胞死亡**。國考考法：「何者毒素機制與白喉毒素相同？」→ ***Pseudomonas aeruginosa* exotoxin A**。抑制蛋白質合成的毒素表會出現四次。
- **診斷（國考題）**：不是靠臨床症狀、也不是只分離出白喉桿菌，**必須證明菌株會產生白喉毒素** → **Elek test**（免疫擴散沉澱：中間抗毒素血清條、兩側 positive / negative control 與待測菌，交集出現「叉叉」沉澱線 = 有毒素）。Schick test（測是否有抗體）已不用。
- 台灣自 **1981 年後長期零本土病例**；近期**澳洲**白喉 outbreak（數百例、有死亡，2018 年以來首例）。預防：**三合一（白喉、百日咳、破傷風）類毒素疫苗**。

| 診斷 | CSF 顯微鏡；**cold enrichment**；**CAMP (+)**（與 *S. aureus*）；13 種血清型；PFGE、基因體定序 |
| 治療 | **gentamicin ＋ penicillin 或 ampicillin** |
| 預防 | 很難（到處都有、病例零星）；**無疫苗** |
| 國考小哉問 | 檢體 4 °C 貯存兩週以上再分離的 cold enrichment 適用哪種菌？→ ***Listeria***（下一章還有 *Y. enterocolitica*） |

## *Erysipelothrix rhusiopathiae*（豬丹毒桿菌）

| 特性 | G+、不產孢子；毛髮狀細絲，**看起來像 G−**；微需氧；長得慢；寄居豬與火雞 |

## *Corynebacterium diphtheriae*（白喉棒狀桿菌）
| 項目 | slides 重點 |
|---|---|
| 特性 | G+、不規則**棒狀（club-shaped）**桿菌；**人類為唯一宿主** |
| 疾病 | 白喉（呼吸道、皮膚）；非產毒株 → 咽炎、心內膜炎；厚**偽膜**（細菌、淋巴球、漿細胞、纖維蛋白、死細胞） |
| Biotype | belfanti、gravis、intermedius、**mitis（最多）** |
| 毒素 | **β 噬菌體帶 tox 基因**；**AB toxin**：B 結合受體（heparin-binding EGF precursor）→ 胞吞 → 酸化使 B 形成通道 → A 進入細胞質 → **ADP-ribosylate EF-2** → 抑制蛋白質合成 → 細胞死亡 |

# 考點分析

## 🔥 高頻考點（27 題）
1. **B. anthracis 毒素組成**：PA + EF = edema、PA + LF = lethal；**PA 單獨毒性最強**是錯的；**疫苗抗原 = PA**。
2. **Anthrax 感染途徑**：皮膚最常見（「最罕見」是錯的）、草食動物吃孢子、生物武器吸入；**flagella 不是毒力因子**。
3. **B. cereus**：米飯 → emetic（heat-stable）；fried rice 情境題（出 3 次）。
4. **Listeria**：冰箱 4°C、LLO、actin 移動、tumbling motility 是初步判斷依據、**「體液免疫重要」是錯的**。
5. **Diphtheria toxin**：EF-2（不是 60S）、Elek test 測毒素、先 antitoxin；DPT **不含 anthrax**；**白喉不是人畜共通**。
6. **不產孢子 G(+) 桿菌**：Clostridium 不屬於。

## 📝 出題模式
- 大量「which is not / incorrect」+ 臨床情境（偽膜 → club-shaped G+）。

## 🎙️ 老師課堂提示
- 錄影中點名的國考題：Koch's postulates、**產孢子只有 Bacillus 與 Clostridium**、炭疽 capsule = **poly-D-glutamic acid（胜肽）**、三型炭疽的盛行率與致死率、gamma phage lysis / DFA、鼠疫為何能當生物武器、有 capsule 的 *B. cereus* 菌株 → 嚴重肺炎、*Listeria* 高度移動性、**cold enrichment → *Listeria***、白喉毒素作用於 **EF-2**（同 *Pseudomonas* exotoxin A）、**白喉確診要證明會產毒素（Elek test）**、白喉以人為唯一宿主。
- 老師勘誤：*B. cereus* 腹瀉型毒素是 **pore-forming**，不是 cAMP 機制（與課本不同）。
- 嘔吐型 vs 腹瀉型：< 6 h、heat-stable、米飯 vs > 6 h、heat-labile、蔬菜肉類。
- Edema toxin 的機制「同 cholera toxin、ETEC LT（↑cAMP）」是常見考法；疫苗抗原 = PA。
- *Erysipelothrix*：「15 年國考沒考過」。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| *Listeria*、*Corynebacterium* 會產孢子 | 產孢子的 G(+) 桿菌只有 ***Bacillus*（需氧）與 *Clostridium*（厭氧）** |
| *B. anthracis* 有鞭毛會動 | ***B. anthracis* 不動**；*B. cereus* 會動 |
| 炭疽莢膜是多醣 | **poly-D-glutamic acid（胜肽）**，由 pXO2 編碼；毒素在 **pXO1** |
| PA 單獨就有毒性 | PA 單獨**無毒**；**PA + EF = edema toxin、PA + LF = lethal toxin** |
| EF 是 zinc protease | **EF = adenylate cyclase（↑cAMP、水腫）**；**LF = zinc protease（切 MEK）** |
| 炭疽最常見是吸入型 | **皮膚型 > 90%**（黑色焦痂）；吸入型（wool-sorter's）致死率最高；腸胃型最罕見 |
| 皮膚炭疽要切開引流 | **不可切開**（會散播） |
| *B. cereus* 嘔吐型毒素怕熱 | 嘔吐型（炒飯、< 6 h）**耐熱、耐蛋白酶**；腹瀉型（> 6 h）怕熱 |
| *Listeria* 在 37 °C 動得最好 | **20–25 °C tumbling motility**；37 °C 運動差；**4 °C 可生長** |
| *Listeria* 靠抗體清除 | 胞內菌 → **細胞免疫**重要 |
| LLO 讓 *Listeria* 進入細胞 | **Internalin** 進入；**LLO 溶解液泡**；**ActA** 聚合 actin 胞間移動 |
| 所有 *C. diphtheriae* 都產毒 | 只有被帶 ***tox* gene 的 β-phage 溶原化**的菌株 |
| 白喉毒素結合 60S | 白喉毒素 **ADP-ribosylate EF-2**（同 *Pseudomonas* exotoxin A）；60S 是 Shiga toxin |
| Schick test 偵測毒素產生 | **Elek test** 偵測菌株是否產毒；Schick test 測抗體（已淘汰） |
| 白喉先給抗生素 | **先給 antitoxin**，再給抗生素 |
| 白喉是人畜共通 | **人類是唯一宿主** |
