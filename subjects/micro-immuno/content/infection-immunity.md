# 對抗感染的免疫反應（依百十四內容整理、對照百十三共筆，林秋烽）

## 1. 第一道防線
- **物理屏障**：皮膚、黏液、纖毛上皮、低 pH（胃酸、陰道）、眼淚沖洗、**免疫特權區**（水晶體、睪丸：擋住免疫細胞，避免不可逆傷害）。
- **化學／生物因子**：**microbiota**（先駐菌抵抗入侵（invasion）；抗生素破壞多樣性 → 益生菌、糞便移植）、lysozyme、**AMPs**、抗微生物脂肪酸、補體、cytokines。
- **AMPs**：12–50 aa，哺乳類已知 >600 種；多帶**正電**（Arg、Lys、His）→ 結合帶負電的細菌膜 → 穿孔裂解；對含**膽固醇**的宿主細胞膜結合力弱，所以有選擇性。
  - 例：**defensins**（β：上皮；α：neutrophil、Paneth cell）、cathelicidin（neutrophil）、dermcidin（上皮／汗腺）。
  - 分類：陰離子胜肽（Glu、Asp）、線性陽離子 α-helix（無 Cys）、富含特定胺基酸（Pro、Arg、Phe、Gly、Trp）、含 1–3 個以上雙硫鍵。
  - 作用：**直接殺菌**（類似 MAC（membrane attack complex，膜攻擊複合體） 的穿孔、進入菌體抑制核酸／蛋白合成）＋**調節宿主免疫**（趨化（chemotaxis） neutrophil、monocyte、DC（dendritic cell，樹突細胞）、T，效果遠大於補體；中和（neutralization） LPS（lipopolysaccharide，脂多醣）／LTA（lipoteichoic acid，脂磷壁酸）、防止過度發炎；增強 TLR3／7／8／9 的核酸辨識 → IFN）。
  - 臨床藥：bacitracin（外用）、boceprevir／telaprevir（HCV（hepatitis C virus，C 型肝炎病毒））、enfuvirtide（HIV（human immunodeficiency virus，人類免疫缺乏病毒））、oritavancin／teicoplanin（細菌）。
- **補體**（約 30 種血漿蛋白）：**C3b 調理**（CR1）、**C3a／C5a** 使 mast cell 釋放 histamine、**C5b-9（MAC）**裂解。
  - 古典途徑（抗原–抗體複合體活化 C1 → **C4b2a**，連結先天與後天）、凝集素途徑（MBL（mannose-binding lectin）／ficolin 辨識 mannose → C4b2a）、替代途徑（C3 自發水解＋factor B、D、P；不需抗體，最快啟動）。
- **先天 vs 後天**：先天 0–12 小時、辨識 PAMP（pathogen-associated molecular pattern）／DAMP（damage-associated molecular pattern）、胚系編碼、無記憶；後天數天、基因片段重組、有記憶。T／B 細胞也有 immune sensor，可參與發炎性活化；**ILCs** 不需抗原專一性即可活化。

## 2. 胞外感染：吞噬為主
- 定義：病原在宿主細胞外（血液、呼吸道、腸胃道、泌尿生殖道管腔、上皮表面）複製；多數細菌與真菌屬此類。**吞噬作用是最主要的先天防禦。**
- **皮膚**：表皮 Langerhans cell（特化 DC）、真皮 dermal DC 與 macrophage；上皮分泌 β-defensin。**黏膜**：tight junction、**Paneth cell（α-defensin）**、IgA 經 **pIgR**（polymeric immunoglobulin receptor） 送到管腔、**M cell**、Treg（TGF-β（transforming growth factor-β）、IL-10，對共生菌與食物不過度反應）、**IEL（85% αβ、15% γδ T）**。
- **吞噬五步驟**：趨化 → 附著（mannose receptor、Mac-1 integrin、scavenger receptor）→ 吞入（偽足，形成 phagosome）→ 殺死（與 lysosome 融合成 phagolysosome，H⁺ pump 酸化）→ 排出殘餘物。
- **吞噬受體**：CLRs（**mannose receptor**：末端 mannose／fructose；**Dectin-1**：真菌 β-glucan）、scavenger receptor（**CD36**：微生物 diacylglycerides；另有 SR-A、MARCO）、**FPR／FPRL1**（N-formyl-Met 胜肽，只在細菌與粒線體蛋白起始端）、complement receptor（C3b）。
- **殺菌武器**：
  - **Respiratory burst**：**NADPH oxidase（NOX）** O₂ → O₂⁻ →（**SOD**）H₂O₂ →（**MPO**）＋Cl⁻ → **HOCl**。
  - **NO**：**iNOS** 以 L-arginine 為受質（→ citrulline）；NO＋O₂⁻ → peroxynitrite（ONOO⁻，硝化 Tyr）；S-nitrosothiol 破壞 Fe-S、Zn-S cluster。
  - **NOX 結構**：膜上 **gp91phox＋p22phox**（flavocytochrome b558）；細胞質 **p40、p47、p67**＋Rac1/2。**p47 磷酸化、Rac 轉為 GTP 型** → 移位到膜上組裝。
- **CGD（慢性肉芽腫病）**：NOX 任一次單元缺陷 → 無 respiratory burst（吞得進去、殺不死）。**最常見 gp91，唯一 X-linked**；p47、p67、p22 為體染色體隱性。肺炎、膿瘍（abscess）、敗血性關節炎、骨髓炎（osteomyelitis）、菌血症（bacteremia）；特別怕 **catalase(+) 菌（*S. aureus*）與真菌（*Aspergillus*）**；病原被包圍成 **granuloma** 而得名。
- **NETs**：neutrophil 吐出染色質＋殺菌蛋白（DNA、histone、NE、cathepsin G、MPO、tissue factor）。
  - **NETosis**（溶解型，慢）：核分葉消失、核膜瓦解 → 染色質解開 → 細胞膜破裂、細胞死亡。**Non-lytic NETosis**（快）：活細胞擠出染色質，剩下無核的 cytoplast 仍能吞噬。
  - 活化：TLR4（LPS）、C5a、TNF-α、活化血小板、自體抗體 → PKC → Raf → MEK → ERK → NOX 產生 ROS（reactive oxygen species，活性氧）；**PAD4 瓜胺酸化 histone** 使染色質解開。GAS（group A Streptococcus，A 群鏈球菌） 以 **DNase** 切 NETs 逃脫；過度生成會傷組織（敗血症（sepsis））。
- **Neutrophil 的結局**：消退（PICD 凋亡 → macrophage **efferocytosis**）、病原在其中存活 → 裂解散播、NETosis 困住病原但也傷組織。
- **Efferocytosis**：凋亡細胞外翻 **phosphatidylserine**（eat me）→ 橋接分子（GAS6、MFG-E8、C1q、CRP）接到 Mer、CD36、αvβ3/5 等受體 → 分泌 **IL-10、TGF-β**，不發炎；壞死細胞則釋放 DAMP、促發炎。
- **巨噬細胞來源**：胚胎（yolk sac、fetal liver）→ 常駐型（microglia、Kupffer cell、alveolar macrophage、脾竇 macrophage）；骨髓（bone marrow） → 血中 monocyte → 組織 macrophage。發炎時兩群並存。
- **調理作用**（opsonization）：C3b ↔ **CR1**、IgG Fc（fragment crystallizable） ↔ Fc receptor。
- **吞噬後的抗原處理**：macropinocytosis、pinocytosis（含 clathrin）、phagocytosis 三條路平行成熟：early endosome（**Rab5／EEA1**）→ late endosome（**Rab7／Lamp1**）→ lysosome（Lamp1），pH 6.5 → 4.0 → 胜肽上 MHC（major histocompatibility complex，主要組織相容性複合體） I／II；DC 可 **cross-presentation**。
- **DC**：TLR（Toll-like receptor，類鐸受體） 與細胞質 PRR（pattern recognition receptor，模式辨識受體） 最多；活化 naive TH 的三訊號：TCR（T cell receptor，T 細胞受體）–peptide/MHC II、共刺激（**CD28–B7**、CD40–CD40L）、**signal 3 極化 cytokine**（TH1：IFN-γ、TNF-β；TH2：IL-4、5、13）。DC 被感染後：浸潤或躲藏（成熟↓但遷移↑ → 把病原帶到淋巴結（lymph node），如 HIV）、殺死（遷移也↓）。

## 3. PRRs、PAMPs、DAMPs
- **PAMPs**：病原特有分子（G(+) 的 peptidoglycan、LTA → **TLR2**；G(−) 的 **LPS → TLR4**）。**DAMPs**：受損細胞釋出的內源分子，如 **HMGB1**、**尿酸結晶**（痛風）。
- **Membrane PRRs**：
  - **TLRs**：Hoffmann 果蠅 Toll（**2011 諾貝爾**）、Akira 小鼠剔除研究。人類 TLR1–10，**TLR3、7、8、9 在 endosome**，其餘在細胞膜（cell membrane）。多數經 **MyD88** → NF-κB、MAPK → 發炎 cytokine；**TLR3 只走 TRIF** → IRF3／7 → type I IFN；**TLR4 兩條都走**。
  - **CLRs**：辨識 mannose、galactose 等醣類；mannose receptor（macrophage、DC）、**Dectin-1／2**、**DC-SIGN（CD209，DC 特有）**；第二群為 asialoglycoprotein receptor family。
- **Cytoplasmic PRRs**：**NLRs**（NOD1／NOD2 辨識 peptidoglycan，經 **RIPK2** → NF-κB；NLRP 參與 inflammasome）、**RLRs**（**RIG-I、MDA5**，病毒 RNA → type I IFN）、**cytosolic DNA sensors**（**AIM2**、STING 相關系統）。
- 剔除鼠研究：**Lyme disease（*Borrelia*，OspA）靠 TLR1／2**；**West Nile virus 靠 TLR3** 進腦造成腦膜炎（meningitis）；吸入性肺損傷的 **OxPLs 靠 TLR4**（TLR4 抑制劑可避免二次發炎傷害）。
- PRR 分布：**DC 幾乎所有 PRR 都有**（最專業的 APC（antigen-presenting cell，抗原呈現細胞））> macrophage；**CD4 T 也有 TLR2、TLR4**。

## 4. 胞內感染
- 病原進入宿主細胞內複製（病毒必須如此）；抗體、補體碰不到 → 主要靠**細胞媒介免疫**（活化 macrophage、CTL（cytotoxic T lymphocyte，毒殺性 T 細胞））。
- **Inflammasome**：sensor（**NLRP3**、NLRC4、AIM2）＋adaptor **ASC**＋**pro-caspase-1**。
  - 種類：NLRP1（微生物毒素）、**NLRP3**（最廣，PAMP／DAMP）、**NLRC4**（經 **NAIP** 辨識鞭毛蛋白、第三型分泌系統）、**AIM2**（細胞質 dsDNA）、**Pyrin**（毒素造成的 Rho GTPase 異常）。
  - **NLRP3 兩訊號**：Signal 1 priming（LPS–TLR4 → MyD88 → NF-κB → 表現 NLRP3、pro-IL-1β）；Signal 2 activation（**細胞外 ATP–P2X7 → K⁺ 外流**、尿酸結晶造成溶酶體受損釋出 cathepsin、粒線體受損、ROS）→ 寡聚化、募集 ASC 與 pro-caspase-1。
  - 下游：**caspase-1** → 成熟 **IL-1β**（局部發炎、內皮活化）、**IL-18**（促 NK（natural killer，自然殺手）、T 產生 IFN-γ）；切割 **gasdermin D** → 膜孔 → **pyroptosis**。
- **Pyroptosis**：caspase-1／gasdermin D 媒介的**發炎性**程序性死亡，細胞腫脹破裂，釋出 IL-1β、IL-18、HMGB1。對照：**necrosis**（物理傷害、DAMP、發炎）、**apoptosis**（粒線體（mitochondria） → apoptosome → **caspase-3、7** → DNA 切斷，不發炎）。
- **先天與後天的接力**：macrophage／DC 分泌 **IL-12** → NK 分泌 **IFN-γ**、naive CD4 分化成 **Th1** → IFN-γ＋**CD40L–CD40** 強化 macrophage 殺菌、增加 MHC 表現。
- 活化 macrophage：TLR4（經 **CD14**）＋IFN-γ（JAK–**STAT1** dimer）→ NF-κB、IRF → pro-IL-1β、IL-6、IL-8、ROS；**iNOS → NO**；分泌 TNF（tumor necrosis factor，腫瘤壞死因子）、IL-1、IL-12；促進組織修復。
- **IFN-γ（type II）**：抗微生物、抗腫瘤、免疫調節；維持 MHC I／II、誘導 **autophagy**。老師補充：**IFN-γ 幾乎所有免疫細胞**都會產生；**IFN-α／β 幾乎所有體細胞（RBC 除外）**都會產生。
  - **Adult-onset immunodeficiency**：HIV 陰性卻像 HIV 一樣易得 TB → 見下方〈IFN-γ 訊號受損〉。
- **細胞毒殺**：分泌 TNF-α、perforin、granulysin、IFN-γ。CTL 經 MHC I 辨識抗原；**NK** 的抑制型 **KIR**（killer-cell immunoglobulin-like receptor） 碰到 MHC I 就不殺 → 感染／腫瘤細胞降低 MHC I，抑制訊號消失＋活化型受體結合 → 釋放 granzyme、perforin；**NKG2D** 直接辨識壓力分子，不需 MHC。
- **Type I IFN（IFN-α、β）**：IRF 家族調控；TLR4–LPS、endosome 核酸、RIG-I → NF-κB、IRF3 → IFN；**IFNAR1／2** → JAK–**STAT1／STAT2** → **ISRE** → PKR、2-5AS、Mx1 等抗病毒蛋白；被感染細胞把 IFN 傳給鄰近細胞先武裝起來，再等 NK／CTL 清除。
- **ADCC**（antibody-dependent cell-mediated cytotoxicity，抗體依賴性細胞毒殺）：抗體 Fc ↔ **NK 的 CD16**、macrophage、eosinophil → 去顆粒殺死目標細胞。

### IFN-γ 訊號受損（slides p64 ⭐）
- **IFN-γ 從哪來**：innate lymphoid cells（含 **NK**）、**Th1**、**CTL**。
- **作用在誰**（經 **STAT1、IRF1、NF-κB**）：
  - **APC（巨噬細胞、DC）**：趨化、吞噬增加，產生 **ROS、NO** → 殺死吞入的胞內菌（intracellular bacteria）；**MHC I／II** 呈現、共刺激分子、Th1 誘導激素（IL-12）都增加 → 回頭再推 Th1，形成放大迴路。
  - **腫瘤細胞**：增加 MHC I 呈現，抑制生長、促凋亡。
- **成人型免疫缺乏（adult-onset immunodeficiency）**：
  - 表現：**HIV 陰性**卻反覆感染 **TB**、**NTM** 等伺機性感染（opportunistic infection），臨床上很像 HIV／AIDS（acquired immunodeficiency syndrome，後天免疫缺乏症候群）。
  - 原因（slide 列的四項）：**抗 IFN-γ 自體抗體**、IFN-γ 本身缺陷（基因缺失，或下游受體／轉錄因子突變，訊號傳不下去）、遺傳因素、環境因素。
  - 老師補充：北醫三家附屬醫院常收到疑似個案；診斷先**排除遺傳**，再**驗自體抗體**。如果是自體抗體，治療要**針對 B 細胞**（免疫療法），只殺菌會一直復發。
- 考題辨識：「HIV 陰性＋反覆／播散性 TB、NTM」→ **抗 IFN-γ 自體抗體**；鑑別：C5–C9 缺乏 → *Neisseria*；選擇性 IgA 缺乏 → 黏膜感染；CGD（chronic granulomatous disease，慢性肉芽腫病） → catalase(+) 菌與真菌、granuloma。

## 5. 體液免疫、自體免疫與免疫脫逃

<div data-fig="immune-evasion-map"></div>

- 抗體三大作用：中和、調理、活化補體（詳見 W4-2）。
- **Molecular mimicry**：病原抗原與自身相似 → cross-reaction、tolerance breakdown。例：HIV gp120／gp41 疫苗抗體會結合 **cardiolipin**；**vaccinosis**（傷寒（typhoid fever）、小兒麻痺、B 肝疫苗可能引發關節炎）；**post-streptococcal**：心肌炎、關節炎、舞蹈症。
- **逃避吞噬**：表面蛋白、**capsule**、biofilm（GAS **M protein**、肺炎鏈球菌莢膜）；**leukocidin** 殺吞噬細胞（GAS 的 SLO（streptolysin O）、SLS（streptolysin S）；*S. aureus*）。
- **吞噬體裡的三種求生法**：逃出吞噬體（***Shigella*、*Rickettsia***）、阻止吞噬體與溶酶體融合（***M. tuberculosis***）、在吞噬溶酶體中照樣存活（***Coxiella burnetii***）。
- ⚠️ **易錯配對**：**GAS（*S. pyogenes*）的主要策略不是阻止吞噬體與溶酶體融合**，而是在被吞進去之前就擋掉——**M protein（抓 C4BP）、hyaluronic acid 莢膜**抑制調理與吞入、**SLO／SLS** 殺吞噬細胞、**DNase** 切 NETs、**ScpA／C5a peptidase** 擋趨化。阻止融合的是 ***M. tuberculosis***（還有 HIV）。

  | 病原 | 在哪一步作弊 | 策略 |
  |---|---|---|
  | GAS、*S. aureus*、肺炎鏈球菌 | 吞入**之前** | 莢膜、M protein、Protein A、CHIPS、SCIN、leukocidin |
  | *Shigella*、*Rickettsia*（*Listeria*） | 吞入之後 | **逃出吞噬體** |
  | *M. tuberculosis*、HIV | 吞入之後 | **阻止吞噬體與溶酶體融合** |
  | *Coxiella burnetii* | 吞入之後 | **在吞噬溶酶體裡存活** |
- **GAS**：**DNase** 切 NETs、SLO／SLS 殺吞噬細胞、**SpeB**（蛋白酶）、**EndoS**（修飾 IgG 醣鏈）、Mac-1／Mac-2、**ScpA／ScpC**（切 C5a、IL-8）、**M protein 結合 C4BP** 降低 C3b 沉積。
- ***S. aureus***：**Protein A**（抓 IgG **Fc**）、**CHIPS**（干擾 C5a receptor，抑制趨化）、**PVL**（Panton-Valentine leukocidin） 等白血球毒素、**SCIN**（抑制 C3 convertase）、**catalase**；**MprF、Dlt** 抵抗陽離子 AMP。
- **病毒脫逃**：干擾核酸辨識（TLR3、RIG-I、MDA5）、IFN 產生或 IFNAR–JAK–STAT 訊號。
- **慢性病毒感染（HBV（hepatitis B virus，B 型肝炎病毒）、HCV）**：**T cell exhaustion**（CD8 增殖、cytokine、毒殺力都下降；不是免疫完全停擺）；Treg（regulatory T cell，調節性 T 細胞）、**IL-10** 過強，M2 macrophage 參與修復與調節。
- **登革熱**：四種血清型（serotype）；**ADE**——異型抗體能結合卻中和不了 → 病毒–抗體複合體經 **Fcγ receptor** 進入免疫細胞（重症機制之一，但不是唯一）；IL-10、**SOCS** 抑制 IFN 訊號。
- ***M. tuberculosis***：阻止吞噬體成熟與融合；**SOD** 清除 O₂⁻；UreC（urease 相關，與吞噬體內存活有關）；**granuloma** 限制但不一定清除 → 免疫下降時再活化。
- **SARS-CoV-2**：病毒蛋白干擾核酸辨識與 type I IFN；**spike 變異**降低中和；早期抗病毒不足、後期過度發炎。

## 🎙️ 上課錄影重點（林秋烽，10/07，約 105 分）
- 老師定位：從**宿主**的角度看免疫如何對抗病原，並強調**病原如何免疫脫逃**（所以感染症至今沒有解決）。「幫病毒上一堂免疫學，你要懂得 survive，就要懂得 immune evasion」。
- 防疫演進：isolation（隔離病人、隔離病房）→ 口罩、防護衣 → **疫苗**才是宿主本身的特異性防禦，還能形成**群體免疫**的牆（David Ho 也說根絕傳染病要靠疫苗（vaccine））。
- 區分感染型態：多數細菌是 **extracellular**；少數胞內菌（如 TB）；**病毒絕對胞內寄生**。看免疫要放在 innate 或 adaptive 的框架；免疫也可能**過度**（hyperinflammation、hypersensitivity、autoimmunity）造成**間接傷害** → microbial immunopathogenesis。
- **第一道防線**：皮膚、黏液、低 pH、眼淚；**打噴嚏也算免疫力**（物理性排除）。**共生菌是 barrier**：像「大風吹已經有人卡位」，病原無法定殖 → 維持菌相多樣性很重要。台灣第一例 FMT：桃園某醫院腸胃科醫師用病人兒子的糞便治療反覆腹瀉的老婦人。抗生素濫用 → 腸胃不適。
- **AMP「一定要記得」**：12–50 aa、**多帶正電** → 結合帶負電的細菌膜 → **pore forming**（類似 MAC）；已鑑定 > 600 種。命名來自細胞：**defensin**、**cathelicidin（PMN）**、**dermcidin（皮膚上皮）**。功能：直接溶菌 + **免疫調節**（趨化、抑制或促進 TLR 訊號）→ 可開發成免疫調節產品。感染與 cytokine 都能快速誘導 AMP。
- 補體複習：classical 由抗體啟動，但因「最早被發現」才叫 classical；alternative 不需 converting enzyme、啟動最快、只是發現得晚。C3a / C5a 促 mast cell 敏感、血管通透 → 類過敏反應的開端；**C3b 是經典調理素**（像**裹粉的炸雞排**——標記成「可以炸」）。⚠️ **不是所有抗體都能固定補體**。
- **課堂問題：淋巴球碰到 *E. coli* 會不會活化？→ 會**，但是**非抗原特異性**的先天活化（T 細胞也有 **TLR4**，也有 TLR2、TLR9）→ 可產生 IL-6、AMP；但只有 TLR4 訊號**不足以讓 T 細胞增殖**（增殖需 TCR 訊號產生的 IL-2）。
- 時間軸：innate 幾分鐘到幾小時；adaptive 需數天（初次感染 **IgM 至少 7 天**）。Innate 與 adaptive 有 **crosstalk**，二次感染時兩者同時啟動。區分兩者的核心是 **memory 與 specificity**（百貨公司週年慶比喻：排隊人山人海沒人記得你 = innate；在 SK-II 專櫃買兩打 → 下次被認出來 = adaptive）。
- **胞外感染「決戰於境外」**：多發生在呼吸道、腸胃道、泌尿生殖道黏膜。皮膚下的 **Langerhans cell**（常駐、特化 APC）；樹突狀細胞的發現者（Steinman）在諾貝爾獎宣布前因胰臟癌過世，由家人代領。腸隱窩底部的 **Paneth cell 高度表現 α-defensin**（位置最底層、最容易卡東西）；**M cell** 像守門員、tight junction 易打開，下方有常駐免疫細胞（肺泡液中也有免疫細胞巡邏）；**IEL** 偏向類先天反應，innate 也有類似 TH1 / 2 / 17 的分型。
- 吞噬的「辨別敵我」= **可識別性**而非 memory 的專一性：吞凋亡細胞 = **efferocytosis（胞葬）**；病態下連正常細胞也吞 = **hemophagocytosis（噬血）**；正常細胞有「**don't eat me**」訊號、凋亡細胞出現「**eat me**」訊號。吞噬受體「**務必記起來**」：mannose receptor、complement receptor、lipid receptor（**CD36**）、scavenger receptor、Dectin、fMLP receptor；歸類為 **CLR** 等 PRR。病毒多以 endocytosis 進入。
- **NADPH oxidase（NOX）**：膜上 **gp91、p22**，細胞質 **p47、p67、p40**；受刺激後組裝到膜上產生 superoxide → 任何次單位異常 → 活性下降 → 反覆感染（部分「免疫力低落」病人是這類基因突變）→ **CGD**：巨噬細胞清不掉病原，只好形成 **granuloma** 包起來。IFN-γ 可促進這條殺菌路徑。
- **Neutrophil**：血中最多的免疫細胞，從骨髓出來只活 **24–48 小時**；「**吞了也死、不吞也死**」（吞完 = phagocytosis-induced cell death，由鄰居 efferocytosis 清除）。
- **NET / NETosis**：德國科學家發現（約 10 年前），把 neutrophil 用滴管吸住、旁邊放細菌，最後它吐出 **DNA**（PI 染色）+ granule 酵素 → 遠端捕殺細菌；代價是**暴露 self antigen**（與自體免疫、敗血性休克的 **DIC**（disseminated intravascular coagulation，瀰漫性血管內凝血） 有關）。後來發現氣喘病人的 **eosinophil** 也有、老師實驗室發現**上皮細胞**也會 → 統稱 **ETosis**。涉及氧化壓力與 autophagy。GAS 用 **DNase「剪破網」**逃出。
- Efferocytosis 的好處：吞噬細胞吞凋亡細胞後釋放 **IL-10、TGF-β** → 預防性降低發炎、維持免疫恆定；efferocytosis 不完整可能與**自體免疫**有關。上皮細胞之間也會互相 efferocytosis。
- 各組織常駐吞噬細胞：**microglia**（腦曾被認為是免疫特權區）、Kupffer cell、alveolar macrophage、脾臟（spleen） macrophage。抗體 + C3b 共同調理 = **adaptive 協助 innate** 的典型例子。
- DC 依抗原與微環境決定 T 細胞走向：**過敏原 → 偏 TH2**；細菌、病毒 → 偏 TH1。病原也會**躲在 DC 裡**被帶到淋巴結（造成淋巴結感染）、長期潛伏、或直接清除 DC。
- **PAMP / DAMP / PRR**：DAMP 是**內生性**、平常不該暴露的分子（如核蛋白 **HMGB1**，細胞死亡、核膜改變才跑出來；可被 TLR2、TLR4 等多個受體辨識）。**所有體細胞（內皮、上皮、fibroblast）都有 PRR** → 刀傷時免疫細胞還沒到就有發炎。G+ 的 PDG ↔ **TLR2**、G− 的 LPS ↔ **TLR4**；細菌膜、DNA 也都能當 PAMP。**痛風**：尿酸結晶 = DAMP → 痛是**發炎反應**造成，不是結晶刺到。
- **2011 諾貝爾**：Hoffmann 的突變果蠅（缺 **Toll**）竟死於**真菌感染**；高等動物找到的是 Toll-*like* receptor。日本 **Akira** 建立大規模 TLR knockout 小鼠庫。TLR：人類 9 類（TLR1–9 以內）、小鼠共 13 類。PRR 下游兩大轉錄因子：**NF-κB**（IL-1、IL-6、IL-8、TNF-α、MCP-1…）與 **IRF**（interferon）。
- 研究例：Lyme disease 的 **OspA** 由 **TLR1 / TLR2** 辨識（疫苗開發）；**West Nile virus**（與登革同科）在 **TLR3** knockout 小鼠病毒量高、早期發炎低；吸入性嗆傷（消防員、士兵）→ 酸造成**氧化磷脂（OxPL）** → **TLR4** → NF-κB → 急性肺損傷（TLR4 knockout 小鼠有抗性 → TLR4 抑制劑可能用於預防）。
- **DC 帶有的 PRR 種類最多 → 最 professional 的 APC**。
- 抗體功能補充：「**抗體不只有中和**」——結合的 epitope 不一定是關鍵位置；有些抗體結合穿膜蛋白反而**刺激活化**；還有調理（Fc receptor）、協助 classical pathway。**95% 以上 B 細胞活化依賴 T**；沒有 T 協助則多為 IgM、polyclonal。
- **Molecular mimicry**：2005 年 Science —— HIV **gp120 / gp41** 的中和抗體會交叉結合宿主分子；self antigen 序列恰好與病原相似 → 自體免疫（大家共用同一個地球的資源，演化出相似的蛋白）。另一機制：感染讓 efferocytosis 下降 → self antigen 清不掉 → **tolerance breakdown**。疫苗 side effect（如 arthritis）也可用此解釋 → 從安全性看，**特異性 peptide 疫苗**比 whole agent 好控制。GAS 反覆感染 → 抗體交叉結合神經受體 → **Sydenham chorea（手足舞蹈症）**；也懷疑與心肌炎、關節炎有關。
- **胞內感染**：PRR 在細胞質：**NLR（NOD1、NOD2、NLRP）**、**RLR（RIG-I、MDA5 認病毒 RNA）**、**cytosolic DNA sensor（AIM2、STING 相關）**。「**請大家一定要對 NLRP 有點印象**」：NLRP = **inflammasome**，產生 **IL-1β（mature form）與 IL-18**；訊號來自細胞內 crystal、ATP、lysosome damage 等。兩步驟：**signal 1（TLR → 準備原物料）+ signal 2（activation，如氧化壓力 → 組裝）**。絕大部分感染與 DAMP 都有 IL-1 → 所有 PRR 都可能連到 caspase-1 / inflammasome。
- Caspase 對照：**caspase-8**（death receptor）、**caspase-9**（粒線體）是 initiator → **caspase-3** → 內切核酸酶切 DNA → apoptosis（**silent**，膜完整、不釋放 self antigen，形成凋亡小體被 efferocytosis）；**caspase-1** → IL-1β → **pyroptosis（細胞焦亡，pro-inflammatory）**。Pyro 取自 *pyogenes*：化膿性鏈球菌造成高燒（IL-1β、TNF-α）、**壞死性筋膜炎（噬肉菌）**傷口早期像燒焦、需外科清創。
- **NK 與 macrophage 的 crosstalk**：macrophage 的 **IL-12** 活化 NK → NK 分泌 **IFN-γ** 回饋活化 macrophage（抗原呈現（antigen presentation）↑、抗微生物蛋白↑）；adaptive 中 **TH1** 也分泌 IFN-γ 回饋 APC → 不斷放大循環。有 cytokine（如 IFN）存在時 PRR 反應可差到 **1000 倍**。
- **成人型免疫缺乏症（adult-onset immunodeficiency）**：**HIV 陰性**但反覆感染、像 HIV（**TB、NTM**）→ 缺 IFN-γ 訊號（基因缺陷、下游轉錄因子突變，或產生**抗 IFN-γ 自體抗體**）。北醫三家附屬醫院實驗室常收到疑似個案；先排除遺傳、再驗自體抗體 → 若是自體抗體，治療要**針對 B 細胞**（只殺菌會一直復發）。
- NK「翹翹板」：抑制型 KIR 認 MHC I；癌化或病毒感染細胞下調 MHC I → 抑制訊號消失 → 活化 → **granzyme B、perforin**；IFN-γ 讓標的細胞先「準備好」促凋亡蛋白。
- **Interferon**：type I（**IFN-α、β**，幾乎所有細胞，抗病毒）、type II（**IFN-γ**）。**TLR3、7、8、9** 是誘導 type I IFN 最主要的 PRR → 疫苗會用這四個受體的人工 ligand 當佐劑（adjuvant）。訊號都走 **JAK–STAT**（JAK 3 個成員取 2、STAT 6 個成員可 dimer → 組合出不同 cytokine 訊號）→ **ISG**（PKR、OAS、Mx1）→ 抗病毒。
- **免疫脫逃「道高一尺、魔高一丈」**：細菌抑制 phagosome–lysosome 融合、抑制 NADPH oxidase、抑制酸化；**M protein、capsule、biofilm**（GAS、*S. pneumoniae*）妨礙附著；**leukocidin、streptolysin** 是**殺免疫細胞的 pore-forming toxin**；*Shigella*、HIV 逃出 phagosome；被 autophagosome 包住也能逃。
- PRR 訊號有**內生性煞車**（「發炎像油門、旁邊要有煞車」）→ 病原只要操控 negative regulator 就能關掉發炎與 IFN。**SOCS（suppressor of cytokine signaling）**：**SOCS3** 由 **IL-10** 誘導；JEV、RSV（respiratory syncytial virus，呼吸道融合病毒） 增加 SOCS；**EBV（Epstein-Barr virus） 產生類 IL-10** 分子；病毒蛋白還能破壞 STAT 磷酸化或 dimer。**Ebola VP24、VP35** 擋 type I IFN → 爭取複製時間。
- **GAS 全套脫逃**：DNase 切 NET、toxin 殺 neutrophil、**M protein 結合 C4bp（內生性補體抑制劑）** → 抑制 C3b 調理、降低吞噬；**protein A / protein G** 抓抗體的 **Fc**（Fab（fragment antigen-binding） 抓不到菌）；**SpeB（cysteine protease）切 IgG** → 就算有抗體疫苗也能破壞。*S. aureus* 同為 G+，用**不同分子達到同樣的脫逃**（「免疫系統就這麼一套」）。
- **慢性 / 潛伏感染**：病原負向調節免疫（類似腫瘤）；例：**HBV carrier 肝組織有大量 Treg 浸潤** → 抑制毒殺性細胞 → 病原「長居久安」。

| ✗ 淋巴球碰到 *E. coli* 不會活化 | ✓ **會**（T 也有 TLR4），但非特異性、**不會增殖** |
| ✗ 所有抗體都能固定補體 | ✓ **不是所有抗體**都能固定補體 |
| ✗ Efferocytosis 會引發發炎 | ✓ 釋放 **IL-10、TGF-β**、抑制發炎 |
| ✗ *M. tuberculosis* 逃出 phagosome | ✓ TB、HIV 是**阻止 phagosome–lysosome 融合**；逃出 phagosome 的是 ***Shigella*、*Rickettsia***（*Listeria* 用 pore-forming toxin） |
| ✗ SOCS3 由 IL-12 誘導 | ✓ **SOCS3 由 IL-10 誘導**，抑制 JAK–STAT |
| ✗ Protein A 結合抗體 Fab | ✓ Protein A／G 抓的是 **Fc** |
