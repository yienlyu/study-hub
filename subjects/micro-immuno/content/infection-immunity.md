# 對抗感染的免疫反應（依 113 共筆整理，林秋烽）

## 1. 第一道防線
- 物理：皮膚、黏液、纖毛上皮（咳嗽）、低 pH、眼淚、免疫特權區（水晶體、睪丸）。
- 化學 / 生物：**microbiota**（先駐菌抵抗入侵、抗生素破壞多樣性）、lysozyme、**抗微生物肽 AMPs**、抗微生物脂肪酸、補體、cytokines。
- **AMPs**：12–50 aa、多帶**正電**（Arg、Lys、His）→ 結合帶負電的細菌膜 → 穿孔；亦有趨化與調節 TLR 功能。例：**defensins（α：neutrophil、Paneth cell；β：上皮）**、cathelicidin（neutrophil）、dermcidin（汗腺上皮）。臨床藥：bacitracin、enfuvirtide（HIV）、telaprevir（HCV）。

## 2. 胞外感染：吞噬為主
- 皮膚：Langerhans cell（特化 DC）、macrophage；黏膜：Paneth cell、**IEL（85% αβ、15% γδ）**、Treg、**M cell**。
- 吞噬 → phagosome → phagolysosome（H⁺ pump 酸化）→ 酵素、NO、**ROS**。
- **Respiratory burst**：**NADPH oxidase（NOX）**：O₂ → O₂⁻ → （SOD）H₂O₂ →（**myeloperoxidase**）HOCl。
  - NOX 結構：膜上 **gp91、p22**；細胞質 **p40、p47、p67**（磷酸化後移位結合）。
- **Chronic granulomatous disease（CGD）**：X-linked；**gp91（~65%）**、p47（~25%）缺陷 → 無 ROS → 反覆感染，特別是 **catalase-positive 菌（S. aureus）**、真菌。
- **NETosis**：neutrophil 吐出 DNA + defensin 網捕捉病原；GAS 以 **DNase** 逃脫。
- **Efferocytosis**（胞葬）：清除凋亡細胞 → IL-10、TGF-β，不發炎。
- 抗體與 C3b 促進調理作用。

## 3. PRRs、PAMPs、DAMPs
- PAMPs（病原分子）、**DAMPs**（受損細胞釋出，如 **HMGB1** → TLR4）。
- Membrane PRRs：**TLRs**（TLR3、7、8、9 在 endosome；**TLR3 不經 MyD88**，走 TRIF → IRF3）、**CLRs**（mannose receptor、**Dectin-1（β-glucan，真菌）**、DC-SIGN）、scavenger receptor、lipid receptor（CD36）。
- Cytoplasmic PRRs：**NLRs**（peptidoglycan、stress）、**RLRs（RIG-I，病毒 RNA）**、**CDS（cytosolic DNA sensor，如 cGAS）**。
- 研究例：Lyme disease（*Borrelia*）靠 TLR1/2；West Nile virus 靠 TLR3；肺損傷 OxPLs 靠 TLR4。
- DC 擁有幾乎所有 PRRs；CD4 T 也有 TLR2、TLR4。
- 2011 諾貝爾：Hoffmann（果蠅 Toll）。

## 4. 胞內感染
- **Inflammasome（NLRP3）**：Signal 1（TLR4 → NF-κB → pro-IL-1β、pro-IL-18、NLRP3）+ Signal 2（ATP–P2X7、尿酸結晶、PAMP/DAMP）→ **caspase-1** → **IL-1β、IL-18**。
- **Pyroptosis**：caspase-1 媒介的發炎性細胞死亡（vs apoptosis 不發炎、necrosis 釋放 DAMP）。
- **IL-12**（APC）→ NK、T 分泌 **IFN-γ** → 活化 macrophage、TH1。
- **IFN-γ（type II）**：抗微生物、抗腫瘤、免疫調節；維持 MHC I/II、誘導 autophagy；JAK–**STAT1**。缺陷（或自體抗體）→ 成人發病免疫不全（易 TB、NTM）。
- **Type I IFN（IFN-α、β）**：幾乎所有體細胞；IRF 調控；IFNAR1/2 → STAT1/2 → **ISRE** → PKR、2-5AS、Mx1 → 抗病毒狀態。
- NK：抑制型 KIR 失去 MHC I 配對 + 活化受體（**NKG2D**）→ 毒殺。
- ADCC：抗體 Fc ↔ **NK 的 CD16**、macrophage、eosinophil。

## 5. 自體免疫與免疫逃脫
- **Molecular mimicry**：病原抗原類似自身 → cross-reaction（HIV gp41 抗體結合 cardiolipin；post-streptococcal：心肌炎、關節炎、舞蹈症）。
- 逃脫策略：M protein、capsule、biofilm；抗原變異；干擾 IFN（**SOCS 抑制 JAK-STAT**、Ebola **VP24/VP35**）；修飾 MHC；殺死吞噬細胞；躲在 phagosome。
- **GAS**：DNase 切 NETs、SLO/SLS 殺吞噬細胞、SpeB、EndoS、**C4BP 結合 M protein** 阻 C3b 沉積。
- 慢性感染（HBV、HCV、登革熱、TB）：轉向 Treg、IL-10、M2 → T cell exhaustion；TB 以 SOD、UreC 抗氧化，形成 granuloma。

## 🎙️ 上課錄影重點（林秋烽，10/07，約 105 分）
- 老師定位：從**宿主**的角度看免疫如何對抗病原，並強調**病原如何免疫脫逃**（所以感染症至今沒有解決）。「幫病毒上一堂免疫學，你要懂得 survive，就要懂得 immune evasion」。
- 防疫演進：isolation（隔離病人、隔離病房）→ 口罩、防護衣 → **疫苗**才是宿主本身的特異性防禦，還能形成**群體免疫**的牆（David Ho 也說根絕傳染病要靠疫苗）。
- 區分感染型態：多數細菌是 **extracellular**；少數胞內菌（如 TB）；**病毒絕對胞內寄生**。看免疫要放在 innate 或 adaptive 的框架；免疫也可能**過度**（hyperinflammation、hypersensitivity、autoimmunity）造成**間接傷害** → microbial immunopathogenesis。
- **第一道防線**：皮膚、黏液、低 pH、眼淚；**打噴嚏也算免疫力**（物理性排除）。**共生菌是 barrier**：像「大風吹已經有人卡位」，病原無法定殖 → 維持菌相多樣性很重要。台灣第一例 FMT：桃園某醫院腸胃科醫師用病人兒子的糞便治療反覆腹瀉的老婦人。抗生素濫用 → 腸胃不適。
- **AMP「一定要記得」**：12–50 aa、**多帶正電** → 結合帶負電的細菌膜 → **pore forming**（類似 MAC）；已鑑定 > 600 種。命名來自細胞：**defensin**、**cathelicidin（PMN）**、**dermcidin（皮膚上皮）**。功能：直接溶菌 + **免疫調節**（趨化、抑制或促進 TLR 訊號）→ 可開發成免疫調節產品。感染與 cytokine 都能快速誘導 AMP。
- 補體複習：classical 由抗體啟動，但因「最早被發現」才叫 classical；alternative 不需 converting enzyme、啟動最快、只是發現得晚。C3a / C5a 促 mast cell 敏感、血管通透 → 類過敏反應的開端；**C3b 是經典調理素**（像**裹粉的炸雞排**——標記成「可以炸」）。⚠️ **不是所有抗體都能固定補體**。
- **課堂問題：淋巴球碰到 *E. coli* 會不會活化？→ 會**，但是**非抗原特異性**的先天活化（T 細胞也有 **TLR4**，也有 TLR2、TLR9）→ 可產生 IL-6、AMP；但只有 TLR4 訊號**不足以讓 T 細胞增殖**（增殖需 TCR 訊號產生的 IL-2）。
- 時間軸：innate 幾分鐘到幾小時；adaptive 需數天（初次感染 **IgM 至少 7 天**）。Innate 與 adaptive 有 **crosstalk**，二次感染時兩者同時啟動。區分兩者的核心是 **memory 與 specificity**（百貨公司週年慶比喻：排隊人山人海沒人記得你 = innate；在 SK-II 專櫃買兩打 → 下次被認出來 = adaptive）。
- **胞外感染「決戰於境外」**：多發生在呼吸道、腸胃道、泌尿生殖道黏膜。皮膚下的 **Langerhans cell**（常駐、特化 APC）；樹突狀細胞的發現者（Steinman）在諾貝爾獎宣布前因胰臟癌過世，由家人代領。腸隱窩底部的 **Paneth cell 高度表現 α-defensin**（位置最底層、最容易卡東西）；**M cell** 像守門員、tight junction 易打開，下方有常駐免疫細胞（肺泡液中也有免疫細胞巡邏）；**IEL** 偏向類先天反應，innate 也有類似 TH1 / 2 / 17 的分型。
- 吞噬的「辨別敵我」= **可識別性**而非 memory 的專一性：吞凋亡細胞 = **efferocytosis（胞葬）**；病態下連正常細胞也吞 = **hemophagocytosis（噬血）**；正常細胞有「**don't eat me**」訊號、凋亡細胞出現「**eat me**」訊號。吞噬受體「**務必記起來**」：mannose receptor、complement receptor、lipid receptor（**CD36**）、scavenger receptor、Dectin、fMLP receptor；歸類為 **CLR** 等 PRR。病毒多以 endocytosis 進入。
- **NADPH oxidase（NOX）**：膜上 **gp91、p22**，細胞質 **p47、p67、p40**；受刺激後組裝到膜上產生 superoxide → 任何次單位異常 → 活性下降 → 反覆感染（部分「免疫力低落」病人是這類基因突變）→ **CGD**：巨噬細胞清不掉病原，只好形成 **granuloma** 包起來。IFN-γ 可促進這條殺菌路徑。
- **Neutrophil**：血中最多的免疫細胞，從骨髓出來只活 **24–48 小時**；「**吞了也死、不吞也死**」（吞完 = phagocytosis-induced cell death，由鄰居 efferocytosis 清除）。
- **NET / NETosis**：德國科學家發現（約 10 年前），把 neutrophil 用滴管吸住、旁邊放細菌，最後它吐出 **DNA**（PI 染色）+ granule 酵素 → 遠端捕殺細菌；代價是**暴露 self antigen**（與自體免疫、敗血性休克的 **DIC** 有關）。後來發現氣喘病人的 **eosinophil** 也有、老師實驗室發現**上皮細胞**也會 → 統稱 **ETosis**。涉及氧化壓力與 autophagy。GAS 用 **DNase「剪破網」**逃出。
- Efferocytosis 的好處：吞噬細胞吞凋亡細胞後釋放 **IL-10、TGF-β** → 預防性降低發炎、維持免疫恆定；efferocytosis 不完整可能與**自體免疫**有關。上皮細胞之間也會互相 efferocytosis。
- 各組織常駐吞噬細胞：**microglia**（腦曾被認為是免疫特權區）、Kupffer cell、alveolar macrophage、脾臟 macrophage。抗體 + C3b 共同調理 = **adaptive 協助 innate** 的典型例子。
- DC 依抗原與微環境決定 T 細胞走向：**過敏原 → 偏 TH2**；細菌、病毒 → 偏 TH1。病原也會**躲在 DC 裡**被帶到淋巴結（造成淋巴結感染）、長期潛伏、或直接清除 DC。
- **PAMP / DAMP / PRR**：DAMP 是**內生性**、平常不該暴露的分子（如核蛋白 **HMGB1**，細胞死亡、核膜改變才跑出來；可被 TLR2、TLR4 等多個受體辨識）。**所有體細胞（內皮、上皮、fibroblast）都有 PRR** → 刀傷時免疫細胞還沒到就有發炎。G+ 的 PDG ↔ **TLR2**、G− 的 LPS ↔ **TLR4**；細菌膜、DNA 也都能當 PAMP。**痛風**：尿酸結晶 = DAMP → 痛是**發炎反應**造成，不是結晶刺到。
- **2011 諾貝爾**：Hoffmann 的突變果蠅（缺 **Toll**）竟死於**真菌感染**；高等動物找到的是 Toll-*like* receptor。日本 **Akira** 建立大規模 TLR knockout 小鼠庫。TLR：人類 9 類（TLR1–9 以內）、小鼠共 13 類。PRR 下游兩大轉錄因子：**NF-κB**（IL-1、IL-6、IL-8、TNF-α、MCP-1…）與 **IRF**（interferon）。
- 研究例：Lyme disease 的 **OspA** 由 **TLR1 / TLR2** 辨識（疫苗開發）；**West Nile virus**（與登革同科）在 **TLR3** knockout 小鼠病毒量高、早期發炎低；吸入性嗆傷（消防員、士兵）→ 酸造成**氧化磷脂（OxPL）** → **TLR4** → NF-κB → 急性肺損傷（TLR4 knockout 小鼠有抗性 → TLR4 抑制劑可能用於預防）。
- **DC 帶有的 PRR 種類最多 → 最 professional 的 APC**。
- 抗體功能補充：「**抗體不只有中和**」——結合的 epitope 不一定是關鍵位置；有些抗體結合穿膜蛋白反而**刺激活化**；還有調理（Fc receptor）、協助 classical pathway。**95% 以上 B 細胞活化依賴 T**；沒有 T 協助則多為 IgM、polyclonal。
- **Molecular mimicry**：2005 年 Science —— HIV **gp120 / gp41** 的中和抗體會交叉結合宿主分子；self antigen 序列恰好與病原相似 → 自體免疫（大家共用同一個地球的資源，演化出相似的蛋白）。另一機制：感染讓 efferocytosis 下降 → self antigen 清不掉 → **tolerance breakdown**。疫苗 side effect（如 arthritis）也可用此解釋 → 從安全性看，**特異性 peptide 疫苗**比 whole agent 好控制。GAS 反覆感染 → 抗體交叉結合神經受體 → **Sydenham chorea（手足舞蹈症）**；也懷疑與心肌炎、關節炎有關。
- **胞內感染**：PRR 在細胞質：**NLR（NOD1、NOD2、NLRP）**、**RLR（RIG-I、MDA5 認病毒 RNA）**、**cytosolic DNA sensor（AIM2、STING 相關）**。「**請大家一定要對 NLRP 有點印象**」：NLRP = **inflammasome**，產生 **IL-1β（mature form）與 IL-18**；訊號來自細胞內 crystal、ATP、lysosome damage 等。兩步驟：**signal 1（TLR → 準備原物料）+ signal 2（activation，如氧化壓力 → 組裝）**。絕大部分感染與 DAMP 都有 IL-1 → 所有 PRR 都可能連到 caspase-1 / inflammasome。
- Caspase 對照：**caspase-8**（death receptor）、**caspase-9**（粒線體）是 initiator → **caspase-3** → 內切核酸酶切 DNA → apoptosis（**silent**，膜完整、不釋放 self antigen，形成凋亡小體被 efferocytosis）；**caspase-1** → IL-1β → **pyroptosis（細胞焦亡，pro-inflammatory）**。Pyro 取自 *pyogenes*：化膿性鏈球菌造成高燒（IL-1β、TNF-α）、**壞死性筋膜炎（噬肉菌）**傷口早期像燒焦、需外科清創。
- **NK 與 macrophage 的 crosstalk**：macrophage 的 **IL-12** 活化 NK → NK 分泌 **IFN-γ** 回饋活化 macrophage（抗原呈現↑、抗微生物蛋白↑）；adaptive 中 **TH1** 也分泌 IFN-γ 回饋 APC → 不斷放大循環。有 cytokine（如 IFN）存在時 PRR 反應可差到 **1000 倍**。
- **成人型免疫缺乏症（adult-onset immunodeficiency）**：**HIV 陰性**但反覆感染、像 HIV（**TB、NTM**）→ 缺 IFN-γ 訊號（基因缺陷、下游轉錄因子突變，或產生**抗 IFN-γ 自體抗體**）。北醫三家附屬醫院實驗室常收到疑似個案；先排除遺傳、再驗自體抗體 → 若是自體抗體，治療要**針對 B 細胞**（只殺菌會一直復發）。
- NK「翹翹板」：抑制型 KIR 認 MHC I；癌化或病毒感染細胞下調 MHC I → 抑制訊號消失 → 活化 → **granzyme B、perforin**；IFN-γ 讓標的細胞先「準備好」促凋亡蛋白。
- **Interferon**：type I（**IFN-α、β**，幾乎所有細胞，抗病毒）、type II（**IFN-γ**）。**TLR3、7、8、9** 是誘導 type I IFN 最主要的 PRR → 疫苗會用這四個受體的人工 ligand 當佐劑。訊號都走 **JAK–STAT**（JAK 3 個成員取 2、STAT 6 個成員可 dimer → 組合出不同 cytokine 訊號）→ **ISG**（PKR、OAS、Mx1）→ 抗病毒。
- **免疫脫逃「道高一尺、魔高一丈」**：細菌抑制 phagosome–lysosome 融合、抑制 NADPH oxidase、抑制酸化；**M protein、capsule、biofilm**（GAS、*S. pneumoniae*）妨礙附著；**leukocidin、streptolysin** 是**殺免疫細胞的 pore-forming toxin**；*Shigella*、HIV 逃出 phagosome；被 autophagosome 包住也能逃。
- PRR 訊號有**內生性煞車**（「發炎像油門、旁邊要有煞車」）→ 病原只要操控 negative regulator 就能關掉發炎與 IFN。**SOCS（suppressor of cytokine signaling）**：**SOCS3** 由 **IL-10** 誘導；JEV、RSV 增加 SOCS；**EBV 產生類 IL-10** 分子；病毒蛋白還能破壞 STAT 磷酸化或 dimer。**Ebola VP24、VP35** 擋 type I IFN → 爭取複製時間。
- **GAS 全套脫逃**：DNase 切 NET、toxin 殺 neutrophil、**M protein 結合 C4bp（內生性補體抑制劑）** → 抑制 C3b 調理、降低吞噬；**protein A / protein G** 抓抗體的 **Fc**（Fab 抓不到菌）；**SpeB（cysteine protease）切 IgG** → 就算有抗體疫苗也能破壞。*S. aureus* 同為 G+，用**不同分子達到同樣的脫逃**（「免疫系統就這麼一套」）。
- **慢性 / 潛伏感染**：病原負向調節免疫（類似腫瘤）；例：**HBV carrier 肝組織有大量 Treg 浸潤** → 抑制毒殺性細胞 → 病原「長居久安」。

## 🎙️ 老師課堂提示
- 老師明講要記：**AMP**（「一定要記得」）、**吞噬受體**（「務必把它記起來」）、**NLRP / inflammasome**（「一定要有點印象」）。
- 課堂提問：淋巴球碰到 *E. coli* 會不會活化？→ 會（TLR4，非抗原特異性），但不會因此增殖。
- 易考配對：TLR2–PDG、TLR4–LPS / OxPL、TLR3–West Nile virus、TLR1/2–Lyme OspA；caspase-1 → pyroptosis vs caspase-3 → apoptosis；SOCS3 ← IL-10；Ebola VP24/VP35；GAS 的 C4bp、SpeB、DNase、protein A/G。
- 臨床情境：HIV 陰性卻反覆 TB / NTM → 想到 **IFN-γ 訊號缺陷或抗 IFN-γ 自體抗體**；CGD → granuloma、反覆感染。
