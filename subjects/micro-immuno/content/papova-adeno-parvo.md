# 乳突、多瘤、腺病毒與微小病毒 內容整理（依百十三共筆整理，林良宗）

> 📑 依百十三共筆 W9-1 §八–§十四（同一位老師）整理，並對照 2026 講義「醫-Papil.Polyo.Adeno.Parvo.」（27 頁，Ch.49、50、53）。百十四共筆上傳後再補。
> 老師開場與結尾都提醒：**講義裡的 tables 是複習重點**，最後一頁的 Summary 表要會。

## 1. 分類：四個科一張表 ⭐⭐⭐

| 科 | 病毒 | 套膜 | 基因體 |
|---|---|---|---|
| **Papillomaviridae** | Papillomavirus（**HPV**） | **無** | **雙股環狀 DNA** |
| **Polyomaviridae** | Polyomavirus（**SV40、BK、JC**） | **無** | **雙股環狀 DNA** |
| **Adenoviridae** | Adenovirus（ADV） | **無** | **雙股線狀 DNA** |
| **Parvoviridae** | Parvovirus（**B19**） | **無** | **單股 (+) 線狀 DNA** |

- **四個都沒有套膜、都是 DNA 病毒、都以 cell lysis 釋出**。
- 舊的 **Papovaviridae 已拆成 Papillomaviridae 與 Polyomaviridae**。
- 只有 **parvovirus 是單股**，其餘都是雙股；只有 **adenovirus 是線狀雙股**，papilloma 與 polyoma 是**環狀**。

## 2. 為什麼這幾個病毒跟癌症有關 ⭐⭐⭐

老師在錄影裡花了很長一段講這個邏輯，是本章的主軸：

- 病毒**完全依賴宿主**，好不容易找到宿主細胞，當然希望宿主**活久一點**、持續幫它做蛋白質。
- 但細胞察覺被感染時，會選擇**凋亡（apoptosis）**——這是「安全的死法」：膜起泡、核濃縮、分裝成小包被免疫細胞吃掉，**病毒與細胞內容物都不會跑出去**。守門員是 **p53**。
- 所以病毒要**關掉這個機制**，並**override 細胞的能量回饋**，讓細胞像工廠一樣不停做蛋白。
- 結果：**細胞一直增生 ＋ 忘記怎麼死掉** = 很像癌細胞。
- 這些病毒都會去**調控生長抑制蛋白 p53 與 pRb（p105RB）**：

| 病毒 | 致癌基因 | 結合對象 |
|---|---|---|
| **Papillomavirus** | **E6** | **p53** |
| | **E7** | **pRb** |
| **Polyomavirus** | **Large T antigen** | **p53 與 pRb 兩個都結合** |
| **Adenovirus** | **E1A** | **pRb** |
| | **E1B** | **p53** |
| Parvovirus | **無** | — |

- ⚠️ 老師強調：**影響這些基因不等於細胞已經癌化**，只是有癌化的可能；**真的會在人類造成癌症的只有 HPV**。polyoma、adeno 在動物模式會長腫瘤，**在人類沒有**。
- 實驗室應用：**SV40 large T antigen** 常用來把 primary cell **immortalize**（建立細胞株）——primary cell 離開原環境培養幾代就會死，打進 T antigen 就能一直複製。

### 在 permissive vs nonpermissive 細胞

- **Permissive cell**：完成複製 → **lytic infection**，宿主細胞死亡。
- **Nonpermissive cell**：**abortive**（進得去但做不完）、**persistent**、**latent**、**immortalize／transformation**（癌化）。

## 3. Papillomavirus（HPV）⭐⭐⭐

- 感染並複製於**皮膚與黏膜的鱗狀上皮**（生殖道、口腔、結膜），引起**上皮增生**。
- **疣（wart）怎麼形成**：病毒刺激細胞生長、**基底層與棘細胞層變厚** → 促進 **keratin（角蛋白）** 生成、形成上皮棘狀突起（**papillomatosis**）。
- 病毒生活史跟著**角質化分層**走：基底細胞（感染、增生）→ 棘狀細胞（複製）→ 角質層細胞（成熟與釋出）。
- 感染**通常侷限在局部、會自行消退，但可能復發**。

| 部位 | 型別 |
|---|---|
| 手、腳的常見疣 | **HPV-1 ～ 4** |
| 生殖器疣 | **HPV-6、11** |
| 喉頭乳突瘤（喉部良性上皮瘤） | **HPV-6、11** |

- **傳播**：密切接觸——**皮膚或黏膜的破損處、性行為、嬰兒經過產道**。
- **HPV 躲過免疫反應、持續存在**，直到免疫反應被啟動才解決。
- **HPV 與癌症** ⭐⭐⭐
  - 性活躍族群中非常普遍。
  - **99.7% 的子宮頸癌都找得到 HPV**。
  - **高危險型：HPV-16、18、31、33、45**；**低危險型：HPV-6、11**。
  - **HPV-52、58** 與陰道感染及癌症有關。
  - 某些型造成 **dysplasia（不典型增生）**，再加上輔因子才可能癌化；**病毒 DNA 嵌入腫瘤細胞染色體**。
- **診斷**
  - 組織學：**棘細胞增生 + 角蛋白過度產生** → 確認疣。
  - **子宮頸抹片（Pap smear，巴潘尼克氏染色）**：看 **koilocytotic cell**——細胞質有空泡、細胞變圓、**成叢**出現。
  - **DNA probe 與 PCR** 可定型；**抗體檢驗很少用**。
- **治療**：疣可去除——**冷凍治療（液態氮）、電燒、化學藥劑（強酸）**；**喉頭乳突瘤必須手術**。**IFN 與 imiquimod** 可加速癒合。
- **預防** ⭐⭐⭐
  - 疫苗最初針對 **HPV-6、11、16、18**，可減少肛門生殖器疣與子宮頸癌；現有**九價疫苗（6、11、16、18、31、33、45、52、58）**。
  - **11 歲起、性行為之前**接種；**男女都要打**——男性雖然沒有子宮頸，但**會傳播**。
  - ⚠️ **打了疫苗不能取代子宮頸抹片**（疫苗只涵蓋部分型別）。
  - 避免接觸病灶、使用保險套等防護。

## 4. Polyomavirus ⭐⭐

- **45 nm（小）、約 5000 bp、雙股環狀 DNA**；**BK、JC、SV40 的基因體組織相似**；組裝與複製都在**細胞核內**。
- **BK、JC 到處都是（ubiquitous），通常不致病**；只有在**免疫低下**病人才可能出現併發症（少見）。

| 病毒 | 宿主 | 疾病 |
|---|---|---|
| **BK virus** | 人 | **腎臟疾病**，可能變成出血性膀胱炎 |
| **JC virus** | 人 | 感染 CNS → **PML（漸進性多發性腦白質病變）** |
| **SV40** | 猴 | **人類沒有相關疾病**；實驗室的致癌模式病毒 |
| murine polyomavirus | 鼠 | 同上 |

- **致病基因只強調 Large T antigen**：結合 **p53 與 pRb** → 促增生、抑凋亡 → **immortalize 與 transformation**。
- **致病機轉**：呼吸道進入 → **初級病毒血症** → 在**腎臟**複製 → 被免疫壓制後**終身潛伏**；免疫低下時再出問題。
- ⚠️ **BK、JC、SV40 在動物模式會長腫瘤，但都沒有被認為會造成人類腫瘤**。

## 5. Adenovirus ⭐⭐

- **無套膜、二十面體（icosadeltahedron）、70–90 nm**；表面有 **fiber（末端 knob）**，負責結合細胞進入。
- **線狀雙股 DNA**；**約 100 個血清型，47 型感染人**，**ADV 1–7 最常見**。
- **三種感染型態**：
  - **Lytic**：黏膜上皮細胞
  - **Latent**：淋巴細胞
  - **Transforming**：**只在倉鼠，人類不會**
- **致病基因**：**E1A 結合 pRb、E1B 結合 p53** → 促 transformation、抑凋亡（**對非人類細胞致癌，對人類不致癌**）。
- **免疫逃脫機制**：
  - **VA RNA（virus-associated RNA）**：阻止 **PKR 活化**（避免宿主停掉病毒蛋白合成）
  - **E3 與 E1A**：阻擋 T 細胞或細胞激素誘導的凋亡
- **臨床**（多半輕微、**自限性**，放著一週會好）：
  - 眼：**結膜炎（pinkeye）**
  - 腸胃道：**腸胃炎**
  - 泌尿道：**出血性膀胱炎**
  - 呼吸道：一般上呼吸道感染
- **治療與疫苗**：**沒有核准的治療**；有 **ADV-4、ADV-7 口服活疫苗，但只用於軍人**。
- **應用** ⭐⭐：高感染力、低毒性、高表現量 → **基因治療的優良載體**（囊腫性纖維化、癌症；常用 **type 5、4、7**）。COVID-19 有些疫苗就是腺病毒載體。
  - **溶瘤病毒治療**：中國 SFDA **2005 年核准 H101（Oncorine）** 治療頭頸癌。

## 6. Parvovirus B19 ⭐⭐⭐

- **最小的 DNA 病毒（18–26 nm）**、**單股線狀 DNA、無套膜**；**只有 B19 已知會感染人**。
- 全球都有；**沒有專一治療或控制方式**。
- **生活史**：受體媒介胞吞進入 → **核內**脫殼、複製、組裝 → **lysis 釋出**，宿主細胞死亡（**cytolytic**）。
- **嗜性 ⭐⭐⭐：偏好在有絲分裂旺盛的紅血球系細胞複製**——骨髓細胞、胎兒肝的紅血球前驅細胞、紅血球系白血病細胞 → **不成熟紅血球異常下降**。
- **臨床**：
  - **兒童：傳染性紅斑（erythema infectiosum）＝ 第五病**，典型的**「被打巴掌」臉頰（slapped cheek）**，通常自己會好。
  - **成人：急性多關節炎（acute polyarthritis）**。
  - **慢性溶血性貧血患者 → aplastic crisis（再生不良性危象）**，嚴重、有生命危險。
- **雙相病程（biphasic）** ⭐⭐：
  - **溶解期（lytic phase）**：對應**病毒血症**。
  - **後期（late phase）**：對應**免疫反應**——**出疹與關節痛是在這個階段**出現。

## 7. Summary 表（老師說要背）⭐⭐⭐

| | Papillomavirus | Polyomavirus | Adenovirus | Parvovirus |
|---|---|---|---|---|
| **遺傳物質** | 雙股**環狀** DNA | 雙股**環狀** DNA | 雙股**線狀** DNA | **單股線狀** DNA |
| **致癌基因** | **E6、E7** | **Large T antigen** | **E1A、E1B** | **無** |
| **傳播方式** | **直接接觸** | **Aerosol** | **Aerosol、密切接觸、糞口** | **Aerosol** |
| **特殊疾病** | 疣／癌症（**HPV-16、18**；koilocytotic cell） | **BK：腎臟疾病**；**JC：PML** | **Pinkeye**、出血性膀胱炎、腸胃炎 | **傳染性紅斑**、急性多關節炎、**aplastic crisis** |
