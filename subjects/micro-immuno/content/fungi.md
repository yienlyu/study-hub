# 真菌構造與黴菌病（鍾筱菁）

> 🎙️ 本章依 2026 上課錄影的逐字稿與 slides 整理：10/24「真菌結構及抗真菌藥物」（颱風假錄影 54 分）、10/28「真菌感染症」（約 90 分），並對照 113／111 考古詳解（113 共筆沒有收錄本章）。期中配分：**真菌構造與抗真菌藥 3%、真菌感染 6%**。
> 「**真菌一定會考**，不像細菌、病毒要用猜的」，期中考題中英文混雜，背不起英文就背中文；國考直接考英文學名。
> ⭐ = 老師說會考或國考題；~~刪除線~~ = 老師說不考。

## 1. 真菌是什麼：和細菌、人比一比 ⭐

- **真核生物**、無葉綠素（異營）；約 100,000 種，**只有約 300 種**和動物疾病有關。
- **ergosterol**

|          | 細胞壁                                                                                       | 細胞膜上的固醇             |
| -------- | -------------------------------------------------------------------------------------------- | -------------------------- |
| **真菌** | **β-1,3-D-glucan（主軸）+ chitin（網架）+ mannan（mannoprotein）**；無 peptidoglycan、無 LPS | **Ergosterol（麥角固醇）** |
| 人       | **沒有細胞壁**                                                                               | **Cholesterol**            |
| 細菌     | **Peptidoglycan**                                                                            | **沒有固醇**               |

- 這兩個差異 = **抗真菌藥的兩大標的**（cell wall synthesis、ergosterol）。人也有固醇 → amphotericin B 會傷到人。
- 考古選項陷阱：chitin 是 **β-1,4** NAG、glucan 是 **β-1,3**（主鏈）／β-1,6（側鏈）；常被換成 α、1-4 或 peptidoglycan。
- 生長條件：最適 pH **4–6**、多數最適 **25–30 °C**（不是 37 °C）。
- **真菌不耐高溫、不耐乾燥（國考題）** ⭐：yeast 加熱到 60–80 °C 就死（實驗課 _Candida albicans_ 就是「不耐熱的遜咖」）。老師的偏方：香港腳就在七、八月中午把腳插進燙沙裡。
- 孢子功能不同：細菌孢子（只有 _Bacillus_ 需氧、_Clostridium_ 厭氧）用來**抵抗惡劣環境**；真菌孢子用來**繁衍後代**。

## 2. 型態：yeast、mold、dimorphism

- **Yeast = 單細胞**：**出芽（budding）**或分裂；菌落**圓、糊狀或黏液狀**；行為、菌落、分裂都像細菌。芽像貓耳朵、兔耳朵（大顆生小顆）。
  - **Yeast 不要翻成「酵母菌」**：酵母菌專指 _Saccharomyces_（白馬非馬）。
  - **Pseudohyphae 不是 hyphae**，仍屬 yeast form（出芽後沒分開，_Candida_）。
- **Mold = 多細胞**：**hyphae（菌絲）→ mycelium（菌絲體）+ spore**；菌落**絲狀、毛狀、棉絮狀**。
- **菌絲的兩種分法（國考題）** ⭐：
  - 形態：**septate（有隔）**（子囊菌、擔子菌）vs **coenocytic（無隔）**（**接合菌**）。
  - 功能：**營養菌絲**（匍匐在培養基表面或內部吸收養分，像草莓的匍匐莖）vs **空中（氣生）菌絲**（頂端長分生孢子或孢子囊孢子）。
- **Dimorphism（雙形性）取決於「溫度」** ⭐（老師說「一個字就能判斷你有沒有上課」）：戶外低於 37 °C = **mold**；吸進體內 37 °C = **yeast**（像細菌一樣分裂、造成肺炎）。**全身性的 true pathogen 幾乎全都是 dimorphic**。
  - 代表：_Histoplasma_、_Blastomyces_、_Coccidioides_、_Paracoccidioides_、_Talaromyces marneffei_、**_Sporothrix schenckii_**（皮下）。
  - _Candida albicans_ 在 37 °C yeast、pseudohyphae、hyphae 同時存在 → **不算典型 dimorphic**；_Cryptococcus_ 是 yeast，也不算。

## 3. 孢子與生活史

|        | 有性孢子                                                                                                 | 無性孢子                                                                      |
| ------ | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 過程   | 兩個相容 mating type（±、a／α）→ **質融合（plasmogamy，N+N）→ 核融合（karyogamy）→ 減數分裂 → 4 個子代** | **只有有絲分裂**；最常見（不必等另一半）                                      |
| 意義   | **物種多樣性**                                                                                           | 快速繁殖                                                                      |
| 世代名 | **Teleomorph**                                                                                           | **Anamorph**                                                                  |
| 種類   | **zygospore、ascospore、basidiospore**                                                                   | **sporangiospore**（**一個布袋裝很多孢子**）、**conidia**（最常見的無性孢子） |

- Conidia 的形態：**arthroconidia／arthrospore**（菌絲分節斷裂，_Coccidioides_）、**blastoconidia**（出芽）、**chlamydospore**（厚膜；**菌絲本身細胞壁增厚**）、**phialoconidia（瓶孢子）**、microconidia。
- 考古分法：**Blastic** = blastospore、phialospore、sporangiospore；**Thallic（體細胞型）** = **arthrospore、chlamydospore**。

## 4. 分類：醫學上要記的四個門 ⭐

- 老師說會考**不同門的有性孢子、無性孢子、菌絲特色**。
- 分類演變（看看就好）：傳統四門（Asco、Basidio、Zygo、Deutero）→ 2007 年 7 門 → 2018 年 18 門；舊 Zygomycetes 拆成 **Mucoromycota（毛黴門）**與 Entomophthoromycota（蟲黴門），接合菌門已不存在。

| 門                                   | 菌絲                               | 無性孢子                                  | 有性孢子                                     | 代表                                                                                                                         |
| ------------------------------------ | ---------------------------------- | ----------------------------------------- | -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **子囊菌門 Ascomycota**              | **有隔**                           | **conidia**（_Talaromyces_ 掃帚狀、瓶形） | **ascospore**（ascus 內 4、8 個）            | **約 50% 已命名真菌、約 80% 醫學重要真菌**：_Aspergillus_、_Penicillium／Talaromyces_、酵母菌、_Candida_、**_Pneumocystis_** |
| **擔子菌門 Basidiomycota（香菇門）** | 有隔、clamp connection             | **幾乎沒有**                              | **basidiospore**（菌傘下每個 basidium 4 個） | 香菇、杏鮑菇、毒蠅傘（紅傘傘白桿桿）；**醫學三隻：_Malassezia_、_Trichosporon_、_Cryptococcus neoformans_（國考題）** ⭐     |
| **接合菌（毛黴門）**                 | **無隔（coenocytic）**、分枝約 90° | **sporangiospore**                        | **zygospore（接合孢子）**                    | **_Rhizopus_（麵包發霉的根黴菌）**、_Mucor_、_Absidia_                                                                       |
| **微孢子門 Microspora**              | —                                  | 只有無性                                  | **沒有有性世代**                             | _Encephalitozoon_：**無粒線體、無微管（無典型 cytoskeleton）、絕對細胞內寄生**；伸出 tube 把核注入宿主細胞                   |

- **_Cryptococcus neoformans_ 長得像 yeast、行為像 yeast、染色也像 yeast，但屬於擔子菌門** ⭐（常被誤認為子囊菌）。考古：它是 Basidiomycetes 中唯一的致病酵母；_Aspergillus_ 不屬於擔子菌。
- **微孢子蟲（Microsporidia）是真菌不是蟲**：以前當寄生蟲，定序後歸為真菌，因太特別自成一門。**新興感染症**（人類病例近年變多），**和水有關**（泡溫泉、泥水噴濺）→ **角膜炎**（2022、2025 新聞）；也是免疫低下者與老人的伺機感染。
- **卡氏肺囊蟲（_Pneumocystis_）也不是蟲**：rRNA 像酵母 → **子囊菌門**（和微孢子門不同門）。
- 考古另有 **Deuteromycota（不完全菌）** = 有隔、只有 conidia、**未發現**有性世代。

## 5. 抗真菌藥：四類、兩個標的 ⭐

| 類                          | 藥                                                                                     | 機制                                                    | 老師強調                                                                                                                |
| --------------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **I. 細胞膜（ergosterol）** | **Allylamine：terbinafine（療黴舒，國考題）**                                          | **抑制 ergosterol 合成**（squalene epoxidase）          | 作用在哪個酵素「考了實在有點狠，我不會考」                                                                              |
|                             | **Azole**（最大宗，字尾 -zole：ketoconazole、fluconazole、itraconazole、voriconazole） | **抑制 ergosterol 合成**（14-α-lanosterol demethylase） | **Ketoconazole = 仁山利舒**（頭皮屑、汗斑；2%，嚴重 4%）；口服或外用                                                    |
|                             | **Polyene：amphotericin B、nystatin**                                                  | **直接結合 ergosterol → 在膜上打洞**                    | 見下方 amphotericin B                                                                                                   |
| **II. 細胞壁**              | **Echinocandin**（caspofungin；**2015 上市當年就考，國考題**）                         | 抑制 **β-1,3-D-glucan 合成** → **與 ergosterol 無關**   | 標的是人沒有的細胞壁，**像 penicillin 一樣專一、副作用小** → 臨床治療**侵襲性麴菌症**；但仍不如 amphotericin B 暴力有效 |
| **III. 細胞分裂**           | **Griseofulvin**                                                                       | 破壞有絲分裂紡錘體（停在 metaphase）                    | **累積在角質層 → 頭癬**（皮癬菌二線藥）                                                                                 |
| **IV. 核酸合成**            | **5-flucytosine（5-FC）**（氟化的 cytosine）                                           | 經 cytosine permease 進入 → 5-FU → 抑制 RNA／DNA 合成   | **窄譜**：_Candida albicans_、_Cryptococcus_、_Aspergillus_、_Blastomyces_                                              |

- \*\*Amphotericin B ⭐：
  - **直接結合膜上的 ergosterol 打洞 → 殺菌效果直接**；但也會結合人的 **cholesterol** → **高毒性**，「**殺敵一萬、自損八千**」。
  - **IV 給藥，用在快死的、致命的全身性黴菌病**。從皮下以下每一種嚴重感染，老師都問「用什麼藥？」→ 答案都是 amphotericin B。
  - **Amphotericin B + 5-FC = 協同作用（synergistic）** ⭐：amphotericin B 的毒性 **dose-dependent** → 併用 5-FC 可以**降低劑量、達到同樣療效**（1 + 1 > 1）。
  - **例外：_Pneumocystis_ 沒有 ergosterol → 不能用 amphotericin B** ⭐。
- 考古：_Candida krusei_ **天生抗 fluconazole**（見 §11）；真菌感染上升的原因是抗藥性、免疫抑制劑、AIDS（**不是菌種明顯增加**）。

## 6. 黴菌病總覽（老師說國考前整張背起來）

- 兩大類：**感染健康人（true pathogen）** vs **伺機性感染**（老、弱、慢性病、幼兒、immunocompromised）。
- 依部位由淺到深：

| 層次                        | 要記的菌／病                                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **淺表（superficial）**     | 汗斑 _Malassezia furfur_；白色毛結節 _Trichosporon_；黑色毛結節 _Piedraia hortae_                            |
| **皮膚（cutaneous）**       | **皮癬菌（癬類）**：_Trichophyton_、_Microsporum_、_Epidermophyton_                                          |
| **皮下（subcutaneous）**    | **孢子絲菌病（_Sporothrix schenckii_）**；暗色黴菌三病：**著色芽生菌病、暗色絲孢黴病、足菌腫**               |
| **全身性（true pathogen）** | _Histoplasma_、_Coccidioides_、_Blastomyces_、_Paracoccidioides_ ＋ **醫學系第五支 _Talaromyces marneffei_** |
| **伺機性（五大必記）**      | **白色念珠菌、新型隱球菌、卡氏肺囊蟲、煙麴菌、接合菌（毛黴菌）病**                                           |

## 7. 淺表黴菌病

- **汗斑／花斑癬（tinea versicolor）：_Malassezia furfur_（皮屑芽孢菌）** ⭐
  - **擔子菌門（國考題）**；**幾乎每個人身上都有**，但**需要油脂**才發病（老師：全身油滋滋、不愛洗澡的年輕人）。
  - 干擾黑色素 → **脫色白斑**（深膚色者最明顯）。
  - 嚴重一點：毛囊炎、**脂漏性皮膚炎、頭皮屑**；systemic infection 很少（導管相關敗血症）。
  - 治療：**ketoconazole（仁山利舒）**。
- **毛結節菌病（piedra）**：長在毛幹上，看起來像頭蝨卵。
  - **白色毛結節 white piedra：_Trichosporon_（beigelii）**，**擔子菌門**。
  - **黑色毛結節 black piedra：_Piedraia hortae_**。

## 8. 皮膚黴菌病：皮癬菌（dermatophytes）⭐

- **「Keratin lover」**：喜歡**角質蛋白（keratin）** → 侵犯角質層、毛髮、指甲。
- 依部位命名：**頭癬、鬚癬、體癬（金錢癬，ringworm）、股癬、足癬（香港腳 = athlete's foot，濕又溫暖）、甲癬（灰指甲）**。
- **三個屬一定要背（醫學系、護理系國考出過 3–4 次）**：**_Trichophyton_、_Microsporum_、_Epidermophyton_**。
  - 考古看圖題：大孢子形狀 _Trichophyton_ 臘腸狀、**_Microsporum_ 梭狀**、**_Epidermophyton_ 棒狀**。
- **不會致死**；症狀來自發炎與過敏反應。治療用 **azole**（不用 amphotericin B）；灰指甲太嚴重就拔掉；頭癬用 griseofulvin。考古情境題：_Candida_ 或皮癬菌造成的指甲感染 → **terbinafine**。
- 診斷：**Wood's lamp（UV）照射會發螢光**；KOH 看皮屑、指甲。
- 人、動物（貓）、土壤都是 reservoir；孢子耐性強、潛伏期長。
- 老師的貓「將將」故事：從一屋 19 隻貓的家庭領養 → 全身真菌 → 獸醫叫牠用 **ketoconazole 藥浴（仁山利舒同成分）**洗澡 → 老師手上長出「最典型的金錢癬」 → 口服藥吃 3 天、睡 3 天。

## 9. 皮下黴菌病

- **孢子絲菌病（sporotrichosis）：_Sporothrix schenckii_（dimorphic）** ⭐
  - **玫瑰園丁病（rose gardener's disease）**：土壤中的孢子經**刺傷傷口**進入。
  - 從皮膚進來的感染 → **沿淋巴管一顆一顆、成串的結節**（lymphocutaneous）；看到「園丁 + 成串淋巴結」就是它。未治療可能到肺。
  - 培養：25 °C **rosette（雛菊、梅花狀）conidia**、37 °C **cigar-shaped yeast**。
  - 治療：**potassium iodide（KI）**或 itraconazole；**很少致死**。
- **暗色黴菌三病（三個一起記；記病名就好，菌名「考了太狠」）**：菌絲和孢子都是**暗色**（統稱暗色黴菌症）。
  - **著色芽生菌病（chromoblastomycosis）**：_Fonsecaea pedrosoi_ 等；**赤腳農夫**在田裡被割傷 → 經過**好幾年**才從癢的小病灶變成 papule／ulcer，再變成**疣狀 nodule、granuloma**。
  - **暗色絲孢黴病（phaeohyphomycosis）**：棕色菌絲（_Alternaria_、_Exophiala_）；高度免疫低下者，皮膚 → 囊腫 → 骨、腦、肺。
  - **足菌腫（fungal mycetoma，Madura foot）**：真菌（_Pseudallescheria_、_Madurella_）；**細菌性的是 actinomycetes（放線菌）**；黑色顆粒，侵犯肌肉、骨骼。
  - 共同點：**不知不覺、時間冗長、很難治療** → **手術切除疣狀物 + amphotericin B**（或併用 azole、5-FC）。

## 10. 全身性黴菌病（true pathogen）⭐ 老師：「這四個我會考一題，每個系都一樣」

- **共同特色**：
  1. **地方性**（北美、南美、非洲等地大物博處）；~~哪隻在哪個地區「我不會考」~~，但國考會考。
  2. 戶外是 **mold**，有人跑步經過 → **吸入 conidia → 肺** → 進體內變 **yeast** → **全部都是 dimorphic**。
  3. 多數無症狀或 **flu-like**（頭痛、發燒、不舒服）→ 自己好了。
  4. 少數**從肺播散到全身**（liver、kidney、heart、brain、bone，甚至**皮膚長瘡流膿、結節**；**不是從皮膚進來，是吸進去後跑到皮膚**）→ 可能致死 → **amphotericin B**。
  5. 感染後**長期免疫**（對真菌抗原的過敏反應）。

## 11. 伺機性黴菌病（五大必記，臨床最常遇到、最會致死）⭐

### ① 念珠菌病（candidiasis）

- 菌種：**_C. albicans_**（最常見）、_C. glabrata_、_C. parapsilosis_、_C. tropicalis_、_C. krusei_。
- 型態：**budding yeast** + **pseudohyphae** + 真 hyphae；creamy smooth colony；chlamydospore。
- **正常菌叢**：約 **20% 的人**帶 _C. albicans_（咽喉、腋下、指甲、陰道）；宿主防禦下降才致病；**院內黴菌感染約 70%**。比例依病人族群不同（有些族群 _C. glabrata_ 最多），但整體仍以 _C. albicans_ 最多。
- **⭐ _C. krusei_ 天生抗 fluconazole**（醫學系、護理系國考題，老師講了三次）。
- 疾病（從口到全身）：
  - **鵝口瘡（oral candidiasis, thrush）**：偽膜性白斑；新生兒、老人、吸類固醇的過敏病人。
  - **外陰陰道念珠菌病**：陰道本來就**充滿好菌（microbiota）**，**亂用抗生素或過度清洗（用肥皂洗）**破壞菌叢 → _Candida_ 爬起來；只用抗生素或抗真菌藥治療，一、兩週後會再發 → 補回**陰道菌叢**（不是腸道的優酪乳）；糖尿病、懷孕也是危險因子。
  - 甲溝炎、皮膚皺褶、尿布疹；**食道念珠菌病：約 70% AIDS 病人**。
  - **念珠菌血症（systemic candidiasis）**：**死亡率 40–60%，比一般敗血症更高** → **amphotericin B + 5-FC**。
- 診斷 ⭐：
  - **Germ tube test**：**馬血清、37 °C、2–4 小時** → _C. albicans_（及 _C. dubliniensis_）長出 germ tube。
  - **CHROMagar Candida（國考題，藥學系、醫學系）**：不同菌種把 substrate 轉成不同顏色 → **_C. albicans_ 綠色、_C. tropicalis_ 藍色、_C. krusei_ 粉紅色**。
  - 其他：trypan blue 培養基、生化測試、DNA amplification。

### ② 新型隱球菌（_Cryptococcus neoformans_）⭐

- **看到鴿子要想到它**（看到雞蛋想到沙門氏菌、看到海鮮想到弧菌）。
- **擔子菌門**、像 yeast；**莢膜（capsule）**作用是**防止被辨認**（主要致病因子）；無 pseudohyphae、不形成 chlamydospore。
- **吸入**鴿糞（**不是腸胃道**）→ 肺 → 血 → **腦膜炎**（最易侵犯腦的真菌）：頭痛、意識改變、癲癇、昏迷，致死率高；好發於 **AIDS**、老人、小孩、類固醇、糖尿病、癌症患者。新聞案例：新北清潔工全身無力，原以為中風，結果是鳥糞感染。
- 診斷：**India ink（墨汁）負染色 → 莢膜呈亮暈**；**birdseed（Niger seed）agar**：代謝鳥種子成分 → **產生黑色素**（phenoloxidase，國考題）；nitrate 同化 (−)。
- 治療：**amphotericin B（+ fluconazole／5-FC）**，數週到數月。
- 111 考古陷阱：「常引發伺機性肺炎」判為錯，重點是**腦膜炎**。

### ③ 卡氏肺囊蟲肺炎（_Pneumocystis jirovecii_ pneumonia, PCP）⭐

- 早期因**絕對寄生**被當成寄生蟲；**rRNA 定序像酵母（_Saccharomyces_）→ 子囊菌門**。
- **AIDS 末期最常見的伺機感染（70–80%）**；飛沫 → 肺泡 → 泡沫狀滲出物；無法培養、細胞壁弱。
- **⭐ 沒有 ergosterol → 不能用 amphotericin B**；治療 **TMP-SMX（co-trimoxazole）、pentamidine**。

### ④ 麴菌病（aspergillosis）

- **子囊菌門**；***A. fumigatus*（煙麴菌）**是致病主角。紅麴健康、**黃麴（_A. flavus_）產 aflatoxin（致癌）**、**黑麴**是環境最常見的（柚子皮上根根分明）。
- 型態：**有隔菌絲、約 45° 分枝**（國考題；老師覺得「考這個很無聊」）、**分生孢子**。名稱來自聖水器 aspergillum。
- 吸入孢子雲 → 免疫低下者在肺形成 **fungus ball（aspergilloma）**：比肺癌死得更快（病例一週就死），因為病人本來就免疫低下，孢子早已全身跑透透；侵襲性可播散到腦、心、皮膚。
- 治療：手術移除 + **echinocandin（國考題，標的是 cell wall，副作用小，臨床治療侵襲性麴菌症）**；不行再用 amphotericin B 或 azole（voriconazole）。

### ⑤ 接合菌病／毛黴菌病（zygomycosis／mucormycosis）

- 不是單一菌，是**整個接合菌（毛黴）門**造成的病：_Rhizopus_、_Mucor_、_Absidia_。
- **無隔、寬、帶狀的大菌絲**（PAS），會**侵犯血管**；無性 sporangiospore、有性 zygospore。
- 傷口 → 傷口發炎；吃進去 → 腸胃型（營養不良兒童）；leukemia → 肺型。
- **⭐ 鼻腦型毛黴菌病（rhinocerebral）**：從鼻咽吸入 → 侵入血管 → 臉、眼、腦；好發於**糖尿病（酮酸中毒 → pH 下降）**。
- 治療：**手術清創 + amphotericin B**（高劑量）。

### 其他 outbreak（~~不考~~，老師說看看就好）

- **2012 年美國類固醇注射液汙染 → 黴菌性腦膜炎**（_Exserohilum rostratum_；600+ 人生病、39 人死亡）：類固醇抑制免疫（自體免疫、移植病人），雪上加霜。

# 考點分析

## 🔥 高頻考點（68 題，含 111 期中 5 題）

1. **細胞壁成分 chitin + β-1,3-glucan**（出 4 次，選項常換成 α、1-4、peptidoglycan）。
2. **Cryptococcus**（出 10+ 次）：鴿糞、腦膜炎、India ink、厚莢膜、Basidiomycetes、吸入、無假菌絲。
3. **Sporothrix 情境題**（刺傷 + rosette + 37°C yeast + 淋巴排列）。
4. **Zygomycota = coenocytic → sporangiospore**；Chlamydospore = thallic、菌絲本身壁增厚。
5. **抗真菌藥機制**（azole ↔ 14-α-demethylase；echinocandin ↔ glucan；amphotericin ↔ membrane）。
6. **Dimorphism** 定義與哪些菌是。
7. **Candida**：germ tube（serum）、非典型 dimorphic、指甲情境題（terbinafine）。
8. **Penicillium marneffei**：東南亞 AIDS。

## ⚠️ 陷阱

- 真菌膜「不含固醇」→ 錯（含 ergosterol）。
- 真菌最適溫度 37°C → 錯。
- 「Mold form 沒能力感染人類」→ 錯。
- 子囊菌無性世代產生「孢子囊孢子」→ 錯（是 conidia）。
- 新型隱球菌「常引發伺機性肺炎」→ 111 考古判為錯（重點是腦膜炎）。
