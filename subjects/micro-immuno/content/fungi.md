# 真菌構造與黴菌病（依考古詳解整理，鍾筱菁）

> 113 共筆沒有收錄本章，以下整理自考古詳解。**這章去年考古題數最多（63 題）**，有不少看圖題（本站未收錄圖片題）。

## 1. 真菌定義與構造
- **真核**、無葉綠素（異營）、單細胞（yeast）或多細胞（mold）。
- **細胞壁：chitin（β-1,4 NAG）+ β-1,3-glucan（主鏈）/ β-1,6-glucan（側鏈）**、mannan、glycoprotein；**沒有 peptidoglycan、沒有 LPS**。
- **細胞膜：ergosterol**（取代 cholesterol）→ 抗真菌藥標的；細菌膜則無固醇。
- 最適 pH **4–6**（偏酸）；多數最適溫度 **25–30°C**（不是 37°C）。
- 基本細胞型：**yeast 與 hyphae**。
  - Hyphae：**septate**（有隔：Asco、Basidio、Deutero）vs **coenocytic**（無隔：**Zygomycota**）；菌絲集合 = mycelium。
  - Pseudohyphae：出芽未分離（*Candida*）。
  - Filamentous fungus = 會產生菌絲者（mold、蕈）。
- **Dimorphism**：隨環境（主要**溫度**）改變型態：**25°C mold / 37°C yeast** → 多為**全身性或皮下感染**真菌（*Histoplasma*、*Blastomyces*、*Coccidioides*、*Paracoccidioides*、*Penicillium (Talaromyces) marneffei*、**Sporothrix schenckii**）。
  - *Candida albicans*：yeast、pseudohyphae、hyphae 在 37°C 同時存在 → 一般**不視為典型 dimorphic**。
  - *Cryptococcus*：yeast（不算 dimorphic）。

## 2. 生活史與分類
- **Anamorph = 無性世代**；teleomorph = 有性世代。
- Amastigomycota（無鞭毛菌門）= **true fungi**；slime molds 最先被分出。

| 門 | 菌絲 | 無性孢子 | 有性構造 |
|---|---|---|---|
| **Zygomycotina** | **Coenocytic（無隔）**、rhizoids | **Sporangiospore**（孢子囊，columella） | Zygospore（接合孢子） |
| **Ascomycotina** | Septate、無 clamp | **Conidia / phialospore**（conidiophore、phialides） | **Ascus**（4、8、16 ascospores） |
| **Basidiomycotina** | Septate、**clamp connection** | 少量 conidia、budding | Basidiospore（basidium） |
| Deuteromycotina | Septate | conidia | **未發現**有性世代 |

- ***Cryptococcus neoformans* 是 Basidiomycetes 中唯一的致病酵母**；*Aspergillus* 不屬於擔子菌。

### 無性孢子
| 類型 | 孢子 |
|---|---|
| **Blastic（投射型 / ballistic）** | **Blastospore**（出芽）、**Phialospore / conidia**（瓶梗頂端）、**Sporangiospore**（囊內） |
| **Thallic（體細胞型）** | **Arthrospore**（菌絲斷裂；*Coccidioides*）、**Chlamydospore**（**菌絲本身、細胞壁增厚**） |

- **最常見的無性孢子 = conidia（分生孢子）**。
- 皮癬菌大孢子：*Trichophyton* 臘腸狀、***Microsporum* 梭狀**、***Epidermophyton* 棒狀**。

## 3. 染色與診斷
- **PAS**（periodic acid-Schiff）：組織切片中真菌呈紫紅；染**醣類**（chitin 不呈色）。
- **India ink（負染）**：*Cryptococcus* 厚莢膜呈亮暈。
- **KOH**：皮屑、指甲。
- **Germ tube test（serum）**：*C. albicans* 唯一會長 germ tube。
- Sabouraud agar；CHROMagar（*C. albicans* 綠色）。

## 4. 重要致病真菌
| 分類 | 菌 | 重點 |
|---|---|---|
| 淺部 / 皮膚 | **Dermatophytes（mold）**：*Trichophyton*、*Microsporum*、*Epidermophyton* | 香港腳、灰指甲、頭癬 |
| 皮下 | ***Sporothrix schenckii*** | **刺傷**（玫瑰、樹枝）；25°C **rosette（雛菊狀）conidia**、37°C **cigar-shaped yeast**；**lymphocutaneous sporotrichosis**（沿淋巴管直線排列潰瘍、結節） |
| 全身性（primary / true pathogen，健康人也會；dimorphic；吸入） | *Histoplasma*（北美、密西西比）、*Blastomyces*、*Coccidioides*（arthroconidia）、***Paracoccidioides***、***Penicillium marneffei***（**東南亞、中國南方、AIDS**） | 多為輕微肺部感染；特定地區流行 |
| 伺機性 | ***Candida albicans***（正常菌相）、***Cryptococcus***、***Aspergillus***、**Zygomycosis**（Mucor、Rhizopus）、*Pneumocystis* | 免疫低下 |

- ***Candida albicans***：budding yeast、creamy smooth colony、pseudohyphae、germ tube、chlamydospore；**鵝口瘡、陰道炎、尿布疹、甲溝炎 / 指甲、食道炎（AIDS）、菌血症（candidemia，死亡率 40–60%）**、腦膜炎；不造成溼疹、產毒性感染。
- ***Cryptococcus neoformans***：**鴿糞**、**吸入**（非腸胃道）→ 肺 → **腦膜炎**（最易侵犯腦的真菌）；**厚莢膜（主要致病物）**、無假菌絲、不形成 chlamydospore；India ink；治療 **amphotericin B + fluconazole**（± flucytosine）。
- ***Aspergillus***：septate、分生孢子；aspergilloma、侵襲性麴菌症；*A. flavus* → aflatoxin（致癌）。
- **Zygomycosis**：**寬、帶狀、無隔菌絲**（PAS），侵犯血管。
- **AIDS 最常見伺機真菌**：*Pneumocystis* 肺炎（PCP）。
- 真菌毒素（mycotoxicosis）：地區性、季節性、**不具傳染性**；致癌、過敏、慢性中毒。

## 5. 抗真菌藥
| 藥 | 機制 |
|---|---|
| **Polyenes（Amphotericin B、Nystatin）** | 結合 **ergosterol → 膜上打孔** |
| **Azoles（imidazoles：ketoconazole；triazoles：fluconazole）** | 抑制 **14-α-lanosterol demethylase**（ergosterol 合成） |
| **Allylamines（terbinafine）、butenafine** | 抑制 **squalene epoxidase**（ergosterol 合成） |
| **Echinocandins（caspofungin）** | 抑制 **β-1,3-glucan synthase**（細胞壁）→ **與 ergosterol 無關** |
| **Flucytosine（5-FC）** | 抑制 DNA / RNA 合成 |

- 真菌感染上升原因：抗藥性、免疫抑制劑、AIDS（**不是菌種明顯增加**）。

## 抗真菌藥物
| 類別 | slides 重點 |
|---|---|
| I. 作用在細胞膜 | **Allylamines**（terbinafine，抑制 squalene epoxidase）；**Azoles**（抑制 14-α-demethylase → ergosterol 合成）；**Polyenes**（amphotericin B、nystatin：**直接結合膜上 sterol** → 打洞；**毒性高、劑量相關副作用**，**靜脈注射用於致命的全身性感染**） |
| II. 作用在細胞壁 | **Echinocandins**：抑制 **β-1,3-D-glucan** 合成 |
| III. 抑制細胞分裂 | **Griseofulvin**：破壞**有絲分裂紡錘體 → 停在 metaphase**；累積在**角質層** → **皮癬菌（頭癬、甲癬）二線用藥** |
| IV. 抑制核酸合成 | **5-flucytosine（5-FC）**：cytosine 類似物，經真菌膜上 **cytosine permease** 進入 → 5-FU → 5-F-UMP → 抑制 RNA（與可能的 DNA）；**與 amphotericin B 協同**治療全身性致命黴菌病；窄譜：*Candida albicans*、*Cryptococcus*、*Aspergillus*、*Blastomyces* |
| 治療原則 | **全身性、致命感染才用全身性藥物**；*Candida krusei* **天生抗 fluconazole** |

## 黴菌病分類
| 層次 | 代表 |
|---|---|
| **Superficial（淺表）** | **汗斑 tinea versicolor**：***Malassezia furfur***（擔子菌、**需要油脂**、幾乎 100% 人帶菌；干擾黑色素 → 脫色斑；也造成毛囊炎、脂漏性皮膚炎、頭皮屑，導管相關敗血症）→ ketoconazole（仁山利舒）；**白色毛幹結節 white piedra：*Trichosporon beigelii***；**黑色毛幹結節 black piedra：*Piedraia hortae*** |
| **Cutaneous（皮膚）** | **皮癬菌 dermatophytes（Tinea、ringworm）**：「**愛角蛋白**」，侵犯毛髮、指甲、角質層；*Trichophyton*、*Microsporum*、*Epidermophyton*；頭癬、鬚癬、股癬、**足癬（香港腳）**、**甲癬（灰指甲）**；孢子耐性強；人、動物、土壤為 reservoir；潛伏期長；**不致命但很不舒服**；**Wood's lamp（UV）**協助診斷 |
| **Subcutaneous（皮下）** | **Sporotrichosis（*Sporothrix schenckii*，dimorphic）**：**玫瑰園丁病**，土壤 → 手部小潰瘍 → **沿淋巴管結節** → 肺（未治療）；很少致命；KI 或 itraconazole。**Chromoblastomycosis**（*Fonsecaea pedrosoi* 等，**暗色**）：**赤腳農夫**，疣狀斑塊，多年進展。**Phaeohyphomycosis**（棕色菌絲，*Alternaria*、*Exophiala* 等）：高度免疫低下者，皮膚 → 囊腫 → 骨、腦、肺。**Mycetoma（Madura foot）**：真菌（*Pseudallescheria*、*Madurella*）或細菌（actinomycetes），**黑色顆粒**、侵犯肌肉骨骼，極難治 |
| **Systemic（全身性）— 真病原** | **地方性**；**吸入土壤中的 conidia → 肺**，多數無症狀或輕微；**都是 dimorphic**；少數全身化；感染後**長期免疫**（對真菌抗原的過敏反應） |
| **Opportunistic（伺機性）** | *Candida*、*Cryptococcus*、*Pneumocystis*、*Aspergillus*、Mucorales 等 |

## 全身性真病原（dimorphic）
| 菌 | slides 重點 |
|---|---|
| ***Histoplasma capsulatum***（**Ohio Valley fever**） | 除澳洲外各洲；**鳥糞、蝙蝠糞**；高盛行區 80–90% 在 20 歲前感染過 → **單純抗體陽性不代表疾病，要看抗體上升**；**寄生在巨噬細胞內**；**fish-eye yeast**；amphotericin B、手術 |
| ***Coccidioides immitis***（**Valley fever**） | **所有黴菌中毒力最強**，一個孢子就能感染；美國西南；農作、考古挖掘、山崩、沙塵暴；**25 °C 土壤：thick-walled arthroconidia；37–40 °C 肺：spherule（巨大孢子囊含大量 endospores）**；60% 無症狀、40% 類感冒；fungoma、肺空洞 |
| ***Blastomyces dermatitidis***（北美芽生菌病、Chicago disease） | 菌絲期：細隔菌絲 + 卵圓 conidia；**酵母期：大、厚壁、寬基出芽**；10–100 個 conidia 即可感染；肺（咳嗽、胸痛、沙啞）→ **約 20% 擴散到皮膚**、骨、攝護腺、CNS；死亡約 5%；amphotericin B（播散）或 azole |
| ***Paracoccidioides brasiliensis***（南美芽生菌病） | 巴西；肺或皮膚、多自限；少數侵犯頭部黏膜與淋巴；**「船舵」狀多極出芽** |
| ***Talaromyces (Penicillium) marneffei*** | **HIV 感染者**；**泰國、中國南方** |

## 伺機性黴菌
| 菌 | slides 重點 |
|---|---|
| ***Candida***（albicans、glabrata、parapsilosis、tropicalis、krusei） | **出芽酵母 + pseudohyphae + 真菌絲**；約 20% 人帶 *C. albicans*；正常菌叢，宿主防禦下降（幼兒、懷孕、藥物、免疫缺陷、外傷）即致病；**約 70% 院內黴菌感染** |
| *Candida* 疾病 | **鵝口瘡 thrush**（新生兒、虛弱老人；白色附著斑塊）；**外陰陰道念珠菌病**（糖尿病、懷孕、口服抗生素改變陰道菌相）；甲溝、皺褶處、皮膚；**食道念珠菌病：約 70% AIDS 病人**；**念珠菌血症：致死人數超過其他所有黴菌（40–60%）**，手術、骨髓移植、癌症、靜脈毒癮；UTI、心內膜、腦 |

| ***Cryptococcus neoformans***（擔子菌） | **莢膜**；**鴿子棲息處（鴿糞）**；**AIDS** 病人**嚴重腦膜炎**、常致命；也見於類固醇、糖尿病、癌症；吸入 → 肺結節 → 血 → 腦與腦膜（頭痛、意識改變、昏迷、癲癇）；**India ink 負染色**；**nitrate 同化 (−)**、**birdseed（Niger seed）agar 上產色素（phenoloxidase）**、螢光抗體；**amphotericin B + fluconazole**，數週到數月 |
| ***Pneumocystis jirovecii***（PCP） | **AIDS 最常見伺機感染（70–80%）**；曾以為是原蟲，**rRNA 像酵母（子囊菌）**；**缺 ergosterol、細胞壁弱、無法培養**；飛沫 → 肺泡 → **泡沫狀滲出物**；咳嗽、發燒、淺呼吸、發紺；**pentamidine、co-trimoxazole（TMP-SMX）** |
| ***Aspergillus***（子囊菌） | ***A. fumigatus*** 最常見；AIDS、白血病、免疫缺陷；吸入 conidia → **fungus ball** → 壞死性肺炎、播散到腦心皮膚；嚴重全身性預後差；PCR、血清學；手術切除 + **echinocandin、voriconazole 或 amphotericin** |
| **Mucormycosis（接合菌病）** | *Rhizopus*、*Mucor*、*Absidia*；土壤、水、腐物；白血病、營養不良、皮膚損傷、**未控制的糖尿病（酮酸中毒）**；**鼻腦型**（鼻腔 → 血 → 眼、腦）、肺型（白血病）、腸胃型（蛋白質營養不良兒童）；**非常大、厚壁、無隔（nonseptate）菌絲**；手術清創 + 高劑量 amphotericin B 或 voriconazole |
| 其他 | *Geotrichum candidum*（乳製品）；***Fusarium*：隱形眼鏡 → 黴菌性角膜炎（2006 爆發）**；**2012 美國汙染類固醇注射 → *Exserohilum rostratum* 黴菌性腦膜炎（39 死、600+ 病）** |

# 考點分析

## 🔥 高頻考點（68 題，含 111 期中 5 題）
1. **細胞壁成分 chitin + β-1,3-glucan**（出 4 次，選項常換成 α、1-4、peptidoglycan）。
2. **Cryptococcus**（出 10+ 次）：鴿糞、腦膜炎、India ink、厚莢膜、Basidiomycetes、吸入、無假菌絲。
3. **Sporothrix 情境題**（刺傷 + rosette + 37°C yeast + 淋巴排列）。
4. **Zygomycota = coenocytic → sporangiospore**；Chlamydospore = thallic、菌絲本身壁增厚。
5. **抗真菌藥機制**（azole ↔ 14-α-demethylase；echinocandin ↔ glucan；amphotericin ↔ membrane）。
6. **Dimorphism** 定義與哪些菌是。
7. **Candida**：germ tube（serum）、非典型 dimorphic、指甲情境題（terbinafine）。
8. **Penicillium marneffei**：東南亞 AIDS。

## ⚠️ 陷阱
- 真菌膜「不含固醇」→ 錯（含 ergosterol）。
- 真菌最適溫度 37°C → 錯。
- 「Mold form 沒能力感染人類」→ 錯。
- 子囊菌無性世代產生「孢子囊孢子」→ 錯（是 conidia）。
- 新型隱球菌「常引發伺機性肺炎」→ 111 考古判為錯（重點是腦膜炎）。
