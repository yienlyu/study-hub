## 菌名：形狀與排列

| 字根 | 意思 | 本科例字 |
|---|---|---|
| **-coccus**／cocci | 球菌 | Staphylococcus、Streptococcus、Enterococcus |
| bacillus／**-bacter** | 桿菌 | Bacillus、Campylobacter、Helicobacter |
| coccobacillus | 短桿（介於球、桿之間） | Haemophilus、Bordetella |
| diplo- | 成對 | diplococci：Neisseria、S. pneumoniae |
| strepto- | 扭成一串、鏈狀 | Streptococcus、streptolysin |
| staphylo- | 一串葡萄 | Staphylococcus |
| vibrio | 振動 → 彎曲、逗點狀 | Vibrio cholerae |

| coryne- | 棒子 | Corynebacterium diphtheriae |
| myco- | 真菌、蠟（像黴菌一樣長） | Mycobacterium、mycolic acid |
| -aceae | 「科」 | Enterobacteriaceae |
