# 滅菌、消毒與防腐

## 1. 三個定義（必考）
| | 定義 | 能否殺 **endospore** | 對象 |
|---|---|---|---|
| **Sterilization 滅菌** | 摧毀**所有**微生物（含孢子、mycobacteria、無套膜病毒、真菌） | ✅ | 物品 |
| **Disinfection 消毒** | 殺死 vegetative pathogens | ❌（high-level 例外，接近滅菌） | **無生命物品** |
| **Antisepsis 防腐** | 減少**皮膚（活組織）**上的微生物 | ❌ | 活組織 |

- Antiseptics 可當 disinfectants，但 disinfectants 不一定能當 antiseptics（對組織有毒）。
- 作用機制：蛋白變性、化學修飾蛋白/核酸（**alkylating / oxidizing**）、破壞細胞膜。

## 2. 物理方法

| 方法 | 條件 | 等級 / 用途 |
|---|---|---|
| Incineration | 火焰、電熱圈 | 滅菌 |
| **Hot-air oven（乾熱）** | 150–180°C；**160–170°C 60–90 min** | 滅菌；耐熱物品（玻璃、金屬、粉末） |
| **Autoclave（濕熱）** | **121°C、15 psi、10–40 min** | 滅菌；紗布、器械、培養基 |
| Flash sterilization | **134°C、3 min** | 滅菌 |
| Boiling | 100°C 30 min | 消毒（孢子存活） |
| **Pasteurization** | LTLT 63–66°C 30 min；HTST **71.6°C 15 s**；UHT **>135°C 2–5 s（滅菌牛奶）** | 消毒（牛奶） |
| **Ionizing radiation**（γ、X、cathode） | 穿透力強、打斷 DNA | **滅菌**：醫材、食品 |
| **UV（nonionizing）** | **pyrimidine dimer**；穿透力差、需直接照射；傷人 | 消毒 |
| Filtration | **0.22–0.45 μm**；HEPA | 化療藥物（滅菌）、BSC、手術室 |

- 濕熱注意：蒸氣要接觸物品表面、物品不怕熱/濕、**不能有空氣**；液體瓶要鬆蓋、冷到 80°C 再開。

## 3. 化學方法
- **Alkylating**：**Ethylene oxide（ETO）**（>10.8°C 為氣體、易爆 → 用 CO₂/N₂ 稀釋、低溫、可大量、需通氣時間）、**Aldehydes**（glutaraldehyde / formaldehyde，**cold sterilization**）。
- **Oxidizing**：O₃、**peracetic acid（產物無毒）**、**H₂O₂（10–25%、55–60°C）**、**Plasma gas**（ionized H₂O₂ / peracetic acid；取代 ETO；**塑膠植入物、隱形眼鏡、人工裝置**；貴）。
- **Supercritical CO₂**：兼具液體溶解力與氣體低表面張力；**45°C**、臨界點 **31.1°C、73.8 atm**；食品、醫療移植物（骨、肌腱）。
- **Glutaraldehyde**（sporicidal、high-level）：**鹼性 pH 較活化（2% + 0.3% NaHCO₃）**、會被有機物失活（先清洗）、活化後保存 **14 天**、用於**內視鏡**、呼吸治療器材；CIDEX-OPA（0.55% OPA）。

## 4. 消毒劑等級
| 等級 | 可殺 |
|---|---|
| High | G+、G−、**spores**、**M. tuberculosis** |
| Intermediate | **M. tuberculosis**、多數病毒與真菌，少數孢子 |
| Low | 多數細菌與真菌，**不能殺 MTB 與孢子** |

## 5. 常用消毒 / 防腐劑
- **Alcohol（70%，intermediate）**：溶解膜脂、凝固蛋白；**70% 比 95% 有效**；揮發快無殘留、易燃、被有機物失活。
- **Phenolics（low–intermediate）**：不易被有機物降解 → 粗消毒；殺病毒、孢子差。
- **Halogens**：氯（漂白水；自來水、泳池）、**Povidone-iodine**（穩定、對組織無毒、貴）。
- **Chlorhexidine（biguanide）**：一個氯 + 兩個 phenolic rings；低毒、快速、不深入組織；殺 G+ G− 但**不殺孢子**；0.2%（漱口抗牙菌斑）、0.4%（刷手）、2%（消毒）。
- Quaternary ammonium（cationic detergents）：破壞膜。

## 6. 滅菌監測
- Mechanical（溫度、壓力表）→ Chemical / process indicator（滅菌膠帶，**只證明有跑過流程**）→ **Biological indicator（唯一能證明滅菌）**：
  - *B. subtilis*：乾熱、ETO
  - *B. pumilus*：radiation
  - ***B. stearothermophilus*：濕熱（autoclave）**

## 🎙️ 上課錄影重點（黃姿雯，非同步遠距 25 分）
- 老師定調：課本只是小章節，「有個概念就好，不用記太細節」；**這部分考試大概 3 題**。殺菌作用機制「你不大需要記」。
- 選擇層級時要考慮對抗的病原體：一般病原用最低階消毒就夠；**prion、endospore** 抗性最高。
- **防腐劑一定是消毒劑，消毒劑不一定是防腐劑**（防腐用在活體，不能傷到組織）。
- 乾熱：接種環用酒精燈**燒紅**（醫院用電熱圈）；150–180 °C 乾烤玻璃製品。
- **濕熱「一定要記清楚」**：最常用 = **autoclave 121 °C、約 20 分鐘**（10–40 分鐘）；鍋內一定要放水，乾燒就變成乾熱法。Flash 法壓力溫度更高、時間更短。
- ⚠️ **Pasteurization 是消毒不是滅菌**：去除牛乳中人畜共通病原（*M. bovis*、*Brucella*），鮮乳保存期約 **10–14 天**；**UHT 才是滅菌 → 保久乳**（同樣是鮮乳做的），可保存**一年以上**。煮沸 100 °C 30 分鐘孢子可能還活著。
- **游離輻射（γ ray）= 滅菌**：打斷 dsDNA、斷點太多修不回來；用在**無菌包裝耗材（棉棒、紗布）**與**進口水果**保鮮。**UV = 消毒**：相鄰 pyrimidine 形成共價鍵 → 複製時突變；會傷人。
- 過濾：濾膜 **0.22–0.45 μm**（細菌約 1 μm）；不能高壓滅菌的配製藥品要用過濾；**HEPA** 用於開刀房、**隔離病房**（如 COVID-19）、生物安全操作櫃 → 也防止病原體跑出去。
- **EO（環氧乙烷）**：氣體、溫度不用高、一次可大量；易爆需惰性氣體稀釋；滅完**不可馬上拿出**，要等活性降下來。
- **Glutaraldehyde / OPA**：市售已配好（鹼性）；泡完**一定要清水沖乾淨**；開封後效期 **14 天**；用於**內視鏡**、呼吸器相關器材。
- 氧化劑：臭氧、過醋酸毒性低；H₂O₂ 10–25%、50–60 °C 可達滅菌；**隱形眼鏡消毒液**是低濃度雙氧水。**電漿**（H₂O₂ 或過醋酸）效果好但設備貴，可處理多種手術器械。**超臨界 CO₂** 約 45 °C、保持生物活性 → **移植物**滅菌（不能加熱也不能泡藥）。
- **70% 酒精比 100% 有效**：其中的水分子兼具親水 / 疏水性，幫助酒精浸潤細菌表面、破壞膜。
- 自來水、泳池加**低濃度氯**；**PI（povidone-iodine）**含碘、對人傷害小，臨床常與 chlorhexidine 交替使用。
- **Chlorhexidine「這個你要記得」**：醫院一定常聽到的防腐劑，殺 G+ 與 G−、孢子較差；依用途調濃度（擦拭 vs 刷手）；感染控制會**幫病人全身擦 chlorhexidine** 降低被抗藥菌感染的機會。
- 四級銨（如市售「沒有氯味的漂白水」）= 破壞表面膜的清潔劑。
- 監測：機械性（溫度、壓力、水量）→ **滅菌膠帶**（白線變黑只代表「有處理過」）→ **生物指示劑（放入孢子一起滅菌再培養）才能證明真的滅菌**；醫院多為**每月**定期做一次。

# 考點分析

## 🔥 高頻考點
1. **情境選方法**：
   - 醫院紗布 → **高壓蒸氣滅菌（autoclave）**
   - 牛奶 → **巴斯德消毒法**
   - 不耐熱醫材（塑膠植入物、隱形眼鏡），不留毒性 → **gamma radiation**（111 考古答案）／plasma gas 也常見
   - 炭疽桿菌污染的皮毛 → **UV 不行**（穿透差），γ、ETO、glutaraldehyde、plasma 可以
2. **Autoclave 條件 121°C**（「100°C 15 分鐘」是錯的）。
3. **70% 酒精比 95% 有效**。
4. **Supercritical CO₂ 條件**：>73.8 atm、45°C（考過數字選擇題）。
5. **Biguanide = Chlorhexidine**（hexachlorophene、triclosan 是 phenolics）。

## ⚠️ 陷阱
- UV：需直接照射、會傷人 → 屬消毒不是滅菌。
- Chemical indicator 不能證明滅菌成功。
- Glutaraldehyde 在「鹼性」才活化（不是酸性）。

## 📝 出題模式
- 幾乎都是情境應用題（「最適合的方法是？」），偶有數字題。今年 slides 新增 biological indicator 三種菌、chlorhexidine 濃度 → 可能出配對題。
