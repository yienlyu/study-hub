# 小 RNA 病毒與冠狀病毒 內容整理（依百十三共筆整理，林良宗）

> 📑 依 2026 講義「[講義] PicornaV & CoV」（54 頁）與百十三共筆 W9-2 整理。I'm@TMU 已有「[影音] PicornaV & CoV」錄影，但還沒有逐字稿；百十四共筆也還沒上傳。

## 1. RNA 病毒先放對位置

| | Picornaviridae | Coronaviridae |
|---|---|---|
| 名稱 | pico = small + RNA | 電顯下 S 蛋白排成皇冠（corona） |
| 大小 | **20–30 nm**（很小） | **80–160 nm**，**最大的 RNA 病毒** |
| 套膜 | **無**（乙醚、有機溶劑、**酒精無效**） | **有** |
| 衣殼 | 二十面體 | **螺旋狀**核衣殼 |
| 基因體 | (+) ssRNA，7–8.8 kb | 不分段 (+) ssRNA，**27–30 kb** |
| 釋出 | **細胞溶解（lysis），不是出芽** | 含病毒的囊泡與細胞膜融合（exocytosis） |

## 2. Picornavirus 的基因體與複製 ⭐⭐

- 裸露的 (+) ssRNA **本身就有感染力**（可以直接當 mRNA 轉譯）。
- 基因體分 **structural**（衣殼蛋白）與 **non-structural**（幫病毒控制宿主、複製）兩段；先轉譯成一條 **polyprotein**，再由病毒 **protease 切割**成各個蛋白。
- 複製週期：結合受體 → **receptor-mediated endocytosis** → 脫殼、移除 **VPg**（與基因體相連的蛋白）→ 轉譯 polyprotein → 由 viral RNA polymerase 複製出全長 (−) ssRNA → 再做出大量 (+) ssRNA → 後期 (+) RNA 進入組裝 → **lysis 釋出**。
- 多數 picornavirus 會**抑制宿主 RNA 與蛋白合成**，造成 CPE。

## 3. Picornaviridae 分類 ⭐⭐

- 五個屬：**Enterovirus、Rhinovirus、Hepatovirus、Aphthovirus、Cardiovirus**。
- 會感染人的重要成員：
  - **Enterovirus**：**Poliovirus 1–3 型**（原型）、**Coxsackie A**（1–22、24）、**Coxsackie B**（1–6）、**Echovirus**（enteric cytopathic human orphan）、**Enterovirus 68–71**。
  - **Hepatovirus**：**HAV**（= enterovirus 72 型）。
  - **Rhinovirus**：100 多型。

### HAV vs Enterovirus

| HAV 的不同點 |
|---|
| 很難在細胞培養中生長、複製慢、**沒有 CPE** |
| 對溫度、酸、熱與環境**更有抵抗力** |
| 與抗 enterovirus 抗體**沒有交叉反應** |
| 有**肝細胞嗜性** |
| 相對**不溶解細胞**，感染較持久 |

### Rhinovirus vs Enterovirus ⭐⭐⭐

| | Enterovirus | Rhinovirus |
|---|---|---|
| 感染部位 | 主要是腸道 | 鼻、喉 |
| pH 3 | **耐酸**（pH 3–5，可通過胃酸） | **不耐酸（acid-labile）** |
| 最適溫度 | **37 °C** | **33 °C** |
| 傳播 | 糞口 | 呼吸道飛沫、手與污染物 |

## 4. Poliovirus（小兒麻痺病毒）⭐⭐⭐

- **流行病學**：主要影響 **5 歲以下兒童**；全球盛行率下降 **> 99%**（社經改善與疫苗）；**糞口傳染**，主要來源是含病毒的糞便。
  - 已認證無小兒麻痺：美洲、歐洲、東南亞、西太平洋；**80%** 的人住在無小兒麻痺地區。
  - 仍流行：**阿富汗、奈及利亞、巴基斯坦**。
  - 根除進度：**野生型第 2 型 1999 年根除**；第 3 型接近根除（2013 年後沒有新病例）；**第 1 型仍在流行**。2011 年中國新疆南部出現境外移入的野生型（中國已十年無病例）。GPEI 目標：2014 年前中斷傳播、2018 年前認證全球無小兒麻痺。
- **致病**：只感染**靈長類**；組織嗜性 = **腸胃道、口咽、CNS**。
  - **無症狀 90%**（侷限在口咽與腸道）
  - **Abortive poliomyelitis**（nonparalytic）：類流感
  - **Paralytic polio 約 1%**：多數流行由 **type 1** 造成
  - **Post-polio syndrome**：感染多年後才出現
- 路徑：口咽或小腸感染 → 淋巴期 → **viremia** → 嚴重時進 CNS 攻擊 **motor neuron**（cytolytic）→ 肌無力、癱瘓。恢復期存活的運動神經長出新分支（sprout）重新接上肌肉；**post-polio syndrome** = 新分支因過度負荷（overexertion）退化，機制不完全清楚。
- Bulbar poliomyelitis 影響呼吸 → 20 世紀前半用**鐵肺（iron lung）**。
- **診斷**：**病毒分離**（糞便、喉頭拭子，**最敏感**）；RT-PCR 做型內分型；血清學：急性期與恢復期（> 3 週）抗體效價 **4 倍上升**，輔助診斷麻痺型（特別是未接種者）。
- **治療**：**沒有抗病毒藥**，靠疫苗：

| 疫苗 | 種類 | 途徑 |
|---|---|---|
| **Salk（IPV）** | 不活化 | 肌肉／皮下注射 |
| **Sabin（OPV）** | 減毒活疫苗 | **口服** |

  支持療法：臥床、止痛、可攜式呼吸器、物理治療防變形。

## 5. Enterovirus（腸病毒）⭐⭐⭐

- 多為 **cytolytic**；**組織嗜性與溶細胞能力決定疾病**。同一血清型可造成不同疾病、不同血清型可造成同一疾病（看影響哪個組織）。
- 通常無症狀，症狀從類感冒到麻痺都有；**糞口傳播，但很少造成腸胃疾病**。
- **免疫：抗體是主要保護**——**sIgA** 擋住口咽、腸胃道的感染，**血清 IgG** 阻止病毒血症擴散到目標組織；**細胞免疫通常不參與**。
- 台灣：**1998 年夏天 EV71 大流行，70 多名兒童死亡**（無菌性腦膜炎、胸膜痛、麻痺、心肌與心包膜感染）。
  - 神經併發症：**Poliovirus、EV71**；最容易造成嚴重併發症：**Poliovirus、CVB、Echovirus、EV71**。
  - 台灣多數病例是 **Coxsackie A**。

### 臨床症候群（台灣 CDC 表）⭐⭐⭐

| 疾病 | 重點 | 病毒 |
|---|---|---|
| **疱疹性咽峽炎（Herpangina）** | 突發發燒、咽峽部小水泡或潰瘍，4–6 天 | **CVA**1–10、16、22、EV71 |
| **手足口病（HFMD）** | 口腔、手掌、腳掌、臀部紅疹與小水泡，7–10 天，常因口腔潰瘍無法進食 | **CVA16**、A4–A10、B2、B5、**EV71** |
| **流行性肌肋痛（Pleurodynia）** | 胸部突發陣痛 | **CVB** |
| **嬰兒心肌炎、成人心包膜炎** | 呼吸困難、心跳過速，可快速心衰竭 | **CVB** |
| 急性淋巴結性咽炎 | 懸雍垂與後咽壁白色病灶 | CVA10 |
| 無菌性腦膜炎、腦炎 | 發燒、頸部僵硬 | Coxsackie、Polio、Echo、EV71 |
| 發燒合併皮疹 | 斑丘疹 | Coxsackie、Echo |
| **急性出血性結膜炎** | 眼睛發紅出血，一眼先發再擴到另一眼 | **EV70、CVA24** |

- **口蹄疫（FMD）≠ 手足口病**：FMD 是 **Aphthovirus** 造成的**偶蹄動物**（牛、羊、豬、鹿）疾病；高傳染、耐熱、耐清潔劑，但**不耐酸**（像 rhinovirus）。是人畜共通病，但很難跨物種、對人影響小。手足口病是 EV71、CVA16／B5。
- **治療與預防**：沒有專一抗病毒藥；polio 有 Salk、Sabin；**Coxsackie、Echo 等沒有全球核准疫苗**。**酒精無效**，要濕洗手；避免接觸與群聚；**漂白水 500 ppm 清潔、1000 ppm 消毒污染物**。

## 6. Rhinovirus（鼻病毒）⭐⭐

- 和其他 picornavirus 不同：**較不耐酸、較耐熱**。
- 全球分布、**秋冬**多；嬰幼兒常感冒，成人因累積免疫而減少。傳播：吸入飛沫、手或污染物接觸。
- 只感染**人與黑猩猩**；**普通感冒與上呼吸道感染最重要的原因**（coronavirus、enterovirus、adenovirus、parainfluenza 也會造成感冒症狀）。
- 診斷靠臨床，實驗室診斷**不必要**（要做就從鼻腔沖洗液分離）。
- **治療**：症狀治療，self-limited。**沒有疫苗**：血清型太多（**100 多型、幾乎沒有交叉保護**）、需要 **sIgA**、效益風險比不划算。洗手與消毒是最好的預防。
- **受體：80% 的 rhinovirus 共用 ICAM-1（CD54）**。病毒表面有峽谷（canyon），與受體作用的 **pocket** 在谷底，抗體不容易進去。
- 藥物開發：
  - **Pleconaril**：嵌入 VP1、穩定衣殼，**阻斷 attachment 與 uncoating**，廣效抗 enterovirus 與 rhinovirus（含 EV71）。
  - **Enviroxime**：抗 enterovirus／rhinovirus 的 RNA polymerase 抑制劑。
  - **AG-7404**：抗 poliovirus 的 protease 抑制劑。

## 7. Coronavirus 基本病毒學 ⭐⭐

- 結構蛋白：**N**（nucleocapsid）、**M**（membrane glycoprotein）、**E**（envelope）、**S**（spike，**病毒附著蛋白、中和抗體的目標**）。
- 複製：S 蛋白結合受體 → **膜融合或胞吞**進入 → (+) RNA 轉譯成 polyprotein，切出 RdRp → 做出全長 (−) 模板 → 由 subgenomic (−) 模板合成 **subgenomic mRNA** → 轉譯結構蛋白（S 表現在細胞表面，可與鄰近未感染細胞融合）→ **在囊泡內組裝**，囊泡與細胞膜融合釋出。
- 致病：**普通感冒的第二大原因**（流鼻水、喉嚨痛、低燒，self-limited）；感染上呼吸道上皮，**33–35 °C 複製最好**、感染侷限；醣蛋白「corona」幫助病毒通過腸胃道；SARS 因**細胞激素風暴**惡化；糞便中看得到病毒但與腸胃炎的關係未證實。
- 會感染人的冠狀病毒：**229E、OC43、SARS-CoV（2003）、MERS-CoV（2012）、SARS-CoV-2（2019）**。

## 8. SARS、MERS、COVID-19 比較 ⭐⭐⭐

| | SARS-CoV | MERS-CoV | SARS-CoV-2 |
|---|---|---|---|
| 首發 | **2002 年 11 月中國廣東** | **2012 年 9 月**（中東） | **2019 年 12 月中國武漢** |
| 動物來源 | **中華菊頭蝠**（果子狸等 732 隻動物都沒找到） | **單峰駱駝**（主要動物宿主） | 與 SARS-like **蝙蝠**病毒親緣相近 |
| 致死率 | 約 **9%** | 約 **35%** | 約 **3%**（老人、共病較高） |
| 傳播 | 人傳人；早期**大量醫護院內感染** | 接觸駱駝；人傳人 | 飛沫、密切接觸、可能糞口；**症狀前與無症狀傳播** |
| 受體／致病 | 呼吸道黏膜細胞；**50% 無症狀**；免疫短暫、可再感染 | 發燒、咳嗽、喘；肺炎常見但不一定；有腸胃症狀；鼻液與糞便可分離 | **ACE2**（呼吸道、肺，也在心、腸）；嗅味覺喪失、淋巴球減少、肺炎；重症 ARDS、多重器官衰竭；變異株、再感染 |
| 診斷 | 抗體、PCR | 活動感染 **rRT-PCR**；過去感染 **ELISA 篩檢 + IFA、microneutralization 兩項確認** | RT-PCR、抗原、血清學 |
| 治療 | 無藥無疫苗；ribavirin + 類固醇效果不確定；**溫度計是控制 SARS 最重要的工具** | 無藥無疫苗，支持療法 | **有疫苗**（降低重症與死亡）；支持療法、實驗性抗病毒藥、免疫調節（dexamethasone、IFN-1b）、恢復期血漿 |

- SARS 疫苗開發：編碼 S 蛋白的單一質體 **DNA 疫苗**。2004 年後沒有新病例。
- **SARS 的教訓**：一國的傳染病是全世界的威脅；**航空旅行**在國際傳播很重要；WHO 促成國際合作；機場熱像儀。
- 控制原則（SARS、COVID 都適用）：**快速發現病例、立即隔離、接觸者追蹤**。

# 考點分析

## 📝 高頻考點

- **Picornavirus 無套膜 → 酒精無效、lysis 釋出**；coronavirus 有套膜、最大 RNA 病毒。
- **Rhinovirus vs enterovirus**：耐酸與否、33 vs 37 °C、傳播途徑。
- **Rhinovirus 受體 ICAM-1**、Pleconaril 作用點（VP1，擋 attachment／uncoating）。
- **Polio**：90% 無症狀、1% 麻痺、type 1 造成多數流行、type 2 已根除；**Salk = IPV 注射、Sabin = OPV 口服**；病毒分離最敏感。
- **腸病毒症候群配對**：HFMD（EV71、CVA16）、herpangina（CVA）、pleurodynia 與心肌炎（CVB）、出血性結膜炎（EV70、CVA24）。
- 腸病毒的保護性免疫是**抗體（sIgA、IgG）**，不是細胞免疫。
- **SARS／MERS／COVID 三欄比較**：年份、地點、動物宿主（菊頭蝠／單峰駱駝／蝙蝠）、致死率（9%／35%／3%）、受體 ACE2。

## ⚠️ 易混點

| 容易選錯 | 正確 |
|---|---|
| ✗ 酒精可殺腸病毒 | ✓ **無套膜，酒精無效**；用漂白水 |
| ✗ Rhinovirus 耐酸、37 °C 長最好 | ✓ Rhinovirus **不耐酸、33 °C**；耐酸、37 °C 的是 enterovirus |
| ✗ 口蹄疫 = 手足口病 | ✓ 口蹄疫是 **Aphthovirus**、偶蹄動物；手足口病是 **EV71、CVA16** |
| ✗ Picornavirus 以出芽釋出 | ✓ **細胞溶解**釋出 |
| ✗ MERS 的動物宿主是蝙蝠 | ✓ 主要宿主是**單峰駱駝**（蝙蝠也有可能） |
| ✗ Sabin 是不活化疫苗 | ✓ **Sabin = 減毒口服**；**Salk = 不活化注射** |
