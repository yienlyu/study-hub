# 細菌簡介、分類、構造與代謝

## 1. 微生物學史（必背人物配對）

| 人物                   | 年代      | 貢獻                                                                   |
| ---------------------- | --------- | ---------------------------------------------------------------------- |
| Antony van Leeuwenhoek | 1632–1723 | 單透鏡顯微鏡，**第一個觀察並描述微生物**（animalcules）                |
| Louis Pasteur          | 1822–1895 | 鵝頸瓶實驗**推翻自然發生說**、**Pasteurization**（食物保存）           |
| Ignaz Semmelweis       | 1840s     | **洗手**降低產褥熱                                                     |
| Joseph Lister          | 1860s     | 以 **phenol** 做手術消毒（antiseptic surgery）                         |
| Robert Koch            | 1870s     | **Koch's postulates**：證明特定微生物造成特定疾病（炭疽桿菌 × 炭疽病） |
| Paul Ehrlich           | 1910s     | **化學療法**：Salvarsan 606 治梅毒，「magic bullet」                   |
| Alexander Fleming      | 1928      | 發現 **Penicillin**                                                    |
| Gerhard Domagk         | 1935      | Sulfanilamide（磺胺）                                                  |
| Selman Waksman         | 1943      | Streptomycin（治 TB）                                                  |
| John Enders            | 1946/1954 | 首次培養病毒（小兒麻痺病毒）→ 疫苗之父                                 |

**Koch's postulates**：① 病原體存在於患病者、不在健康者 ② 可分離並純培養 ③ 接種健康宿主可重現疾病 ④ 可從新宿主再分離出同一病原體。
例外：無症狀帶原者、無法培養的病原體（e.g. 部分）、只感染特定物種、一病原多症狀。

> Koch 假說 = 「一菌一病」；新觀念 = **Dysbiosis**：疾病由整個菌落（community）失衡造成。

## 2. 抗藥性與人體微生物相

- **抗藥性**：每個國家都有、源自抗生素濫用；細菌、真菌、病毒、寄生蟲都會出現；**MDR = superbugs**。對策：監測、新抗生素、噬菌體等新療法、疫苗。
- 新型抗生素例：**Zosurabalpin**（針對 _Acinetobacter baumannii_，抑制 LPS 運送到外膜）。
- **Human Microbiome Project**：細菌數約為人體細胞 3 倍（新估計約 1:1），基因數 > 100 倍。
  - 同一個人**不同部位**組成不同；**不同人**同一部位組成也差很多。
  - ⭐ **taxonomic diversity 大，但 functional properties 高度保守（functional redundancy）**。
  - Core microbiome：≥95% 個體共有的菌種；共有菌種數：**口 > 鼻 > 腸 > 皮膚 > 陰道**。
- Dysbiosis 相關：_C. difficile_ 腸炎（抗生素後、20–60% 復發）→ **FMT 糞便微菌叢植入**（台灣 2018 特管辦法開放）；肥胖、糖尿病、IBD、憂鬱等。
- Prebiotics（膳食纖維）／Probiotics（Bifidobacterium、Lactobacillus、次世代：_Akkermansia muciniphila_）／Postbiotics（代謝物，如 SCFAs）。

## 3. 分類與命名

- 三域：Bacteria、Archaea（無 peptidoglycan 細胞壁、極端環境）、Eucarya。
- 大小：Algae > Protozoa > Fungi > Bacteria > Viruses；**多數細菌約 1 μm**。巨型：_Thiomargarita_（0.1–0.3 mm）；侏儒：_Chlamydia/Rickettsia_（0.1–0.2 μm）。
- 二名法：**屬名大寫＋種小名小寫，皆斜體**（_Staphylococcus aureus_，第二次可縮寫 _S. aureus_）。
- 分類依據：
  - 巨觀菌落 / 顯微型態（形狀、排列、Gram stain）
  - **代謝特性 → Biotype（生化分型，最常用於定種）**
  - Protein profiling：**MALDI-TOF MS**（現行主流）
  - **抗原性 → Serotype**（e.g. _E. coli_ O157:H7）
  - **Genotype（最精準）**：DNA hybridization、PCR、**16S rRNA 定序**
- 排列：diplococci（成對）、streptococci（鏈狀）、staphylococci（葡萄串）。

## 5. 細胞壁：G(+) vs G(−)

|                              | Gram (+)（紫）                        | Gram (−)（粉紅）                                                    |
| ---------------------------- | ------------------------------------- | ------------------------------------------------------------------- |
| Peptidoglycan                | **厚、多層**                          | 薄（5–10%），位於 periplasm                                         |
| Teichoic / lipoteichoic acid | ✅（**G+ 獨有**，帶負電、抗原特異性） | ❌                                                                  |
| Outer membrane               | ❌                                    | ✅：**LPS**、lipoprotein、phospholipid、**porin（蛋白質，在外膜）** |
| Periplasmic space            | 無（或極少）                          | 有，含 **β-lactamase**、protease 等水解酶                           |
| LPS / Lipid A                | ❌                                    | ✅（**G− 獨有**）                                                   |

- **Peptidoglycan**：NAG–NAM 交替，NAM 上 tetrapeptide；**第三位 diamino acid（L-Lys / DAP）與第四位 D-Ala 交叉連結**（transpeptidation，由 PBPs 催化 → β-lactam、vancomycin 作用點）。
- **Lysozyme** 切 NAG–NAM 的 **β-1,4 鍵** → 破壞 PDG。
- **LPS 三段（內→外）**：**Lipid A（毒性 / endotoxin）** → Core（含 KDO，同一菌種相同）→ **O-antigen（最多變異，血清分型用）**。LPS → septic shock。
- 例外：
  - _Mycobacterium_：mycolic acid → **acid-fast**（carbolfuchsin 染後抗 acid alcohol 脫色）
  - _Mycoplasma_：**無細胞壁**、膜含 sterol、對作用於細胞壁的抗生素無效
  - _Chlamydia_：類 G−、但無 PDG
  - Spheroplast（G− 去壁留外膜）、Protoplast（G+ 完全去壁）、L-form（抗生素誘導）→ 易滲透壓裂解

## 6. 生長與代謝

- 生長條件：溫度、**pH 6.5–7.5**、滲透壓、氧、營養（C、N、S、P）。
- 氧需求：obligate aerobe、facultative anaerobe、**microaerophile（2–10% O₂）**、aerotolerant、obligate anaerobe。需氧菌能在有氧下活，是因為有酵素（catalase、SOD）清除 ROS。

<div data-fig="oxygen"></div>

- **生長曲線**：Lag（不分裂但代謝活躍，非「完全不生長」）→ **Log / Exponential（計算 generation time；對 penicillin 最敏感）** → Stationary → Death。

<div data-fig="growth-curve"></div>

- **Biofilm**：可逆附著 → 分泌 EPS（多醣、蛋白、DNA）→ 成熟；抗 UV 與抗生素。
- ATP 產生：Substrate-level phosphorylation（細胞質）、**Oxidative phosphorylation（主要；ETC 在細胞膜）**、Photophosphorylation。
- 1 NADH → 3 ATP；1 FADH₂ → 2 ATP。Aerobic respiration：Glycolysis → TCA → ETC。
- Anaerobic respiration：以 NO₃⁻、SO₄²⁻、CO₂ 作電子接受者（ATP 較少）；Fermentation：pyruvate → 代謝物（乳酸、乙醇、SCFAs）。
- Amphibolic pathway：NAD⁺ → 異化；NADP⁺ → 同化。

### 微生物學史、抗藥性、微生物相（09/09）
- 老師坦白：細菌總論國考大約只考 **1–2 題**，但 G+ / G− 等基本觀念直接影響臨床選藥，「最基本的知識才是最有用的」。
- Leeuwenhoek 透鏡約放大 **200–300 倍**；Pasteur 幫釀酒的朋友解決「酒變醋」→ pasteurization（短暫加熱，用於液態食品）；Semmelweis 發現助產士接生前會洗手、醫師沒有 → 產褥熱比例不同（做對的事卻被邊緣化）；Lister 以化學消毒處理手術器械。
- **Koch's postulates 的邏輯**：從病動物採檢 → 體外培養得 **pure culture** → 打入健康動物重現疾病 → **再從新病動物分離出同一菌**（排除中途被別的來源感染）。第一個證實的是炭疽桿菌 × 炭疽病。
- Ehrlich 的砷化合物「magic bullet」其實也會傷人體；Fleming 放假回來看到黴菌周圍透明圈（和現在藥敏試驗概念相同），但 penicillin 是另外兩位化學家純化成藥；**Waksman** 從**土壤細菌的二級代謝物**找到 streptomycin（治 TB），之後抗生素大多用此法尋找。
- **MegaPlate 實驗**：*E. coli* 在 0 → 1 → 10 → 100 → 1000 倍抗生素濃度梯度上，**11 天**就長到 1000 倍區 → 少數存活族群再放大 = 抗藥性產生。
- Fleming 在 1940 年代諾貝爾演講就警告「抗生素不能吃一半」；1950–70 年代是抗生素黃金期，之後藥廠因**急性用藥、獲利低**而停止開發 → 現用藥多是 70 年代結構的官能基修飾；預估 **2050 年**抗藥菌死亡數超過癌症；人畜用藥要分家。
- 「Superbug」是新聞用詞，定義隨年代改變（早期 MRSA 就被稱為超級細菌）。
- 對策：監測（台灣國衛院做了 20 年，現在希望細到各醫院）、新抗生素（培養以前養不起來的菌）、**噬菌體療法**（以前因專一性太高、療效不一致被拋棄，現在反而用來「精準打擊」抗藥株、不傷腸道菌）、疫苗。
- **Zosurabalpin**（Nature 2024 年 1 月）：50 年來第一個**新作用機轉**（抑制 LPS 運送 / 合成），針對 *A. baumannii*；不一定能用於其他菌。
- **Microbiome**：以定序（非培養）鑑定；細菌數約人體細胞 **3 倍**、基因數 **100 倍**。不同人口腔、腸道菌組成差很多，但以**功能**看高度一致 → **functional redundancy**：「重點不是帶了哪支菌，而是這支菌在做什麼事」。
- **Dysbiosis** 強調**組成**與**比例**都不同；*C. difficile* 反覆復發 → **FMT**（早期把健康人糞便裝膠囊吞，治癒率非常高；中國古籍「黃龍湯」、獸醫也用）。
- Probiotics 功效是**菌株特異**（廠商專利）；宣稱功效需動物實驗證據、主管機關核定；次世代益生菌 *Akkermansia* 是**絕對厭氧菌**；Postbiotics：真正作用的是代謝物（經循環到腦等遠端器官）。
- Archaea 與細菌長得一樣，但化學組成、作用機制完全不同 → 在「域」就分開；生活在高鹽、高熱、甲烷環境。肉眼極限約 **0.2 mm**；2022 年在澳洲海域發現 **1 cm** 大的細菌。

### 分類、構造、生長代謝（09/11）
- 學名：**屬、種用斜體**；屬以上（科、目、綱、門）用正體。分類名稱會因基因體定序而更名（如乳酸桿菌大量改名）。
- 屬名常反映形狀：*Staphylococcus*（-coccus 球菌）、*Bacillus*（桿菌）；也有球桿菌、梭狀（*C. difficile*）、弧菌（*Vibrio cholerae*）、螺旋菌；有些菌天生多形性（臨床檢體更常見）。
- **「麻煩請你牢記 Gram stain」**：crystal violet（結合 PDG）→ iodine 媒染 → **酒精脫色** → safranin 復染。G− 的 PDG 藏在外膜脂質層內且較薄 → 第一步就染得少、一脫色就掉。⚠️ 老化或變異的 *S. aureus* 可能染成粉紅色（PDG 狀態改變）。
- **MALDI-TOF**：把菌落蛋白打碎、依質荷比得圖譜比對資料庫；**約 30 分鐘**出結果，比傳統生化法省一天 → 減少經驗療法猜錯。血清型 / 基因型多用於危險或難養的菌（出血性 *E. coli*、HIV、MTB）。
- Capsule：菌落看起來**黏糊糊、亮亮的**；緻密 = capsule、鬆散 = slime layer；多醣抗原性差、抗吞噬。
- Flagella 由 flagellin 組成、嵌在細胞膜；運動是「趨吉避凶」的 **chemotaxis**（走走停停、往濃度高處）；**H antigen**。Spirochete 的 axial filament 像螺絲起子邊轉邊前進。
- Fimbriae 短而多；**pili 主要在 G−**，**sex pilus → conjugation**（下一章）。
- ⭐ **細胞壁「前面都可以當做沒有聽見，但這個一定要聽到」**：PDG 像**編織物**（不是水泥牆）→ 有彈性、多孔、可通透。
- **PBP 催化 transpeptidation**；**lysozyme**（眼淚、鼻腔）切 NAG–NAM 間的鍵 → 滲透壓脹破；**β-lactam 抑制 transpeptidation**；**vancomycin**（G+ 後線藥）綁住側鏈胜肽末端、使其無法交聯。「麻煩要記清楚，講抗生素時通通會連過來」。
- G+ 另有 teichoic / lipoteichoic acid 加固；G− 外膜有 **porin**（小分子通道）。
- ⭐⭐⭐ **LPS**（三顆星）：「有人說 G+ 有 LPS → 一定是錯的」。Lipid A → septic shock（進程極快，可在 **6 小時內**由健康到多重器官衰竭，且表徵因人而異）；Core 含 **KDO**（同菌種相同）；O antigen = **4–7 個糖重複 50–100 次**。O157:H7 的 O = O antigen、H = 鞭毛蛋白。
- **β-lactamase 位在 periplasmic space**：抗生素經 porin 進來馬上被分解（「要記得位置」）。
- 特例：*Mycobacterium*（mycolic acid → **acid-fast**：carbolfuchsin、acid alcohol 脫不掉）、*Mycoplasma*（無細胞壁、膜含 sterol）、*Chlamydia*（雙層膜但中間無 PDG）；protoplast 在**等張溶液**可存活（實驗室做 G+ 轉形會人工製造）；L-form 放回對的環境可恢復。
- Inclusion body =「小倉庫」（polyphosphate、多醣 → 可做生物塑膠）；磁小體細菌被研究當成磁力導引的抗癌藥載體（冷知識）。
- **Endospore**：*Bacillus*（炭疽桿菌那群）與 *C. difficile* 那群；複製染色體後層層包裹、**脫水、代謝靜止**，母細胞裂解後釋出，環境適合時 **germination** 長回桿菌。
- 二分裂：新舊各半（DNA、細胞質、細胞壁）。
- 病原菌都是 **mesophile**：最適 **35–37 °C**，10 °C 以下不長、50 °C 以上完全不長。⚠️ **冰箱是為了不讓病原菌長，不是為了不壞**：嗜冷菌在 0–10 °C 仍會長 → 便當放兩週還是會酸。
- 氧需求：obligate aerobe 需有 SOD、catalase 解毒；*E. coli* = facultative anaerobe（腸道低氧也能活，只是長得慢）；**microaerophile 代表 = *H. pylori*（2–10% O₂）**；厭氧培養最簡易法 = 密封罐 + 蠟燭燒掉氧氣。腸道研究讓絕對厭氧菌越來越受重視。
- 生長曲線：lag phase 肉眼清澈但在準備材料；**log phase**：*E. coli* 約 **20 分鐘**分裂一次，20 次（約 400 分鐘）→ 一隻變**百萬隻**；這時期菌體**最健康**，研究基因表達、酵素活性都取這期；**stationary phase 開始累積突變株**（可能出現抗藥）。「一定要特別記得 log phase 跟 stationary phase 代表的意思」。
- **Biofilm**：越內層越缺氧缺營養 → 抗藥；會剝離散播 → 反覆感染；醫療管路（引流管、導尿管、呼吸管）是大問題；組織上的代表是**感染性心內膜炎**（鏈球菌章）。
- 代謝：1 葡萄糖有氧呼吸 → **38 ATP，其中 34 個來自電子傳遞鏈**（oxidative phosphorylation）。無氧呼吸最終電子接受者可為 NO₃⁻、SO₄²⁻、**CO₂**（**國考考過**）。發酵只走 glycolysis，pyruvate 再被**還原**成菌種特有產物（酒精、乳酸、腸道 SCFAs → 調節免疫）。
- 老師原話：「**Murray 那本有出現的，國考都可以考**」、「**我沒有講的就是不會考**」；合成代謝只需記 PDG 由 UDP-N-acetylglucosamine 合成。

**II. Classification, Structure & Replication**

- Three domains；Algae > Protozoa > Fungi > Bacteria > Viruses；Giant / Dwarf bacteria。
- Binomial nomenclature（Linnaeus 1735）。
- Archaea：lack PDG；methanogens、halophiles、thermophiles。
- Classification I：colony / microscopic、**Gram stain（Christian Gram；exception: starved bacteria / atypical cell wall）**。
- Classification II：Biotype、**MALDI-TOF**、Serotype（O157:H7）、Genotype（16S rRNA）。
- Structures（p.35–54）：glycocalyx、flagella（filament/hook/basal body；chemotaxis run & tumble）、axial filaments、fimbriae & pili、cell wall（PDG、transpeptidation、PBPs、β-lactam & vancomycin）、G+ / G− wall、**LPS 三段**、exceptions、plasma membrane（lack sterols → hopanoids；被 alcohol、quaternary ammonium、polymyxin 破壞）、inclusions（volutin、carboxysome、gas vacuole、**magnetosome**）、spores、binary fission。

**III. Growth and metabolism**

- Physical（溫度、pH 6.5–7.5、滲透壓）＋ chemical factors（O₂、nutrients）。
- Oxygen effect（microaerophile 2–10% O₂）、growth curve、**biofilm formation**（EPS）。
- ATP generation：substrate-level / oxidative / photophosphorylation；ETC：1 NADH → 3 ATP、1 FADH₂ → 2 ATP；「? ATP from 1 mole glucose」。
- Fermentation：no ATP from pyruvate→metabolites；SCFAs 調節人體免疫。
- Biosynthesis：UDP-NAG（多醣）、cholesterol（真核膜）vs waxes（acid-fast 細胞壁）；amphibolic pathways。

# 考點分析

## 🔥 高頻考點（依去年考古出現次數）

1. **G(+) vs G(−) 獨有成分**：Lipid A / LPS → 只在 G−；Teichoic / lipoteichoic acid → 只在 G+；Porin → G− 外膜「蛋白質」（常被改成多醣、內膜來出錯）。
2. **構造 ↔ 功能配對**：Fimbriae = 黏附（不是運動）；Flagella = 運動；Inclusion = 儲存（不是蛋白質合成）；Plasmid = 基因交換 / 抗藥性。
3. **所有細菌都有**：cell membrane、DNA（nucleoid）、70S ribosome；capsule、flagella、plasmid 都「不一定」。
4. **Microbiota**：同一人不同部位不同、不同人同部位也不同、taxonomic diversity 大但 **functional redundancy**；dysbiosis 不只腸道疾病（代謝、免疫、癌症）。**這題去年出了 3 次、正反都考。**
5. **Koch**：證明微生物致病、Koch's postulates；**人物配對題**（Ehrlich–chemotherapy、Fleming–penicillin、Jenner–vaccine、Pasteur–germ theory / pasteurization）。
6. **LPS 三部分**：Lipid A（毒性）、Core、O-antigen（最多變、血清型）；Murein 不是 LPS 的成分。
7. **生長曲線**：generation time 用 log phase；penicillin 對 log phase 最有效；lag phase「不是完全不長」。
8. **ATP**：主要機制 = oxidative phosphorylation、位置 = **cell membrane**（細菌沒有粒線體）。

## ⚠️ 常見陷阱

- 「Porin-like polysaccharides in the inner membrane」→ 錯兩處（蛋白質、外膜）。
- 「Having a cell membrane equals greater resistance」→ 應為 outer membrane。
- Teichoic acid 是 **water-soluble**，嵌在細胞壁（不是 organic-soluble、錨在細胞膜）。
- Capsule 是多醣 → 唯一「非蛋白質」構造（vs flagellum、pilus、porin 都是蛋白質）。
- Endospore：為了存活、不是繁殖；代謝極低；不易被 Gram stain 染色。
- 最精準分類 = genetic material（16S rRNA / 全基因體）；最常用於定種 = biochemical typing。

## 📝 出題模式

- 大多為「Which is TRUE / FALSE」單選，選項常把兩個正確概念交換（例：fimbriae↔flagella、G+↔G−）。
- 組合題（a–f 選三個正確）考原核 vs 真核構造。
- 會出少量超出範圍的菌種細節（炭疽桿菌感染途徑、Clostridium 孢子形狀）——屬於各論章節，可先略過。
