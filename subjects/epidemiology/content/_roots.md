# 專有名詞字根字首背誦表
<!-- 格式同 _sheet.md：每張卡片以「## 標題」開頭，「@ch 章節id」加章節連結。表格固定三欄：字根｜意思｜本科例字。 -->

## 流行病學的基本詞
@ch intro,transmission
| 字根 | 意思 | 本科例字 |
|---|---|---|
| epi- + demos + -logy | 在…之上 + 人群 + 學問 | epidemiology、epidemic |
| en- + demos | 在…之內 + 人群 | endemic（一直存在、常態） |
| hyper- + endemic | 過多 + 地方性 | hyperendemic |
| pan- + demos | 全部 + 人群 | pandemic（跨國、跨洲） |
| etio- | 原因 | etiology |
| zoo- + -nosis | 動物 + 疾病 | zoonosis |
| propag- | 繁殖、散播 | propagated epidemic（人傳人，一波接一波） |
| secul- | 世代 → 長期 | secular trend |
| in- + cub- | 在…裡面 + 躺著 | incubation period |
| sub-／pre- + clinical | 低於／之前 + 臨床 | subclinical、preclinical |

## 傳播與測量
@ch transmission,morbidity,mortality
| 字根 | 意思 | 本科例字 |
|---|---|---|
| infect- + -ivity | 感染 + 能力 | infectivity（感染力：感染數 ÷ 暴露數） |
| pathogen- + -icity | 致病 + 能力 | pathogenicity（發病數 ÷ 感染數） |
| virul- + -ence | 毒力 | virulence（重症或死亡 ÷ 發病數） |
| vect-／vehic- | 搬運者 | vector（活的，如蚊子）、vehicle（無生命，如水、食物） |
| morb- | 疾病 | morbidity |
| mort- | 死亡 | mortality、proportionate mortality |
| fatal- | 致死 | case-fatality |
| incid- | 落進來 → 新發生 | incidence（新病例） |
| preval- | 普遍存在 | prevalence（現有病例，P ≈ I × D） |
| sero- | 血清 | seroprevalence |

## 篩檢、預後與試驗
@ch screening,prognosis,rct
| 字根 | 意思 | 本科例字 |
|---|---|---|
| sens- | 感覺 → 抓得到 | sensitivity（真的有病被驗出來） |
| spec- | 特定 → 認得準 | specificity（真的沒病判為陰性） |
| valid- | 有效、正確 | validity（準不準） |
| reli- | 可依靠 | reliability（重複測量結果一樣嗎） |
| pro- + -gnosis | 預先 + 知道 | prognosis |
| dia- + -gnosis | 透過 + 知道 | diagnosis |
| co- + hort | 一起 + 羅馬軍團的單位 | cohort（一群一起被追蹤的人） |
| random- | 隨機 | randomized controlled trial |
| placebo | 拉丁文「我會取悅你」 | placebo（安慰劑） |
| cross- + over | 交叉 | crossover design（中間要 washout） |
| factor- + -ial | 因子 | factorial design（aspirin × 紅麴） |
| prim-／second-／terti- | 第一／二／三 | primary、secondary、tertiary prevention |
