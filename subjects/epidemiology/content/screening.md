## 0. 篩檢的定義與形式 ⭐⭐

- **篩檢（screening）**：對**沒有已知症狀或徵象**的人施以檢查，找出**可能**（potential）的疾病。篩檢落在**臨床前期（preclinical phase）**，屬於**次段預防（secondary prevention）**。
- **篩檢 ≠ 診斷**：

  |          | 篩檢                         | 診斷                       |
  | -------- | ---------------------------- | -------------------------- |
  | 對象     | 健康者、高風險者、臨床前期   | 有症狀的病人               |
  | 檢查     | 便宜、快速，通常單一檢查     | 昂貴、耗時、侵入性，多項檢查 |
  | 例       | 乳房 X 光攝影（政府補助 40–74 歲婦女每 2 年 1 次） | 乳房組織切片 |

- 篩檢的兩個前提：① 早期發現能降低罹病與死亡；② 可疑結果一定要轉介診斷與治療。
- **普遍篩檢（universal）**：篩檢族群中的每個人，例：新生兒聽力篩檢。**目標篩檢（targeted／selective）**：只篩高風險族群，例：有乳癌家族史的婦女做乳房 X 光攝影。
- 篩檢的衡量：檢查本身的特性是**效度、信度**；解讀結果用**預測值**。

## 1. 生物差異與切點（cut point）⭐

- **雙峰分佈**：例如 tuberculin 反應硬塊直徑，兩個高峰之間容易找到切點。
- **單峰分佈**：例如男性收縮壓，較難區分，要選最適合的切點（例：140 mmHg）。切點會隨時間、性別、年齡改變；台灣有人主張 BMI 切點降為 23。
- 降低切點 → 抓到更多病人（敏感度 ↑），但病人變多、醫療支出增加。

## 2. 效度（Validity）⭐⭐⭐

|          | 有病    | 沒病    |
| -------- | ------- | ------- |
| 篩檢陽性 | a（TP） | b（FP） |
| 篩檢陰性 | c（FN） | d（TN） |

- **敏感度 Sensitivity = a / (a + c)**：有病的人中被正確判為陽性的比例。
- **特異度 Specificity = d / (b + d)**：沒病的人中被正確判為陰性的比例。
- **%偽陽性（%FP）= b / (b + d) = 1 − Sp**；**%偽陰性（%FN）= c / (a + c) = 1 − Se**（slides 的分母是**真實疾病狀態**，不是篩檢結果）。
- slides 例：500 名疑似聽力問題者，300 人真的有。理學檢查 Se 0.8、Sp 0.8；聽力檢查 Se 0.9、Sp 0.7 → 聽力檢查**較敏感、較不特異**；聽力檢查 %FN 0.1、%FP 0.3。
- 偽陽性 → 增加醫療資源負擔；偽陰性 → 錯失治療時機、疾病惡化或傳染。
- 篩檢陽性者再用**黃金標準（gold standard）**確認，例如快篩陽性再做 PCR。
- **連續變數**：正常人與病人的數值分布實際上會**重疊**，所以一定有誤判。同一個檢查、同一個切點下，病人的嚴重度分布（**spectrum of severity**）越接近真正陰性者，誤判越多。
- **ROC 曲線**：曲線上每一點代表某個切點對應的一組 Se／Sp；改變判為陽性的切點，就能在 Se 與 Sp 之間取捨。
- **切點怎麼選**：
  - **漏掉病人代價高**（疾病嚴重且有治療、疾病會傳染）→ 減少偽陰性 → 選**高敏感度（低切點）**。例：**捐血篩 HIV** 要高敏感度。
  - **後續確診檢查昂貴或侵入性** → 減少偽陽性 → 選**高特異度（高切點）**。
- **連續變數的切點取捨**：切點**高** → 特異度高、敏感度低；切點**低** → 敏感度高、特異度低（例：血糖切點 80 mg/dl → 敏感度 100%、特異度 17.7%；200 mg/dl → 敏感度 39.2%、特異度 100%）。

## 3. 多重測試 ⭐⭐⭐

|          | **序列篩檢 Sequential（two-stage）**           | **平行篩檢 Simultaneous（parallel）**                |
| -------- | ---------------------------------------------- | ---------------------------------------------------- |
| 做法     | 第一階段（便宜、低侵入）陽性者才做第二階段     | 同時做兩種檢查                                       |
| 淨敏感度 | **兩次都陽性**：Se₁ × Se₂ → **下降**           | **任一陽性**：Se₁ + Se₂ − Se₁ × Se₂ → **上升**       |
| 淨特異度 | **任一陰性**：Sp₁ + Sp₂ − Sp₁ × Sp₂ → **上升** | **兩次都陰性**：Sp₁ × Sp₂ → **下降**                 |
| 適用     | 公衛、群體篩檢（COVID 快篩 → PCR）；住院時間長 | 臨床、醫院端（同時做很多檢驗，快速診斷）；住院時間短 |

- 共筆例：糖尿病 10,000 人、盛行率 5%，血糖（Se 70%、Sp 80%）→ OGTT（Se 90%、Sp 90%）：淨敏感度 63%、淨特異度 98%。
- 平行例：Test A（Se 80%、Sp 60%）＋ Test B（Se 90%、Sp 90%）：淨敏感度 98%、淨特異度 54%。

## 4. 預測值（Predictive value）⭐⭐⭐

- **PPV = a / (a + b)**：篩檢陽性者中真的有病的比例（臨床：「這個病人真的有病的機率」）。
- **NPV = d / (c + d)**：篩檢陰性者中真的沒病的比例。
- **PPV 受盛行率影響**：盛行率 ↑ → **PPV ↑、NPV ↓**；在**低盛行率**族群中，即使敏感度、特異度都很高，PPV 也會很低。
- 疾病少見時，**特異度**對 PPV 的影響最大。
- slides 例（Se 0.99、Sp 0.95、10,000 人）：盛行率 **1% → PPV 0.17**；盛行率 **5% → PPV 0.51**。所以篩檢放在**高風險族群**比較有效益；篩罕見疾病則浪費資源。
- slides 例（盛行率 10%、Se 1.0）：**Sp 0.70 → PPV 0.27**；**Sp 0.95 → PPV 0.69**。同樣盛行率與敏感度下，**Sp↑ → PPV↑**。
- 盛行率、Se、Sp 任一上升，PPV 都上升；**序列篩檢的淨特異度↑，所以 PPV↑**。
- **Se、Sp 不受盛行率影響**；盛行率↓ → PPV↓↓、NPV↑。
- 偽陽性的代價是醫療資源與心理負擔；偽陰性的代價是健康負擔（看疾病嚴重度與有沒有介入手段）。例：加拿大職場無症狀員工快篩 903,408 次，1,103 次陽性中有 462 次（42%）PCR 陰性。
- 例：Hemoccult Se = Sp = 80%、盛行率 1% → PPV = 0.8 × 0.01 ÷ (0.8 × 0.01 + 0.2 × 0.99) ≈ **3.9%**。

## 5. 信度（Reliability／Repeatability）⭐⭐

- 同一檢驗在相同條件下重複測量，得到一致結果的程度。
- 變異來源：**受試者本身（intrasubject，例如血壓日夜波動、白袍症候群）**、**同一觀察者（intraobserver）**、**不同觀察者之間（interobserver）**。
- 另一個變異來源是**儀器或方法**本身的技術特性。
- **百分比一致性（percent agreement）** = 判讀一致數 ÷ 總判讀數；大部分是陰性時會被 d 灌水 → 修正為 a ÷ (a + b + c)，slides 稱為 **Chamberlain 陽性一致率（percent positive agreement）**：兩人都判陽性 ÷ 至少一人判陽性。
- **Kappa 的意義**：觀察一致率扣掉機率一致率後，占「最多還能超出機率的一致」的比例。Pc =〔(a+b)(a+c)/N + (c+d)(b+d)/N〕÷ N。slides 例：P₀ 0.919、Pc 0.514 → κ = 0.405 ÷ 0.486 = **0.833**。
- **Kappa 悖論（Kappa paradox）**：Se、Sp 相同時，**陽性盛行率較高**的族群 Kappa 較大。
- **Kappa = (P₀ − Pc) ÷ (1 − Pc)**：P₀ 觀察一致率、Pc 機率一致率。
  | Kappa | 一致性 |
  |---|---|
  | 0–0.20 | slight |
  | 0.21–0.40 | fair |
  | 0.41–0.60 | moderate |
  | 0.61–0.80 | substantial |
  | 0.81–1.00 | almost perfect |
  一般可接受 ≥ 0.6，嚴格要 ≥ 0.8。共筆例：兩位病理學家判讀 75 張切片，P₀ 90.7%、Pc 51.7% → κ = 0.81。
- **一致率高但 Kappa 低**：通常是**盛行率極低**，機率一致（Pc）很高。

## 6. 效度與信度的關係 ⭐⭐

- 結果**越接近真值** → 效度越高（accurate，準確度）；結果**越集中** → 信度越高（precise，精確度）。打靶圖：集中但偏離靶心 = 信度高、效度低。
- **群體效度 vs 個人效度**：對群體有效的檢查，用在臨床上的個人不一定有效；信度差的檢查，對個人的效度通常也差。

- **Se、Sp、%FP、%FN「考試沒有放公式，自己記」**；算的時候看**直的 column**（以真實疾病狀態為分母）；%FP = 1 − Sp、%FN = 1 − Se 可以用相減速算。
- 切點：要抓到所有病人 → 切點**往下**（Se↑，但誤抓高血糖的非病人）；不能忍受誤抓 → 切點**往上**（Sp↑，但漏掉血糖較低的病人）。選切點就是**權衡 FP 與 FN**。
- **不考的兩頁**：病人集中在輕症或重症（spectrum of severity）那張**綠色進階圖「不會考」**（但前一頁會考）；**ROC 曲線那頁「只是補充，不會考」**。
- **漏掉代價高 → 高敏感度（低切點）**：**捐血篩 HIV** 不能有任何偽陰性，否則會感染受血者。**後續確診檢查昂貴或侵入 → 高特異度**，避免沒病的人被送去做。
- **序列檢定**：淨 Se = Se₁ × Se₂；淨 Sp = 1 −（1 − Sp₁）（1 − Sp₂）；「要記得系列檢定之下**敏感度往下降、特異度往上升**」，淨 Se 比兩項工具都低。臨床上比較常用序列（例：糞便潛血 → 大腸鏡）。
- **平行檢定**：任一陽性即陽性、兩項都陰性才是陰性 → 淨 Se↑、淨 Sp↓。同一種病看情境選：在意確診的心理負擔 → HIV 快篩後再做西方墨點（序列）；不能漏掉 → 快篩與酵素免疫法同時做（平行）。
- **預測值算的時候要「橫著看」**（以篩檢結果為分母）。盛行率 1% 的 10,000 人社區：有病 100 人 × 0.99 = 99；沒病 9,900 × 0.95 = 9,405 → PPV = 99 /（99 + 495）= **0.17**；盛行率 5% → PPV 0.51。
- **PPV 只會考盛行率的影響**：Se、Sp 提高也會讓 PPV 上升，但老師說「這樣考太複雜了，所以就會考盛行率而已」。
- 信度的變異來源：儀器／方法、**受試者內**、**觀察者內**（同一位老師早上、下午改考卷心情不同）、**觀察者間**（老師改和 TA 改標準不同）。
- **「我沒有考算一致率」「我也沒有考算 Kappa index」**：不用記計算，但**選項裡可能出現一致率**；Kappa **國考出現過**，要知道是什麼：κ =（P₀ − Pₑ）/（1 − Pₑ），P₀ = 觀察到的一致、Pₑ = 預期（機率）一致，越高信度越好。效度相同時，族群的盛行狀況不同，Kappa 也會不同。
- 結尾：「不要問我會出什麼題目」。

# 考點分析

## 🔥 高頻考點（考古 109、110、114 期中）

- **敏感度、特異度計算**（乳癌觸診題 109、110 都出）。
- **序列 vs 平行篩檢**對淨敏感度、淨特異度的影響（110、114 都出）；平行的淨敏感度計算（110：98.9%）。
- **PPV 與盛行率**：盛行率 1% → 10% 時 PPV ↑、NPV ↓（114）；低盛行率社區快篩陽性只有 40% 為真（114）；PPV 計算（110：3.889%）。
- **降低切點**：敏感度 ↑、PPV ↓（114）。
- **Kappa**：一致率 90% 但 κ 只有 0.45 → 盛行率低、機率一致高（114）。
- **打靶圖**判斷信度與效度（109、110）。

## 🎙️ 老師課堂提示

- 期中考**全部選擇題、含計算**，帶計算機與 2B 鉛筆；**公式不提供**，Se、Sp、%FP、%FN、PPV、NPV 要自己記。
- **三段五級可能出兩到三題**：篩檢 = 次段預防 = 第三級。
- **ROC 曲線頁、spectrum of severity 的綠色進階圖不考**。
- PPV **只考盛行率的影響**（不考 Se、Sp 對 PPV 的影響）。
- **不考算一致率、不考算 Kappa**，但選項可能出現一致率，Kappa 要知道意義（國考考過）。

## 📝 出題模式

- 給 2×2 表或人數，算 Se、Sp、PPV、NPV；判斷兩種檢查誰比較敏感或特異。

## ⚠️ 陷阱整理

| 容易選錯                        | 正確                                                                                         |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| ✗ 敏感度 = 陽性者中有病的比例     | ✓ 敏感度 = **有病者中被判陽性**（a／a+c）；陽性者中有病的比例是 **PPV**（a／a+b）              |
| ✗ 切點提高 → 敏感度上升           | ✓ 切點**提高 → 特異度↑、敏感度↓**；降低切點則相反                                              |
| ✗ 序列篩檢提高淨敏感度            | ✓ **序列（兩次都陽性才算）→ 淨敏感度↓、淨特異度↑**；**平行（任一陽性）→ 淨敏感度↑、淨特異度↓** |
| ✗ 敏感度、特異度受盛行率影響      | ✓ Se、Sp 是試驗本身的特性；**PPV、NPV 才受盛行率影響**                                         |
| ✗ 盛行率上升 → NPV 上升           | ✓ 盛行率**↑ → PPV↑、NPV↓**                                                                     |
| ✗ 罕見疾病時敏感度對 PPV 影響最大 | ✓ 疾病罕見時 **特異度**對 PPV 影響最大                                                         |
| ✗ 百分比一致性高 = 信度好         | ✓ 一致率可能被大量陰性（d）灌水 → 用 **Kappa** 校正機率一致                                    |
| ✗ Kappa 0.5 = substantial         | ✓ 0.41–0.60 **moderate**；0.61–0.80 substantial；≥ 0.81 almost perfect                         |
| ✗ 一致率高 Kappa 也一定高         | ✓ 盛行率極低時 **Pc 很高 → Kappa 可能很低**                                                    |
| ✗ 信度高就有效度                  | ✓ **有信度不一定有效度**（可能穩定地錯）                                                       |
| ✗ %FP = b／(a+b)                  | ✓ slides 定義 **%FP = b／(b+d) = 1 − Sp**、**%FN = c／(a+c) = 1 − Se**；分母是真實疾病狀態      |
| ✗ 捐血篩 HIV 用高特異度           | ✓ 漏掉代價高、會傳染 → **高敏感度（低切點）**                                                  |
| ✗ 篩檢屬於初段預防                | ✓ 篩檢在臨床前期 → **次段預防**；篩檢 ≠ 診斷                                                   |
