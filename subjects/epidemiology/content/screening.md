## 1. 篩檢的定義、目的與預防層級 ⭐⭐

- **篩檢（screening）**：在**沒有症狀或明顯徵象**的人群中，用某種檢測找出**可能**罹患某疾病或狀況的人。
- **核心目的**：改善預後、降低死亡率。兩個基本假設：① **早期發現**能降低發病率與死亡率；② 篩檢發現的**可疑個案必須轉介**確診與治療。
- 屬於三段五級中的**次段預防（secondary prevention）**，作用在疾病的**臨床前期（preclinical phase）**。
- **成功要素**：選對族群、以**高危險群**為目標。例：政府補助 40–74 歲婦女每 2 年 1 次乳房 X 光攝影；老年男性攝護腺癌篩檢。

## 2. 篩檢與診斷的區別、篩檢形式 ⭐⭐

|          | 篩檢                                   | 診斷                                         |
| -------- | -------------------------------------- | -------------------------------------------- |
| 對象     | 健康者、高風險者、臨床前期病人         | 已出現症狀的病人                             |
| 檢查     | 便宜、快速、**非侵入**，通常單一檢查   | 昂貴、耗時、侵入性、準確率高，通常結合多項檢查 |
| 目的     | 找出可能罹病的人                       | 確定是否罹病，並分類、治療                   |
| 例       | 乳房 X 光攝影（無症狀、找早期腫瘤）    | 乳房組織切片（有症狀、確認腫瘤型態與良惡性） |

- 乳房 X 光影像：正常脂肪型乳房的脂肪是暗色、乳腺與纖維組織呈白色網狀；**良性腫塊**白色、邊界清楚、周圍有暈輪；**惡性病灶**形狀不規則、邊界模糊、有放射狀尖刺邊緣。
- **普遍篩檢（universal）**：篩特定人口中的每一個人，例：新生兒聽力篩檢。**目標篩檢（targeted／selective）**：只篩高風險族群，例：有乳癌家族史的女性做乳房 X 光攝影。

## 3. 效度與信度 ⭐⭐

- **效度／準確度（validity／accuracy）**：測量值接近**真實值**的程度。
- **信度／精確度（reliability／precision）**：相同條件下重複測量時，**多次測量值彼此接近**的程度。
- 打靶圖：集中但偏離靶心 = **高信度、低效度**；分散但平均在靶心附近 = 高效度、低信度；集中在靶心 = 兩者都高。

## 4. 二元變數的效度：敏感度、特異度、偽陽性、偽陰性 ⭐⭐⭐

- 二元結果（陽性／陰性）要和**黃金標準（gold standard）**比對，建 2×2 表：

|          | 有病    | 沒病    | 合計  |
| -------- | ------- | ------- | ----- |
| 篩檢陽性 | a（TP） | b（FP） | a+b   |
| 篩檢陰性 | c（FN） | d（TN） | c+d   |
| 合計     | a+c     | b+d     | N     |

- **敏感度 Sensitivity**：真正有病的人中被判為陽性的機率。
  $$\text{Se} = \frac{TP}{TP+FN} = \frac{a}{a+c}$$
- **特異度 Specificity**：沒病的人中被判為陰性的機率。
  $$\text{Sp} = \frac{TN}{FP+TN} = \frac{d}{b+d}$$
- **偽陽性率（%FP）**：沒病的人中被誤判為陽性的比例；**偽陰性率（%FN）**：有病的人中被誤判為陰性的比例（分母是**真實疾病狀態**，不是篩檢結果）。
  $$
  \%\text{FP} = \frac{b}{b+d} = 1 - \text{Sp}
  \%\text{FN} = \frac{c}{a+c} = 1 - \text{Se}
  $$
  - ⚠️ 共筆 %FN 的文字誤寫成「沒有患病的人當中被誤判為陽性」，公式 $c/(a+c)$ 才對。
- **例（聽力）**：500 名疑似聽力問題者，黃金標準確診 300 人有、200 人沒有。
  - 理學檢查：$\text{Se} = \dfrac{240}{300} = 0.8$、$\text{Sp} = \dfrac{160}{200} = 0.8$。
  - 聽力檢測：$\text{Se} = \dfrac{270}{300} = 0.9$、$\text{Sp} = \dfrac{140}{200} = 0.7$ → **較敏感、較不特異**。
  - 聽力檢測 %FP = $\dfrac{60}{200}$ = **0.3**（30% 沒問題的人被誤判異常）；%FN = $\dfrac{30}{300}$ = **0.1**（漏掉 10% 的病人）。
- 偽陽性 → 增加醫療資源負擔；偽陰性 → 錯失治療時機、疾病惡化或傳染（講義）。

## 5. 連續變數：切點選擇與 ROC 曲線 ⭐⭐⭐

- **理想分布**：健康者與病人的數值完全不重疊。**真實分布**：兩者**部分重疊**，所以一定有誤判。
- **切點取捨**：
  - **切點左移（降低陽性界值）→ 高敏感度**：找到更多病人，但**偽陽性增加**。
  - **切點右移（提高陽性界值）→ 高特異度**：排除更多健康者，但**偽陰性增加**。
  - **中間值（intermediate limit）**：讓偽陽性與偽陰性都盡量少；落在重疊灰色地帶的人可能要**召回（call back）**再檢查。
  - 例：血糖切點 **80 mg/dL → 敏感度 100%**（偽陽性多）；**200 mg/dL → 特異度 100%**（偽陰性多）。
- **疾病嚴重度光譜（spectrum of severity）**：同一檢查、同一切點下，病人的數值分布越靠近未患病者，誤判越多。光譜**較廣** → 偽陰性較少、**敏感度較高**；光譜**較窄** → 偽陰性較多、敏感度較低。
- **ROC 曲線**：Se 與 Sp 要互相取捨，改變判陽性的切點就能調整。**縱軸是真陽性率（Se），橫軸是偽陽性率（1 − Sp）**；曲線上每一點代表一個切點的 Se／Sp 組合。
- **切點怎麼選**：
  - **漏診代價高**（疾病嚴重且有治療、或具傳染性，例：**HIV** 篩檢）→ 減少偽陰性 → 選**高敏感度（低切點）**。
  - **後續檢查代價高**（很貴或高度侵入性）→ 減少偽陽性 → 選**高特異度（高切點）**。

## 6. 多重測試：系列檢定與平行檢定 ⭐⭐⭐

|          | **系列檢定 Sequential（two-stage）**                               | **平行檢定 Simultaneous**                                          |
| -------- | ------------------------------------------------------------------ | ------------------------------------------------------------------ |
| 做法     | 先做便宜、低侵入、舒適的檢查，**陽性者**再做較貴、較侵入但更準的第二階段 | 對目標族群**同時**做兩種檢查                                       |
| 判定     | 兩次都陽性才算陽性                                                 | **任一陽性**就算陽性；**兩項都陰性**才算陰性                       |
| 淨敏感度 | $\text{Se}_1 \times \text{Se}_2$ → **下降**                        | $1 - (1 - \text{Se}_1)(1 - \text{Se}_2)$ → **上升**                |
| 淨特異度 | $1 - (1 - \text{Sp}_1)(1 - \text{Sp}_2)$ → **上升**                | $\text{Sp}_1 \times \text{Sp}_2$ → **下降**                        |

## 7. 預測值及其影響因素 ⭐⭐⭐

- **預測值**：已知檢驗結果後，推估真正有病／沒病的機率（看 2×2 表**橫向**）。
  $$
  \text{PPV} = \frac{TP}{TP+FP} = \frac{a}{a+b}
  \text{NPV} = \frac{TN}{FN+TN} = \frac{d}{c+d}
  $$

  | 指標 | 已知條件 | 分母 | 看表方向 | 受盛行率影響 |
  | ---- | -------- | ---- | -------- | ------------ |
  | Se   | 真的有病 | a+c  | 直向 ↓   | **否**       |
  | Sp   | 真的沒病 | b+d  | 直向 ↓   | **否**       |
  | PPV  | 檢驗陽性 | a+b  | 橫向 →   | **是**       |
  | NPV  | 檢驗陰性 | c+d  | 橫向 →   | **是**       |

- **例（聽力檢測）**：PPV = $\dfrac{270}{270 + 60}$ = **0.82**；NPV = $\dfrac{140}{30 + 140}$ = **0.82**。
- **盛行率的影響**（Se 0.99、Sp 0.95，各 10,000 人）：

  |            | 盛行率 1%                  | 盛行率 5%                   |
  | ---------- | -------------------------- | --------------------------- |
  | 有病／沒病 | 100／9,900                 | 500／9,500                  |
  | TP         | 99                         | 495                         |
  | FP         | 495                        | 475                         |
  | **PPV**    | $\dfrac{99}{594}$ = **0.17** | $\dfrac{495}{970}$ = **0.51** |

  - Se、Sp 固定時：**盛行率↑ → PPV↑、NPV↓**；盛行率↓ → PPV↓↓、NPV↑（Se、Sp 本身不受盛行率影響）。
  - 公衛意涵：低盛行率普篩偽陽性多、浪費資源 → 應針對**高危險群**篩檢。
  - 用盛行率 $P$ 表示（講義）：
  $$
  \text{PPV} = \frac{\text{Se} \cdot P}{\text{Se} \cdot P + (1 - \text{Sp})(1 - P)}
  \text{NPV} = \frac{\text{Sp}\,(1 - P)}{\text{Sp}\,(1 - P) + (1 - \text{Se})\,P}
  $$
- **特異度的影響**（Se 1.0、盛行率 10%、10,000 人）：**Sp 0.70 → PPV** $\dfrac{1000}{3700}$ = **0.27**；**Sp 0.95 → PPV** $\dfrac{1000}{1450}$ = **0.69**。
  - **低盛行率時，提高 Sp 比提高 Se 更能提升 PPV**：Se 50% → 90%，PPV 只從 20% → 31%；Sp 50% → 90%，PPV 從 20% → **56%**。
  - 延伸：**系列檢定淨特異度↑ → PPV↑**。
- **COVID-19 篩檢**：

  |      | 快速抗原檢測     | RT-PCR                   |
  | ---- | ---------------- | ------------------------ |
  | 定位 | 篩檢工具         | **黃金標準**             |
  | 優點 | 便宜、快速       | 準確度高                 |
  | 缺點 | 準確度較低       | 昂貴、耗時、量能有限     |

  - 加拿大：無症狀員工快篩 903,408 次，1,103 次陽性中 462 次（42%）RT-PCR 陰性 → **PPV 只有約 58%**。
  - 台灣：疫情初期盛行率低，不推普篩；**萬華群聚**時盛行率高 → 快篩 PPV↑，能迅速找出並隔離感染者。

  |          | 偽陽性 FP                      | 偽陰性 FN                              |
  | -------- | ------------------------------ | -------------------------------------- |
  | 代價     | 醫療資源浪費、心理負擔         | 健康負擔（延誤治療、持續傳播）         |
  | 嚴重程度取決於 | 後續確診檢查的成本與侵入性 | 疾病性質、嚴重度、可用的介入措施       |

## 8. 信度：變異來源、一致率、Kappa ⭐⭐

| 變異來源                                  | 說明                           | 例                                           |
| ----------------------------------------- | ------------------------------ | -------------------------------------------- |
| **儀器或方法**（instrument／method）      | 儀器本身的技術特性             | 血壓計未校正                                 |
| **受試者本身**（intrasubject）            | 同一人的生理值隨時間改變       | 皮質醇早上最高、夜間最低                     |
| **同一觀察者**（intraobserver）           | 同一判讀者前後不一致           | 同一醫師早上與疲倦時判讀同一張 X 光結果不同  |
| **不同觀察者之間**（interobserver）       | 不同判讀者之間不一致           | 三位醫師把同一張 X 光判為輕度／中度／重度    |

- **一致率（percent agreement）** 與 **Chamberlain 陽性一致率**（忽略兩人都判陰性的 d，只看至少一人判陽性者）：
  $$
  \text{一致率} = \frac{a+d}{a+b+c+d}
  \text{Chamberlain 陽性一致率} = \frac{a}{a+b+c}
  $$
  - 限制：兩者都**沒有扣除隨機（chance）造成的巧合一致**。
- **Kappa**（老師說不考計算，但國考出現過）：扣除隨機一致後，衡量「真正的一致程度」。$P_o$ 觀察一致率、$P_e$ 期望（隨機）一致率：
  $$
  \kappa = \frac{P_o - P_e}{1 - P_e}
  P_e = \frac{(a+b)(a+c) + (c+d)(b+d)}{N^2}
  $$
  - 例：數位 vs 合成 2D 乳房攝影判讀乳腺密度（N = 309；a = 168、b = 14、c = 11、d = 116）：$P_o = \dfrac{284}{309}$ = 0.919；$P_e = \dfrac{182 \times 179 + 127 \times 130}{309^2}$ = 0.514；$\kappa = \dfrac{0.405}{0.486}$ = **0.833** → 實際超出隨機的一致（40.5%）占最大可能（48.6%）的 83.3%，almost perfect。
  - 🎙️ 不同學者對 Kappa 好壞的分級定義不一致，老師說一般不會考「這個 Kappa 是好是壞」。
- **Kappa 悖論（Kappa paradox）**：Se、Sp 相同時，盛行率越偏向極端（極低或極高），$P_e$ 越高 → 即使一致率很高，Kappa 仍可能偏低。講義的說法：同樣 Se、Sp 下，**陽性盛行率較高**的族群 Kappa 較大（指盛行率偏低的範圍）。

| 參考書（p.45） | Gordis Ch5、Friis Ch11、Szklo Ch8、Newman Ch5–6。結尾：「正常人只是還沒被充分檢查的人」 |

| ✗ 敏感度 = 陽性者中有病的比例     | ✓ 敏感度 = **有病者中被判陽性**（a／a+c）；陽性者中有病的比例是 **PPV**（a／a+b）              |

## 百十三共筆對照
- 百十三 W5 是**葉志清**老師上的（今年是陳偉仁），架構相同，但例子不太一樣。以下是百十三有、百十四沒寫的：
- **生物差異與切點**：雙峰分布（tuberculin 反應硬塊直徑）容易找切點；單峰分布（男性收縮壓）較難，要選最適合的切點（例：140 mmHg），切點會隨時間、性別、年齡改變；BMI 正常範圍 18.5–24 是歐美標準，台灣有人主張切點降為 23。
- **連續變數例**：血糖切點 80 mg/dL → 所有糖尿病人都被篩為陽性（Se 100%）；200 mg/dL → 所有非糖尿病人都被篩為陰性（Sp 100%）。切點低 → 陽性多，要考量後續精確檢查的費用。
- **序列篩檢例**：糖尿病 10,000 人、盛行率 5%，血糖（Se 70%、Sp 80%）→ OGTT（Se 90%、Sp 90%）：第一階段陽性 2,250 人進第二階段；淨敏感度 **63%**、淨特異度 **98%**。
- **平行篩檢例**：1,000 人、盛行率 20%，Test A（Se 80%、Sp 60%）＋ Test B（Se 90%、Sp 90%）：淨敏感度 **98%**、淨特異度 **54%**。
- **使用時機**：序列篩檢用在公衛、群體篩檢（COVID 快篩 → PCR）；平行篩檢用在臨床、醫院端（同時做很多檢驗、快速診斷）。其他考量：住院時間長用序列、短用平行；花費、侵入程度、保險是否給付。
- **預測值**：公衛領域關心「有病的人中多少能被正確找出」（Se），臨床關心「這個病人真的有病的機率」（PPV）；AFP 篩檢脊柱裂例（高風險孕婦 PPV 較高，NPV 差不多）；Hemoccult Se = Sp = 80%、盛行率 1% → PPV ≈ 3.9%。
- **信度**：受試者本身的變異例子是 24 小時血壓變化與**白袍症候群**；percent agreement 會被 d 灌水 → 忽略 d 修正。
- **Kappa 分級**（百十三有，今年老師說定義不一致、不會考好壞）：0–0.20 slight、0.21–0.40 fair、0.41–0.60 moderate、0.61–0.80 substantial、0.81–1.00 almost perfect；一般可接受 ≥ 0.6，嚴格要 ≥ 0.8。例：兩位病理學家判讀 75 張切片，$P_o$ 90.7%、$P_c$ 51.7% → κ = 0.81。
- **效度與信度的關係**：對群體有效的檢查，用在臨床上的個人不一定有效（講義也有這句）。
