## 1. 研究設計總覽 ⭐⭐

- **縱斷研究（longitudinal）**：暴露和疾病**不在同一時間**收集。
  - **前瞻性設計** → **prospective（concurrent）cohort**：研究開始時確定暴露，往未來追蹤疾病。
  - **回溯性設計** → **retrospective（non-concurrent）cohort**：從過去紀錄確定暴露，追蹤期已經發生。
  - **病例對照研究**：從疾病（case／control）出發，**回頭**問過去暴露。
- **橫斷研究**：暴露和疾病**同一時間**收集（上週）。
- 老師：台灣講「**世代研究**」（中國、AI 講「隊列研究」），**考試只會出現世代研究**；英文**考卷只寫 prospective**，不會一直換用 concurrent、longitudinal 等同義詞。

## 2. 世代研究（cohort study）⭐⭐⭐

### 什麼是 cohort

- **一群分享共同經驗的人**：同年出生（**birth cohort**，例如 1990 年後出生的人有打水痘疫苗）、共同行為（吸菸者）、同一工廠員工、同年入學的同學。
- **世代研究**：把**沒有疾病**的人依**暴露**分成暴露組與非暴露組，**往後追蹤**，比較兩組**疾病的發生率**。

### 三種世代研究

| 類型 | 研究開始時 | 例子 |
|---|---|---|
| **前瞻性（prospective／concurrent）** | 開始時確定暴露，**往未來**追蹤新病例 | 8,000 人（3,000 吸菸、5,000 不吸菸）、基線無心臟病，追蹤 CHD |
| **回溯性（retrospective／non-concurrent／historical）** | 從**過去紀錄**確定暴露，疾病從過去追到現在（**追蹤期已經發生**） | 1978 年調閱 1945–1965 年接受不孕症治療的婦女，依荷爾蒙異常與否追蹤乳癌 |
| **雙向（ambidirectional）** | 從過去紀錄確定 cohort 與暴露，追到現在，**再往未來追蹤** | 1993–1994 年出生的 2,000 名兒童，出生時收案追到 5 歲認知發展，並回溯孕期空汙暴露；最常見於孕產婦／出生世代 |

- **前瞻 vs 回溯**：都比較暴露與非暴露族群，差別只在**日曆時間**。前瞻性**貴、費時**；回溯性解決這個問題，但**依賴既有紀錄（可能不完整、不準確）**。
- 例子：**Framingham Heart Study**（1948 年，5,000 多名無 CVD 的成人，依吸菸、肥胖、高血壓等分組，每 2 年檢查一次、追蹤 20 年）；西班牙 **INMA** 出生世代（孕 10–13 週收案）。

### 研究族群與比較組

- **一般族群**（如 Framingham）：結果**外推性高**；但貴、耗人力、容易**失訪**。
- **特殊族群**（如 Nurses' Health Study、退伍軍人）：追蹤較容易，外推性較差。
- **特殊暴露族群**：原爆倖存者、職業暴露（化學物質）。
- 比較組：**內部比較（internal，最常見）**＝同一族群中的未暴露者（如 Framingham 低膽固醇 vs 高膽固醇）；**外部比較（external）**＝一般族群資料或其他研究；或兩者合併（少見）。找外部比較組要找**社經地位、居住地、背景暴露相近**的人（如多氯聯苯例找鄰居孩童），增加可比較性。

### 封閉與開放世代（過去考過）

- **Closed cohort（封閉世代）**：一開始就固定的研究族群，**不再加入新成員**，只會因死亡等離開。
- **Open／dynamic cohort（開放／動態世代）**：追蹤期間持續有人**進出**（遷入、出生；遷出、死亡）；C = **censored（刪失）**（遷出、拒絕、失訪）。假設族群處於**穩定狀態**，所以算死亡率時分母用**年中人口**（6/30 或 7/1）。

### 暴露與疾病的測量

- **暴露**：定義、資料來源（訪談、既有紀錄、身體檢查）、**暴露時間點**（相對於發病）、劑量反應（**頻率、強度、持續時間**）、**暴露狀態的改變**（世代研究可以重複測量，例如 Framingham 每兩年重測 BMI）。
- **疾病**：一開始要確定**無病**（排除條件在開始時套用）；結果要明確可測量（誰算新病例）；暴露組與非暴露組**用同樣的程序**；判定疾病時**最好不知道暴露狀態（blinded）**，否則觀察者可能更仔細檢查暴露組。

### 指標 ⭐⭐⭐

- **Risk（cumulative incidence 累積發生率、incidence proportion 發病比）**＝追蹤期間新病例數 ÷ 基線的族群人數。分母是人數；**比例，0–1**；用在**封閉世代**。
- **Incidence rate（發生比率，incidence density 發生密度）**＝新病例數 ÷ **人時（person-time，風險時間）**。**率，單位 time⁻¹，0–∞**；開放或封閉世代都可以。
- **Relative risk**：**risk ratio（RR）**或 **incidence rate ratio（IRR）**＝暴露組 ÷ 非暴露組。

| | 疾病 D | 無病 D̄ | 合計 |
|---|---|---|---|
| 暴露 E | a | b | a + b |
| 非暴露 Ē | c | d | c + d |

$$RR = \frac{a/(a+b)}{c/(c+d)}$$

- **Framingham 例題**（追蹤 18 年）：高血壓 90/493 = **0.183**；非高血壓 70/1271 = **0.055**；**RR = 3.327**。
  - 解釋要完整：「**經過 18 年追蹤，佛萊明罕參與者中有高血壓者發生心血管疾病的危險性是非高血壓者的 3.327 倍**」——老師：**只寫「3.327 倍」沒辦法給分**，要寫出暴露、疾病、追蹤時間。
- **RR = 1** 無相關；**> 1** 正相關（危險因子）；**< 1** 負相關（保護因子）。

### 優缺點 ⭐⭐

| 優點 | 限制 |
|---|---|
| **時序明確**（暴露在前、疾病在後） | 開始時要無病，但疾病可能已開始、只是還沒被偵測 |
| **一個暴露可以看多種結果** | **貴、費時**，限制可行性 |
| 暴露的測量偏差小，**不會受結果影響** | **失訪（loss to follow-up）** |
| 容易評估危險因子的改變 | **不適合罕見疾病**；需要非常大的樣本 |
| **可以直接算發生率** | |

- 台灣例子：**多氯聯苯（PCB）油症**（1979 年米糠油事件）的先天中毒兒童世代（Rogan et al., Science 1988），外部比較組是配對的鄰居孩童，用兒童行為檢核表（CBCL）評估。

## 3. 病例對照研究（case-control study）⭐⭐⭐

- **依疾病狀態選研究族群**：從**有病的人（cases）**和**沒病的人（controls）**出發，**比較兩組過去暴露的勝算（odds）**。
- 例：兒童白內障與孕期德國麻疹病毒暴露——case 是有白內障的兒童，control 是沒有的，回問母親懷孕時是否感染德國麻疹。

### 病例的選擇

- 選 case 時**不能知道（不參考）其暴露史**。
- **診斷標準**明確、客觀、標準化，得到一致的病例群（例：早產 = 以第一孕期超音波頭臀長推算 < 37 週）；**納入／排除條件**明確，且對 case 和 control **同樣套用**。
- **盛行病例（prevalent）vs 新發病例（incident）**：盡量用**新發病例**——
  - 減少**存活／病程**的影響（盛行病例會受存活長短影響）；
  - 診斷標準一致（ICD 定義會隨年代改變）；
  - 對暴露的**回憶較好**。
- 病例來源：
  - **醫院**：容易、便宜、受試意願高；但病例可能有偏差（轉診模式），只適合通常會住院的疾病。
  - **社區／族群**（或用**登記資料**，如癌症登記）：代表性好；但貴、費時，沒有登記檔很難做（台灣癌登檔無法連結到個人）。

### 對照的選擇 ⭐⭐

- **最大原則：case 從哪裡來，control 就從哪裡來**——control 要代表**產生 case 的同一來源族群（source population）**的暴露頻率，用和 case 相同的方式選。
  - 例：在台北市以**全市癌症登記**找扁桃腺切除與淋巴瘤的 case → control 也要從**全市**選。
- Control **沒有疾病**、選取時**不知道暴露史**；case 的排除條件也套用到 control。
- **醫院對照**：同一院所因**無關疾病**就醫的人；要排除和暴露相關的疾病（研究吸菸與心肌梗塞時不能用肺氣腫病人當 control）。優點：容易找、經濟；缺點：**選樣偏差**、外推性差。
- **社區對照**：一般族群隨機樣本（如**隨機撥號 random-digit dialing**）；代表性高、可算族群暴露率；但貴、回應率低。
- **多組對照**：每組控制不同的偏差（例：兒童腦瘤與輻射暴露同時用「其他實體腫瘤的病童（sick controls）」和「同出生世代的健康兒童」評估**回憶偏差**）；優點：內部重複、評估偏差；缺點：貴、結果可能不一致。

### 暴露的測量

- 暴露必須在**發病之前**；來源：訪談、病歷、就業紀錄、藥局或檢驗紀錄、直接測量。
- 例：腎細胞癌與降血壓藥，查閱診斷前三個月以前的門診、住院病歷。

### 指標：odds 與 odds ratio ⭐⭐⭐

- **Odds（勝算）**＝事件發生機率 ÷ 不發生機率 = P / (1 − P)。
  - 例：100 位慢性咳嗽病人中 60 位抽菸 → 抽菸的勝算 = 0.6 / 0.4 = **1.5**（**和比例 0.6 不一樣**）。
- **Odds ratio（OR，勝算比／危險對比值）**＝**case 的暴露勝算 ÷ control 的暴露勝算**：

$$OR = \frac{a/c}{b/d} = \frac{ad}{bc}$$

- **病例對照研究只能算 OR，不能算 RR**：研究組是依疾病選的、不是依暴露，**無法算發生率**。設計良好時（且疾病罕見），OR 是 RR 的好近似。
- **肺癌與吸菸例題**：case 647 抽菸／2 不抽；control 622／27 → case 勝算 323.50、control 23.04 → **OR = (647 × 27) / (622 × 2) = 14.04**。
  - 解釋：「**肺癌病人抽菸的勝算是沒有肺癌對照的 14.04 倍**」——比較的是**暴露的勝算**，**不能說「抽菸者得肺癌的機率是 14 倍」**。
- **速算 ad/bc 可以用，但 2×2 表一定要填對**（暴露在列、疾病在行），填錯位置算出來就錯。
- OR = 1 無相關；> 1 正相關；< 1 負相關（保護）。

### 配對（matching）⭐⭐

- 選 control 時讓它和 case 在**可能的干擾因子（confounder）**上相似（年齡、性別、種族、社經地位），是處理干擾的方法之一。
- **個別配對（individual／pair matching）**：每個 case 配一個或多個 control（例：67 歲白人男性 MI 病人 → 配 62–72 歲、白人、男性、沒有 MI 的人）。
- **頻率配對（frequency matching）**：讓 control 組在配對變項上的**分布**和 case 組相同（例如年齡、性別比例一樣），不需要一對一。
- 課本或其他老師會寫「配對」或「匹配」，都是 matching。
- **配對資料的 OR 只看不一致的配對（discordant pairs）**：

| | Control 暴露 | Control 未暴露 |
|---|---|---|
| **Case 暴露** | 一致（不提供資訊） | **b：case 暴露、control 未暴露（支持假說）** |
| **Case 未暴露** | **c：case 未暴露、control 暴露（不支持）** | 一致（不提供資訊） |

$$OR_{matched} = \frac{b}{c}$$

- **例題（出生體重 ≥ 8 磅與兒童腦瘤，依性別配對，71 對）**：兩者都暴露 8 對、case 暴露 control 未暴露 **18** 對、case 未暴露 control 暴露 **7** 對、都未暴露 38 對 → **OR = 18/7 = 2.57**。每一格是**配對數**，不能拿一般 2×2 表的方法算。

### 優缺點 ⭐⭐

| 優點 | 限制 |
|---|---|
| 比世代研究**快、便宜** | 偏差來源比世代研究多 |
| **適合罕見疾病**、**潛伏期長**的疾病 | 選 control 的**選樣偏差** |
| 需要的人數較少 | 回問暴露的**回憶偏差（recall bias）** |
| **可同時評估多個病因（暴露）** | **時序**問題（是暴露造成疾病，還是疾病造成暴露？） |
| | 適當的 control 很難找 |

## 4. 世代 vs 病例對照

| | 世代研究 | 病例對照研究 |
|---|---|---|
| 出發點 | **暴露**（無病的人依暴露分組） | **疾病**（case vs control） |
| 方向 | 往後追蹤疾病 | 回頭問暴露 |
| 指標 | **Risk、incidence rate、RR、IRR** | **Odds、OR**（不能算發生率） |
| 適合 | **罕見暴露**、一個暴露多種結果 | **罕見疾病**、潛伏期長、一種疾病多個暴露 |
| 時序 | 明確 | 可能不明 |
| 成本 | 高、費時、失訪 | 較低、較快 |
| 主要偏差 | 失訪、判定結果時知道暴露 | 選樣偏差、回憶偏差 |

## 🎙️ 上課錄影重點（陳偉仁，2026/11/20）

- **上週練習題檢討**：第 1 題錯在「推論到個人層次」（生態研究不能推論到個人）；第 5 題結論仍停在州的層次、**沒有推論到個人就不構成生態謬誤**（答「是」，沒構成）。補講上週沒講完的：橫斷研究抓到的是**盛行病例**，受發生率與病程影響。
- **用詞**：考試只會出現「**世代研究**」；英文考卷只寫 **prospective**，不會一直換同義詞。
- **Cohort** 的例子：不同出生年有不同的疫苗經驗（1990 年後出生的人打過水痘疫苗）；「你們同一年入學就是一個 cohort」。
- **三種世代研究**：前瞻性一開始納入的一定是**沒有要觀察的疾病**的人；**雙向世代最常見於孕產婦研究**（出生時收案、往前回溯孕期暴露、再往後追蹤）。
- **比較組**：課程與考試主要是 **internal comparison**；external 要找背景相近的人（PCB 例找**鄰居**孩童，不會在彰化婦女的研究裡找台北市婦女當對照），增加可比較性。
- **封閉 vs 開放世代**：「**過去考試考過**，不知道會不會再考」；動態世代假設遷入遷出、出生死亡平衡，所以算台北市死亡率時**分母用年中人口**（內政部 6/30 或 7/1）。
- **暴露測量**：不只問有沒有抽菸，要問開始抽的年齡、有沒有戒菸、戒了幾歲到幾歲 → 建立詳盡的暴露史；世代研究可以**測量暴露的改變**（Framingham 每兩年重測 BMI）。判定疾病時**觀察者不可以知道暴露狀態**。
- **Risk vs rate**：累積發生率算的是**人數**、0–1、用在**封閉世代**；發生比率的分母是**人時**、0–∞。RR 的詳細陷阱「**下週講**」。
- **期末考時間**：「**12 月 21 日早上九點到十點二十**」（多考十分鐘），因為 12/25 是假日才排在這個時間；座位表教務處會公布。
- **RR 的解釋要完整**：「經過十八年追蹤，佛萊明罕參與者中有高血壓者的心血管疾病危險性是非高血壓者的 3.327 倍」，「**如果你只跟我說 3.327 倍，我真的沒辦法給分**」；寫得越詳盡越容易給分。
- **世代研究適合「一個暴露因子、多個疾病」**；時序足夠，偏差程度相對最小（除非設計或判定結果時有偏差）。
- **病例選擇**：最希望找**新發病例**（受疾病因素影響最少、ICD-9 → ICD-10 定義會改變、回憶較正確），實務上很少找已經得病一段時間的病例。醫院病例：病人想知道自己的病因，參與意願高、方便；但不知道他為什麼來這家醫院。台灣癌登檔不能連結到個人，國外私人保險資料反而比較容易找到人。
- **對照選擇**：「**你的 case 從哪裡來，你的 control 就從哪裡來**」——case 從北醫附醫收，control 也要從北醫附醫收。
- **Odds 和比例不一樣**：60/100 抽菸 → 比例 0.6、**勝算 1.5**。**病例對照只能算 OR，不可以算 RR**。中文「勝算比」或「危險對比值」看出題老師用哪個，期末兩個都可能出現。
- **速算 ad/bc** 可以用，但「**表格一定要填對**」，暴露和疾病填錯位置就算錯。
- **OR 的解釋**：「**肺癌病人抽菸的勝算是沒有肺癌對照的 14.04 倍**」——比較的是暴露的勝算，「**不可以說抽菸比沒抽菸的疾病發生是幾倍**」。
- **配對**：個別配對（一個 case 配一或兩個 control）與**頻率配對**；「配對」「匹配」是同一件事。**配對 OR 只看 discordant pairs**：依研究假設，**case 暴露、control 未暴露的放分子**，相反的放分母 → 2.57；一致的配對不提供資訊。
- **病例對照的優點**：「相對於**世代研究**」省錢省時（不一定比橫斷研究省）、適合**稀有疾病**、人數少；缺點：回憶偏差等，**最後一週講偏差**時再詳細說。
- 每週都有練習題，記得作答；最後兩頁是課本的比較表，自己看。

# 考點分析

## 🔥 高頻考點（百十三 114 期末考古）

- **選研究設計**：低發生率、誘導期長、危險因子很普遍 → **病例對照**（114 期末 1）；出生收案、多次測血鉛、10 歲評估發展 → **前瞻性世代**（114 期末 3）。
- **病例對照最有利的情況：常見暴露、罕見疾病**（114 期末 6）。
- **前瞻性世代的「非」優點：通常比病例對照便宜**（錯，世代研究比較貴；114 期末 7）。
- **世代研究不需要考慮的事**：「研究開始時很難找到足夠的肝癌病人」——那是病例對照的問題（114 期末 5）。
- **OR 近似 RR：結果（疾病）罕見時**（114 期末 9）。
- **病例對照用郵寄問卷問孕期用藥 → 回憶偏差**（114 期末 21）。
- **納入盛行病例**：飲酒者存活較差，盛行病例中飲酒者被低估 → **OR 變小**（114 期末 22）。
- **IRR 計算**：死亡數 ÷ 人年，兩組相除（114 期末 32）。
- 計算題（期末會有）：**RR、IRR、OR、配對 OR**，並寫出完整的解釋。

## 📝 出題模式

- 給研究描述 → 判斷設計（前瞻／回溯／雙向世代、病例對照、橫斷、生態、病例交叉等）。
- 「下列何者不是某設計的優點／何者最適合用某設計」。
- 給 2×2 表或配對表 → 算 RR、IRR、OR、matched OR。
- 給研究情境 → 問可能的偏差（回憶偏差、選樣偏差、Berkson's bias；後續章節）。

## ⚠️ 陷阱整理

| ✗ 錯誤說法 | ✓ 正確 |
|---|---|
| 病例對照研究可以算 RR | 只能算 **OR**（無法算發生率） |
| OR 表示暴露者得病的機率是幾倍 | OR 是 **case 與 control 的暴露勝算比** |
| Odds = 比例 | Odds = P/(1 − P)；60/100 → 0.6 vs 1.5 |
| 世代研究適合罕見疾病 | 適合**罕見暴露**；罕見疾病用**病例對照** |
| 世代研究比病例對照便宜 | 世代研究**貴、費時** |
| 回溯性世代研究就是病例對照研究 | 回溯性世代仍**從暴露出發**、只是追蹤期已經發生 |
| 配對 OR 用 ad/bc | 用**不一致配對 b/c** |
| Case 用盛行病例比較好 | 盡量用**新發病例** |
| Control 從方便的地方找就好 | 要和 case 來自**同一來源族群** |
| Cumulative incidence 的分母是人時 | CI 的分母是**人數**；incidence rate 才是**人時** |
