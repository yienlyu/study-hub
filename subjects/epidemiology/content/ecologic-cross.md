## 1. 分析性流行病學與研究設計 ⭐⭐

- 前六週的描述性流病回答 **What／Who／When／Where**；分析性流行病學要回答 **Why／How**——找出暴露（因）與健康結果（果）的**因果關係（etiology）**，靠**因果推論**。
- 研究設計分類：

| | 有沒有比較組 | 目的 | 例子 |
| --- | --- | --- | --- |
| 觀察性研究（無比較組） | 沒有 | **產生假說**（hypothesis generating） | 病例報告、描述性研究 |
| 觀察性研究（有比較組） | 有 | **檢驗假說**（hypothesis testing） | 世代、病例對照、橫斷、生態 |
| 實驗性研究 | 有，**研究者介入** | 檢驗假說 | 隨機臨床試驗（RCT） |

- 有隨機分派＝RCT；**沒有隨機分派**、觀察自然發生的差異＝世代研究（追蹤一群人看誰發病）、病例對照研究（比較有病與沒病的人）、橫斷研究（同一時間對不同群體觀察比較）。
- 選擇研究設計的考量：**研究問題、對問題已知的資訊、實際情況（時間、經費）、研究倫理**。

## 2. 生態研究（ecologic study） ⭐⭐⭐

### 定義與分析單位
- 研究暴露與疾病的關聯，但**分析單位是「群體」**（不是個人），通常依**地理區域**分組（郡、州、國家），也可以依**時間**分組（生態趨勢研究，比較偏描述性）。
- 資料是**人口層級**：平均值、比例、率；**沒有個人的暴露與疾病資料**。
  - 例：美國各州**人均香菸消費量** vs **冠狀動脈心臟病死亡率**（每一點是一州）。
- **判斷題型**（講義例題）：
  - 各郡空氣污染排放密度與全死因死亡率做 Pearson correlation → **生態研究**（分析單位是郡、資料是平均值）。
  - Nurses' Health Study 收集每位護理師的出生地、15、30 歲居住州，追蹤 Crohn's disease／UC，用 Cox 模型算 HR → **不是**生態研究（有個人層級資料，是世代研究）。

### 2×2 表（老師：暴露擺左邊！）

| | 有病 $D$ | 沒病 $\bar D$ | 合計 |
| --- | --- | --- | --- |
| **暴露 $E$** | $a$ | $b$ | $a+b$ |
| **未暴露 $\bar E$** | $c$ | $d$ | $c+d$ |
| 合計 | $a+c$ | $b+d$ | $a+b+c+d$ |

- 🎙️「不管以後算任何暴露與疾病關聯指標，都要先畫二乘二表，**暴露擺列（左邊）、疾病擺行**；要用速算法的話 a、b、c、d 一定要擺對。」
- **生態研究填不出 a、b、c、d**：只知道各群體**暴露的頻率**與**疾病的頻率**（邊際），**不知道個人層級的聯合分布**。

### 關聯指標
- **相關係數 $r$**（常配散佈圖）：衡量**線性相關的方向與強度**。

$$r = \frac{\operatorname{Cov}(X,Y)}{S_X S_Y} = \frac{\sum (x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum (x_i-\bar x)^2}\sqrt{\sum (y_i-\bar y)^2}}$$

  - 介於 $-1$ 與 $+1$；$r \approx 0$ 無線性相關、$r < 0$ 負相關（inverse）、$r > 0$ 正相關（direct）；越接近 $\pm1$ 越強。
  - **標準化過 → 沒有單位**；只說明「同向或反向」，**不代表因果方向**。
- **迴歸係數 $\beta$**（線性迴歸 $y = \beta_0 + \beta_1 x$，最小平方法）：$X$ 每增加一單位，$Y$ 平均改變 $\beta_1$。
  - **有方向性**、**有單位**（可用真實單位解釋，例：「綠地增加 1% → 死亡率下降 0.3／10 萬人」）。
  - **$r$ 與 $\beta$ 同號**（$\beta = 0 \Rightarrow r = 0$），但**大小不能互相比較**（$r$ 無單位、$\beta$ 有單位）。
  - 🎙️ 迴歸的公式「只是給大家看，不會考」；但生統也會出現在國考，要留意。

### 案例：費城綠地形態與社區死亡率（Lancet Planet Health 2019）
- 2008 年高解析度土地覆蓋資料，算綠地的**綠意程度、破碎度、連結度、聚集度、形狀**等景觀指標；分析 2006 年 **369 個 census tracts**（每區 2,500–8,000 人）的全死因與特定死因死亡率，用 **negative binomial regression**。
- 結果：**綠地越多、死亡率越低（負相關）**；依族群特徵分層後斜率仍為負，但**年齡、教育**等族群特徵會影響斜率，需要調整。

### 什麼時候用、優缺點

- **使用時機**：在群體層級**初步看**暴露與疾病可能有關（**產生假說**）；**只有群體資料**；暴露**只在群體層級變化**（同一群體內個人沒有差異，例：地區平均收入、飲用水含氟量、城市綠覆率）。
- **優點**：用**現有資料**（死亡率最常用，其次是癌症發生）；**不用接觸個人**（不必問卷、追蹤、收案）；**快、便宜**；適合產生病因假說，歷史例子：**1920 人均收入與癩皮病（pellagra）、1938 飲水含氟與蛀牙、1964 吸菸與肺癌**；研究**生態層級暴露**時不可或缺。
- **限制**：
  1. **生態謬誤（ecologic fallacy）**：用群體資料推論個人。
  2. 群體資料通常沒有其他相關變項 → **無法控制混雜因子**。
  3. **不能建立因果關係**（證據很弱：沒有個人資料、時序不清）。

### 生態謬誤 ⭐⭐⭐（🎙️「很重要的 term，請大家要記得」）
- 定義：**用群體層級的資料，對個人層級的關係做出不恰當的結論**；沒有區分「族群之間的相關」與「個人之間的相關」。
- 例：群體層級看起來結果與暴露**正相關**，但在每個群體**內部**看，個人層級卻是**負相關**。
- 講義另舉 Berg et al.（Sci Adv 2020）的例子，以及 $r_s = -0.28$ 的散佈圖練習：先判斷研究設計、能不能說是因果、有什麼限制。

## 3. 橫斷研究（cross-sectional study） ⭐⭐⭐

### 「時間」決定設計

| | 暴露與疾病資料的蒐集 | 例子 |
| --- | --- | --- |
| **橫斷研究**（cross-sectional，又稱 **prevalence study**） | **同一時間** | 國民營養健康調查、NHANES |
| 縱斷研究：前瞻性 | 先確認暴露 → 隨時間觀察發病、比較發生率 | **世代研究**（同期性／非同期性追蹤） |
| 縱斷研究：回溯性 | 先確認有病／沒病 → 回問過去暴露 | **病例對照研究** |

### 特徵與用途
- 像一張**快照（snapshot）**：在**同一時間點**看個人身上暴露與結果是否**共存**；**在個人層級**測量暴露與疾病（這點和生態研究不同）。
- 找到的是**盛行病例（prevalent cases）**＝新發生病例＋既存病例。
- 適合**慢性病**（臨床前期長、病程長）；**不適合罕見疾病或病程很短的疾病**。
- 常抽樣一般族群 → **可推論性（generalizability）好**；用來估計健康問題的**規模與分布（盛行比例）**、**產生假說**、**規劃介入**。
- 研究族群可依特定特徵選（例：只收 Hispanic 族群，比較冠心病與 CRP 的盛行率）。
- 暴露評估：問卷（吸菸、職業、用藥）、紀錄、實驗室檢驗（血鉛）、身體測量（血壓、BMI）、特殊程序（頭髮檢體等）；疾病評估：問卷／病歷、理學檢查、特殊檢查（DXA 骨密度）、**明確的診斷標準**（可分 definite／probable／possible 或依嚴重度）。

### 關聯指標：盛行率比（PPR）⭐⭐⭐

| | 糖尿病 $D$ | 非糖尿病 $\bar D$ | 合計 |
| --- | --- | --- | --- |
| 高戴奧辛 $E$ | 80 | 120 | 200 |
| 低戴奧辛 $\bar E$ | 60 | 340 | 400 |
| 合計 | 140 | 460 | 600 |

（越戰 Agent Orange 退伍軍人，600 位 50 歲以上受試者）

- **疾病中的暴露盛行率**：糖尿病者 $\frac{a}{a+c} = \frac{80}{140} = 57\%$ 高戴奧辛；非糖尿病者 $\frac{b}{b+d} = \frac{120}{460} = 26\%$；總體 $\frac{200}{600} = 33\%$。
- **暴露中的疾病盛行率**（🎙️「大家基本上記得黃色這部分即可」）：暴露組 $\frac{a}{a+b} = \frac{80}{200} = 0.40$、非暴露組 $\frac{c}{c+d} = \frac{60}{400} = 0.15$、總體 $\frac{140}{600} = 23\%$。

$$\text{PPR（盛行率比）} = \frac{a/(a+b)}{c/(c+d)} = \frac{0.40}{0.15} = 2.67$$

- 解釋：**高血清戴奧辛者的糖尿病「盛行率」是低濃度者的 2.67 倍**。🎙️ 一定要說清楚比較的是**盛行率**（因為是橫斷研究），不是發生率、不是風險。
- 橫斷研究同時可以算**疾病**與**暴露**的盛行率（同一時間點），但多數研究比較的是「有暴露 vs 沒暴露的疾病盛行率」。

### 優點
- 若是一般族群的**隨機樣本** → 可估計**整個族群的盛行率**（例：中和區居民使用 NSAIDs 的盛行率是多少？）。
- 初步檢查暴露與疾病的關聯（**產生假說**）。
- 時間短、成本低；**不用等待、不用追蹤、沒有追蹤流失**。

### 限制 ⭐⭐⭐
1. **不能建立因果關係**。
2. **無法確定時間順序（temporality）**——**例外：暴露是永久不變的因素**（例：性別、基因型、血型）。
3. **盛行病例造成推論偏差**：盛行病例同時反映**發生率（病因）**與**病程（存活）**：$P \approx I \times D$（🎙️「完整公式很長，記得 $P = I \times D$ 就好」）。
   - **存活偏差（survival bias）**：只在一個時間點評估，**病程中已經死亡的人沒機會被納入**。
   - 已緩解或治療過的病例可能被漏掉。
4. 不適合罕見疾病或病程很短的疾病。

### 經典問題一：時序（工作轉換）

| | 時間點 X（還沒換工作） | 時間點 Y（10 位 A 工人因病轉到 B） |
| --- | --- | --- |
| Job A（危險）盛行率 | $20/100 = 20\%$ | $10/90 = 11\%$ |
| Job B（安全）盛行率 | $5/100 = 5\%$ | $15/110 = 14\%$ |
| PPR（A／B） | **4.0** | **0.8** |

- 在時間點 Y 做橫斷研究，**危險工作看起來反而比較安全**：生病的人因病轉到安全工作 → A 的盛行率被低估、B 被高估。
- 橫斷研究只知道**現在**的暴露，不知道**過去**的暴露；而暴露的改變又**和結果有關**。這也是 **healthy worker effect（自我選擇偏差）**：身體好的人留在危險職業，身體差的人轉到安全職業。

### 經典問題二：盛行／發生偏差（NSAIDs 與失智症）
- 橫斷研究發現**使用 NSAIDs 者失智症盛行率較低**，可能是：
  1. NSAIDs 真的**預防失智症發生**（影響病因、發生率）；或
  2. **用 NSAIDs 的失智症患者比較容易死亡**（影響存活、病程）→ 讓 NSAIDs 看起來有保護效果。
- 盛行率比混合了發生與存活，無法分辨是哪一種（老師說下週再詳細講）。

## 4. 生態研究 vs 橫斷研究

| | 生態研究 | 橫斷研究 |
| --- | --- | --- |
| 分析單位 | **群體**（地區、時間） | **個人** |
| 資料 | 人口層級的平均值、比例、率 | 每個人的暴露與疾病狀態 |
| 能否填 2×2 表 | **不能** | **能** |
| 關聯指標 | 相關係數 $r$、迴歸係數 $\beta$ | **盛行率比（PPR）** |
| 主要謬誤／偏差 | **生態謬誤**、無法控制混雜 | **時序不明**、**存活偏差**（盛行病例） |
| 共同點 | 快、便宜、**產生假說**、**不能建立因果** | 同左 |

- **盛行率比的解釋**：「要記得我們這時候比較的是**盛行率**——因為是橫斷研究——所以要跟人家說你比較的是盛行率。」疾病中的暴露、暴露中的疾病兩種都能算，「**基本上記得黃色這部分（暴露組 vs 非暴露組的疾病盛行率）即可**」。
- $P = I \times D$：「完整公式蠻長的，這邊大家只要記得 $P = I \times D$ 就好」；既存病例要活得夠久才會被抓到 → **存活偏差**，量到的常是「為什麼活到現在」而不是病因。
- 工作轉換例：身體好的人留在危險職業、身體差的轉到安全職業 → **健康工人效應很常發生**；在不同時間點做橫斷研究會量到不同結果。
- NSAIDs 與失智症的例子**留到下週（11/20）再講**。

# 考點分析

## 🔥 高頻考點（百十三 114 期末考古）

- **研究設計判斷**：題組描述「某城市各里（village）的綠地、全死因死亡率與社經資料」→ **生態研究**（114 期末 28）。
- **為什麼用生態研究**：**暴露在地理單位之間差異很大、在個人之間差異很小**（114 期末 30）。
- **橫斷研究的特徵**：**不適合罕見疾病或病程短的疾病**（114 期末 2）；陷阱選項：「在地理單位測量」（那是生態研究）、「病例是發生病例」（應是盛行病例）、「可建立強因果」、「暴露與結果在不同時間點測量」。
- 分層後斜率不同 → **異質性、可能有效應修飾**（114 期末 29）。

## 🎙️ 老師課堂提示

- 期末考**一定有計算題**：PPR、2×2 表的各種盛行率都要會算，解釋時要寫「盛行率」。
- 生態謬誤是必記名詞。
- 迴歸公式不考，但相關係數與迴歸係數的**性質比較**（有無單位、方向、同號）是好出題的地方。

## 📝 出題模式

- 給一段研究摘要 → 問研究設計（分析單位是群體 → 生態；同一時間點、個人層級 → 橫斷；先有暴露再追蹤 → 世代；先有病再回問 → 病例對照）。
- 給 2×2 表 → 算 PPR 或各種盛行率，並選正確的解釋。
- 「下列何者是限制／優點」：生態 → 生態謬誤、不能控制混雜；橫斷 → 時序不明、存活偏差。

## ⚠️ 陷阱整理

- 生態研究**沒有**個人層級資料 → 不能填 a、b、c、d、不能算 PPR／RR／OR。
- 橫斷研究**有**個人層級資料，但只有一個時間點 → 能算盛行率比，**不能算發生率、不能說風險**。
- $r$ 沒有單位、$\beta$ 有單位；兩者同號，但 $|r|$ 大不代表 $|\beta|$ 大。
- 「暴露是永久因素（性別、基因）」時，橫斷研究的時序問題可以排除。
- 盛行率較低不一定是保護作用，可能是有暴露的病人**死得比較快**（NSAIDs 例）。
