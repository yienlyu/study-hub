## 1. 臨床試驗的歷史 ⭐

- **1537 Paré**（首次、非計畫性）：戰地標準做法是用煮沸的油燙傷口；油不夠時改用蛋黃、玫瑰油、松脂，記錄預後後發現和用油差不多。
- **1747 Lind**（首次有計畫）：船醫認為海上食物和陸上不同，讓船員航海超過 3 個月後不適。把 12 名船員平分成 6 組，**對照組喝海水**，**柳橙汁與檸檬汁**組改善最多 → 帶動維他命 C 與**壞血病（scurvy）**研究。
- **Galton**（臨床試驗之父）：重視研究設計與統計，提出**兩組比較**（自己祈禱 vs 別人代為祈禱 → 自己祈禱的痊癒較好）。講義另提 Galton 的 **regression to the mean**。
- **1965 Joyce & Welldon**：提出**雙盲**，避免醫師差別對待兩組 → 兩組療效差不多。
- **1988 Byrd**：提出**隨機**，保證兩組其他條件相同 → 心肌梗塞病人中自己祈禱的一組較好。

## 2. RCT 設計與研究個案的分配 ⭐⭐⭐

- 1988 年後，新治療、藥物、醫材基本上都用 RCT 評估，評估指標是上一章的**預後指標（prognosis measures）**。
- 研究對象分兩種：**社區試驗（community-based trial）**（先在一個社區實施再比較，例：飲水加氟是否降低齲齒率）與**臨床試驗（clinical trial）**（在臨床環境對病人進行）。
- **選取研究個案**：明確的納入與排除標準（最好有 protocol）；能客觀執行、可複製（常跨院、跨區）；保有**外推性**（不排除特定族群）；符合醫學倫理與研究效率；醫病雙方都能接受；對病人利大於弊。

**分配方式**：先分「有沒有隨機」；沒有隨機的再分「有沒有比較」；有比較的再分「同步」與「非同步（歷史）」對照。

| 分配方式                         | 做法                                                                                     | 問題                                                                                  |
| -------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| **無比較研究**                   | 全部都是實驗組，以其他學者的經驗資料當作默認對照；多為 case study、case series            | 不符合 Galton 的「**可比性**」，不算好研究                                            |
| **歷史對照**（noncurrent）       | 同一主治醫師的過去病歷；電子病歷資料庫（例：健保資料庫）                                 | **歷史偏差**：醫療品質、診療方法、病人生活型態、量表**學習效應**隨時間改變             |
| **同步非隨機對照**（simultaneous） | **時間配對**（同時間、不同醫師的病人，用同一台機器測）；**背景因素配對**（年齡、性別相同） | 優點：比隨機省錢省力、可減少歷史偏差；缺點：**分派方式可預期** → 研究者分派時產生偏差 |
| **隨機分派**                     | 丟銅板、亂數表、事先算好機率用信封或清單密封；**醫療人員沒有選擇權**                     | 避免歷史偏差、選擇偏差與無法測量的背景差異                                            |

- 講義補充：無比較研究最常見的是**無對照前後比較（uncontrolled before-after study）**，只適合評估短期功效。
- **疫苗例（同步非隨機）**：依是否打疫苗分兩組 → 對照組死亡率高。但研究者傾向把配合度高的孩童分到疫苗組，這些家長也比較注重健康、定期就醫 → 肺結核死亡率低可能不是疫苗造成。**改良**：孩童輪流施打、未打者當對照 → 兩組死亡率相近。
- **心律不整例（隨機 vs 非隨機）**：無心律不整病人的 CFR 10%、有心律不整的 50%。**有隨機**（II）兩組的無／有比例都維持 **13：7** → 新藥對 CFR 沒有影響；**沒有隨機**（I）醫師把新藥開給低風險病人，高風險病人用自己較能掌握的傳統治療 → 造成新藥 CFR 較低的假象。
- **固定機率隨機**：整個研究期間介入組與對照組的比例固定。
- **非固定機率隨機**：依已收個案的分布、個案死亡情形調整分派機率。例：某癌症病人平均只活 3 個月，新藥讓病人至少活 1 年 → 用固定機率的話，第 6–12 個月幾乎沒有對照組可比。
- **分層隨機（stratified randomization）**：先依特定因素分層、再隨機分派，讓兩組人數充足、分布一致，保證想控制的變因相同。例：男女比固定 6：4、分好年齡層後再隨機分給新藥組與傳統治療組。

## 3. 最好的設計：隨機分派盲性同期對照試驗 ⭐⭐⭐

- **randomized blinded concurrent controlled trial**：**隨機＋同期對照**移除兩組潛在的背景誤差，結果只和用新藥或標準治療有關；**隨機＋盲性**讓未知或無法測量的因素在兩組分布均勻；確保統計效力。
- 三要素缺一的後果：

  | 少了       | 後果                                                                                                    | 常見於                 |
  | ---------- | ------------------------------------------------------------------------------------------------------- | ---------------------- |
  | **盲性**   | 無法掌控研究者的主觀干擾                                                                                | **外科處置**試驗       |
  | **隨機**   | 選擇偏差（歷史對照多為**盛行病人**、介入組多為**新發病人**；標準療法無效的病人常被放進介入組）          | 罕見疾病、樣本過小     |
  | **同期對照** | 時間造成的誤差（發生率、診斷方式、儀器改變）                                                          | 想快速知道結果時       |

- **資料收集**：兩組的收集方式與品質要可比——治療（**分配到的治療**、對治療的**遵從性**）、結果（改善與否、副作用）、入組時的整體預後（有沒有干擾因子或危險因子）、執行程序是否平衡（盲性）。
- **盲性**：研究者或受試者不知道用的是真處理還是假處理。

  | 類型     | 不知道分組的人                                    |
  | -------- | ------------------------------------------------- |
  | **單盲** | 僅**受試者**（可減少 lost to follow-up）          |
  | **雙盲** | 受試者＋施測者                                    |
  | **三盲** | 受試者＋施測者＋**資料處理者**                    |

- **Placebo**：外觀、口感、氣味都和真藥一樣的無療效物質；有醫療倫理問題與技術限制 → 現今趨勢是**以標準治療當對照**，但盲性更難做。
- **使用 placebo 不保證盲性**：病人可從副作用猜出組別（aspirin 試驗出血症狀有顯著差異 → 有些試驗併用**質子幫浦抑制劑（PPI）**減輕副作用，讓受試者猜不出來）；維他命 C 感冒試驗**近 8 成猜中**，且「吃維他命 C 卻以為吃安慰劑」的人感冒率比「吃安慰劑卻以為吃維他命 C」的人高 → 心理作用干擾結果。

## 4. 遵從性（Noncompliance）⭐⭐

- 病人同意被隨機分派、也願意用指派的藥，但沒有完成被指派的治療。
- **Coronary Drug Project（clofibrate，五年死亡率）**：

  | 遵從性        | Clofibrate 人數 | 死亡率   | Placebo 人數 | 死亡率   |
  | ------------- | --------------- | -------- | ------------ | -------- |
  | Poor（< 80%） | 357             | 24.6%    | 882          | 28.2%    |
  | Good（≥ 80%） | 708             | 15.0%    | 1,813        | **15.1%** |
  | 全組          | 1,065           | **18.2%** | 2,695       | **19.4%** |

- 只看全組：18.2% vs 19.4%，新藥只好一點點。只看 clofibrate 組：good complier 15.0% 明顯低於 placebo 19.4%。
- ⚠️ 共筆的解讀是「去掉 poor complier 後新藥有效」「poor complier 中 clofibrate 仍比 placebo 低 → 吃一點也有差」。但 **placebo 組的 good complier 死亡率也只有 15.1%**，和 clofibrate good complier 幾乎一樣 → **遵從性本身就和預後有關**，不能只挑 good complier 和全體 placebo 比（Gordis 的結論，考題以此為準）。

## 5. 結果的呈現 ⭐⭐⭐

- **Reduction in risk（treatment efficacy）**：兩組治癒率（或風險）下降或增加的比例，常用 person-time 計算。
  $$\text{Efficacy} = \frac{\lvert R_{\text{placebo}} - R_{\text{treatment}} \rvert}{R_{\text{placebo}}}$$
  - 例：新藥治癒率 60%、安慰劑 10% → $\dfrac{\lvert 0.1 - 0.6 \rvert}{0.1}$ = **5**。
  - 例：新藥 CFR 5%、安慰劑 20% → 共筆與講義都寫 $\dfrac{0.2 - 0.05}{0.05}$ = 3（**分母用了新藥組**）；依公式應為 $\dfrac{0.2 - 0.05}{0.2}$ = **0.75**，即降低 75%。
- **Ratio of risk（relative risk）**
  $$\text{RR} = \frac{R_{\text{treatment}}}{R_{\text{placebo}}}$$
  - 例：得 TB 的人中，打過疫苗者死亡率 0.67%、沒打過 3.30% → RR = $\dfrac{0.67}{3.30}$ ≈ **0.20**。
  - 例：新藥第一年存活率 55%、安慰劑 40% → relative risk to survival = $\dfrac{0.55}{0.4}$ = **1.375**。
- **存活曲線**（Ch6 的 K-M）：例：第三年存活率 15% vs 35% → RR = $\dfrac{15\%}{35\%}$ ≈ **0.43**。
- **ARR**、**RRR**
  $$
  \text{ARR} = \text{CER} - \text{EER}
  \text{RRR} = \frac{\text{CER} - \text{EER}}{\text{CER}}
  $$
- **NNT**：每減少一個不良結果需要治療的人數。
  $$\text{NNT} = \frac{1}{\text{ARR}} = \frac{1}{R_{\text{untreated}} - R_{\text{treated}}}$$
  - 例：clofibrate 18.2% vs placebo 19.4% → $\text{NNT} = \dfrac{1}{0.194 - 0.182}$ ≈ **83.3**，每 83 人用新藥可預防 1 人死亡。
  - 考古：阿司匹靈中風 5% vs 20% → $\text{NNT} = \dfrac{1}{0.15} \approx 6.67$（109）；標靶治療惡化 60% vs 40% → **NNT = 5**（110、114）。
  - RRR 相同時，事件很罕見的 NNT 可能大到不值得治療：干擾素治療 **MS**，CER 50%、EER 39% → ARR 11%、RRR 22%、**NNT = 9**；假設的 trivial case 0.00050% vs 0.00039%，RRR 一樣 22%，但 **NNT = 909,090**，干擾素副作用又很不舒服 → 不值得。共筆與講義文字寫「重症肌無力」，表格寫 MS（多發性硬化症，Gordis 原例），以 MS 為準。

## 6. 外推性（Generalizability）⭐⭐

- Study population 決定結果能外推到誰：外推性越好，未來能用的人越多；**study population 設得越窄，之後能用這個藥的族群越小**。例：COVID-19 疫苗一開始只研究 20–40 歲 → 只能外推到 20–40 歲。
- **內在效度**：哪種人能讓研究有效看到結果（干擾因素少、配合度高）。
- **外在效度**：研究選定的族群決定新治療之後能用在哪些人。講義用 Gordis 的同心圓圖：**參與者 → 合格者 → 目標族群 → 全體族群**，越往外越難外推。

## 7. RCT 的變形 ⭐⭐⭐

- **預期性交叉試驗（planned crossover）**：A、B 階段兩組分別用新藥、舊藥 → C、D 階段互換，中間要**停藥**一段時間避免**殘餘效應（residual carryover）** → E、F 階段可比較同一組人前後、以及同時期不同組。
- **非預期性交叉試驗（unplanned crossover）**：原本沒設計交叉，因受試者拒絕指派治療或病情變化被迫換組（常見於跨科治療，例：手術組拒絕手術要求吃藥、藥物組要求開刀）→ 依原分組分析造成**錯誤分類（misclassification）**；依實際治療分析則**破壞隨機**。
- **因子型設計（factorial）**：同時併用兩種以上治療，常用來看**藥物交互作用**；2×2 表中比較 a+c vs b+d 看 A 的效果、a+b vs c+d 看 B 的效果。例：先隨機分 aspirin／placebo，各組再隨機分 beta-carotene／placebo → 4 組（考古：aspirin × 紅麴）。

## 8. 新藥試驗分期 ⭐⭐⭐

| 分期        | 重點                                                         | 規模       |
| ----------- | ------------------------------------------------------------ | ---------- |
| **Phase 1** | 人體**毒性與藥理**反應（第一次用在人身上，看多少劑量有毒性） | 20–80 人   |
| **Phase 2** | 在 Phase 1 的可用劑量範圍內測**有效性與相對安全性**，找出有效又安全的劑量 | 100–200 人 |
| **Phase 3** | 大型 RCT，**效果與相對安全性** → 完成後可**上市**            | 大型       |
| **Phase 4** | **上市後監測**：大規模使用時臨床試驗看不到的副作用（有些藥上市後下架，或改治其他疾病） | —          |

- 台灣衛福部的分期和美國 FDA 差不多。

## 9. 臨床試驗的優勢與限制 ⭐⭐

- 優勢：**最具證據力**，兼具因果與時序；可依研究問題操控介入、觀察特殊劑量（暴露）；可同時觀察多種健康事件。
- 限制：成本高；有些主題有倫理問題；**外推有限**；**通常只能處理一種介入**（太複雜的介入無法處理）。

| 盲性（p.23–24）                | **單盲**：受試者；**雙盲**：受試者＋施測者（研究醫師、護理師、醫檢、藥師）；**三盲**：再加**資料處理者**。用 **placebo**（看、嚐、聞都像真藥的惰性物質），但**不保證盲性**                                                                                                                                                                                  |
| Planned crossover（p.25–26）   | 兩組先後互換治療；前提是**沒有上一個治療的殘餘效應（residual carryover）**                                                                                                                                                                                                                                                                                  |
| Unplanned crossover（p.27–29） | 「產生大問題」：依**原分派**分析 → **misclassification**；依**實際接受**的治療分析 → **破壞隨機**                                                                                                                                                                                                                                                           |
| Factorial design（p.30–32）    | **同時併用兩種以上治療**；2×2 四格（A+B、只有 A、只有 B、都沒有）可同時看兩個主效果與交互作用                                                                                                                                                                                                                                                               |
| Noncompliance（p.33–34）       | 病人同意被隨機分派、也願意用指派的藥，但**無法完成**被指派的治療                                                                                                                                                                                                                                                                                            |
| 結果呈現（p.35–40）            | 四種：**reduction in risk（treatment efficacy）**、**relative risk**、**survival curves**（Ch6）、**NNT**。例：治癒率 60% vs 10% → efficacy 5；CFR 5% vs 20% → 講義算 3（分母用新藥組，見重點整理第 5 節）；第一年存活 55% vs 40% → RR to survival **1.375**；MS 干擾素 **NNT 9** vs 罕見事件 **NNT 909,090**                                               |
| 外推性（p.41）                 | Gordis 同心圓：研究參與者 → 合格者 → 目標族群 → 全體族群                                                                                                                                                                                                                                                                                                    |
| 新藥分期（p.42–44）            | FDA 標準：**Phase 1** 20–80 人，毒性與藥理；**Phase 2** 100–200 人，efficacy 與相對安全性；**Phase 3** 大型 RCT，effectiveness 與相對安全性；**Phase 4** 上市後監測，看藥物不良反應                                                                                                                                                                         |
| 優勢與限制（p.45）             | 優勢：證據力最強（**因果＋時序**）、可操弄介入與劑量、同時觀察多種健康事件；限制：成本高、倫理問題、**外推有限**、通常**只能處理一種介入**                                                                                                                                                                                                                  |
| 結尾（p.46）                   | 「NOT A JOKE」：陽痿新藥試驗沒人願意參加，因為**每個人都想進介入組** → 倫理與招募也會影響隨機試驗                                                                                                                                                                                                                                                           |

# 考點分析

## 🔥 高頻考點（考古 109、110、114 期中，幾乎每年同題）

- 規劃試驗時**不適當**的技巧：用 single blind 讓「執行試驗者」不知道組別（錯，那是雙盲）。
- **隨機分派不一定 1:1**。
- **雙盲、三盲**的人員組合（三盲 = 病人、照顧醫師、統計分析師）。
- **交叉試驗**的錯誤敘述（可以依變數做分層隨機、要看遵從性與殘餘效應）。
- **aspirin × 紅麴**的主效果與交互作用 → **factorial design**。
- 臨床試驗的「非」優點：**結果適合外推**（錯）。
- **Phase 4** 完成後才能上市（錯，Phase 3 完成就能上市）。
- **NNT** 計算；隨機分派的優點不包括「外在效度增加」（109）。

## 📝 出題模式

- 題目幾乎每年重複，110 與 114 的試驗題幾乎一模一樣。

## ⚠️ 陷阱整理

| 容易選錯                                           | 正確                                                                                                            |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| ✗ 單盲是研究者不知道                                 | ✓ **單盲 = 受試者**不知道；雙盲加施測者；三盲再加資料分析者                                                       |
| ✗ 隨機分派一定要 1:1                                 | ✓ **不一定 1:1**                                                                                                  |
| ✗ 歷史對照可避免選擇偏差                             | ✓ 歷史對照有**歷史偏差**；同步非隨機有**選擇偏差**；隨機分派才能避免                                              |
| ✗ 只分析 good complier 最能看出療效                  | ✓ 遵從性本身與預後有關（Coronary Drug Project：安慰劑 good complier 也較好）                                      |
| ✗ Treatment efficacy 除以治療組（講義 CFR 例算出 3） | ✓ 依 Gordis **÷ 安慰劑組**：(0.20 − 0.05) ÷ 0.20 = **0.75**                                                       |
| ✗ Unplanned crossover 依實際治療分析最準             | ✓ 依原分派 → **misclassification**；依實際治療 → **破壞隨機**                                                     |
| ✗ NNT = 1 ÷ RRR                                      | ✓ **NNT = 1 ÷ ARR**（ARR = CER − EER）                                                                            |
| ✗ RRR 相同 → NNT 相同                                | ✓ 事件率不同時 **NNT 可能差很多**（罕見事件 NNT 很大）                                                            |
| ✗ Relative risk = 安慰劑率 ÷ 治療率                  | ✓ **RR = 治療組率 ÷ 安慰劑組率**；efficacy = (安慰劑 − 治療) ÷ 安慰劑                                             |
| ✗ Crossover 不需要 washout                           | ✓ 預期性交叉要 **washout**，並考慮殘餘效應                                                                        |
| ✗ 因子型設計只能看主效果                             | ✓ 可同時評估**主效果與交互作用**                                                                                  |
| ✗ Phase 2 確認上市                                   | ✓ **Phase 1** 毒性藥理（20–80 人）；**Phase 2** 有效性與劑量；**Phase 3** 大型 RCT → 上市；**Phase 4** 上市後監測 |
| ✗ 內在效度高就能外推                                 | ✓ 外推性是**外在效度**，由研究族群決定                                                                            |
