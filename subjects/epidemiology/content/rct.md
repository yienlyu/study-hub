# 隨機臨床試驗 重點整理

> 以下依百十三共筆 W9（Gordis Ch7–8，白其卉）整理，並對照今年講義「ch07 RCT（完整N）」（10/30 上課，Ch7–8 合併）補充；上課錄影與逐字稿尚未上架，上架後再補 🎙️ 錄影重點。
>
> ⚠️ 講義的 treatment efficacy 兩個例子**分母不一致**（見第 5 節），考試以 Gordis 定義「÷ 安慰劑組」為準。

## 1. 臨床試驗的歷史 ⭐

- **1537 Paré**：油不夠時改用蛋黃、玫瑰油、松脂處理傷口（非計畫性試驗）。
- **1747 Lind**：12 名水手分 6 組（每組 2 人：蘋果汁、硫酸類藥劑、醋、**柳橙與檸檬**、海水、肉豆蔻），柳橙與檸檬最有效 → **壞血病**（第一個有計畫的臨床試驗）。
- **Galton**（臨床試驗之父）：強調研究設計、兩組比較（祈禱研究）。Galton 約 1883 年問「祈禱的病人是否好得比較快」，也提出**迴歸均值（regression to the mean）**。**1965 Joyce & Welldon**：雙盲、序列分析的祈禱試驗 → 沒有差異；**1988 Byrd**：**隨機雙盲**祈禱試驗 → 心肌梗塞病人中祈禱組較好。

## 2. RCT 設計 ⭐⭐

- 類型：**社區試驗**（政策，例：飲水加氟 → 中興新村）與**臨床試驗**（醫療）。
- **選取研究個案**：明確的納入排除標準（protocol）、客觀可複製、盡量保有外推性、符合倫理與效率、醫病雙方都能接受、對病人利大於弊。
- 評估結果用的是上一章的**預後指標**（prognosis measures）。
- **無比較研究**（case study、case series）：最常見的是**無對照前後比較（uncontrolled before-after study）**，全部是實驗組 → 有**歷史偏差**（時間造成的變化，例如醫療環境改善）、量表有**學習效應**，只適合評估短期功效。
- **非隨機分派**：**歷史對照**（同一主治醫師的過去病人、整個醫療資料庫）→ 簡易方便，但有**可比性**問題（差異是真的，還是只是資料收集品質不同？）與生活條件、營養、生活型態等隨日曆時間改變的未測量因素；**同步非隨機對照**（時間配對：依入院日期單雙號分組；背景配對：同時接受手術的病人；配合度高的病人）→ 方便但分派可預期，會有**選擇偏差**（講義例：疫苗組死亡遠少於對照組，可能只是積極的家長才讓孩子打疫苗）。
- **隨機分派**：丟銅板、亂數表、密封信封；醫療人員沒有選擇權。避免歷史偏差、選擇偏差與無法測量的背景差異。**不一定要 1:1**。
  - 固定機率 vs 非固定機率（依已收個案或死亡情形調整）。
  - 隨機的其他問題：歷史對照通常是**盛行病人**、介入組是**新發病人**；標準療法無效的病人常被放進介入組 → 都是沒隨機造成的選擇偏差。
  - **分層隨機分派（stratified）**：先依特定因素（性別、年齡、運動量）分層再隨機，確保兩組分布一致。

## 3. 最好的設計：隨機分派盲性同期對照試驗 ⭐⭐⭐

- **randomized blinded concurrent controlled trial**：隨機＋同期對照移除背景誤差；隨機＋盲性使未知因素在兩組均勻分布；保證統計效力。
- 沒有盲性 → 研究者的主觀干擾（常見於外科試驗）；沒有隨機 → 選擇偏差（常見於罕見疾病、小樣本）；沒有同期對照 → 時間造成的誤差。
- **盲性**：
  | 類型 | 不知道分組的人 |
  |---|---|
  | **單盲** | 僅**受試者** |
  | **雙盲** | 受試者＋施測者（醫師、護理師、醫檢、藥師） |
  | **三盲** | 受試者＋施測者＋**資料處理（統計分析）者** |
- **資料收集**：兩組的收集方式與品質要可比——治療（**分派到的** vs **實際接受的**）、結果（改善與副作用）、入組時的預後特徵（危險因子、干擾因子）、盲性。
- **Placebo**：外觀、味道、氣味都和真藥一樣的惰性物質；但**使用 placebo 不保證盲性**——：病人可從副作用猜到組別（aspirin 腸胃不適；維他命 C 感冒試驗約 8 成猜中）。

## 4. 遵從性（Noncompliance）⭐⭐

- 病人同意被分派，但沒有完成被指派的治療。
- **Coronary Drug Project（clofibrate）**：總死亡率 18.2% vs 安慰劑 19.4%；good complier 15.0%、poor complier 24.6%；但安慰劑組 good complier 也只有 15.1% → **遵從性本身就和預後有關**，不能只挑 good complier 比較。

## 5. 結果的呈現 ⭐⭐⭐

- **Treatment efficacy（reduction in risk）**＝ |Rate_placebo − Rate_treatment| ÷ Rate_placebo。
- **Relative risk** ＝ Rate_treatment ÷ Rate_placebo。
  - 講義例：新藥治癒率 60%、安慰劑 10% → |0.1 − 0.6| ÷ 0.1 = **5**；新藥 CFR 5%、安慰劑 20% → 講義寫 (0.2 − 0.05) ÷ **0.05** = 3（**分母用了新藥組**；依 Gordis 定義應 ÷ 0.2 = **0.75**，即降低 75%）。
  - Relative risk 講義例：新藥第一年存活 55%、安慰劑 40% → relative risk to survival = 0.55 ÷ 0.4 = **1.375**。
  - 也可用**存活曲線**（Ch6 的 K-M）呈現。
- **ARR** ＝ CER − EER；**RRR** ＝ (CER − EER) ÷ CER。
- **NNT = 1 ÷ ARR = 1 ÷ (Rate_untreated − Rate_treated)**：每減少一個不良結果需要治療的人數。
  - 例：阿司匹靈中風 5% vs 20% → NNT = 1 ÷ 0.15 ≈ 6.67（109）；標靶治療惡化 60% vs 40% → **NNT = 5**（110、114）。
  - RRR 相同時，事件很罕見的 NNT 可能大到不值得治療（講義例：干擾素治療 **MS**，CER 50%、EER 39% → RRR 22%、ARR 11%、**NNT = 9**；假設的罕見事件 0.00050% vs 0.00039%，RRR 一樣 22%，但 **NNT = 909,090**，不值得治療）。講義文字寫「重症肌無力」，表格寫 MS（多發性硬化症，Gordis 原例），以 MS 為準。

## 6. 外推性 ⭐⭐

- **內在效度**：研究能否有效看到結果（受試者干擾少、配合度高）。
- **外在效度（generalizability）**：研究族群決定結果能用在哪些人（例：COVID 疫苗最初只研究 20–40 歲）。講義用 Gordis 的同心圓圖：**參與者 → 合格者 → 目標族群 → 全體族群**，越往外越難外推。

## 7. RCT 的變形 ⭐⭐⭐

- **預期性交叉試驗（planned crossover）**：兩組先後互換治療；中間要停藥（washout），要考慮**殘餘效應（residual carryover）**；可同時比較同一組人與同時期不同組。
- **非預期性交叉試驗**：病人自行換組（例：手術組拒絕手術）→ 依原分組分析造成錯誤分類；依實際治療分析則破壞隨機。
- **因子型設計（factorial）**：同時評估兩種治療的**主效果與交互作用**（例：aspirin × beta-carotene；考古：aspirin × 紅麴）。

## 8. 新藥試驗分期 ⭐⭐⭐

| 分期        | 重點                                              | 規模       |
| ----------- | ------------------------------------------------- | ---------- |
| **Phase 1** | 人體**毒性與藥理**反應（第一次用在人身上）        | 20–80 人   |
| **Phase 2** | **有效性與相對安全性**，找有效劑量                | 100–200 人 |
| **Phase 3** | 大型 RCT，**效果與相對安全性** → 完成後可**上市** | 大型       |
| **Phase 4** | **上市後監測**，臨床試驗看不到的副作用            | —          |

## 9. 臨床試驗的優勢與限制 ⭐⭐

- 優勢：**最具證據力**，兼具因果與時序；可操控介入、觀察特殊劑量；可同時觀察多種健康事件。
- 限制：成本高；有些主題有倫理問題；**外推有限**；**通常只能處理一種介入**（太複雜的介入無法處理）。

# 考點分析

## 🔥 高頻考點（考古 109、110、114 期中，幾乎每年同題）

- 規劃試驗時**不適當**的技巧：用 single blind 讓「執行試驗者」不知道組別（錯，那是雙盲）。
- **隨機分派不一定 1:1**。
- **雙盲、三盲**的人員組合（三盲 = 病人、照顧醫師、統計分析師）。
- **交叉試驗**的錯誤敘述（可以依變數做分層隨機、要看遵從性與殘餘效應）。
- **aspirin × 紅麴**的主效果與交互作用 → **factorial design**。
- 臨床試驗的「非」優點：**結果適合外推**（錯）。
- **Phase 4** 完成後才能上市（錯，Phase 3 完成就能上市）。
- **NNT** 計算；隨機分派的優點不包括「外在效度增加」（109）。

## 📝 出題模式

- 題目幾乎每年重複，110 與 114 的試驗題幾乎一模一樣。

## ⚠️ 陷阱整理

| 容易選錯                                           | 正確                                                                                                            |
| -------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 單盲是研究者不知道                                 | **單盲 = 受試者**不知道；雙盲加施測者；三盲再加資料分析者                                                       |
| 隨機分派一定要 1:1                                 | **不一定 1:1**                                                                                                  |
| 歷史對照可避免選擇偏差                             | 歷史對照有**歷史偏差**；同步非隨機有**選擇偏差**；隨機分派才能避免                                              |
| 只分析 good complier 最能看出療效                  | 遵從性本身與預後有關（Coronary Drug Project：安慰劑 good complier 也較好）                                      |
| Treatment efficacy 除以治療組（講義 CFR 例算出 3） | 依 Gordis **÷ 安慰劑組**：(0.20 − 0.05) ÷ 0.20 = **0.75**                                                       |
| Unplanned crossover 依實際治療分析最準             | 依原分派 → **misclassification**；依實際治療 → **破壞隨機**                                                     |
| NNT = 1 ÷ RRR                                      | **NNT = 1 ÷ ARR**（ARR = CER − EER）                                                                            |
| RRR 相同 → NNT 相同                                | 事件率不同時 **NNT 可能差很多**（罕見事件 NNT 很大）                                                            |
| Relative risk = 安慰劑率 ÷ 治療率                  | **RR = 治療組率 ÷ 安慰劑組率**；efficacy = (安慰劑 − 治療) ÷ 安慰劑                                             |
| Crossover 不需要 washout                           | 預期性交叉要 **washout**，並考慮殘餘效應                                                                        |
| 因子型設計只能看主效果                             | 可同時評估**主效果與交互作用**                                                                                  |
| Phase 2 確認上市                                   | **Phase 1** 毒性藥理（20–80 人）；**Phase 2** 有效性與劑量；**Phase 3** 大型 RCT → 上市；**Phase 4** 上市後監測 |
| 內在效度高就能外推                                 | 外推性是**外在效度**，由研究族群決定                                                                            |
