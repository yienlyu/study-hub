# 血絲蟲（Filaria）重點整理

> 范家堃，2026/09/22。斑氏絲蟲、馬來絲蟲、羅阿絲蟲、蟠尾絲蟲。

## 1. 總論 ⭐⭐⭐
- 絲蟲症是**寄生在淋巴管與皮下組織**的線蟲造成的；感染人的主要有 **8 種**。
- 造成大部分疾病負擔的 3 種：
  - ***Wuchereria bancrofti*（斑氏絲蟲）**與 ***Brugia malayi*（馬來絲蟲）** → **淋巴絲蟲症**。
  - ***Onchocerca volvulus*（蟠尾絲蟲）** → **河盲症（river blindness）**。
- 其他 5 種：*Loa loa*、*Mansonella perstans*、*M. streptocerca*、*M. ozzardi*、*Brugia timori*（也造成淋巴絲蟲症）。
- **所有血絲蟲都要靠節肢動物傳播（arthropod-borne）**，**感染期都是第三期幼蟲（L3）**。
- 雌蟲產出**幼蟲（微絲蚴 microfilaria）**而不是卵。

## 2. 分布、成蟲部位與病媒 ⭐⭐⭐（老師：國考常考，要背）
| 蟲種 | 分布 | 成蟲部位 | 微絲蚴位置 | **病媒** |
|---|---|---|---|---|
| *W. bancrofti* | 熱帶；**台灣曾流行**（本島、澎湖、金門） | 淋巴管、淋巴結 | 血液（**夜間週期性**） | **蚊**（家蚊 *Culex*、斑蚊 *Aedes*、曼蚊 *Mansonia*、瘧蚊 *Anopheles*） |
| *B. malayi* | 亞洲 | 淋巴管 | 血液（夜間週期性） | **蚊**（曼蚊、斑蚊、瘧蚊） |
| *B. timori* | 印尼 | 淋巴管 | 血液 | 瘧蚊 |
| *Loa loa* | **西非、中非**（森林、沼澤） | 皮下組織（**主動移行**） | 血液（**日間週期性**） | **斑虻（deerfly、mango fly，*Chrysops*）** |
| *O. volvulus* | **非洲**、拉丁美洲、中東（葉門） | **皮下結節** | **皮膚、眼睛** | **黑蠅（blackfly，*Simulium*）** |
| *M. perstans* | 非洲、南美 | 體腔 | 血液 | **蠓（midges）** |
| *M. streptocerca* | 非洲 | 真皮、皮下 | **皮膚** | 蠓 |
| *M. ozzardi* | 美洲 | 皮下 | 血液 | 蠓與黑蠅 |

- 微絲蚴在節肢動物體內 **1–2 週**發育為感染性 L3，下次吸血時感染人；*Onchocerca* 在人體發育為成蟲可能要 **18 個月**。
- 黑蠅體內的 L3 要接觸**唾腺**、完成成熟後才有感染力（老師補充）。

## 3. 淋巴絲蟲症的臨床 ⭐⭐⭐
- 症狀主要由**成蟲**造成；成蟲與微絲蚴都會造成**嗜酸性球增多**。
- 分期：**無症狀** → **發炎期（急性）**：淋巴管炎、淋巴水腫、**絲蟲熱** → **阻塞期（慢性）**。
- **熱帶肺嗜酸性球症候群（tropical pulmonary eosinophilia）**：**血中沒有微絲蚴**、**IgE 很高**、**嗜酸性球很高**。
- **阻塞期**：成蟲死亡或鈣化 → 阻塞淋巴管 → **淋巴曲張** → 纖維母細胞增生。
  - **象皮病（elephantiasis）**：淋巴管阻塞 → 皮膚腫脹 → 血液營養供應不足；好發於**下肢、陰囊、乳房、外陰**。
  - **乳糜尿（chyluria）**：*W. bancrofti* 的晚期表現，常合併血尿。乳糜池以下的淋巴結阻塞 → 腸道淋巴逆流到腎臟淋巴管 → 破裂流入集尿系統。**尿液早上呈白色，之後漸漸轉紅**；會流失蛋白質與脂肪 → 貧血、低蛋白血症、體重下降。

## 4. 診斷 ⭐⭐⭐
- **微絲蚴的週期性（periodicity）**：
  - **夜間週期性**：晚上 **10 點到清晨 4 點**密度最高（斑氏、馬來絲蟲）。
  - **日間週期性**：白天出現（*Loa loa*）。
  - **亞週期性（subperiodic）**：隨時都有，但在夜間或白天（中午 12 點到晚上 8 點）達到高峰（太平洋島嶼、越南）。
  - 非週期性。
- 在**血液、尿液、陰囊水腫液或切片**中找到微絲蚴；**厚、薄血片 Giemsa 染色**，依蟲種在**最佳時間採血**。
- 血液濃縮法比抹片敏感：**Knott technique**（formalin 沉澱）、**Nucleopore 濾膜法**。
- **潛隱性絲蟲症（occult filariasis）**：血中找不到微絲蚴 → 用血清學。
- **微絲蚴形態鑑別** ⭐⭐⭐：
  | 微絲蚴 | 外鞘（sheath） | 尾核 | 其他 |
  |---|---|---|---|
  | ***W. bancrofti*** | **有** | **無** | 體核排列整齊不重疊；彎曲平順 |
  | ***B. malayi*** | **有** | **有**（尾端 2 個獨立的核） | 體核重疊、深染；大彎中有小彎 |
  | ***Loa loa*** | **有** | **有**（體核**連續**延伸到尾尖） | |
  | ***O. volvulus*** | **無** | — | 在皮膚，不在血液 |

## 5. 治療與防治（淋巴絲蟲）⭐⭐
- **DEC（diethylcarbamazine，海喘散 Hetrazan）**：**同時殺死成蟲與微絲蚴**，2 mg/kg、2–4 週；劑量不足可能引起全身過敏。
- **Ivermectin**：讓**微絲蚴麻痺**。
- 象皮病需要**手術**。
- 防治：防蚊、化學治療、病媒控制。
- 台灣：民國 40–50 年代本島、澎湖、金門有本土病例；**范秉真教授**在**金門**把 **DEC 混入食鹽**發給家戶，終於**根除**台灣的血絲蟲。

## 6. 羅阿絲蟲 *Loa loa*（非洲眼蟲）⭐⭐
- ♀ 5–7 cm、♂ 2–3.5 cm；由 **mango fly（*Chrysops silicea*、*C. dimidiata*）**傳播；只在**西非與中非**的森林、沼澤地區。
- 臨床：**Calabar swelling（卡拉巴腫）**（上肢或下肢）、微絲蚴血症、嗜酸性球增多、**眼蟲（成蟲爬過結膜）**、慢性腎病。
- 診斷：**日間週期性**採血、Calabar swelling、**在結膜找到蟲體**；**RAPLOA** 快速評估。
- 治療：DEC 2 mg/kg、21 天（一天三次）；**重度感染者副作用可能很嚴重（致命性腦炎、腎臟病變）**；預防性 DEC 300 mg／週；病媒控制效果不好。

## 7. 蟠尾絲蟲 *Onchocerca volvulus*（河盲症）⭐⭐⭐
- ♀ 33–50 cm、♂ < 5 cm；**第 2 常見**的絲蟲感染；非洲、南美、葉門的**大河附近**；全球 30%（slides）病例在非洲。
- 病媒 **黑蠅（*Simulium*）**，**白天叮咬**。
- 臨床主要由**微絲蚴**造成（皮膚與眼睛）：**蟠尾絲蟲皮膚炎**、**皮下結節（onchocercoma，成蟲盤繞在其中）**、嗜酸性球增多、淋巴結腫大、**Sowda**（皮膚變黑、水腫、真皮增厚）；腎、肺、肝等器官病灶。
  - 結節位置：**非洲在下軀幹與下肢**；**中美洲在頭、胸、頸**。
- **失明原因**：微絲蚴蛋白質引起的發炎，以及**共生菌 *Wolbachia*** 引起的發炎。
- **診斷**：
  - **皮膚切片（skin snips）**找微絲蚴（無外鞘）：南美取上半身，非洲取下肢與**髂骨嵴**。
  - **Mazzotti test**：口服 **50 mg DEC**，觀察皮膚過敏反應（**可能造成嚴重副作用**）。
  - **Patch test**：10% DEC 塗在無水羊毛脂上。
  - **結節切除（nodulectomy）**。
- **治療**：**Ivermectin**（成人單次 0.2 mg/kg；**只對微絲蚴有效**；有抗藥性）；DEC；手術取蟲。
  - **Ivermectin 機轉**：avermectin 類，和無脊椎動物神經與肌肉細胞的 **glutamate-gated chloride channel** 高親和力結合 → 氯離子通透增加、細胞**過極化** → 寄生蟲**麻痺死亡**。
- **注意**：*Loa loa* 與 *O. volvulus* **合併感染**時，治療可能出現嚴重副作用。

## 🎙️ 上課錄影重點（范家堃）
- 「所有血絲蟲感染期都是 L3」；不同血絲蟲的**病媒不一樣，要背，國考常考**。全球暖化可能讓這類疾病回升，是 WHO NTDs 關心的議題。
- **Mazzotti test「國考曾經考出來過」**：殘忍但實用，用臉部或皮膚的過敏反應判斷有沒有 *Onchocerca* 感染。
- 台灣以前是斑氏絲蟲疫區，經過三四十年的努力已經根除；范秉真教授在金門用 DEC 鹽。
- 寄生蟲病的危害在於**長期的痛苦與經濟損失**，不是像病毒、細菌那樣立即致死。
- 到東南亞或非洲做志工：穿**素色長袖**、常噴防蚊液。

# 考點分析

## 🔥 高頻考點
- **病媒配對**（蚊、黑蠅、蠓、斑虻）——國考常考。
- 所有絲蟲的感染期都是 **L3**；雌蟲產微絲蚴。
- **微絲蚴形態**：外鞘與尾核（斑氏 vs 馬來 vs 羅阿 vs 蟠尾）。
- **夜間週期性**（10 PM–4 AM）→ 採血時間；*Loa loa* 是日間。
- 象皮病、**乳糜尿**（早白晚紅）；熱帶肺嗜酸性球症候群（沒有微絲蚴、IgE 高）。
- **Mazzotti test**、skin snips；*Wolbachia* 與失明。
- DEC vs Ivermectin 的作用對象；*Loa loa* 合併感染的治療風險。

## 📝 出題模式
- 「下列何者的微絲蚴有外鞘但沒有尾核？」「河盲症的病媒是？」

## 🎙️ 老師課堂提示
- 「不同血絲蟲的 vector 要去背記，國考常常會考。」
- 「Mazzotti test 國考曾經考出來過。」

## 📚 考古題（共 41 題：113 考古 23、109 期中考古 17、110 期中考古 1）
- 題型：選正確／單一概念題 30、簡答題 5、多選題 4、選錯誤／否定題 2。
- 練習區可以只勾選某一年的來源；多選、配合與手寫題會直接顯示參考答案。109、110 和 113 完全重複的題目只收一次。

## 📒 115 共筆補充（week3）
- **微絲蚴是診斷期、L3 才是感染期**（所有血絲蟲都是「幼蟲生」＝卵胎生）；從 L3 發育到成蟲約 **18 個月**。
- 血片：**厚片（10 μL）看有沒有、薄片（5 μL）看是哪一種**。
- **微絲蚴型態（★考）**：有外鞘＝斑氏、馬來、羅阿；有尾核＝馬來（尾端單獨兩個）、羅阿（體核連續到尾尖）、*Mansonella* 類；斑氏蟲體平滑大彎、核柱疏鬆，馬來核柱密集重疊、大彎中有小彎。
- **Mazzotti test 原理**：老師說是 DEC 讓雌蟲大量釋放微絲蚴；共筆學藝查證較常見的解釋是 DEC **殺死微絲蚴**、死蟲抗原與 *Wolbachia* 引發強烈發炎 → 可能休克或傷眼，現已被 WHO 禁用。
- 蟠尾絲蟲治療：**Ivermectin 只殺微絲蚴（已出現抗藥性）**；DEC 殺成蟲與微絲蚴但可能致盲；**nodulectomy** 手術摘除結節。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| 血絲蟲雌蟲產卵 | 產**微絲蚴（幼蟲）** |
| 蚊子吸血傳給人的是微絲蚴 | 傳給人的感染期是 **L3**；微絲蚴是在人血中被蚊子吸走的 |
| 河盲症由蚊子傳播 | **黑蠅（*Simulium*）**，白天叮咬 |
| Loa loa 由黑蠅傳播 | **斑虻（*Chrysops*，mango fly）** |
| Calabar swelling 是河盲症 | **Calabar swelling = *Loa loa*** |
| Loa loa 微絲蚴夜間週期性 | ***Loa loa* 日間週期性**；斑氏、馬來夜間（晚上 10 點到清晨 4 點） |
| 河盲症用血片找微絲蚴 | ***O. volvulus* 微絲蚴在皮膚、眼睛** → **skin snip**；Mazzotti test（可能嚴重副作用）／patch test |
| 斑氏絲蟲微絲蚴有尾核 | **斑氏：有鞘、無尾核**；馬來：有鞘、**尾端 2 個核**；Loa loa：有鞘、核延伸到尾尖；*O. volvulus*：**無鞘** |
| 熱帶肺嗜酸性球症候群血中有大量微絲蚴 | **血中沒有微絲蚴**、IgE 與嗜酸性球很高 |
| 乳糜尿是馬來絲蟲 | 乳糜尿是 ***W. bancrofti*** 晚期表現 |
| Ivermectin 同時殺成蟲與微絲蚴 | **DEC** 殺成蟲＋微絲蚴；**Ivermectin 讓微絲蚴麻痺** |
| 河盲失明只因微絲蚴本身 | 也因共生菌 ***Wolbachia*** 引起的發炎 |
| 台灣血絲蟲靠殺蚊根除 | 范秉真教授在**金門把 DEC 混入食鹽** |
