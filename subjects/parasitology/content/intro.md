# 寄生蟲總論 重點整理（依百十四共筆整理、對照百十三共筆）

> 范家堃教授（分子寄生蟲暨熱帶疾病學科、國際熱帶醫學研究中心主任、台灣寄生蟲學會理事長），2026/09/07。以下依百十四共筆 week1（Ch1 前半）與 slides 整理。

## 1. 為什麼台灣還要學寄生蟲 ⭐

- 全球 **17 種 NTDs**（被忽視的熱帶疾病）中有 **11 種是寄生蟲病**；百十四共筆補充 WHO 近期更新為 **22 種，寄生蟲病占 12 種**。WHO 把熱帶寄生蟲病和 HIV、瘧疾列在同等防治位階。
- 台灣本土腸道蠕蟲大規模感染已少見（蟯蟲仍在台北市存在）；現在的感染主要和**寵物、飲食習慣、國際旅遊與移工**有關。飲食：生海鮮 → **海獸胃線蟲**；淡水魚生魚片 → **中華肝吸蟲**；醉蟹 → **衛氏肺吸蟲**；未熟豬肉或蟲卵汙染 → **豬肉絛蟲（囊尾幼蟲）**。
- 台灣的風險來源：出國旅遊（東南亞：印尼、越南、寮國、馬來西亞、泰國）、往返兩岸的台商、外籍配偶、外籍移工、**人畜共通寄生蟲**（毛小孩）。
- 寵物相關例子：**犬心絲蟲**（蚊子傳播，寄生在狗的右心室與肺動脈）、**東方眼蟲 _Thelazia callipaeda_**（蒼蠅傳播，寄生在眼結膜）、**巴貝氏原蟲**（蜱傳播，寄生在血球）。
- **東方眼蟲（犬眼蟲）_Thelazia callipaeda_** ⭐：投影片寫「**僅寄生於狗**」，人是偶然感染。
  - **經蒼蠅傳播**：戶外活動（**長跑、馬拉松**）時蒼蠅撞到眼睛，把幼蟲帶進**眼結膜**，在結膜長成成蟲。
  - 外觀像「**眼結膜長豆芽菜**」；眼睛可能受傷，但不至於失明。
  - 治療：眼科醫師**局部麻醉後把蟲夾出來**。
  - 台灣 2001–2018 年病例報告 **1 例**（台中居民）。
- 2001–2018 年台灣發表的病例報告共 **127 例：線蟲 60、原蟲 50、吸蟲 10、絛蟲 7**（經典案例：海獸胃線蟲胃痛嘔吐、東方眼蟲、淋巴絲蟲象皮病、包蟲囊胞、腦囊尾幼蟲症、衛氏肺吸蟲類似肺結核）。
- **人畜共通寄生蟲（zoonotic parasite）**：病原為寄生蟲的人畜共通病；最常見是**犬蛔蟲**（美國 CDC：每年約 70 人因此失明）。巴貝氏原蟲（蜱）對免疫正常者只造成輕微貧血，**無脾臟或免疫不全者**可能嚴重溶血致死（「犬貓的瘧疾」）。「台灣不是沒有寄生蟲病了」是錯誤資訊。

## 2. 基本定義 ⭐⭐

- **Parasite（寄生蟲）**：暫時或永久生活在另一個生物體內或體表，並從中取得食物與庇護的生物。
  - **Facultative（兼性）寄生蟲**：可以自由生活，也可以寄生。例：**_Strongyloides_**（糞小桿線蟲）。
  - **Obligate（絕對）寄生蟲**：必須永久寄生在宿主身上，離開宿主無法生存。例：**_Trichomonas_**。
  - 百十四共筆把容易混淆的四種分清楚：**coprozoic／spurious**（吃進其他動物的蟲卵，只是通過消化道被驗到）、**pseudoparasite**（花粉、植物纖維、澱粉、氣泡被誤認為蟲卵）、**erratic**（跑錯器官，如蛔蟲進膽囊、肺吸蟲進腦）、**accidental／incidental**（感染非正常宿主，能存活甚至致病但完成不了生活史，如犬貓蛔蟲 VLM）。
  - **Coprozoic（spurious，過誤性）寄生蟲**：外來生物只是通過消化道，沒有造成影響。例：吃到動物肝臟，糞便中出現 _Capillaria hepatica_ 卵。
- **生物之間的關係**：
  - **Symbiosis（共生）**：兩種生物永久性的結合。
  - **Mutualism（互利）**：雙方都得利。
  - **Commensalism（片利）**：一方得利，另一方不受影響；如果另一方受到傷害，就變成 **Parasitism（寄生）**。
  - **Zoonosis（人畜共通病）**：動物的疾病可以傳給人。例：**_Toxocara canis_**。

## 3. 宿主的分類 ⭐⭐⭐（老師：生活史是最快的學習手段）

- **Definitive host（最終宿主）**：寄生蟲在體內完成**有性生殖**或**發育為成蟲**。
- **Intermediate host（中間宿主）**：寄生蟲的**幼蟲期**或中間階段在體內發育。例：**_Clonorchis sinensis_（中華肝吸蟲）** 成蟲在人；第一中間宿主是**螺**；囊蚴（**metacercaria**）在**淡水鯉科魚**（第二中間宿主）。
- **Reservoir host（保蟲宿主）**：與寄生蟲適應良好、可以耐受感染，但會成為其他生物的感染源。
  - 老師強調的術語差別：如果有性生殖或發育為成蟲**同時發生在人與其他哺乳動物**身上，**人稱為 final host，其他哺乳動物稱為 reservoir host**（生物現象相同，只是定義不同）。
- **Paratenic host（保幼宿主）**：幼蟲在體內存活但**不發育**。例：人是犬蛔蟲的 paratenic host。
- **診斷期 vs 感染期**：以中華肝吸蟲為例，糞便中的**蟲卵是診斷期**，魚肉中的 **metacercaria 才是感染期**。「把診斷期、感染期、第一與第二中間宿主、最終宿主、保蟲宿主分清楚，寄生蟲學就學完了。」

## 4. 醫學寄生蟲的分類 ⭐⭐

| 類別               | 特徵                                               | 例子                   |
| ------------------ | -------------------------------------------------- | ---------------------- |
| **線蟲 Nematode**  | 線狀；**雌雄異體**；雌蟲比雄蟲大                   | 蛔蟲、鉤蟲、蟯蟲、鞭蟲 |
| **吸蟲 Trematode** | 口吸盤、腹吸盤；多數**雌雄同體**                   | 中華肝吸蟲、衛氏肺吸蟲 |
| **絛蟲 Cestode**   | 由頭節與節片構成；**雌雄同體**；分為擬葉目、圓葉目 | 魚肉絛蟲、豬肉絛蟲     |
| **原蟲 Protozoa**  | 單細胞，要用顯微鏡（400×、1000× 油鏡）才看得到     | 瘧原蟲、阿米巴         |
| **醫學節肢動物**   | 只學它會**傳播**哪些寄生蟲病                       | 蚊、蠅、蜱             |

## 5. 寄生蟲病的預防 ⭐

1. **治療病人與保蟲宿主**。
2. **處理最終宿主的排泄物**。
3. **控制病媒與中間宿主**。
4. **預防性投藥**（prophylaxis）。

- 個人層面：少吃生食（生魚、生菜、生肉）、注意飲水；寵物定期到獸醫做體檢與驅蟲。

## 6. 學名寫法 ⭐⭐

- **二名法（Binominal）**：屬名＋種名，例 **_Ascaris lumbricoides_** Linnaeus, 1758（蛔蟲）。
- **三名法（Trinominal）**：例 **_Trypanosoma brucei gambiense_** Dutton, 1902（甘比亞錐蟲），較少用。
- **考試的填空題、問答題、跑台（混合蟲卵）都要寫出學名全名**。

## 7. 學習目標

**Epidemiology → Life cycle → Pathology → Diagnosis → Treatment → Prevention**：把這些填進生活史裡，就學完了。

## 8. 體內移行路徑比較：誰走門脈？ ⭐⭐⭐

> 門脈路徑＝**腸道 → 腸繫膜靜脈 → 門靜脈 → 肝**。考題常把「經血流」「穿腹腔」「走膽管」混在一起考。

| 路徑                               | 寄生蟲                                                         | 過程                                                                                                                                    |
| ---------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **門脈循環**（腸 → 門靜脈 → 肝）   | **蛔蟲 _Ascaris lumbricoides_**                                | 吃入蟲卵 → 小腸孵化 → 幼蟲**穿過腸壁 → 門脈到肝** → 心 → **肺**（Ascaris pneumonia）→ 氣管 → 吞回小腸                                   |
|                                    | **肝毛線蟲 _Capillaria hepatica_**                             | 吃入胚胎化的卵 → 小腸孵化 → **經門脈到肝** → 在肝內長成成蟲，卵留在肝實質                                                               |
|                                    | **犬貓蛔蟲 _Toxocara canis / cati_**                           | 幼蟲穿過腸壁後**多數停在肝**，部分到肺、肌肉、眼、CNS（VLM／OLM）                                                                       |
|                                    | **血吸蟲 _Schistosoma japonicum / mansoni_**                   | 成蟲**住在門脈系統本身**（日本＝上腸繫膜靜脈、曼森＝下腸繫膜靜脈）→ 蟲卵順門脈流到肝 → egg granuloma → 肝脾腫大、**門脈高壓**、側枝循環 |
|                                    | 📌 課外：**痢疾阿米巴 _Entamoeba histolytica_**                | 大腸 → 門脈 → 肝 → **阿米巴肝膿瘍**                                                                                                     |
|                                    | 📌 課外：**包生絛蟲 _Echinococcus_、豬肉絛蟲 _Taenia solium_** | 六鉤蚴穿過腸壁 → 門脈 → 肝（包生絛蟲包囊最常見於肝）→ 再擴散到肺、腦等                                                                  |
| **皮膚 → 體循環靜脈**（右心 → 肺） | 鉤蟲、糞小桿線蟲、**血吸蟲童蟲**                               | 鑽皮膚 → 靜脈 → 右心 → 肺；血吸蟲童蟲之後才到門脈定居（**進入走體循環，成蟲住門脈**）                                                   |
| **穿腸壁 → 腹腔**（不走血）        | **衛氏肺吸蟲**                                                 | 穿過腸壁 → 腹腔 → **穿過橫膈** → 肺                                                                                                     |
|                                    | **牛羊肝吸蟲 _Fasciola hepatica_**                             | 穿過腸壁 → 腹腔 → **穿過肝被膜** → 在肝實質移行 → 膽管（traumatic hepatitis）                                                           |
| **膽管上行**（不穿腸壁）           | **中華肝吸蟲 _Clonorchis sinensis_**                           | 十二指腸脫囊 → **經總膽管（Vater 壺腹）上行** → 肝內膽管                                                                                |

- **埃及血吸蟲 _S. haematobium_** 住在**膀胱靜脈叢**，不屬於門脈系統 → 以**血尿**為主，不是門脈高壓。
- 同樣「到肝」，走法不同：蛔蟲／肝毛線蟲／犬蛔蟲走**門脈**；_Fasciola_ 走**腹腔穿肝被膜**；中華肝吸蟲走**膽管**。

# 考點分析

## 🔥 高頻考點

- **宿主的定義**：final host vs reservoir host vs intermediate host vs paratenic host。
- **診斷期 vs 感染期**（以中華肝吸蟲為例）。
- facultative（_Strongyloides_）、obligate、spurious 寄生的例子。
- zoonosis 的例子（_Toxocara canis_）。
- 線蟲雌雄異體；吸蟲、絛蟲雌雄同體（例外：住血吸蟲）。
- **東方眼蟲 _Thelazia callipaeda_**：**蒼蠅**傳播、寄生在**眼結膜**。考古題考過兩種問法：
  - **可侵犯眼睛的線蟲**：_T. canis_、_Gnathostoma_、_A. cantonensis_、_L. loa_、_O. volvulus_、_T. callipaeda_。
  - **傳播需要節肢動物 vector**：_T. callipaeda_（蒼蠅）和血絲蟲（蚊子、黑蠅、斑虻）都需要；_T. canis_ 不需要。

## ⚠️ 陷阱整理

| 容易選錯                                  | 正確                                                                                        |
| ----------------------------------------- | ------------------------------------------------------------------------------------------- |
| Final host 是有幼蟲發育的宿主             | Final（definitive）host：**有性生殖或發育為成蟲**；幼蟲在 intermediate host                 |
| 人是犬蛔蟲的中間宿主                      | 人是犬蛔蟲的 **paratenic（保幼）host**：幼蟲存活但不發育                                    |
| 人與動物都讓蟲成熟時，動物也叫 final host | 人稱 **final host**，其他哺乳動物稱 **reservoir host**                                      |
| 中華肝吸蟲的感染期是蟲卵                  | 糞便**蟲卵 = 診斷期**；魚肉中的 **metacercaria = 感染期**                                   |
| 糞便有 _C. hepatica_ 卵 = 肝毛線蟲感染    | 是 **spurious（coprozoic）**：吃了感染動物的肝                                              |
| _Strongyloides_ 是絕對寄生蟲              | _Strongyloides_ 是**兼性（facultative）**；_Trichomonas_ 才是絕對寄生                       |
| 吸蟲、絛蟲都雌雄異體                      | 線蟲**雌雄異體**；吸蟲（血吸蟲除外）與絛蟲**雌雄同體**                                      |
| 東方眼蟲傳播不需要節肢動物                | _T. callipaeda_ 要靠**蒼蠅**把幼蟲帶進眼結膜                                                |
| 會到肝的寄生蟲都走門脈                    | 蛔蟲、肝毛線蟲、犬蛔蟲走**門脈**；_Fasciola_ 走**腹腔穿肝被膜**；中華肝吸蟲走**總膽管上行** |
| 血吸蟲尾蚴鑽皮後直接進門脈                | 童蟲先走**體循環**（靜脈 → 右心 → 肺），之後才到**門脈／腸繫膜靜脈**定居                    |
| 學名寫中文或只寫屬名就好                  | 填空、問答、跑台都要寫**學名全名**（屬名大寫、種名小寫、斜體或底線）                        |
