## 1. 吸蟲總論 ⭐⭐⭐
- **扁蟲門（Platyhelminthes）**，腹背扁平；**無體腔**、沒有循環與呼吸系統（線蟲有假體腔，吸蟲較低等）。
- 通常有**兩個吸盤**（口吸盤、腹吸盤）；消化道不完整：口 → 咽 → 食道 → 兩個腸支，**沒有肛門**。
- 排泄：**焰細胞（flame cell）** → 毛細管 → 集合管 → 排泄囊 → 排泄孔。
- **雌雄同體、異體受精**；**血吸蟲例外，是雌雄異體**。
- 會感染人的都是**雙殖目（Digenea）**：有性世代在最終宿主，無性世代在中間宿主（螺）。
- **發育順序**：卵 → **纖毛幼蟲 miracidium** → **胞狀幼蟲 sporocyst** → **雷氏幼蟲 redia** → **尾動幼蟲 cercaria** → **囊狀幼蟲 metacercaria** → 成蟲。**血吸蟲沒有雷氏幼蟲與囊狀幼蟲**。
- **免疫逃避**：皮層（glycocalyx tegument）約 3 小時更新一次、會黏附宿主抗原偽裝、成分隨生活史改變 → 需要靠藥物治療。
- **共通藥物：Praziquantel**（增加蟲體鈣離子通透性 → 強直性麻痺；破壞皮層、暴露抗原）。**唯一例外：牛羊肝吸蟲用 Bithionol**。孕婦不能用 Praziquantel。

### 血吸蟲 vs 其他吸蟲 ⭐⭐⭐（考例外）
| | **血吸蟲** | 肺吸蟲、肝吸蟲、腸吸蟲 |
|---|---|---|
| 外型 | **圓柱形** | 扁平、葉狀 |
| 性別 | **雌雄異體**（雄蟲有**抱雌溝**） | 雌雄同體 |
| 腸道 | 一分為二**再合一** | 一分為二 |
| 蟲卵 | **沒有卵蓋** | 有卵蓋 |
| 中間宿主 | **一個**（螺） | 兩個以上 |
| 幼蟲期 | **沒有雷蚴、囊蚴** | 有 |
| 感染方式 | **尾蚴鑽皮膚** | 吃入囊蚴 |
| 致病 | 以**蟲卵**為主 | 以成蟲為主 |
| 尾蚴 | **尾巴分叉** | 不分叉 |

## 2. 腸吸蟲（Intestinal flukes）⭐⭐
| 蟲種 | 重點 |
|---|---|
| **薑片蟲 *Fasciolopsis buski*** | **人體最大的吸蟲**（3–7 cm）；腹吸盤比口吸盤大約 5 倍；卵 130–140 µm，**人體最大的寄生蟲卵**、卵蓋不明顯。1st IH **扁捲螺**；2nd IH **水生植物（菱角、荸薺、筊白筍）**；保蟲宿主**豬**；寄生小腸。症狀較其他腸吸蟲嚴重（腹痛、腹瀉、腸阻塞、臉部水腫）。Praziquantel。 |
| **橫川異形吸蟲 *Metagonimus yokogawai*** | 第一個病例在**台灣**發現（橫川定）；腹吸盤**偏向中線右側**（「橫川歪一邊」）；2nd IH 淡水魚 |
| **異形異形吸蟲 *Heterophyes heterophyes*** | **人體最小的吸蟲**之一；有**三個吸盤**（多一個生殖吸盤，「異形多一個」）；蟲卵可經腸壁血管異位到腦、心肌 |
| **棘口吸蟲 *Echinostoma*** | **馬蹄形頭冠、兩列頭棘**；2nd IH 種類很多（蝸牛、水生植物、蛙、魚） |
| **人雙口吸蟲 *Gastrodiscoides hominis*** | 角錐狀；寄生大腸；2nd IH 水生植物 |
| **胰臟吸蟲 *Eurytrema*** | **陸生吸蟲**：1st IH 陸螺、2nd IH **蝗蟲**；卵殼厚、顏色深；寄生胰管 |

- **薑片蟲 vs 牛羊肝吸蟲**（兩隻大型吸蟲）：牛羊肝吸蟲有**明顯頭錐**、**腸道有許多側分支**、腹吸盤只比口吸盤稍大；薑片蟲頭錐不明顯、腸道不再分支。

## 3. 肺吸蟲：衛氏肺吸蟲 *Paragonimus westermani* ⭐⭐⭐
- **首二例在台灣發現**（1881 年萬巴德 Manson 報告）；新竹醫院曾是研究重鎮。
- 成蟲像**咖啡豆**；**兩個並列的手掌狀睪丸位於後 1/3**（必考，並殖科）。
- **1st IH：川蜷（*Semisulcospira libertina*）**；**2nd IH：淡水蝦、蟹**（醉蝦、醉蟹）；保蟲宿主貓、狗、豬。
- 囊蚴在小腸脫囊 → **穿過腸壁、經腹腔、穿過橫膈到肺**（不是經血液循環）。
- 症狀**像結核病**：咳嗽、血痰、胸痛；痰中有蟲卵與 **Charcot-Leyden 結晶**；嗜酸性球上升。
- 異位寄生：**腦部最嚴重**（佔位性病灶、癲癇），多發生在 30 歲以下。
- 診斷：痰、糞便、胃液找蟲卵（卵蓋在較平的一端）；皮內試驗、ELISA；X 光常誤診為 TB。治療：Praziquantel（Bithionol 較差）。

## 4. 肝吸蟲（Liver flukes）⭐⭐⭐
| 蟲種 | 感染來源 | 中間宿主 | 重點 |
|---|---|---|---|
| **中華肝吸蟲 *Clonorchis sinensis***、貓肝吸蟲 *O. felineus*、泰國肝吸蟲 *O. viverrini* | **生淡水魚（鯉科）** | 1st **滿州泥螺**；2nd 鯉科淡水魚 | 寄生**膽管**（不是肝）；可活 15 年以上；**膽管癌**；靠**睪丸形狀**分辨（中華：珊瑚狀）；孫中山死於其引起的膽囊癌 |
| **槍狀肝吸蟲 *Dicrocoelium dendriticum*** | **吃到螞蟻** | 1st 陸螺；2nd **螞蟻** | 陸生吸蟲、卵殼厚；可能吃到動物肝臟造成假性感染 |
| **牛羊肝吸蟲 *Fasciola hepatica***（巨型肝吸蟲 *F. gigantica*） | **汙染的水生植物** | 1st **椎實螺**；2nd 水生植物（**非必要**） | 保蟲宿主牛羊；**Praziquantel 無效，用 Bithionol** |

- 中華肝吸蟲：兒童時期感染 → 脾腫大、營養不良、**侏儒症**。診斷：糞便或十二指腸液找蟲卵，三種卵極相似，要問盛行區。

## 5. 血吸蟲（Schistosomes）⭐⭐⭐
| | **日本血吸蟲 *S. japonicum*** | **曼森血吸蟲 *S. mansoni*** | **埃及血吸蟲 *S. haematobium*** |
|---|---|---|---|
| 中間宿主（螺） | **湖北釘螺 *Oncomelania hupensis*** | **雙臍扁螺 *Biomphalaria*** | **小泡螺 *Bulinus*** |
| 成蟲位置 | **上腸繫膜靜脈叢** | **下腸繫膜靜脈叢** | **膀胱、前列腺、子宮靜脈叢** |
| 蟲卵排出 | 糞便 | 糞便 | **尿液**（偶爾糞便） |
| 疾病 | 肝脾腫大、腸血吸蟲病 | 腸血吸蟲病 | **泌尿性血吸蟲病（血尿）** |

- **感染**：尾蚴**鑽皮膚** → 尾動幼蟲皮膚炎；水鳥血吸蟲尾蚴造成「**泳者之癢（swimmer's itch）**」。
- **片山熱（Katayama fever）**：感染 1–3 個月後的急性期，免疫複合體沉積引起過敏。
- **蟲卵造成肉芽腫**（主要致病原因）。
- 治療：Praziquantel；Artemether；Oxamniquine（只針對曼森，效果差）。

# 考點分析

## 🔥 高頻考點（百十三 w5~6 Trematodes 考古）
- **發育順序**（miracidium → sporocyst → redia → cercaria → metacercaria）。
- **血吸蟲的例外**：雌雄異體、無卵蓋、一個中間宿主、尾蚴鑽皮膚、沒有雷蚴與囊蚴。
- **吃什麼得什麼**：水生植物 → 薑片蟲、牛羊肝吸蟲；淡水魚 → 中華肝吸蟲、異形吸蟲；蝦蟹 → 肺吸蟲；螞蟻 → 槍狀肝吸蟲。
- **共通藥 Praziquantel**；牛羊肝吸蟲例外用 Bithionol。
- 台灣首例：橫川異形吸蟲、衛氏肺吸蟲。
- 血吸蟲三種的螺、寄生靜脈叢與蟲卵排出途徑。

## 📝 出題模式
- 臨床情境：嘉南地區病人吃荸薺後嚴重腹瀉 → 薑片蟲；咳血、X 光像 TB、吃過醉蟹 → 肺吸蟲。
- 考古也有**配合題**（網站練習區未收錄，請看原檔）。
