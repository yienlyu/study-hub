> 老師提醒：**考試特別喜歡考例外（血吸蟲）**；要知道**吃什麼會得什麼**。今年腸吸蟲的定位：**核心＝薑片蟲；鑑別群＝橫川／異形吸蟲（小、魚媒、卵易混淆）；認得就好＝棘口吸蟲**（罕見腸吸蟲移到補充教材）。

## 1. 吸蟲總論 ⭐⭐⭐
- **扁蟲門（Platyhelminthes）**，腹背扁平；**無體腔**、沒有循環與呼吸系統（線蟲有假體腔，吸蟲較低等）。
- 通常有**兩個吸盤**（口吸盤、腹吸盤）；消化道不完整：口 → 咽 → 食道 → 兩個腸支，**沒有肛門**。
- 排泄：**焰細胞（flame cell）** → 毛細管 → 集合管 → 排泄囊 → 排泄孔。
- **雌雄同體、異體受精**；**血吸蟲例外，是雌雄異體**。
- 會感染人的都是**雙殖目（Digenea）**：有性世代在最終宿主，無性世代在中間宿主（螺）。
- **發育順序**：卵 → **纖毛幼蟲 miracidium** → **胞狀幼蟲 sporocyst** → **雷氏幼蟲 redia** → **尾動幼蟲 cercaria** → **囊狀幼蟲 metacercaria** → 成蟲。**血吸蟲沒有雷氏幼蟲與囊狀幼蟲**。
- **免疫逃避**：皮層（glycocalyx tegument）約 3 小時更新一次、會黏附宿主抗原偽裝、成分隨生活史改變 → 需要靠藥物治療。
- **共通藥物：Praziquantel（PZQ）**（增加蟲體鈣離子通透性 → 強直性麻痺；破壞皮層、暴露抗原）。**例外：牛羊肝吸蟲 PZQ 療效不佳 → 用 Triclabendazole（老師總表）或 Bithionol（副作用大）**。孕婦不能用 Praziquantel（易流產）；肺吸蟲的替代藥也是 Bithionol。
- **吸蟲鑑定原則**（slides）：體型（扁平；血吸蟲圓柱）、型態（圓桶、樹葉、長條、梨形）、大小（<1 mm 到 cm）、**生殖系統（是否雌雄異體、睪丸數目位置形狀）**、吸盤數、焰細胞排列、**宿主專一性與數目**、蟲卵形態大小。

### 血吸蟲 vs 其他吸蟲 ⭐⭐⭐（考例外）
| | **血吸蟲** | 肺吸蟲、肝吸蟲、腸吸蟲 |
|---|---|---|
| 外型 | **圓柱形** | 扁平、葉狀 |
| 性別 | **雌雄異體**（雄蟲有**抱雌溝**） | 雌雄同體 |
| 腸道 | 一分為二**再合一** | 一分為二 |
| 蟲卵 | **沒有卵蓋** | 有卵蓋 |
| 中間宿主 | **一個**（螺） | 兩個以上 |
| 幼蟲期 | **沒有雷蚴、囊蚴** | 有 |
| 感染方式 | **尾蚴鑽皮膚** | 吃入囊蚴 |
| 致病 | 以**蟲卵**為主 | 以成蟲為主 |
| 尾蚴 | **尾巴分叉** | 不分叉 |

## 2. 腸吸蟲（Intestinal flukes）⭐⭐
| 蟲種 | 重點 |
|---|---|
| **薑片蟲 *Fasciolopsis buski*** | **人體最大的吸蟲**（3–7 cm）；腹吸盤比口吸盤大約 5 倍；卵 130–140 µm，**人體最大的寄生蟲卵**、卵蓋不明顯。1st IH **扁捲螺**；2nd IH **水生植物（菱角、荸薺、筊白筍）**；保蟲宿主**豬**；寄生小腸。症狀較其他腸吸蟲嚴重（腹痛、腹瀉、腸阻塞、臉部水腫）。Praziquantel。 |
| **橫川異形吸蟲 *Metagonimus yokogawai*** | 第一個病例在**台灣**發現（橫川定）；腹吸盤**偏向中線右側**（「橫川歪一邊」）；2nd IH 淡水魚 |
| **異形異形吸蟲 *Heterophyes heterophyes*** | **人體最小的吸蟲**之一；有**三個吸盤**（多一個生殖吸盤，「異形多一個」）；蟲卵可經腸壁血管異位到腦、心肌 |
| **棘口吸蟲 *Echinostoma*** | **馬蹄形頭冠、兩列頭棘**；2nd IH 種類很多（蝸牛、水生植物、蛙、魚） |
| **人雙口吸蟲 *Gastrodiscoides hominis*** | 角錐狀；寄生大腸；2nd IH 水生植物 |
| **胰臟吸蟲 *Eurytrema*** | **陸生吸蟲**：1st IH 陸螺、2nd IH **蝗蟲**；卵殼厚、顏色深；寄生胰管 |

- **薑片蟲 vs 牛羊肝吸蟲**（兩隻大型吸蟲）：牛羊肝吸蟲有**明顯頭錐**、**腸道有許多側分支**、腹吸盤只比口吸盤稍大；薑片蟲頭錐不明顯、腸道不再分支。

## 3. 肺吸蟲：衛氏肺吸蟲 *Paragonimus westermani* ⭐⭐⭐
- **首二例在台灣發現**（1881 年萬巴德 Manson 報告）；新竹醫院曾是研究重鎮。
- 成蟲像**咖啡豆**；**兩個並列的手掌狀睪丸位於後 1/3**（必考，並殖科）。
- **1st IH：川蜷（*Semisulcospira libertina*）**；**2nd IH：淡水蝦、蟹**（醉蝦、醉蟹）；保蟲宿主貓、狗、豬。
- 囊蚴在小腸脫囊 → **穿過腸壁、經腹腔、穿過橫膈到肺**（不是經血液循環）。
- 症狀**像結核病**：咳嗽、血痰、胸痛；痰中有蟲卵與 **Charcot-Leyden 結晶**；嗜酸性球上升。
- 異位寄生：**腦部最嚴重**（佔位性病灶、癲癇），多發生在 30 歲以下。
- 診斷：痰、糞便、胃液找蟲卵（卵蓋在較平的一端）；皮內試驗、ELISA；X 光常誤診為 TB。治療：Praziquantel（Bithionol 較差）。

## 4. 肝吸蟲（Liver flukes）⭐⭐⭐
| 蟲種 | 感染來源 | 中間宿主 | 重點 |
|---|---|---|---|
| **中華肝吸蟲 *Clonorchis sinensis***、貓肝吸蟲 *O. felineus*、泰國肝吸蟲 *O. viverrini* | **生淡水魚（鯉科）** | 1st **滿州泥螺**；2nd 鯉科淡水魚 | 寄生**膽管**（不是肝）；可活 15 年以上；**膽管癌**；靠**睪丸形狀**分辨（中華：珊瑚狀）；孫中山死於其引起的膽囊癌 |
| **槍狀肝吸蟲 *Dicrocoelium dendriticum*** | **吃到螞蟻** | 1st 陸螺；2nd **螞蟻** | 陸生吸蟲、卵殼厚；可能吃到動物肝臟造成假性感染 |
| **牛羊肝吸蟲 *Fasciola hepatica***（巨型肝吸蟲 *F. gigantica*） | **汙染的水生植物** | 1st **椎實螺**；2nd 水生植物（**非必要**） | 保蟲宿主牛羊；囊蚴**穿腸壁 → 腹腔 → 穿肝被膜 → 肝實質移行 → 膽管**（急性期 traumatic hepatitis）；**Halzoun**（生吃動物肝）；肝外異位（皮下結節、肺膿瘍）；**PZQ 療效不佳 → Triclabendazole／Bithionol** |

- 中華肝吸蟲**感染期 = 囊蚴（metacercaria）**，寄生在**淡水魚（鯉科）的肌肉／鱗下**；生吃或沒煮熟的魚（生魚片、生滾魚片粥）→ 囊蚴在**十二指腸脫囊** → 經**總膽管（Vater 壺腹）上行**至肝內膽管發育為成蟲（**不穿腸壁、不經肝實質**，和 *Fasciola* 不同）。
- 中華肝吸蟲：兒童時期感染 → 脾腫大、營養不良、**侏儒症**。診斷：糞便或十二指腸液找蟲卵，三種卵極相似，要問盛行區。

## 5. 血吸蟲（Schistosomes）⭐⭐⭐
| | **日本血吸蟲 *S. japonicum*** | **曼森血吸蟲 *S. mansoni*** | **埃及血吸蟲 *S. haematobium*** |
|---|---|---|---|
| 中間宿主（螺） | **湖北釘螺 *Oncomelania hupensis*** | **雙臍扁螺 *Biomphalaria*** | **小泡螺 *Bulinus*** |
| 成蟲位置 | **上腸繫膜靜脈叢** | **下腸繫膜靜脈叢** | **膀胱、前列腺、子宮靜脈叢** |
| 蟲卵排出 | 糞便 | 糞便 | **尿液**（偶爾糞便） |
| 疾病 | 肝脾腫大、腸血吸蟲病 | 腸血吸蟲病 | **泌尿性血吸蟲病（血尿）** |

- **感染**：尾蚴**鑽皮膚** → 尾動幼蟲皮膚炎；水鳥血吸蟲尾蚴造成「**泳者之癢（swimmer's itch）**」。
- **片山熱（Katayama fever）**：感染 1–3 個月後的急性期，免疫複合體沉積引起過敏。
- **蟲卵造成肉芽腫**（主要致病原因）。
- 治療：Praziquantel；Artemether；Oxamniquine（只針對曼森，效果差）。

- 肺吸蟲：**皮內試驗**敏感度 80–90%，但痊癒後仍**陽性 10–20 年**（只適合流病篩檢）；腦部 CT／MRI 可見 **soap bubble sign**；Bithionol 抑制 succinate dehydrogenase。
- 陸生 vs 水生：看 **2nd IH**（水生植物／魚 → 水生；蝗蟲、螞蟻 → 陸生）；陸生吸蟲卵**殼厚、顏色深**（抗乾燥）。

- 臨床三階段：① **尾動幼蟲皮膚炎**（24 h → macular rash；swimmer's／fisherman's itch）② **免疫複合體 → 片山熱**（急性期：蕁麻疹、高燒、腹瀉、哮喘、咳嗽、肝壓痛）③ **蟲卵反應**：排出 → 血便黏膜便（mansoni、japonicum）／血尿蛋白尿（haematobium）；留在組織 → 肝脾腫大、門脈高壓、腹水、**侏儒症**、側枝循環；膀胱癌、尿毒症（haematobium）；異位到肺、腦（癲癇）、脊髓（癱瘓）、生殖道；**egg granuloma**：嗜酸性球 → 淋巴球 → 上皮樣與巨細胞。

- 治療：**PZQ**（對所有血吸蟲有效、破壞 tegument）；**Artemether**（青蒿素衍生物，**針對童蟲**）；**Oxamniquine**（只對曼森）。

# 考點分析

## 🔥 高頻考點（百十三 w5~6 Trematodes 考古）
- **發育順序**（miracidium → sporocyst → redia → cercaria → metacercaria）。
- **血吸蟲的例外**：雌雄異體、無卵蓋、一個中間宿主、尾蚴鑽皮膚、沒有雷蚴與囊蚴。
- **吃什麼得什麼**：水生植物 → 薑片蟲、牛羊肝吸蟲；淡水魚 → 中華肝吸蟲、異形吸蟲；蝦蟹 → 肺吸蟲；螞蟻 → 槍狀肝吸蟲。
- **共通藥 Praziquantel**；牛羊肝吸蟲例外（PZQ 療效不佳 → **Triclabendazole**／Bithionol）。
- **113 期中考古（第 20–41 題，115 第二組整理，練習區已收錄 17 題）**：毛蚴孵化法 → 血吸蟲；Charcot-Leyden → 肺吸蟲；血吸蟲**沒有 metacercaria**；Fasciola 會破壞肝實質；**spurious infection = Dicrocoelium、Capillaria hepatica**；中華 vs 貓肝吸蟲靠**居住地區**；**喝生水不會得肺吸蟲**；吸蟲**不脫皮**；感染兩週只能用**免疫學**檢測；**槍狀肝吸蟲不會到腦**；配合題：最小（異形）、吃水生植物（薑片蟲、牛羊）、昆蟲中間宿主（胰臟吸蟲）、PZQ 無效（牛羊）、吃生魚（中華、異形、貓）。
- 台灣首例：橫川異形吸蟲、衛氏肺吸蟲。
- 血吸蟲三種的螺、寄生靜脈叢與蟲卵排出途徑。

## 📝 出題模式
- 臨床情境：嘉南地區病人吃荸薺後嚴重腹瀉 → 薑片蟲；咳血、X 光像 TB、吃過醉蟹 → 肺吸蟲。
- 考古也有**配合題**（網站練習區未收錄，請看原檔）。

## 📒 115 共筆補充（week5）
- **衛氏肺吸蟲不經血液循環**：囊蚴在十二指腸脫囊 → **穿腸壁進腹腔 → 穿過橫膈 → 肺**（和多數寄生蟲走血流不同）。
- 肺部病程三期：**浸潤（膿腫）期 → 囊腫期 → 纖維疤痕期**；成蟲雌雄同體、異體受精，例外是**三倍體孤雌生殖型**。台灣有分布但病例少，因河川汙染、少吃淡水蝦蟹。
- **橫川異形吸蟲的生活史修正**：老師簡報寫「蟲卵在水中孵化」，但生活史圖與文獻都是**螺吃下含胚卵後在螺體內孵化**。
- 薑片蟲卵與 *Fasciola hepatica* 卵外觀幾乎無法區分 → 要靠**飲食史（生水生植物）、旅遊史**；治療 **praziquantel 25 mg/kg，一天三次**。
- 吸蟲總論：比線蟲低等（線蟲有假體腔、吸蟲無體腔）；Monogenea、Aspidogastrea 不在範圍；**血吸蟲是唯一雌雄異體、卵無卵蓋、沒有雷氏幼蟲期**。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| 所有吸蟲都雌雄同體 | **血吸蟲雌雄異體**（雄蟲有抱雌溝） |
| 所有吸蟲卵都有卵蓋 | **血吸蟲卵無卵蓋** |
| 血吸蟲有 redia、metacercaria | 血吸蟲**沒有雷蚴、囊蚴**；尾蚴**分叉**、直接鑽皮 |
| 吸蟲幼蟲靠脫皮長大 | 脫皮是**線蟲與節肢動物**；吸蟲靠變態與無性增殖 |

| Fasciola 幼蟲經膽管逆流、不傷肝 | 穿腸壁 → 腹腔 → **穿肝被膜在肝實質移行** → 膽管 |
