## 一眼看完：感染期 × 進入途徑

@ch intro
| 感染期 | 進入途徑 | 蟲 |
|---|---|---|
| **胚胎化蟲卵** | 經口（手、土、食物） | 蛔蟲、鞭蟲、蟯蟲、犬蛔蟲、肝毛線蟲 |
| **絲狀幼蟲 L3**（filariform） | **鑽皮膚**（土壤） | 美洲鉤蟲、十二指腸鉤蟲、犬／巴西鉤蟲、糞小桿線蟲 |
| **L3**（節肢動物帶入） | **叮咬**／蒼蠅帶進眼 | 班氏、馬來、羅阿、蟠尾絲蟲、犬心絲蟲；東方眼蟲 |
| **食物裡的幼蟲** | 經口（生肉、生魚、生螺） | 旋毛蟲（包囊幼蟲）、海獸胃、顎口、廣東住血（L3）、菲律賓毛線蟲 |
| **囊蚴 metacercaria** | 經口（2nd IH） | 血吸蟲以外的**所有吸蟲** |
| **尾蚴 cercaria** | **鑽皮膚**（淡水） | 日本、曼森、埃及血吸蟲 |
| **Procercoid／plerocercoid** | 經口、傷口 | 廣節裂頭絛蟲、曼氏裂頭絛蟲（期末） |

- **會鑽皮膚的只有三類**：鉤蟲、糞小桿線蟲（都是 L3 絲狀幼蟲）、血吸蟲（尾蚴）。再加上曼氏裂頭絛蟲的 plerocercoid 從**敷傷口的蛙皮**鑽入。
- **所有血絲蟲的感染期都是 L3**；微絲蚴是診斷期。

## ① 胚胎化蟲卵（經口）

@ch sth,enterobius-toxocara,capillaria-strongyloides
| 蟲 | 從哪吃到 | 卵多久有感染力 | 進去之後 |
|---|---|---|---|
| *Ascaris lumbricoides* 蛔蟲 | 土壤汙染的食物、手 | 要在**土壤中胚胎化** | 小腸孵化 → 肝 → **肺** → 吞回小腸 |
| *Trichuris trichiura* 鞭蟲 | 同上 | 要在土壤中胚胎化（排出時未胚胎化） | 小腸孵化 → **盲腸、大腸**；**不經過肺** |
| *Enterobius vermicularis* 蟯蟲 | 手 → 口、衣物、塵埃、吸入 | **約 6 小時**（肛周產卵） | 小腸孵化 → 盲腸；**自體再感染**、全家傳染 |
| *Toxocara canis* 犬蛔蟲 | 狗糞汙染的沙坑、公園土壤 | 排出後 **2–5 週** | 幼蟲在人體移行（肝、肺、眼、腦），不會成熟 |
| *Capillaria hepatica* 肝毛線蟲 | 動物死亡分解後釋出的卵 | 要在土壤中胚胎化 | 小腸孵化 → 門脈 → **肝**成蟲 |

- 大表把蛔蟲、鞭蟲、蟯蟲、犬蛔蟲都寫成「**含 L3 幼蟲的蟲卵**」。
- 犬蛔蟲另一條路：吃生的**保幼宿主**（雞、羊、兔的肉或內臟），吃進的是幼蟲（日韓病例）。

## ② 絲狀幼蟲 L3 鑽皮膚（土壤）

@ch sth,capillaria-strongyloides
| 蟲 | 感染期 | 其他途徑 | 重點 |
|---|---|---|---|
| *Necator americanus* 美洲鉤蟲 | L3 **絲狀（有鞘）幼蟲** | — | 經肺；arrested development |
| *Ancylostoma duodenale* 十二指腸鉤蟲 | L3 絲狀幼蟲 | **也可經口、經母乳** | 經肺；arrested development |
| *A. caninum*／*A. braziliense* 犬／巴西鉤蟲 | L3 絲狀幼蟲 | — | 人不是適合宿主，在皮下亂鑽 → **CLM**，不會成熟 |
| *Strongyloides stercoralis* 糞小桿線蟲 | L3 **絲狀幼蟲** | 母體哺乳；**自體感染** | 腸內直接變成絲狀幼蟲，鑽腸黏膜或肛周皮膚再感染 |

- 糞便裡的**桿狀幼蟲（rhabditiform）是診斷期**，蛻皮成絲狀幼蟲才是感染期。
- 鉤蟲 L3 鑽皮膚 → **Ground itch**（最早出現的症狀）。

## ③ L3 由節肢動物帶入（血絲蟲、眼蟲）

@ch filaria,intro
| 蟲 | 病媒 | 成蟲在哪 |
|---|---|---|
| *Wuchereria bancrofti* 班氏絲蟲 | **蚊子**（家蚊 *Culex*、斑蚊、曼蚊、瘧蚊） | 淋巴管、淋巴結 |
| *Brugia malayi* 馬來絲蟲 | **蚊子**（曼蚊 *Mansonia*、斑蚊、瘧蚊） | 淋巴管 |
| *Loa loa* 羅阿絲蟲 | **斑虻** *Chrysops*（白天） | 皮下（會爬過眼睛） |
| *Onchocerca volvulus* 蟠尾絲蟲 | **黑蠅** *Simulium*（白天） | 皮下結節 → 河盲症 |
| *Dirofilaria immitis* 犬心絲蟲 | 蚊子 | 人體內無法成熟（**肺部肉芽腫**，X 光像錢幣狀病灶） |
| *Thelazia callipaeda* 東方眼蟲 | **蒼蠅**把幼蟲帶進結膜 | 結膜（長跑、馬拉松） |

- 血絲蟲：**L3 = 感染期、微絲蚴 = 診斷期**；從 L3 長到成蟲約 18 個月。
- 考古陷阱：蚊子傳給人的**不是微絲蚴**。微絲蚴是蚊子從人血裡吸走的那一期。

## ④ 食物裡的幼蟲（食源性線蟲）

@ch foodborne,capillaria-strongyloides
| 蟲 | 感染期 | 吃了什麼 | 在人體 |
|---|---|---|---|
| *Trichinella spiralis* 旋毛蟲 | **被囊幼蟲**（encysted larva） | 生**豬肉**、熊肉（生肉都會） | 小腸成蟲 → 幼蟲到**橫紋肌**結囊 |
| *Anisakis simplex* 海獸胃線蟲 | **L3** | 生**海魚**、魷魚 | 鑽胃腸壁，不會成熟 |
| *Gnathostoma spinigerum* 顎口線蟲 | **L3** | 生**淡水魚**、泥鰍、蛙、蛇、鳥 | 移行，不會成熟 |
| *Angiostrongylus cantonensis* 廣東住血線蟲 | **L3** | 生**螺**（非洲大蝸牛、*Pila*）、蛞蝓、淡水蝦、陸蟹、蛙；汙染的生菜 | 幼蟲到**腦**（嗜酸性腦膜炎） |
| *Capillaria philippinensis* 菲律賓毛線蟲 | **魚體內的幼蟲** | 生**淡水魚** | 小腸成蟲，**自體感染**使蟲數越來越多 |

- 旋毛蟲的包囊幼蟲**同時是感染期和診斷期**（肌肉切片）。
- 廣東住血線蟲：**只有 L3 能感染人**；大鼠糞便排出的是 L1，在螺體內發育成 L3（不增殖）。
- 大表原本把菲律賓毛線蟲的感染期印成「含 L3 幼蟲的蟲卵」，紅筆劃掉改成「含 L3 幼蟲的**淡水魚**」。

## ⑤ 囊蚴 metacercaria（吸蟲，血吸蟲除外）

@ch trematodes
| 囊蚴在哪（2nd IH） | 蟲 | 成蟲在哪 |
|---|---|---|
| **水生植物**（菱角、荸薺、茭白筍、蓮藕） | *Fasciolopsis buski* 薑片蟲 | 小腸 |
| **水生植物**（菱角、荸薺） | *Gastrodiscoides hominis* 人雙口吸蟲 | **大腸** |
| **水生植物**（水田芥）、生水 | *Fasciola hepatica*／*F. gigantica* 肝蛭 | 穿肝實質 → 膽管 |
| **淡水魚**（鯉科） | *Clonorchis sinensis* 中華肝吸蟲 | 膽管 |
| **淡水魚** | *Opisthorchis viverrini*／*O. felineus* | 膽管 |
| **淡水魚**（香魚、鯉科）、蛙 | *Metagonimus yokogawai* 橫川吸蟲 | 小腸 |
| **海水魚**（烏魚） | *Heterophyes heterophyes* 異形吸蟲 | 小腸 |
| **淡水蝦蟹**（澤蟹 *Potamon*；醉蝦醉蟹） | *Paragonimus westermani* 肺吸蟲 | 穿橫膈 → **肺** |
| **蝗蟲** | *Eurytrema pancreaticum* 胰吸蟲 | 胰管 |
| **螞蟻** | *Dicrocoelium dendriticum* 槍狀肝吸蟲 | 膽管、膽囊 |
| **很廣泛**（螺、蛙、魚、水生植物） | *Echinostoma ilocanum* 棘口吸蟲 | 小腸 |

- 招牌例子：中華肝吸蟲的**糞便蟲卵 = 診斷期**、**魚肉裡的囊蚴 = 感染期**。
- 肝蛭的 2nd IH **可有可無**，囊蚴直接附在水生植物上。

## ⑥ 尾蚴 cercaria 鑽皮膚（血吸蟲）

@ch trematodes
| 蟲 | 中間宿主（螺） | 成蟲在哪 | 卵從哪排 |
|---|---|---|---|
| *Schistosoma japonicum* 日本血吸蟲 | 湖北釘螺 *Oncomelania hupensis* | **上腸繫膜**靜脈叢 | 糞便 |
| *S. mansoni* 曼森血吸蟲 | 雙臍扁螺 *Biomphalaria* | **下腸繫膜**靜脈叢 | 糞便 |
| *S. haematobium* 埃及血吸蟲 | 小泡螺 *Bulinus* | **膀胱**、前列腺、子宮靜脈叢 | **尿液** |

- 血吸蟲**只有一個中間宿主**，沒有雷氏幼蟲和囊蚴，所以感染期是**尾巴分叉的尾蚴**，在淡水中直接鑽皮膚。

## ⑦ 絛蟲：procercoid／plerocercoid（期末）

@ch cestodes-pseudo
| 蟲 | 感染期 | 怎麼感染 | 人的角色 |
|---|---|---|---|
| *Diphyllobothrium latum* 廣節裂頭絛蟲 | **Plerocercoid**（長尾蚴） | 生的**淡水魚**（鮭、鱒、梭魚、鱸魚） | 最終宿主 → B12 缺乏 |
| *Spirometra (D.) mansoni* 曼氏裂頭絛蟲 | **Procercoid＋plerocercoid**（兩種） | 生水裡帶 procercoid 的橈足類；生的蛙、蛇；**蛙皮、蛇肉敷傷口** | 第二中間宿主或保幼宿主 → sparganosis |

- 考古必考：*D. mansoni* 有**兩種感染期**。
- 圓葉目（囊尾蚴、擬囊尾蚴、包囊蚴）還沒上到，上完再補。

## 感染期 vs 診斷期：容易搞混的

@ch intro,capillaria-strongyloides,filaria,foodborne
| 蟲 | 感染期 | 診斷期 |
|---|---|---|
| 中華肝吸蟲 | 魚肉裡的**囊蚴** | 糞便**蟲卵** |
| 血絲蟲 | **L3**（病媒叮咬） | 血中**微絲蚴** |
| 糞小桿線蟲 | **絲狀幼蟲** | 糞便**桿狀幼蟲** |
| 廣東住血線蟲 | 螺體內 **L3** | （大鼠糞便 L1） |
| 旋毛蟲 | 肌肉**包囊幼蟲** | 同一期（肌肉切片） |
| 廣節裂頭絛蟲 | 魚肉 **plerocercoid** | 糞便蟲卵、GP |
| 蛔蟲、鞭蟲 | **胚胎化**蟲卵 | 糞便裡**未胚胎化**的蟲卵 |

- 「吃到診斷期的蟲卵不會被感染」，卵要先在外界發育。例外是**蟯蟲**，約 6 小時就有感染力，所以會自體再感染。
