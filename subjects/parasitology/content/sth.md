# 土源性蠕蟲（Soil-transmitted Helminths）重點整理

> 范家堃，2026/09/07。蛔蟲 *Ascaris lumbricoides*、鞭蟲 *Trichuris trichiura*、鉤蟲 *Ancylostoma duodenale*／*Necator americanus*。

## 0. 三種 STH 總覽 ⭐⭐⭐
| | **蛔蟲** *Ascaris lumbricoides* | **鞭蟲** *Trichuris trichiura* | **鉤蟲** *A. duodenale*／*N. americanus* |
|---|---|---|---|
| 盛行排名 | **人類最常見**的蠕蟲感染 | 第 **3** 常見的線蟲 | 第 **2** 常見 |
| 成蟲部位 | 小腸 | **大腸（盲腸）** | 小腸（咬住腸壁吸血） |
| 感染方式 | **吃入感染性蟲卵** | 吃入感染性蟲卵 | **絲狀幼蟲（L3）鑽皮膚**；十二指腸鉤蟲也可經口 |
| 肺部移行 | **有**（Ascaris pneumonia） | 無 | **有** |
| 主要表現 | 幼蟲：肺炎、血痰、嗜酸性球增多；成蟲：**腸阻塞**（兒童）、異位移行 | **直腸脫垂**、腹痛腹瀉、生長遲緩 | **缺鐵性貧血**、異食癖（pica）、**ground itch** |

## 1. 蛔蟲 *Ascaris lumbricoides* ⭐⭐⭐
- **最大的人類腸道線蟲**：雌蟲 20–35 cm（粗如鉛筆）；雄蟲較細，尾端**向內捲曲**、有兩根交尾刺。乳白色帶粉紅，表皮有細環紋。
- 分布：全球，**人類最常見的蠕蟲感染**；熱帶、亞熱帶與衛生不良地區盛行率最高。
- **生活史**：吃入感染性蟲卵 → 小腸孵化 → 幼蟲穿腸壁 → 血流到肝 → **肺**（穿入肺泡）→ 氣管 → 吞回 → 小腸發育為成蟲。
- **病理**：
  1. **幼蟲期**：感染後 4 天到 2 週，肺部移行造成 **Ascaris pneumonia**：發燒、咳嗽帶血痰、**嗜酸性球增多**；敏感者會氣喘發作。
  2. **大量感染**：**腸阻塞**，兒童特別常見。
  3. **異位移行（ectopic）**：成蟲鑽進**胰管、膽管、膽囊、肝**，或往上爬到食道。
- 診斷：**糞便中找到蟲卵**（最常用）。受精卵約 60 µm、未受精卵約 90 µm（較大、較長）。
- 治療：**Albendazole**、Mebendazole 或 Ivermectin，通常 1–3 天。
  - **Albendazole 機轉**：結合 **β-tubulin 的 colchicine-sensitive site**，抑制微管聚合；並使幼蟲與成蟲**吸收葡萄糖受損、耗盡肝醣**。

## 2. 鞭蟲 *Trichuris trichiura* ⭐⭐
- 又稱 **human whipworm**；**第 3 常見**的人類線蟲，全球約 8 億人感染，好發在熱帶、衛生差的地區與兒童。
- 構造：**前細後粗**；食道由一串**念珠狀細胞（stichocytes）**構成 **stichosome**；屬於 **Aphasmid nematode**（沒有尾端化學感受器），生殖器官只有單套；雄蟲只有一根交尾刺。
- 臨床：多數無症狀；**大量感染（尤其幼童）→ 腹痛、腹瀉、直腸脫垂（rectal prolapse）**、可能生長遲緩。
- 診斷：糞便找蟲卵；輕度感染建議**濃縮法**；嚴重度與蟲負荷有關，可用 **Kato-Katz** 定量。
- **蟲卵**：**桶狀（barrel shape）**、**兩端有不染色的透明極塞（polar plugs）**、50–54 × 22–23 µm、黃棕色；排出時**尚未胚胎化**。
- 治療：**Mebendazole 首選**，Albendazole 為替代。

## 3. 鉤蟲 Hookworms ⭐⭐⭐
- 人類鉤蟲：**十二指腸鉤蟲 *Ancylostoma duodenale***（♀ 1.0–1.3 cm）與**美洲鉤蟲 *Necator americanus***（♀ 0.9–1.1 cm）。
- 動物鉤蟲：***A. ceylanicum*（錫蘭鉤蟲）**可在人體寄生；***A. braziliense*（巴西鉤蟲）**只鑽皮膚造成**皮膚幼蟲移行症（CLM）**，不會在人體繼續發育。
- 分布：**第 2 常見**的人類蠕蟲感染（僅次於蛔蟲），溫暖潮濕地區；***N. americanus* 以美洲與澳洲為主**；中東、北非、南歐只有 ***A. duodenale***。
- **形態鑑別** ⭐⭐：
  | | 口腔 | 雄蟲交尾刺 | 雌蟲尾刺 |
  |---|---|---|---|
  | *A. duodenale* | **2 對大小相似的牙齒** | 兩根**分開** | **有** caudal spine |
  | *N. americanus* | 一對**切板（cutting plates）** | 兩根在末端**合而為一** | **沒有** |
  | 犬鉤蟲 *A. caninum* | **3 對**大小依序遞減的牙齒 | 分開 | — |
  | 巴西鉤蟲 *A. braziliense* | 2 對大小相異的牙齒 | — | — |
  - 雄蟲尾端有膨大的**交尾囊（copulatory bursa）**。
- **生活史**：桿狀幼蟲（rhabditiform）在土壤中發育為**絲狀幼蟲（filariform L3，有鞘）** → 鑽入皮膚 → 血流 → 肺 → 氣管 → 吞回 → 小腸成蟲。
- **Arrested development（發育停滯，hypobiosis）**：幼蟲在 L3 或 L4 暫停發育數週到數月，使潛伏期延長；是狗與人類鉤蟲生活史的重要特色。
- **臨床**：
  - **缺鐵性貧血最常見**（成蟲咬住腸壁造成失血），可合併心臟併發症。
  - **異食癖（pica）**。
  - 胃腸與營養代謝症狀。
  - **Ground itch**：L3 鑽皮膚時的局部皮膚症狀。
  - 幼蟲經過肺部時的呼吸道症狀。
- 診斷：**糞便找蟲卵**；蟲卵中型（56–76 × 36–40 µm）、薄殼。**各種鉤蟲卵無法區分，只要寫 "hookworm" 就可以。**
- 治療：流行區輕度感染常不治療；美國用 **Albendazole**，也可用 Mebendazole 或 pyrantel pamoate。

## 🎙️ 上課錄影重點（范家堃）
- 十二指腸鉤蟲的「兩對大小相似的牙齒」會鉤住小腸、破壞 enterocyte 後吸血。
- 鉤蟲 L3 鑽皮膚會引發肥大細胞釋放 histamine，非常癢；抓破後可能續發細菌感染。幼蟲經過肺部，路徑跟 *Ascaris* 很像。
- 「同學如果有想咬牆壁、咬鐵條的衝動，可能是鉤蟲感染」（pica）；貧血會讓人昏沉、學習表現差，去家醫科驗糞便即可，Mebendazole 治療很簡單。
- **鉤蟲卵**：「不管什麼鉤蟲放出的卵，你就寫 hookworm，就拿到分數了」；形態像雞蛋或鴨蛋，卵殼很薄。
- 考題情境：臨床醫師夾出的蟲體片段上，**兩根交尾刺合而為一** → 美洲鉤蟲（*Necator*）。以前有問答題時常考這種形態判斷。
- 鉤蟲有「減敏」的好處（花粉熱等過敏），壞處是貧血。

# 考點分析

## 🔥 高頻考點
- 三種 STH 的**感染方式**（吃卵 vs 鑽皮膚）、**成蟲部位**（小腸 vs 大腸）、**有沒有肺部移行**。
- 最常見（蛔蟲）、第二（鉤蟲）、第三（鞭蟲）。
- 特徵症狀配對：腸阻塞（蛔蟲）、直腸脫垂（鞭蟲）、缺鐵性貧血（鉤蟲）。
- **每隻蟲每天的失血量：*A. duodenale* 0.2 ml ＞ *N. americanus* 0.03 ml ＞ *T. trichiura* 0.005 ml**（slides W1 p.56；113 考古第 28 題，正解 C）。鞭蟲只有在**大量蟲體**的重度感染（Trichuris dysentery syndrome）才會貧血。113 考古解答寫的「鞭蟲 8.6 ml」是病人一天的總失血量，不是每隻蟲。
- 鉤蟲形態鑑別：牙齒、切板、交尾刺是否合一、尾刺。
- Albendazole 作用在 β-tubulin。
- *A. braziliense* 造成 CLM。

## 📝 出題模式
- 形態判斷題：「兩根交尾刺合而為一的蟲體片段是哪一種？」
- 蟲卵判斷：桶狀＋極塞（鞭蟲）、蛋白質外套膜（蛔蟲）、薄殼透明（鉤蟲）。

## 🎙️ 老師課堂提示
- 鉤蟲卵寫 "hookworm" 就給分，不需要分種。

## 📒 115 共筆補充（week1）
- 鉤蟲雄蟲**背肋（dorsal ray）**：十二指腸鉤蟲分 2 根、每根再分 **3 小支、分叉淺**；美洲鉤蟲每根分 **2 小支、分叉深**。
- 腸道線蟲感染人數：**蛔蟲 > 鉤蟲 > 鞭蟲**；但在溫帶、已開發國家與兒童，**蟯蟲最常見**。
- 鞭蟲屬 **Aphasmid**：串珠狀食道（stichosome）約佔蟲體 1/2，是**組織切片判讀**的依據；生殖器單套（**monodelphic**，國考單字）。
- 學名書寫格式（填空、跑台、混合蟲卵都要）：屬名大寫、種名小寫、**斜體或底線**。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| 鞭蟲寄生在小腸 | 鞭蟲在**大腸（盲腸）**；蛔蟲、鉤蟲在小腸 |
| 鞭蟲有肺部移行 | **蛔蟲、鉤蟲**有肺部移行；鞭蟲沒有 |
| 鉤蟲經口感染 | 主要是 **L3 絲狀幼蟲鑽皮膚**（只有十二指腸鉤蟲也可經口、經母乳） |
| 鉤蟲造成巨球性貧血 | **缺鐵性（小球性）貧血**；巨球性是廣節裂頭絛蟲（B₁₂） |
| 十二指腸鉤蟲有切板 | **美洲鉤蟲 = 切板**；十二指腸 = **兩對大小相似的牙齒** |
| 美洲鉤蟲雌蟲有尾刺 | **十二指腸鉤蟲**雌蟲有 caudal spine；美洲沒有 |
| 犬鉤蟲兩對牙齒 | 犬鉤蟲**三對**（遞減）；巴西鉤蟲兩對大小相異 |
| 巴西鉤蟲可在人體發育為成蟲 | 只造成**皮膚幼蟲移行症（CLM）** |
| 未受精蛔蟲卵比受精卵小 | **未受精卵較大（約 90 µm）**、長橢圓、內含油滴 |
| 鞭蟲卵排出時已胚胎化 | 排出時**尚未胚胎化**，要在土壤發育 |
| 鉤蟲卵要分種 | 各種鉤蟲卵無法區分，寫 **hookworm** |
| 鞭蟲首選 Albendazole | 鞭蟲首選 **Mebendazole** |
| 直腸脫垂是蛔蟲 | 直腸脫垂是**鞭蟲**（大量感染幼童）；蛔蟲是腸阻塞 |
