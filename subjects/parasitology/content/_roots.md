| miracid- | 小孩 → 第一期幼蟲（有纖毛） | miracidium（毛蚴） |
| sporo- + -cyst | 孢子 + 囊 | sporocyst（胞蚴） |
| cerc- | 尾巴 | cercaria（尾蚴） |
| meta- + cercaria | 之後 + 尾蚴 | metacercaria（囊蚴：吃進去會感染） |
| rhabdit- + -iform | 桿子 + 形狀 | rhabditiform larva（桿狀幼蟲，不會感染） |
| filar- + -iform | 線 + 形狀 | filariform larva（絲狀幼蟲，鑽皮感染） |
| para- + -tenic | 旁邊 + 保持 | paratenic host（保幼宿主：只帶著、不發育） |
| auto- + infection | 自己 | autoinfection（Strongyloides、Enterobius） |
| hyper- + infection | 過多 | hyperinfection（免疫抑制、類固醇） |
| spurious | 假的 | spurious infection（只是吃到蟲卵經過） |
| larva + migrans | 幼蟲 + 遊走 | cutaneous／visceral／ocular larva migrans |
| gyneco- + -phoral | 女性 + 攜帶 | gynecophoral canal（抱雌溝） |
| acetabul- | 醋杯 | acetabulum（腹吸盤） |
| teg- | 覆蓋 | tegument（吸蟲體表） |

| copul- | 交配 | copulatory bursa（鉤蟲雄蟲交接囊） |
| embryon- | 胚胎 | embryonated egg（已發育成熟、可感染的蟲卵） |
