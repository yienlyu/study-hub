# 毛線蟲與糞小桿線蟲 重點整理

> 范家堃，2026/09/14。*Capillaria philippinensis*、*Capillaria hepatica*、*Strongyloides stercoralis*。

## 1. 菲律賓毛線蟲 *Capillaria philippinensis*（腸道型）⭐⭐
- 造成**人類腸道毛線蟲病（intestinal capillariasis）**。
- 分布：**菲律賓**為流行區，泰國也有；其他亞洲國家、中東、哥倫比亞有零星病例。**台灣東部阿美族**病例特別多（老師提到）。
- 感染：吃生的或沒煮熟的**魚**（魚身上的幼蟲是感染期）。
- ⭐ **人畜共通（zoonosis）**：自然界的終宿主是**吃魚的鳥類**（如鷺科水鳥），淡水魚是中間宿主；人吃生魚只是闖進這個「魚 ↔ 鳥」循環。候鳥遷徙可把蟲帶到新地區，所以流行區以外（含台灣）也會出現病例。
- 臨床：腹痛、腹瀉；不治療會因**自體感染（autoinfection）**變嚴重；**蛋白質流失性腸病（protein-losing enteropathy）** → **惡病質、死亡**。
- 診斷：糞便或腸道切片找到**蟲卵、幼蟲或成蟲**；糞便中典型是**未胚胎化的蟲卵**；嚴重感染時可見胚胎化卵、幼蟲甚至成蟲。
- 蟲卵：30–40 µm（中小型），像**帶殼花生**，兩端有**稍微突出的透明卵塞**，卵殼有不明顯的放射狀紋路。
- 治療：**Mebendazole 首選**，Albendazole 為替代。

## 2. 肝毛線蟲 *Capillaria hepatica*（肝臟型）⭐⭐⭐
- 成蟲寄生在多種動物（特別是**大鼠**）的**肝臟**；雌蟲產的卵**留在肝實質中**，不會隨糞便排出。
- ⭐ **終宿主（DH）主要是大鼠**等囓齒動物；人只是**偶然宿主**（吃入土壤中的胚胎化卵）→ 屬於**人畜共通（zoonosis）**。這種蟲**不需要中間宿主**，卵在土壤中胚胎化後直接感染下一個宿主。
- 卵要散到環境中有兩種方式：
  1. 被感染的動物被另一隻動物**吃掉** → 卵經消化釋出，隨第二隻動物的糞便排出 → 在土壤中**胚胎化**。
  2. 動物**死亡分解** → 卵在土壤中成熟。
- 吃入**胚胎化的卵** → 小腸孵出幼蟲 → 經**門脈循環**到肝臟 → 發育為成蟲。
- 臨床：急性或亞急性**肝炎合併嗜酸性球增多**，可能擴散到其他器官，**可能致命**。台灣有 2 例合併肝癌（同時有 HBV／HCV，因果不明；小鼠實驗可致癌）。
- **診斷**：**肝臟切片或解剖**找到成蟲或蟲卵。
- ⭐ **糞便中出現 *C. hepatica* 卵 = 過誤性寄生（spurious finding）**：不是真正感染，而是吃了被感染動物的肝臟（老師的例子：愛吃「三杯鼠」內臟）。停止吃這些內臟後，糞便就不會再有蟲卵。
- 蟲卵：中型到中大型；卵殼有凹陷，在顯微鏡下呈**放射狀紋路**；兩端有透明卵塞，但卵塞**與卵殼密接、不突出**（和鞭蟲不同）。

## 3. 糞小桿線蟲 *Strongyloides stercoralis* ⭐⭐⭐
- 另有 ***S. fülleborni***（感染黑猩猩、狒狒，偶爾感染人）。
- 分布：熱帶與亞熱帶，也見於溫帶（包括美國南部）；**鄉村、機構（安養院等）、低社經族群**較常見。
- 是**兼性寄生蟲（facultative parasite）**的代表。狗也可以傳播。
- **生活史比多數線蟲複雜**：在**自由生活週期**與**寄生週期**之間交替，而且可以**自體感染**，在宿主體內增殖。
  - **自由生活週期**：糞便中的**桿狀幼蟲（rhabditiform）** → 蛻皮 2 次成為**絲狀幼蟲（filariform，感染期）**（直接發育）；或蛻皮 4 次成為**自由生活的雌雄成蟲**，交配產卵，再孵出桿狀幼蟲。
  - **寄生週期**：絲狀幼蟲**鑽皮膚** → 血流到**肺**、進入肺泡 → 氣管 → 咽 → 吞下 → **小腸**蛻皮 2 次成為**雌蟲**。雌蟲嵌在小腸上皮中，以**孤雌生殖（parthenogenesis）**產卵，卵孵出桿狀幼蟲隨糞便排出。
  - **自體感染（autoinfection）**：桿狀幼蟲在體內就變成絲狀幼蟲，鑽入**腸黏膜（內自體感染）**或**肛門周圍皮膚（外自體感染）**，重新走肺部路徑，或**廣泛散布**到全身。
- **臨床**：
  - 常無症狀。
  - 胃腸症狀（腹瀉、便秘、食慾差、腹痛）約在感染後 **2 週**出現，**3–4 週**後糞便可以找到幼蟲。
  - 肺部症狀：幼蟲經過肺時的咳嗽、氣管刺激（像支氣管炎）。
  - 皮膚：**臀部與腰部的蕁麻疹**；**larva currens**（快速移動的爬行疹）。
  - 急性與慢性期通常有**嗜酸性球增多**，但**散布性感染時可能消失**。
  - 慢性：常無症狀；間歇性嘔吐、腹瀉、便秘；肛門搔癢；反覆**氣喘**、**腎病症候群**。
- **超感染（hyperinfection）** ⭐⭐⭐：加速的自體感染，通常（不一定）因**免疫狀態改變**而起。
  - 胃腸與肺部症狀出現或惡化；**糞便或痰中的幼蟲數量增加是 hallmark**；蛋白質流失性腸病。
  - 心肺：咳嗽、喘鳴、胸痛、**咯血**（可能大量）、心房顫動、呼吸困難；**呼吸性鹼中毒**常見；肺部**出血性肺炎**。
  - 中樞神經：**腦膜徵象最常見**。
  - 絲狀幼蟲破壞微血管造成出血，還會把**腸道革蘭氏陰性菌**帶進組織 → **敗血症**。
- **散布性糞小桿線蟲症（disseminated）**：發生在**免疫抑制**病人（器官移植、使用免疫抑制劑），出現腹痛、腹脹、休克、肺部與神經併發症、敗血症，**可能致命**。器官移植捐贈者體內的糞小桿線蟲可以傳給受贈者。
- **診斷**：
  - 糞便或**十二指腸液**中找到**幼蟲**（主要是桿狀幼蟲，偶爾絲狀幼蟲）。
  - 糞便檢查敏感度低，需要**多次採檢**：濃縮法（formalin-ethyl acetate）、**Baermann funnel**、**Harada-Mori 濾紙培養法**、**洋菜平板培養**。
  - 十二指腸液：**Enterotest string** 或十二指腸抽吸。
  - 散布性感染時痰中可見幼蟲。
  - 桿狀幼蟲的特徵：中段明顯的**生殖原基（genital primordium）**。
  - 洋菜平板上的爬行痕跡：**糞小桿線蟲第一天就出現規則的波狀痕跡**；**鉤蟲要 3–5 天**，痕跡不規則扭曲；東方毛線蟲要數天，痕跡淡而不明顯。
  - 蟲卵（少見）：50–58 × 30–34 µm，極薄殼，內有幼蟲；臨床上看到的多半是已孵出的桿狀幼蟲。
- **治療**：**Ivermectin 首選**，**thiabendazole** 為替代；**有散布風險的病人都要治療**。

## 🎙️ 上課錄影重點（范家堃，9/14）
- 生活史要分清楚 **infective stage 與 diagnostic stage**：吃到診斷期的蟲卵不會被感染。
- *C. hepatica* 要靠**切片**才能發現；糞便有卵代表「這個人喜歡吃齧齒類的內臟」。
- 糞小桿線蟲的生活史跟鉤蟲很像，但多了自體感染，會「由少量變多量」。症狀很綜合，有時像大腸癌（便中帶血）。
- 免疫力低的人（例如器官移植）要先排除糞小桿線蟲，驅蟲後再做後續治療比較保險。台灣老人養狗越來越多，要注意。
- **旅遊回來驗糞便的時機**：腸道寄生蟲從感染到產卵大約需要 **1 個月**；旅遊回來才 1–2 週驗糞便是看不到的，要問清楚出國與回國時間。
- 人與其他哺乳動物都能讓蟲發育為成蟲時，**人稱為 final host、動物稱為 reservoir host**（國考用書的定義）。
- 治療：Ivermectin 或 Albendazole；Albendazole 在台灣要特別申請，Ivermectin 有獸醫用藥但劑量不同。

# 考點分析

## 🔥 高頻考點
- ***C. hepatica* 糞便有卵 = 過誤性寄生**；確診要靠肝臟切片。
- *C. philippinensis*：自體感染、蛋白質流失性腸病。
- **糞小桿線蟲**：兼性寄生、孤雌生殖、**自體感染**、免疫抑制者的 **hyperinfection／disseminated**（合併革蘭氏陰性菌敗血症）。
- 糞小桿線蟲診斷方法（Baermann、Harada-Mori、洋菜平板）；治療用 **Ivermectin**。

## 📝 出題模式
- 臨床情境：器官移植或使用類固醇的病人出現肺出血、革蘭氏陰性菌敗血症 → 糞小桿線蟲 hyperinfection。

## 🎙️ 老師課堂提示
- 旅遊後懷疑腸道寄生蟲，要等約 1 個月再驗糞便。

## 📚 考古題（共 18 題：109 期中考古 10、113 考古 8）
- 題型：選正確／單一概念題 9、多選題 4、選錯誤／否定題 3、簡答題 2。
- 練習區可以只勾選某一年的來源；多選、配合與手寫題會直接顯示參考答案。109、110 和 113 完全重複的題目只收一次。

## 📒 115 共筆補充（week2）
- **散布性糞小桿線蟲症的高風險族群**：長期使用**類固醇**、器官移植受贈者、**HTLV-1** 感染者。
- 敗血症機轉：幼蟲穿腸壁時把**腸道菌（如 *E. coli*）**帶入血流 → 革蘭氏陰性菌敗血症、內毒素休克。
- 直接塗片檢出率低 → **Baermann funnel**（收漏斗底部沉澱找活幼蟲）、**洋菜平板**（看細菌爬痕盡頭的幼蟲）；活幼蟲有**傳染風險**。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| *C. philippinensis* 吃生肝感染 | **菲律賓毛線蟲吃生魚**（腸道型）；**肝毛線蟲**才是吃到**胚胎化卵**（肝臟型） |
| 糞便有 *C. hepatica* 卵代表感染 | **假性感染**；真正感染要靠**肝切片** |
| *C. hepatica* 卵塞像鞭蟲一樣突出 | 卵塞**與卵殼密接、不突出**；殼面放射狀紋 |
| *C. philippinensis* 不會自體感染 | **會自體感染** → 蛋白質流失性腸病、惡病質 |
| 糞小桿線蟲的診斷期是蟲卵 | 臨床看到的是糞便中的**桿狀幼蟲**（卵殼極薄，排出時多已孵化） |
| 糞小桿線蟲雌蟲需雄蟲交配 | 寄生期雌蟲以**孤雌生殖**產卵 |
| 散布性感染時嗜酸性球一定很高 | 散布性感染時嗜酸性球**可能消失** |
| 超感染的 hallmark 是嗜酸性球上升 | Hallmark 是糞便或痰中**幼蟲數量增加** |
| 洋菜平板上鉤蟲第一天就有規則痕跡 | **糞小桿線蟲第一天**規則波狀；鉤蟲 3–5 天、不規則 |
| 糞小桿線蟲首選 Mebendazole | 首選 **Ivermectin**（替代 thiabendazole）；有散布風險者都要治療 |
| 自體感染只發生在糞小桿線蟲 | **蟯蟲、糞小桿線蟲、菲律賓毛線蟲**都會自體感染 |
