# 線蟲實驗：蟲卵與蟲體鑑別 重點整理

> 2026/09/21 實驗課（線蟲實體標本與顯微標本）＋學生顯微鏡使用說明影片。圖譜：1 線蟲圖檔、Mixed ova 圖譜。

## 1. 蟲卵鑑別的五個要點 ⭐⭐⭐
**大小、顏色、形狀、裡面內容物、外面附屬物**——五點要「一體到位」，建立「蛋感」。
- **大小分級（平均長徑）**：
  | 等級 | 長徑 |
  |---|---|
  | 小型 | < 45 µm |
  | 中小型 | 45–60 µm |
  | 中型 | 約 60 µm |
  | 中大型 | 60–100 µm |
  | 大型 | > 100 µm |
- 顏色：黃棕色多半是卵殼被糞便中的**膽色素**染色；淡青色或透明則接近背景色。
- 卵縮皺是製片造成的，蛋感建立起來就不會因此誤判。

## 2. 線蟲蟲卵總表 ⭐⭐⭐
| 蟲卵 | 大小 | 顏色 | 形狀 | 內容物 | 附屬物、特徵 |
|---|---|---|---|---|---|
| **蛔蟲受精卵** | 約 60 µm（中型） | **黃棕色** | 對稱、像雞蛋 | 胚細胞（放 7 天以上可發育成 L3） | **蛋白質外套膜（protein coat）**，波浪狀、緻密；很黏，菜葉上洗不掉，要煮熟 |
| 蛔蟲受精卵（去外套膜） | 同上 | 透亮、淡黃 | 同上 | 胚細胞 | 雙層厚卵殼清晰可見 |
| **蛔蟲未受精卵** | 約 **90 µm**（比受精卵大） | 黃棕色 | **長橢圓形、近長方形** | **退化的油滴、顆粒** | 外套膜**較鬆散**、卵殼較薄 |
| **蟯蟲卵** | 約 55 µm（中小型） | 淡青色、透明 | **不對稱（像米粒，一邊扁一邊凸）** | **對摺的幼蟲**（約 6 小時就發育） | 卵殼乾淨光滑；**肛圍擦拭法** |
| **鞭蟲卵** | 約 54 µm（中小型） | 黃棕到深棕（**極塞透明**） | **桶狀、像橄欖球**，對稱 | 胚細胞 | **兩端突出的透明極塞**（像紅酒瓶塞） |
| **鉤蟲卵** | 約 60 µm | 淡青色、透明 | 對稱、像雞蛋或鴨蛋 | 胚細胞或分裂中的細胞（放 7 天以上可能有桿狀幼蟲） | **薄殼、平滑**；**寫 "hookworm" 即可** |
| **糞小桿線蟲卵**（少見） | 約 54 µm | 淡青色 | 對稱 | **一條桿狀幼蟲** | 卵殼**極薄**，通常排出時已破，臨床上多看到幼蟲 |
| **犬蛔蟲卵**（狗糞便） | 80–85 µm（中大型） | 淡青色 | 對稱、近球形 | 胚細胞 | 卵殼**有凹洞，像高爾夫球**；**人的糞便看不到** |
| ***C. hepatica* 卵** | 中型到中大型 | 淡青或黃棕 | 對稱 | 胚細胞 | **放射狀紋路**；兩端透明卵塞**與卵殼密接、不突出**；人糞便中出現 = spurious |
| ***C. philippinensis* 卵** | 30–40 µm（中小型） | — | 對稱，像**帶殼花生**或小香腸 | 胚細胞 | 兩端卵塞**稍微突出**；放射紋不明顯 |

## 3. 蟲體鑑別重點 ⭐⭐
- **線蟲的雌蟲永遠比雄蟲大。**
- **蛔蟲**：20–35 cm、晶瑩剔透；**cuticle 是非細胞性物質**，能抵抗胃酸；雄蟲尾端有**兩根交尾刺**。
- **蟯蟲**：**透明頸翼（頭翼）**＋**燈泡狀的大食道球**；雌蟲 0.8–1.3 cm、尾端長尖、子宮內滿是蟲卵（氧化後呈黑色）。
- **鞭蟲**：**前細後粗**，3–5 cm；**念珠狀食道（stichosome）**由 stichocytes 構成（毛細管性食道，和蛔蟲的肌肉性食道不同）；Aphasmid、單套生殖器；雄蟲**一根**交尾刺。
- **鉤蟲**：約 1 cm、肉眼可見；雄蟲有**交尾囊（bursa）**。
  - 美洲鉤蟲：**切板**；雄蟲兩根交尾刺**末端合而為一**；雌蟲**沒有尾刺**。
  - 十二指腸鉤蟲：**兩對大小相似的牙齒**；交尾刺**分開**；雌蟲**有尾刺（caudal spine）**。
  - 犬鉤蟲：**三對大小遞減的牙齒**。巴西鉤蟲：兩對大小相異的牙齒，只造成皮膚幼蟲移行症。
- **旋毛蟲**：雄蟲有**交尾乳突**；**橫紋肌中的包囊幼蟲**是診斷期與感染期。
- **犬蛔蟲 vs 貓蛔蟲**：頸翼形狀不同：貓蛔蟲**短胖（stumpy）**，犬蛔蟲**狹長（slender）**；雄蟲尾端捲曲。
- **廣東住血線蟲雌蟲**：**黑色腸管與白色子宮纏繞**，像理髮店旋轉燈；雄蟲有交尾傘。最終宿主是大鼠，中間宿主是非洲大蝸牛與蛞蝓。
- **Anisakis**：2–3 cm 的 L3（demo 標本）。

## 4. 微絲蚴鑑別（血片）⭐⭐
- **斑氏絲蟲**：有透明鞘膜、體核排列整齊不重疊、**沒有尾核**、彎曲平順。
- **馬來絲蟲**：有鞘膜、**有尾核**、體核重疊深染、大彎中有小彎。
- 夜間週期性：晚上 10 點到半夜兩三點採靜脈血最容易看到。

## 5. 顯微鏡操作（OLYMPUS CH2）⭐
- 構造（由上到下）：觀察筒、兩個目鏡、轉盤、物鏡、載物台、夾片、XY 軸移動鈕、**聚光鏡**（可上下調整）、光源、開關與調光鈕。
- 步驟：
  1. 打開開關，調光先在最低。
  2. **一律從低倍物鏡開始**往高倍轉。
  3. 放上玻片、夾好，先抓大概的位置。
  4. 用 **4×** 觀察，把光線調亮，用**粗調**再用**細調**對焦。
  5. 轉到 **10×**，再對焦；光線依眼睛的舒適度微調。
  6. 轉到 **40×**（一般看到 40× 就夠），再調焦距。
  7. **雙眼屈光度**：先用右眼對好焦，再轉左邊可旋轉的目鏡調整度數。

## 6. 跑台秘笈：線蟲標本（學長姐「寄蟲跑台秘笈」，★＝考過）⭐⭐
| 標本 | 怎麼認 |
|---|---|
| **Hookworm**（瓶裝） | 5–10 mm、偏小、細、淡黃 |
| ***Necator americanus*** | **一對切板（cutting plate）**；雄：膨大 **copulatory bursa**＋spicule（**J 形尾巴**）；雌：尾端有裂縫（anus）、顏色一致 |
| ★ ***Ancylostoma duodenale*** | **兩對大小差不多的牙齒**、黃棕色；雄 bursa 像一根骨頭；雌 **anus＋caudal spine**、深色 |
| ★ ***A. caninum*** | 偏粉色、**三對牙齒（不等大）**；尾巴分不出 |
| ***A. braziliense*** | **兩對大小不同的牙齒**、淡黃、像爪子 |
| ★ ***Ascaris lumbricoides***（瓶裝） | **粗大隻**、瓶子滿、黃黃的 |
| ***Trichuris trichiura*** | 很小很細、白色絲狀，要用**放大鏡**；**念珠狀食道（stichosome）**兩側透明殼；雄尾巴捲、雌有 vulva |
| ★ ***Enterobius vermicularis*** | **esophageal bulb（深紅球狀）＋ cephalic alae（頭兩側透明）**——標示處就是考點 |
| ***Toxocara canis***（瓶裝） | 淡黃、中等粗細；有 cephalic alae、三片唇 |
| *Trichinella spiralis* | 藍紅色；雄有 copulatory papilla；★ **肌肉中的 encysted larvae（nurse cell）** 好認 |
| *Angiostrongylus cantonensis* | 雌：vulva、anus；★ **barber's pole（紅白纏繞：黑色腸道明顯、白色子宮不明顯）**；鼠肺中的成蟲（紅色半月形） |
| ★ *Achatina fulica*（非洲大蝸牛） | 廣東住血線蟲的中間宿主 |
| *Anisakis simplex* | 小、白、細，用放大鏡 |
| ★ *Capillaria hepatica* | **鼠肝中的蟲卵**：深紅、很多、密密麻麻（考蟲卵） |
| *C. philippinensis* | 只有 ova 圖；會 autoinfection |
| ★ *Wuchereria bancrofti* | 血片微絲蚴：**粉紫、捲曲平順、尾端無核**；Culex／Aedes／Mansonia／Anopheles 傳播 |
| *Brugia malayi* | 三條、深色、雜質淡色淺紫點；**有尾核** |
| 糞小桿線蟲 | 只有 ova 圖（幼蟲旁的圓形是 *E. coli* cyst） |

## 7. Mixed Ova 考試戰略（學長姐「蟲卵祕笈」）⭐⭐
- **找卵**：先在 40× 對好焦，**用 100× 找、400× 確認**（40× 會漏、400× 時間不夠；一片約 10 分鐘）；轉 400× 後**光圈、聚光器要調亮**；確認有**濾光片**（沒有的話顏色都一樣）；沿蓋玻片有規則地找，轉**聚光器**看不同層。
- **大小以受精蛔蟲卵 60 µm 為尺**：大型 ≈ 2 倍、中大型 ≈ 1.5 倍、中小型 ≈ 1/2、小型 ≈ 1/4。斜躺或豎起時大小會失真（兩端不在同一焦平面）。
- **蛔蟲卵要註明（受精／未受精）或（F／UF）**，老師算兩種卵。
- **考試片裡有哪些（不要寫沒有的）**：只有 *Taenia* sp.（沒有 *Echinococcus*）；肝吸蟲類**只有中華肝吸蟲**（沒有泰國、貓）；**只有胰臟吸蟲**（沒有槍狀肝吸蟲）；**只有橫川吸蟲**（沒有異形異形吸蟲）→ **小型蟲卵只有中華肝吸蟲與橫川吸蟲**。
- **易混淆的卵**：
  - 鉤蟲卵 vs **脫去蛋白膜的受精蛔蟲卵**（蛔蟲卵有兩層厚殼）。
  - 未受精蛔蟲卵（蛋白膜、粗糙）vs **肺吸蟲卵**（有卵蓋、底部增厚、金黃、不對稱；**中大型吸蟲卵只有它**）。
  - 中華肝吸蟲 vs 橫川吸蟲：中華**卵蓋旁有肩峰**、殼面粗糙像絲瓜筋（老師強調看卵蓋端，**不要用尾端小突起分**，兩者都有）。
  - **胰臟吸蟲卵 vs 豎起來的鞭蟲卵**：細調看頂底，**一個圈＝卵蓋（胰臟吸蟲）、兩個圈＝卵塞（鞭蟲）**。
  - 三顆大型吸蟲卵：**牛羊肝吸蟲（金黃、最大、狹長不對稱）**、**薑片蟲（淡黃、圓胖）**、**棘口吸蟲（最小、內容物粗顆粒、殼可能龜裂）**。
  - 放射狀紋：*C. hepatica*、*C. philippinensis*、縮小包膜絛蟲；**鳥類鞭蟲卵**（兩端卵塞歪、約菲律賓毛細線蟲 2 倍大）**算雜質，寫了沒分**。
- **最難認**：糞小桿線蟲卵（殼極薄，像雜質）→ 高倍細調找薄殼。
- 會被誤認為蟲卵：花粉粒、保衛細胞、真菌孢子、雜質、氣泡。
- 參考：同學整理的「蟲蟲大表（郭乃榕學姊，Ying 筆記版）」是全寄生蟲總表，在 slides/parasitology/。

## 🎙️ 上課錄影重點（9/21 實驗課）
- 「大小、顏色、形狀、裡面內容物、外面附屬物，五個要點一體到位」；看到蟲卵時五個要點要「一起衝到腦門」。
- **期中考前**晚上會有蟲卵辨識的**加強輔導**，名額有限，由助教公告登記。
- **鞭蟲卵是有名的「重修卵」**：跑台的第一題常放鞭蟲卵（或蛔蟲卵），第一題答錯，考卷會被放到最後面「好好考慮」。
- 鉤蟲卵不需要用微米尺分種，寫 "hookworm" 就給分。
- 犬蛔蟲卵大小是 **80–85 µm**（講義上寫成 mm 要更正）。
- 人是犬蛔蟲的保幼宿主，所以人的糞便中不會有犬蛔蟲卵。
- 糞便蟲卵片考試**也會出 *C. hepatica***。
- 廣東住血線蟲和血絲蟲的 PowerPoint 會放上網，讓同學自學。

# 考點分析

## 🔥 高頻考點（混合蟲卵跑台）
- **鞭蟲卵**（桶狀＋兩端極塞）、**蛔蟲卵**（蛋白質外套膜；受精 vs 未受精）是必考的「重修卵」。
- 蟯蟲卵（不對稱、內有幼蟲）、鉤蟲卵（薄殼透明，寫 hookworm）。
- *C. hepatica* 卵（放射紋、卵塞不突出）。
- 跑台與填空題要寫**學名全名**。

## 📝 出題模式
- 跑台：顯微鏡下辨識蟲卵、蟲體部位（交尾刺、食道球、頸翼、牙齒）。
- 筆試：蟲卵大小分級、哪種卵有極塞或蛋白質外套膜。

## 🎙️ 老師課堂提示
- 第一題答錯鞭蟲卵，代表沒有來上實驗課。
- 期中考前有晚上的蟲卵辨識加強輔導，要登記。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| 線蟲雄蟲比雌蟲大 | 線蟲**雌蟲永遠比雄蟲大** |
| 鉤蟲卵與脫膜蛔蟲受精卵一樣 | 蛔蟲卵是**雙層厚殼**；鉤蟲卵**薄殼透明** |
| 未受精蛔蟲卵 = 肺吸蟲卵 | 肺吸蟲卵**有卵蓋**、底部增厚、不對稱、金黃 |
| 豎起來的鞭蟲卵 = 胰臟吸蟲卵 | 細調：**兩個圈（卵塞）= 鞭蟲**、一個圈（卵蓋）= 胰臟吸蟲 |
| 用尾端小突起分中華肝吸蟲與橫川吸蟲 | 兩者尾端都有；看**卵蓋旁的肩峰**（中華有） |
| 寫「蛔蟲卵」就好 | 要註明**受精（F）或未受精（UF）** |
| 犬蛔蟲卵 80–85 mm | **80–85 µm**（講義誤植） |
| 斑氏絲蟲微絲蚴有尾核 | 斑氏**無尾核**；馬來**有尾核** |
| 用 40× 或 400× 找卵 | **100× 找、400× 確認** |
