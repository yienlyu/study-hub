# 食源性線蟲 重點整理

> 范家堃，2026/09/14、09/22。旋毛蟲 *Trichinella spiralis*、顎口線蟲 *Gnathostoma*、海獸胃線蟲 *Anisakis*、廣東住血線蟲 *Angiostrongylus cantonensis*。

## 1. 豬肉旋毛蟲 *Trichinella spiralis* ⭐⭐⭐
- 分布：全球，**歐洲與美國**部分地區最常見（中國大陸也有）；「有豬有人的地方就有」。
- **同一宿主同時是最終宿主與中間宿主（FH & IH）**。
- **生活史**：
  1. 吃入含**包囊幼蟲（encysted larvae）**的肉 → 胃酸與 pepsin 釋出幼蟲 → 侵入**小腸黏膜**發育為成蟲（♀ 2.2 mm、♂ 1.2 mm），在小腸存活約 **4 週**。
  2. **1 週後**雌蟲產出**幼蟲**（不是卵）→ 移行到**橫紋肌**形成包囊（***T. pseudospiralis* 不形成包囊**）。
  3. 包囊在 **4–5 週**內完成，包囊幼蟲可以存活**數年**。
  4. **大鼠與齧齒類**維持流行；豬、熊等雜食或肉食動物吃了被感染的齧齒類或其他動物的肉。
  5. 人是**意外感染**：吃了處理不當的這些動物的肉。
- 屬於 **Aphasmid nematode**：生殖器官單套；雄蟲有**交尾乳突（copulatory papilla）**。
- **臨床**：
  - 輕度感染可能無症狀。
  - 腸道侵入期：腹瀉、腹痛、嘔吐。
  - **幼蟲移行到肌肉（感染後 1 週）**：**眼眶周圍與臉部水腫**、結膜炎、發燒、**肌肉痛**、**指甲下裂片狀出血（splinter hemorrhages）**、皮疹、**嗜酸性球增多**。
  - 偶爾致命：**心肌炎**、中樞神經侵犯、肺炎。
  - 肌肉包囊形成：肌肉痛與無力，之後症狀消退。
- **診斷**：依臨床症狀與嗜酸性球增多懷疑，再以**抗體檢測、肌肉切片、顯微鏡**確認。肌肉切片中的**包囊幼蟲是診斷期**（也是感染期）。
- **治療**：及早用 **Mebendazole 或 Albendazole** 殺死成蟲、阻止繼續產幼蟲；幼蟲在骨骼肌定居後（感染後 3–4 週）可能無法完全清除。副作用：**骨髓抑制**，長期治療要追蹤 CBC；**孕婦與 2 歲以下兒童不建議使用**。嚴重時加**類固醇**。
- **預防（USDA 溫度）**：整塊肉（不含禽肉與野味）**63 °C（145 °F）**；絞肉與所有野味 **71 °C（160 °F）**；禽肉 **74 °C（165 °F）**。

## 2. 顎口線蟲 *Gnathostoma* spp. ⭐⭐
- 歷史：1836 年在倫敦動物園死亡老虎的胃壁發現；1889 年泰國首例人類病例。
- 屬於 **Spirurida 目**：生活史需要**一個以上的中間宿主**。12 個種，只有 4 種感染人。泰國、日本與東南亞病例最多。
- 種類：***G. spinigerum***（貓、狗；印度、中國、日本、東南亞，最常見）、***G. hispidum***（豬）、***G. doloresi***（日本野豬）、***G. nipponicum***（日本黃鼠狼；頭球只有 **3 排**小鉤）。
- 形態：人體內多半是**進階第三期幼蟲**或很年輕的成蟲；**頭球（head bulb）有 4 排以上小鉤**、身體有表皮棘。
- **臨床**：**CLM、VLM、OLM、NLM**，由進階 L3 移行造成；初期常有嗜酸性球增多。
  - **皮膚型最常見**：軀幹或上肢**間歇性遊走性腫脹**，紅、癢、痛，不治療會反覆數月到數年；蟲有時會從皮膚冒出來。
  - **內臟型（larva migrans profundus）**：肺、胃腸、泌尿生殖、耳、眼、中樞神經。**神經型可造成致命的嗜酸性腦膜炎與脊髓腦炎**；眼型可能失明。
- **診斷＝治療**：**取出蟲體並鑑定**。
- 台灣病例：有錢人**生吞泥鰍**養生而感染；泰國廚師病例。

## 3. 海獸胃線蟲 *Anisakis simplex* ⭐⭐⭐
- **異尖線蟲症（anisakiasis）**：誤食 ***Anisakis simplex*** 與 ***Pseudoterranova decipiens*** 的**幼蟲（L3）**。
- 分布：全球，**生食魚的地區**較多：**日本**（全球約 2 萬例，**超過 90% 在日本**）、南美太平洋沿岸、**荷蘭**（1960 年 Van Thiel 首例，吃生鯡魚）。
- 形態：L3 約 **2 cm**；尾端有特徵性的**尾突（mucron）**；橫切面可見 **Y 字形側索（lateral cords）**。
- **病理**：胃或腸壁因水腫與發炎而**增厚**，偶有潰瘍或出血；可能與幼蟲分泌排泄物引起的**過敏反應**有關。
- **臨床**：吃生海鮮後約 **6 小時**出現**上腹痛、噁心、嘔吐**（急性症狀在 1–3 天內，幾天後緩解）。*P. decipiens* 常造成**喉嚨刺痛症（tingling throat syndrome）**（幼蟲從胃往口移行）。
  - 四大類型：**胃型（最常見，好發於胃體大彎）**、腸型、腸外型、**過敏型**。慢性通常無症狀。
- **診斷與治療**：**胃鏡**看到並取出幼蟲；或手術切除組織做病理。**治療首選是內視鏡或手術取出**。
- 范老師的研究：**Wasabi 殺不死幼蟲**（wasabi 醬約 26–42 分鐘才達 LD50），一般沾一下完全沒用。

## 4. 廣東住血線蟲 *Angiostrongylus cantonensis* ⭐⭐⭐
- **大鼠肺線蟲（rat lungworm）**，是**人類嗜酸性腦膜炎最常見的病因**。（*A. costaricensis* 造成腹部或腸道型血管圓線蟲症。）
- **生活史**：
  - **最終宿主：大鼠**。成蟲在大鼠**肺動脈**產卵 → 卵卡在肺動脈末梢孵出 L1 → 經肺泡、氣管、咽、食道到腸道 → **L1 隨大鼠糞便排出**。
  - **中間宿主：軟體動物**（陸生螺如**非洲大蝸牛 *Achatina fulica***、水生螺 *Pila*、蛞蝓 slugs）→ 發育為**感染性 L3**。
  - 大鼠吃了螺 → 幼蟲到 **CNS** 發育（2–3 週）→ 到蜘蛛膜下腔 → 經靜脈到肺動脈成熟。感染 40–60 天後大鼠糞便可見幼蟲。
  - **保幼宿主（paratenic）**：淡水**蝦、陸蟹、青蛙**。
  - **人的感染**：吃生的螺、蛞蝓或保幼宿主；或吃到被螺**黏液（含 L3）**汙染的生菜。
- 雌蟲特徵：**黑色腸管與白色子宮纏繞**，像理髮店的旋轉燈。
- **臨床**：
  - **嗜酸性腦膜炎**：幼蟲在腦中以及宿主的局部反應。
  - 潛伏期 **1–5 週（平均 2 週）**。
  - 頭痛（枕部、顳部為主）、頸部僵硬、噁心嘔吐、輕微發燒、皮疹、搔癢、腹痛、癲癇。
  - 腦膜徵象、**腦神經麻痺（III、IV、VI、VII）**、感覺異常、疼痛與無力。
  - **很少死亡**，多數完全恢復；偶爾侵犯眼前房；肺部侵犯少見。
- **診斷**：**腦脊髓液嗜酸性球增多（500–5000 cells/mm³，其中 20–90% 是嗜酸性球）**、CSF 蛋白上升、葡萄糖正常或略低；可見 **Charcot-Leyden crystals**；血液嗜酸性球 > 10%；血清學（IF、EIA）確認。
- **治療**：**沒有公認有效的治療**；**不建議用驅蟲藥**（仍有爭議）。
- 預防：教小朋友不要摸路上的蝸牛，摸到要用肥皂洗手。

## 🎙️ 上課錄影重點（范家堃）
- **嗜酸性球增多超過 50%** 時不要排除蠕蟲感染；排除過敏與其他血液疾病後，一定要懷疑 helminths。
- 旋毛蟲：幼蟲可以跑到眼眶（水腫）、肌肉、心臟（心肌炎）、神經系統、肺（pneumonitis）。「**如果期中考問你哪些寄生蟲可以跑到什麼部位，這是同學要整理一下的**。」
- 用 wasabi 沾生肉或生魚片完全殺不死寄生蟲；生肉、生菜、山泉水都要注意。
- 美國農業部篩檢了幾十萬隻豬都沒有發現旋毛蟲；台灣有高官吃生鱉肉感染的病例。
- 廣東住血線蟲：小女孩幫蝸牛過馬路後吃吐司 → 吃進 L3 → 腦膜炎。「**問你吃淡水蝦類會感染哪些寄生蟲時，不要排除 A. cantonensis**。」
- 顎口線蟲：台灣有人生吞泥鰍養生而感染。

# 考點分析

## 🔥 高頻考點
- **旋毛蟲**：產幼蟲、FH = IH、橫紋肌包囊、眼眶水腫＋肌肉痛＋嗜酸性球增多；*T. pseudospiralis* 不形成包囊。
- **嗜酸性腦膜炎最常見的病因 = *A. cantonensis***；中間宿主是螺、蛞蝓；保幼宿主是蝦、蟹、蛙。
- **Anisakis**：胃大彎最常見、胃鏡取出、日本最多。
- 顎口線蟲：遊走性皮下腫脹。
- 整理「**哪些寄生蟲會跑到哪些部位**」（眼、腦、肌肉、心臟、肺）。

## 📝 出題模式
- 「吃淡水蝦可能感染哪些寄生蟲？」（不要漏掉 *A. cantonensis*）。
- 臨床情境：吃生野豬肉後眼眶水腫、肌肉痛、嗜酸性球增多 → 旋毛蟲。

## 🎙️ 老師課堂提示
- 期中考可能問「哪些寄生蟲可以跑到什麼部位」。
- 嗜酸性球 > 50% 要懷疑蠕蟲感染。

## 📚 考古題（共 28 題：113 考古 17、109 期中考古 11）
- 題型：選正確／單一概念題 15、選錯誤／否定題 5、多選題 5、簡答題 3。
- 練習區可以只勾選某一年的來源；多選、配合與手寫題會直接顯示參考答案。109、110 和 113 完全重複的題目只收一次。

## 📒 115 共筆補充（week3）
- **旋毛蟲的 nurse cell**：幼蟲侵入骨骼肌細胞後把它重塑成「護理細胞」，誘導血管新生與膠原沉積形成包囊；免疫反應以 **TH2** 為主（TGF-β1、fibroblast、collagen）。宿主特異性極低，豬、熊、鼠、人都可**同時當最終與中間宿主**。
- 老師在錄影中說包囊幼蟲「免疫力下降時會出來侵犯眼睛和腦」；共筆學藝查證：一般說法是包囊要被下一個宿主吃掉才繼續生活史，但有文獻指出原宿主免疫低下時包囊較易破裂。
- **海獸胃線蟲 L3**：2–3 cm、像豆芽菜，有**尾刺**與 **Y 形 lateral cords**（可用來和其他線蟲區分）。老師學生的研究：鯖魚、白帶魚以 ***A. pegreffii*** 最多；幼蟲多在腸胃內臟，宿主死後會移行到肌肉；泡**芥末**約 26 分鐘死一半，用芥末主成分 **AITC** 約 14 分鐘。
- **廣東住血線蟲**：只有 **L3** 能感染人（老師特別強調感染期）；L1 → L3 在螺體內**不會增殖**（數量不變）；大鼠感染後 **40–60 天**糞便可見幼蟲。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| 旋毛蟲雌蟲產卵 | 雌蟲**直接產幼蟲**（不是卵） |
| 旋毛蟲的最終宿主與中間宿主不同 | **同一宿主同時是 FH 與 IH** |
| 所有旋毛蟲都在肌肉形成包囊 | ***T. pseudospiralis* 不形成包囊** |
| 旋毛蟲幼蟲寄生在平滑肌 | 包囊在**橫紋肌**；也是診斷期與感染期 |
| 旋毛蟲症狀：腸阻塞 | 典型：**眼眶與臉部水腫**、肌肉痛、**指甲下裂片狀出血**、嗜酸性球↑；致命：心肌炎 |
| Mebendazole 能清除已包囊的幼蟲 | 要**及早**用；幼蟲在肌肉定居後可能無法清除；孕婦與 2 歲以下不建議 |
| 顎口線蟲在人體會發育為成蟲 | 人體內多半是**進階 L3**，造成 CLM／VLM／OLM／NLM；**取出蟲體 = 診斷＝治療** |
| Anisakis 感染期是成蟲 | 吃到魚、魷魚中的 **L3 幼蟲** |
| Anisakis 以腸型最常見 | **胃型最常見**（胃體大彎）；吃生海鮮後約 6 小時上腹痛 |
| Anisakis 用驅蟲藥治療 | **內視鏡（或手術）取出** |
| Wasabi 可殺死 Anisakis | **殺不死**（約 26–42 分鐘才達 LD50） |
| 廣東住血線蟲最終宿主是人 | 最終宿主是**大鼠**（肺動脈）；人是意外宿主 |
| 廣東住血線蟲的中間宿主是蝦蟹 | 中間宿主是**軟體動物**（非洲大蝸牛、蛞蝓）；蝦、蟹、青蛙是**保幼宿主** |
| 廣東住血線蟲造成化膿性腦膜炎 | **嗜酸性腦膜炎**（CSF 嗜酸性球、Charcot-Leyden 結晶） |
| 廣東住血線蟲要用驅蟲藥 | **沒有公認有效治療**、不建議用驅蟲藥 |
| 「吃淡水蝦會得哪些寄生蟲」只選肺吸蟲 | 別漏掉**廣東住血線蟲**（蝦是保幼宿主） |
