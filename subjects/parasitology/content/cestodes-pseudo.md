## 1. 絛蟲分類 ⭐⭐

- 扁形動物門（Platyhelminthes）→ 吸蟲綱（Trematoda）與**絛蟲綱（Cestoda，舊稱 Cestoidea）**。絛蟲綱有 **13 個目**，只有**假葉目（Pseudophyllidea）**和**圓葉目（Cyclophyllidea）**會感染人。
  - 共筆學藝補充：Pseudophyllidea 是舊分類名，現已拆成 Bothriocephalidea 與 Diphyllobothriidea，**考試不會考**。
  - 共筆提醒：slides 分類圖有一處把 Trematoda 打錯。
- 醫學上重要的種類與長度單位：

| 目 | 蟲種 | 長度單位 |
|---|---|---|
| **假葉目** | 廣節裂頭絛蟲 *Diphyllobothrium latum* | 公尺 |
| | 曼氏裂頭絛蟲 *Spirometra mansoni* | 公分 |
| **圓葉目** | 牛肉絛蟲 *T. saginata*、亞洲絛蟲 *T. (saginata) asiatica*、豬肉絛蟲 *T. solium* | 公尺 |
| | 縮小包膜絛蟲 *H. diminuta*、短小包膜絛蟲 *H. nana*、犬複殖器絛蟲 *D. caninum* | 公分 |
| | 單胞絛蟲 *E. granulosus*、多胞絛蟲 *E. multilocularis* | 公釐 |

- 為了和曼氏血吸蟲（*Schistosoma mansoni*）區分，**考試時曼氏裂頭絛蟲建議寫舊名 *D. mansoni***。

## 2. 絛蟲總論 ⭐⭐⭐

- 外觀：**白色或乳白色**、長如皮帶、**分節**，數公釐到數公尺（越長通常代表活越久）；由**頭節（scolex）、頸部（neck）、體節鏈（strobila）**組成，體節鏈由一節節 **proglottid** 串成，前細後寬。
- 會把養分吸收殆盡；共筆學藝補充：**惡性貧血最常見是廣節裂頭絛蟲搶 B12**，不是每種絛蟲都會，牛肉、豬肉絛蟲通常只有輕微腸胃不適。
- **所有絛蟲都是寄生性**：成蟲多在脊椎動物消化道、可活多年；幼蟲在 1–2 個中間宿主（脊椎或無脊椎動物）體內發育。**假葉目 2 個中間宿主，圓葉目 1 個或沒有**。
- 有些絛蟲有宿主專一性，有些能寄生多種宿主；已知約 **6000 種**，幾乎每種脊椎動物都至少有一種絛蟲。
- **沒有口、沒有消化系統** → 直接從宿主腸道吸收養分（考古：「Class Cestoda 有消化道」是錯的）。
- 排泄系統：**焰細胞（flame cell）**。
- **全部雌雄同體（hermaphrodite）**，和吸蟲一樣（**血吸蟲例外**）。
- 頸部末端的**生發細胞**持續產生節片，每個節片都有一套生殖系統。治療要**把只有幾毫米的頭節取出**，頭部和頸部殘留就會再長。
- **為什麼假葉目 GP 很少脫落？**（共筆學藝補充）假葉目有**子宮孔**，可直接從節片排卵，老化的 GP 通常在腸道內崩解；圓葉目**沒有子宮孔**，所以 GP 要整段脫落（隨糞便排出，或像牛肉絛蟲主動爬出肛門）。

### 構造

- **體表**：具代謝活性的合胞體皮層 **tegument**（表面**醣萼**可抵抗宿主消化酶），特化出 **microthrix（微毛）**增加吸收。
- **無體腔**，器官之間由**實質細胞（parenchymal cells）**填充，儲存肝醣、支持蟲體。
- **石灰小體（calcareous corpuscles）**：成分**碳酸鈣**，在實質組織裡，**成蟲與幼蟲都有**，是**絛蟲的特徵性構造**，看到就代表是絛蟲。學藝補充：可緩衝酸性環境、儲存離子；病理切片（裂頭蚴症、囊尾蚴症、包蟲症）中 **H&E 呈深紫藍色（嗜鹼性）的同心圓層狀小體**就是絛蟲組織的證據。
- 頭節與頭節上的神經：兩目頭節都有**原始神經系統**。

## 3. 假葉目 vs 圓葉目 ⭐⭐⭐（必背比較）

| | **假葉目 Pseudophyllidea** | **圓葉目 Cyclophyllidea** |
|---|---|---|
| 頭節 | **長條狀，杏仁形／匙形（almond / spatulate）**；背腹各一條凹陷的**吸溝（bothrium，sucking groove）**；沒有額嘴 | **球狀（globular）**；**4 個吸盤**（背 2 腹 2），中央頂端可能有**頂突（rostellum）**，周邊有**吻鉤（hooklets）**；有些 rostellum 可伸縮（共筆：長得像刮鬍刀） |
| 子宮 | **不分支** | **有分支，兩端盲端** |
| 子宮孔（uterine pore） | **有** | **無** |
| 生殖孔 | **腹面（ventral）中線** | **側緣（lateral）** |
| 受孕節片形狀 | **橫的長方形（躺著）**；廣節＝**玫瑰花瓣狀**子宮、曼氏＝**螺旋狀**；生殖孔在上、子宮孔在下 | **直的長方形（豎著）**，例外：**短小、縮小包膜絛蟲是橫的**；染色看子宮分支數分種：**豬肉 7–13、牛肉 15–30** |
| 排卵 | 蟲卵從子宮孔排出、隨糞便出來（GP 老化才整段脫落） | **GP 從母體脫落**，GP 和蟲卵一起隨糞便排出 |
| 蟲卵 | **有卵蓋**，卵蓋對側有小點（knob）；孵出**有纖毛的幼蟲**（coracidium） | **無卵蓋**，不會孵出纖毛幼蟲 |
| Apolysis | **Anapolytic（假脫節性）**：隨時可從子宮孔排卵 | **Apolytic（真脫節性）**：蟲卵隨 GP 脫落，GP 在腸道或排出後破裂才釋出 |
| 中間宿主 | **2 個** | **0 或 1 個** |
| 感染期幼蟲 | 長尾蚴（plerocercoid） | 囊尾蚴、擬囊尾蚴、包囊等 |

### 節片與生殖系統

- **未成熟節片（IP）→ 成熟節片（MP，雌雄兩套生殖系統）→ 受孕節片（GP）**。
- **雄性先發育**：睪丸約 3 到數百個、高度纏繞的輸精管（vas deferens）、陰莖（cirrus）、精囊。
- 雌性：**一個雙葉狀卵巢（bilobed ovary）**、輸卵管、子宮、卵黃腺。學藝補充：**是「一」個卵巢**，雙葉狀容易誤以為兩個；只有**犬複殖器絛蟲**有雙套生殖系統、兩個雙葉卵巢；豬肉絛蟲卵巢多一個副葉成三葉狀。
- 交配：cirrus 伸入同節片、同蟲相鄰節片（單蟲感染）或另一隻蟲（多蟲感染）的生殖孔與陰道交換精子。
- **GP**：交配後節片變大（越後端越大），生殖器官退化殆盡，**只剩充滿蟲卵的子宮**。

## 4. 絛蟲幼蟲型態 ⭐⭐

| 幼蟲 | 中文 | 代表蟲種 | 重點 |
|---|---|---|---|
| **Plerocercoid** | 長尾蚴（裂頭蚴、sparganum） | *D. latum*、*D. mansoni* | 假葉目的 **infective stage**，在第二中間宿主體內 |
| **Cysticercus** | 囊尾蚴 | *Taenia* spp. | 立體球狀、像小黃豆，頭節藏在囊內（4 吸盤），進腸道後翻出；染色淡紅；豬肉絛蟲的會跑到腦部造成**癲癇** |
| **Cysticercoid** | 擬囊尾蚴 | *H. diminuta*、*H. nana*、*D. caninum* | 有尾巴與吸盤，在**蟑螂、米蟲**體內（人畜共通） |
| **Coenurus** | 多頭蚴 | ***Taenia multiceps***（共筆；slides 列 *E. multilocularis*） | 單一囊腔內壁長出許多頭節，主要寄生**羊腦**，偶爾感染人 |
| **Hydatid cyst** | 包囊蚴 | *E. granulosus* | 母囊內有育囊、子囊、孫囊，生發層不斷產生原頭節（**hydatid sand**）；囊液**高致敏，弄破可能過敏性休克**；發現時多已 late stage；畜牧業國家多 |

## 5. 生活史與病理

- 中間宿主提供幼蟲寄生，幼蟲進入最終宿主腸道後長成成蟲、行有性生殖。多數絛蟲兩宿主（例：*T. saginata*，牛是中間宿主、人是最終宿主）；***Diphyllobothrium* 是三宿主**（甲殼類 → 淡水魚 → 哺乳類）。
- 學藝補充：*Echinococcus* 的最終宿主是**狗／狐狸**，*S. mansoni* 的最終宿主是**貓／狗**，人只是中間或保幼宿主。
- 病理：
  - 腸胃道絛蟲感染**通常無症狀**。
  - 頭節勾住腸道 → 局部發炎；**廣節裂頭絛蟲吸收 B12 → 貧血（甚至惡性貧血）**；蟲體是外來物 → **過敏反應**。
  - 可能頭痛、頭暈、虛弱、營養缺乏、肛門與鼻腔搔癢。
  - **幼蟲在腸胃道外移行時，症狀比成蟲嚴重**（曼氏裂頭絛蟲的裂頭蚴症、豬肉絛蟲的囊蟲症 cysticercosis）。

## 6. 廣節裂頭絛蟲 *Diphyllobothrium latum*（魚絛蟲，broad fish tapeworm）⭐⭐⭐

- 新名 ***Dibothriocephalus latus***（慣用舊名）；**寄生在人體最大的絛蟲**，成蟲 **3–10 m**（slides 寫 4–10 m），可多達 **4000 個體節**；以公尺計的絛蟲通常只單一隻感染。
- **分布**：
  - *D. latum*：俄羅斯、加拿大、冰島、北美（阿拉斯加）、北歐
  - *D. nihonkaiense*（日本海裂頭絛蟲）：北太平洋、東亞
  - *D. dendriticus*（樹狀裂頭絛蟲）：環北極圈（北美、北歐）與南美（智利、阿根廷）
  - 因貿易跨區，用地域判斷不準；種間型態高度重疊，**分種要 PCR**。
- **生活史（三宿主）**：

| | |
|---|---|
| 感染期 | **Plerocercoid（長尾蚴，L2）** |
| 感染源 | 吃含 plerocercoid 的中間宿主（生的淡水魚） |
| 第一中間宿主 | **甲殼類，如劍水蚤（copepod / Cyclops）** |
| 第二中間宿主 | **鮭魚、鱒魚、梭魚**（淡水魚） |
| 保幼宿主 | 吃了小魚的大魚 |
| 保蟲宿主 | 犬、貓、熊等吃魚的哺乳類 |
| 最終宿主 | **人** |

  - 受孕蟲卵在水中完成胚胎發育 → **coracidium（纖毛蚴，內含鉤球蚴）** → 劍水蚤 → **procercoid（原尾蚴，L1）** → 淡水魚，從魚腸爬入肌肉 → **plerocercoid（L2）** → 人生食 → 寄生**小腸**長成成蟲 → 蟲卵經子宮孔排出、隨糞便出來。slides：在小腸約 **3 週**成熟。
  - 學藝補充：**鮭魚是洄游魚**，主要對應的是**日本海裂頭絛蟲**，但也是 *D. latum* 的第二中間宿主。
- **臨床**（症狀非特異，多是偶然發現）：
  - **Long-lasting infection**：症狀輕微，可活 **25 年**
  - **Intestinal obstruction**：多蟲感染或蟲體纏結，少見
  - **Aberrant migration**：節片往上跑到膽道、胰管 → **膽管炎、膽囊炎**
  - **Vitamin B12 malabsorption**：對 B12 親和力極高，寄生在空腸／迴腸，搶走食糜中的 B12、阻礙它和 **intrinsic factor** 結合（slides：吸走約 80% 飲食 B12）→ 約 **1–2%** 患者出現**惡性貧血（pernicious anemia）**
  - **Toxic secretions**：成蟲代謝物 → 噁心、嘔吐、頭暈
- **診斷**：糞便看**蟲卵或 GP**（不是 MP）；每天產卵高達 **100 萬顆**，**直接塗片或福馬林-乙醚沉澱**就能檢出。
- **治療**：
  - **Praziquantel ＋ 瀉藥**排出蟲體（效果較好；slides 劑量 5–10 mg/kg 單次）
  - 替代藥 **niclosamide**（slides：2 g 嚼碎）。學藝補充：其實療效也好，但會破壞表皮讓頭節與節片被消化，**糞便裡較難找到完整頭節確認治癒**
  - **內視鏡／大腸鏡夾出**蟲體
  - **一定要確認頭節有出來**：殘留的頭節有生長點，**5–6 週至 2 個月**可再長成成蟲
  - 長期感染補 B12（slides）
- **預防**：不吃生的淡水魚或淡鹹水交界的魚；**−10 °C 冷凍 24–48 小時**。
- **形態**：

| | |
|---|---|
| 頭節 | **2–3 mm，紡錘形，2 條吸溝**；頸部細長不分節 |
| 節片 | 單節寬可達 **10–20 mm**、寬大於長；MP 與 GP 難區分（GP 子宮較大、卵較多） |
| 子宮 | **分葉狀（玫瑰花狀），塞滿黑色蟲卵**；子宮孔與生殖孔靠近，在節片中線偏上 |
| 幼蟲 | Procercoid（L1）；plerocercoid（L2）約 **1 cm、肉眼可見** |

- **蟲卵**：中大型 **55–75 × 40–50 µm**；**卵圓形、對稱、兩端鈍**，前端比 *D. mansoni* 圓；有**卵蓋**（卵蓋裂縫處可能呈鋸齒狀，不一定每顆都有）；末端有小突起（**不是判斷依據**）；內含未分化卵細胞與大量卵黃細胞；排出時**未胚胎化**。
- **台灣病例**（slides p.47）：2006 年高雄首例兒童（8 歲男童，肛門掛著蟲體）、2007 年北台灣 30 歲男性吃生魚片、2017 年 8 歲女童（PCR 鑑定）。韓國病例的感染源大多是**鮭魚**；美國華盛頓州有首例 *D. nihonkaiense*。

## 7. 曼氏裂頭絛蟲 *Spirometra mansoni*（裂頭蚴症 sparganosis）⭐⭐⭐

- 型態和 *D. latum* 很像，但成蟲較小（**60–100 cm**），GP 子宮**盤繞似團狀（螺旋）**、不是玫瑰花狀；臨床最大差別：**人感染的是幼蟲**，造成 sparganosis。
- *Spirometra* 屬另有 *S. ranarum*、*S. mansonoides*、*S. erinacei*，以及會增生的 ***Sparganum proliferum***（slides）。
- **生活史**：

| | |
|---|---|
| 感染期 | **兩種**：①**procercoid（L1）**：感染第二中間宿主 ②**plerocercoid／sparganum（L2）**：感染保幼與最終宿主 |
| 感染源 | 喝到帶 procercoid 劍水蚤的生水；生食帶 plerocercoid 的**蛙、蛇、雞、豬**；**民俗療法把蛙皮、蛇皮、蛇肉敷傷口**，plerocercoid 從傷口鑽入（在人體可待近 **20 年**） |
| 第一中間宿主 | 橈足類劍水蚤（copepod） |
| 第二中間宿主 | 蛙、蛇、魚類，**人**（吃進 procercoid，在人體長成 plerocercoid） |
| 保幼宿主 | 脊椎動物，**人**（吃進 plerocercoid，在人體維持幼蟲型態） |
| 保蟲宿主（最終） | **貓、狗、狐狸**（**人不是最終宿主！**） |

  - 受孕蟲卵在水中 → coracidium → 劍水蚤 → procercoid →
    - **路徑一**：人喝污染水吃進 procercoid → 穿過腸壁移行到皮下、肌肉、眼、腦 → 長成 plerocercoid，**不發育為成蟲**（人＝第二中間宿主）
    - **路徑二**：蛙、蛇吃進 → plerocercoid → ①人生食或敷貼（人＝**保幼宿主**），維持幼蟲型態；②貓狗狐狸吃到 → 小腸長成成蟲
  - 補充：古代用蛙皮治傷口（多彩鈴蟾 *Bombina variegata*，皮含抗菌胜肽 **bombinin**），但帶有 L2 就會感染人。

### 人是保幼宿主的整理（考試喜歡考特例）

| 蟲 | 進入人體的幼蟲 | 在人體 |
|---|---|---|
| 犬蛔蟲 *T. canis* | L3 | 不再發育 |
| 曼氏裂頭絛蟲 *D. mansoni* | L2（plerocercoid） | 維持幼蟲型態 |
| 巴西鉤蟲／犬鉤蟲 *A. braziliense*／*A. caninum* | L3 鑽皮膚 | 不再發育，皮下亂爬（CLM） |
| 棘顎口線蟲 *G. spinigerum* | 食入 L3 | 不再發育，在皮下、內臟、眼、腦亂竄 |
| **例外**：廣東住血線蟲 *A. cantonensis*（人是偶然宿主） | L3 | 可發育到 **L5**，但不會成蟲 |

- **臨床（sparganosis）**：人不是最終宿主，幼蟲到處移行。
  - **皮下裂頭蚴症**：**最常見**；皮下移行通常不痛
  - **眼裂頭蚴症**：學藝補充：盛行於東南亞、越南、華南與早期台灣，**最經典的途徑是把生蛙肉或蛇皮敷在紅腫的眼睛上**，幼蟲直接鑽入眼瞼或眼眶（也可喝生水或幼蟲移行而來）
  - **腦裂頭蚴症**：較嚴重（slides：無力、頭痛、**癲癇**、感覺異常）
  - slides 另列：乳房、泌尿道、胸腔、肺、腹腔；侵犯內耳 → 眩暈、耳聾；*S. proliferum* 會增生。
  - slides 病例：高雄榮總**眼裂頭蚴症被誤認為眼眶發炎**；韓國結膜下裂頭蚴；歐洲腦裂頭蚴症；台灣從結膜取出 4 cm 裂頭蚴。
- **診斷**（人體只會有幼蟲；正常情況下**糞便看不到蟲卵或節片**）：
  - 病灶**切片找裂頭蚴**
  - **CT／MRI**（特別是腦裂頭蚴症）
  - **血清學**：血清或腦脊髓液 **IgG**，敏感度與特異度 **>95%**
- **治療**：**手術取出幼蟲**（效果比藥好）或 praziquantel。
- **預防**：不喝生水、不接觸蛙皮蛇皮。
- **流行**：中國、日本、東南亞，**中國最多**。
- **形態**：頭節**紡錘形、較短小（1–1.5 mm）**，和 *D. latum* 一樣 2 條吸溝；GP 寬扁、寬＞長、子宮盤繞似團狀；有石灰小體。
- **蟲卵**：**52–76 × 26–43 µm**，中大型；**不對稱、頭尾尖**，末端小突起極不明顯；一端有卵蓋、另一端較尖細；內含卵細胞與顆粒狀卵黃細胞，位置不固定。老師提醒：角度不同時也可能看起來對稱，只能多看。卵蓋明顯，容易和**吸蟲卵**搞混（slides）。

## 8. 廣節裂頭絛蟲 vs 曼氏裂頭絛蟲 ⭐⭐⭐

| | ***D. latum*** | ***S. mansoni*（*D. mansoni*）** |
|---|---|---|
| 成蟲大小 | **3–10 m**（人體最大絛蟲） | **60–100 cm** |

| 治療 | Praziquantel ＋ 瀉藥；內視鏡夾出（確認頭節） | **手術取出**（較佳）／praziquantel |

## 百十三共筆對照

- 分類：百十三寫絛蟲綱 **Cestoidea**；百十四改寫 **Cestoda**（Cestoidea 是舊稱），並補充假葉目已拆成兩個目（不考）。
- 頭節殘留再長回來：百十三寫 **2–3 個月**；百十四寫 **5–6 週至 2 個月**。
- Niclosamide：兩版都寫療效較差；百十四學藝補充說其實療效也好，只是糞便裡難找到完整頭節。
- 惡性貧血：百十三只寫「發生率低」；百十四寫約 **1–2%**，並說明是阻礙 B12 和 intrinsic factor 結合。
- 子宮分支數分種：百十三寫**豬肉 < 14、牛肉 ≥ 14**；百十四寫**豬肉 7–13、牛肉 15–30**。
- Coenurus：百十三照 slides 列 *E. multilocularis*；百十四改成 ***Taenia multiceps***（羊腦），教科書也寫 *T. multiceps*。
- *D. latum* 蟲卵：百十三寫 **55–76 × 41–56 µm**；百十四寫 **55–75 × 40–50 µm**（slides 同百十四）。
- 只有百十四有：石灰小體的 H&E 外觀、aberrant migration 的章節位置（百十三放在比較表的膽囊炎、膽管炎）、PCR 分種、豬肉絛蟲三葉卵巢與犬複殖器絛蟲雙卵巢、為什麼假葉目 GP 很少脫落。

# 考點分析

## 🔥 高頻考點

- **假葉目 vs 圓葉目**：頭節（吸溝 vs 吸盤）、子宮孔、生殖孔位置、蟲卵有無卵蓋、中間宿主數目。
- 絛蟲共同特徵：**沒有消化道**、雌雄同體、焰細胞、**石灰小體**。
- ***D. latum***：吃生的淡水魚（鮭魚），感染期 plerocercoid，**B12 缺乏 → 惡性貧血（巨球性）**，診斷看糞便蟲卵與 GP，是寄生人體最大的絛蟲。
- ***D. mansoni***：**兩種感染期**（procercoid、plerocercoid）；**蛙肉或蛙皮敷傷口**；sparganosis；人不是最終宿主（狗、貓才是）。
- 惡性貧血（B12，*D. latum*） vs 缺鐵性貧血（鉤蟲、鞭蟲、血吸蟲）。
- 人當保幼宿主的例子：犬蛔蟲、*D. mansoni*（幼蟲不再發育）；例外是廣東住血線蟲（L3 會長到 L5）。

## 📝 出題模式

- 病例題：「以蛙肉敷眼眶傷口，數天後取出約 3 cm 白色蟲體」→ *D. mansoni*。
- 病例題：「釣魚後吃生魚，出現巨球性貧血，糞便有蟲卵」→ *D. latum*。
- 「下列何者錯誤：*D. latum* 具有圓形吸盤」→ 錯，假葉目是吸溝。
