## 1. 絛蟲總論 ⭐⭐⭐

- 分類：扁形動物門（Platyhelminthes）→ **絛蟲綱（Cestoidea）**（另一綱是吸蟲綱）。絛蟲綱有 **13 個目**，只有**假葉目（Pseudophyllidea）**和**圓葉目（Cyclophyllidea）**有醫學與獸醫上的重要性。
- 外觀：長如皮帶、**分節**、白色或乳白色，長度從數公釐到數公尺；由**頭節（scolex）、頸部（neck）、節片（proglottid）**組成，前細後寬。
- **所有絛蟲都是寄生性**；成蟲多在脊椎動物消化道，可活好幾年；幼蟲在 1–2 個中間宿主體內發育。
- **沒有口、沒有消化系統** → 直接從宿主腸道吸收養分（考古：「Class Cestoda 有消化道」是錯的）。
- 排泄系統：**焰細胞（flame cell）**。
- **全部雌雄同體（hermaphrodite）**；通常異體受精（兩隻蟲的陰莖 cirrus 經生殖孔互接交換精子），只有一隻時也能自體受精。
- 頸部持續產生節片：**未成熟節片（IP）→ 成熟節片（MP，雌雄生殖器官齊全）→ 受孕節片（GP，生殖器官退化、只剩塞滿蟲卵的子宮）**。
  - **雄性生殖系統先發育**（睪丸 3 到數百個、輸精管、cirrus sac）；雌性在 MP 才成熟（1 個卵巢、卵黃腺、Mehlis' gland、子宮、陰道）。
  - 頭節與頸部只要留在體內就會再長出節片 → 治療後**要確認頭節有排出**。
- 體表：**tegument** 上布滿 **microtriches（微毛）**，負責保護、吸收、附著。
- **石灰小體（calcareous corpuscles）**：在實質組織（parenchyma）裡，成蟲與幼蟲都有，是**絛蟲的特徵性構造**，看到就代表是絛蟲。

## 2. 假葉目 vs 圓葉目 ⭐⭐⭐（必背比較）

| | **假葉目 Pseudophyllidea** | **圓葉目 Cyclophyllidea** |
|---|---|---|
| 頭節 | 杏仁狀／匙狀，**2 條吸溝（bothria，sucking groove）** | 球狀，**4 個杯狀吸盤**，可能有額嘴（rostellum）與吻鉤（hooklets） |
| 子宮 | **不分支**，有子宮孔（玫瑰花狀） | **分支、盲端** |
| 子宮孔（uterine pore） | **有** | **無** |
| 生殖孔 | **腹面中線** | **側面** |
| 蟲卵 | **有卵蓋**，孵出**有纖毛的幼蟲**（coracidium） | **無卵蓋**，不會孵出纖毛幼蟲 |
| 中間宿主 | **2 個** | **1 個或沒有** |
| Apolysis | **Anapolytic**：節片留在蟲體上，蟲卵從子宮孔排進腸道 | **Apolytic**：GP 脫落隨糞便排出，在外界崩解才釋出蟲卵 |
| 感染期幼蟲 | 長尾蚴（plerocercoid） | 囊尾蚴、擬囊尾蚴、包囊等 |

- 醫學上重要的種類與長度單位（百十三共筆）：
  - **假葉目**：廣節裂頭絛蟲 *D. latum*（公尺）、曼氏裂頭絛蟲 *Spirometra mansoni*（公分）。
  - **圓葉目**：牛肉絛蟲、亞洲絛蟲、豬肉絛蟲（公尺）；縮小／短小包膜絛蟲、犬複殖器絛蟲（公分）；單胞、多胞絛蟲（公釐）。
- 百十三共筆提醒：為了和曼森血吸蟲（*Schistosoma mansoni*）區分，考試時曼氏裂頭絛蟲可寫舊名 ***D. mansoni***。

## 4. 生活史與病理

- 多數絛蟲是**兩宿主**的生活史（例：*Taenia saginata*，牛是中間宿主、人是最終宿主）；***Diphyllobothrium* 是三宿主**（1 個最終宿主＋2 個中間宿主）。
- 病理：
  - **大多無症狀**。
  - 症狀來自巨大蟲體的存在與活動、頭節鉤造成的局部發炎，或**維生素 B12 吸收減少**。
  - 過敏反應：頭痛、頭暈、虛弱、肛門與鼻腔搔癢。
  - **幼蟲在腸道外移行時，症狀往往比成蟲嚴重**（例：曼氏裂頭絛蟲的裂頭蚴症、豬肉絛蟲的囊蟲症）。

## 5. 廣節裂頭絛蟲 *Diphyllobothrium latum*（魚絛蟲，broad fish tapeworm）⭐⭐⭐

- 新名 ***Dibothriocephalus latus***；寄生在人體**最大的絛蟲**，常見 **4–10 m**。同屬感染人的還有 *D. nihonkaiense*（日本海裂頭絛蟲）、*D. dendriticus*、*Adenocephalus pacificus* 等，型態相近，**要靠 PCR 分種**。
- **分布**：環北極地區（加拿大、芬蘭、丹麥、冰島、挪威、俄羅斯、瑞典、阿拉斯加）；*D. nihonkaiense* 在北太平洋、東亞（愛吃生魚的地區）。
- **生活史（三宿主）**：
  1. 蟲卵（**未胚胎化**，有卵蓋）隨糞便排出，在水中約 9–12 天孵出有纖毛、會游泳的 **coracidium**。
  2. 被**第一中間宿主：橈足類（copepod，如劍水蚤 Cyclops）**吃下，在體腔發育成 **procercoid（原尾蚴）**。
  3. **第二中間宿主：淡水魚**（鮭魚、鱒魚、梭魚、鱸魚）吃下橈足類，procercoid 鑽入組織，發育成 **plerocercoid（長尾蚴＝感染期）**，在魚肉中可存活數年。大魚吃小魚時可當**保幼宿主**。
  4. 人吃**生或未煮熟的魚** → plerocercoid 在**小腸**翻出頭節附著，約 **3 週**成熟，可活好幾年。
  5. 保蟲宿主：狗、貓等吃魚的哺乳類。
- **臨床**：
  - 可以持續很久（**長達 25 年**），大多無症狀或只有腸胃症狀。
  - 節片異位移行 → **膽囊炎、膽管炎**；大量感染可造成**腸阻塞**。
  - **維生素 B12 缺乏 → 巨母紅血球性貧血／惡性貧血（pernicious anemia）**：蟲吸走約 **80%** 的飲食 B12。
  - 但實際發生貧血的**不到 2%**（slides p.50）。
- **診斷**：
  - 每天可從子宮孔排出多達 **100 萬顆蟲卵** → 量多，**不用濃縮法**就能在糞便看到蟲卵；也可看排出的節片（GP）。
  - 用蟲卵只能分到「科」，分種要 **PCR**。
  - 考古陷阱：診斷看**蟲卵與 GP**，不是 MP。
- **蟲卵**：卵圓形，**55–75 × 40–50 µm**，一端有卵蓋（可能不明顯），另一端（abopercular end）有**小突起**；排出時**未胚胎化**。
- **治療**：
  - **Praziquantel** 5–10 mg/kg 單次口服（隨餐配水吞服）。
  - 替代藥：**niclosamide** 2 g 單次（要嚼碎）。
  - 長期感染要**補充 B12**；腸阻塞才需要手術。
  - 百十三共筆：praziquantel 加瀉藥把蟲排出，**要確認頭節有出來**，否則 2–3 個月後會再長回來。
- **預防**：不吃生的淡水魚；百十三共筆提到 **−10 °C 冷凍 24–48 小時**。
- **形態**：
  - 頭節約 1 × 2.5 mm，有 **2 條吸溝**；頸部細長、不分節，比頭長。
  - 成熟節片**寬大於長（長：寬＝1：2–4）**，子宮在中央呈**玫瑰花狀**。
  - 雌雄生殖孔分開，都在**腹面中線**；睪丸散布整個節片。
  - **GP 不脫落**，蟲卵由子宮孔排出。
- **台灣病例**（slides p.47）：2006 年高雄首例兒童病例（8 歲男童，肛門掛著蟲體）、2007 年北台灣 30 歲男性吃生魚片、2017 年 8 歲女童（PCR 鑑定）。韓國病例的感染源大多是**鮭魚**；美國華盛頓州有首例 *D. nihonkaiense*。

## 6. 曼氏裂頭絛蟲 *Spirometra mansoni*（裂頭蚴症 sparganosis）⭐⭐⭐

- *Spirometra* 屬包括 *S. mansoni*、*S. ranarum*、*S. mansonoides*、*S. erinacei*，以及會增生的 ***Sparganum proliferum***。分布全世界，**人類病例多在東南亞**（百十三共筆：中國、日本、東南亞）。
- 成蟲在最終宿主（**狗、貓**）小腸，**型態和 *D. latum* 相似**；成蟲約 60–100 cm，比廣節裂頭絛蟲小。
- **生活史**：
  1. 蟲卵隨狗、貓糞便排出，在水中胚胎化，孵出 coracidium。
  2. 被**橈足類**（第一中間宿主）吃下 → procercoid。
  3. **第二中間宿主（魚、爬蟲類、兩棲類，如蛙、蛇）**吃下橈足類 → plerocercoid（sparganum）。
  4. 狗、貓吃到第二中間宿主 → 長成成蟲。
- **人不是最終宿主**，人可以當**第二中間宿主或保幼宿主**：
  - 喝到含帶 **procercoid 橈足類**的生水 → 人是**第二中間宿主**。
  - 吃生的或未煮熟的蛙、蛇（含 **plerocercoid**） → 人是**保幼宿主**。
  - 百十三共筆補充：民俗療法**用蛙皮、蛇肉敷傷口**，plerocercoid 會從傷口鑽入。
  - → **兩種感染期：procercoid 與 plerocercoid**（考古必考）。
  - Sparganum 在人體可活到 **20 年**。
- **臨床**：裂頭蚴在體內移行，症狀看停在哪裡。
  - 可出現在**皮下**、乳房、**眼眶**、泌尿道、胸腔、肺、腹腔內臟、**中樞神經**。
  - 皮下移行通常**不痛**。
  - 跑到腦或脊髓：無力、頭痛、**癲癇**、感覺異常（麻、刺痛）。
  - 侵犯內耳：眩暈、耳聾。
  - *S. proliferum* 會**增生**，同一處有很多個 plerocercoid。
  - slides 病例：高雄榮總**眼裂頭蚴症被誤認為眼眶發炎**；韓國結膜下裂頭蚴；歐洲腦裂頭蚴症。台灣也有從結膜取出 4 cm 裂頭蚴的病例。
- **診斷**：從組織中**取出 sparganum** 就能確診，通常不用分種。真要分種，要把活的裂頭蚴餵給適當的最終宿主，等長成成蟲再鑑定。百十三共筆另列 CT／MRI 與 IgG 血清學。
- **治療**：**手術取出**（百十三共筆：也可用 praziquantel，但手術效果較好）。
- **預防**：不喝生水、不吃生的蛙或蛇、不用蛙皮或蛇肉敷傷口。
- **蟲卵**：有卵蓋，卵圓形，**55–76 × 30–43 µm**；因為卵蓋明顯，容易和**吸蟲卵**或 *Diphyllobothrium* 卵搞混。百十三共筆的分法：*Spirometra* 卵**不對稱、兩端較尖**，*D. latum* 卵**對稱、兩端較鈍**。

## 7. 廣節裂頭絛蟲 vs 曼氏裂頭絛蟲 ⭐⭐⭐

| | ***D. latum*** | ***S. mansoni*（*D. mansoni*）** |
|---|---|---|
| 最終宿主 | **人**（狗、貓等吃魚哺乳類為保蟲宿主） | **狗、貓**（人**不是**最終宿主） |
| 第一中間宿主 | 橈足類（劍水蚤） | 橈足類 |
| 第二中間宿主 | **淡水魚**（鮭、鱒、梭魚） | **蛙、蛇**、魚、鳥、哺乳類；**人也可以** |

| 感染期 | **Plerocercoid** | **Procercoid＋plerocercoid** |

# 考點分析

## 🔥 高頻考點

- **假葉目 vs 圓葉目**：頭節（吸溝 vs 吸盤）、子宮孔、生殖孔位置、蟲卵有無卵蓋、中間宿主數目。
- 絛蟲共同特徵：**沒有消化道**、雌雄同體、焰細胞、**石灰小體**。
- ***D. latum***：吃生的淡水魚（鮭魚），感染期 plerocercoid，**B12 缺乏 → 惡性貧血（巨球性）**，診斷看糞便蟲卵與 GP，是寄生人體最大的絛蟲。
- ***D. mansoni***：**兩種感染期**（procercoid、plerocercoid）；**蛙肉或蛙皮敷傷口**；sparganosis；人不是最終宿主（狗、貓才是）。
- 惡性貧血（B12，*D. latum*） vs 缺鐵性貧血（鉤蟲、鞭蟲、血吸蟲）。
- 人當保幼宿主的例子：犬蛔蟲、*D. mansoni*（幼蟲不再發育）；例外是廣東住血線蟲（L3 會長到 L5）。

## 📝 出題模式

- 病例題：「以蛙肉敷眼眶傷口，數天後取出約 3 cm 白色蟲體」→ *D. mansoni*。
- 病例題：「釣魚後吃生魚，出現巨球性貧血，糞便有蟲卵」→ *D. latum*。
- 「下列何者錯誤：*D. latum* 具有圓形吸盤」→ 錯，假葉目是吸溝。

| 容易選錯 | 正確 |
