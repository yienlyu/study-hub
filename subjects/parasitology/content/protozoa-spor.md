## 1. 頂端複合門（Apicomplexa）總論 ⭐⭐

- 成員：血液——**瘧原蟲 *Plasmodium***、**巴貝氏蟲 *Babesia***；腸道與組織——**弓蟲 *Toxoplasma gondii***、**隱孢子蟲 *Cryptosporidium parvum***、環孢子蟲 *Cyclospora*、微孢子蟲、貝氏等孢球蟲 *Isospora belli*、肉孢子蟲 *Sarcocystis*。
- 特徵：**沒有自由生活型**；生活史有**有性與無性**世代；有孢子樣型態、細胞內寄生；**頂端複合體（apical complex）**＝細胞骨架與分泌胞器（conoid、microneme、rhoptry、dense granule）；**滑行運動（gliding motility）**。
- 一般生活史三種生殖：**裂體生殖（schizogony／merogony，無性）** → **配子生殖（gametogony，有性）** → **孢子生殖（sporogony）**。
  - 階段：sporozoite → merozoite → gametocyte → zygote。

## 2. 弓蟲 *Toxoplasma gondii* ⭐⭐⭐

- **人畜共通**；血液與組織寄生；**孕婦與免疫低下**最重要。
- **最終宿主：貓（有性生殖在貓小腸上皮細胞）**；**中間宿主：人、鼠、豬等溫血動物**；**卵囊（oocyst）只在最終宿主（貓）產生**。
- **傳播途徑**：① 吃到生肉中的**組織囊體（cyst，含 bradyzoite）**；② 接觸貓糞中的**卵囊（oocyst）**；③ 輸血、器官移植；④ **母親傳胎兒（垂直傳染）**。
- **三種型態**：
  - **Tachyzoite（速殖子）**：4–8 µm，快速複製、急性期；有 conoid（穿入細胞）、microneme／rhoptry（附著、入侵）、dense granule（細胞內存活）、**apicoplast**（四層膜、35 kb 環狀 DNA）；在**納蟲空泡（parasitophorous vacuole）**中阻止溶酶體融合。
  - **Tissue cyst（含 bradyzoite 緩殖子）**：5–50 µm，慢性感染；腦內圓形、心肌與骨骼肌中較長。
  - **Oocyst（卵囊）**：9–11 µm，含 **2 個孢子囊、各 4 個孢子體**；排出後要在外界成熟（sporulate）才有感染力。
- **症狀**：
  - **免疫正常成人：80–90% 無症狀**或類流感；IFN-γ 是重要的宿主抵抗力；可能造成**單側**網膜脈絡膜炎（40–60 歲）。
  - **先天性弓蟲症**：**母親懷孕期間「首次」感染**才會傳給胎兒（**IgM 不能通過胎盤**）；約 1/1,000；出生時常無症狀、之後才出現——**雙側網膜脈絡膜炎（20–30 歲）、水腦（hydrocephalus）、小腦症、腦鈣化**、腦脊髓炎、智能障礙、肝脾腫大、癲癇。
  - **眼部弓蟲症**：多半是先天感染在成人才表現；先天感染兒童 20% 出生時有眼部症狀、青春期 80%；AIDS 病人進展很快。
  - **免疫低下（AIDS、移植）**：潛伏感染**再活化** → **弓蟲腦炎**（多發性環狀增強病灶）。
- 「行為操控」假說：弓蟲讓大鼠不再怕貓尿；與**思覺失調症**相關（OR = 2.7）。
- **診斷**：組織切片看到蟲可確診但困難；**血清學：Sabin-Feldman dye test**、ELISA、EIA、IFA（IgM、IgG）；**IgM 5 天–2 週出現**、IgG 2–3 週上升且**終身可測**；產前診斷看抗弓蟲 IgM；PCR；AIDS 病人：臨床症狀＋IgG 陽性＋腦部多發環狀病灶。
- **流行病學**：美國盛行率 22.5%；**台灣育齡婦女約 10%**；肉食動物吃囊體、草食動物吃卵囊；加州海獺死亡原因之一。
- **治療**：**pyrimethamine＋trisulfapyrimidines**（一個月，抑制 DNA／RNA 合成）＋**folinic acid（亞葉酸）**對抗骨髓抑制；**殺不死組織囊體**；TMP-SMX；**spiramycin**（孕早期預防）。
- **預防**：肉煮到 **66 °C 以上**、洗手、**孕婦避免接觸貓**、貓只餵罐頭或乾飼料、貓砂每天清並用沸水消毒、小孩玩沙後洗手。

## 3. 隱孢子蟲 *Cryptosporidium parvum* ⭐⭐⭐

- **寄生蟲性腹瀉的主要原因**；**自體感染**；在**納蟲空泡**中發育（細胞內、細胞質外）；**耐氯消毒**、主要**經水傳播**；動物保蟲宿主很多。
- 卵囊含 **4 個 sporozoite**；**薄壁卵囊 → 自體感染**、**厚壁卵囊 → 排出、具感染力**。
- 致病：**分泌性水瀉**，每天可達 10 公升（吸收不良、通透性增加、氯離子分泌）。
- **症狀**：
  - 免疫正常：水瀉、噁心、嘔吐、腹絞痛、體重減輕，**自限性約 2 週**；**5 歲以下兒童**最嚴重（兒童腹瀉四大原因之一）。
  - **HIV**：嚴重度依 CD4 數，**慢性**（數月到數年），致死率可達 50%。
- **診斷**：**糞便鏡檢最不敏感（約 30%）**，**改良抗酸染色（modified acid-fast）**可提高；**PCR 高敏感、可分基因型**；單株抗體抗原檢測敏感度高。
- **治療**：免疫正常 **nitazoxanide**；**HIV 病人沒有有效治療**。

## 4. 瘧原蟲 *Plasmodium* spp. ⭐⭐⭐

- **世界上最重要的病媒傳染病**；由**瘧蚊（*Anopheles*）**傳播；Ronald Ross、Patrick Manson；「瘴癘」。2010 年約 2.19 億病例、66 萬死亡，91% 在非洲。
- **五種**：

| 種 | 中文 | 重點 |
|---|---|---|
| ***P. falciparum*** | **惡性瘧** | 最嚴重（腦性瘧疾等） |
| ***P. vivax*** | **間日瘧** | 肝臟**休眠子（hypnozoite）** → relapse |
| ***P. malariae*** | **三日瘧** | **腎炎** |
| ***P. ovale*** | **卵圓瘧** | 肝臟**休眠子** |
| ***P. knowlesi*** | 諾氏瘧 | 東南亞獼猴瘧原蟲（台灣有境外移入病例） |

### 生活史 ⭐⭐⭐

- **人是中間宿主（無性生殖）；瘧蚊是最終宿主（有性生殖）**。
- 雌瘧蚊叮咬注入 **sporozoite（孢子體，感染期）** →
- **紅血球外裂體生殖（exoerythrocytic schizogony，肝臟）**：侵入肝細胞，6–15 天，產生 1,000–10,000 個 merozoite；***P. vivax*、*P. ovale* 有 hypnozoite（休眠子）**。
- **紅血球內裂體生殖**：merozoite 入侵紅血球 → **環狀體（ring form，周邊血中的 young trophozoite）** → 吃血紅素，heme 聚合成**瘧色素（hemozoin）** → schizont（裂殖體）→ 破裂釋出 merozoite。
- **配子體形成**：部分變成 **gametocyte（雄 micro-、雌 macro-）**，**沒有病理意義、是蚊子的感染期**。
- **蚊子體內**：中腸的配子形成（**exflagellation**，由溫度、pH、**xanthurenic acid** 觸發）→ **zygote → ookinete（動合子）** → 穿過腸上皮成 **oocyst（卵囊）** → 釋出 sporozoite → 移到**唾腺**（9–21 天）。

### 血片型態 ⭐⭐⭐

| | *P. falciparum* | *P. vivax* | *P. malariae* | *P. ovale* |
|---|---|---|---|---|
| 被感染紅血球 | 不變大；常多重感染 | **變大**、**Schüffner's dots** | 不變大（甚至變小） | 稍大、**橢圓、邊緣鬚狀（fimbriation）**、Schüffner's dots |
| 環狀體 | 細小、可有雙核點、**Maurer's clefts** | 粗、單一大核點，之後**阿米巴狀** | 較粗、**bird's-eye** | 似 vivax |
| 發育中滋養體 | 多維持環狀 | **阿米巴狀**、大空泡 | **帶狀（band form）**、籃狀（basket form） | 緊實 |
| 裂殖體 | **周邊血很少見**（重症才有）、8–24 個 merozoite | 12–24 個 | **6–12 個、菊花狀（rosette）**、周邊血常見 | 4–16 個 |
| 配子體 | **新月形／香腸形（crescent）**、Laveran's bib | 圓到橢圓、填滿細胞 | 緊實 | 似 vivax |

- 周邊血通常只看到 ring form 與 gametocyte；**惡性瘧的晚期滋養體與裂殖體黏在深部血管（sequestration）**。

### 臨床表現 ⭐⭐⭐

- **瘧疾發作（paroxysm）**：**畏寒顫抖（10–15 分）→ 發燒（2–6 小時）→ 出汗**；紅血球破裂釋出 merozoite 與代謝毒素 → 巨噬細胞活化、TNF-α 等致熱原。
- 週期：**間日瘧、卵圓瘧約 48 小時**；**三日瘧 72 小時**；**惡性瘧 36–48 小時、不規則或持續發燒**。潛伏期：惡性 8–11 天、間日與卵圓 10–17 天、三日 18–40 天。
- 溶血：黃疸、脾腫大；**貧血**（紅血球被破壞、脾臟巨噬細胞增生、骨髓功能不良、免疫病理）。
- **Relapse（復發）**：血中蟲已清除後，**肝臟 hypnozoite** 再活化（**vivax、ovale**）。**Recrudescence（再發）**：治療不完全，**紅血球內殘存**的少量蟲再增生。
- **熱帶脾腫大症候群（TSS）**：慢性脾腫大、IgM 升高。
- **重症併發症（主要是惡性瘧）**：
  - **腦性瘧疾**：惡性瘧**最嚴重**的併發症，死亡率 25–50%；感染紅血球表面的 **PfEMP-1** 與血管內皮的 **ICAM-1** 結合 → 隔離在腦微血管；NO 干擾神經傳導。
  - **黑水熱（blackwater fever）**：大量血管內溶血 → **血紅素尿**（惡性瘧）。
  - **腎病**：急性腎絲球腎炎（**惡性瘧、三日瘧**），類固醇無效。
  - 痢疾型瘧疾、肺水腫（DIC）、**低血糖**（quinine 造成高胰島素 → 孕晚期胎兒死亡的重要原因）。
- **對瘧疾有抵抗力的情況**：**鐮刀型貧血異型合子（HbAS）**、**G6PD 缺乏**、地中海型貧血、**Duffy 抗原陰性（西非黑人）→ 抵抗間日瘧**、東南亞橢圓形紅血球症（band 3 變異 → 抵抗惡性瘧）、**premunition（帶蟲免疫）**。

### 診斷 ⭐⭐⭐

- 症狀＋**旅遊史**。
- **Giemsa 染色血片（多次採血）**：**厚片篩檢（有沒有）、薄片鑑定種別**。
- **快篩（RDT）**：惡性瘧 **HRP2**、Pf-pLDH；間日瘧 Pv-pLDH；全種 pan-pLDH、aldolase。限制：HRP2 基因缺失、低傳播地區敏感度下降。
- 分子：**LAMP**、PCR（vivax 120 bp、malariae 144 bp、falciparum 205 bp、ovale 800 bp）。

### 治療 ⭐⭐⭐

- 選藥依：瘧疾種類、當地抗藥性、嚴重度（意識下降、抽搐、低血糖、貧血、腎功能、黃疸、休克、肺水腫、**惡性瘧蟲血症 > 10%** → 靜脈注射）、年齡。
- **Quinine**（金雞納生物鹼，對所有種的**血液裂殖體**有效）、quinidine（靜脈）；mefloquine（對組織期與配子體無效）、halofantrine。
- **Chloroquine**（4-aminoquinoline，惡性瘧多抗藥）。
- **Primaquine**（8-aminoquinoline）：殺 **vivax、ovale 的 hypnozoite（組織裂殖體）**，並殺**所有種的配子體**；**G6PD 缺乏者會溶血**。
- **Artemisinin（青蒿素）**：血液裂殖體殺滅劑；衍生物 artesunate、artemether、arteether；**WHO 建議 ACT（artemisinin-based combination therapy）**；**屠呦呦 2015 年諾貝爾獎**。
- 其他組合：quinine／mefloquine＋**doxycycline**（光敏感）、pyrimethamine＋sulfadoxine（Fansidar，抗藥）、pyrimethamine＋dapsone、**atovaquone＋proguanil（Malarone；出發前 2 天到離開後 7 天）**。
- **MDA（大規模藥物投予）**：不經個別診斷就給族群投藥，用於接近根除、湄公河多重抗藥地區、流行、緊急狀況；endectocide（如 ivermectin）殺吸血的蚊子。

### 流行病學與防治

- **台灣 1965 年根除瘧疾**（病媒**矮小瘧蚊 *Anopheles minimus***；DDT 室內殘效噴灑）；現在只有境外移入。
- 防治：防蚊（紗窗、DEET）、**殺蟲劑處理蚊帳（ITN）**、**室內殘效噴灑（IRS）**、孕婦間歇預防性投藥（IPTp）、病媒控制；WHO 2007「Roll Back Malaria」；控制階段：準備 → 攻擊 → 鞏固 → 維持。
- **疫苗**：SPf66 在非洲無保護力；**RTS,S（Mosquirix，GSK）**針對惡性瘧**紅血球前期**，保護力有限（約 50%）、**4 年內下降**；疫苗＋季節性預防投藥效果最好；肯亞、迦納、馬拉威試辦。

## 5. 巴貝氏蟲 *Babesia* spp. ⭐⭐

- *B. microti*、*B. divergens*、*B. duncani*、MO-1；**感染紅血球**；由**蜱（硬蜱 *Ixodes*）**傳播。
- 血片：環狀體，**二分或四分體（tetrad，馬爾他十字 Maltese cross）**——和惡性瘧的環狀體要區分（**沒有色素、沒有配子體**）。
- 分布：北美、歐洲、**台灣**、日本（slides 最後一頁：台灣第一例人體病例）。
- **症狀**：無症狀或類流感；溶血性貧血、黃疸、深色尿；**無脾、免疫低下（約 20%）、老人**會危及生命。
- 傳播：戶外活動被蜱叮、**輸血**、先天。
- 診斷：厚薄血片、PCR 分種。
- 治療（至少 7–10 天）：**atovaquone＋azithromycin**，或 **clindamycin＋quinine**。

## 6. 孢子蟲總整理 ⭐⭐⭐

| | 弓蟲 | 隱孢子蟲 | 瘧原蟲 | 巴貝氏蟲 |
|---|---|---|---|---|
| 最終宿主 | **貓** | 同一宿主（人、動物） | **瘧蚊** | **蜱** |
| 人的角色 | 中間宿主 | 宿主（自體感染） | **中間宿主** | 偶然宿主 |
| 感染方式 | 生肉囊體、貓糞卵囊、垂直、輸血 | 喝水（耐氯）卵囊 | 瘧蚊叮咬 sporozoite；輸血 | 蜱叮咬、**輸血** |
| 寄生處 | 有核細胞（腦、眼、肌肉） | 小腸上皮 | 肝 → 紅血球 | 紅血球 |
| 招牌 | 先天：水腦、腦鈣化、網膜脈絡膜炎 | 水瀉、AIDS 慢性腹瀉 | 週期性發燒、腦性瘧、黑水熱 | 四分體、無脾者嚴重 |
| 診斷 | 血清學（Sabin-Feldman、IgM／IgG）、PCR | 改良抗酸染色、PCR、抗原 | 厚薄血片、RDT、PCR | 血片、PCR |
| 藥 | pyrimethamine＋sulfa、spiramycin（孕婦） | nitazoxanide | ACT、primaquine… | atovaquone＋azithromycin |

# 考點分析

## 🔥 高頻考點（百十三原蟲考古）

1. **弓蟲宿主**：**貓是最終宿主、人是中間宿主**（「人是終宿主、貓是中間宿主」是錯的，pz-19）；**只在貓體內的時期＝oocyst**（pz-42）。
2. **免疫正常成人後天感染弓蟲大多無症狀**（pz-06）；先天弓蟲症的母親是**懷孕時首次感染**（pz-41）；孕婦吃生的醃豬肉感染（pz-53）。
3. **隱孢子蟲屬於 Apicomplexa（coccidia）**（pz-01）。
4. **黑水熱 → 惡性瘧**（pz-16）；**黑熱病（kala-azar）和惡性瘧無關**（那是利什曼，pz-11）。
5. **腦性瘧疾只由惡性瘧造成**（pz-37）；西非回來的發燒病人 → 惡性瘧（pz-02、pz-05）。
6. **Primaquine 殺 hypnozoite、配子體**（pz-08）；**WHO 建議 ACT**（pz-38）；**屠呦呦發現青蒿素**（pz-04）。
7. 台灣有境外移入的**諾氏瘧**（pz-12）；**RTS,S 不是最好的預防方法**（保護力有限，pz-40）。
8. **巴貝氏蟲可經輸血感染**（pz-28、pz-43）。

## 📝 出題模式

- 臨床情境（旅遊史＋發燒型態＋血片）→ 選瘧原蟲種類與用藥。
- 「何者錯誤」：宿主角色（弓蟲貓 vs 人；瘧原蟲蚊 vs 人）、各期名稱、藥物作用對象。
- 名詞配對：relapse vs recrudescence、黑水熱 vs 黑熱病、Schüffner's dots、Maurer's clefts、band form。

## ⚠️ 陷阱整理

| ✗ 錯誤說法 | ✓ 正確 |
|---|---|
| 人是弓蟲的最終宿主 | **貓**是最終宿主；人是中間宿主 |
| 人是瘧原蟲的最終宿主 | 人是**中間宿主**（無性）；**瘧蚊**是最終宿主（有性） |
| 黑熱病是惡性瘧的併發症 | 黑熱病＝**內臟型利什曼病**；惡性瘧的是**黑水熱** |
| 所有瘧原蟲都會 relapse | 只有**間日瘧、卵圓瘧**（肝臟 hypnozoite）；治療不完全的再發叫 recrudescence |
| Primaquine 是主要的血液期用藥 | Primaquine 殺 **hypnozoite 與配子體**；G6PD 缺乏會溶血 |
| 配子體造成症狀 | 配子體**沒有病理意義**，是**蚊子的感染期** |
| 弓蟲藥物可以殺死組織囊體 | Pyrimethamine＋sulfa **殺不死組織囊體** |
| 隱孢子蟲可以用氯消毒 | **耐氯**，主要經水傳播 |
| 糞便直接鏡檢是隱孢子蟲最好的診斷 | 鏡檢最不敏感（約 30%）；**改良抗酸染色**、PCR、抗原檢測較好 |
| Duffy 陰性的人對惡性瘧有抗性 | Duffy 陰性抵抗**間日瘧**；band 3 變異（東南亞橢圓形紅血球症）抵抗惡性瘧 |
