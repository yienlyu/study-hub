## 1. 血液鞭毛蟲總論 ⭐⭐

- **肉足鞭毛門（Sarcomastigophora）動鞭綱（Zoomastigophora）**；寄生在**血液、組織或巨噬細胞內**，可造成嚴重疾病甚至死亡。
- **都由節肢動物傳播**、區域性很強，**台灣沒有本土病例**。
- 成員：

| 類別 | 種 | 疾病 |
|---|---|---|
| **非洲錐蟲** | *T. brucei gambiense*（岡比亞，**西非**）、*T. b. rhodesiense*（羅德西亞，**東非**） | 非洲昏睡病 |
| **美洲錐蟲** | *T. cruzi*（枯西氏）、*T. rangeli*（藍氏，對人無症狀） | Chagas disease |
| **利什曼原蟲** | *L. donovani*（內臟型 VL）、*L. braziliensis*（黏膜皮膚型 MCL）、*L. tropica*、*L. mexicana*（皮膚型 CL） | 利什曼病 |

### Kinetoplastida 的構造與型態

- 錐蟲 14–33 µm，「U」或「C」形；有**鞭毛、波動膜（undulating membrane）**、毛基體（kinetosome／basal body）、**動基體（kinetoplast）**。
- Kinetoplast DNA：**maxicircles** 編碼粒線體呼吸蛋白；**minicircles** 編碼 guide RNA，編輯 maxicircle 的 RNA。
- **四種型態**（依鞭毛起點與波動膜）：
  - **Amastigote（無鞭毛體）**：細胞內、沒有游離鞭毛（利什曼在巨噬細胞、*T. cruzi* 在肌肉細胞）。
  - **Promastigote（前鞭毛體／無膜）**：鞭毛從前端伸出、沒有波動膜（利什曼在白蛉體內）。
  - **Epimastigote（側鞭毛體／短膜）**：動基體在核前方、短波動膜（錐蟲在病媒體內）。
  - **Trypomastigote（錐鞭毛體）**：動基體在核後方、長波動膜（錐蟲在人血中）。

## 2. 非洲錐蟲 *T. brucei gambiense*／*T. b. rhodesiense* ⭐⭐⭐

- **非洲昏睡病（African sleeping sickness）**；**Salivarian（前位傳播）**：病媒**采采蠅（tsetse fly，舌蠅 *Glossina* spp.）**叮咬時從**唾腺**注入；只在非洲鄉村。
- 采采蠅：6 種是病媒、8–17 mm、**翅膀完全疊起**、長口器。
- **生活史**：
  - 人體：**metacyclic trypomastigote（後循環期，感染期）** → 血中 trypomastigote（slender、stumpy、intermediate form）。
  - 采采蠅：trypomastigote → **procyclic trypomastigote（前循環期，中腸）** → **epimastigote（唾腺）** → metacyclic trypomastigote（唾腺）。
- **症狀分期**：
  1. **Stage 1（急性，1–3 週）**：叮咬處 **trypanosomal chancre（下疳）**。
  2. **Stage 2（周邊循環）**：發燒、頭痛、疲倦、夜間盜汗、貧血；**Winterbottom's sign＝後頸淋巴結腫大**。
  3. **Stage 3（中樞神經）**：穿過 BBB → 臉部水腫、**Kerandel's sign**（深部感覺過敏）、腦膜腦炎、**嗜睡（somnolence）**、精神退化、人格改變、昏迷、死亡。
- **免疫逃脫：variable surface glycoprotein（VSG）抗原變換（antigenic switching）** → 一波波寄生蟲血症；**IgM 升高 4 倍以上**；DIC → 血小板低下；軟腦膜炎（Virchow-Robin space 淋巴球與漿細胞浸潤）；**prostaglandin D2 升高 → 嗜睡**。
- **兩亞種比較**：

| | *T. b. gambiense* | *T. b. rhodesiense* |
|---|---|---|
| 分布 | **西非**（沿河岸，病媒多、難控制） | **東非**（Malawi、Tanzania、Uganda、Zambia；病媒密度低、較好控制） |
| 病程 | **慢性**、CNS 侵犯較慢，嗜睡、昏迷，常死於肺炎 | **急性**、很快侵犯 CNS，發炎失調（perivascular cuffing） |
| DFMO | **有效** | **無效** |
| Suramin | 早期 | **早期（主要用於 rhodesiense）** |

- **診斷**：旅遊史；**血液、淋巴結、CSF** 找蟲；血清／CSF 的 IgM；**CATT（card agglutination test for trypanosomiasis）**。
- **治療**：
  - 早期：**pentamidine**（不能通過 BBB）、**suramin**（rhodesiense）。
  - 晚期（CNS）：**melarsoprol**（各期都可，含砷，Herxheimer reaction）、**DFMO（eflornithine）**抑制 ornithine decarboxylase，**對 rhodesiense 無效**。
  - 治療後要**連續兩年檢查 CSF**。
- 每年撒哈拉以南非洲約 10 萬人死亡。

## 3. 美洲錐蟲 *T. cruzi* ⭐⭐⭐

- **Chagas disease**（1909 年 Carlos Chagas 命名；秘魯、智利 4,000 年前的木乃伊驗出 *T. cruzi* DNA）。
- 病媒：**錐鼻蟲（triatomine，kissing bug／assassin bug，*Rhodnius*、*Triatoma*）**；**Stercorarian（後位傳播）**：錐鼻蟲吸血時在旁邊**排便**，糞便中的 metacyclic trypomastigote 經叮咬傷口或結膜進入。
  - *T. rangeli* 經 reduviid bug **叮咬**傳播，對人無症狀。
- **生活史**：
  - 人體：metacyclic trypomastigote → **amastigote（在各種組織細胞內複製，特別是肌肉）** → trypomastigote（入血）。
  - 錐鼻蟲：trypomastigote → epimastigote（**中腸**）→ metacyclic trypomastigote（**後腸**）。
- **症狀**：
  - **急性期（4–8 週）**：叮咬處 **chagoma**；**Romaña's sign（單側眼瞼腫脹，oculoglandular syndrome）**；發燒、疲倦、皮疹；1% 嚴重（心肌炎、腦部損傷，5 歲以下兒童可能死亡）。
  - **潛伏期（10 週到數年）**：無症狀。
  - **慢性期（20–30%）**：**心臟**（心肌肥大、心律不整、心衰竭；amastigote 在心肌形成 pseudocyst）；**消化道**（**巨食道症、巨結腸症**：破壞腸繫膜神經節與 **Auerbach's plexus**）。
  - 偏好侵犯肝 Kupffer cell、脾巨噬細胞、心肌細胞。
- 免疫：以 **IgG** 為主（**IgM 升高不像非洲錐蟲明顯**）；trypomastigote 抑制 C3b、C4b（阻斷替代路徑補體）；**沒有明顯的抗原變異** → 比較有機會做疫苗。
- **其他傳播途徑**：**輸血**、器官移植、**先天（母親急性期感染，< 10% 嬰兒）**、實驗室意外、汙染的食物飲料；HIV 等免疫低下可**再活化**。被稱為「美洲的新 AIDS」（玻利維亞、墨西哥、哥倫比亞、中美洲約 800 萬人）。
- **診斷**：急性期（幼童）**血片找蟲**；慢性期**血清學（IgG：IFA、ELISA、Machado-Guerreiro 補體結合試驗）**、PCR；**xenodiagnosis（病媒接種診斷）**：讓乾淨的錐鼻蟲吸病人的血，再檢查蟲糞中的 trypomastigote。
- **治療**（急性期治療才有效）：**nifurtimox**（90 天，**孕婦禁用**）、**benznidazole**（60 天）、allopurinol。
- 防治：泥土茅草屋改成木造或金屬、病媒控制、**捐血篩檢（PCR）**。

## 4. 利什曼原蟲 *Leishmania* spp. ⭐⭐⭐

- 1901 年 Leishman 發展染色法、1903 年 Donovan 用它看到 → **Leishman-Donovan body（LD body）＝ amastigote**。
- 病媒：**白蛉（sand fly）**——**舊世界 *Phlebotomus***（中東、印度、非洲）、**新世界 *Lutzomyia***（中南美）；白蛉卵產在富含有機質的土壤，孳生地難找 → 病媒控制困難。
- 保蟲宿主：沙鼠（gerbil）、樹懶（sloth）、蹄兔、狗等（**有動物保蟲宿主**；印度的內臟型可以沒有動物宿主、人傳人）。
- 分布：3.5 億人有風險、每年 150–200 萬病例；舊世界**不在澳洲、太平洋島嶼**；新世界**不在智利、烏拉圭**。
- **生活史**：白蛉叮咬注入 **metacyclic promastigote（感染期）** → 被**巨噬細胞**吞噬（CR1、CR3 協助附著）→ 在吞噬體內變成 **amastigote** 複製 → 白蛉吸血吸回 → 在白蛉中腸變成 procyclic → nectomonad → metacyclic promastigote。
  - 白蛉唾液的 **maxadilan**：擴張小動脈、抑制 T 細胞與巨噬細胞活化、吸引巨噬細胞。
  - 毒力：amastigote **下調 IL-12**、cysteine protease B、**leishmanolysin**（分解 type IV collagen 移到新細胞）；**Th1／NK → iNOS 殺蟲；Th2（IL-4、IL-13）→ polyamine 讓蟲存活**。
- **三型**：

| 型 | 主要病原 | 特徵 |
|---|---|---|
| **皮膚型 CL（東方癤 oriental sore）** | *L. tropica*、*L. major*、*L. mexicana* complex | 叮咬處 2–8 週出現**無痛紅色丘疹** → 擴大、**火山口狀潰瘍**（邊緣隆起）→ 留疤；多在臉、手、腳等暴露處。免疫無反應（anergy）→ **瀰漫性皮膚型（DCL）**；過敏 → leishmaniasis recidiva（再發） |
| **黏膜皮膚型 MCL** | ***L. braziliensis*** complex | **口、鼻黏膜潰瘍**、鼻中隔、唇、上顎嚴重毀容；南美（巴西、玻利維亞、秘魯）；潛伏 1 個月–30 年，可在初次病灶痊癒多年後發生 |
| **內臟型 VL（黑熱病 kala-azar）** | ***L. donovani*** complex（新世界 *L. chagasi*、地中海 *L. infantum*） | 侵犯**網狀內皮系統**：**肝脾腫大**、**一天兩到三次發燒高峰**、腹水、**皮膚變黑**；骨髓侵犯 → 貧血、白血球低下；**未治療 2 年內死亡率 75–90%**；> 90% 在印度、孟加拉、蘇丹、巴西 |

- **PKDL（post-kala-azar dermal leishmaniasis）**：內臟型治療後（多為治療失敗）出現的紅斑丘疹，**像瘤型痲瘋**。
- **診斷**：
  - CL／MCL／DCL：臨床表現與地區、白蛉叮咬史；**從潰瘍隆起的邊緣**採檢找 amastigote（不論病灶多久，蟲只在邊緣的活組織）、培養；**MCL 切片很難找到蟲，PCR 是確診方法**。
  - VL：**金標準＝骨髓、肝切片或脾臟抽吸找 amastigote（PCR）**——**不是血片**；培養（**NNN medium**、RPMI 1640、Schneider's）；ELISA、IFA；**rK39** 抗原（高敏感、高特異）、免疫層析快篩（ICT）。
- **治療**：**sodium stibogluconate（Pentostam，五價銻）**（抑制糖解與脂肪酸氧化，20 天）、**amphotericin B**、allopurinol（HIV 病人）、**miltefosine**（口服）、病灶內注射 IFN-γ。
- 防治：防白蛉叮咬、病媒控制、減少野生保蟲宿主、疫苗開發。

## 5. 錐蟲與利什曼比較 ⭐⭐⭐

| | 非洲錐蟲 | 美洲錐蟲 | 利什曼原蟲 |
|---|---|---|---|
| 病媒 | **采采蠅**（叮咬，前位） | **錐鼻蟲**（**糞便**，後位） | **白蛉**（叮咬） |
| 人體內型態 | **trypomastigote（血液、淋巴、CSF）** | trypomastigote（血）＋ **amastigote（組織、心肌）** | **amastigote（巨噬細胞內）** |
| 感染期 | metacyclic trypomastigote | metacyclic trypomastigote | **metacyclic promastigote** |
| 招牌 | chancre、**Winterbottom's sign**、昏睡、**VSG 抗原變換** | chagoma、**Romaña's sign**、心肌病、巨食道、巨結腸 | 東方癤、毀容、**黑熱病（肝脾腫大、皮膚變黑）**、PKDL |
| 診斷 | 血、淋巴結、CSF；CATT | 急性血片；慢性血清 IgG；xenodiagnosis | 病灶邊緣、**骨髓／脾**；rK39 |
| 藥 | pentamidine、suramin、melarsoprol、DFMO | **nifurtimox**、benznidazole | **Pentostam**、amphotericin B、miltefosine |

## 🎙️ 上課錄影重點（莊定武，2026 原蟲_II 錄影）

- **四種形態什麼時候出現，是考試很重要的地方**（老師原話）：amastigote、promastigote、epimastigote、trypomastigote **不是每隻都有四種**。
  - **利什曼只有前兩種**（amastigote、promastigote），沒有 epimastigote 與 trypomastigote。
  - 老師要大家念生活史時特別注意哪一期出現在哪個宿主。
- **毛基體（basal body）與動基體（kinetoplast）的相對位置**可以幫忙判斷是哪一期；染色時看得到 kinetoplast、basal body 與細胞核。
- **非洲錐蟲**：
  - 傳播是**前位傳播（salivarian）**，采采蠅**唾液腺**帶的是 **metacyclic trypomastigote**，老師說「這個名詞很重要，一定要記得」。
  - **VSG 是人體內蟲體的外套膜**（多變性醣蛋白）→ 免疫逃避；進到采采蠅體內後會脫掉，變成 procyclic。
  - **Winterbottom's sign（後頸部淋巴結腫大）是第二期很典型的臨床判定症狀**。
  - **嗜睡的機轉是前列腺素 D2（PGD2）異常升高**，打亂睡眠節律。
  - **gambiense 病程慢**（數月到數年才進 CNS）、**rhodesiense 快**（幾個月就到 CNS），這是臨床上很明顯的差異；但**形態上鏡檢分不出東非或西非**。
  - **診斷第一步是旅遊史**（地理區塊明確），再從 CSF 找蟲體；非洲現場用 **CATT 快篩**。
  - 治療複雜、「不是一服見效」：**pentamidine 不能穿過 BBB**，所以一定要在還沒進 CNS 時診斷出來；**越早診斷越好**。
- **美洲錐蟲**：
  - **錐鼻蟲（錐蝽）吸血策略原始**，口器不尖，要挑**眼窩、嘴唇旁**等皮膚柔軟處；吸血時會後退再往前衝。
  - **後位傳播（posterior station）**：錐蝽體內是 epimastigote；辨識重點是**細胞核、毛基體、動基體都在蟲體中間**。
  - **Romaña's sign（單側眼瞼腫）對應非洲錐蟲的 Winterbottom's sign**，是急性期的典型症狀。
  - **沒有 VSG**：不像非洲錐蟲會讓 IgM／IgG 大幅升高；它是感染樹突細胞後**下調 IL-6、IL-12、TNF** 等，抑制 Th1／Th2 活化，也抑制 **C3b、C4b**，躲在細胞內。
  - **鐵離子對枯西錐蟲複製很重要**，臨床上會用控制宿主鐵量來抑制複製。
  - **只有約四成病人 ECG 異常**。
  - **xenodiagnosis（病媒接種診斷）效果不亞於 PCR**；台灣沒有養錐蝽，日本長崎大學熱帶醫學中心有（日本有巴西移民案例）。
  - 保蟲宿主很多（浣熊、犰狳、負鼠、貓狗），所以**很難防控**。
- **利什曼**：
  - 名稱由來：1901 年 **William Leishman** 的染色、1903 年 **Charles Donovan** → **Leishman-Donovan（LD）body**。
  - **造成 MCL 的主要是 *L. braziliensis***，老師說「這倒是可以記一下」，流行區在亞馬遜盆地。
  - 潛伏期可以**數月到數年**（貧窮地區常延遲就醫）。
  - **PKDL** 是 VL 痊癒後的皮膚黑色素沉澱，容易和**痲瘋病**搞混。
  - 診斷重點：臨床表現＋**旅遊史**＋有沒有被**白蛉**叮咬的印象；取樣要取**病灶周邊**；現在多用 **PCR**。
  - 防治：巴西曾因野犬是 VL 保蟲宿主而**大量撲殺野犬**。
- 老師在進入孢子蟲前總結：「前面三個血液鞭毛蟲，**生活史裡面各個階段的名稱很重要**。」

# 考點分析

## 🔥 高頻考點（百十三原蟲考古）

1. **病媒配對**：非洲錐蟲 → **采采蠅**（不是蚊子，考古 pz-33）；美洲錐蟲 → **錐鼻蟲**；利什曼 → **白蛉**。
2. **Winterbottom's sign＋下疳＋西非 → *T. b. gambiense***（pz-10、pz-35）；東非 → rhodesiense（pz-44）。
3. **Gambiense vs rhodesiense**：**DFMO 只對 gambiense 有效**（「兩種都能用 DFMO」是錯的，pz-36）。
4. **黑熱病（kala-azar）**：印度、非洲旅遊後**肝脾腫大、貧血、一天兩次高燒**、骨髓巨噬細胞內看到 **amastigote** → *L. donovani*（pz-14、pz-24、pz-50）；**金標準是骨髓／脾臟，不是血片**（pz-34）。
5. **利什曼有動物保蟲宿主**（「沒有保蟲宿主」是錯的，pz-32）。
6. **感染期比較**：*T. cruzi* 是 **trypomastigote**、*Leishmania* 是 **promastigote**（pz-52）。

## 📝 出題模式

- **臨床情境題**最多：給旅遊地點＋症狀＋檢體所見 → 選病原或疾病。
- 「何者錯誤」型：病媒、保蟲宿主、診斷金標準、藥物適用範圍。
- 中英對照的國考風格題（百十三考古有標國考年份）。

## ⚠️ 陷阱整理

| ✗ 錯誤說法 | ✓ 正確 |
|---|---|
| 非洲錐蟲由蚊子傳播 | **采采蠅（*Glossina*）** |
| 美洲錐蟲靠叮咬時注入 | 錐鼻蟲**糞便**中的 trypomastigote 經傷口或結膜進入（後位傳播） |
| DFMO 兩種非洲錐蟲都有效 | **對 rhodesiense 無效** |
| 黑熱病用血片確診 | **骨髓、肝、脾**找 amastigote |
| 利什曼在人體以 promastigote 存在 | 人體內是**巨噬細胞內的 amastigote**；promastigote 在白蛉體內 |
| 利什曼沒有保蟲宿主 | 有（沙鼠、狗、樹懶等）；印度的 VL 可人傳人 |
| Romaña's sign 是非洲錐蟲 | **美洲錐蟲**（單側眼瞼腫）；非洲是 Winterbottom's sign |
| 美洲錐蟲 IgM 顯著升高 | 以 **IgG** 為主；IgM 明顯升高的是非洲錐蟲 |
