# 質體 DNA 限制酶反應 重點整理

> 2026/10/15 實驗課（周志銘）：用 BamHI、XhoI、EcoRI 切 pTMU 質體，跑洋菜膠，判斷 DNA 形狀並畫限制酶圖譜。講義：生化實驗上課講義－限制酵素反應；共筆：114 生化實 W5、W6（限制酵素反應）。

## 1. 限制酶的特性 ⭐⭐
- 限制酶 = restriction **endo**nuclease，細菌（與少數古菌）用來切入侵的外來 DNA（如噬菌體）的防禦蛋白；細菌把**自己的 DNA 甲基化**來避免被切。
- **序列專一**：點突變後就不切。**立體構造專一**：甲基化後就不切。
- 大多數需要 **Mg²⁺** → 加 **EDTA** 可以停止反應。（Type I 另外需要 SAM。）
- 活性定義：最適溫度（通常 **37 °C**）下，**1 U = 50 µL 反應中 1 小時完全切割 1 µg λ DNA** 的酵素量。
- 切完的末端：**5′-磷酸、3′-OH**。

## 2. 命名 ⭐
- **屬名第 1 字母＋種名前 2 字母（斜體）**＋品系（正體）＋**羅馬數字（發現順序）**。
- 例：*Escherichia coli* RY13 → **EcoRI**；同一菌株有兩種 → EcoRI、EcoRV；BglI、BglII。

## 3. 分類 ⭐⭐⭐
| 類型 | 組成 | 辨識與切割 | 常用？ |
|---|---|---|---|
| **Type I** | 2–3 種次單元，**同時有限制與甲基化**功能 | 切點離辨識位可達數千 bp（約 10 kb），位置不固定 | 不常用 |
| **Type II** | **限制與甲基化分開** | 辨識**短的回文序列**，在序列**內**切 | **最常用**（BamHI、XhoI、EcoRI 都是） |
| Type IIs | Type II 的子集 | 在辨識序列**下游**切 | |
| **Type III** | 和 Type I 類似，兼具修飾與切割 | 辨識短的不對稱序列，切在 24–26 bp 外 | 不常用 |

## 4. 本實驗用的三種限制酶 ⭐⭐⭐
| 酵素 | 來源 | 辨識序列 | 切法 | 末端 |
|---|---|---|---|---|
| **BamHI** | *Bacillus amyloliquefaciens* H | GGATCC | **G↓GATCC** | 5′ 突出黏端 |
| **XhoI** | *Xanthomonas holcicola* | CTCGAG | **C↓TCGAG** | 5′ 突出黏端 |
| **EcoRI** | *Escherichia coli* RY13 | GAATTC | **G↓AATTC** | 5′ 突出黏端 |
- 其他末端：**BglI、BluI 切出 3′ 突出**；**PvuII（CAG↓CTG）切出平端（blunt end）**。

## 5. 實驗流程
1. 每組 5 管：undigested（3 µL DNA ＋ 17 µL ddH₂O）、BamHI、BamHI＋XhoI、XhoI、EcoRI（3 µL DNA ＋ 17 µL enzyme mix，內含 buffer）。
2. 混勻、spin down，**37 °C 水浴 45–60 分鐘**。
3. 各加 **2 µL 10× loading dye**，取 10 µL 上樣；M 是 **1 kb DNA ladder**。
4. **120 V、20 分鐘** → 燈箱照相，上傳結果。

- pTMU = pGEM-T 載體（約 4.2 kb）＋ TMU gene（1139 bp）。EcoRI 位置在插入片段兩側，BamHI 和 XhoI 各在插入片段的一端 → 預期 BamHI 單切得一條約 4.2 kb 的線狀帶；BamHI＋XhoI 與 EcoRI 都切出約 1.1–1.2 kb 的插入片段＋約 3 kb 的載體。

## 6. 判斷線狀或環狀 ⭐⭐⭐
| | 一個切位 | n 個切位 |
|---|---|---|
| **線狀 DNA** | 2 個片段 | **n + 1** 個片段 |
| **環狀 DNA** | **1 個片段** | **n** 個片段 |
- 單切只出現一條帶、而且大小等於全長 → **環狀**。
- 每種酵素單切都有好幾個片段、加總等於全長 → 用片段數推回是線狀（n+1）還是環狀（n）。
- 帶特別粗：可能是兩個一樣大的片段疊在一起（例：9 kb 線狀 DNA 被 XhoI 切成 4＋4＋1）。

## 7. 畫限制酶圖譜（必考手寫題） ⭐⭐⭐
1. 先判斷線狀或環狀，**寫出 DNA 全長**（左上角一定要寫）。
2. 選切位最多的酵素當基準，標出它的切點。
3. 用雙切的片段大小推另一個酵素的切點在哪個片段裡、離基準切點多遠（雙切片段 = 單切片段再被切一刀）。
4. 檢查：每一組雙切的片段加總要等於全長。

## 8. 結果判讀
- 未切的質體兩條帶：**SC 跑得快（在下）**、少量 nicked／OC 在上。
- **DNA smear（拖尾）**：DNA 部分降解（反覆凍融、放太久、抽取時剪力太大）、DNase 污染（沒戴手套）、樣品太濃、膠品質不好。
- 雙切的 lane 裡若還有單切大小的帶 → **切不完全**（部分 DNA 只被其中一種酶切到）。

# 考點分析

## 🔥 高頻考點
- **EcoRI 屬 Type II**（手寫題）。
- **畫限制酶圖譜**：114 考三題（pTest 15.6 kb 線狀、一張 16 道雙切膠圖、一張 11 道雙切膠圖），都要先判斷線狀或環狀。
- 單切只有一條帶 → 環狀；n 個切位 → 環狀 n 段、線狀 n+1 段。
- 雙切 lane 出現單切大小的帶 → 切不完全。

## 📝 出題模式
- 這一單元幾乎都是**手寫題**：判斷形狀、畫圖譜、解釋某 lane 的結果。圖譜題的原圖請看 slides/biochemistry/共筆考古/百十三資料/生化(二)/考古/終審版/實驗/1141生化實考古 周志銘老師.pdf 第 4–6 頁。
- 單選偶爾問限制酶類型、辨識序列、需要的離子。

## ⚠️ 陷阱整理
| 容易選錯 | 正確 |
|---|---|
| 限制酶是外切酶 | **內切酶**（endonuclease） |
| Type I 最常用 | **Type II** 最常用 |
| 單切出一條帶 = 線狀 | 一條帶（全長）= **環狀** |
| 圖譜不用寫全長 | **一定要寫 DNA 全長** |
| 停止反應要加熱或加 SDS | 加 **EDTA** 螯合 Mg²⁺ 最直接 |
